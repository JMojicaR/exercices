## 1. Hello, World!
**Description:** Create a class with a `main` method that prints a greeting. The canonical first Java program that introduces the class/method structure.
**Difficulty:** Basic
**Concepts:** Class declaration, `public static void main`, `System.out.println()`.
**Starter code:**
```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

## 2. Even or Odd
**Description:** Read an integer and print whether it is even or odd.
**Difficulty:** Basic
**Concepts:** `Scanner` for input, conditionals, modulo operator.
**Starter code:**
```java
import java.util.Scanner;

public class EvenOdd {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = sc.nextInt();
        if (n % 2 == 0) {
            System.out.println(n + " is even");
        } else {
            System.out.println(n + " is odd");
        }
        sc.close();
    }
}
```

## 3. Sum of Array Elements
**Description:** Declare an array of integers and compute the sum of all its elements.
**Difficulty:** Basic
**Concepts:** Arrays, `for` loop, array `.length`.
**Starter code:**
```java
public class ArraySum {
    public static void main(String[] args) {
        int[] numbers = {1, 2, 3, 4, 5};
        int sum = 0;
        for (int i = 0; i < numbers.length; i++) {
            sum += numbers[i];
        }
        System.out.println("Sum: " + sum);
    }
}
```

## 4. Factorial
**Description:** Compute the factorial of a number using a loop (and optionally recursion).
**Difficulty:** Basic
**Concepts:** Loops, recursion, method definition, integer overflow awareness.
**Starter code:**
```java
public class Factorial {
    static int factorial(int n) {
        int result = 1;
        for (int i = 1; i <= n; i++) {
            result *= i;
        }
        return result;
    }

    public static void main(String[] args) {
        System.out.println("5! = " + factorial(5));
    }
}
```

## 5. Palindrome Checker
**Description:** Check whether a given string reads the same forwards and backwards.
**Difficulty:** Basic
**Concepts:** `String` methods, loops, `charAt()`, conditionals.
**Starter code:**
```java
public class Palindrome {
    static boolean isPalindrome(String s) {
        int left = 0, right = s.length() - 1;
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }

    public static void main(String[] args) {
        System.out.println(isPalindrome("racecar")); // true
        System.out.println(isPalindrome("hello"));   // false
    }
}
```
