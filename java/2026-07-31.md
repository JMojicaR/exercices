## Exercise 1: Hello World and User Input

**Title:** Hello, Java! — Your First Program

**Description:** Write a Java program that prints "Hello, World!" to the console. Then extend it to ask the user for their name using `Scanner` and print a personalized greeting.

**Difficulty:** ★☆☆☆☆ (Very Easy)

**Concepts Practiced:**
- Class and `main` method
- `System.out.println()`
- `Scanner` for user input
- Variables and string concatenation
- Import statements

**Starter Code:**
```java
// Exercise 1: Hello, Java!
import java.util.Scanner;

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");

        Scanner scanner = new Scanner(System.in);
        System.out.print("Enter your name: ");
        String name = scanner.nextLine();
        System.out.println("Welcome, " + name + "!");
        scanner.close();
    }
}
```

## Exercise 2: Simple Calculator with Switch

**Title:** Basic Arithmetic Calculator

**Description:** Write a Java program that takes two numbers and an operator (+, -, *, /) from the user, then performs the calculation using a `switch` statement. Handle division by zero.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- `Scanner` for reading numbers
- `switch` statement
- Arithmetic operators
- Conditional logic (division by zero check)
- `double` data type

**Starter Code:**
```java
// Exercise 2: Simple Calculator
import java.util.Scanner;

public class Calculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter first number: ");
        double num1 = scanner.nextDouble();

        System.out.print("Enter operator (+, -, *, /): ");
        char operator = scanner.next().charAt(0);

        System.out.print("Enter second number: ");
        double num2 = scanner.nextDouble();

        double result;
        switch (operator) {
            case '+': result = num1 + num2; break;
            case '-': result = num1 - num2; break;
            case '*': result = num1 * num2; break;
            case '/':
                if (num2 != 0) result = num1 / num2;
                else { System.out.println("Error: Division by zero!"); return; }
                break;
            default:
                System.out.println("Invalid operator!");
                return;
        }

        System.out.println("Result: " + result);
        scanner.close();
    }
}
```

## Exercise 3: Factorial Calculator

**Title:** Factorial Using Loop and Recursion

**Description:** Write a Java program that calculates the factorial of a given number. Implement it in two ways: using a `for` loop and using a recursive method. The factorial of n (n!) is the product of all positive integers from 1 to n.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- `for` loops
- Recursive methods
- Method overloading (optional)
- `long` data type (large numbers)
- Input validation (non-negative)

**Starter Code:**
```java
// Exercise 3: Factorial Calculator
import java.util.Scanner;

public class Factorial {
    // Iterative method
    public static long factorialLoop(int n) {
        long result = 1;
        for (int i = 1; i <= n; i++) {
            result *= i;
        }
        return result;
    }

    // Recursive method
    public static long factorialRecursive(int n) {
        if (n == 0 || n == 1) return 1;
        return n * factorialRecursive(n - 1);
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Enter a non-negative integer: ");
        int n = scanner.nextInt();

        if (n < 0) {
            System.out.println("Factorial not defined for negative numbers.");
        } else {
            System.out.println(n + "! (loop) = " + factorialLoop(n));
            System.out.println(n + "! (recursive) = " + factorialRecursive(n));
        }
        scanner.close();
    }
}
```

## Exercise 4: Prime Number Checker

**Title:** Is It a Prime Number?

**Description:** Write a Java program that checks whether a given integer is a prime number. A prime number is only divisible by 1 and itself. Test numbers from 2 to a user-provided limit and list all primes in that range.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Nested `for` loops
- Modulo operator
- Boolean flags
- Method creation
- Algorithmic thinking

**Starter Code:**
```java
// Exercise 4: Prime Number Checker
import java.util.Scanner;

public class PrimeChecker {
    public static boolean isPrime(int n) {
        if (n <= 1) return false;
        for (int i = 2; i <= Math.sqrt(n); i++) {
            if (n % i == 0) return false;
        }
        return true;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Enter the upper limit: ");
        int limit = scanner.nextInt();

        System.out.println("Prime numbers up to " + limit + ":");
        for (int i = 2; i <= limit; i++) {
            if (isPrime(i)) {
                System.out.print(i + " ");
            }
        }
        System.out.println();
        scanner.close();
    }
}
```

## Exercise 5: Array Operations

**Title:** Array Manipulation — Max, Min, Average, Search

**Description:** Write a Java program that creates an array of integers, then performs the following: find maximum and minimum values, calculate the average, reverse the array, and search for a specific number.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Array declaration and initialization
- Iterating over arrays
- Array algorithms (max, min, sum)
- Array reversal (in-place or new array)
- Linear search

**Starter Code:**
```java
// Exercise 5: Array Operations
public class ArrayOperations {
    public static void main(String[] args) {
        int[] numbers = {23, 45, 12, 67, 34, 89, 15, 42};

        // Find max and min
        int max = numbers[0], min = numbers[0];
        int sum = 0;
        for (int num : numbers) {
            if (num > max) max = num;
            if (num < min) min = num;
            sum += num;
        }

        double average = (double) sum / numbers.length;

        System.out.println("Array: " + java.util.Arrays.toString(numbers));
        System.out.println("Maximum: " + max);
        System.out.println("Minimum: " + min);
        System.out.println("Average: " + average);

        // Reverse the array
        System.out.print("Reversed: [");
        for (int i = numbers.length - 1; i >= 0; i--) {
            System.out.print(numbers[i]);
            if (i > 0) System.out.print(", ");
        }
        System.out.println("]");

        // Search for a value
        int searchValue = 34;
        boolean found = false;
        for (int i = 0; i < numbers.length; i++) {
            if (numbers[i] == searchValue) {
                System.out.println(searchValue + " found at index " + i);
                found = true;
                break;
            }
        }
        if (!found) System.out.println(searchValue + " not found.");
    }
}
```
