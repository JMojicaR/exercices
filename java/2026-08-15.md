## Exercise 1: Sum of Digits

**Difficulty:** Basic

### Problem
Write a Java program that reads an integer and calculates the sum of its digits.

**Given Input:** `1234`

**Expected Output:**
```
Sum of digits: 10
```

### Concepts
- `while` loops
- Modulo (`%`) and integer division (`/`)
- Primitive `int` variables

### Example / Starter Code

```java
public class SumOfDigits {
    public static void main(String[] args) {
        int num = 1234;
        int sum = 0;

        while (num > 0) {
            sum += num % 10;
            num /= 10;
        }

        System.out.println("Sum of digits: " + sum);
    }
}
```

## Exercise 2: Check Prime Number

**Difficulty:** Basic

### Problem
Write a method `isPrime(int n)` that returns `true` if `n` is a prime number and `false` otherwise.

**Given Input:**
- `isPrime(11)`
- `isPrime(15)`

**Expected Output:**
- `true`
- `false`

### Concepts
- Static methods with boolean return type
- `for` loops with `break`/early return
- `Math.sqrt()` for optimization

### Example / Starter Code

```java
public class PrimeCheck {
    static boolean isPrime(int n) {
        if (n < 2) return false;
        for (int i = 2; i <= Math.sqrt(n); i++) {
            if (n % i == 0) return false;
        }
        return true;
    }

    public static void main(String[] args) {
        System.out.println(isPrime(11));  // true
        System.out.println(isPrime(15));  // false
    }
}
```

## Exercise 3: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a Java program that finds the largest of three integers.

**Given Input:** `a = 10, b = 25, c = 15`

**Expected Output:**
```
Largest: 25
```

### Concepts
- `if` comparison logic
- Conditional assignment
- Comparing primitive values

### Example / Starter Code

```java
public class LargestOfThree {
    public static void main(String[] args) {
        int a = 10, b = 25, c = 15;
        int max = a;

        if (b > max) max = b;
        if (c > max) max = c;

        System.out.println("Largest: " + max);
    }
}
```

## Exercise 4: Armstrong Number

**Difficulty:** Basic

### Problem
Write a Java program that checks whether a number is an Armstrong number. A number is Armstrong if it equals the sum of the cubes of its digits (e.g. `153 = 1³ + 5³ + 3³`).

**Given Input:** `153`

**Expected Output:**
```
153 is an Armstrong number
```

### Concepts
- `while` loops
- Extracting digits with `% 10`
- Accumulator pattern
- Ternary operator for output

### Example / Starter Code

```java
public class Armstrong {
    public static void main(String[] args) {
        int num = 153, sum = 0, temp = num;

        while (temp > 0) {
            int digit = temp % 10;
            sum += digit * digit * digit;
            temp /= 10;
        }

        System.out.println(num + (sum == num ? " is" : " is not") + " an Armstrong number");
    }
}
```

## Exercise 5: Count Vowels

**Difficulty:** Basic

### Problem
Write a Java program that counts the number of vowels in a string (case-insensitive).

**Given Input:** `"Hello World"`

**Expected Output:**
```
Vowels: 3
```

### Concepts
- `String.toLowerCase()`
- `String.toCharArray()` / enhanced `for` loop
- Character comparison with `==`

### Example / Starter Code

```java
public class CountVowels {
    public static void main(String[] args) {
        String text = "Hello World".toLowerCase();
        int count = 0;

        for (char c : text.toCharArray()) {
            if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
                count++;
            }
        }

        System.out.println("Vowels: " + count);
    }
}
```
