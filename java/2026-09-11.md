## Exercise 3: Factorial
- **Difficulty:** Easy
- **Description:** Write a method `factorial(int n)` that returns n! using recursion (handle 0! = 1), and print the result for `factorial(5)`.
- **Concepts:** methods, recursion, base case, return types
- **Starter code:**
```java
public class Main {
    static int factorial(int n) {
        if (n == 0) return 1;
        return n * factorial(n - 1);
    }

    public static void main(String[] args) {
        System.out.println(factorial(5)); // 120
    }
}
```
