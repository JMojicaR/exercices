## Exercise 1: Linear Search
**Difficulty:** Basic
**Concepts:** `for` loop, array indexing, comparison, `return`, `static` method

Write a method that searches for a target value in an array and returns its index, or `-1` if not found.

**Starter code:**
```java
public class LinearSearch {
    public static int linearSearch(int[] arr, int target) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == target) {
                return i;
            }
        }
        return -1;
    }

    public static void main(String[] args) {
        int[] numbers = {10, 23, 45, 70, 11, 15};
        System.out.println(linearSearch(numbers, 70)); // expected: 3
        System.out.println(linearSearch(numbers, 99)); // expected: -1
    }
}
```

**Task:** Change the method to return the *count* of matching elements instead of the first index.

## Exercise 2: Binary Search
**Difficulty:** Basic
**Concepts:** `while` loop, midpoint index, sorted input, integer arithmetic

Search for a target in a *sorted* array using binary search, halving the search range each step.

**Starter code:**
```java
public class BinarySearch {
    public static int binarySearch(int[] arr, int target) {
        int low = 0, high = arr.length - 1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] == target) return mid;
            if (arr[mid] < target) low = mid + 1;
            else high = mid - 1;
        }
        return -1;
    }

    public static void main(String[] args) {
        int[] sorted = {1, 3, 5, 7, 9, 11, 13};
        System.out.println(binarySearch(sorted, 9)); // expected: 4
        System.out.println(binarySearch(sorted, 4)); // expected: -1
    }
}
```

**Task:** Print the value of `low`, `high`, and `mid` at the top of each loop iteration to visualize how the range shrinks.

## Exercise 3: Bubble Sort
**Difficulty:** Basic
**Concepts:** nested `for` loops, swapping with a temp variable, comparison operators

Sort an array in ascending order using bubble sort (repeatedly swap adjacent out-of-order elements).

**Starter code:**
```java
import java.util.Arrays;

public class BubbleSort {
    public static void bubbleSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - 1 - i; j++) {
                if (arr[j] > arr[j + 1]) {
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }
    }

    public static void main(String[] args) {
        int[] data = {64, 34, 25, 12, 22, 11, 90};
        bubbleSort(data);
        System.out.println(Arrays.toString(data)); // expected: [11, 12, 22, 25, 34, 64, 90]
    }
}
```

**Task:** Add a `boolean swapped` flag that breaks out of the outer loop early when a pass makes no swaps.

## Exercise 4: Find Minimum and Maximum
**Difficulty:** Basic
**Concepts:** iteration, comparison, tracking state variables, empty-array edge case

Find and return the smallest and largest values in an array in a single pass.

**Starter code:**
```java
public class MinMax {
    public static int[] findMinMax(int[] arr) {
        if (arr.length == 0) return new int[0];
        int min = arr[0], max = arr[0];
        for (int val : arr) {
            if (val < min) min = val;
            if (val > max) max = val;
        }
        return new int[]{min, max};
    }

    public static void main(String[] args) {
        int[] nums = {45, 2, 78, 13, 9, 54};
        int[] result = findMinMax(nums);
        System.out.println("Min: " + result[0] + " Max: " + result[1]); // Min: 2 Max: 78
    }
}
```

**Task:** Also return the *indices* of the min and max elements (hint: return a 4-element array or track `minIdx`/`maxIdx`).

## Exercise 5: Selection Sort
**Difficulty:** Basic
**Concepts:** nested loops, index tracking, swapping, finding the minimum in a sub-range

Sort an array using selection sort: repeatedly find the smallest remaining element and move it to the front.

**Starter code:**
```java
import java.util.Arrays;

public class SelectionSort {
    public static void selectionSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n; i++) {
            int minIdx = i;
            for (int j = i + 1; j < n; j++) {
                if (arr[j] < arr[minIdx]) minIdx = j;
            }
            int temp = arr[i];
            arr[i] = arr[minIdx];
            arr[minIdx] = temp;
        }
    }

    public static void main(String[] args) {
        int[] data = {29, 10, 14, 37, 13};
        selectionSort(data);
        System.out.println(Arrays.toString(data)); // expected: [10, 13, 14, 29, 37]
    }
}
```

**Task:** Sort in *descending* order by changing a single comparison, and skip the swap when `minIdx == i`.
