## Exercise 1: Bubble Sort

**Difficulty:** Basic

### Problem
Write a program that sorts an integer array in ascending order using bubble sort.

**Given Input:** `{64, 34, 25, 12, 22, 11, 90}`

**Expected Output:**
```
Sorted: [11, 12, 22, 25, 34, 64, 90]
```

### Concepts
- Nested `for` loops
- Temporary-variable swap
- `Arrays.toString()`

### Example / Starter Code

```java
import java.util.Arrays;

public class BubbleSort {
    public static void main(String[] args) {
        int[] arr = {64, 34, 25, 12, 22, 11, 90};
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - i - 1; j++) {
                if (arr[j] > arr[j + 1]) {
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }
        System.out.println("Sorted: " + Arrays.toString(arr));
    }
}
```

## Exercise 2: Linear Search

**Difficulty:** Basic

### Problem
Write a program with a `linearSearch` method that returns the index of a target value in an array, or `-1` if absent.

**Given Input:** array `{10, 23, 45, 70, 11, 15}`, target `70`

**Expected Output:**
```
Found at index 3
```

### Concepts
- Static methods
- `for` loop with array `.length`
- Early `return`

### Example / Starter Code

```java
public class LinearSearch {
    public static int linearSearch(int[] arr, int target) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == target) return i;
        }
        return -1;
    }

    public static void main(String[] args) {
        int[] nums = {10, 23, 45, 70, 11, 15};
        int index = linearSearch(nums, 70);
        System.out.println(index != -1 ? "Found at index " + index : "Not found");
    }
}
```

## Exercise 3: Anagram Check

**Difficulty:** Basic

### Problem
Write a program that checks whether two strings are anagrams, ignoring case.

**Given Input:** `"listen"`, `"silent"`

**Expected Output:**
```
Anagram
```

### Concepts
- `toLowerCase()` and `toCharArray()`
- `Arrays.sort()`
- `Arrays.equals()`

### Example / Starter Code

```java
import java.util.Arrays;

public class Anagram {
    public static boolean isAnagram(String s1, String s2) {
        char[] a = s1.toLowerCase().toCharArray();
        char[] b = s2.toLowerCase().toCharArray();
        Arrays.sort(a);
        Arrays.sort(b);
        return Arrays.equals(a, b);
    }

    public static void main(String[] args) {
        System.out.println(isAnagram("listen", "silent") ? "Anagram" : "Not an anagram");
    }
}
```

## Exercise 4: Greatest Common Divisor (GCD)

**Difficulty:** Basic

### Problem
Write a program that computes the GCD of two positive integers using the Euclidean algorithm.

**Given Input:** `48`, `18`

**Expected Output:**
```
GCD: 6
```

### Concepts
- `while` loop
- Modulo `%`
- Local variable reassignment

### Example / Starter Code

```java
public class GCD {
    public static int gcd(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }

    public static void main(String[] args) {
        System.out.println("GCD: " + gcd(48, 18));
    }
}
```

## Exercise 5: Armstrong Number Check

**Difficulty:** Basic

### Problem
Write a program that checks whether a number is an Armstrong number.

**Given Input:** `153`

**Expected Output:**
```
Armstrong
```

### Concepts
- `Integer.toString()` and `length()`
- Enhanced `for` over `char[]`
- `Math.pow()`

### Example / Starter Code

```java
public class Armstrong {
    public static boolean isArmstrong(int n) {
        String s = Integer.toString(n);
        int power = s.length();
        int total = 0;
        for (char c : s.toCharArray()) {
            total += Math.pow(c - '0', power);
        }
        return total == n;
    }

    public static void main(String[] args) {
        System.out.println(isArmstrong(153) ? "Armstrong" : "Not Armstrong");
    }
}
```
