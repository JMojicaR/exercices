## Exercise 1: Print the ASCII Value of a Character
**Difficulty:** Basic
**Concepts:** type casting (`char` → `int`), characters as numbers

Given a character, print its ASCII value by casting it to an integer.

**Starter code:**
```java
public class AsciiValue {
    public static void main(String[] args) {
        char ch = 'A';
        int ascii = (int) ch;
        System.out.println("ASCII value of " + ch + " is " + ascii);
    }
}
```

**Task:** Print the ASCII values of the letters A–Z using a `for` loop (`for (char c = 'A'; c <= 'Z'; c++)`).

## Exercise 2: Check Vowel or Consonant
**Difficulty:** Basic
**Concepts:** `switch`, `case`, `char` comparisons

Read a letter and report whether it is a vowel or a consonant.

**Starter code:**
```java
public class VowelConsonant {
    public static void main(String[] args) {
        char ch = 'e';
        ch = Character.toLowerCase(ch);

        switch (ch) {
            case 'a': case 'e': case 'i': case 'o': case 'u':
                System.out.println(ch + " is a vowel");
                break;
            default:
                System.out.println(ch + " is a consonant");
        }
    }
}
```

**Task:** Use `Scanner` to read the letter from the user, and print "Not a letter" for non-alphabetic characters.

## Exercise 3: Maximum and Minimum in an Array
**Difficulty:** Basic
**Concepts:** arrays, `for` loops, comparisons

Find the largest and smallest values in an integer array.

**Starter code:**
```java
public class MaxMin {
    public static void main(String[] args) {
        int[] numbers = {45, 12, 78, 34, 89, 23};
        int max = numbers[0];
        int min = numbers[0];

        for (int n : numbers) {
            if (n > max) max = n;
            if (n < min) min = n;
        }

        System.out.println("Max: " + max + ", Min: " + min);
    }
}
```

**Task:** Extend it to also compute the sum and average of the array.

## Exercise 4: Simple Calculator
**Difficulty:** Basic
**Concepts:** `switch`, `Scanner`, arithmetic operators

Build a calculator that reads two numbers and an operator and prints the result.

**Starter code:**
```java
import java.util.Scanner;

public class Calculator {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("First number: ");
        double a = sc.nextDouble();
        System.out.print("Second number: ");
        double b = sc.nextDouble();
        System.out.print("Operator (+, -, *, /): ");
        char op = sc.next().charAt(0);

        switch (op) {
            case '+': System.out.println(a + b); break;
            case '-': System.out.println(a - b); break;
            case '*': System.out.println(a * b); break;
            case '/':
                if (b != 0) System.out.println(a / b);
                else System.out.println("Cannot divide by zero");
                break;
            default: System.out.println("Invalid operator");
        }
        sc.close();
    }
}
```

**Task:** Add a `%` (remainder) case, and use `sc.hasNextDouble()` to validate numeric input.

## Exercise 5: Print Prime Numbers in a Range
**Difficulty:** Basic
**Concepts:** nested `for` loops, `break`, boolean flags

Print every prime number between two given bounds (e.g. 10 and 50).

**Starter code:**
```java
public class PrimesInRange {
    public static void main(String[] args) {
        int start = 10, end = 50;

        for (int num = start; num <= end; num++) {
            boolean isPrime = num >= 2;
            for (int i = 2; i <= Math.sqrt(num); i++) {
                if (num % i == 0) {
                    isPrime = false;
                    break;
                }
            }
            if (isPrime) System.out.print(num + " ");
        }
    }
}
```

**Task:** Extract the check into a `static boolean isPrime(int n)` method and count the primes printed.
