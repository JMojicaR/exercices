## Exercise 1: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** arrays, `for` loop, accumulation

Compute the sum of all elements in an integer array.

**Starter code:**
```java
public class SumArray {
    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};
        int sum = 0;
        for (int n : numbers) {
            sum += n;
        }
        System.out.println("Sum: " + sum);
    }
}
```

**Task:** Use an index-based `for` loop instead of the enhanced `for` loop.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** modulo operator (`%`), `if/else`

Check whether a number is even or odd.

**Starter code:**
```java
public class EvenOdd {
    public static void main(String[] args) {
        int n = 7;
        if (n % 2 == 0) {
            System.out.println(n + " is even");
        } else {
            System.out.println(n + " is odd");
        }
    }
}
```

**Task:** Read the number from the user with `Scanner`.

## Exercise 3: Celsius to Fahrenheit
**Difficulty:** Basic
**Concepts:** arithmetic, methods, `Scanner` input

Convert Celsius to Fahrenheit using `F = C × 9/5 + 32`.

**Starter code:**
```java
public class Temperature {
    public static double cToF(double celsius) {
        return (celsius * 9 / 5) + 32;
    }

    public static void main(String[] args) {
        System.out.println("20°C = " + cToF(20) + "°F");
    }
}
```

**Task:** Add a `fToC` method that converts Fahrenheit back to Celsius.

## Exercise 4: Find the Smallest Number
**Difficulty:** Basic
**Concepts:** arrays, comparison, loops

Find the smallest value in an integer array.

**Starter code:**
```java
public class Smallest {
    public static void main(String[] args) {
        int[] numbers = {45, 12, 78, 4, 33};
        int smallest = numbers[0];
        for (int n : numbers) {
            if (n < smallest) smallest = n;
        }
        System.out.println("Smallest: " + smallest);
    }
}
```

**Task:** Also find the largest value in the same array.

## Exercise 5: Simple Interest
**Difficulty:** Basic
**Concepts:** variables, arithmetic, methods

Calculate simple interest using `SI = (P × R × T) / 100`.

**Starter code:**
```java
public class Interest {
    public static void main(String[] args) {
        double principal = 1000, rate = 5, time = 3;
        double interest = (principal * rate * time) / 100;
        System.out.println("Simple interest: " + interest);
    }
}
```

**Task:** Also print the total amount (principal + interest).
