## Exercise 1: Define a Node Class and Build a List
**Difficulty:** Basic
**Concepts:** class with fields and constructor, object references, `while`-loop traversal

**Starter code:**
```java
class Node {
    int value;
    Node next;

    Node(int value) {
        this.value = value;
        this.next = null;
    }
}

public class Main {
    public static void main(String[] args) {
        Node head = new Node(10);
        head.next = new Node(20);
        head.next.next = new Node(30);

        Node current = head;
        while (current != null) {
            System.out.print(current.value + " ");
            current = current.next;
        }
        // prints: 10 20 30
    }
}
```

**Task:** Add a `printList(Node head)` method that prints values separated by `" -> "` and ends with `"null"`.

## Exercise 2: Append a Node to the End
**Difficulty:** Basic
**Concepts:** walking to the tail, empty-list edge case, updating references

**Starter code:**
```java
static Node append(Node head, int value) {
    if (head == null) return new Node(value);
    Node current = head;
    while (current.next != null) {
        current = current.next;
    }
    current.next = new Node(value);
    return head;
}
```

**Task:** Append the numbers `1..5` to an empty list inside a loop and print the result.

## Exercise 3: Length and Sum of a Linked List
**Difficulty:** Basic
**Concepts:** counter variable, accumulating a running total

**Starter code:**
```java
static int length(Node head) {
    int count = 0;
    Node current = head;
    while (current != null) {
        count++;
        current = current.next;
    }
    return count;
}

static int sum(Node head) {
    int total = 0;
    Node current = head;
    while (current != null) {
        total += current.value;
        current = current.next;
    }
    return total;
}
```

**Task:** Build `4 -> 6 -> 8` and verify `length` returns `3` and `sum` returns `18`.

## Exercise 4: Search for a Value
**Difficulty:** Basic
**Concepts:** early `return`, comparing primitives with `==`

**Starter code:**
```java
static boolean contains(Node head, int target) {
    Node current = head;
    while (current != null) {
        if (current.value == target) return true;
        current = current.next;
    }
    return false;
}
```

**Task:** Write `indexOf(Node head, int target)` returning the 0-based index of the first match, or `-1`.

## Exercise 5: Delete the First Matching Node
**Difficulty:** Basic
**Concepts:** rewiring `next` references, head-removal special case

**Starter code:**
```java
static Node delete(Node head, int value) {
    if (head == null) return null;
    if (head.value == value) return head.next;
    Node current = head;
    while (current.next != null && current.next.value != value) {
        current = current.next;
    }
    if (current.next != null) {
        current.next = current.next.next;
    }
    return head;
}
```

**Task:** Test removing the head, a middle node, and a missing value from `10 -> 20 -> 30`.
