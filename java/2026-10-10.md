## Exercise 1: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** loops, variables, class with main method

Print the first `n` numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...).

**Starter code:**
```java
import java.util.Scanner;

public class Fibonacci {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("How many numbers? ");
        int n = sc.nextInt();
        int a = 0, b = 1;
        for (int i = 0; i < n; i++) {
            System.out.print(a + " ");
            int next = a + b;
            a = b;
            b = next;
        }
        sc.close();
    }
}
```

**Task:** Print only the Fibonacci numbers below a user-specified limit.

## Exercise 2: Reverse a Number
**Difficulty:** Basic
**Concepts:** while loop, modulo, integer arithmetic

Read an integer and print its digits in reverse order (e.g. 1234 → 4321).

**Starter code:**
```java
import java.util.Scanner;

public class ReverseNumber {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = sc.nextInt();
        int reversed = 0;
        while (n != 0) {
            reversed = reversed * 10 + n % 10;
            n /= 10;
        }
        System.out.println("Reversed: " + reversed);
        sc.close();
    }
}
```

**Task:** Check whether the original number is a palindrome (equals its reverse).

## Exercise 3: Sum of Digits
**Difficulty:** Basic
**Concepts:** while loop, modulo, integer division

Compute the sum of the digits of a positive integer (e.g. 1234 → 10).

**Starter code:**
```java
import java.util.Scanner;

public class SumOfDigits {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a positive integer: ");
        int n = sc.nextInt();
        int sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        System.out.println("Sum of digits: " + sum);
        sc.close();
    }
}
```

**Task:** Also print the product of the digits and the count of digits.

## Exercise 4: FizzBuzz
**Difficulty:** Basic
**Concepts:** for loop, conditionals, modulo

Print numbers from 1 to a given `n`, replacing multiples of 3 with "Fizz", multiples of 5 with "Buzz", and multiples of both with "FizzBuzz".

**Starter code:**
```java
import java.util.Scanner;

public class FizzBuzz {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter n: ");
        int n = sc.nextInt();
        for (int i = 1; i <= n; i++) {
            if (i % 15 == 0) System.out.println("FizzBuzz");
            else if (i % 3 == 0) System.out.println("Fizz");
            else if (i % 5 == 0) System.out.println("Buzz");
            else System.out.println(i);
        }
        sc.close();
    }
}
```

**Task:** Let the user supply custom divisors for "Fizz" and "Buzz".

## Exercise 5: Leap Year Check
**Difficulty:** Basic
**Concepts:** Scanner, conditionals, boolean logic

Read a year and print whether it is a leap year.

**Starter code:**
```java
import java.util.Scanner;

public class LeapYear {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a year: ");
        int year = sc.nextInt();
        boolean leap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
        System.out.println(year + (leap ? " is" : " is not") + " a leap year");
        sc.close();
    }
}
```

**Task:** Print all leap years between two given years.
