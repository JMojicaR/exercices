## Exercise 1: Build a Stack with `ArrayDeque`
**Difficulty:** Basic
**Concepts:** `Deque` interface, `push()`/`pop()`/`peek()`, LIFO order, `isEmpty()`

`ArrayDeque` is the recommended stack in modern Java (the legacy `Stack` class is discouraged).

**Starter code:**
```java
import java.util.ArrayDeque;
import java.util.Deque;

public class StackDemo {
    public static void main(String[] args) {
        Deque<String> stack = new ArrayDeque<>();

        stack.push("a");   // push
        stack.push("b");
        stack.push("c");
        System.out.println(stack);            // [c, b, a] (top first)

        String top = stack.pop();             // removes and returns the top
        System.out.println(top);              // c
        System.out.println(stack.peek());     // b (without removing)
        System.out.println(stack.isEmpty());  // false
    }
}
```

**Task:** Push the integers `1..5` onto a stack and pop them all, printing each. The output should be `5 4 3 2 1` (reverse order).

## Exercise 2: Build a Queue with `LinkedList`
**Difficulty:** Basic
**Concepts:** `Queue` interface, `offer()`/`poll()`/`peek()`, FIFO order

Use a `LinkedList` as a `Queue` to get FIFO behavior.

**Starter code:**
```java
import java.util.LinkedList;
import java.util.Queue;

public class QueueDemo {
    public static void main(String[] args) {
        Queue<String> q = new LinkedList<>();

        q.offer("a");   // enqueue (back)
        q.offer("b");
        q.offer("c");
        System.out.println(q);             // [a, b, c]

        String first = q.poll();           // dequeue (front), returns null if empty
        System.out.println(first);         // a
        System.out.println(q.peek());      // b (front, without removing)
        System.out.println(q);             // [b, c]
    }
}
```

**Task:** Enqueue the numbers `1..5` and dequeue them all in a loop, printing each. The output should be `1 2 3 4 5`.

## Exercise 3: Balanced Parentheses Checker
**Difficulty:** Basic
**Concepts:** `Deque<Character>`, `switch` for matching brackets, early `false` on mismatch

Use a stack to verify that brackets are balanced and correctly nested.

**Starter code:**
```java
import java.util.ArrayDeque;
import java.util.Deque;

public class Balanced {
    public static boolean isBalanced(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char ch : s.toCharArray()) {
            if (ch == '(' || ch == '[' || ch == '{') {
                stack.push(ch);
            } else if (ch == ')' || ch == ']' || ch == '}') {
                if (stack.isEmpty()) return false;
                char open = stack.pop();
                if ((ch == ')' && open != '(') ||
                    (ch == ']' && open != '[') ||
                    (ch == '}' && open != '{')) {
                    return false;
                }
            }
        }
        return stack.isEmpty();
    }

    public static void main(String[] args) {
        System.out.println(isBalanced("(a[b]{c})"));   // true
        System.out.println(isBalanced("([)]"));        // false
    }
}
```

**Task:** Add a test for the string `"((("` and confirm it returns `false` (unmatched openers remain on the stack).

## Exercise 4: Reverse a String with a Stack
**Difficulty:** Basic
**Concepts:** push characters, pop to a `StringBuilder`, `toString()`

Push each character onto a stack and pop them off to reverse the string.

**Starter code:**
```java
import java.util.ArrayDeque;
import java.util.Deque;

public class ReverseString {
    public static String reverse(String text) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char ch : text.toCharArray()) {
            stack.push(ch);
        }
        StringBuilder sb = new StringBuilder();
        while (!stack.isEmpty()) {
            sb.append(stack.pop());
        }
        return sb.toString();
    }

    public static void main(String[] args) {
        System.out.println(reverse("hello"));   // "olleh"
    }
}
```

**Task:** Change the method to ignore spaces (e.g., reverse the letters only) so `reverse("a b c")` returns `"c b a"` with spaces preserved in place. Hint: skip pushing spaces.

## Exercise 5: Process a Task Queue in FIFO Order
**Difficulty:** Basic
**Concepts:** `offer()`/`poll()` loop, `while (!queue.isEmpty())`, simulating a work queue

Simulate a printer/job queue by processing tasks in the order they arrive.

**Starter code:**
```java
import java.util.LinkedList;
import java.util.Queue;

public class TaskQueue {
    public static void main(String[] args) {
        Queue<String> jobs = new LinkedList<>();
        jobs.offer("print-report");
        jobs.offer("print-invoice");
        jobs.offer("print-receipt");

        while (!jobs.isEmpty()) {
            String job = jobs.poll();
            System.out.println("Processing: " + job);
        }
        System.out.println("All jobs done: " + jobs.isEmpty());
    }
}
```

**Task:** Add a `PriorityQueue<String>` variant where jobs are processed alphabetically instead of FIFO, and print the jobs to confirm the different order.
