## Exercise 1: Prime Number Check
**Difficulty:** Basic
**Concepts:** for loop, modulo, boolean

Write a program that reads an integer and prints whether it is prime.

**Starter code:**
```java
import java.util.Scanner;

public class PrimeCheck {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a positive integer: ");
        int n = sc.nextInt();
        boolean isPrime = n > 1;
        for (int i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                isPrime = false;
                break;
            }
        }
        System.out.println(n + (isPrime ? " is prime" : " is not prime"));
    }
}
```

**Task:** Move the check into a `static boolean isPrime(int n)` method and call it from `main`.

## Exercise 2: Palindrome String
**Difficulty:** Basic
**Concepts:** String, charAt, loops

Check whether a word reads the same backwards and forwards.

**Starter code:**
```java
import java.util.Scanner;

public class Palindrome {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a word: ");
        String word = sc.nextLine().toLowerCase();
        String reversed = "";
        for (int i = word.length() - 1; i >= 0; i--) {
            reversed += word.charAt(i);
        }
        System.out.println(word.equals(reversed) ? "palindrome" : "not a palindrome");
    }
}
```

**Task:** Compare characters from both ends without building a reversed string.

## Exercise 3: Factorial
**Difficulty:** Basic
**Concepts:** for loop, long, methods

Compute the factorial of a non-negative integer using a method.

**Starter code:**
```java
import java.util.Scanner;

public class Factorial {
    static long factorial(int n) {
        long result = 1;
        for (int i = 1; i <= n; i++) {
            result *= i;
        }
        return result;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a non-negative integer: ");
        int n = sc.nextInt();
        System.out.println(n + "! = " + factorial(n));
    }
}
```

**Task:** Print the factorial of every number from 1 to 10 in a loop.

## Exercise 4: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** arrays, for loop

Fill an integer array and print the sum of its elements.

**Starter code:**
```java
public class ArraySum {
    public static void main(String[] args) {
        int[] numbers = {4, 7, 1, 9, 3};
        int sum = 0;
        for (int n : numbers) {
            sum += n;
        }
        System.out.println("Sum: " + sum);
    }
}
```

**Task:** Also compute and print the average (as a `double`) and the maximum value.

## Exercise 5: Armstrong Number
**Difficulty:** Basic
**Concepts:** while loop, modulo, Math.pow

Check whether a number is an Armstrong number (the sum of its digits each raised to the power of the number of digits equals the number itself, e.g. 153).

**Starter code:**
```java
import java.util.Scanner;

public class Armstrong {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int original = sc.nextInt();
        int digits = String.valueOf(original).length();
        int sum = 0, temp = original;
        while (temp > 0) {
            int digit = temp % 10;
            sum += Math.pow(digit, digits);
            temp /= 10;
        }
        System.out.println(original + (sum == original ? " is" : " is not") + " an Armstrong number");
    }
}
```

**Task:** Print all Armstrong numbers between 1 and 1000.
