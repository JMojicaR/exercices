## Exercise 1: Define a Node and Build a Small Tree
**Difficulty:** Basic
**Concepts:** class with fields, constructor, object references

**Starter code:**
```java
class Node {
    int value;
    Node left, right;

    Node(int value) {
        this.value = value;
    }
}

public class Main {
    public static void main(String[] args) {
        //         8
        //        / \
        //       3   10
        Node root = new Node(8);
        root.left = new Node(3);
        root.right = new Node(10);
    }
}
```

**Task:** Build the full tree below and print `root.left.right.value`:
```
       8
      / \
     3   10
    / \    \
   1   6    14
```
(Expected output: `6`.)

## Exercise 2: Insert a Value into the BST
**Difficulty:** Basic
**Concepts:** static recursive method, `null` base case, comparing values

**Starter code:**
```java
static Node insert(Node node, int value) {
    if (node == null) return new Node(value);
    if (value < node.value) node.left = insert(node.left, value);
    else node.right = insert(node.right, value);
    return node;
}

public static void main(String[] args) {
    Node root = null;
    for (int v : new int[]{8, 3, 10, 1, 6}) {
        root = insert(root, v);
    }
}
```

**Task:** Insert `14`, `4`, and `7`, then write a recursive `printTree(Node n)` that prints `value (left, right)` for each node to confirm the structure.

## Exercise 3: Search for a Value
**Difficulty:** Basic
**Concepts:** recursive search, pruning half the tree, boolean return

**Starter code:**
```java
static boolean contains(Node node, int value) {
    if (node == null) return false;
    if (node.value == value) return true;
    if (value < node.value) return contains(node.left, value);
    return contains(node.right, value);
}

public static void main(String[] args) {
    Node root = null;
    for (int v : new int[]{8, 3, 10, 1, 6, 14, 4, 7}) {
        root = insert(root, v);
    }
    System.out.println(contains(root, 6));   // true
    System.out.println(contains(root, 12));  // false
}
```

**Task:** Modify `contains` to return the depth (steps from the root) where the value is found, or `-1` if absent.

## Exercise 4: In-Order Traversal (Sorted Output)
**Difficulty:** Basic
**Concepts:** left → current → right recursion, building a result `ArrayList<Integer>`

**Starter code:**
```java
static void inorder(Node node, List<Integer> out) {
    if (node == null) return;
    inorder(node.left, out);
    out.add(node.value);
    inorder(node.right, out);
}

public static void main(String[] args) {
    Node root = null;
    for (int v : new int[]{8, 3, 10, 1, 6, 14, 4, 7}) {
        root = insert(root, v);
    }
    List<Integer> out = new ArrayList<>();
    inorder(root, out);
    System.out.println(out);  // [1, 3, 4, 6, 7, 8, 10, 14]
}
```

**Task:** Add a `preorder(Node node, List<Integer> out)` method (current → left → right). Print both traversals and confirm `inorder` is sorted while `preorder` starts with `8`.

## Exercise 5: Find the Minimum and Maximum
**Difficulty:** Basic
**Concepts:** following `left`/`right` chains with a `while` loop

**Starter code:**
```java
static int minValue(Node node) {
    while (node.left != null) {
        node = node.left;
    }
    return node.value;
}

static int maxValue(Node node) {
    while (node.right != null) {
        node = node.right;
    }
    return node.value;
}

public static void main(String[] args) {
    Node root = null;
    for (int v : new int[]{8, 3, 10, 1, 6, 14, 4, 7}) {
        root = insert(root, v);
    }
    System.out.println(minValue(root));  // 1
    System.out.println(maxValue(root));  // 14
}
```

**Task:** Rewrite both methods using recursion instead of a `while` loop.
