## Exercise 1: Create and Print a Matrix
**Difficulty:** Basic
**Concepts:** 2D arrays, nested `for` loops, `System.out.print`

Declare and print a 2D array row by row.

**Starter code:**
```java
public class PrintMatrix {
    public static void main(String[] args) {
        int[][] matrix = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };

        System.out.println("Matrix:");
        for (int i = 0; i < matrix.length; i++) {
            for (int j = 0; j < matrix[i].length; j++) {
                System.out.print(matrix[i][j] + " ");
            }
            System.out.println();
        }
    }
}
```

**Task:** Print the matrix with enhanced `for` loops (`for (int[] row : matrix)`), then print only the first and last row.

## Exercise 2: Matrix Addition
**Difficulty:** Basic
**Concepts:** 2D arrays, element-wise addition, result array allocation

Add two matrices and print the sum.

**Starter code:**
```java
public class MatrixAddition {
    public static void main(String[] args) {
        int[][] a = {{1, 2}, {3, 4}};
        int[][] b = {{5, 6}, {7, 8}};
        int rows = a.length, cols = a[0].length;
        int[][] result = new int[rows][cols];

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                result[i][j] = a[i][j] + b[i][j];
            }
        }

        for (int[] row : result) {
            for (int val : row) {
                System.out.print(val + " ");
            }
            System.out.println();
        }
    }
}
```

**Task:** Compute subtraction (`a - b`) and add a check that both matrices have equal dimensions.

## Exercise 3: Matrix Transpose
**Difficulty:** Basic
**Concepts:** row/column swapping, allocating a flipped-size array

Transpose a matrix (swap rows and columns).

**Starter code:**
```java
public class Transpose {
    public static void main(String[] args) {
        int[][] matrix = {{1, 2, 3}, {4, 5, 6}};
        int rows = matrix.length, cols = matrix[0].length;
        int[][] transpose = new int[cols][rows];

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                transpose[j][i] = matrix[i][j];
            }
        }

        for (int[] row : transpose) {
            for (int val : row) {
                System.out.print(val + " ");
            }
            System.out.println();
        }
    }
}
```

**Task:** Write a method `transpose(int[][])` that returns the transposed array instead of printing it.

## Exercise 4: Sum of the Main Diagonal
**Difficulty:** Basic
**Concepts:** square matrices, single loop, index tracking

Sum the main diagonal (top-left to bottom-right) of a square matrix.

**Starter code:**
```java
public class DiagonalSum {
    public static void main(String[] args) {
        int[][] matrix = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
        int n = matrix.length;
        int total = 0;

        for (int i = 0; i < n; i++) {
            total += matrix[i][i];
        }

        System.out.println("Sum of main diagonal: " + total);
    }
}
```

**Task:** Add the anti-diagonal using `matrix[i][n - 1 - i]` and print both sums.

## Exercise 5: Sum of Each Row and Each Column
**Difficulty:** Basic
**Concepts:** nested loops, running totals

Print the sum of every row and every column.

**Starter code:**
```java
public class RowColumnSums {
    public static void main(String[] args) {
        int[][] matrix = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
        int rows = matrix.length, cols = matrix[0].length;

        System.out.println("Row sums:");
        for (int i = 0; i < rows; i++) {
            int rowSum = 0;
            for (int j = 0; j < cols; j++) {
                rowSum += matrix[i][j];
            }
            System.out.println("Row " + i + ": " + rowSum);
        }

        System.out.println("Column sums:");
        for (int j = 0; j < cols; j++) {
            int colSum = 0;
            for (int i = 0; i < rows; i++) {
                colSum += matrix[i][j];
            }
            System.out.println("Col " + j + ": " + colSum);
        }
    }
}
```

**Task:** Find the row and column with the maximum sum and print their indices.
