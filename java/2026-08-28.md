## Exercise 1: Hello World

**Difficulty:** Basic

### Problem
Write a Java class with a `main` method that prints "Hello, World!" and then declares an `int` and a `String` variable and prints them.

**Expected Output:**
```
Hello, World!
Name: Alice, Age: 25
```

### Concepts
- Class and `main` method
- `System.out.println()`
- Variables and `+` string concatenation

### Example / Starter Code

```java
public class HelloWorld {
    public static void main(String[] args) {
        String name = "Alice";
        int age = 25;

        System.out.println("Hello, World!");
        System.out.println("Name: " + name + ", Age: " + age);
    }
}
```

## Exercise 2: Even or Odd

**Difficulty:** Basic

### Problem
Write a program that reads an integer from the user with `Scanner` and prints whether it is even or odd.

**Given Input:** `7`

**Expected Output:**
```
Enter a number: 7
7 is Odd
```

### Concepts
- `Scanner` for input
- `if`/`else` and the modulo operator `%`

### Example / Starter Code

```java
import java.util.Scanner;

public class EvenOdd {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter a number: ");
        int number = sc.nextInt();

        if (number % 2 == 0) {
            System.out.println(number + " is Even");
        } else {
            System.out.println(number + " is Odd");
        }

        sc.close();
    }
}
```

## Exercise 3: Sum of Numbers 1 to N

**Difficulty:** Basic

### Problem
Write a program that reads a positive integer `n` and prints the sum of all integers from 1 to `n`.

**Given Input:** `10`

**Expected Output:**
```
Sum from 1 to 10 is 55
```

### Concepts
- `for` loop
- Accumulator variable

### Example / Starter Code

```java
import java.util.Scanner;

public class SumToN {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a positive integer: ");
        int n = sc.nextInt();

        int total = 0;
        for (int i = 1; i <= n; i++) {
            total += i;
        }

        System.out.println("Sum from 1 to " + n + " is " + total);
        sc.close();
    }
}
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a program that counts the vowels (a, e, i, o, u) in a given string, ignoring case.

**Given Input:** `"Hello World"`

**Expected Output:**
```
Number of vowels: 3
```

### Concepts
- `String` methods: `charAt()`, `toLowerCase()`
- `if` conditions with character comparison

### Example / Starter Code

```java
public class CountVowels {
    public static void main(String[] args) {
        String text = "Hello World".toLowerCase();
        int count = 0;

        for (int i = 0; i < text.length(); i++) {
            char c = text.charAt(i);
            if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
                count++;
            }
        }

        System.out.println("Number of vowels: " + count);
    }
}
```

## Exercise 5: Find the Maximum in an Array

**Difficulty:** Basic

### Problem
Write a program that finds and prints the largest value in an integer array.

**Given Input:** `{12, 5, 8, 130, 44}`

**Expected Output:**
```
Maximum is 130
```

### Concepts
- Arrays
- `for` loop traversal
- Tracking a running maximum

### Example / Starter Code

```java
public class MaxInArray {
    public static void main(String[] args) {
        int[] numbers = {12, 5, 8, 130, 44};

        int max = numbers[0];
        for (int i = 1; i < numbers.length; i++) {
            if (numbers[i] > max) {
                max = numbers[i];
            }
        }

        System.out.println("Maximum is " + max);
    }
}
```
