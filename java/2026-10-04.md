## Exercise 1: Fibonacci Series
**Difficulty:** Basic
**Concepts:** loops, variables, swapping

Print the first `n` numbers of the Fibonacci series, where each term is the sum of the two preceding ones.

**Starter code:**
```java
public class Fibonacci {
    public static void main(String[] args) {
        int n = 10;
        int a = 0, b = 1;
        for (int i = 0; i < n; i++) {
            System.out.print(a + " ");
            int next = a + b;
            a = b;
            b = next;
        }
    }
}
```

**Task:** Modify the loop to print only Fibonacci numbers that are multiples of 3.

## Exercise 2: Leap Year Check
**Difficulty:** Basic
**Concepts:** conditionals, modulo, boolean logic

Write a program that checks whether a year is a leap year (divisible by 4, not by 100, unless divisible by 400).

**Starter code:**
```java
public class LeapYear {
    public static void main(String[] args) {
        int year = 2024;
        if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
            System.out.println(year + " is a leap year.");
        } else {
            System.out.println(year + " is not a leap year.");
        }
    }
}
```

**Task:** Read the year from the user instead of hard-coding it, using a `Scanner`.

## Exercise 3: Sum of Digits
**Difficulty:** Basic
**Concepts:** while loop, modulo, integer division

Compute the sum of the digits of a given positive integer.

**Starter code:**
```java
public class SumOfDigits {
    public static void main(String[] args) {
        int number = 12345;
        int sum = 0;
        while (number > 0) {
            sum += number % 10;
            number /= 10;
        }
        System.out.println("Sum of digits: " + sum);
    }
}
```

**Task:** Also compute and print the product of the digits.

## Exercise 4: GCD of Two Numbers
**Difficulty:** Basic
**Concepts:** methods, while loop, Euclidean algorithm

Compute the greatest common divisor (GCD) of two integers using the Euclidean algorithm.

**Starter code:**
```java
public class GCD {
    static int gcd(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }

    public static void main(String[] args) {
        System.out.println("GCD: " + gcd(48, 18));
    }
}
```

**Task:** Extend the program to also print the least common multiple (LCM) of the two numbers.

## Exercise 5: Reverse a String (without StringBuilder)
**Difficulty:** Basic
**Concepts:** strings, charAt, loops

Reverse a given string by building a new one character by character, without using `StringBuilder`.

**Starter code:**
```java
public class ReverseString {
    public static void main(String[] args) {
        String original = "hello";
        String reversed = "";
        for (int i = original.length() - 1; i >= 0; i--) {
            reversed += original.charAt(i);
        }
        System.out.println("Reversed: " + reversed);
    }
}
```

**Task:** Modify the program to check whether the string is a palindrome using the reversed result.
