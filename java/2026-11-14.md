## Exercise 1: Define a Book Class
**Difficulty:** Basic
**Concepts:** `class`, fields, constructor, `new`, `System.out.println`

Create a `Book` class with `title`, `author`, and `year` fields, a constructor that sets them, and a `main` method that prints an instance.

**Starter code:**
```java
public class Book {
    String title;
    String author;
    int year;

    Book(String title, String author, int year) {
        this.title = title;
        this.author = author;
        this.year = year;
    }

    public static void main(String[] args) {
        Book book = new Book("1984", "George Orwell", 1949);
        System.out.println(book.title + " by " + book.author + " (" + book.year + ")");
    }
}
```

**Task:** Add a `double price` field with a constructor parameter, then create a second book and print all four fields.

## Exercise 2: Create and Use Multiple Objects
**Difficulty:** Basic
**Concepts:** arrays of objects, enhanced `for` loop, method calls

Create a `Book` class with a `describe()` method, then store three books in an array and print each.

**Starter code:**
```java
public class Book {
    String title;
    String author;
    int year;

    Book(String title, String author, int year) {
        this.title = title;
        this.author = author;
        this.year = year;
    }

    String describe() {
        return title + " by " + author + " (" + year + ")";
    }

    public static void main(String[] args) {
        Book[] books = {
            new Book("1984", "George Orwell", 1949),
            new Book("Dune", "Frank Herbert", 1965),
            new Book("Neuromancer", "William Gibson", 1984),
        };

        for (Book b : books) {
            System.out.println(b.describe());
        }
    }
}
```

**Task:** Add a `price` field and print the total price of all books using a loop.

## Exercise 3: Add Instance Methods
**Difficulty:** Basic
**Concepts:** methods, `this`, return values, method calls on objects

Add methods that compute derived values from the object's own fields.

**Starter code:**
```java
public class Book {
    String title;
    String author;
    int year;
    double price;

    Book(String title, String author, int year, double price) {
        this.title = title;
        this.author = author;
        this.year = year;
        this.price = price;
    }

    int age(int currentYear) {
        return currentYear - year;
    }

    double discountedPrice(double percent) {
        return price * (1 - percent / 100);
    }

    public static void main(String[] args) {
        Book book = new Book("Dune", "Frank Herbert", 1965, 15.99);
        System.out.println(book.age(2026));
        System.out.printf("%.2f%n", book.discountedPrice(20));
    }
}
```

**Task:** Add a `boolean isClassic(int currentYear)` method returning `true` when the book is 50+ years old, and test it on several books.

## Exercise 4: Encapsulation with Getters and Setters
**Difficulty:** Basic
**Concepts:** `private` fields, getters/setters, validation, data hiding

Make the fields private and expose them through accessor methods, validating that `price` is never negative.

**Starter code:**
```java
public class Book {
    private String title;
    private double price;

    Book(String title, double price) {
        this.title = title;
        setPrice(price);
    }

    public String getTitle() {
        return title;
    }

    public double getPrice() {
        return price;
    }

    public void setPrice(double price) {
        if (price < 0) {
            throw new IllegalArgumentException("price cannot be negative");
        }
        this.price = price;
    }

    public static void main(String[] args) {
        Book book = new Book("1984", 12.50);
        System.out.println(book.getTitle() + " costs " + book.getPrice());
        book.setPrice(10.00);
        System.out.println(book.getPrice());
    }
}
```

**Task:** Add a `setTitle` method and demonstrate that the fields can no longer be accessed directly (the code won't compile if you try `book.title`).

## Exercise 5: A Library That Holds Books
**Difficulty:** Basic
**Concepts:** composition, `ArrayList`, `import java.util.*`, search and summary methods

Build a `Library` class that stores `Book` objects in an `ArrayList` and can add, list, and find them.

**Starter code:**
```java
import java.util.ArrayList;

public class Library {
    ArrayList<Book> books = new ArrayList<>();

    void add(Book book) {
        books.add(book);
    }

    Book find(String title) {
        for (Book b : books) {
            if (b.title.equalsIgnoreCase(title)) {
                return b;
            }
        }
        return null;
    }

    void listBooks() {
        for (Book b : books) {
            System.out.println(b.describe());
        }
    }

    public static void main(String[] args) {
        Library lib = new Library();
        lib.add(new Book("Dune", "Frank Herbert", 1965));
        lib.add(new Book("1984", "George Orwell", 1949));
        lib.listBooks();
        System.out.println(lib.find("dune").describe());
    }
}

class Book {
    String title;
    String author;
    int year;

    Book(String title, String author, int year) {
        this.title = title;
        this.author = author;
        this.year = year;
    }

    String describe() {
        return title + " by " + author + " (" + year + ")";
    }
}
```

**Task:** Add a `count()` method and a `booksByYear(int year)` method returning a new `ArrayList<Book>` of matches.
