## Exercise 1: Add Two Numbers
**Difficulty:** Basic
**Concepts:** `Scanner` input, variables, arithmetic, `System.out.println`.

Write a program that reads two integers and prints their sum.

**Starter code:**
```java
import java.util.Scanner;

public class AddTwoNumbers {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter first number: ");
        int a = sc.nextInt();
        System.out.print("Enter second number: ");
        int b = sc.nextInt();
        System.out.println("Sum: " + (a + b));
    }
}
```

**Task:** Extend it to also print the difference, product, and quotient.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** Modulo (`%`), `if`/`else`, conditional logic.

Write a program that reads an integer and tells the user whether it is even or odd.

**Starter code:**
```java
import java.util.Scanner;

public class EvenOdd {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = sc.nextInt();
        if (n % 2 == 0)
            System.out.println(n + " is even");
        else
            System.out.println(n + " is odd");
    }
}
```

**Task:** Handle negative numbers correctly and print the result for a range of inputs using a loop.

## Exercise 3: Multiplication Table
**Difficulty:** Basic
**Concepts:** Loops (`for`), string concatenation, multiplication.

Write a program that prints the multiplication table (1–10) for a given number.

**Starter code:**
```java
import java.util.Scanner;

public class MultiplicationTable {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = sc.nextInt();
        for (int i = 1; i <= 10; i++)
            System.out.println(n + " x " + i + " = " + (n * i));
    }
}
```

**Task:** Use a nested loop to print tables for all numbers from 1 to 5.

## Exercise 4: Reverse a String
**Difficulty:** Basic
**Concepts:** `StringBuilder`, `.reverse()`, string input.

Write a program that reads a string and prints it reversed.

**Starter code:**
```java
import java.util.Scanner;

public class ReverseString {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a string: ");
        String s = sc.nextLine();
        String rev = new StringBuilder(s).reverse().toString();
        System.out.println("Reversed: " + rev);
    }
}
```

**Task:** Reverse the string with a manual character loop instead of `StringBuilder`.

## Exercise 5: Largest Element in an Array
**Difficulty:** Basic
**Concepts:** Arrays, `.length`, loops, comparison.

Write a program that finds and prints the largest value in an integer array.

**Starter code:**
```java
public class LargestInArray {
    public static void main(String[] args) {
        int[] arr = {3, 7, 2, 9, 5};
        int largest = arr[0];
        for (int i = 1; i < arr.length; i++)
            if (arr[i] > largest)
                largest = arr[i];
        System.out.println("Largest: " + largest);
    }
}
```

**Task:** Also find the smallest element and the average of the array.
