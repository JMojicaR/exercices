## Exercise 1: Print a Right-Angled Triangle of Stars
**Difficulty:** Basic
**Concepts:** nested `for` loops, `Scanner`, `System.out.print`

Print a right-angled triangle of `*` where the number of rows is user-supplied.

**Starter code:**
```java
import java.util.Scanner;

public class RightTriangle {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter number of rows: ");
        int rows = sc.nextInt();

        for (int i = 1; i <= rows; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print("*");
            }
            System.out.println();
        }
        sc.close();
    }
}
```

**Task:** Print an inverted triangle instead, then print numbers (`1`, `22`, `333`, …) using the same nested-loop structure.

## Exercise 2: Print Floyd's Triangle
**Difficulty:** Basic
**Concepts:** nested loops, running counter, `System.out.print`

Print Floyd's triangle — consecutive numbers arranged in rows of increasing length.

**Starter code:**
```java
import java.util.Scanner;

public class FloydTriangle {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter number of rows: ");
        int rows = sc.nextInt();
        int num = 1;

        for (int i = 1; i <= rows; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print(num + " ");
                num++;
            }
            System.out.println();
        }
        sc.close();
    }
}
```

**Task:** Right-align the triangle with leading spaces, and start the counter at a user-supplied value.

## Exercise 3: Count Uppercase and Lowercase Letters
**Difficulty:** Basic
**Concepts:** `String`, `charAt()`, `Character.isUpperCase()` / `isLowerCase()`

Count how many uppercase and lowercase letters a string contains.

**Starter code:**
```java
import java.util.Scanner;

public class CountCase {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a string: ");
        String text = sc.nextLine();
        int upper = 0, lower = 0;

        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);
            if (Character.isUpperCase(ch)) upper++;
            else if (Character.isLowerCase(ch)) lower++;
        }

        System.out.println("Uppercase: " + upper + ", Lowercase: " + lower);
        sc.close();
    }
}
```

**Task:** Also count digits (`Character.isDigit`) and whitespace (`Character.isWhitespace`), and print a full breakdown.

## Exercise 4: Remove All Spaces from a String
**Difficulty:** Basic
**Concepts:** `String.replace()`, string manipulation

Remove every space from an input string and print the result.

**Starter code:**
```java
import java.util.Scanner;

public class RemoveSpaces {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a string: ");
        String text = sc.nextLine();

        String noSpaces = text.replace(" ", "");
        System.out.println("Without spaces: " + noSpaces);
        sc.close();
    }
}
```

**Task:** Remove all whitespace (tabs, newlines) using `replaceAll("\\s", "")`, and implement a manual loop version using `charAt()`.

## Exercise 5: Find the Largest Digit in a Number
**Difficulty:** Basic
**Concepts:** `%` and `/`, `while` loop, max tracking

Read a whole number and print its largest single digit.

**Starter code:**
```java
import java.util.Scanner;

public class LargestDigit {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int num = sc.nextInt();
        int largest = 0;

        while (num > 0) {
            int digit = num % 10;
            if (digit > largest) largest = digit;
            num /= 10;
        }

        System.out.println("Largest digit: " + largest);
        sc.close();
    }
}
```

**Task:** Also find the smallest digit, and handle negative input using `Math.abs()`.
