## Exercise 1: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a Java program that reads a non-negative integer and prints its factorial using a `for` loop. Factorial of 0 is 1.

**Given Input:** `5`

**Expected Output:**
```
Factorial of 5 is 120
```

### Concepts
- `Scanner` for input
- `for` loop accumulator
- `long` type for larger results

### Example / Starter Code

```java
import java.util.Scanner;

public class Factorial {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = sc.nextInt();

        long factorial = 1;
        for (int i = 1; i <= n; i++) {
            factorial *= i;
        }

        System.out.println("Factorial of " + n + " is " + factorial);
        sc.close();
    }
}
```

## Exercise 2: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a Java program that prints the first `n` terms of the Fibonacci sequence (`0, 1, 1, 2, 3, 5, …`).

**Given Input:** `7`

**Expected Output:**
```
0
1
1
2
3
5
8
```

### Concepts
- `for` loop
- Swapping variables with a temporary value
- `System.out.println`

### Example / Starter Code

```java
import java.util.Scanner;

public class Fibonacci {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("How many terms? ");
        int n = sc.nextInt();

        int a = 0, b = 1;
        for (int i = 0; i < n; i++) {
            System.out.println(a);
            int next = a + b;
            a = b;
            b = next;
        }
        sc.close();
    }
}
```

## Exercise 3: Palindrome Check

**Difficulty:** Basic

### Problem
Write a Java program that reads a string and checks whether it is a palindrome (ignoring case) using `StringBuilder`.

**Given Input:** `Racecar`

**Expected Output:**
```
Racecar is a palindrome
```

### Concepts
- `String.toLowerCase()`
- `StringBuilder.reverse()`
- `.equals()` for string comparison

### Example / Starter Code

```java
import java.util.Scanner;

public class Palindrome {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a string: ");
        String text = sc.nextLine().toLowerCase();

        String reversed = new StringBuilder(text).reverse().toString();

        if (text.equals(reversed)) {
            System.out.println(text + " is a palindrome");
        } else {
            System.out.println(text + " is not a palindrome");
        }
        sc.close();
    }
}
```

## Exercise 4: Prime Number Check

**Difficulty:** Basic

### Problem
Write a Java program that reads a positive integer and determines whether it is a prime number.

**Given Input:** `29`

**Expected Output:**
```
29 is a prime number
```

### Concepts
- `for` loop with `break`
- Modulo operator `%`
- `Math.sqrt()` for early exit

### Example / Starter Code

```java
import java.util.Scanner;

public class PrimeCheck {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = sc.nextInt();

        boolean isPrime = n > 1;
        for (int i = 2; isPrime && i <= Math.sqrt(n); i++) {
            if (n % i == 0) {
                isPrime = false;
            }
        }

        if (isPrime) {
            System.out.println(n + " is a prime number");
        } else {
            System.out.println(n + " is not a prime number");
        }
        sc.close();
    }
}
```

## Exercise 5: Sum of Digits

**Difficulty:** Basic

### Problem
Write a Java program that reads a positive integer and prints the sum of its digits.

**Given Input:** `12345`

**Expected Output:**
```
Sum of digits: 15
```

### Concepts
- `while` loop
- Modulo `%` and integer division `/`
- Digit extraction

### Example / Starter Code

```java
import java.util.Scanner;

public class SumOfDigits {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = sc.nextInt();

        int total = 0;
        while (n > 0) {
            total += n % 10;
            n /= 10;
        }

        System.out.println("Sum of digits: " + total);
        sc.close();
    }
}
```
