## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** `for` loop, `long`, static methods, `main`, overflow

Compute `n!` and return it as a `long` (note: `20!` overflows a `long`).

**Starter code:**
```java
public class Factorial {
    public static long factorial(int n) {
        long result = 1;
        for (int i = 1; i <= n; i++) {
            result *= i;
        }
        return result;
    }

    public static void main(String[] args) {
        System.out.println(factorial(5)); // 120
        System.out.println(factorial(0)); // 1
    }
}
```

**Task:** Use `java.math.BigInteger` to compute `factorial(25)` without overflow.

## Exercise 2: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** `for` loop, temporary variable, integer swapping, printing

Print the first `n` Fibonacci numbers (`0, 1, 1, 2, 3, 5, 8, …`).

**Starter code:**
```java
public class Fibonacci {
    public static void main(String[] args) {
        int n = 7, a = 0, b = 1;
        for (int i = 0; i < n; i++) {
            System.out.print(a + " ");
            int next = a + b;
            a = b;
            b = next;
        }
        System.out.println(); // 0 1 1 2 3 5 8
    }
}
```

**Task:** Refactor the loop body into a `fibonacci(int n)` method that returns the numbers in an `int[]`.

## Exercise 3: Check Prime Number
**Difficulty:** Basic
**Concepts:** modulo `%`, `Math.sqrt`, `for` loop, early return, `boolean`

Return `true` if a number is prime, `false` otherwise.

**Starter code:**
```java
public class PrimeCheck {
    public static boolean isPrime(int n) {
        if (n < 2) return false;
        for (int i = 2; i <= Math.sqrt(n); i++) {
            if (n % i == 0) return false;
        }
        return true;
    }

    public static void main(String[] args) {
        System.out.println(isPrime(7));  // true
        System.out.println(isPrime(10)); // false
    }
}
```

**Task:** Add a `countPrimes(int limit)` method that returns how many primes are less than `limit`.

## Exercise 4: Sum of Digits
**Difficulty:** Basic
**Concepts:** `%`, `/`, `while` loop, digit extraction

Return the sum of the individual digits of a number.

**Starter code:**
```java
public class SumOfDigits {
    public static int sumOfDigits(int n) {
        int sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        return sum;
    }

    public static void main(String[] args) {
        System.out.println(sumOfDigits(1234)); // 10
    }
}
```

**Task:** Rewrite it using `String.valueOf(n)` and `Character.getNumericValue(ch)`.

## Exercise 5: Greatest Common Divisor (GCD)
**Difficulty:** Basic
**Concepts:** Euclidean algorithm, `while` loop, temporary variable, `%`

Compute the greatest common divisor of two integers.

**Starter code:**
```java
public class GCD {
    public static int gcd(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }

    public static void main(String[] args) {
        System.out.println(gcd(48, 18)); // 6
        System.out.println(gcd(100, 35)); // 5
    }
}
```

**Task:** Add an `lcm(int a, int b)` method using `lcm(a, b) = a * (b / gcd(a, b))` to avoid overflow.
