## Exercise 1: Sum of Natural Numbers

**Difficulty:** Basic

### Problem
Write a program that computes and prints the sum of natural numbers from `1` to `n` using a loop.

**Given Input:** `n = 10`

**Expected Output:**
```
Sum = 55
```

### Concepts
- `for` loop
- Accumulator variable
- `System.out.println`

### Example / Starter Code

```java
public class SumNatural {
    public static void main(String[] args) {
        int n = 10;
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += i;
        }
        System.out.println("Sum = " + sum);
    }
}
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that reads three integers and prints the largest one using `if / else if`.

**Given Input:** `a = 12, b = 7, c = 19`

**Expected Output:**
```
Largest = 19
```

### Concepts
- Nested `if` / `else if`
- Comparison operators
- (Alternative) `Math.max()`

### Example / Starter Code

```java
public class LargestOfThree {
    public static void main(String[] args) {
        int a = 12, b = 7, c = 19;
        int largest;

        if (a >= b && a >= c) {
            largest = a;
        } else if (b >= a && b >= c) {
            largest = b;
        } else {
            largest = c;
        }

        System.out.println("Largest = " + largest);
    }
}
```

## Exercise 3: Simple Calculator with switch

**Difficulty:** Basic

### Problem
Write a program that performs `+`, `-`, `*`, `/` on two numbers using a `switch` statement on an operator character.

**Given Input:** `a = 10, b = 5, op = '*'`

**Expected Output:**
```
50
```

### Concepts
- `switch` statement
- Basic arithmetic
- Handling division by zero

### Example / Starter Code

```java
public class Calculator {
    public static void main(String[] args) {
        double a = 10, b = 5;
        char op = '*';
        double result = 0;

        switch (op) {
            case '+': result = a + b; break;
            case '-': result = a - b; break;
            case '*': result = a * b; break;
            case '/':
                if (b != 0) result = a / b;
                else System.out.println("Cannot divide by zero");
                break;
            default: System.out.println("Unknown operator");
        }

        System.out.println(result);
    }
}
```

## Exercise 4: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that prints the multiplication table of a number `n` from `1` to `10` using a `for` loop.

**Given Input:** `n = 5`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
```

### Concepts
- `for` loop with a counter
- String concatenation
- Formatted output

### Example / Starter Code

```java
public class MultiplicationTable {
    public static void main(String[] args) {
        int n = 5;
        for (int i = 1; i <= 10; i++) {
            System.out.println(n + " x " + i + " = " + (n * i));
        }
    }
}
```

## Exercise 5: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a method `countVowels(String s)` that returns the number of vowels in `s`, ignoring case.

**Given Input:** `countVowels("Hello World")`

**Expected Output:**
```
3
```

### Concepts
- `charAt()` and `length()`
- `toLowerCase()`
- `indexOf()` for membership

### Example / Starter Code

```java
public class CountVowels {
    public static int countVowels(String s) {
        String vowels = "aeiou";
        s = s.toLowerCase();
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            if (vowels.indexOf(s.charAt(i)) != -1) {
                count++;
            }
        }
        return count;
    }

    public static void main(String[] args) {
        System.out.println(countVowels("Hello World"));   // 3
        System.out.println(countVowels("Java"));          // 2
    }
}
```
