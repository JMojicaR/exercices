## 1. Temperature Converter
- **Description**: Write a program that reads a Celsius temperature and converts it to Fahrenheit (`F = C × 9/5 + 32`).
- **Difficulty**: Beginner
- **Concepts**: `Scanner` input, `double`, arithmetic operators, `System.out.println`
- **Example/Starter code**:
```java
import java.util.Scanner;

public class TemperatureConverter {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Enter temperature in Celsius: ");
        double celsius = scanner.nextDouble();
        double fahrenheit = celsius * 9 / 5 + 32;
        System.out.println(celsius + " C = " + fahrenheit + " F");
        scanner.close();
    }
}
```

## 2. Multiplication Table
- **Description**: Print the multiplication table (1 to 10) for a number entered by the user.
- **Difficulty**: Beginner
- **Concepts**: `Scanner`, `for` loops, string concatenation
- **Example/Starter code**:
```java
import java.util.Scanner;

public class MultiplicationTable {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = scanner.nextInt();
        for (int i = 1; i <= 10; i++) {
            System.out.println(n + " x " + i + " = " + (n * i));
        }
        scanner.close();
    }
}
```

## 3. Count the Vowels
- **Description**: Count how many vowels appear in a given string, ignoring case.
- **Difficulty**: Beginner
- **Concepts**: `String`, `.toLowerCase()`, `.toCharArray()`, `indexOf()`, `for` loops
- **Example/Starter code**:
```java
public class CountVowels {
    public static void main(String[] args) {
        String text = "hello world";
        String vowels = "aeiou";
        int count = 0;
        for (char ch : text.toLowerCase().toCharArray()) {
            if (vowels.indexOf(ch) != -1) {
                count++;
            }
        }
        System.out.println("Vowel count: " + count);
    }
}
```

## 4. Fibonacci Series
- **Description**: Print the first N numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...).
- **Difficulty**: Beginner
- **Concepts**: `for` loops, variable swapping, integer arithmetic
- **Example/Starter code**:
```java
public class Fibonacci {
    public static void main(String[] args) {
        int n = 10, a = 0, b = 1;
        System.out.println(a);
        for (int i = 1; i < n; i++) {
            System.out.println(b);
            int next = a + b;
            a = b;
            b = next;
        }
    }
}
```

## 5. Sum of Digits
- **Description**: Given an integer, compute the sum of its digits (e.g. 12345 → 15).
- **Difficulty**: Beginner
- **Concepts**: `while` loops, modulo `%` and integer division `/`
- **Example/Starter code**:
```java
public class SumOfDigits {
    public static void main(String[] args) {
        int num = 12345, sum = 0;
        while (num > 0) {
            sum += num % 10;
            num /= 10;
        }
        System.out.println("Sum of digits: " + sum);
    }
}
```
