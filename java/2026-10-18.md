## Exercise 1: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** variables, temporary variable, `main` method

Swap the values of two variables.

**Starter code:**
```java
public class SwapNumbers {
    public static void main(String[] args) {
        int a = 5, b = 10;

        int temp = a;
        a = b;
        b = temp;

        System.out.println("a = " + a + ", b = " + b);
    }
}
```

**Task:** Swap again using arithmetic (no temporary variable): `a = a + b; b = a - b; a = a - b;`.

## Exercise 2: Area of a Circle
**Difficulty:** Basic
**Concepts:** `Scanner`, `Math.PI`, `printf`, double

Compute the area of a circle given its radius (`area = π × r²`).

**Starter code:**
```java
import java.util.Scanner;

public class CircleArea {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter radius: ");
        double radius = sc.nextDouble();

        double area = Math.PI * radius * radius;
        System.out.printf("Area: %.2f%n", area);

        sc.close();
    }
}
```

**Task:** Also print the circumference using `2 * Math.PI * radius`.

## Exercise 3: Positive, Negative or Zero
**Difficulty:** Basic
**Concepts:** `if / else if / else`, comparison operators, `Scanner`

Classify a number as positive, negative, or zero.

**Starter code:**
```java
import java.util.Scanner;

public class CheckNumber {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        double n = sc.nextDouble();

        if (n > 0) {
            System.out.println("Positive");
        } else if (n < 0) {
            System.out.println("Negative");
        } else {
            System.out.println("Zero");
        }

        sc.close();
    }
}
```

**Task:** Extend it to also report whether a whole number is even or odd.

## Exercise 4: Power of a Number (xⁿ)
**Difficulty:** Basic
**Concepts:** `for` loop, accumulation, `Math.pow`

Compute `base` raised to the power `exp` using a loop.

**Starter code:**
```java
import java.util.Scanner;

public class PowerOfNumber {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Base: ");
        int base = sc.nextInt();
        System.out.print("Exponent: ");
        int exp = sc.nextInt();

        int result = 1;
        for (int i = 0; i < exp; i++) {
            result *= base;
        }

        System.out.println(base + "^" + exp + " = " + result);
        sc.close();
    }
}
```

**Task:** Rewrite using `Math.pow(base, exp)` (note: it returns a `double`).

## Exercise 5: Reverse a Number
**Difficulty:** Basic
**Concepts:** `while` loop, modulo (`%`), integer division (`/`)

Reverse the digits of an integer (e.g. 1234 → 4321).

**Starter code:**
```java
import java.util.Scanner;

public class ReverseNumber {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = sc.nextInt();

        int rev = 0;
        while (n != 0) {
            rev = rev * 10 + n % 10;
            n /= 10;
        }

        System.out.println("Reversed: " + rev);
        sc.close();
    }
}
```

**Task:** Confirm it also works for negative numbers (the `while (n != 0)` condition handles them automatically).
