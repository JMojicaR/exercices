## Exercise 1: Check Leap Year

**Difficulty:** Basic

### Problem
Write a method that takes a year and returns `true` if it is a leap year, otherwise `false`. A year is a leap year if it is divisible by 4, except century years which must be divisible by 400.

**Given Input:** `isLeapYear(2024)`

**Expected Output:**
```
2000 -> Leap year
1900 -> Not a leap year
2024 -> Leap year
2023 -> Not a leap year
```

### Concepts
- Modulo operator (`%`)
- Boolean logic (`&&`, `||`)
- `if` / `else` conditions and methods

### Example / Starter Code

```java
public class LeapYear {
    public static boolean isLeapYear(int year) {
        if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
            return true;
        }
        return false;
    }

    public static void main(String[] args) {
        int[] years = {2000, 1900, 2024, 2023};
        for (int y : years) {
            System.out.println(y + " -> " + (isLeapYear(y) ? "Leap year" : "Not a leap year"));
        }
    }
}
```

## Exercise 2: GCD of Two Numbers

**Difficulty:** Basic

### Problem
Write a method that computes the Greatest Common Divisor (GCD) of two positive integers using the Euclidean algorithm.

**Given Input:** `gcd(48, 18)`

**Expected Output:**
```
GCD of 48 and 18: 6
```

### Concepts
- `while` loop
- Euclidean algorithm with `%`
- Static methods and return values

### Example / Starter Code

```java
public class GCD {
    public static int gcd(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }

    public static void main(String[] args) {
        System.out.println("GCD of 48 and 18: " + gcd(48, 18));
    }
}
```

## Exercise 3: Check Positive / Negative / Zero

**Difficulty:** Basic

### Problem
Write a method that takes an integer and prints whether it is positive, negative, or zero.

**Given Input:** `check(5)`, `check(-3)`, `check(0)`

**Expected Output:**
```
5 is positive
-3 is negative
0 is zero
```

### Concepts
- `if` / `else if` / `else` branching
- Relational operators (`>`, `<`)
- Method parameters

### Example / Starter Code

```java
public class CheckNumber {
    public static void check(int num) {
        if (num > 0) {
            System.out.println(num + " is positive");
        } else if (num < 0) {
            System.out.println(num + " is negative");
        } else {
            System.out.println(num + " is zero");
        }
    }

    public static void main(String[] args) {
        check(5);
        check(-3);
        check(0);
    }
}
```

## Exercise 4: Simple Interest Calculator

**Difficulty:** Basic

### Problem
Write a method that calculates simple interest using the formula `SI = (principal * rate * time) / 100` and returns the result as a `double`.

**Given Input:** `simpleInterest(10000, 5, 3)`

**Expected Output:**
```
Simple Interest: 1500.0
```

### Concepts
- Arithmetic with `double`
- Method with parameters and return value
- Formula evaluation

### Example / Starter Code

```java
public class SimpleInterest {
    public static double simpleInterest(double principal, double rate, double time) {
        return (principal * rate * time) / 100;
    }

    public static void main(String[] args) {
        double si = simpleInterest(10000, 5, 3);
        System.out.println("Simple Interest: " + si);
    }
}
```

## Exercise 5: Print Even Numbers from 1 to n

**Difficulty:** Basic

### Problem
Write a method that prints all even numbers from 1 to `n` (inclusive) on a single line, separated by spaces.

**Given Input:** `printEven(10)`

**Expected Output:**
```
2 4 6 8 10
```

### Concepts
- `for` loop with a counter
- Modulo operator to test evenness
- `System.out.print` for inline output

### Example / Starter Code

```java
public class EvenNumbers {
    public static void printEven(int n) {
        for (int i = 1; i <= n; i++) {
            if (i % 2 == 0) {
                System.out.print(i + " ");
            }
        }
        System.out.println();
    }

    public static void main(String[] args) {
        printEven(10);
    }
}
```
