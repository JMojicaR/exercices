## Exercise 1: Area of a Circle
**Difficulty:** Basic
**Concepts:** Class structure, `main`, `Scanner`, `Math.PI`, arithmetic.

Write a program that reads a radius from the user and prints the area of the circle (`πr²`).

**Starter code:**
```java
import java.util.Scanner;

public class AreaOfCircle {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter radius: ");
        double r = sc.nextDouble();

        double area = Math.PI * r * r;
        System.out.println("Area: " + area);

        sc.close();
    }
}
```

**Task:** Also print the circumference (`2πr`), rounded to two decimal places.

## Exercise 2: Check Prime Number
**Difficulty:** Basic
**Concepts:** Loops (`for`), conditionals, modulo, boolean flags.

Write a program that reads an integer and tells the user whether it is prime.

**Starter code:**
```java
import java.util.Scanner;

public class PrimeCheck {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter an integer: ");
        int n = sc.nextInt();

        boolean isPrime = n > 1;
        for (int i = 2; i < n && isPrime; i++) {
            if (n % i == 0) {
                isPrime = false;
            }
        }

        System.out.println(isPrime ? "Prime" : "Not prime");
        sc.close();
    }
}
```

**Task:** Optimize the loop to only check divisors up to `Math.sqrt(n)`.

## Exercise 3: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** Variables, assignment, temporary variables.

Write a program that reads two numbers and swaps their values, then prints the result.

**Starter code:**
```java
public class SwapNumbers {
    public static void main(String[] args) {
        int a = 5;
        int b = 10;

        int temp = a;
        a = b;
        b = temp;

        System.out.println("a = " + a + ", b = " + b);
    }
}
```

**Task:** Swap two numbers again, this time without using a temporary variable (using addition/subtraction).

## Exercise 4: Factorial
**Difficulty:** Basic
**Concepts:** Loops, accumulator variables, `long` type for larger results.

Write a program that computes the factorial of a number (`n! = 1 × 2 × … × n`).

**Starter code:**
```java
import java.util.Scanner;

public class Factorial {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter n: ");
        int n = sc.nextInt();

        long result = 1;
        for (int i = 1; i <= n; i++) {
            result *= i;
        }

        System.out.println(n + "! = " + result);
        sc.close();
    }
}
```

**Task:** Implement the factorial using recursion instead of a loop.

## Exercise 5: Average of Array Elements
**Difficulty:** Basic
**Concepts:** Arrays, loops, accumulation, division.

Write a program that computes the average of a fixed array of numbers.

**Starter code:**
```java
public class ArrayAverage {
    public static void main(String[] args) {
        int[] numbers = {4, 8, 15, 16, 23, 42};

        int sum = 0;
        for (int n : numbers) {
            sum += n;
        }

        double average = (double) sum / numbers.length;
        System.out.println("Average: " + average);
    }
}
```

**Task:** Extend it to find and print the minimum and maximum values in the array.
