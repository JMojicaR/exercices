## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** `StringBuilder`, `.reverse()`, `.toString()`, static methods

Write a method that returns the input string reversed.

**Starter code:**
```java
public class Main {
    public static String reverseString(String s) {
        return new StringBuilder(s).reverse().toString();
    }

    public static void main(String[] args) {
        System.out.println(reverseString("hello"));  // expected: olleh
    }
}
```

**Task:** Rewrite the method using a `for` loop and `charAt()`, building the result without `StringBuilder`.

## Exercise 2: Check Palindrome
**Difficulty:** Basic
**Concepts:** `.toLowerCase()`, `.equals()`, `StringBuilder`, conditional return

Check whether a string reads the same forwards and backwards (ignoring case).

**Starter code:**
```java
public class Main {
    public static boolean isPalindrome(String s) {
        String lower = s.toLowerCase();
        return lower.equals(new StringBuilder(lower).reverse().toString());
    }

    public static void main(String[] args) {
        System.out.println(isPalindrome("Radar"));  // expected: true
        System.out.println(isPalindrome("hello"));  // expected: false
    }
}
```

**Task:** Rewrite it comparing characters from both ends with a `while` loop, without `StringBuilder`.

## Exercise 3: Count Vowels
**Difficulty:** Basic
**Concepts:** `charAt()`, `.length()`, `for` loop, `switch` or `||` comparisons, `.toLowerCase()`

Count how many vowels (a, e, i, o, u) appear in a string, case-insensitively.

**Starter code:**
```java
public class Main {
    public static int countVowels(String s) {
        int count = 0;
        String lower = s.toLowerCase();
        for (int i = 0; i < lower.length(); i++) {
            char ch = lower.charAt(i);
            if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u') {
                count++;
            }
        }
        return count;
    }

    public static void main(String[] args) {
        System.out.println(countVowels("hello world"));  // expected: 3
    }
}
```

**Task:** Refactor the vowel check into a separate `isVowel(char)` helper method.

## Exercise 4: Count Character Occurrences
**Difficulty:** Basic
**Concepts:** `charAt()`, `for` loop, method parameters, `char` arguments

Count how many times a given character appears in a string.

**Starter code:**
```java
public class Main {
    public static int countChar(String s, char ch) {
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == ch) {
                count++;
            }
        }
        return count;
    }

    public static void main(String[] args) {
        System.out.println(countChar("banana", 'a'));  // expected: 3
    }
}
```

**Task:** Overload the method to also accept a `String` of multiple characters and count any of them.

## Exercise 5: Count Words
**Difficulty:** Basic
**Concepts:** `.trim()`, `.split("\\s+")`, arrays, `.length`

Count the number of words in a sentence (words separated by whitespace).

**Starter code:**
```java
public class Main {
    public static int countWords(String sentence) {
        String[] words = sentence.trim().split("\\s+");
        return words.length;
    }

    public static void main(String[] args) {
        System.out.println(countWords("I love programming"));  // expected: 3
    }
}
```

**Task:** Handle an empty string input so it returns `0` instead of `1`.
