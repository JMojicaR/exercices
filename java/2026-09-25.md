## Exercise 1: Hello, World!
**Difficulty:** Basic
**Concepts:** Class structure, `main` method, `System.out.println`.

Write the classic "Hello, World!" program.

**Starter code:**
```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

**Task:** Modify it to print your name and a short welcome message on separate lines.

## Exercise 2: Read Input and Sum
**Difficulty:** Basic
**Concepts:** `Scanner`, `nextInt()`, variables, arithmetic.

Read two integers from the user and print their sum.

**Starter code:**
```java
import java.util.Scanner;

public class Sum {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter first number: ");
        int a = sc.nextInt();
        System.out.print("Enter second number: ");
        int b = sc.nextInt();

        int sum = a + b;
        System.out.println("Sum: " + sum);
        sc.close();
    }
}
```

**Task:** Also print the difference, product, and quotient.

## Exercise 3: Even or Odd
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator, `Scanner`.

Read an integer and print whether it is even or odd.

**Starter code:**
```java
import java.util.Scanner;

public class EvenOdd {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter an integer: ");
        int num = sc.nextInt();

        if (num % 2 == 0) {
            System.out.println("Even");
        } else {
            System.out.println("Odd");
        }
        sc.close();
    }
}
```

**Task:** Add a case that prints "Zero" when the number is 0.

## Exercise 4: Print 1 to N
**Difficulty:** Basic
**Concepts:** `for` and `while` loops, incrementing counters.

Print the numbers from 1 to N (read from the user).

**Starter code:**
```java
import java.util.Scanner;

public class PrintNumbers {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter N: ");
        int n = sc.nextInt();

        for (int i = 1; i <= n; i++) {
            System.out.print(i + " ");
        }
        System.out.println();
        sc.close();
    }
}
```

**Task:** Reimplement the loop using `while` instead of `for`.

## Exercise 5: Maximum in an Array
**Difficulty:** Basic
**Concepts:** Arrays, loops, comparison operators.

Find the largest element in a given array.

**Starter code:**
```java
public class ArrayMax {
    public static void main(String[] args) {
        int[] numbers = {4, 7, 1, 9, 3, 8};
        int max = numbers[0];

        for (int i = 1; i < numbers.length; i++) {
            if (numbers[i] > max) {
                max = numbers[i];
            }
        }

        System.out.println("Max: " + max);
    }
}
```

**Task:** Also compute and print the minimum and the average.
