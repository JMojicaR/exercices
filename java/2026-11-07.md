## Exercise 1: Even or Odd Checker
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator `%`, method definition, `System.out.println()`

Write a method that takes an `int` and prints whether it is even or odd.

**Starter code:**
```java
public class Main {
    public static void evenOrOdd(int n) {
        if (n % 2 == 0) {
            System.out.println(n + " is even");
        } else {
            System.out.println(n + " is odd");
        }
    }

    public static void main(String[] args) {
        evenOrOdd(4); // 4 is even
        evenOrOdd(7); // 7 is odd
    }
}
```

**Task:** Read the number from the user with `Scanner(System.in)` and `nextInt()`. Handle non-integer input with a `try`/`catch` around `nextInt()`.

## Exercise 2: Print Numbers 1 to N
**Difficulty:** Basic
**Concepts:** `for` loop, loop variable, increment `i++`, `System.out.println()`

Print every integer from 1 up to and including `N`, one per line.

**Starter code:**
```java
public class Main {
    public static void printRange(int n) {
        for (int i = 1; i <= n; i++) {
            System.out.println(i);
        }
    }

    public static void main(String[] args) {
        printRange(5);
        // 1
        // 2
        // 3
        // 4
        // 5
    }
}
```

**Task:** Modify the loop to print only odd numbers. Then rewrite it with an enhanced `for` loop (`for (int i : ...)`) over an `int[]` array.

## Exercise 3: Countdown
**Difficulty:** Basic
**Concepts:** `while` loop, decrementing a counter, loop condition

Print a countdown from `N` down to 1, then print `"Liftoff!"`.

**Starter code:**
```java
public class Main {
    public static void countdown(int n) {
        while (n > 0) {
            System.out.println(n);
            n--;
        }
        System.out.println("Liftoff!");
    }

    public static void main(String[] args) {
        countdown(5);
        // 5
        // 4
        // 3
        // 2
        // 1
        // Liftoff!
    }
}
```

**Task:** Add a guard so that `n <= 0` prints `"Nothing to count"`. Then convert the `while` loop into a `do`/`while` loop and explain when the body is guaranteed to run at least once.

## Exercise 4: Grade Classifier
**Difficulty:** Basic
**Concepts:** `if`/`else if`/`else` ladder, comparison operators, `return`

Convert a numeric score (0–100) into a letter grade: 90+ → A, 80–89 → B, 70–79 → C, 60–69 → D, below 60 → F.

**Starter code:**
```java
public class Main {
    public static String classify(int score) {
        if (score >= 90) {
            return "A";
        } else if (score >= 80) {
            return "B";
        } else if (score >= 70) {
            return "C";
        } else if (score >= 60) {
            return "D";
        } else {
            return "F";
        }
    }

    public static void main(String[] args) {
        System.out.println(classify(95)); // A
        System.out.println(classify(83)); // B
        System.out.println(classify(57)); // F
    }
}
```

**Task:** Rewrite using a `switch` statement (`switch (score / 10)` with `case 10, 9:` etc.). Then handle scores outside 0–100 by returning `"Invalid"`.

## Exercise 5: Sum of Even Numbers up to N
**Difficulty:** Basic
**Concepts:** `for` loop + `if` condition, accumulator variable, `+=`

Return the sum of every even number from 2 up to and including `N`.

**Starter code:**
```java
public class Main {
    public static int sumEven(int n) {
        int total = 0;
        for (int i = 1; i <= n; i++) {
            if (i % 2 == 0) {
                total += i;
            }
        }
        return total;
    }

    public static void main(String[] args) {
        System.out.println(sumEven(10)); // 2 + 4 + 6 + 8 + 10 = 30
        System.out.println(sumEven(7));  // 2 + 4 + 6 = 12
    }
}
```

**Task:** Rewrite using `i += 2` so the conditional is unnecessary, and add a `sumOdd(int n)` method. Compare `sumEven(n) + sumOdd(n)` against `n*(n+1)/2` for a given `n`.
