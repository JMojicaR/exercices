## Exercise 1: Find Maximum & Minimum
**Difficulty:** Basic
**Concepts:** `int[]`, enhanced `for` loop, comparisons

Find and print the smallest and largest values in an integer array.

**Starter code:**
```java
public class MinMax {
    public static void main(String[] args) {
        int[] numbers = {3, 1, 4, 1, 5, 9, 2};
        int min = numbers[0];
        int max = numbers[0];
        for (int n : numbers) {
            if (n < min) min = n;
            if (n > max) max = n;
        }
        System.out.println("min = " + min + ", max = " + max); // min = 1, max = 9
    }
}
```

**Task:** Refactor into a static method `int[] findMinMax(int[] arr)` that returns `{min, max}`, and call it from `main`.

## Exercise 2: Sum of Elements
**Difficulty:** Basic
**Concepts:** `int[]`, enhanced `for` loop, accumulator

Compute and print the sum of all elements in an integer array.

**Starter code:**
```java
public class SumArray {
    public static void main(String[] args) {
        int[] numbers = {1, 2, 3, 4, 5};
        int total = 0;
        for (int n : numbers) {
            total += n;
        }
        System.out.println("sum = " + total); // sum = 15
    }
}
```

**Task:** Wrap the loop in a `static int sum(int[] arr)` method, then compute the average as a `double` using `total / (double) numbers.length`.

## Exercise 3: Reverse an Array
**Difficulty:** Basic
**Concepts:** array indexing, `new int[]`, `Arrays.toString()`

Build a new array holding the elements of the input in reverse order.

**Starter code:**
```java
import java.util.Arrays;

public class ReverseArray {
    public static void main(String[] args) {
        int[] numbers = {1, 2, 3, 4};
        int[] reversed = new int[numbers.length];
        for (int i = 0; i < numbers.length; i++) {
            reversed[i] = numbers[numbers.length - 1 - i];
        }
        System.out.println(Arrays.toString(reversed)); // [4, 3, 2, 1]
    }
}
```

**Task:** Reverse the array **in place** using a two-pointer swap loop (swap `numbers[i]` with `numbers[numbers.length - 1 - i]` for the first half).

## Exercise 4: Count Occurrences
**Difficulty:** Basic
**Concepts:** enhanced `for` loop, equality `==`, counter

Count how many times a target value appears in an integer array.

**Starter code:**
```java
public class CountOccurrences {
    public static void main(String[] args) {
        int[] numbers = {1, 2, 3, 2, 4, 2};
        int target = 2;
        int count = 0;
        for (int n : numbers) {
            if (n == target) count++;
        }
        System.out.println("count of " + target + " = " + count); // count of 2 = 3
    }
}
```

**Task:** Generalize to count occurrences of a `String` target in a `String[]` array, and also count *every* distinct value using a `HashMap<Integer, Integer>`.

## Exercise 5: Remove Duplicates
**Difficulty:** Basic
**Concepts:** `ArrayList`, `.contains()`, autoboxing, generics

Build a list of unique values, preserving the original order of first appearance.

**Starter code:**
```java
import java.util.ArrayList;
import java.util.List;

public class RemoveDuplicates {
    public static void main(String[] args) {
        int[] numbers = {1, 2, 2, 3, 4, 4, 4, 5};
        List<Integer> unique = new ArrayList<>();
        for (int n : numbers) {
            if (!unique.contains(n)) unique.add(n);
        }
        System.out.println(unique); // [1, 2, 3, 4, 5]
    }
}
```

**Task:** Rewrite using `LinkedHashSet<Integer>` (which removes duplicates while preserving insertion order) and compare the results.
