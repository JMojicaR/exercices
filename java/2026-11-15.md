## Exercise 1: try/catch ArithmeticException
**Difficulty:** Basic
**Concepts:** `try`, `catch`, `ArithmeticException`, `e.getMessage()`

Catch the exception that dividing by zero throws.

**Starter code:**
```java
public class Main {
    public static int divide(int a, int b) {
        return a / b;
    }

    public static void main(String[] args) {
        try {
            System.out.println(divide(10, 2)); // 5
            System.out.println(divide(10, 0)); // throws
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero: " + e.getMessage());
        }
    }
}
```

**Task:** Move the two `divide` calls into a loop over a list of divisors `{2, 0, 5}`, catching the exception once per iteration so the loop continues past the zero.

## Exercise 2: Multiple catch Blocks
**Difficulty:** Basic
**Concepts:** `Integer.parseInt`, `NumberFormatException`, multiple `catch` blocks, most-specific-first ordering

Parse several strings, catching the format error for bad input.

**Starter code:**
```java
public class Main {
    public static void main(String[] args) {
        String[] inputs = {"10", "abc", "5"};
        for (String s : inputs) {
            try {
                int n = Integer.parseInt(s);
                System.out.println("Parsed: " + n);
            } catch (NumberFormatException e) {
                System.out.println("'" + s + "' is not a number");
            } catch (Exception e) {
                System.out.println("Other error: " + e);
            }
        }
    }
}
```

**Task:** Add `null` to the array and a `NullPointerException` catch block placed *before* the `Exception` block, and observe which handler runs.

## Exercise 3: The finally Block
**Difficulty:** Basic
**Concepts:** `finally`, guaranteed execution on success and failure

Show that cleanup runs whether or not an exception is thrown.

**Starter code:**
```java
public class Main {
    public static void main(String[] args) {
        try {
            System.out.println("Trying...");
            int result = 10 / 0;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("Caught: " + e);
        } finally {
            System.out.println("This always runs");
        }
    }
}
```

**Task:** Add a second `try` block with no exception and confirm its `finally` still runs, then print the messages in a different order to see the flow.

## Exercise 4: Custom Exception Class
**Difficulty:** Basic
**Concepts:** `extends Exception`, `super(message)`, `throw`, `throws`, catching a checked exception

Define `InvalidAgeException` and throw it from a checked method.

**Starter code:**
```java
class InvalidAgeException extends Exception {
    public InvalidAgeException(String message) {
        super(message);
    }
}

public class Main {
    public static void checkAge(int age) throws InvalidAgeException {
        if (age < 0) {
            throw new InvalidAgeException("Age cannot be negative");
        }
        System.out.println("Age is valid: " + age);
    }

    public static void main(String[] args) {
        try {
            checkAge(-1);
        } catch (InvalidAgeException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```

**Task:** Add an `age > 150` check that throws `InvalidAgeException("Age is unrealistically high")`, and call `checkAge(200)` to verify it.

## Exercise 5: throw + ArrayIndexOutOfBoundsException
**Difficulty:** Basic
**Concepts:** `throw`, `ArrayIndexOutOfBoundsException`, bounds checking, custom error message

Throw an exception with a descriptive message when an index is out of bounds.

**Starter code:**
```java
public class Main {
    public static int getElement(int[] arr, int index) {
        if (index < 0 || index >= arr.length) {
            throw new ArrayIndexOutOfBoundsException("Index " + index + " out of bounds");
        }
        return arr[index];
    }

    public static void main(String[] args) {
        int[] nums = {1, 2, 3};
        try {
            System.out.println(getElement(nums, 5));
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```

**Task:** Call `getElement(nums, -1)` and confirm the same catch block handles the negative index with its own message.
