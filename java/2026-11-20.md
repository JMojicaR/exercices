## Exercise 1: Create a HashMap & Put/Get
**Difficulty:** Basic
**Concepts:** `HashMap`, `put()`, `get()`, generics `<K, V>`, `replace()`

Store and retrieve student grades by name.

**Starter code:**
```java
import java.util.HashMap;

public class Grades {
    public static void main(String[] args) {
        HashMap<String, Integer> grades = new HashMap<>();

        grades.put("Alice", 85);
        grades.put("Bob", 72);
        grades.put("Carol", 90);

        System.out.println(grades.get("Alice"));   // 85
        System.out.println(grades.get("Dave"));    // null

        grades.replace("Bob", 75);                 // update
        System.out.println(grades);
    }
}
```

**Task:** Use `grades.getOrDefault("Dave", 0)` and print the result to show a safe fallback instead of `null`.

## Exercise 2: Count Word Frequencies
**Difficulty:** Basic
**Concepts:** splitting strings, `getOrDefault()`, incrementing counts

Count how many times each word appears in a sentence.

**Starter code:**
```java
import java.util.HashMap;

public class WordCount {
    public static void main(String[] args) {
        String sentence = "the cat and the dog and the bird";
        HashMap<String, Integer> counts = new HashMap<>();

        for (String word : sentence.split(" ")) {
            counts.put(word, counts.getOrDefault(word, 0) + 1);
        }

        System.out.println(counts);
        // {the=3, cat=1, and=2, dog=1, bird=1}
    }
}
```

**Task:** Print the counts in sorted order by first converting the key set to a sorted list (`new ArrayList<>(counts.keySet())` then `Collections.sort(...)`).

## Exercise 3: Iterate Over Entries
**Difficulty:** Basic
**Concepts:** `entrySet()`, `Map.Entry`, enhanced `for`, `keySet()`

Print every key-value pair in a map.

**Starter code:**
```java
import java.util.HashMap;
import java.util.Map;

public class IterateMap {
    public static void main(String[] args) {
        HashMap<String, String> capitals = new HashMap<>();
        capitals.put("Mexico", "Mexico City");
        capitals.put("France", "Paris");
        capitals.put("Japan", "Tokyo");

        for (Map.Entry<String, String> entry : capitals.entrySet()) {
            System.out.println(entry.getKey() + " -> " + entry.getValue());
        }
    }
}
```

**Task:** Add a second loop that iterates `capitals.values()` and prints only the capital cities, sorted.

## Exercise 4: ContainsKey & Remove
**Difficulty:** Basic
**Concepts:** `containsKey()`, `remove()`, `size()`, `clear()`

Manage an inventory map: check, delete, and report.

**Starter code:**
```java
import java.util.HashMap;

public class Inventory {
    public static void main(String[] args) {
        HashMap<String, Integer> stock = new HashMap<>();
        stock.put("apples", 10);
        stock.put("bananas", 5);
        stock.put("cherries", 20);

        if (stock.containsKey("bananas")) {
            stock.remove("bananas");
        }

        System.out.println("Has bananas? " + stock.containsKey("bananas"));
        System.out.println("Total items: " + stock.size());
    }
}
```

**Task:** Before removing, print the removed value using `stock.remove("bananas")` (which returns the value), and confirm it equals `5`.

## Exercise 5: Find the Key with the Maximum Value
**Difficulty:** Basic
**Concepts:** iterating `entrySet()`, tracking the current max, comparisons

Find the student with the highest grade.

**Starter code:**
```java
import java.util.HashMap;
import java.util.Map;

public class MaxValue {
    public static void main(String[] args) {
        HashMap<String, Integer> grades = new HashMap<>();
        grades.put("Alice", 85);
        grades.put("Bob", 72);
        grades.put("Carol", 90);
        grades.put("Dave", 78);

        String best = null;
        int max = Integer.MIN_VALUE;
        for (Map.Entry<String, Integer> e : grades.entrySet()) {
            if (e.getValue() > max) {
                max = e.getValue();
                best = e.getKey();
            }
        }
        System.out.println(best + " has the highest grade: " + max);
    }
}
```

**Task:** Handle the empty-map case by printing `"No students"` when `grades.isEmpty()`.
