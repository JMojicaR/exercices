## 1. Temperature Converter
**Description:** Read a temperature and a scale from the user and convert between Celsius and Fahrenheit. Use separate methods for each direction.
**Difficulty:** Basic
**Concepts:** Class + `main` structure, `Scanner`, methods, arithmetic, `System.out.printf`.
**Starter code:**
```java
import java.util.Scanner;

public class TempConverter {
    static double toFahrenheit(double c) {
        return c * 9 / 5 + 32;
    }

    static double toCelsius(double f) {
        return (f - 32) * 5 / 9;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter temperature: ");
        double temp = sc.nextDouble();
        System.out.print("Scale (C/F): ");
        char scale = sc.next().toUpperCase().charAt(0);

        if (scale == 'C') {
            System.out.printf("%.1fC = %.1fF%n", temp, toFahrenheit(temp));
        } else if (scale == 'F') {
            System.out.printf("%.1fF = %.1fC%n", temp, toCelsius(temp));
        } else {
            System.out.println("Unknown scale");
        }
    }
}
```

## 2. Factorial of a Number
**Description:** Compute the factorial of a non-negative integer N (N! = 1 × 2 × … × N) using a loop. Use a `long` to allow larger results.
**Difficulty:** Basic
**Concepts:** `for` loop, `long` type, accumulator, `Scanner`.
**Starter code:**
```java
import java.util.Scanner;

public class Factorial {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter N: ");
        int n = sc.nextInt();

        long fact = 1;
        for (int i = 2; i <= n; i++) {
            fact *= i;
        }
        System.out.println(n + "! = " + fact);
    }
}
```

## 3. Count Words in a Sentence
**Description:** Read a full sentence and count how many words it contains, splitting on whitespace.
**Difficulty:** Basic
**Concepts:** `Scanner.nextLine()`, `String.split()`, array length, `.trim()`.
**Starter code:**
```java
import java.util.Scanner;

public class WordCount {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a sentence: ");
        String sentence = sc.nextLine().trim();

        String[] words = sentence.isEmpty()
            ? new String[0]
            : sentence.split("\\s+");

        System.out.println("Word count: " + words.length);
    }
}
```

## 4. Multiplication Table
**Description:** Print the multiplication table (1 to 10) for a number entered by the user.
**Difficulty:** Basic
**Concepts:** `for` loop, formatted output, `Scanner`.
**Starter code:**
```java
import java.util.Scanner;

public class MultiplicationTable {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = sc.nextInt();

        for (int i = 1; i <= 10; i++) {
            System.out.printf("%d x %d = %d%n", n, i, n * i);
        }
    }
}
```

## 5. Palindrome Check
**Description:** Check whether a string reads the same forwards and backwards, ignoring case and spaces.
**Difficulty:** Basic
**Concepts:** `StringBuilder.reverse()`, `String` methods, conditionals, `.replaceAll()`.
**Starter code:**
```java
import java.util.Scanner;

public class Palindrome {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a word: ");
        String original = sc.nextLine()
            .toLowerCase()
            .replaceAll("\\s+", "");

        String reversed = new StringBuilder(original).reverse().toString();

        if (original.equals(reversed)) {
            System.out.println("It is a palindrome");
        } else {
            System.out.println("It is NOT a palindrome");
        }
    }
}
```
