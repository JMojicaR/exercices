## Exercise 1: Area and Perimeter of a Rectangle
**Difficulty:** Basic
**Concepts:** `Scanner` input, variables, arithmetic, `System.out.println`.

Write a program that reads the length and width of a rectangle and prints its area and perimeter.

**Starter code:**
```java
import java.util.Scanner;

public class Rectangle {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter length: ");
        double length = sc.nextDouble();
        System.out.print("Enter width: ");
        double width = sc.nextDouble();

        double area = length * width;
        double perimeter = 2 * (length + width);

        System.out.println("Area: " + area);
        System.out.println("Perimeter: " + perimeter);

        sc.close();
    }
}
```

**Task:** Add validation that rejects negative or zero dimensions.

## Exercise 2: Check Leap Year
**Difficulty:** Basic
**Concepts:** Conditionals, logical operators (`&&`, `||`, `!`), modulus, `Scanner`.

Write a program that reads a year and tells the user whether it is a leap year (divisible by 4, but century years must also be divisible by 400).

**Starter code:**
```java
import java.util.Scanner;

public class LeapYear {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a year: ");
        int year = sc.nextInt();

        boolean leap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);

        if (leap) {
            System.out.println(year + " is a leap year.");
        } else {
            System.out.println(year + " is not a leap year.");
        }
        sc.close();
    }
}
```

**Task:** Print all leap years in a range the user specifies (e.g., 2000–2026).

## Exercise 3: Count Vowels in a String
**Difficulty:** Basic
**Concepts:** Strings, `charAt()`, loops, `toLowerCase()`, counting.

Write a program that counts the vowels (a, e, i, o, u) in a user-entered string.

**Starter code:**
```java
import java.util.Scanner;

public class VowelCount {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a string: ");
        String text = sc.nextLine().toLowerCase();

        int count = 0;
        for (int i = 0; i < text.length(); i++) {
            char c = text.charAt(i);
            if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
                count++;
            }
        }

        System.out.println("Vowels: " + count);
        sc.close();
    }
}
```

**Task:** Also count the consonants and print both totals.

## Exercise 4: Fibonacci Series
**Difficulty:** Basic
**Concepts:** Loops, variable swapping, sequence generation.

Write a program that prints the first `n` Fibonacci numbers using a loop.

**Starter code:**
```java
import java.util.Scanner;

public class Fibonacci {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("How many terms? ");
        int n = sc.nextInt();

        int a = 0, b = 1;
        for (int i = 1; i <= n; i++) {
            System.out.print(a + " ");
            int next = a + b;
            a = b;
            b = next;
        }
        System.out.println();
        sc.close();
    }
}
```

**Task:** Store the sequence in an `int[]` and print only the values that are even.

## Exercise 5: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** Variables, temporary variable, arithmetic without temp, `Scanner`.

Write a program that swaps two numbers, first using a temporary variable, then without one.

**Starter code:**
```java
import java.util.Scanner;

public class SwapNumbers {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a: ");
        int a = sc.nextInt();
        System.out.print("Enter b: ");
        int b = sc.nextInt();

        // Using a temporary variable
        int temp = a;
        a = b;
        b = temp;
        System.out.println("After swap (temp): a = " + a + ", b = " + b);

        // Without a temporary variable (swap back)
        a = a + b;
        b = a - b;
        a = a - b;
        System.out.println("After swap (no temp): a = " + a + ", b = " + b);

        sc.close();
    }
}
```

**Task:** Write a `swap(int[] arr)` method that swaps the first two elements of an array.
