## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** String, StringBuilder, loops

Read a string and print it reversed.

**Starter code:**
```java
import java.util.Scanner;

public class ReverseString {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a string: ");
        String text = sc.nextLine();

        String reversed = new StringBuilder(text).reverse().toString();
        System.out.println("Reversed: " + reversed);
    }
}
```

**Task:** Reverse the string manually with a `for` loop and `charAt()`.

## Exercise 2: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** conditionals, Scanner, comparisons

Read three numbers and print the largest.

**Starter code:**
```java
import java.util.Scanner;

public class LargestOfThree {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter three numbers: ");
        int a = sc.nextInt();
        int b = sc.nextInt();
        int c = sc.nextInt();

        int largest = a;
        if (b > largest) largest = b;
        if (c > largest) largest = c;

        System.out.println("Largest: " + largest);
    }
}
```

## Exercise 3: Multiplication Table
**Difficulty:** Basic
**Concepts:** for loop, println

Print the multiplication table (1 to 10) for a given number.

**Starter code:**
```java
import java.util.Scanner;

public class MultiplicationTable {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int n = sc.nextInt();

        for (int i = 1; i <= 10; i++) {
            System.out.println(n + " x " + i + " = " + (n * i));
        }
    }
}
```

**Task:** Use `printf` to align the output columns neatly.

## Exercise 4: Armstrong Number
**Difficulty:** Basic
**Concepts:** while loop, modulo, Math.pow, String length

Check whether a number is an Armstrong number.

**Starter code:**
```java
import java.util.Scanner;

public class Armstrong {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a positive integer: ");
        int n = sc.nextInt();

        int original = n;
        int digits = String.valueOf(n).length();
        int sum = 0;

        while (n > 0) {
            int digit = n % 10;
            sum += Math.pow(digit, digits);
            n /= 10;
        }

        if (sum == original) {
            System.out.println(original + " is an Armstrong number");
        } else {
            System.out.println(original + " is not an Armstrong number");
        }
    }
}
```

**Task:** Print all Armstrong numbers between 1 and 1000.

## Exercise 5: Count Digits in a Number
**Difficulty:** Basic
**Concepts:** while loop, integer division, counting

Count the digits of a positive integer.

**Starter code:**
```java
import java.util.Scanner;

public class CountDigits {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter an integer: ");
        int n = Math.abs(sc.nextInt());
        int count = 0;

        while (n > 0) {
            n /= 10;
            count++;
        }

        System.out.println("Number of digits: " + count);
    }
}
```

**Task:** Fix the code so that an input of 0 prints 1 digit.
