## Exercise 1: Write Text to a File
**Difficulty:** Basic
**Concepts:** `FileWriter`, `BufferedWriter`, `try-with-resources`, checked exceptions

Write a program that creates a file named `notes.txt` and writes two lines into it. Java file operations throw checked exceptions, so use `try-with-resources` and handle `IOException`.

**Starter code:**
```java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class WriteFile {
    public static void main(String[] args) {
        try (BufferedWriter writer = new BufferedWriter(new FileWriter("notes.txt"))) {
            writer.write("First line");
            writer.newLine();
            writer.write("Second line");
            writer.newLine();
            System.out.println("File written.");
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```

**Task:** Write the same lines using `java.nio.file.Files.write(Paths.get("notes.txt"), List.of("a", "b", "c"))`, and run it after adding `import java.nio.file.*;`.

## Exercise 2: Read an Entire File
**Difficulty:** Basic
**Concepts:** `BufferedReader`, `.readLine()`, `Files.readAllLines`

Write a program that reads every line of `notes.txt` and prints it to the console.

**Starter code:**
```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class ReadFile {
    public static void main(String[] args) {
        try (BufferedReader reader = new BufferedReader(new FileReader("notes.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```

**Task:** Replace the manual loop with `Files.readAllLines(Paths.get("notes.txt"))` and print the resulting `List<String>`. Note how this reads everything into memory at once.

## Exercise 3: Append a Line to a File
**Difficulty:** Basic
**Concepts:** `FileWriter` with `append` flag, appending without overwriting

Write a program that adds a new line to the end of `notes.txt` without deleting the existing content.

**Starter code:**
```java
import java.io.FileWriter;
import java.io.IOException;

public class AppendFile {
    public static void main(String[] args) {
        try (FileWriter writer = new FileWriter("notes.txt", true)) {
            writer.write("Appended line\n");
            System.out.println("Appended.");
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```

**Task:** Use a `for` loop to append the numbers 1 through 5, one per line. Then read the file back to confirm the original lines remain.

## Exercise 4: Count Lines and Words
**Difficulty:** Basic
**Concepts:** `BufferedReader`, `String.split()`, `String.trim()`, counters

Write a program that opens `notes.txt` and reports the number of lines and the total number of words it contains.

**Starter code:**
```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class CountFile {
    public static void main(String[] args) {
        int lines = 0;
        int words = 0;
        try (BufferedReader reader = new BufferedReader(new FileReader("notes.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                lines++;
                if (!line.trim().isEmpty()) {
                    words += line.trim().split("\\s+").length;
                }
            }
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
        System.out.println("Lines: " + lines);
        System.out.println("Words: " + words);
    }
}
```

**Task:** Also count characters per line with `line.length()` and print the longest line's length. Then count how many lines contain the word "the" (case-insensitive) using `line.toLowerCase().contains("the")`.

## Exercise 5: Copy a File
**Difficulty:** Basic
**Concepts:** reading and writing simultaneously, `Files.copy`, `Files.exists`

Write a program that copies the contents of `notes.txt` into a new file named `notes_copy.txt`.

**Starter code:**
```java
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.StandardCopyOption;
import java.io.IOException;

public class CopyFile {
    public static void main(String[] args) {
        Path source = Paths.get("notes.txt");
        Path target = Paths.get("notes_copy.txt");
        try {
            Files.copy(source, target, StandardCopyOption.REPLACE_EXISTING);
            System.out.println("Copied.");
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```

**Task:** Before copying, use `Files.exists(target)` to print a warning when the destination already exists. Then rewrite the copy manually with a `BufferedReader`/`BufferedWriter` pair to understand what `Files.copy` does under the hood.
