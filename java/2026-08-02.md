## Exercise 1: Area of a Circle
- **Difficulty**: Basic
- **Concepts**: Variables, data types, arithmetic operators, `Math.PI`, user input (`Scanner`)
- **Description**: Write a Java program that reads the radius of a circle from the user and calculates its area using the formula: area = π × r². Print the result rounded to two decimal places.

### Example/Starter Code
```java
import java.util.Scanner;

public class CircleArea {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter the radius: ");
        double radius = scanner.nextDouble();

        double area = Math.PI * radius * radius;

        System.out.printf("Area of the circle: %.2f%n", area);

        scanner.close();
    }
}
```

## Exercise 2: Leap Year Checker
- **Difficulty**: Basic
- **Concepts**: Conditional statements (if/else), logical operators (&&, ||), modulus operator
- **Description**: Write a Java program that checks whether a given year is a leap year. Leap year rules: a year is a leap year if it is divisible by 4, except for years divisible by 100 — unless they are also divisible by 400.

### Example/Starter Code
```java
import java.util.Scanner;

public class LeapYear {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a year: ");
        int year = scanner.nextInt();

        boolean isLeap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);

        if (isLeap) {
            System.out.println(year + " is a leap year.");
        } else {
            System.out.println(year + " is not a leap year.");
        }

        scanner.close();
    }
}
```

## Exercise 3: Sum of Digits
- **Difficulty**: Basic
- **Concepts**: Loops (while), arithmetic operators, division and modulus
- **Description**: Write a Java program that takes an integer from the user and calculates the sum of its digits. For example, the sum of digits of 1234 is 1 + 2 + 3 + 4 = 10. Use a while loop to extract digits one by one using modulus and division.

### Example/Starter Code
```java
import java.util.Scanner;

public class SumOfDigits {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter an integer: ");
        int number = scanner.nextInt();

        int sum = 0;
        int temp = Math.abs(number); // handle negative numbers

        while (temp > 0) {
            sum += temp % 10;  // extract last digit
            temp /= 10;         // remove last digit
        }

        System.out.println("Sum of digits: " + sum);

        scanner.close();
    }
}
```

## Exercise 4: Prime Number Checker
- **Difficulty**: Basic
- **Concepts**: Loops (for), conditional statements, modulus operator, algorithm design
- **Description**: Write a Java program that checks if a given number is prime. A prime number is a number greater than 1 that has no positive divisors other than 1 and itself. Use a loop to test divisibility from 2 up to the square root of the number for efficiency.

### Example/Starter Code
```java
import java.util.Scanner;

public class PrimeChecker {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a number: ");
        int number = scanner.nextInt();

        boolean isPrime = true;

        if (number <= 1) {
            isPrime = false;
        } else {
            for (int i = 2; i <= Math.sqrt(number); i++) {
                if (number % i == 0) {
                    isPrime = false;
                    break;
                }
            }
        }

        if (isPrime) {
            System.out.println(number + " is prime.");
        } else {
            System.out.println(number + " is not prime.");
        }

        scanner.close();
    }
}
```

## Exercise 5: Right Triangle Star Pattern
- **Difficulty**: Basic
- **Concepts**: Nested loops (for), string output, pattern generation
- **Description**: Write a Java program that prints a right-angled triangle made of asterisks (`*`). The user specifies the number of rows. For example, if the input is 5, the output should be:
```
*
**
***
****
*****
```
Use nested loops: the outer loop for rows, the inner loop for columns.

### Example/Starter Code
```java
import java.util.Scanner;

public class StarPattern {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter number of rows: ");
        int rows = scanner.nextInt();

        for (int i = 1; i <= rows; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print("*");
            }
            System.out.println(); // move to next line
        }

        scanner.close();
    }
}
```
