## Exercise 1: Even or Odd Checker
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator `%`, method definition, `Console.WriteLine()`

Write a method that takes an `int` and prints whether it is even or odd.

**Starter code:**
```csharp
using System;

class Program
{
    static void EvenOrOdd(int n)
    {
        if (n % 2 == 0)
        {
            Console.WriteLine($"{n} is even");
        }
        else
        {
            Console.WriteLine($"{n} is odd");
        }
    }

    static void Main()
    {
        EvenOrOdd(4); // 4 is even
        EvenOrOdd(7); // 7 is odd
    }
}
```

**Task:** Read the number from the user with `Console.ReadLine()` and `int.Parse()`. Handle invalid input with `int.TryParse()` and print an error message instead of throwing.

## Exercise 2: Print Numbers 1 to N
**Difficulty:** Basic
**Concepts:** `for` loop, loop variable, increment `i++`, `Console.WriteLine()`

Print every integer from 1 up to and including `N`, one per line.

**Starter code:**
```csharp
using System;

class Program
{
    static void PrintRange(int n)
    {
        for (int i = 1; i <= n; i++)
        {
            Console.WriteLine(i);
        }
    }

    static void Main()
    {
        PrintRange(5);
        // 1
        // 2
        // 3
        // 4
        // 5
    }
}
```

**Task:** Modify the loop to print only odd numbers using `i += 2`. Then rewrite it with a `foreach` loop over an `int[]` array.

## Exercise 3: Countdown
**Difficulty:** Basic
**Concepts:** `while` loop, decrementing a counter, loop condition

Print a countdown from `N` down to 1, then print `"Liftoff!"`.

**Starter code:**
```csharp
using System;

class Program
{
    static void Countdown(int n)
    {
        while (n > 0)
        {
            Console.WriteLine(n);
            n--;
        }
        Console.WriteLine("Liftoff!");
    }

    static void Main()
    {
        Countdown(5);
        // 5
        // 4
        // 3
        // 2
        // 1
        // Liftoff!
    }
}
```

**Task:** Add a guard so that `n <= 0` prints `"Nothing to count"`. Then rewrite the countdown using a `do`/`while` loop and explain when the body is guaranteed to run at least once.

## Exercise 4: Grade Classifier
**Difficulty:** Basic
**Concepts:** `if`/`else if`/`else` ladder, comparison operators, `return`

Convert a numeric score (0–100) into a letter grade: 90+ → A, 80–89 → B, 70–79 → C, 60–69 → D, below 60 → F.

**Starter code:**
```csharp
using System;

class Program
{
    static string Classify(int score)
    {
        if (score >= 90)
        {
            return "A";
        }
        else if (score >= 80)
        {
            return "B";
        }
        else if (score >= 70)
        {
            return "C";
        }
        else if (score >= 60)
        {
            return "D";
        }
        else
        {
            return "F";
        }
    }

    static void Main()
    {
        Console.WriteLine(Classify(95)); // A
        Console.WriteLine(Classify(83)); // B
        Console.WriteLine(Classify(57)); // F
    }
}
```

**Task:** Rewrite using a `switch` expression (`score / 10` with `case 10 or 9:`). Then handle scores outside 0–100 by returning `"Invalid"`.

## Exercise 5: Sum of Even Numbers up to N
**Difficulty:** Basic
**Concepts:** `for` loop + `if` condition, accumulator variable, `+=`

Return the sum of every even number from 2 up to and including `N`.

**Starter code:**
```csharp
using System;

class Program
{
    static int SumEven(int n)
    {
        int total = 0;
        for (int i = 1; i <= n; i++)
        {
            if (i % 2 == 0)
            {
                total += i;
            }
        }
        return total;
    }

    static void Main()
    {
        Console.WriteLine(SumEven(10)); // 2 + 4 + 6 + 8 + 10 = 30
        Console.WriteLine(SumEven(7));  // 2 + 4 + 6 = 12
    }
}
```

**Task:** Rewrite using `i += 2` so the conditional is unnecessary, and add a `SumOdd(int n)` method. Compare `SumEven(n) + SumOdd(n)` against `n*(n+1)/2` for a given `n`.
