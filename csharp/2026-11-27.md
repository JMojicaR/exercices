## Exercise 1: Define a Node and Build a Small Tree
**Difficulty:** Basic
**Concepts:** class with fields and constructor, object references, nullable reference types

**Starter code:**
```csharp
using System;

class Node {
    public int Value;
    public Node Left;
    public Node Right;

    public Node(int value) {
        Value = value;
    }
}

class Program {
    static void Main() {
        //         8
        //        / \
        //       3   10
        Node root = new Node(8);
        root.Left  = new Node(3);
        root.Right = new Node(10);
    }
}
```

**Task:** Build the full tree below and print `root.Left.Right.Value`:
```
       8
      / \
     3   10
    / \    \
   1   6    14
```
(Expected output: `6`.)

## Exercise 2: Insert a Value into the BST
**Difficulty:** Basic
**Concepts:** static recursive method, `null` base case, comparing values

**Starter code:**
```csharp
static Node Insert(Node node, int value) {
    if (node == null) return new Node(value);
    if (value < node.Value)
        node.Left = Insert(node.Left, value);
    else
        node.Right = Insert(node.Right, value);
    return node;
}

static void Main() {
    Node root = null;
    foreach (int v in new int[] { 8, 3, 10, 1, 6 }) {
        root = Insert(root, v);
    }
}
```

**Task:** Insert `14`, `4`, and `7`, then write a recursive `PrintTree(Node n)` that prints `value (left, right)` for each node to confirm the structure.

## Exercise 3: Search for a Value
**Difficulty:** Basic
**Concepts:** recursive search, pruning half the tree, `bool` return

**Starter code:**
```csharp
static bool Contains(Node node, int value) {
    if (node == null) return false;
    if (node.Value == value) return true;
    if (value < node.Value) return Contains(node.Left, value);
    return Contains(node.Right, value);
}

static void Main() {
    Node root = null;
    foreach (int v in new int[] { 8, 3, 10, 1, 6, 14, 4, 7 }) {
        root = Insert(root, v);
    }
    Console.WriteLine(Contains(root, 6));   // True
    Console.WriteLine(Contains(root, 12));  // False
}
```

**Task:** Modify `Contains` to return the depth (steps from the root) where the value is found, or `-1` if absent.

## Exercise 4: In-Order Traversal (Sorted Output)
**Difficulty:** Basic
**Concepts:** left → current → right recursion, building a `List<int>` result

**Starter code:**
```csharp
using System.Collections.Generic;

static void Inorder(Node node, List<int> out) {
    if (node == null) return;
    Inorder(node.Left, out);
    out.Add(node.Value);
    Inorder(node.Right, out);
}

static void Main() {
    Node root = null;
    foreach (int v in new int[] { 8, 3, 10, 1, 6, 14, 4, 7 }) {
        root = Insert(root, v);
    }
    var out = new List<int>();
    Inorder(root, out);
    Console.WriteLine(string.Join(" ", out));  // 1 3 4 6 7 8 10 14
}
```

**Task:** Add a `Preorder(Node node, List<int> out)` method (current → left → right). Print both traversals and confirm `Inorder` is sorted while `Preorder` starts with `8`.

## Exercise 5: Find the Minimum and Maximum
**Difficulty:** Basic
**Concepts:** following `Left`/`Right` chains with a `while` loop

**Starter code:**
```csharp
static int MinValue(Node node) {
    while (node.Left != null) {
        node = node.Left;
    }
    return node.Value;
}

static int MaxValue(Node node) {
    while (node.Right != null) {
        node = node.Right;
    }
    return node.Value;
}

static void Main() {
    Node root = null;
    foreach (int v in new int[] { 8, 3, 10, 1, 6, 14, 4, 7 }) {
        root = Insert(root, v);
    }
    Console.WriteLine(MinValue(root));  // 1
    Console.WriteLine(MaxValue(root));  // 14
}
```

**Task:** Rewrite both methods using recursion instead of a `while` loop.
