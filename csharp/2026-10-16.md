## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** string, char array, Array.Reverse

Read a string and print it reversed.

**Starter code:**
```csharp
using System;

class ReverseString
{
    static void Main()
    {
        Console.Write("Enter a string: ");
        string text = Console.ReadLine();

        char[] chars = text.ToCharArray();
        Array.Reverse(chars);
        Console.WriteLine("Reversed: " + new string(chars));
    }
}
```

**Task:** Reverse the string using a `for` loop without `Array.Reverse`.

## Exercise 2: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** conditionals, Console.ReadLine, comparisons

Read three numbers and print the largest.

**Starter code:**
```csharp
using System;

class LargestOfThree
{
    static void Main()
    {
        Console.Write("Enter three numbers: ");
        int a = int.Parse(Console.ReadLine());
        int b = int.Parse(Console.ReadLine());
        int c = int.Parse(Console.ReadLine());

        int largest = a;
        if (b > largest) largest = b;
        if (c > largest) largest = c;

        Console.WriteLine("Largest: " + largest);
    }
}
```

**Task:** Rewrite using `Math.Max(a, Math.Max(b, c))`.

## Exercise 3: Multiplication Table
**Difficulty:** Basic
**Concepts:** for loop, Console.WriteLine

Print the multiplication table (1 to 10) for a given number.

**Starter code:**
```csharp
using System;

class MultiplicationTable
{
    static void Main()
    {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());

        for (int i = 1; i <= 10; i++)
        {
            Console.WriteLine($"{n} x {i} = {n * i}");
        }
    }
}
```

**Task:** Print the table in reverse order (from 10 down to 1).

## Exercise 4: Armstrong Number
**Difficulty:** Basic
**Concepts:** while loop, modulo, Math.Pow, string length

Check whether a number is an Armstrong number.

**Starter code:**
```csharp
using System;

class Armstrong
{
    static void Main()
    {
        Console.Write("Enter a positive integer: ");
        int n = int.Parse(Console.ReadLine());

        int original = n;
        int digits = n.ToString().Length;
        int sum = 0;

        while (n > 0)
        {
            int digit = n % 10;
            sum += (int)Math.Pow(digit, digits);
            n /= 10;
        }

        if (sum == original)
            Console.WriteLine(original + " is an Armstrong number");
        else
            Console.WriteLine(original + " is not an Armstrong number");
    }
}
```

**Task:** Print all Armstrong numbers between 1 and 1000.

## Exercise 5: Count Digits in a Number
**Difficulty:** Basic
**Concepts:** while loop, integer division, counting

Count the digits of an integer.

**Starter code:**
```csharp
using System;

class CountDigits
{
    static void Main()
    {
        Console.Write("Enter an integer: ");
        int n = Math.Abs(int.Parse(Console.ReadLine()));
        int count = 0;

        if (n == 0)
        {
            count = 1;
        }
        else
        {
            while (n > 0)
            {
                n /= 10;
                count++;
            }
        }

        Console.WriteLine("Number of digits: " + count);
    }
}
```

**Task:** Convert the logic into a reusable `CountDigits(int n)` method.
