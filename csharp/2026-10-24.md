## Exercise 1: Print a Right-Angled Triangle of Stars
**Difficulty:** Basic
**Concepts:** nested `for` loops, `Console.ReadLine()`, `int.Parse()`

Print a right-angled triangle of `*` where the number of rows is user-supplied.

**Starter code:**
```csharp
using System;

class RightTriangle {
    static void Main() {
        Console.Write("Enter number of rows: ");
        int rows = int.Parse(Console.ReadLine());

        for (int i = 1; i <= rows; i++) {
            for (int j = 1; j <= i; j++) {
                Console.Write("*");
            }
            Console.WriteLine();
        }
    }
}
```

**Task:** Print an inverted triangle instead, then print numbers (`1`, `22`, `333`, …) using the same nested-loop structure.

## Exercise 2: Print Floyd's Triangle
**Difficulty:** Basic
**Concepts:** nested loops, running counter, `Console.Write`

Print Floyd's triangle — consecutive numbers arranged in rows of increasing length.

**Starter code:**
```csharp
using System;

class FloydTriangle {
    static void Main() {
        Console.Write("Enter number of rows: ");
        int rows = int.Parse(Console.ReadLine());
        int num = 1;

        for (int i = 1; i <= rows; i++) {
            for (int j = 1; j <= i; j++) {
                Console.Write(num + " ");
                num++;
            }
            Console.WriteLine();
        }
    }
}
```

**Task:** Right-align the triangle with leading spaces, and start the counter at a user-supplied value.

## Exercise 3: Count Uppercase and Lowercase Letters
**Difficulty:** Basic
**Concepts:** `string`, `foreach`, `char.IsUpper()` / `char.IsLower()`

Count how many uppercase and lowercase letters a string contains.

**Starter code:**
```csharp
using System;

class CountCase {
    static void Main() {
        Console.Write("Enter a string: ");
        string text = Console.ReadLine();
        int upper = 0, lower = 0;

        foreach (char ch in text) {
            if (char.IsUpper(ch)) upper++;
            else if (char.IsLower(ch)) lower++;
        }

        Console.WriteLine($"Uppercase: {upper}, Lowercase: {lower}");
    }
}
```

**Task:** Also count digits (`char.IsDigit`) and whitespace (`char.IsWhiteSpace`), and print a full breakdown.

## Exercise 4: Remove All Spaces from a String
**Difficulty:** Basic
**Concepts:** `string.Replace()`, string manipulation

Remove every space from an input string and print the result.

**Starter code:**
```csharp
using System;

class RemoveSpaces {
    static void Main() {
        Console.Write("Enter a string: ");
        string text = Console.ReadLine();

        string noSpaces = text.Replace(" ", "");
        Console.WriteLine("Without spaces: " + noSpaces);
    }
}
```

**Task:** Remove all whitespace using a loop with `char.IsWhiteSpace()`, and also try a `StringBuilder` approach.

## Exercise 5: Find the Largest Digit in a Number
**Difficulty:** Basic
**Concepts:** `%` and `/`, `while` loop, max tracking

Read a whole number and print its largest single digit.

**Starter code:**
```csharp
using System;

class LargestDigit {
    static void Main() {
        Console.Write("Enter a number: ");
        int num = int.Parse(Console.ReadLine());
        int largest = 0;

        while (num > 0) {
            int digit = num % 10;
            if (digit > largest) largest = digit;
            num /= 10;
        }

        Console.WriteLine("Largest digit: " + largest);
    }
}
```

**Task:** Also find the smallest digit, and handle negative input using `Math.Abs()`.
