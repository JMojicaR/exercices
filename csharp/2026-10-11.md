## Exercise 1: Number Guessing Game
**Difficulty:** Basic
**Concepts:** Random, while loop, Console I/O, parsing

Generate a random number between 1 and 100 and let the user guess with hints.

**Starter code:**
```csharp
using System;

class GuessingGame {
    static void Main() {
        Random rand = new Random();
        int target = rand.Next(1, 101);
        int guess = 0;

        while (guess != target) {
            Console.Write("Guess a number (1-100): ");
            guess = int.Parse(Console.ReadLine());
            if (guess < target) Console.WriteLine("Too low!");
            else if (guess > target) Console.WriteLine("Too high!");
        }
        Console.WriteLine("You guessed it!");
    }
}
```

**Task:** Add an attempt counter and report it when the player wins.

## Exercise 2: Simple Calculator with switch
**Difficulty:** Basic
**Concepts:** switch, Console I/O, parsing, arithmetic

Read an operator and two numbers, then print the result.

**Starter code:**
```csharp
using System;

class Calculator {
    static void Main() {
        Console.Write("Enter operator (+, -, *, /): ");
        char op = Console.ReadLine()[0];
        Console.Write("Enter two numbers: ");
        string[] parts = Console.ReadLine().Split(' ');
        double a = double.Parse(parts[0]);
        double b = double.Parse(parts[1]);

        switch (op) {
            case '+': Console.WriteLine(a + b); break;
            case '-': Console.WriteLine(a - b); break;
            case '*': Console.WriteLine(a * b); break;
            case '/': Console.WriteLine(b != 0 ? a / b : double.NaN); break;
            default: Console.WriteLine("Invalid operator"); break;
        }
    }
}
```

**Task:** Print a friendly "Cannot divide by zero" message instead of `NaN`.

## Exercise 3: Power of a Number
**Difficulty:** Basic
**Concepts:** for loop, multiplication, parsing

Compute `base` raised to `exponent` using a loop.

**Starter code:**
```csharp
using System;

class Power {
    static void Main() {
        Console.Write("Enter base: ");
        double b = double.Parse(Console.ReadLine());
        Console.Write("Enter exponent: ");
        int e = int.Parse(Console.ReadLine());

        double result = 1;
        for (int i = 0; i < e; i++) result *= b;
        Console.WriteLine($"{b}^{e} = {result}");
    }
}
```

**Task:** Compare your result with `Math.Pow(b, e)` for several inputs.

## Exercise 4: Anagram Check
**Difficulty:** Basic
**Concepts:** string methods, LINQ, sorting

Check whether two strings are anagrams (same letters, different order), e.g. "listen" and "silent".

**Starter code:**
```csharp
using System;
using System.Linq;

class Anagram {
    static void Main() {
        Console.Write("Enter first string: ");
        string a = Console.ReadLine();
        Console.Write("Enter second string: ");
        string b = Console.ReadLine();

        string Normalize(string s) =>
            string.Concat(s.ToLower().Where(char.IsLetter).OrderBy(c => c));

        Console.WriteLine(Normalize(a) == Normalize(b) ? "Anagrams" : "Not anagrams");
    }
}
```

**Task:** Do the check without LINQ, using arrays and `Array.Sort`.

## Exercise 5: Sum of Natural Numbers
**Difficulty:** Basic
**Concepts:** for loop, accumulator, parsing

Compute the sum of all natural numbers from 1 to `n`.

**Starter code:**
```csharp
using System;

class SumNatural {
    static void Main() {
        Console.Write("Enter a positive integer: ");
        int n = int.Parse(Console.ReadLine());

        int sum = 0;
        for (int i = 1; i <= n; i++) sum += i;
        Console.WriteLine($"Sum from 1 to {n} is {sum}");
    }
}
```

**Task:** Recompute using `n * (n + 1) / 2` and verify both agree.
