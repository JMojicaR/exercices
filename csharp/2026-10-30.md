## Exercise 1: Linear Search
**Difficulty:** Basic
**Concepts:** `for` loop, array indexing, comparison, `static` method, `return`

Write a method that searches for a target value in an array and returns its index, or `-1` if not found.

**Starter code:**
```csharp
using System;

class LinearSearch {
    static int Find(int[] arr, int target) {
        for (int i = 0; i < arr.Length; i++) {
            if (arr[i] == target) {
                return i;
            }
        }
        return -1;
    }

    static void Main() {
        int[] numbers = { 10, 23, 45, 70, 11, 15 };
        Console.WriteLine(Find(numbers, 70)); // expected: 3
        Console.WriteLine(Find(numbers, 99)); // expected: -1
    }
}
```

**Task:** Rewrite the loop using `foreach` and a manual index counter (since `foreach` hides the index).

## Exercise 2: Binary Search
**Difficulty:** Basic
**Concepts:** `while` loop, midpoint index, sorted input, integer arithmetic

Search for a target in a *sorted* array using binary search, halving the search range each step.

**Starter code:**
```csharp
using System;

class BinarySearch {
    static int Search(int[] arr, int target) {
        int low = 0, high = arr.Length - 1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] == target) return mid;
            if (arr[mid] < target) low = mid + 1;
            else high = mid - 1;
        }
        return -1;
    }

    static void Main() {
        int[] sorted = { 1, 3, 5, 7, 9, 11, 13 };
        Console.WriteLine(Search(sorted, 9)); // expected: 4
        Console.WriteLine(Search(sorted, 4)); // expected: -1
    }
}
```

**Task:** Print `low`, `high`, and `mid` at the start of each iteration to visualize how the range shrinks.

## Exercise 3: Bubble Sort
**Difficulty:** Basic
**Concepts:** nested `for` loops, swapping with a temp variable, comparison operators

Sort an array in ascending order using bubble sort (repeatedly swap adjacent out-of-order elements).

**Starter code:**
```csharp
using System;

class BubbleSort {
    static void Sort(int[] arr) {
        int n = arr.Length;
        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - 1 - i; j++) {
                if (arr[j] > arr[j + 1]) {
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }
    }

    static void Main() {
        int[] data = { 64, 34, 25, 12, 22, 11, 90 };
        Sort(data);
        Console.WriteLine(string.Join(" ", data)); // expected: 11 12 22 25 34 64 90
    }
}
```

**Task:** Add a `bool swapped` flag that breaks out of the outer loop early when a pass makes no swaps.

## Exercise 4: Find Minimum and Maximum
**Difficulty:** Basic
**Concepts:** iteration, comparison, tuple return, empty-array edge case

Find and return the smallest and largest values in an array in a single pass, using a tuple.

**Starter code:**
```csharp
using System;

class MinMax {
    static (int min, int max) Find(int[] arr) {
        if (arr.Length == 0) return (0, 0);
        int min = arr[0], max = arr[0];
        foreach (int v in arr) {
            if (v < min) min = v;
            if (v > max) max = v;
        }
        return (min, max);
    }

    static void Main() {
        int[] nums = { 45, 2, 78, 13, 9, 54 };
        var (lo, hi) = Find(nums);
        Console.WriteLine($"Min: {lo} Max: {hi}"); // Min: 2 Max: 78
    }
}
```

**Task:** Also return the *indices* of the min and max elements by tracking `minIdx`/`maxIdx` inside the loop.

## Exercise 5: Selection Sort
**Difficulty:** Basic
**Concepts:** nested loops, index tracking, swapping, finding the minimum in a sub-range

Sort an array using selection sort: repeatedly find the smallest remaining element and move it to the front.

**Starter code:**
```csharp
using System;

class SelectionSort {
    static void Sort(int[] arr) {
        int n = arr.Length;
        for (int i = 0; i < n - 1; i++) {
            int minIdx = i;
            for (int j = i + 1; j < n; j++) {
                if (arr[j] < arr[minIdx]) minIdx = j;
            }
            int temp = arr[i];
            arr[i] = arr[minIdx];
            arr[minIdx] = temp;
        }
    }

    static void Main() {
        int[] data = { 29, 10, 14, 37, 13 };
        Sort(data);
        Console.WriteLine(string.Join(" ", data)); // expected: 10 13 14 29 37
    }
}
```

**Task:** Sort in *descending* order by changing a single comparison, and skip the swap when `minIdx == i`.
