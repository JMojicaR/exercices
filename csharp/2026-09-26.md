## Exercise 1: Temperature Converter
**Difficulty:** Basic
**Concepts:** `Console.ReadLine`, parsing (`int.Parse`/`Convert`), arithmetic, interpolation.

Write a program that reads a Celsius temperature and converts it to Fahrenheit.

**Starter code:**
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Enter temperature in Celsius: ");
        double celsius = Convert.ToDouble(Console.ReadLine());

        double fahrenheit = (celsius * 9 / 5) + 32;
        Console.WriteLine($"{celsius}°C = {fahrenheit}°F");
    }
}
```

**Task:** Extend it to convert Fahrenheit back to Celsius.

## Exercise 2: Check Palindrome String
**Difficulty:** Basic
**Concepts:** Strings, `ToLower()`, loops, indexing.

Write a program that checks whether a word reads the same forwards and backwards (a palindrome).

**Starter code:**
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Enter a word: ");
        string word = Console.ReadLine().ToLower();

        bool isPalindrome = true;
        for (int i = 0; i < word.Length / 2; i++)
        {
            if (word[i] != word[word.Length - 1 - i])
            {
                isPalindrome = false;
                break;
            }
        }

        Console.WriteLine(isPalindrome ? "Palindrome" : "Not a palindrome");
    }
}
```

**Task:** Make the check ignore spaces and punctuation so full phrases work too.

## Exercise 3: Sum of Digits
**Difficulty:** Basic
**Concepts:** `while` loop, modulo (`%`), integer division (`/`).

Write a program that reads an integer and prints the sum of its digits.

**Starter code:**
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Enter an integer: ");
        int n = int.Parse(Console.ReadLine());

        int sum = 0;
        while (n != 0)
        {
            sum += n % 10;
            n /= 10;
        }

        Console.WriteLine("Sum of digits: " + sum);
    }
}
```

**Task:** Also count how many digits the number has.

## Exercise 4: Fibonacci Series
**Difficulty:** Basic
**Concepts:** Loops, variables, sequence updating.

Write a program that prints the first N Fibonacci numbers.

**Starter code:**
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("How many terms? ");
        int n = int.Parse(Console.ReadLine());

        int a = 0, b = 1;
        for (int i = 0; i < n; i++)
        {
            Console.Write(a + " ");
            int next = a + b;
            a = b;
            b = next;
        }
        Console.WriteLine();
    }
}
```

**Task:** Stop the series when a term exceeds a user-supplied maximum value.

## Exercise 5: Average of Numbers in a List
**Difficulty:** Basic
**Concepts:** `List<int>`, loops, `Average()` (LINQ), accumulation.

Write a program that stores several numbers in a `List<int>` and prints their average.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    static void Main()
    {
        List<int> numbers = new List<int> { 8, 12, 5, 20, 9 };

        double average = numbers.Average();
        Console.WriteLine("Average: " + average);
    }
}
```

**Task:** Compute the average manually with a loop (without LINQ), and also print the minimum and maximum.
