## Exercise 1: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** loops, variables, Console I/O

Print the first `n` numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...).

**Starter code:**
```csharp
using System;

class Fibonacci
{
    static void Main()
    {
        Console.Write("How many Fibonacci numbers? ");
        int n = int.Parse(Console.ReadLine());
        int a = 0, b = 1;
        for (int i = 0; i < n; i++)
        {
            Console.Write(a + " ");
            int next = a + b;
            a = b;
            b = next;
        }
        Console.WriteLine();
    }
}
```

**Task:** Print only the Fibonacci numbers below a user-specified limit.

## Exercise 2: Sum of Digits
**Difficulty:** Basic
**Concepts:** while loop, modulo, integer division

Compute the sum of the digits of a positive integer (e.g. 1234 → 10).

**Starter code:**
```csharp
using System;

class SumOfDigits
{
    static void Main()
    {
        Console.Write("Enter a positive integer: ");
        int n = int.Parse(Console.ReadLine());
        int sum = 0;
        while (n > 0)
        {
            sum += n % 10;
            n /= 10;
        }
        Console.WriteLine("Sum of digits: " + sum);
    }
}
```

**Task:** Also print the product of the digits and the number of digits.

## Exercise 3: Reverse a String
**Difficulty:** Basic
**Concepts:** char arrays, Array.Reverse, strings

Read a string and print it reversed.

**Starter code:**
```csharp
using System;

class ReverseString
{
    static void Main()
    {
        Console.Write("Enter a string: ");
        string input = Console.ReadLine();
        char[] chars = input.ToCharArray();
        Array.Reverse(chars);
        Console.WriteLine("Reversed: " + new string(chars));
    }
}
```

**Task:** Check whether the string is a palindrome (ignoring case and spaces).

## Exercise 4: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** if/else, comparison operators

Read three numbers and print the largest.

**Starter code:**
```csharp
using System;

class LargestOfThree
{
    static void Main()
    {
        Console.Write("Enter three numbers: ");
        string[] parts = Console.ReadLine().Split(' ');
        int a = int.Parse(parts[0]);
        int b = int.Parse(parts[1]);
        int c = int.Parse(parts[2]);

        int largest = a;
        if (b > largest) largest = b;
        if (c > largest) largest = c;

        Console.WriteLine("Largest: " + largest);
    }
}
```

**Task:** Also print the smallest and sort the three numbers in ascending order.

## Exercise 5: FizzBuzz
**Difficulty:** Basic
**Concepts:** for loop, conditionals, modulo

Print numbers from 1 to a given `n`, replacing multiples of 3 with "Fizz", multiples of 5 with "Buzz", and multiples of both with "FizzBuzz".

**Starter code:**
```csharp
using System;

class FizzBuzz
{
    static void Main()
    {
        Console.Write("Enter n: ");
        int n = int.Parse(Console.ReadLine());
        for (int i = 1; i <= n; i++)
        {
            if (i % 15 == 0) Console.WriteLine("FizzBuzz");
            else if (i % 3 == 0) Console.WriteLine("Fizz");
            else if (i % 5 == 0) Console.WriteLine("Buzz");
            else Console.WriteLine(i);
        }
    }
}
```

**Task:** Let the user supply custom divisors for "Fizz" and "Buzz".
