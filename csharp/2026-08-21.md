## Exercise 1: Sum of Natural Numbers

**Difficulty:** Basic

### Problem
Write a program that computes the sum of natural numbers from `1` to `n` using a loop.

**Given Input:** `n = 10`

**Expected Output:**
```
Sum = 55
```

### Concepts
- `for` loop
- Accumulator variable
- `Console.WriteLine`

### Example / Starter Code

```csharp
using System;

class SumNatural {
    static void Main() {
        int n = 10;
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += i;
        }
        Console.WriteLine("Sum = " + sum);
    }
}
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that finds and prints the largest of three numbers.

**Given Input:** `12, 7, 19`

**Expected Output:**
```
Largest = 19
```

### Concepts
- `if / else if`
- Logical operators
- (Alternative) `Math.Max`

### Example / Starter Code

```csharp
using System;

class LargestOfThree {
    static void Main() {
        int a = 12, b = 7, c = 19;
        int largest;

        if (a >= b && a >= c)
            largest = a;
        else if (b >= a && b >= c)
            largest = b;
        else
            largest = c;

        Console.WriteLine("Largest = " + largest);
    }
}
```

## Exercise 3: Simple Calculator with switch

**Difficulty:** Basic

### Problem
Write a program that performs `+`, `-`, `*`, `/` on two numbers based on an operator character using a `switch` statement.

**Given Input:** `a = 10, b = 5, op = '*'`

**Expected Output:**
```
50
```

### Concepts
- `switch` statement
- Arithmetic operators
- Division-by-zero handling

### Example / Starter Code

```csharp
using System;

class Calculator {
    static void Main() {
        double a = 10, b = 5, result = 0;
        char op = '*';

        switch (op) {
            case '+': result = a + b; break;
            case '-': result = a - b; break;
            case '*': result = a * b; break;
            case '/':
                if (b != 0) result = a / b;
                else Console.WriteLine("Cannot divide by zero");
                break;
            default: Console.WriteLine("Unknown operator"); break;
        }

        Console.WriteLine(result);
    }
}
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a method `CountVowels(string s)` that returns the number of vowels in `s`, ignoring case.

**Given Input:** `CountVowels("Hello World")`

**Expected Output:**
```
3
```

### Concepts
- `ToLower()` and `IndexOf()`
- `foreach` over `char`
- Method definition with return type

### Example / Starter Code

```csharp
using System;

class CountVowels {
    static int CountVowels(string s) {
        string vowels = "aeiou";
        s = s.ToLower();
        int count = 0;
        foreach (char ch in s) {
            if (vowels.IndexOf(ch) != -1) {
                count++;
            }
        }
        return count;
    }

    static void Main() {
        Console.WriteLine(CountVowels("Hello World"));   // 3
        Console.WriteLine(CountVowels("CSharp"));        // 1
    }
}
```

## Exercise 5: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that prints the multiplication table of a number `n` from `1` to `10`.

**Given Input:** `n = 5`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
```

### Concepts
- `for` loop
- String interpolation or concatenation
- `Console.WriteLine`

### Example / Starter Code

```csharp
using System;

class MultiplicationTable {
    static void Main() {
        int n = 5;
        for (int i = 1; i <= 10; i++) {
            Console.WriteLine($"{n} x {i} = {n * i}");
        }
    }
}
```
