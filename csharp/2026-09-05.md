## 2. Even or Odd
- **Description**: Read an integer from the user and print whether it is even or odd.
- **Difficulty**: Beginner
- **Concepts**: `Console.ReadLine()`, `Convert.ToInt32()`, `%` operator, `if/else`
- **Example/Starter code**:
```csharp
using System;

class EvenOdd {
    static void Main() {
        Console.Write("Enter a number: ");
        int number = Convert.ToInt32(Console.ReadLine());
        if (number % 2 == 0) {
            Console.WriteLine(number + " is even");
        } else {
            Console.WriteLine(number + " is odd");
        }
    }
}
```

## 3. Sum of an Array
- **Description**: Write a program that sums all the elements of an integer array and prints the result.
- **Difficulty**: Beginner
- **Concepts**: Arrays, `foreach` loop, accumulation
- **Example/Starter code**:
```csharp
using System;

class SumArray {
    static void Main() {
        int[] numbers = { 3, 5, 7, 2, 8 };
        int sum = 0;
        foreach (int n in numbers) {
            sum += n;
        }
        Console.WriteLine("Sum: " + sum); // 25
    }
}
```

## 4. Factorial
- **Description**: Write a program that computes the factorial of a non-negative integer n.
- **Difficulty**: Beginner
- **Concepts**: `for` loops, accumulation
- **Example/Starter code**:
```csharp
using System;

class Factorial {
    static void Main() {
        int n = 5;
        long result = 1;
        for (int i = 1; i <= n; i++) {
            result *= i;
        }
        Console.WriteLine("Factorial of " + n + " is " + result); // 120
    }
}
```

## 5. Palindrome Check
- **Description**: Write a program that checks whether a given string reads the same forwards and backwards.
- **Difficulty**: Beginner
- **Concepts**: Strings, `ToCharArray()`, `Array.Reverse()`, comparison
- **Example/Starter code**:
```csharp
using System;

class Palindrome {
    static void Main() {
        string word = "racecar";
        char[] chars = word.ToCharArray();
        Array.Reverse(chars);
        string reversed = new string(chars);
        if (word == reversed) {
            Console.WriteLine(word + " is a palindrome");
        } else {
            Console.WriteLine(word + " is not a palindrome");
        }
    }
}
```
