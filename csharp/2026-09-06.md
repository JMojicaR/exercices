## 1. Temperature Converter
- **Description**: Read a Celsius temperature and convert it to Fahrenheit (`F = C × 9/5 + 32`).
- **Difficulty**: Beginner
- **Concepts**: `Console.ReadLine()`, `Convert.ToDouble()`, arithmetic, string interpolation
- **Example/Starter code**:
```csharp
using System;

class TemperatureConverter {
    static void Main() {
        Console.Write("Enter temperature in Celsius: ");
        double celsius = Convert.ToDouble(Console.ReadLine());
        double fahrenheit = celsius * 9 / 5 + 32;
        Console.WriteLine($"{celsius} C = {fahrenheit} F");
    }
}
```

## 2. Area of a Circle
- **Description**: Read the radius of a circle and print its area (`π·r²`).
- **Difficulty**: Beginner
- **Concepts**: `const`, `Convert.ToDouble()`, `Math.PI`, string interpolation
- **Example/Starter code**:
```csharp
using System;

class CircleArea {
    static void Main() {
        Console.Write("Enter radius: ");
        double radius = Convert.ToDouble(Console.ReadLine());
        double area = Math.PI * radius * radius;
        Console.WriteLine($"Area = {area:F2}");
    }
}
```

## 3. Count the Vowels
- **Description**: Count how many vowels (`a`, `e`, `i`, `o`, `u`) appear in a string, ignoring case.
- **Difficulty**: Beginner
- **Concepts**: `string`, `ToLower()`, `foreach`, `Contains()`
- **Example/Starter code**:
```csharp
using System;

class CountVowels {
    static void Main() {
        string text = "hello world";
        string vowels = "aeiou";
        int count = 0;
        foreach (char c in text.ToLower()) {
            if (vowels.Contains(c)) count++;
        }
        Console.WriteLine($"Vowel count: {count}");
    }
}
```

## 4. Fibonacci Series
- **Description**: Print the first N numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...).
- **Difficulty**: Beginner
- **Concepts**: `for` loops, integer variables, iterative updates
- **Example/Starter code**:
```csharp
using System;

class Fibonacci {
    static void Main() {
        int n = 10, a = 0, b = 1;
        Console.WriteLine(a);
        for (int i = 1; i < n; i++) {
            Console.WriteLine(b);
            int next = a + b;
            a = b;
            b = next;
        }
    }
}
```

## 5. Sum of Digits
- **Description**: Given an integer, compute the sum of its digits (e.g. 12345 → 15).
- **Difficulty**: Beginner
- **Concepts**: `while` loops, modulo `%` and integer division `/`
- **Example/Starter code**:
```csharp
using System;

class SumOfDigits {
    static void Main() {
        int num = 12345, sum = 0;
        while (num > 0) {
            sum += num % 10;
            num /= 10;
        }
        Console.WriteLine($"Sum of digits: {sum}");
    }
}
```
