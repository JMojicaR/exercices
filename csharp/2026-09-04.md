## Exercise 1: Bubble Sort

**Difficulty:** Basic

### Problem
Write a program that sorts an integer array in ascending order using bubble sort.

**Given Input:** `{64, 34, 25, 12, 22, 11, 90}`

**Expected Output:**
```
Sorted: 11, 12, 22, 25, 34, 64, 90
```

### Concepts
- `Array.Length`
- Nested `for` loops
- `string.Join` for output

### Example / Starter Code

```csharp
using System;

class BubbleSort {
    static void Main() {
        int[] arr = { 64, 34, 25, 12, 22, 11, 90 };
        int n = arr.Length;

        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - i - 1; j++) {
                if (arr[j] > arr[j + 1]) {
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }

        Console.WriteLine("Sorted: " + string.Join(", ", arr));
    }
}
```

## Exercise 2: Linear Search

**Difficulty:** Basic

### Problem
Write a program with a `Search` method that returns the index of a target value in an array, or `-1` if absent.

**Given Input:** array `{10, 23, 45, 70, 11, 15}`, target `70`

**Expected Output:**
```
Found at index 3
```

### Concepts
- Static methods
- `for` loop over `Array.Length`
- String interpolation `$"..."`

### Example / Starter Code

```csharp
using System;

class LinearSearch {
    static int Search(int[] arr, int target) {
        for (int i = 0; i < arr.Length; i++)
            if (arr[i] == target) return i;
        return -1;
    }

    static void Main() {
        int[] nums = { 10, 23, 45, 70, 11, 15 };
        int index = Search(nums, 70);
        Console.WriteLine(index != -1 ? $"Found at index {index}" : "Not found");
    }
}
```

## Exercise 3: Anagram Check

**Difficulty:** Basic

### Problem
Write a program that checks whether two strings are anagrams, ignoring case.

**Given Input:** `"listen"`, `"silent"`

**Expected Output:**
```
Anagram
```

### Concepts
- `ToLower()`
- LINQ `OrderBy()` + `ToArray()`
- `new string(char[])`

### Example / Starter Code

```csharp
using System;
using System.Linq;

class Anagram {
    static bool IsAnagram(string s1, string s2) {
        var a = new string(s1.ToLower().OrderBy(c => c).ToArray());
        var b = new string(s2.ToLower().OrderBy(c => c).ToArray());
        return a == b;
    }

    static void Main() {
        Console.WriteLine(IsAnagram("listen", "silent") ? "Anagram" : "Not an anagram");
    }
}
```

## Exercise 4: Greatest Common Divisor (GCD)

**Difficulty:** Basic

### Problem
Write a program that computes the GCD of two positive integers using the Euclidean algorithm.

**Given Input:** `48`, `18`

**Expected Output:**
```
GCD: 6
```

### Concepts
- `while` loop
- Modulo `%`
- Method with return value

### Example / Starter Code

```csharp
using System;

class GCD {
    static int Gcd(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }

    static void Main() {
        Console.WriteLine("GCD: " + Gcd(48, 18));
    }
}
```

## Exercise 5: Armstrong Number Check

**Difficulty:** Basic

### Problem
Write a program that checks whether a number is an Armstrong number.

**Given Input:** `153`

**Expected Output:**
```
Armstrong
```

### Concepts
- `ToString()` and `Length`
- `foreach` over string
- `Math.Pow` with `(int)` cast

### Example / Starter Code

```csharp
using System;

class Armstrong {
    static bool IsArmstrong(int n) {
        string s = n.ToString();
        int power = s.Length, total = 0;
        foreach (char c in s)
            total += (int)Math.Pow(c - '0', power);
        return total == n;
    }

    static void Main() {
        Console.WriteLine(IsArmstrong(153) ? "Armstrong" : "Not Armstrong");
    }
}
```
