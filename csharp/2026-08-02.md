## Exercise 1: Hello, World!

### Example/Starter Code
```csharp
using System;

namespace HelloWorld
{
    class Program
    {

        }
    }
}
```

## Exercise 2: Temperature Converter (Celsius ↔ Fahrenheit)
- **Difficulty**: Basic
- **Concepts**: Variables, Data types (`double`), Arithmetic expressions, User I/O
- **Description**: Write a program that converts a temperature from Celsius to Fahrenheit, or vice versa. Let the user choose the conversion direction. Formula: F = (C × 9/5) + 32 and C = (F − 32) × 5/9.

### Example/Starter Code
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Temperature Converter");
        Console.WriteLine("1. Celsius to Fahrenheit");
        Console.WriteLine("2. Fahrenheit to Celsius");
        Console.Write("Choose an option (1 or 2): ");
        
        int choice = Convert.ToInt32(Console.ReadLine());
        
        if (choice == 1)
        {
            Console.Write("Enter temperature in Celsius: ");
            double celsius = Convert.ToDouble(Console.ReadLine());
            double fahrenheit = (celsius * 9 / 5) + 32;
            Console.WriteLine($"{celsius}°C = {fahrenheit}°F");
        }
        else if (choice == 2)
        {
            Console.Write("Enter temperature in Fahrenheit: ");
            double fahrenheit = Convert.ToDouble(Console.ReadLine());
            double celsius = (fahrenheit - 32) * 5 / 9;
            Console.WriteLine($"{fahrenheit}°F = {celsius}°C");
        }
        else
        {
            Console.WriteLine("Invalid choice!");
        }
    }
}
```

## Exercise 3: Multiplication Table
- **Difficulty**: Basic
- **Concepts**: Loops (`for`), String interpolation, Console output formatting
- **Description**: Write a program that displays the multiplication table (from 1 to 10) for a number entered by the user. Example: if the user enters 5, print 5 × 1 = 5, 5 × 2 = 10, ..., 5 × 10 = 50.

### Example/Starter Code
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Enter a number: ");
        int num = Convert.ToInt32(Console.ReadLine());
        
        Console.WriteLine($"\nMultiplication Table of {num}:");
        
        for (int i = 1; i <= 10; i++)
        {
            Console.WriteLine($"{num} × {i} = {num * i}");
        }
    }
}
```

## Exercise 4: Palindrome Check
- **Difficulty**: Basic
- **Concepts**: Strings, `ToLower()`, Loops, Character comparison, Boolean flags
- **Description**: Write a program that checks whether a given string is a palindrome. A palindrome reads the same forwards and backwards (e.g., "radar", "level", "Madam"). Ignore case sensitivity.

### Example/Starter Code
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Enter a string: ");
        string input = Console.ReadLine();
        
        // Convert to lowercase for case-insensitive comparison
        string str = input.ToLower();
        bool isPalindrome = true;
        
        for (int i = 0; i < str.Length / 2; i++)
        {
            if (str[i] != str[str.Length - 1 - i])
            {
                isPalindrome = false;
                break;
            }
        }
        
        if (isPalindrome)
            Console.WriteLine($"\"{input}\" is a palindrome.");
        else
            Console.WriteLine($"\"{input}\" is NOT a palindrome.");
    }
}
```

## Exercise 5: Sum of Array Elements
- **Difficulty**: Basic
- **Concepts**: Arrays, `for`/`foreach` loops, Accumulator pattern, User input collection
- **Description**: Write a program that creates an array of integers, populates it with user input, and calculates the sum of all elements. This exercise introduces array declaration, indexing, and iterating over collections.

### Example/Starter Code
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Enter the number of elements: ");
        int size = Convert.ToInt32(Console.ReadLine());
        
        int[] numbers = new int[size];
        
        // Read elements into the array
        for (int i = 0; i < size; i++)
        {
            Console.Write($"Enter element {i + 1}: ");
            numbers[i] = Convert.ToInt32(Console.ReadLine());
        }
        
        // Calculate sum
        int sum = 0;
        foreach (int num in numbers)
        {
            sum += num;
        }
        
        Console.WriteLine($"\nSum of array elements = {sum}");
    }
}
```
