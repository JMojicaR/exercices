## Exercise 1: Sum of Digits

**Difficulty:** Basic

### Problem
Write a C# program that calculates the sum of the digits of an integer.

**Given Input:** `1234`

**Expected Output:**
```
Sum of digits: 10
```

### Concepts
- `while` loops
- Modulo and integer division
- `Console.WriteLine` output

### Example / Starter Code

```csharp
using System;

class Program {
    static void Main() {
        int num = 1234;
        int sum = 0;

        while (num > 0) {
            sum += num % 10;
            num /= 10;
        }

        Console.WriteLine("Sum of digits: " + sum);
    }
}
```

## Exercise 2: Check Prime Number

**Difficulty:** Basic

### Problem
Write a method `IsPrime(int n)` that returns `true` if `n` is prime and `false` otherwise.

**Given Input:**
- `IsPrime(11)`
- `IsPrime(15)`

**Expected Output:**
- `True`
- `False`

### Concepts
- Static methods with `bool` return type
- `Math.Sqrt()` for optimization
- `for` loops with early return

### Example / Starter Code

```csharp
using System;

class Program {
    static bool IsPrime(int n) {
        if (n < 2) return false;
        for (int i = 2; i <= Math.Sqrt(n); i++) {
            if (n % i == 0) return false;
        }
        return true;
    }

    static void Main() {
        Console.WriteLine(IsPrime(11));  // True
        Console.WriteLine(IsPrime(15));  // False
    }
}
```

## Exercise 3: Armstrong Number

**Difficulty:** Basic

### Problem
Write a C# program that checks whether a number is an Armstrong number (equal to the sum of the cubes of its digits).

**Given Input:** `153`

**Expected Output:**
```
153 is an Armstrong number
```

### Concepts
- `while` loops
- Digit extraction with `% 10`
- Ternary operator (`?:`) for output

### Example / Starter Code

```csharp
using System;

class Program {
    static void Main() {
        int num = 153;
        int sum = 0;
        int temp = num;

        while (temp > 0) {
            int digit = temp % 10;
            sum += digit * digit * digit;
            temp /= 10;
        }

        Console.WriteLine(num + (sum == num ? " is" : " is not") + " an Armstrong number");
    }
}
```

## Exercise 4: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a C# program that finds the largest of three integers.

**Given Input:** `a = 10, b = 25, c = 15`

**Expected Output:**
```
Largest: 25
```

### Concepts
- `Math.Max()` helper
- Nested method calls

### Example / Starter Code

```csharp
using System;

class Program {
    static void Main() {
        int a = 10, b = 25, c = 15;
        int max = Math.Max(a, Math.Max(b, c));

        Console.WriteLine("Largest: " + max);
    }
}
```

## Exercise 5: Count Vowels

**Difficulty:** Basic

### Problem
Write a C# program that counts the number of vowels in a string (case-insensitive).

**Given Input:** `"Hello World"`

**Expected Output:**
```
Vowels: 3
```

### Concepts
- `String.ToLower()`
- `foreach` loop over a string
- `String.IndexOf()` for membership checks

### Example / Starter Code

```csharp
using System;

class Program {
    static void Main() {
        string text = "Hello World".ToLower();
        int count = 0;

        foreach (char c in text) {
            if ("aeiou".IndexOf(c) >= 0) {
                count++;
            }
        }

        Console.WriteLine("Vowels: " + count);
    }
}
```
