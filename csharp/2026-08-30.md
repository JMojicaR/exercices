## Exercise 1: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a C# program that reads a non-negative integer and prints its factorial using a `for` loop. Factorial of 0 is 1.

**Given Input:** `5`

**Expected Output:**
```
Factorial of 5 is 120
```

### Concepts
- `Console.ReadLine()` and `int.Parse()`
- `for` loop accumulator
- `long` type for larger results

### Example / Starter Code

```csharp
using System;

class Factorial {
    static void Main() {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());

        long factorial = 1;
        for (int i = 1; i <= n; i++) {
            factorial *= i;
        }

        Console.WriteLine($"Factorial of {n} is {factorial}");
    }
}
```

## Exercise 2: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a C# program that prints the first `n` terms of the Fibonacci sequence (`0, 1, 1, 2, 3, 5, …`).

**Given Input:** `7`

**Expected Output:**
```
0
1
1
2
3
5
8
```

### Concepts
- `for` loop
- Variable swapping
- String interpolation

### Example / Starter Code

```csharp
using System;

class Fibonacci {
    static void Main() {
        Console.Write("How many terms? ");
        int n = int.Parse(Console.ReadLine());

        int a = 0, b = 1;
        for (int i = 0; i < n; i++) {
            Console.WriteLine(a);
            int next = a + b;
            a = b;
            b = next;
        }
    }
}
```

## Exercise 3: Palindrome Check

**Difficulty:** Basic

### Problem
Write a C# program that reads a string and checks whether it is a palindrome (case-insensitive) using `Array.Reverse`.

**Given Input:** `Racecar`

**Expected Output:**
```
racecar is a palindrome
```

### Concepts
- `.ToLower()`
- `.ToCharArray()` and `Array.Reverse()`
- String comparison with `==`

### Example / Starter Code

```csharp
using System;

class Palindrome {
    static void Main() {
        Console.Write("Enter a string: ");
        string text = Console.ReadLine().ToLower();

        char[] chars = text.ToCharArray();
        Array.Reverse(chars);
        string reversed = new string(chars);

        if (text == reversed) {
            Console.WriteLine($"{text} is a palindrome");
        } else {
            Console.WriteLine($"{text} is not a palindrome");
        }
    }
}
```

## Exercise 4: Prime Number Check

**Difficulty:** Basic

### Problem
Write a C# program that reads a positive integer and determines whether it is a prime number.

**Given Input:** `29`

**Expected Output:**
```
29 is a prime number
```

### Concepts
- `for` loop with `break`
- Modulo operator `%`
- `Math.Sqrt()` for early exit

### Example / Starter Code

```csharp
using System;

class PrimeCheck {
    static void Main() {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());

        bool isPrime = n > 1;
        for (int i = 2; isPrime && i <= Math.Sqrt(n); i++) {
            if (n % i == 0) {
                isPrime = false;
            }
        }

        if (isPrime) {
            Console.WriteLine($"{n} is a prime number");
        } else {
            Console.WriteLine($"{n} is not a prime number");
        }
    }
}
```

## Exercise 5: Sum of Digits

**Difficulty:** Basic

### Problem
Write a C# program that reads a positive integer and prints the sum of its digits.

**Given Input:** `12345`

**Expected Output:**
```
Sum of digits: 15
```

### Concepts
- `while` loop
- Modulo `%` and integer division `/`
- Digit extraction

### Example / Starter Code

```csharp
using System;

class SumOfDigits {
    static void Main() {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());

        int total = 0;
        while (n > 0) {
            total += n % 10;
            n /= 10;
        }

        Console.WriteLine($"Sum of digits: {total}");
    }
}
```
