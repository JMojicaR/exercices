## Exercise 1: Create and Print a Matrix
**Difficulty:** Basic
**Concepts:** multidimensional arrays (`int[,]`), `GetLength`, nested `for` loops

Declare a 2D array and print it row by row.

**Starter code:**
```csharp
using System;

class PrintMatrix {
    static void Main() {
        int[,] matrix = {
            { 1, 2, 3 },
            { 4, 5, 6 },
            { 7, 8, 9 }
        };

        Console.WriteLine("Matrix:");
        for (int i = 0; i < matrix.GetLength(0); i++) {
            for (int j = 0; j < matrix.GetLength(1); j++) {
                Console.Write(matrix[i, j] + " ");
            }
            Console.WriteLine();
        }
    }
}
```

**Task:** Print the matrix using a `foreach` loop (`foreach (int val in matrix)`), then print only the last row.

## Exercise 2: Matrix Addition
**Difficulty:** Basic
**Concepts:** multidimensional arrays, element-wise addition

Add two matrices and print the sum.

**Starter code:**
```csharp
using System;

class MatrixAddition {
    static void Main() {
        int[,] a = { { 1, 2 }, { 3, 4 } };
        int[,] b = { { 5, 6 }, { 7, 8 } };
        int rows = a.GetLength(0), cols = a.GetLength(1);
        int[,] result = new int[rows, cols];

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                result[i, j] = a[i, j] + b[i, j];
            }
        }

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                Console.Write(result[i, j] + " ");
            }
            Console.WriteLine();
        }
    }
}
```

**Task:** Compute subtraction (`a - b`) and add a dimension check before adding.

## Exercise 3: Matrix Transpose
**Difficulty:** Basic
**Concepts:** row/column swapping, flipped-size array

Transpose a matrix (swap rows and columns).

**Starter code:**
```csharp
using System;

class Transpose {
    static void Main() {
        int[,] matrix = { { 1, 2, 3 }, { 4, 5, 6 } };
        int rows = matrix.GetLength(0), cols = matrix.GetLength(1);
        int[,] transpose = new int[cols, rows];

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                transpose[j, i] = matrix[i, j];
            }
        }

        for (int i = 0; i < cols; i++) {
            for (int j = 0; j < rows; j++) {
                Console.Write(transpose[i, j] + " ");
            }
            Console.WriteLine();
        }
    }
}
```

**Task:** Extract the transpose into a `static int[,] Transpose(int[,] m)` method and return the result.

## Exercise 4: Sum of the Main Diagonal
**Difficulty:** Basic
**Concepts:** square matrices, single loop, index tracking

Sum the main diagonal (top-left to bottom-right) of a square matrix.

**Starter code:**
```csharp
using System;

class DiagonalSum {
    static void Main() {
        int[,] matrix = { { 1, 2, 3 }, { 4, 5, 6 }, { 7, 8, 9 } };
        int n = matrix.GetLength(0);
        int total = 0;

        for (int i = 0; i < n; i++) {
            total += matrix[i, i];
        }

        Console.WriteLine("Sum of main diagonal: " + total);
    }
}
```

**Task:** Add the anti-diagonal using `matrix[i, n - 1 - i]` and print both sums.

## Exercise 5: Sum of Each Row and Each Column
**Difficulty:** Basic
**Concepts:** nested loops, running totals

Print the sum of every row and every column.

**Starter code:**
```csharp
using System;

class RowColumnSums {
    static void Main() {
        int[,] matrix = { { 1, 2, 3 }, { 4, 5, 6 }, { 7, 8, 9 } };
        int rows = matrix.GetLength(0), cols = matrix.GetLength(1);

        Console.WriteLine("Row sums:");
        for (int i = 0; i < rows; i++) {
            int rowSum = 0;
            for (int j = 0; j < cols; j++) {
                rowSum += matrix[i, j];
            }
            Console.WriteLine($"Row {i}: {rowSum}");
        }

        Console.WriteLine("Column sums:");
        for (int j = 0; j < cols; j++) {
            int colSum = 0;
            for (int i = 0; i < rows; i++) {
                colSum += matrix[i, j];
            }
            Console.WriteLine($"Col {j}: {colSum}");
        }
    }
}
```

**Task:** Find the row and column with the maximum sum and print their indices.
