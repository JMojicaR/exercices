## 1. Hello, World!
**Description:** Write a minimal C# console program that prints a greeting.
**Difficulty:** Basic
**Concepts:** `using System;`, `Main` method, `Console.WriteLine()`, top-level statements.
**Starter code:**
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, World!");
    }
}
```

## 2. Even or Odd
**Description:** Read an integer from the console and print whether it is even or odd.
**Difficulty:** Basic
**Concepts:** `Console.ReadLine()`, `int.Parse()`, conditionals, modulo operator.
**Starter code:**
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());
        if (n % 2 == 0)
            Console.WriteLine($"{n} is even");
        else
            Console.WriteLine($"{n} is odd");
    }
}
```

## 3. Sum of Array Elements
**Description:** Compute the sum of all elements in an integer array.
**Difficulty:** Basic
**Concepts:** Arrays, `foreach` loop, accumulator variable.
**Starter code:**
```csharp
using System;

class Program
{
    static void Main()
    {
        int[] numbers = { 1, 2, 3, 4, 5 };
        int sum = 0;
        foreach (int n in numbers)
            sum += n;
        Console.WriteLine($"Sum: {sum}");
    }
}
```

## 4. Factorial
**Description:** Compute the factorial of a number using a loop.
**Difficulty:** Basic
**Concepts:** Loops, method definitions, return values.
**Starter code:**
```csharp
using System;

class Program
{
    static long Factorial(int n)
    {
        long result = 1;
        for (int i = 1; i <= n; i++)
            result *= i;
        return result;
    }

    static void Main()
    {
        Console.WriteLine($"5! = {Factorial(5)}");
    }
}
```

## 5. FizzBuzz
**Description:** Print numbers 1 to 100, replacing multiples of 3 with "Fizz", multiples of 5 with "Buzz", and multiples of both with "FizzBuzz".
**Difficulty:** Basic
**Concepts:** `for` loop, `if`/`else if`/`else`, modulo operator, order of conditions.
**Starter code:**
```csharp
using System;

class Program
{
    static void Main()
    {
        for (int i = 1; i <= 100; i++)
        {
            if (i % 15 == 0) Console.WriteLine("FizzBuzz");
            else if (i % 3 == 0) Console.WriteLine("Fizz");
            else if (i % 5 == 0) Console.WriteLine("Buzz");
            else Console.WriteLine(i);
        }
    }
}
```
