## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** LINQ `Reverse()`, `ToArray()`, string constructor, `using System.Linq`

Write a method that returns the input string reversed.

**Starter code:**
```csharp
using System;
using System.Linq;

class Program {
    static string ReverseString(string s) {
        return new string(s.Reverse().ToArray());
    }

    static void Main() {
        Console.WriteLine(ReverseString("hello"));  // expected: olleh
    }
}
```

**Task:** Rewrite it using a `char[]` and a `for` loop that swaps characters, without LINQ.

## Exercise 2: Check Palindrome
**Difficulty:** Basic
**Concepts:** `.ToLower()`, LINQ `Reverse()`, string comparison, `bool` return

Check whether a string reads the same forwards and backwards (ignoring case).

**Starter code:**
```csharp
using System;
using System.Linq;

class Program {
    static bool IsPalindrome(string s) {
        string lower = s.ToLower();
        return lower == new string(lower.Reverse().ToArray());
    }

    static void Main() {
        Console.WriteLine(IsPalindrome("Radar"));  // expected: True
        Console.WriteLine(IsPalindrome("hello"));  // expected: False
    }
}
```

**Task:** Rewrite it comparing characters from both ends with a `for` loop and no extra array.

## Exercise 3: Count Vowels
**Difficulty:** Basic
**Concepts:** `foreach`, `.Contains()`, `.ToLower()`, counter

Count how many vowels (a, e, i, o, u) appear in a string, case-insensitively.

**Starter code:**
```csharp
using System;

class Program {
    static int CountVowels(string s) {
        int count = 0;
        string vowels = "aeiou";
        foreach (char c in s.ToLower()) {
            if (vowels.Contains(c)) {
                count++;
            }
        }
        return count;
    }

    static void Main() {
        Console.WriteLine(CountVowels("hello world"));  // expected: 3
    }
}
```

**Task:** Also count the consonants and print both totals.

## Exercise 4: Count Character Occurrences
**Difficulty:** Basic
**Concepts:** `foreach`, `char` comparison, method parameters, counter

Count how many times a given character appears in a string.

**Starter code:**
```csharp
using System;

class Program {
    static int CountChar(string s, char ch) {
        int count = 0;
        foreach (char c in s) {
            if (c == ch) {
                count++;
            }
        }
        return count;
    }

    static void Main() {
        Console.WriteLine(CountChar("banana", 'a'));  // expected: 3
    }
}
```

**Task:** Add a second overload that takes a `string` of characters and counts any of them.

## Exercise 5: Count Words
**Difficulty:** Basic
**Concepts:** `.Split()`, `StringSplitOptions.RemoveEmptyEntries`, arrays, `.Length`

Count the number of words in a sentence (words separated by spaces).

**Starter code:**
```csharp
using System;

class Program {
    static int CountWords(string sentence) {
        string[] words = sentence.Split(
            new[] { ' ' },
            StringSplitOptions.RemoveEmptyEntries);
        return words.Length;
    }

    static void Main() {
        Console.WriteLine(CountWords("I love programming"));  // expected: 3
    }
}
```

**Task:** Split on additional whitespace (tabs, newlines) as well as spaces.
