## Exercise 1: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** variables, temporary variable, string interpolation

Swap the values of two variables.

**Starter code:**
```csharp
using System;

class SwapNumbers {
    static void Main() {
        int a = 5, b = 10;

        int temp = a;
        a = b;
        b = temp;

        Console.WriteLine($"a = {a}, b = {b}");
    }
}
```

**Task:** Swap again using a C# tuple: `(a, b) = (b, a);`.

## Exercise 2: Area of a Circle
**Difficulty:** Basic
**Concepts:** `Math.PI`, `Convert.ToDouble`, `Console.ReadLine`, format specifiers

Compute the area of a circle given its radius (`area = π × r²`).

**Starter code:**
```csharp
using System;

class CircleArea {
    static void Main() {
        Console.Write("Enter radius: ");
        double radius = Convert.ToDouble(Console.ReadLine());

        double area = Math.PI * radius * radius;

        Console.WriteLine($"Area: {area:F2}");
    }
}
```

**Task:** Also print the circumference using `2 * Math.PI * radius`.

## Exercise 3: Positive, Negative or Zero
**Difficulty:** Basic
**Concepts:** `if / else if / else`, comparison operators, `Convert.ToDouble`

Classify a number as positive, negative, or zero.

**Starter code:**
```csharp
using System;

class CheckNumber {
    static void Main() {
        Console.Write("Enter a number: ");
        double n = Convert.ToDouble(Console.ReadLine());

        if (n > 0)
            Console.WriteLine("Positive");
        else if (n < 0)
            Console.WriteLine("Negative");
        else
            Console.WriteLine("Zero");
    }
}
```

**Task:** Extend it to also report whether a whole number is even or odd.

## Exercise 4: Power of a Number (xⁿ)
**Difficulty:** Basic
**Concepts:** `for` loop, accumulation, `Math.Pow`

Compute `base` raised to the power `exp` using a loop.

**Starter code:**
```csharp
using System;

class PowerOfNumber {
    static void Main() {
        Console.Write("Base: ");
        int baseNum = Convert.ToInt32(Console.ReadLine());
        Console.Write("Exponent: ");
        int exp = Convert.ToInt32(Console.ReadLine());

        int result = 1;
        for (int i = 0; i < exp; i++) {
            result *= baseNum;
        }

        Console.WriteLine($"{baseNum}^{exp} = {result}");
    }
}
```

**Task:** Rewrite using `Math.Pow(baseNum, exp)` (note: it returns a `double`).

## Exercise 5: Reverse a Number
**Difficulty:** Basic
**Concepts:** `while` loop, modulo (`%`), integer division (`/`)

Reverse the digits of an integer (e.g. 1234 → 4321).

**Starter code:**
```csharp
using System;

class ReverseNumber {
    static void Main() {
        Console.Write("Enter a number: ");
        int n = Convert.ToInt32(Console.ReadLine());

        int rev = 0;
        while (n != 0) {
            rev = rev * 10 + n % 10;
            n /= 10;
        }

        Console.WriteLine($"Reversed: {rev}");
    }
}
```

**Task:** Confirm it also works for negative numbers (the `while (n != 0)` condition handles them automatically).
