## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** methods, `for` loop, `long`, `Console.WriteLine`

Compute `n!` and return it as a `long`.

**Starter code:**
```csharp
using System;

class Factorial {
    static long Fact(int n) {
        long result = 1;
        for (int i = 1; i <= n; i++) result *= i;
        return result;
    }

    static void Main() {
        Console.WriteLine(Fact(5)); // 120
        Console.WriteLine(Fact(0)); // 1
    }
}
```

**Task:** Use `System.Numerics.BigInteger` to compute `Fact(30)` without overflow.

## Exercise 2: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** `List<int>`, `Add`, `string.Join`, variable swapping

Return the first `n` Fibonacci numbers as a `List<int>` and print them.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

class Fibonacci {
    static void Main() {
        int n = 7, a = 0, b = 1;
        var seq = new List<int>();
        for (int i = 0; i < n; i++) {
            seq.Add(a);
            int next = a + b;
            a = b; b = next;
        }
        Console.WriteLine(string.Join(" ", seq)); // 0 1 1 2 3 5 8
    }
}
```

**Task:** Refactor into a `Fibonacci(int n)` method that returns the list, and guard `n <= 0`.

## Exercise 3: Check Prime Number
**Difficulty:** Basic
**Concepts:** `bool` return, `Math.Sqrt`, `for` loop, early return

Return `true` if a number is prime, `false` otherwise.

**Starter code:**
```csharp
using System;

class PrimeCheck {
    static bool IsPrime(int n) {
        if (n < 2) return false;
        for (int i = 2; i <= Math.Sqrt(n); i++)
            if (n % i == 0) return false;
        return true;
    }

    static void Main() {
        Console.WriteLine(IsPrime(7));  // True
        Console.WriteLine(IsPrime(10)); // False
    }
}
```

**Task:** Add a `CountPrimes(int limit)` method that returns the number of primes below `limit`.

## Exercise 4: Sum of Digits
**Difficulty:** Basic
**Concepts:** `%` and `/`, `while` loop, digit extraction

Return the sum of the individual digits of a number.

**Starter code:**
```csharp
using System;

class SumOfDigits {
    static int SumDigits(int n) {
        int sum = 0;
        while (n > 0) { sum += n % 10; n /= 10; }
        return sum;
    }

    static void Main() {
        Console.WriteLine(SumDigits(1234)); // 10
    }
}
```

**Task:** Rewrite it using `n.ToString()` and `char.GetNumericValue`, then compare the two approaches.

## Exercise 5: Greatest Common Divisor (GCD)
**Difficulty:** Basic
**Concepts:** Euclidean algorithm, `while` loop, temporary variable, `%`

Compute the greatest common divisor of two integers.

**Starter code:**
```csharp
using System;

class GCD {
    static int Gcd(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }

    static void Main() {
        Console.WriteLine(Gcd(48, 18)); // 6
        Console.WriteLine(Gcd(100, 35)); // 5
    }
}
```

**Task:** Add an `Lcm(int a, int b)` method using `Lcm(a, b) = a / Gcd(a, b) * b`.
