## Exercise 1: Find Maximum & Minimum
**Difficulty:** Basic
**Concepts:** `int[]`, `foreach` loop, comparisons, string interpolation

Find and print the smallest and largest values in an integer array.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int[] numbers = { 3, 1, 4, 1, 5, 9, 2 };
        int min = numbers[0], max = numbers[0];
        foreach (int n in numbers) {
            if (n < min) min = n;
            if (n > max) max = n;
        }
        Console.WriteLine($"min = {min}, max = {max}"); // min = 1, max = 9
    }
}
```

**Task:** Rewrite using LINQ `numbers.Min()` and `numbers.Max()` (add `using System.Linq;`), and handle the empty-array case with `if (numbers.Length == 0)`.

## Exercise 2: Sum of Elements
**Difficulty:** Basic
**Concepts:** `int[]`, `foreach` loop, accumulator

Compute and print the sum of all elements in an integer array.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int[] numbers = { 1, 2, 3, 4, 5 };
        int total = 0;
        foreach (int n in numbers) {
            total += n;
        }
        Console.WriteLine($"sum = {total}"); // sum = 15
    }
}
```

**Task:** Replace the loop with LINQ `numbers.Sum()`, then compute the average using `numbers.Average()` (note it returns a `double`).

## Exercise 3: Reverse an Array
**Difficulty:** Basic
**Concepts:** array indexing, `new int[]`, `string.Join()`

Build a new array holding the elements of the input in reverse order.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int[] numbers = { 1, 2, 3, 4 };
        int[] reversed = new int[numbers.Length];
        for (int i = 0; i < numbers.Length; i++) {
            reversed[i] = numbers[numbers.Length - 1 - i];
        }
        Console.WriteLine(string.Join(" ", reversed)); // 4 3 2 1
    }
}
```

**Task:** Use the built-in `Array.Reverse(numbers)` to reverse in place, and compare its behavior with your new-array version.

## Exercise 4: Count Occurrences
**Difficulty:** Basic
**Concepts:** `foreach` loop, equality `==`, counter

Count how many times a target value appears in an integer array.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int[] numbers = { 1, 2, 3, 2, 4, 2 };
        int target = 2, count = 0;
        foreach (int n in numbers) {
            if (n == target) count++;
        }
        Console.WriteLine($"count of {target} = {count}"); // count of 2 = 3
    }
}
```

**Task:** Rewrite with LINQ `numbers.Count(n => n == target)`, and also count occurrences of a string in a `string[]` array.

## Exercise 5: Remove Duplicates
**Difficulty:** Basic
**Concepts:** `List<T>`, `.Contains()`, generics, order preservation

Build a list of unique values, preserving the original order of first appearance.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

class Program {
    static void Main() {
        int[] numbers = { 1, 2, 2, 3, 4, 4, 4, 5 };
        List<int> unique = new List<int>();
        foreach (int n in numbers) {
            if (!unique.Contains(n)) unique.Add(n);
        }
        Console.WriteLine(string.Join(" ", unique)); // 1 2 3 4 5
    }
}
```

**Task:** Rewrite using `new HashSet<int>(numbers)` (which removes duplicates, but does not guarantee order) and then restore order with `numbers.Distinct()` from LINQ.
