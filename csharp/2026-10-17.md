## Exercise 1: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** arrays, `foreach` loop, accumulation, LINQ `Sum()`

Compute the sum of all elements in an integer array.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int[] numbers = { 10, 20, 30, 40, 50 };
        int sum = 0;
        foreach (int n in numbers) {
            sum += n;
        }
        Console.WriteLine("Sum: " + sum);
    }
}
```

**Task:** Rewrite it using `numbers.Sum()` from `System.Linq`.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** modulo operator (`%`), `if/else`

Check whether a number is even or odd.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int n = 7;
        if (n % 2 == 0) {
            Console.WriteLine(n + " is even");
        } else {
            Console.WriteLine(n + " is odd");
        }
    }
}
```

**Task:** Read the number from the user with `Console.ReadLine()`.

## Exercise 3: Celsius to Fahrenheit
**Difficulty:** Basic
**Concepts:** arithmetic, methods, `double`

Convert Celsius to Fahrenheit using `F = C × 9/5 + 32`.

**Starter code:**
```csharp
using System;

class Program {
    static double CToF(double celsius) {
        return (celsius * 9 / 5) + 32;
    }

    static void Main() {
        Console.WriteLine("20°C = " + CToF(20) + "°F");
    }
}
```

**Task:** Add an `FToC` method that converts Fahrenheit back to Celsius.

## Exercise 4: Find the Smallest Number
**Difficulty:** Basic
**Concepts:** arrays, comparison, loops, LINQ `Min()`

Find the smallest value in an integer array.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int[] numbers = { 45, 12, 78, 4, 33 };
        int smallest = numbers[0];
        foreach (int n in numbers) {
            if (n < smallest) smallest = n;
        }
        Console.WriteLine("Smallest: " + smallest);
    }
}
```

**Task:** Solve it with `numbers.Min()` from `System.Linq`.

## Exercise 5: Simple Interest
**Difficulty:** Basic
**Concepts:** variables, arithmetic, `double`

Calculate simple interest using `SI = (P × R × T) / 100`.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        double principal = 1000, rate = 5, time = 3;
        double interest = (principal * rate * time) / 100;
        Console.WriteLine("Simple interest: " + interest);
    }
}
```

**Task:** Also print the total amount (principal + interest).
