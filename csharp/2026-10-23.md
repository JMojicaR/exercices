## Exercise 1: Print the ASCII Value of a Character
**Difficulty:** Basic
**Concepts:** type casting (`char` → `int`), `Console.WriteLine`

Given a character, print its ASCII (Unicode) value.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        char ch = 'A';
        int ascii = (int)ch;
        Console.WriteLine($"ASCII value of {ch} is {ascii}");
    }
}
```

**Task:** Loop over the alphabet (`for (char c = 'A'; c <= 'Z'; c++)`) printing each letter and its code.

## Exercise 2: Check Vowel or Consonant
**Difficulty:** Basic
**Concepts:** `switch`, `char.ToLower`, string methods

Read a letter and report whether it is a vowel or a consonant.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        char ch = 'e';
        ch = char.ToLower(ch);

        switch (ch) {
            case 'a': case 'e': case 'i': case 'o': case 'u':
                Console.WriteLine($"{ch} is a vowel");
                break;
            default:
                Console.WriteLine($"{ch} is a consonant");
                break;
        }
    }
}
```

**Task:** Read input with `Console.ReadLine()`, and use `char.IsLetter(ch)` to print "Not a letter" for invalid input.

## Exercise 3: Maximum and Minimum in an Array
**Difficulty:** Basic
**Concepts:** arrays, `foreach`, LINQ `Max()` / `Min()`

Find the largest and smallest values in an integer array.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int[] numbers = { 45, 12, 78, 34, 89, 23 };
        int max = numbers[0];
        int min = numbers[0];

        foreach (int n in numbers) {
            if (n > max) max = n;
            if (n < min) min = n;
        }

        Console.WriteLine($"Max: {max}, Min: {min}");
    }
}
```

**Task:** Rewrite using LINQ (`numbers.Max()` and `numbers.Min()`), then compute the sum with `numbers.Sum()`.

## Exercise 4: Simple Calculator
**Difficulty:** Basic
**Concepts:** `switch`, arithmetic operators, `double.Parse`

Build a calculator that reads two numbers and an operator and prints the result.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        Console.Write("First number: ");
        double a = double.Parse(Console.ReadLine());
        Console.Write("Second number: ");
        double b = double.Parse(Console.ReadLine());
        Console.Write("Operator (+, -, *, /): ");
        char op = Console.ReadLine()[0];

        switch (op) {
            case '+': Console.WriteLine(a + b); break;
            case '-': Console.WriteLine(a - b); break;
            case '*': Console.WriteLine(a * b); break;
            case '/':
                if (b != 0) Console.WriteLine(a / b);
                else Console.WriteLine("Cannot divide by zero");
                break;
            default: Console.WriteLine("Invalid operator");
        }
    }
}
```

**Task:** Add a `%` case, and use `double.TryParse` so the program reports "Invalid number" instead of crashing on bad input.

## Exercise 5: Print Prime Numbers in a Range
**Difficulty:** Basic
**Concepts:** nested `for` loops, `break`, boolean flags

Print every prime number between two given bounds (e.g. 10 and 50).

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int start = 10, end = 50;

        for (int num = start; num <= end; num++) {
            bool isPrime = num >= 2;
            for (int i = 2; i <= Math.Sqrt(num); i++) {
                if (num % i == 0) {
                    isPrime = false;
                    break;
                }
            }
            if (isPrime) Console.Write(num + " ");
        }
    }
}
```

**Task:** Extract the check into a `static bool IsPrime(int n)` method and print the count of primes found.
