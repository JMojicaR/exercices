## Exercise 1: Hello World

**Difficulty:** Basic

### Problem
Write a C# program that prints "Hello, World!" and then prints the value of a string and an integer variable using string interpolation.

**Expected Output:**
```
Hello, World!
Name: Alice, Age: 25
```

### Concepts
- `class` and `Main` method
- `Console.WriteLine()`
- String interpolation (`$"..."`)

### Example / Starter Code

```csharp
using System;

class HelloWorld
{
    static void Main()
    {
        string name = "Alice";
        int age = 25;

        Console.WriteLine("Hello, World!");
        Console.WriteLine($"Name: {name}, Age: {age}");
    }
}
```

## Exercise 2: Even or Odd

**Difficulty:** Basic

### Problem
Write a C# program that reads an integer from the user and prints whether it is even or odd.

**Given Input:** `7`

**Expected Output:**
```
Enter a number: 7
7 is Odd
```

### Concepts
- `Console.ReadLine()` and `Convert.ToInt32()`
- `if`/`else` and the modulo operator `%`

### Example / Starter Code

```csharp
using System;

class EvenOdd
{
    static void Main()
    {
        Console.Write("Enter a number: ");
        int number = Convert.ToInt32(Console.ReadLine());

        if (number % 2 == 0)
        {
            Console.WriteLine($"{number} is Even");
        }
        else
        {
            Console.WriteLine($"{number} is Odd");
        }
    }
}
```

## Exercise 3: Sum of Numbers 1 to N

**Difficulty:** Basic

### Problem
Write a C# program that reads a positive integer `n` and prints the sum of all integers from 1 to `n`.

**Given Input:** `10`

**Expected Output:**
```
Sum from 1 to 10 is 55
```

### Concepts
- `for` loop
- Accumulator variable

### Example / Starter Code

```csharp
using System;

class SumToN
{
    static void Main()
    {
        Console.Write("Enter a positive integer: ");
        int n = Convert.ToInt32(Console.ReadLine());

        int total = 0;
        for (int i = 1; i <= n; i++)
        {
            total += i;
        }

        Console.WriteLine($"Sum from 1 to {n} is {total}");
    }
}
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a C# program that counts the vowels (a, e, i, o, u) in a string, ignoring case.

**Given Input:** `"Hello World"`

**Expected Output:**
```
Number of vowels: 3
```

### Concepts
- `foreach` loop over a string
- `char.ToLower()` and `"aeiou".Contains()`

### Example / Starter Code

```csharp
using System;

class CountVowels
{
    static void Main()
    {
        string text = "Hello World";
        int count = 0;

        foreach (char c in text.ToLower())
        {
            if ("aeiou".Contains(c))
            {
                count++;
            }
        }

        Console.WriteLine($"Number of vowels: {count}");
    }
}
```

## Exercise 5: Find the Maximum in an Array

**Difficulty:** Basic

### Problem
Write a C# program that finds and prints the largest value in an integer array.

**Given Input:** `{12, 5, 8, 130, 44}`

**Expected Output:**
```
Maximum is 130
```

### Concepts
- Arrays
- `foreach` loop
- Tracking a running maximum

### Example / Starter Code

```csharp
using System;

class MaxInArray
{
    static void Main()
    {
        int[] numbers = { 12, 5, 8, 130, 44 };

        int max = numbers[0];
        foreach (int num in numbers)
        {
            if (num > max)
            {
                max = num;
            }
        }

        Console.WriteLine($"Maximum is {max}");
    }
}
```
