## Exercise 1: Palindrome String
**Difficulty:** Basic
**Concepts:** string, loops, ToLower

Check whether a word reads the same backwards and forwards.

**Starter code:**
```csharp
using System;

class Palindrome
{
    static void Main()
    {
        Console.Write("Enter a word: ");
        string word = Console.ReadLine().ToLower();
        string reversed = "";
        for (int i = word.Length - 1; i >= 0; i--)
        {
            reversed += word[i];
        }
        Console.WriteLine(word == reversed ? "palindrome" : "not a palindrome");
    }
}
```

**Task:** Compare characters from both ends without building a second string.

## Exercise 2: Factorial
**Difficulty:** Basic
**Concepts:** for loop, methods, long

Compute the factorial of a non-negative integer using a method.

**Starter code:**
```csharp
using System;

class Factorial
{
    static long Fact(int n)
    {
        long result = 1;
        for (int i = 1; i <= n; i++)
        {
            result *= i;
        }
        return result;
    }

    static void Main()
    {
        Console.Write("Enter a non-negative integer: ");
        int n = int.Parse(Console.ReadLine());
        Console.WriteLine($"{n}! = {Fact(n)}");
    }
}
```

**Task:** Print the factorial of every number from 1 to 10.

## Exercise 3: Even or Odd
**Difficulty:** Basic
**Concepts:** if/else, modulo

Read an integer and print whether it is even or odd.

**Starter code:**
```csharp
using System;

class EvenOdd
{
    static void Main()
    {
        Console.Write("Enter an integer: ");
        int num = int.Parse(Console.ReadLine());
        if (num % 2 == 0)
        {
            Console.WriteLine($"{num} is even");
        }
        else
        {
            Console.WriteLine($"{num} is odd");
        }
    }
}
```

**Task:** Use a ternary expression (`?:`) instead of the if/else block.

## Exercise 4: Average of an Array
**Difficulty:** Basic
**Concepts:** arrays, for/foreach loop, casting

Compute the average of the numbers in an integer array.

**Starter code:**
```csharp
using System;

class ArrayAverage
{
    static void Main()
    {
        int[] numbers = { 12, 7, 9, 4, 18 };
        int sum = 0;
        foreach (int n in numbers)
        {
            sum += n;
        }
        double average = (double)sum / numbers.Length;
        Console.WriteLine($"Average: {average}");
    }
}
```

**Task:** Use `numbers.Average()` from LINQ (add `using System.Linq;`) and print the max too.

## Exercise 5: Multiplication Table
**Difficulty:** Basic
**Concepts:** nested loops, formatting

Print the multiplication table for a number from 1 to 10.

**Starter code:**
```csharp
using System;

class TimesTable
{
    static void Main()
    {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());
        for (int i = 1; i <= 10; i++)
        {
            Console.WriteLine($"{n} x {i} = {n * i}");
        }
    }
}
```

**Task:** Print the full 10×10 multiplication table using nested loops.
