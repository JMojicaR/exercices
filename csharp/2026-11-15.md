## Exercise 1: try/catch Basics
**Difficulty:** Basic
**Concepts:** `try`, `catch`, `DivideByZeroException`, `ex.Message`

Catch the exception thrown by integer division by zero.

**Starter code:**
```csharp
using System;

class Program
{
    static int Divide(int a, int b)
    {
        return a / b;
    }

    static void Main()
    {
        try
        {
            Console.WriteLine(Divide(10, 2)); // 5
            Console.WriteLine(Divide(10, 0)); // throws
        }
        catch (DivideByZeroException ex)
        {
            Console.WriteLine("Error: " + ex.Message);
        }
    }
}
```

**Task:** Loop over a list of divisors `{2, 0, 5}` inside the `try`, catching the exception once per iteration so the loop continues after the zero.

## Exercise 2: The finally Block
**Difficulty:** Basic
**Concepts:** `finally`, guaranteed cleanup regardless of success or failure

Show that a `finally` block always executes.

**Starter code:**
```csharp
using System;

class Program
{
    static void Main()
    {
        try
        {
            Console.WriteLine("Trying...");
            int result = 10 / 0;
            Console.WriteLine(result);
        }
        catch (DivideByZeroException ex)
        {
            Console.WriteLine("Caught: " + ex.Message);
        }
        finally
        {
            Console.WriteLine("This always runs");
        }
    }
}
```

**Task:** Add a second `try` block (no exception) whose `finally` prints a different message, and confirm both `finally` blocks run in order.

## Exercise 3: int.Parse FormatException
**Difficulty:** Basic
**Concepts:** `int.Parse`, `FormatException`, string interpolation, iterating with `foreach`

Parse strings into integers and handle the format error.

**Starter code:**
```csharp
using System;

class Program
{
    static void Main()
    {
        string[] inputs = { "10", "abc", "5" };
        foreach (string s in inputs)
        {
            try
            {
                int n = int.Parse(s);
                Console.WriteLine("Parsed: " + n);
            }
            catch (FormatException ex)
            {
                Console.WriteLine($"'{s}' is not a number: {ex.Message}");
            }
        }
    }
}
```

**Task:** Use `int.TryParse` to rewrite the loop without exceptions, and print the parsed value or a fallback for each input.

## Exercise 4: Custom Exception Class
**Difficulty:** Basic
**Concepts:** `: Exception`, `base(message)`, `throw`, catching a custom type

Define `InvalidAgeException` and throw it from a validation method.

**Starter code:**
```csharp
using System;

class InvalidAgeException : Exception
{
    public InvalidAgeException(string message) : base(message) { }
}

class Program
{
    static void CheckAge(int age)
    {
        if (age < 0)
            throw new InvalidAgeException("Age cannot be negative");
        Console.WriteLine("Age is valid: " + age);
    }

    static void Main()
    {
        try
        {
            CheckAge(-1);
        }
        catch (InvalidAgeException ex)
        {
            Console.WriteLine("Error: " + ex.Message);
        }
    }
}
```

**Task:** Add an `age > 150` check that throws `InvalidAgeException("Age is unrealistically high")` and call `CheckAge(200)` to verify.

## Exercise 5: Multiple catch Blocks + throw
**Difficulty:** Basic
**Concepts:** multiple `catch` blocks, `IndexOutOfRangeException`, `throw`, most-specific-first ordering

Throw a descriptive exception for an invalid index and catch it specifically.

**Starter code:**
```csharp
using System;

class Program
{
    static int GetElement(int[] arr, int index)
    {
        if (index < 0 || index >= arr.Length)
            throw new IndexOutOfRangeException($"Index {index} is out of bounds");
        return arr[index];
    }

    static void Main()
    {
        int[] nums = { 1, 2, 3 };
        try
        {
            Console.WriteLine(GetElement(nums, 5));
        }
        catch (IndexOutOfRangeException ex)
        {
            Console.WriteLine("Index error: " + ex.Message);
        }
        catch (Exception ex)
        {
            Console.WriteLine("Other error: " + ex.Message);
        }
    }
}
```

**Task:** Call `GetElement(nums, -1)` and confirm the negative index hits the same `IndexOutOfRangeException` catch with its own message.
