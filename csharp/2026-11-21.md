## Exercise 1: `Stack<T>` — Push, Pop, Peek
**Difficulty:** Basic
**Concepts:** `Stack<T>`, `Push()`, `Pop()`, `Peek()`, `Count`, LIFO order

`Stack<T>` is a LIFO collection in `System.Collections.Generic`.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

class Program {
    static void Main() {
        var stack = new Stack<string>();

        stack.Push("a");   // push
        stack.Push("b");
        stack.Push("c");

        Console.WriteLine(stack.Peek());    // c (top without removing)
        string top = stack.Pop();           // remove top
        Console.WriteLine(top);             // c
        Console.WriteLine(stack.Peek());    // b
        Console.WriteLine(stack.Count);     // 2
    }
}
```

**Task:** Push the integers `1..5` onto a stack and pop them all, printing each. The output should be `5 4 3 2 1`.

## Exercise 2: `Queue<T>` — Enqueue, Dequeue, Peek
**Difficulty:** Basic
**Concepts:** `Queue<T>`, `Enqueue()`, `Dequeue()`, `Peek()`, `Count`, FIFO order

`Queue<T>` is a FIFO collection.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

class Program {
    static void Main() {
        var q = new Queue<string>();

        q.Enqueue("a");   // enqueue (back)
        q.Enqueue("b");
        q.Enqueue("c");

        Console.WriteLine(q.Peek());    // a (front without removing)
        string first = q.Dequeue();     // dequeue (front)
        Console.WriteLine(first);       // a
        Console.WriteLine(q.Peek());    // b
        Console.WriteLine(q.Count);     // 2
    }
}
```

**Task:** Enqueue the numbers `1..5` and dequeue them all, printing each. The output should be `1 2 3 4 5`.

## Exercise 3: Balanced Parentheses with `Stack<char>`
**Difficulty:** Basic
**Concepts:** `Stack<char>`, matching pairs, early `false` on mismatch

Use a character stack to check balanced brackets.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

class Program {
    static bool IsBalanced(string s) {
        var stack = new Stack<char>();
        foreach (char ch in s) {
            if (ch == '(' || ch == '[' || ch == '{') {
                stack.Push(ch);
            } else if (ch == ')' || ch == ']' || ch == '}') {
                if (stack.Count == 0) return false;
                char open = stack.Pop();
                if ((ch == ')' && open != '(') ||
                    (ch == ']' && open != '[') ||
                    (ch == '}' && open != '{')) return false;
            }
        }
        return stack.Count == 0;
    }

    static void Main() {
        Console.WriteLine(IsBalanced("(a[b]{c})"));   // True
        Console.WriteLine(IsBalanced("([)]"));        // False
    }
}
```

**Task:** Add a test for the input `"((("` and confirm it returns `False` (unmatched openers remain on the stack).

## Exercise 4: Reverse a String with `Stack<char>`
**Difficulty:** Basic
**Concepts:** push characters, pop to a `StringBuilder`, `ToString()`

Push each character and pop them off to reverse the string.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;
using System.Text;

class Program {
    static string ReverseString(string text) {
        var stack = new Stack<char>();
        foreach (char ch in text) stack.Push(ch);
        var sb = new StringBuilder();
        while (stack.Count > 0) sb.Append(stack.Pop());
        return sb.ToString();
    }

    static void Main() {
        Console.WriteLine(ReverseString("hello"));   // "olleh"
    }
}
```

**Task:** Modify the method to skip vowels when pushing, so `ReverseString("hello")` returns `"llh"`.

## Exercise 5: Simulate a Job Queue with `Queue<T>`
**Difficulty:** Basic
**Concepts:** `while (q.Count > 0)`, `Dequeue()`, processing in arrival order

Simulate a printer/job queue processing tasks in FIFO order.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

class Program {
    static void Main() {
        var jobs = new Queue<string>();
        jobs.Enqueue("print-report");
        jobs.Enqueue("print-invoice");
        jobs.Enqueue("print-receipt");

        while (jobs.Count > 0) {
            string job = jobs.Dequeue();
            Console.WriteLine("Processing: " + job);
        }
        Console.WriteLine("All jobs done: " + (jobs.Count == 0));
    }
}
```

**Task:** Print the remaining number of jobs (using `jobs.Count`) inside the loop before each `Dequeue()`.
