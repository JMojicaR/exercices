## Exercise 1: Temperature Converter
**Difficulty:** Basic
**Concepts:** `Console.ReadLine`, `Convert.ToDouble`, arithmetic, string interpolation.

Write a program that converts a Celsius temperature to Fahrenheit.

**Starter code:**
```csharp
using System;

class TemperatureConverter
{
    static void Main()
    {
        Console.Write("Enter temperature in Celsius: ");
        double celsius = Convert.ToDouble(Console.ReadLine());

        double fahrenheit = (celsius * 9 / 5) + 32;

        Console.WriteLine($"{celsius}°C = {fahrenheit}°F");
    }
}
```

**Task:** Add the reverse conversion (Fahrenheit → Celsius) and let the user choose the direction.

## Exercise 2: Check Palindrome
**Difficulty:** Basic
**Concepts:** Strings, `ToCharArray`, `Array.Reverse`, string comparison.

Write a program that checks whether a word is a palindrome.

**Starter code:**
```csharp
using System;

class PalindromeCheck
{
    static void Main()
    {
        Console.Write("Enter a word: ");
        string word = Console.ReadLine();

        char[] chars = word.ToCharArray();
        Array.Reverse(chars);
        string reversed = new string(chars);

        if (word.Equals(reversed, StringComparison.OrdinalIgnoreCase))
            Console.WriteLine($"{word} is a palindrome.");
        else
            Console.WriteLine($"{word} is not a palindrome.");
    }
}
```

**Task:** Ignore spaces and punctuation so phrases like "A man, a plan, a canal: Panama" pass.

## Exercise 3: Count Vowels in a String
**Difficulty:** Basic
**Concepts:** `foreach`, `char.ToLower`, strings, counting, `Contains`.

Write a program that counts the vowels in a string.

**Starter code:**
```csharp
using System;

class VowelCount
{
    static void Main()
    {
        Console.Write("Enter a string: ");
        string text = Console.ReadLine().ToLower();

        int count = 0;
        foreach (char c in text)
        {
            if ("aeiou".Contains(c))
                count++;
        }

        Console.WriteLine($"Vowels: {count}");
    }
}
```

**Task:** Also count consonants and print both totals.

## Exercise 4: Fibonacci Series
**Difficulty:** Basic
**Concepts:** Loops, variable swapping, sequence generation.

Write a program that prints the first `n` Fibonacci numbers.

**Starter code:**
```csharp
using System;

class FibonacciSeries
{
    static void Main()
    {
        Console.Write("How many terms? ");
        int n = Convert.ToInt32(Console.ReadLine());

        int a = 0, b = 1;
        for (int i = 0; i < n; i++)
        {
            Console.Write(a + " ");
            int next = a + b;
            a = b;
            b = next;
        }
        Console.WriteLine();
    }
}
```

**Task:** Print the sum of the first `n` Fibonacci numbers.

## Exercise 5: Sum and Average of an Array
**Difficulty:** Basic
**Concepts:** Arrays, `for`/`foreach` loops, accumulator, type casting, LINQ optional.

Write a program that computes the sum and average of an array of numbers.

**Starter code:**
```csharp
using System;

class ArrayStats
{
    static void Main()
    {
        int[] numbers = { 12, 7, 23, 41, 18 };

        int sum = 0;
        foreach (int n in numbers)
        {
            sum += n;
        }

        double average = (double)sum / numbers.Length;

        Console.WriteLine($"Sum: {sum}");
        Console.WriteLine($"Average: {average}");
    }
}
```

**Task:** Let the user enter the numbers one per line, and also print the minimum and maximum.
