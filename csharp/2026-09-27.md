## Exercise 1: Add Two Numbers
**Difficulty:** Basic
**Concepts:** `Console.ReadLine`, `int.Parse`, string interpolation, arithmetic.

Write a program that reads two integers and prints their sum.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter first number: ");
        int a = int.Parse(Console.ReadLine());
        Console.Write("Enter second number: ");
        int b = int.Parse(Console.ReadLine());
        Console.WriteLine("Sum: " + (a + b));
    }
}
```

**Task:** Use `int.TryParse` so the program handles non-numeric input without crashing.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** Modulo (`%`), `if`/`else`.

Write a program that reads an integer and prints whether it is even or odd.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());
        if (n % 2 == 0)
            Console.WriteLine(n + " is even");
        else
            Console.WriteLine(n + " is odd");
    }
}
```

**Task:** Use a `switch` statement on `n % 2` to produce the same output.

## Exercise 3: Multiplication Table
**Difficulty:** Basic
**Concepts:** `for` loop, string interpolation (`$`).

Write a program that prints the multiplication table (1–10) for a given number.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());
        for (int i = 1; i <= 10; i++)
            Console.WriteLine($"{n} x {i} = {n * i}");
    }
}
```

**Task:** Use nested loops to print tables for numbers 1 through 5.

## Exercise 4: Factorial
**Difficulty:** Basic
**Concepts:** Loops, `long` type, accumulator variables.

Write a program that reads a non-negative integer and prints its factorial.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());
        long f = 1;
        for (int i = 1; i <= n; i++)
            f *= i;
        Console.WriteLine($"{n}! = {f}");
    }
}
```

**Task:** Move the factorial calculation into a `static long Factorial(int n)` method.

## Exercise 5: Reverse a String
**Difficulty:** Basic
**Concepts:** `ToCharArray`, `Array.Reverse`, `string` constructor.

Write a program that reads a string and prints it reversed.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter a string: ");
        string s = Console.ReadLine();
        char[] chars = s.ToCharArray();
        Array.Reverse(chars);
        Console.WriteLine("Reversed: " + new string(chars));
    }
}
```

**Task:** Reverse the string with a manual `for` loop instead of `Array.Reverse`.
