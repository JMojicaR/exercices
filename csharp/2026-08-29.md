## Exercise 1: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that reads an integer `n` and prints its multiplication table from 1 to 10 using a `for` loop and string interpolation.

**Given Input:** `5`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

### Concepts
- `Console.ReadLine()` and `int.Parse()`
- `for` loop
- String interpolation (`$"..."`)

### Example / Starter Code

```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());

        for (int i = 1; i <= 10; i++) {
            Console.WriteLine($"{n} x {i} = {n * i}");
        }
    }
}
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that reads three integers and prints the largest using `if`/`else if`/`else`.

**Given Input:** `10 25 15`

**Expected Output:**
```
Largest: 25
```

### Concepts
- `Console.ReadLine().Split(' ')`
- `int.Parse()`
- `if`/`else if`/`else`

### Example / Starter Code

```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter three numbers (space-separated): ");
        string[] parts = Console.ReadLine().Split(' ');
        int a = int.Parse(parts[0]);
        int b = int.Parse(parts[1]);
        int c = int.Parse(parts[2]);

        int largest;
        if (a >= b && a >= c) {
            largest = a;
        } else if (b >= a && b >= c) {
            largest = b;
        } else {
            largest = c;
        }

        Console.WriteLine($"Largest: {largest}");
    }
}
```

## Exercise 3: Reverse a String

**Difficulty:** Basic

### Problem
Write a program that reads a string and prints it reversed using `ToCharArray()` and `Array.Reverse()`.

**Given Input:** `hello`

**Expected Output:**
```
Reversed: olleh
```

### Concepts
- `string.ToCharArray()`
- `Array.Reverse()`
- `new string(char[])`

### Example / Starter Code

```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter a string: ");
        string text = Console.ReadLine();

        char[] arr = text.ToCharArray();
        Array.Reverse(arr);
        string reversed = new string(arr);

        Console.WriteLine($"Reversed: {reversed}");
    }
}
```

## Exercise 4: Leap Year Checker

**Difficulty:** Basic

### Problem
Write a program that reads a year and prints whether it is a leap year using the modulo operator and boolean logic.

**Given Input:** `2024`

**Expected Output:**
```
2024 is a leap year
```

### Concepts
- Modulo operator `%`
- Boolean logic with `&&` and `||`
- Ternary operator (`? :`)

### Example / Starter Code

```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter a year: ");
        int year = int.Parse(Console.ReadLine());

        bool isLeap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
        Console.WriteLine(year + (isLeap ? " is a leap year" : " is not a leap year"));
    }
}
```

## Exercise 5: Simple Calculator

**Difficulty:** Basic

### Problem
Write a program that reads two numbers and an operator (`+`, `-`, `*`, `/`) and prints the result using a `switch` statement. Handle division by zero.

**Given Input:** `8 2 /`

**Expected Output:**
```
Result: 4
```

### Concepts
- `switch` statement
- `double.Parse()`
- Division-by-zero handling

### Example / Starter Code

```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter first number: ");
        double a = double.Parse(Console.ReadLine());
        Console.Write("Enter second number: ");
        double b = double.Parse(Console.ReadLine());
        Console.Write("Enter operator (+, -, *, /): ");
        char op = Console.ReadLine()[0];

        switch (op) {
            case '+': Console.WriteLine($"Result: {a + b}"); break;
            case '-': Console.WriteLine($"Result: {a - b}"); break;
            case '*': Console.WriteLine($"Result: {a * b}"); break;
            case '/':
                Console.WriteLine(b != 0 ? $"Result: {a / b}" : "Error: division by zero");
                break;
            default: Console.WriteLine("Invalid operator"); break;
        }
    }
}
```
