## Exercise 1: Define a Node Class and Build a List
**Difficulty:** Basic
**Concepts:** class with constructor, reference types, `null`, `while`-loop traversal

**Starter code:**
```csharp
using System;

public class Node {
    public int Value;
    public Node Next;
    public Node(int value) { Value = value; Next = null; }
}

class Program {
    static void Main() {
        Node head = new Node(10);
        head.Next = new Node(20);
        head.Next.Next = new Node(30);

        Node current = head;
        while (current != null) {
            Console.Write(current.Value + " ");
            current = current.Next;
        }
        // prints: 10 20 30
    }
}
```

**Task:** Write a `PrintList(Node head)` method that prints values separated by `" -> "` and ends with `"null"`.

## Exercise 2: Append a Node to the End
**Difficulty:** Basic
**Concepts:** walking to the tail, empty-list edge case, updating references

**Starter code:**
```csharp
static Node Append(Node head, int value) {
    if (head == null) return new Node(value);
    Node current = head;
    while (current.Next != null) current = current.Next;
    current.Next = new Node(value);
    return head;
}
```

**Task:** Append the numbers `1..5` to an empty list (`null`) in a loop and print the result.

## Exercise 3: Length and Sum of a Linked List
**Difficulty:** Basic
**Concepts:** counter variable, accumulating a running total

**Starter code:**
```csharp
static int Length(Node head) {
    int count = 0;
    for (Node cur = head; cur != null; cur = cur.Next) count++;
    return count;
}

static int Sum(Node head) {
    int total = 0;
    for (Node cur = head; cur != null; cur = cur.Next) total += cur.Value;
    return total;
}
```

**Task:** Build `3 -> 6 -> 9` and verify `Length` returns `3` and `Sum` returns `18`.

## Exercise 4: Search for a Value
**Difficulty:** Basic
**Concepts:** early `return`, reference comparison for `null`, equality with `==`

**Starter code:**
```csharp
static bool Contains(Node head, int target) {
    Node current = head;
    while (current != null) {
        if (current.Value == target) return true;
        current = current.Next;
    }
    return false;
}
```

**Task:** Write `IndexOf(Node head, int target)` returning the 0-based index of the first match, or `-1`.

## Exercise 5: Delete the First Matching Node
**Difficulty:** Basic
**Concepts:** rewiring `Next` references, head-removal special case

**Starter code:**
```csharp
static Node Delete(Node head, int value) {
    if (head == null) return null;
    if (head.Value == value) return head.Next;
    Node current = head;
    while (current.Next != null && current.Next.Value != value) {
        current = current.Next;
    }
    if (current.Next != null) current.Next = current.Next.Next;
    return head;
}
```

**Task:** Test removing the head, a middle node, and a missing value from `10 -> 20 -> 30`.
