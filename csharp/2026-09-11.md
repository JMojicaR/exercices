## Exercise 3: Factorial
- **Difficulty:** Easy
- **Description:** Write a method `Factorial(int n)` that returns n! using recursion and print `Factorial(5)`.
- **Concepts:** methods, recursion, return types
- **Starter code:**
```csharp
using System;

class Program {
    static int Factorial(int n) {
        if (n == 0) return 1;
        return n * Factorial(n - 1);
    }

    static void Main() {
        Console.WriteLine(Factorial(5)); // 120
    }
}
```
