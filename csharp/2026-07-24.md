## Exercise 1: Number Classification (Positive/Negative/Zero)
**Difficulty:** ⭐ Basic  
**Concepts:** Methods, conditionals, Console I/O, parsing

**Description:** Write a C# program with a method `ClassifyNumber(int num)` that returns a string: "Positive", "Negative", or "Zero". Read numbers from the user in a loop until they enter "exit". Print the classification for each number.

**Starter Code:**
```csharp
using System;

class Program {
    static string ClassifyNumber(int num) {
        // Your code here
    }

    static void Main() {
        Console.WriteLine("Enter numbers (or 'exit' to quit):");
        while (true) {
            string input = Console.ReadLine();
            if (input.ToLower() == "exit") break;

            if (int.TryParse(input, out int number)) {
                Console.WriteLine(ClassifyNumber(number));
            } else {
                Console.WriteLine("Invalid input. Try again.");
            }
        }
    }
}
```

**Expected Learning:** `int.TryParse()`, `if/else if/else`, `while` loops, method return types, `Console.ReadLine()`/`Console.WriteLine()`, nullable/out parameters.
