## Exercise 1: Hello World & Console I/O
**Difficulty:** ★☆☆☆☆  
**Concepts:** Console class, string interpolation, type conversion  

**Description:**  
Write a C# console application that asks the user for their name, age, and favorite color. Display a formatted welcome message using string interpolation.

**Example Starter Code:**
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("=== Welcome to C# ===\n");
        
        Console.Write("Enter your name: ");
        string name = Console.ReadLine();
        
        Console.Write("Enter your age: ");
        int age = Convert.ToInt32(Console.ReadLine());
        
        Console.Write("Enter your favorite color: ");
        string color = Console.ReadLine();
        
        Console.WriteLine($"\nHello, {name}!");
        Console.WriteLine($"You are {age} years old.");
        Console.WriteLine($"Your favorite color is {color}.");
        Console.WriteLine($"You were born around {DateTime.Now.Year - age}.");
    }
}
```

**Expected Output:**
```
=== Welcome to C# ===

Enter your name: Diana
Enter your age: 28
Enter your favorite color: Blue

Hello, Diana!
You are 28 years old.
Your favorite color is Blue.
You were born around 1998.
```

## Exercise 2: LINQ Basics
**Difficulty:** ★★☆☆☆  
**Concepts:** LINQ, collections, lambda expressions, filtering/sorting  

**Description:**  
Create a list of numbers and use LINQ to perform various operations: filter even numbers, square each number, sort, and find the first number greater than a threshold.

**Example Starter Code:**
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    static void Main()
    {
        List<int> numbers = new List<int> { 15, 3, 22, 8, 45, 12, 7, 31, 9, 50 };
        
        Console.WriteLine($"Original: [{string.Join(", ", numbers)}]");
        
        // Filter: even numbers
        var evens = numbers.Where(n => n % 2 == 0);
        Console.WriteLine($"Evens: [{string.Join(", ", evens)}]");
        
        // Transform: square each number
        var squares = numbers.Select(n => n * n);
        Console.WriteLine($"Squares: [{string.Join(", ", squares)}]");
        
        // Filter + Sort: odd numbers, descending
        var oddDescending = numbers.Where(n => n % 2 != 0).OrderByDescending(n => n);
        Console.WriteLine($"Odd (desc): [{string.Join(", ", oddDescending)}]");
        
        // Aggregate: sum, average, min, max
        Console.WriteLine($"Sum: {numbers.Sum()}");
        Console.WriteLine($"Average: {numbers.Average():F2}");
        Console.WriteLine($"Min: {numbers.Min()}");
        Console.WriteLine($"Max: {numbers.Max()}");
        
        // First greater than 30
        var firstOver30 = numbers.First(n => n > 30);
        Console.WriteLine($"First > 30: {firstOver30}");
    }
}
```

## Exercise 3: Simple Class & Properties
**Difficulty:** ★★★☆☆  
**Concepts:** Classes, auto-properties, constructors, ToString override  

**Description:**  
Create a `Book` class with properties: Title, Author, Pages, and Price. Include a constructor, auto-properties, a method to display book info, and override `ToString()`.

**Example Starter Code:**
```csharp
using System;

class Book
{
    public string Title { get; set; }
    public string Author { get; set; }
    public int Pages { get; set; }
    public decimal Price { get; set; }
    
    public Book(string title, string author, int pages, decimal price)
    {
        Title = title;
        Author = author;
        Pages = pages;
        Price = price;
    }
    
    public decimal PricePerPage()
    {
        return Price / Pages;
    }
    
    public override string ToString()
    {
        return $"\"{Title}\" by {Author} | {Pages} pages | ${Price:F2}";
    }
}

class Program
{
    static void Main()
    {
        Book[] books = {
            new Book("1984", "George Orwell", 328, 9.99m),
            new Book("Dune", "Frank Herbert", 412, 14.99m),
            new Book("Neuromancer", "William Gibson", 271, 8.99m)
        };
        
        Console.WriteLine("=== Book Collection ===\n");
        
        foreach (var book in books)
        {
            Console.WriteLine(book);
            Console.WriteLine($"  Price per page: ${book.PricePerPage():F3}\n");
        }
    }
}
```

## Exercise 4: List Operations
**Difficulty:** ★★☆☆☆  
**Concepts:** Generic List<T>, methods, foreach, Sort  

**Description:**  
Create a program that manages a shopping list. Users can add items, remove items, display the list, and sort alphabetically. Use a menu-driven interface.

**Example Starter Code:**
```csharp
using System;
using System.Collections.Generic;

class Program
{
    static List<string> shoppingList = new List<string>();
    
    static void DisplayList()
    {
        if (shoppingList.Count == 0)
        {
            Console.WriteLine("Shopping list is empty!");
            return;
        }
        
        Console.WriteLine("\n--- Shopping List ---");
        for (int i = 0; i < shoppingList.Count; i++)
        {
            Console.WriteLine($"  {i + 1}. {shoppingList[i]}");
        }
        Console.WriteLine($"Total items: {shoppingList.Count}\n");
    }
    
    static void Main()
    {
        // Pre-populate with some items
        shoppingList.AddRange(new[] { "Milk", "Bread", "Eggs" });
        
        bool running = true;
        while (running)
        {
            Console.WriteLine("=== Shopping List Manager ===");
            Console.WriteLine("1. Display list");
            Console.WriteLine("2. Add item");
            Console.WriteLine("3. Remove item");
            Console.WriteLine("4. Sort list");
            Console.WriteLine("5. Exit");
            Console.Write("Choose an option: ");
            
            string choice = Console.ReadLine();
            
            switch (choice)
            {
                case "1":
                    DisplayList();
                    break;
                case "2":
                    Console.Write("Enter item to add: ");
                    shoppingList.Add(Console.ReadLine());
                    Console.WriteLine("Item added!\n");
                    break;
                case "3":
                    Console.Write("Enter item to remove: ");
                    string item = Console.ReadLine();
                    if (shoppingList.Remove(item))
                        Console.WriteLine("Item removed!\n");
                    else
                        Console.WriteLine("Item not found!\n");
                    break;
                case "4":
                    shoppingList.Sort();
                    Console.WriteLine("List sorted!\n");
                    break;
                case "5":
                    running = false;
                    break;
                default:
                    Console.WriteLine("Invalid option!\n");
                    break;
            }
        }
    }
}
```

## Exercise 5: Exception Handling
**Difficulty:** ★★★☆☆  
**Concepts:** try-catch-finally, custom exceptions, input validation  

**Description:**  
Write a program that safely converts user input to an integer. Handle `FormatException`, `OverflowException`, and demonstrate the `finally` block. Create a reusable `SafeReadInt` method.

**Example Starter Code:**
```csharp
using System;

class Program
{
    static int SafeReadInt(string prompt, int min = int.MinValue, int max = int.MaxValue)
    {
        while (true)
        {
            try
            {
                Console.Write(prompt);
                string input = Console.ReadLine();
                
                if (string.IsNullOrWhiteSpace(input))
                {
                    throw new ArgumentException("Input cannot be empty!");
                }
                
                int value = int.Parse(input);
                
                if (value < min || value > max)
                {
                    throw new ArgumentOutOfRangeException(
                        $"Value must be between {min} and {max}!");
                }
                
                return value;
            }
            catch (FormatException)
            {
                Console.WriteLine("Error: Please enter a valid integer.");
            }
            catch (OverflowException)
            {
                Console.WriteLine($"Error: Number is too large or too small.");
            }
            catch (ArgumentException ex)
            {
                Console.WriteLine($"Error: {ex.Message}");
            }
        }
    }
    
    static void Main()
    {
        Console.WriteLine("=== Safe Number Input ===\n");
        
        int age = SafeReadInt("Enter your age (0-150): ", 0, 150);
        Console.WriteLine($"Age accepted: {age}");
        
        int score = SafeReadInt("Enter test score (0-100): ", 0, 100);
        Console.WriteLine($"Score accepted: {score}");
        
        // Demonstrate division with exception handling
        Console.WriteLine("\n=== Division Calculator ===");
        int a = SafeReadInt("Enter dividend: ");
        int b = SafeReadInt("Enter divisor: ");
        
        try
        {
            int result = a / b;
            Console.WriteLine($"{a} / {b} = {result}");
        }
        catch (DivideByZeroException)
        {
            Console.WriteLine("Error: Cannot divide by zero!");
        }
        finally
        {
            Console.WriteLine("Calculation attempt completed.");
        }
    }
}
```
