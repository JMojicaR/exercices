## Exercise 1: Hello World and User Input

**Title:** Hello, C#! — Console Output and Input

**Description:** Write a C# console application that prints "Hello, World!" and then prompts the user for their name and age. Print a greeting with the year they were born. Use `Console.WriteLine()` and `Console.ReadLine()`.

**Difficulty:** ★☆☆☆☆ (Very Easy)

**Concepts Practiced:**
- `using System;`
- `class` and `Main` method
- `Console.WriteLine()`
- `Console.ReadLine()`
- `int.Parse()` or `Convert.ToInt32()`
- String interpolation (`$""`)

**Starter Code:**
```csharp
// Exercise 1: Hello, C#!
using System;

class Program {
    static void Main() {
        Console.WriteLine("Hello, World!");

        Console.Write("Enter your name: ");
        string name = Console.ReadLine();

        Console.Write("Enter your age: ");
        int age = int.Parse(Console.ReadLine());

        int birthYear = 2026 - age;
        Console.WriteLine($"Welcome, {name}! You were born around {birthYear}.");
    }
}
```

## Exercise 2: Temperature Converter

**Title:** Celsius ↔ Fahrenheit Converter

**Description:** Write a C# program with two methods: one to convert Celsius to Fahrenheit and another to convert Fahrenheit to Celsius. Let the user choose the conversion direction and input the temperature.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Static methods
- Parameters and return values
- `double` data type
- Conditional logic (`if`/`else`)
- User menu interaction

**Starter Code:**
```csharp
// Exercise 2: Temperature Converter
using System;

class Program {
    static double CelsiusToFahrenheit(double c) {
        return (c * 9 / 5) + 32;
    }

    static double FahrenheitToCelsius(double f) {
        return (f - 32) * 5 / 9;
    }

    static void Main() {
        Console.WriteLine("Temperature Converter");
        Console.WriteLine("1. Celsius to Fahrenheit");
        Console.WriteLine("2. Fahrenheit to Celsius");
        Console.Write("Choose (1 or 2): ");
        int choice = int.Parse(Console.ReadLine());

        if (choice == 1) {
            Console.Write("Enter Celsius: ");
            double c = double.Parse(Console.ReadLine());
            Console.WriteLine($"{c}°C = {CelsiusToFahrenheit(c):F2}°F");
        } else if (choice == 2) {
            Console.Write("Enter Fahrenheit: ");
            double f = double.Parse(Console.ReadLine());
            Console.WriteLine($"{f}°F = {FahrenheitToCelsius(f):F2}°C");
        } else {
            Console.WriteLine("Invalid choice.");
        }
    }
}
```

## Exercise 3: Guess the Number Game

**Title:** Number Guessing Game

**Description:** Write a C# program that generates a random number between 1 and 100. The user tries to guess it. After each guess, the program tells the user if the guess is too high, too low, or correct. Track the number of attempts.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- `Random` class
- `while` loop
- Conditional statements
- Integer comparison
- Counter variables

**Starter Code:**
```csharp
// Exercise 3: Guess the Number
using System;

class Program {
    static void Main() {
        Random rand = new Random();
        int secretNumber = rand.Next(1, 101);
        int guess = 0;
        int attempts = 0;

        Console.WriteLine("I'm thinking of a number between 1 and 100.");

        while (guess != secretNumber) {
            Console.Write("Your guess: ");
            guess = int.Parse(Console.ReadLine());
            attempts++;

            if (guess < secretNumber)
                Console.WriteLine("Too low! Try again.");
            else if (guess > secretNumber)
                Console.WriteLine("Too high! Try again.");
        }

        Console.WriteLine($"Correct! You got it in {attempts} attempts.");
    }
}
```

## Exercise 4: String Reversal

**Title:** Reverse a String (Multiple Approaches)

**Description:** Write a C# program that takes a string from the user and reverses it. Implement it in two ways: using a `for` loop (manual reversal) and using `Array.Reverse()`. Compare the output.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- String manipulation
- `char[]` arrays
- `for` loops
- `Array.Reverse()`
- `StringBuilder` (optional)

**Starter Code:**
```csharp
// Exercise 4: String Reversal
using System;

class Program {
    static string ReverseManual(string input) {
        char[] chars = input.ToCharArray();
        Array.Reverse(chars);
        return new string(chars);
    }

    static string ReverseLoop(string input) {
        char[] chars = new char[input.Length];
        for (int i = 0; i < input.Length; i++) {
            chars[i] = input[input.Length - 1 - i];
        }
        return new string(chars);
    }

    static void Main() {
        Console.Write("Enter a string: ");
        string input = Console.ReadLine();

        Console.WriteLine($"Reversed (Array.Reverse): {ReverseManual(input)}");
        Console.WriteLine($"Reversed (loop): {ReverseLoop(input)}");
    }
}
```

## Exercise 5: Student Grade Calculator

**Title:** Student Grades — Arrays and Averages

**Description:** Write a C# program that stores student names and their grades in arrays. Calculate and display each student's average grade, the class average, and the highest/lowest scoring students.

**Difficulty:** ★★★☆☆ (Moderate)

**Concepts Practiced:**
- Arrays
- `for` and `foreach` loops
- Arithmetic and averages
- Finding max/min in arrays
- String formatting

**Starter Code:**
```csharp
// Exercise 5: Student Grade Calculator
using System;

class Program {
    static void Main() {
        string[] students = { "Alice", "Bob", "Charlie", "Diana", "Eve" };
        int[,] grades = {
            { 85, 90, 78 },
            { 72, 88, 91 },
            { 95, 87, 82 },
            { 68, 75, 80 },
            { 90, 92, 88 }
        };

        double classTotal = 0;
        int numGrades = 0;
        double highestAvg = 0, lowestAvg = 100;
        string topStudent = "", bottomStudent = "";

        for (int i = 0; i < students.Length; i++) {
            int studentTotal = 0;
            for (int j = 0; j < grades.GetLength(1); j++) {
                studentTotal += grades[i, j];
            }
            double avg = (double)studentTotal / grades.GetLength(1);
            Console.WriteLine($"{students[i]} - Average: {avg:F1}");

            classTotal += studentTotal;
            numGrades += grades.GetLength(1);

            if (avg > highestAvg) { highestAvg = avg; topStudent = students[i]; }
            if (avg < lowestAvg) { lowestAvg = avg; bottomStudent = students[i]; }
        }

        Console.WriteLine($"\nClass Average: {classTotal / numGrades:F1}");
        Console.WriteLine($"Top Student: {topStudent} ({highestAvg:F1})");
        Console.WriteLine($"Lowest Student: {bottomStudent} ({lowestAvg:F1})");
    }
}
```
