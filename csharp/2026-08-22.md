## Exercise 1: Check Leap Year

**Difficulty:** Basic

### Problem
Write a method that checks whether a given year is a leap year using the standard rules (divisible by 400 is leap, divisible by 100 is not, divisible by 4 is leap). Print the result for a sample year.

**Given Input:** `IsLeapYear(2024)`

**Expected Output:**
```
2024 is a leap year.
```

### Concepts
- Static methods
- Modulo operator (`%`)
- Conditional expressions (ternary operator)
- Boolean return values

### Example / Starter Code

```csharp
using System;

class LeapYear
{
    static bool IsLeapYear(int year)
    {
        if (year % 400 == 0) return true;
        if (year % 100 == 0) return false;
        if (year % 4 == 0) return true;
        return false;
    }

    static void Main()
    {
        int year = 2024;
        Console.WriteLine(IsLeapYear(year)
            ? $"{year} is a leap year."
            : $"{year} is not a leap year.");
    }
}
```

## Exercise 2: GCD of Two Numbers

**Difficulty:** Basic

### Problem
Write a method that computes the greatest common divisor (GCD) of two positive integers using the Euclidean algorithm. Print the GCD of a sample pair.

**Given Input:** `Gcd(48, 18)`

**Expected Output:**
```
GCD of 48 and 18 is 6
```

### Concepts
- `while` loops
- Euclidean algorithm
- String interpolation (`$"..."`)
- Method parameters and return values

### Example / Starter Code

```csharp
using System;

class GCD
{
    static int Gcd(int a, int b)
    {
        while (b != 0)
        {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }

    static void Main()
    {
        int a = 48, b = 18;
        Console.WriteLine($"GCD of {a} and {b} is {Gcd(a, b)}");
    }
}
```

## Exercise 3: Count Digits in an Integer

**Difficulty:** Basic

### Problem
Write a method that counts how many digits are in a given integer (ignoring the sign). Print the digit count for a sample number.

**Given Input:** `CountDigits(12345)`

**Expected Output:**
```
12345 has 5 digits.
```

### Concepts
- `do`/`while` loops
- `Math.Abs` for absolute value
- Integer division
- Counting with an accumulator

### Example / Starter Code

```csharp
using System;

class CountDigits
{
    static int CountDigits(int number)
    {
        int count = 0;
        int n = Math.Abs(number);
        do
        {
            count++;
            n /= 10;
        } while (n > 0);
        return count;
    }

    static void Main()
    {
        int number = 12345;
        Console.WriteLine($"{number} has {CountDigits(number)} digits.");
    }
}
```

## Exercise 4: Area of a Circle

**Difficulty:** Basic

### Problem
Write a program that calculates and prints the area of a circle given its radius using the formula `area = π * r²`.

**Given Input:** `radius = 5.0`

**Expected Output:**
```
Area of a circle with radius 5 is 78.54
```

### Concepts
- `Math.PI` constant
- Floating-point arithmetic (`double`)
- Formatting output with `:F2`
- Exponentiation via multiplication

### Example / Starter Code

```csharp
using System;

class CircleArea
{
    static void Main()
    {
        double radius = 5.0;
        double area = Math.PI * radius * radius;
        Console.WriteLine($"Area of a circle with radius {radius} is {area:F2}");
    }
}
```

## Exercise 5: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that prints the multiplication table of a given number from 1 to 10 using a loop.

**Given Input:** `n = 5`

**Expected Output:**
```
Multiplication table of 5:
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

### Concepts
- `for` loops
- Arithmetic operations
- String interpolation with `Console.WriteLine`

### Example / Starter Code

```csharp
using System;

class MultiplicationTable
{
    static void Main()
    {
        int n = 5;
        Console.WriteLine($"Multiplication table of {n}:");
        for (int i = 1; i <= 10; i++)
        {
            Console.WriteLine($"{n} x {i} = {n * i}");
        }
    }
}
```
