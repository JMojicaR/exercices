## Exercise 1: Create a Dictionary & Add/Access
**Difficulty:** Basic
**Concepts:** `Dictionary<K, V>`, indexer `dict[key]`, `Add()`, `ContainsKey`, `TryGetValue`

Store and retrieve student grades by name.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        var grades = new Dictionary<string, int>
        {
            { "Alice", 85 },
            { "Bob", 72 },
            { "Carol", 90 }
        };

        Console.WriteLine(grades["Alice"]);   // 85

        grades["Dave"] = 78;                  // add
        grades["Bob"] = 75;                   // update

        if (grades.TryGetValue("Eve", out int eveGrade))
            Console.WriteLine($"Eve: {eveGrade}");
        else
            Console.WriteLine("Eve not found");
    }
}
```

**Task:** Use `grades.Add("Alice", 99)` inside a `try` block to observe the `ArgumentException` thrown when adding a duplicate key.

## Exercise 2: Count Word Frequencies
**Difficulty:** Basic
**Concepts:** `string.Split`, `TryGetValue`, incrementing counts

Count how many times each word appears in a sentence.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        string sentence = "the cat and the dog and the bird";
        var counts = new Dictionary<string, int>();

        foreach (string word in sentence.Split(' '))
        {
            if (counts.TryGetValue(word, out int current))
                counts[word] = current + 1;
            else
                counts[word] = 1;
        }

        foreach (var pair in counts)
            Console.WriteLine($"{pair.Key}: {pair.Value}");
    }
}
```

**Task:** Make the count case-insensitive by converting each word to lowercase with `word.ToLower()` before counting.

## Exercise 3: Iterate Key-Value Pairs
**Difficulty:** Basic
**Concepts:** `KeyValuePair<K, V>`, iterating `.Keys` and `.Values`, `foreach`

Print every country and its capital, then list only the capitals.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        var capitals = new Dictionary<string, string>
        {
            { "Mexico", "Mexico City" },
            { "France", "Paris" },
            { "Japan", "Tokyo" }
        };

        foreach (KeyValuePair<string, string> pair in capitals)
            Console.WriteLine($"{pair.Key} -> {pair.Value}");

        Console.WriteLine("Capitals:");
        foreach (string capital in capitals.Values)
            Console.WriteLine(capital);
    }
}
```

**Task:** Print the entries sorted by key by copying `capitals.Keys` into a `List<string>` and calling `.Sort()`.

## Exercise 4: ContainsKey & Remove
**Difficulty:** Basic
**Concepts:** `ContainsKey`, `Remove`, `Count`, `Clear`

Manage an inventory and safely remove an item.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        var stock = new Dictionary<string, int>
        {
            { "apples", 10 }, { "bananas", 5 }, { "cherries", 20 }
        };

        if (stock.ContainsKey("bananas"))
            stock.Remove("bananas");

        Console.WriteLine($"Has bananas? {stock.ContainsKey("bananas")}");
        Console.WriteLine($"Total items: {stock.Count}");
    }
}
```

**Task:** Capture the removed value with `int removed = stock["bananas"];` before calling `Remove`, and print it.

## Exercise 5: Find the Key with the Maximum Value
**Difficulty:** Basic
**Concepts:** LINQ `OrderByDescending`/`First`, or a manual loop, `KeyValuePair`

Find the student with the highest grade.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    static void Main()
    {
        var grades = new Dictionary<string, int>
        {
            { "Alice", 85 }, { "Bob", 72 }, { "Carol", 90 }, { "Dave", 78 }
        };

        var best = grades.OrderByDescending(pair => pair.Value).First();
        Console.WriteLine($"{best.Key} has the highest grade: {best.Value}");
        // Carol has the highest grade: 90
    }
}
```

**Task:** Reimplement the search with a manual loop (tracking the current max) so it works without LINQ, and handle the empty-dictionary case with `if (grades.Count == 0)`.
