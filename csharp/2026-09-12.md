## Exercise 1: Simple Calculator
- **Difficulty:** Easy
- **Description:** Read two numbers and an operator from the console and print the result using a `switch` statement. Handle division by zero.
- **Concepts:** `Console.ReadLine()`, `Convert.ToDouble()`, `switch`, arithmetic
- **Starter code:**
```csharp
using System;

class Calculator {
    static void Main() {
        Console.Write("Enter a: ");
        double a = Convert.ToDouble(Console.ReadLine());
        Console.Write("Enter operator (+, -, *, /): ");
        char op = Console.ReadLine()[0];
        Console.Write("Enter b: ");
        double b = Convert.ToDouble(Console.ReadLine());

        switch (op) {
            case '+': Console.WriteLine(a + b); break;

            default: Console.WriteLine("Unknown operator"); break;
```
