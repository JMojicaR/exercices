## Exercise 1: Even or Odd
**Difficulty:** Basic
**Concepts:** `Console.ReadLine`, `int.Parse`, conditionals, modulo operator.

Write a console program that reads an integer and prints whether it is even or odd.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());

        if (n % 2 == 0) {
            Console.WriteLine($"{n} is even");
        } else {
            Console.WriteLine($"{n} is odd");
        }
    }
}
```

**Task:** Also report whether the number is positive, negative, or zero.

## Exercise 2: Reverse a String
**Difficulty:** Basic
**Concepts:** Strings, `ToCharArray`, loops, `string.Join`, `Reverse`.

Write a program that reverses a string entered by the user.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        Console.Write("Enter a string: ");
        string input = Console.ReadLine();

        char[] chars = input.ToCharArray();
        Array.Reverse(chars);
        string reversed = new string(chars);

        Console.WriteLine("Reversed: " + reversed);
    }
}
```

**Task:** Write a manual reversal using a `for` loop instead of `Array.Reverse`.

## Exercise 3: Array Sum and Average
**Difficulty:** Basic
**Concepts:** Arrays, `for`/`foreach` loops, accumulation, casting.

Write a program that computes the sum and average of an integer array.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int[] numbers = { 15, 22, 8, 41, 33, 6 };
        int sum = 0;

        foreach (int n in numbers) {
            sum += n;
        }

        double average = (double)sum / numbers.Length;
        Console.WriteLine("Sum = " + sum);
        Console.WriteLine("Average = " + average);
    }
}
```

**Task:** Also find and print the maximum value in the array.

## Exercise 4: Factorial
**Difficulty:** Basic
**Concepts:** Methods, loops, `long`, return values.

Write a program with a method that returns the factorial of a number.

**Starter code:**
```csharp
using System;

class Program {
    static long Factorial(int n) {
        long result = 1;
        for (int i = 1; i <= n; i++) {
            result *= i;
        }
        return result;
    }

    static void Main() {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());
        Console.WriteLine($"{n}! = {Factorial(n)}");
    }
}
```

**Task:** Write a recursive version and compare results for n = 0 to 20.

## Exercise 5: Check Prime Number
**Difficulty:** Basic
**Concepts:** Loops, `Math.Sqrt`, boolean flags, methods.

Write a program that checks whether a number is prime.

**Starter code:**
```csharp
using System;

class Program {
    static bool IsPrime(int n) {
        if (n < 2) return false;
        for (int i = 2; i <= Math.Sqrt(n); i++) {
            if (n % i == 0) return false;
        }
        return true;
    }

    static void Main() {
        Console.Write("Enter a number: ");
        int n = int.Parse(Console.ReadLine());
        Console.WriteLine(n + (IsPrime(n) ? " is prime" : " is not prime"));
    }
}
```

**Task:** Print all prime numbers between 1 and 100.
