## Exercise 1: Write Text to a File
**Difficulty:** Basic
**Concepts:** `File.WriteAllText`, `File.WriteAllLines`, namespaces, `Main`

Write a program that creates a file named `notes.txt` and writes two lines into it. `File.WriteAllText` creates the file if it doesn't exist and overwrites it if it does.

**Starter code:**
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        File.WriteAllText("notes.txt", "First line\nSecond line\n");
        Console.WriteLine("File written.");
    }
}
```

**Task:** Write the same content with `File.WriteAllLines("notes.txt", new[] { "First line", "Second line" })` and observe how it joins lines with newlines automatically.

## Exercise 4: Count Lines and Words
**Difficulty:** Basic
**Concepts:** `File.ReadAllLines`, `String.Split`, `String.IsNullOrWhiteSpace`, `Length`

Write a program that opens `notes.txt` and reports the number of lines and the total number of words it contains.

**Starter code:**
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string[] lines = File.ReadAllLines("notes.txt");
        int wordCount = 0;
        foreach (string line in lines)
        {
            if (!string.IsNullOrWhiteSpace(line))
            {
                wordCount += line.Split(new[] { ' ' }, StringSplitOptions.RemoveEmptyEntries).Length;
            }
        }
        Console.WriteLine($"Lines: {lines.Length}");
        Console.WriteLine($"Words: {wordCount}");
    }
}
```

**Task:** Also count characters with `line.Length` and print the longest line's length. Then count how many lines contain "the" (case-insensitive) using `line.IndexOf("the", StringComparison.OrdinalIgnoreCase)`.

## Exercise 5: Copy a File
**Difficulty:** Basic
**Concepts:** `File.Copy`, `File.Exists`, exception handling

Write a program that copies `notes.txt` into a new file named `notes_copy.txt`, warning the user if the destination already exists.

**Starter code:**
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string source = "notes.txt";
        string target = "notes_copy.txt";

        if (File.Exists(target))
        {
            Console.WriteLine("Destination already exists. Overwriting...");
        }
        File.Copy(source, target, overwrite: true);
        Console.WriteLine("Copied.");
    }
}
```

**Task:** Wrap the copy in a `try/catch` for `IOException` and `UnauthorizedAccessException`, and print a friendly message for each. Then verify the copy by reading `notes_copy.txt` and printing it.
