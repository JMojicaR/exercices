## Exercise 1: Fibonacci Series
**Difficulty:** Basic
**Concepts:** Loops, Arrays, Arithmetic

Generate the first `n` Fibonacci numbers and store them in an array before printing them.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int n = 10;
        int[] fib = new int[n];
        fib[0] = 0;
        fib[1] = 1;

        for (int i = 2; i < n; i++) {
            fib[i] = fib[i - 1] + fib[i - 2];
        }

        for (int i = 0; i < n; i++) {
            Console.Write(fib[i] + " ");
        }
        Console.WriteLine();
    }
}
```

**Task:** Ask the user how many terms to generate and print the sum of all the generated terms.

## Exercise 2: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** Variables, Temporary Variable, Console Input

Read two integers and exchange their values so that the first variable holds the second's original value and vice versa.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int x = 5, y = 10;
        Console.WriteLine($"Before swap: x = {x}, y = {y}");

        int temp = x;
        x = y;
        y = temp;

        Console.WriteLine($"After swap: x = {x}, y = {y}");
    }
}
```

**Task:** Swap the two numbers without a temporary variable and let the user enter both values.

## Exercise 3: Sum of Digits
**Difficulty:** Basic
**Concepts:** Loops, Modulo, Integer Division

Compute the sum of the individual digits of a positive integer (e.g. 1234 gives 1 + 2 + 3 + 4 = 10).

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int num = 1234;
        int sum = 0;

        while (num != 0) {
            sum += num % 10;
            num /= 10;
        }

        Console.WriteLine("Sum of digits = " + sum);
    }
}
```

**Task:** Read the number from the user and also print each digit on its own line.

## Exercise 4: Leap Year Check
**Difficulty:** Basic
**Concepts:** Conditionals, Modulo, Logical Operators

Determine whether a given year is a leap year. A year is a leap year if it is divisible by 4, but century years must also be divisible by 400.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        int year = 2026;

        if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
            Console.WriteLine(year + " is a leap year.");
        } else {
            Console.WriteLine(year + " is not a leap year.");
        }
    }
}
```

**Task:** Read the year from the user and print all leap years between 2000 and the entered year.

## Exercise 5: Simple Calculator (switch)
**Difficulty:** Basic
**Concepts:** switch Statement, Arithmetic, Console Input

Read two numbers and an operator (+, -, *, /) and perform the matching operation using a `switch` statement.

**Starter code:**
```csharp
using System;

class Program {
    static void Main() {
        double a = 12, b = 5;
        char op = '+';

        switch (op) {
            case '+':
                Console.WriteLine(a + " + " + b + " = " + (a + b));
                break;
            case '-':
                Console.WriteLine(a + " - " + b + " = " + (a - b));
                break;
            case '*':
                Console.WriteLine(a + " * " + b + " = " + (a * b));
                break;
            case '/':
                Console.WriteLine(a + " / " + b + " = " + (a / b));
                break;
            default:
                Console.WriteLine("Invalid operator");
                break;
        }
    }
}
```

**Task:** Read the numbers and operator from the user, and guard against division by zero by printing an error message instead.
