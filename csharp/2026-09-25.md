## Exercise 1: Hello, World!
**Difficulty:** Basic
**Concepts:** Namespaces, `Main`, `Console.WriteLine`.

Write the classic "Hello, World!" program.

**Starter code:**
```csharp
using System;

class HelloWorld {
    static void Main() {
        Console.WriteLine("Hello, World!");
    }
}
```

**Task:** Print your name and a short message on separate lines.

## Exercise 2: Read Input and Sum
**Difficulty:** Basic
**Concepts:** `Console.ReadLine`, `int.Parse`/`Convert.ToInt32`, arithmetic.

Read two integers and print their sum.

**Starter code:**
```csharp
using System;

class Sum {
    static void Main() {
        Console.Write("Enter first number: ");
        int a = int.Parse(Console.ReadLine());
        Console.Write("Enter second number: ");
        int b = int.Parse(Console.ReadLine());

        Console.WriteLine("Sum: " + (a + b));
    }
}
```

**Task:** Also print the difference, product, and quotient.

## Exercise 3: Even or Odd
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator.

Read an integer and print whether it is even or odd.

**Starter code:**
```csharp
using System;

class EvenOdd {
    static void Main() {
        Console.Write("Enter an integer: ");
        int num = int.Parse(Console.ReadLine());

        if (num % 2 == 0) {
            Console.WriteLine("Even");
        } else {
            Console.WriteLine("Odd");
        }
    }
}
```

**Task:** Add a branch that prints "Zero" when the number is 0.

## Exercise 4: FizzBuzz
**Difficulty:** Basic
**Concepts:** `for` loop, conditionals, string building.

Print numbers 1 to 20, replacing multiples of 3 with "Fizz", multiples of 5 with "Buzz", and multiples of both with "FizzBuzz".

**Starter code:**
```csharp
using System;

class FizzBuzz {
    static void Main() {
        for (int i = 1; i <= 20; i++) {
            if (i % 15 == 0) {
                Console.WriteLine("FizzBuzz");
            } else if (i % 3 == 0) {
                Console.WriteLine("Fizz");
            } else if (i % 5 == 0) {
                Console.WriteLine("Buzz");
            } else {
                Console.WriteLine(i);
            }
        }
    }
}
```

**Task:** Change the loop to run from 1 to 100.

## Exercise 5: Maximum in a List
**Difficulty:** Basic
**Concepts:** `List<int>`, loops, comparison operators.

Find the largest element in a `List<int>`.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

class ListMax {
    static void Main() {
        var numbers = new List<int> { 4, 7, 1, 9, 3, 8 };
        int max = numbers[0];

        foreach (int n in numbers) {
            if (n > max) {
                max = n;
            }
        }

        Console.WriteLine("Max: " + max);
    }
}
```

**Task:** Also compute and print the minimum and the average.
