## Exercise 1: Define a Book Class
**Difficulty:** Basic
**Concepts:** `class`, constructor, auto-implemented properties, `Console.WriteLine`

Create a `Book` class with `Title`, `Author`, and `Year` properties set by a constructor, and print an instance.

**Starter code:**
```csharp
using System;

public class Book
{
    public string Title { get; set; }
    public string Author { get; set; }
    public int Year { get; set; }

    public Book(string title, string author, int year)
    {
        Title = title;
        Author = author;
        Year = year;
    }
}

class Program
{
    static void Main()
    {
        Book book = new Book("1984", "George Orwell", 1949);
        Console.WriteLine($"{book.Title} by {book.Author} ({book.Year})");
    }
}
```

## Exercise 2: Create and Use Multiple Objects
**Difficulty:** Basic
**Concepts:** arrays and `List<T>` of objects, `foreach`, method calls

Create a `Book` class with a `Describe()` method, store three books in a list, and print each.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

public class Book
{
    public string Title { get; set; }
    public string Author { get; set; }
    public int Year { get; set; }

    public Book(string title, string author, int year)
    {
        Title = title;
        Author = author;
        Year = year;
    }

    public string Describe()
    {
        return $"{Title} by {Author} ({Year})";
    }
}

class Program
{
    static void Main()
    {
        List<Book> books = new List<Book>
        {
            new Book("1984", "George Orwell", 1949),
            new Book("Dune", "Frank Herbert", 1965),
            new Book("Neuromancer", "William Gibson", 1984),
        };

        foreach (Book b in books)
        {
            Console.WriteLine(b.Describe());
        }
    }
}
```

**Task:** Add a `Price` property and print the total price of all books using a `foreach` loop.

## Exercise 3: Add Instance Methods
**Difficulty:** Basic
**Concepts:** methods, computing derived values, method calls

Add methods that compute derived values from the object's own properties.

**Starter code:**
```csharp
using System;

public class Book
{
    public string Title { get; set; }
    public string Author { get; set; }
    public int Year { get; set; }
    public double Price { get; set; }

    public Book(string title, string author, int year, double price)
    {
        Title = title;
        Author = author;
        Year = year;
        Price = price;
    }

    public int Age(int currentYear)
    {
        return currentYear - Year;
    }

    public double DiscountedPrice(double percent)
    {
        return Price * (1 - percent / 100.0);
    }
}

class Program
{
    static void Main()
    {
        Book book = new Book("Dune", "Frank Herbert", 1965, 15.99);
        Console.WriteLine($"Age: {book.Age(2026)}");
        Console.WriteLine($"Discounted: {book.DiscountedPrice(20):F2}");
    }
}
```

**Task:** Add a `bool IsClassic(int currentYear)` method returning `true` when the book is 50+ years old, and test it on several books.

## Exercise 4: Encapsulation with Custom Accessors
**Difficulty:** Basic
**Concepts:** backing fields, get/set accessors, validation, data hiding

Protect the `Price` property with a custom setter that rejects negative values.

**Starter code:**
```csharp
using System;

public class Book
{
    private double _price;

    public string Title { get; }

    public Book(string title, double price)
    {
        Title = title;
        Price = price;
    }

    public double Price
    {
        get { return _price; }
        set
        {
            if (value < 0)
            {
                throw new ArgumentException("price cannot be negative");
            }
            _price = value;
        }
    }
}

class Program
{
    static void Main()
    {
        Book book = new Book("1984", 12.50);
        Console.WriteLine($"{book.Title} costs {book.Price}");
        book.Price = 10.00;
        Console.WriteLine($"New price: {book.Price}");
    }
}
```

**Task:** Add a `set` accessor to `Title` (making it no longer read-only), and catch the exception thrown by `book.Price = -1` in a `try/catch`.

## Exercise 5: A Library That Holds Books
**Difficulty:** Basic
**Concepts:** composition, `List<T>`, search methods, `string.Equals`

Build a `Library` class that stores `Book` objects in a `List<Book>` and can add, list, and find them.

**Starter code:**
```csharp
using System;
using System.Collections.Generic;

public class Book
{
    public string Title { get; set; }
    public string Author { get; set; }
    public int Year { get; set; }

    public Book(string title, string author, int year)
    {
        Title = title;
        Author = author;
        Year = year;
    }

    public string Describe()
    {
        return $"{Title} by {Author} ({Year})";
    }
}

public class Library
{
    private List<Book> books = new List<Book>();

    public void Add(Book book)
    {
        books.Add(book);
    }

    public Book Find(string title)
    {
        foreach (Book b in books)
        {
            if (string.Equals(b.Title, title, StringComparison.OrdinalIgnoreCase))
            {
                return b;
            }
        }
        return null;
    }

    public void ListBooks()
    {
        foreach (Book b in books)
        {
            Console.WriteLine(b.Describe());
        }
    }
}

class Program
{
    static void Main()
    {
        Library lib = new Library();
        lib.Add(new Book("Dune", "Frank Herbert", 1965));
        lib.Add(new Book("1984", "George Orwell", 1949));
        lib.ListBooks();

        Book found = lib.Find("dune");
        Console.WriteLine(found != null ? found.Describe() : "Not found");
    }
}
```

**Task:** Add a `Count` property (get-only) and a `List<Book> BooksByYear(int year)` method.
