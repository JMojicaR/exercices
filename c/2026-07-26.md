## Exercise 1: Hello World & Basic I/O
**Difficulty:** ★☆☆☆☆  
**Concepts:** printf, scanf, data types, format specifiers  

**Description:**  
Write a C program that reads a student's name and their scores in three subjects, calculates the total and average, and prints a formatted report card.

**Example Starter Code:**
```c
#include <stdio.h>

int main() {
    char name[50];
    float math, science, english;
    
    printf("=== Student Report Card ===\n");
    printf("Enter student name: ");
    fgets(name, sizeof(name), stdin);
    // Remove trailing newline from fgets
    name[strcspn(name, "\n")] = '\0';
    
    printf("Enter Math score: ");
    scanf("%f", &math);
    printf("Enter Science score: ");
    scanf("%f", &science);
    printf("Enter English score: ");
    scanf("%f", &english);
    
    float total = math + science + english;
    float average = total / 3.0;
    
    printf("\n--- Report Card ---\n");
    printf("Name: %s\n", name);
    printf("Math: %.1f\n", math);
    printf("Science: %.1f\n", science);
    printf("English: %.1f\n", english);
    printf("Total: %.1f\n", total);
    printf("Average: %.2f\n", average);
    
    if (average >= 60.0) {
        printf("Status: PASSED\n");
    } else {
        printf("Status: FAILED\n");
    }
    
    return 0;
}
```

## Exercise 2: Calculator with Switch
**Difficulty:** ★★☆☆☆  
**Concepts:** switch statements, functions, arithmetic operators  

**Description:**  
Create a menu-driven calculator using a `switch` statement. Support addition, subtraction, multiplication, division, and modulus operations. Handle division by zero.

**Example Starter Code:**
```c
#include <stdio.h>

int main() {
    char operator;
    double num1, num2, result;
    
    printf("=== Simple Calculator ===\n");
    printf("Enter an operator (+, -, *, /, %%): ");
    scanf(" %c", &operator);
    
    printf("Enter two numbers: ");
    scanf("%lf %lf", &num1, &num2);
    
    switch (operator) {
        case '+':
            result = num1 + num2;
            printf("%.2f + %.2f = %.2f\n", num1, num2, result);
            break;
        case '-':
            result = num1 - num2;
            printf("%.2f - %.2f = %.2f\n", num1, num2, result);
            break;
        case '*':
            result = num1 * num2;
            printf("%.2f * %.2f = %.2f\n", num1, num2, result);
            break;
        case '/':
            if (num2 != 0) {
                result = num1 / num2;
                printf("%.2f / %.2f = %.2f\n", num1, num2, result);
            } else {
                printf("Error: Division by zero!\n");
            }
            break;
        case '%':
            if ((int)num2 != 0) {
                result = (int)num1 % (int)num2;
                printf("%d %% %d = %d\n", 
                       (int)num1, (int)num2, (int)result);
            } else {
                printf("Error: Modulus by zero!\n");
            }
            break;
        default:
            printf("Error: Invalid operator!\n");
    }
    
    return 0;
}
```

## Exercise 3: Array Operations
**Difficulty:** ★★☆☆☆  
**Concepts:** Arrays, loops, functions  

**Description:**  
Write a program that fills an array with user input, then finds the sum, average, minimum, and maximum. Implement each operation as a separate function.

**Example Starter Code:**
```c
#include <stdio.h>

#define SIZE 10

int sumArray(int arr[], int size) {
    int sum = 0;
    for (int i = 0; i < size; i++) {
        sum += arr[i];
    }
    return sum;
}

int findMin(int arr[], int size) {
    int min = arr[0];
    for (int i = 1; i < size; i++) {
        if (arr[i] < min) min = arr[i];
    }
    return min;
}

int findMax(int arr[], int size) {
    int max = arr[0];
    for (int i = 1; i < size; i++) {
        if (arr[i] > max) max = arr[i];
    }
    return max;
}

int main() {
    int numbers[SIZE];
    
    printf("Enter %d integers:\n", SIZE);
    for (int i = 0; i < SIZE; i++) {
        printf("Number %d: ", i + 1);
        scanf("%d", &numbers[i]);
    }
    
    int sum = sumArray(numbers, SIZE);
    float avg = (float)sum / SIZE;
    
    printf("\n--- Results ---\n");
    printf("Array: [");
    for (int i = 0; i < SIZE; i++) {
        printf("%d", numbers[i]);
        if (i < SIZE - 1) printf(", ");
    }
    printf("]\n");
    printf("Sum: %d\n", sum);
    printf("Average: %.2f\n", avg);
    printf("Minimum: %d\n", findMin(numbers, SIZE));
    printf("Maximum: %d\n", findMax(numbers, SIZE));
    
    return 0;
}
```

## Exercise 4: String Palindrome
**Difficulty:** ★★★☆☆  
**Concepts:** Strings, character arrays, string.h functions, loops  

**Description:**  
Write a program that checks if a string is a palindrome. Use character arrays and string functions from `<string.h>`. Ignore case, spaces, and punctuation for the check.

**Example Starter Code:**
```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int isPalindrome(char str[]) {
    int left = 0;
    int right = strlen(str) - 1;
    
    while (left < right) {
        // Skip non-alphanumeric characters on the left
        while (left < right && !isalnum(str[left])) {
            left++;
        }
        // Skip non-alphanumeric characters on the right
        while (left < right && !isalnum(str[right])) {
            right--;
        }
        
        // Compare characters (case-insensitive)
        if (tolower(str[left]) != tolower(str[right])) {
            return 0;  // Not a palindrome
        }
        
        left++;
        right--;
    }
    
    return 1;  // Is a palindrome
}

int main() {
    char input[100];
    
    printf("Enter a string: ");
    fgets(input, sizeof(input), stdin);
    input[strcspn(input, "\n")] = '\0';  // Remove newline
    
    if (isPalindrome(input)) {
        printf("\"%s\" IS a palindrome!\n", input);
    } else {
        printf("\"%s\" is NOT a palindrome.\n", input);
    }
    
    // Test more examples
    char *tests[] = {
        "racecar",
        "A man a plan a canal Panama",
        "hello",
        "Madam"
    };
    
    printf("\n--- More Tests ---\n");
    for (int i = 0; i < 4; i++) {
        printf("\"%s\" -> %s\n", tests[i],
               isPalindrome(tests[i]) ? "Palindrome" : "Not palindrome");
    }
    
    return 0;
}
```

## Exercise 5: Number Guessing Game
**Difficulty:** ★★★☆☆  
**Concepts:** Random numbers, loops, conditionals, do-while  

**Description:**  
Write a number guessing game. The program generates a random number between 1 and 100. The user tries to guess it, and the program provides "too high" or "too low" hints. Track the number of attempts and display a score message.

**Example Starter Code:**
```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main() {
    int number, guess, attempts = 0;
    
    // Seed the random number generator
    srand(time(NULL));
    number = (rand() % 100) + 1;
    
    printf("=== Number Guessing Game ===\n");
    printf("I'm thinking of a number between 1 and 100.\n\n");
    
    do {
        printf("Enter your guess: ");
        scanf("%d", &guess);
        attempts++;
        
        if (guess < number) {
            printf("Too low! Try again.\n");
        } else if (guess > number) {
            printf("Too high! Try again.\n");
        } else {
            printf("\nCongratulations! You guessed the number %d!\n", number);
            printf("It took you %d attempts.\n", attempts);
            
            if (attempts <= 5) {
                printf("Score: Excellent!\n");
            } else if (attempts <= 10) {
                printf("Score: Good!\n");
            } else {
                printf("Score: Keep practicing!\n");
            }
        }
    } while (guess != number);
    
    return 0;
}
```

**Expected Output (sample):**
```

Enter your guess: 75
Too high! Try again.

Enter your guess: 68
Too high! Try again.
Enter your guess: 65

Congratulations! You guessed the number 65!
It took you 5 attempts.
Score: Excellent!
```
