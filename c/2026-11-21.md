## Exercise 1: Array-Based Stack
**Difficulty:** Basic
**Concepts:** fixed-size array, `top` index, `push`/`pop`, overflow/underflow checks

Implement a stack over a fixed-size array using an integer `top` to track the last element.

**Starter code:**
```c
#include <stdio.h>
#define MAX 100

int stack[MAX];
int top = -1;

void push(int x) {
    if (top == MAX - 1) { printf("Stack overflow\n"); return; }
    stack[++top] = x;
}

int pop() {
    if (top == -1) { printf("Stack underflow\n"); return -1; }
    return stack[top--];
}

int main() {
    push(10); push(20); push(30);
    printf("%d\n", pop());   // 30
    printf("%d\n", pop());   // 20
    printf("%d\n", pop());   // 10
    return 0;
}
```

**Task:** Add a `peek()` function that returns the top element without removing it, and a `is_empty()` function returning `1` when `top == -1`.

## Exercise 2: Array-Based Circular Queue
**Difficulty:** Basic
**Concepts:** `front`/`rear` indices, wrap-around with `%`, FIFO order, empty/full detection

A circular queue reuses array space by wrapping indices with the modulo operator.

**Starter code:**
```c
#include <stdio.h>
#define MAX 5

int queue[MAX];
int front = 0, rear = 0, count = 0;

void enqueue(int x) {
    if (count == MAX) { printf("Queue full\n"); return; }
    queue[rear] = x;
    rear = (rear + 1) % MAX;
    count++;
}

int dequeue() {
    if (count == 0) { printf("Queue empty\n"); return -1; }
    int x = queue[front];
    front = (front + 1) % MAX;
    count--;
    return x;
}

int main() {
    enqueue(1); enqueue(2); enqueue(3);
    printf("%d\n", dequeue());   // 1
    printf("%d\n", dequeue());   // 2
    return 0;
}
```

**Task:** Enqueue 5 numbers to fill the queue, dequeue two, then enqueue two more and print the whole queue to confirm the wrap-around works.

## Exercise 3: Balanced Parentheses Checker
**Difficulty:** Basic
**Concepts:** character stack, matching pairs, early failure on mismatch

Use a stack of characters to check balanced parentheses, brackets, and braces.

**Starter code:**
```c
#include <stdio.h>
#include <string.h>

int is_balanced(const char *s) {
    char stack[100];
    int top = -1;
    for (int i = 0; s[i] != '\0'; i++) {
        char ch = s[i];
        if (ch == '(' || ch == '[' || ch == '{') {
            stack[++top] = ch;
        } else if (ch == ')' || ch == ']' || ch == '}') {
            if (top == -1) return 0;
            char open = stack[top--];
            if ((ch == ')' && open != '(') ||
                (ch == ']' && open != '[') ||
                (ch == '}' && open != '{')) return 0;
        }
    }
    return top == -1;
}

int main() {
    printf("%d\n", is_balanced("(a[b]{c})"));   // 1 (true)
    printf("%d\n", is_balanced("([)]"));        // 0 (false)
    return 0;
}
```

**Task:** Add a test for the string `"((("` and confirm the function returns `0` (unmatched openers remain on the stack).

## Exercise 4: Reverse a String with a Stack
**Difficulty:** Basic
**Concepts:** push characters, pop to rebuild, null-terminated strings

Push every character onto a stack and pop them back to reverse the string.

**Starter code:**
```c
#include <stdio.h>
#include <string.h>

void reverse_string(const char *src, char *dst) {
    char stack[100];
    int top = -1;
    for (int i = 0; src[i] != '\0'; i++) {
        stack[++top] = src[i];
    }
    int i = 0;
    while (top >= 0) {
        dst[i++] = stack[top--];
    }
    dst[i] = '\0';
}

int main() {
    char result[100];
    reverse_string("hello", result);
    printf("%s\n", result);   // "olleh"
    return 0;
}
```

**Task:** Modify the function to skip digits when reversing (e.g., `reverse_string("h1e2l3lo", result)` should produce `"olleh"`), and test it.

## Exercise 5: Linked-List Stack
**Difficulty:** Basic
**Concepts:** `struct` node, dynamic allocation (`malloc`), `free`, `NULL`-terminated list

Build a stack as a singly linked list where each push allocates a new node at the head.

**Starter code:**
```c
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *head = NULL;

void push(int x) {
    struct Node *n = (struct Node *)malloc(sizeof(struct Node));
    n->data = x;
    n->next = head;
    head = n;
}

int pop() {
    if (head == NULL) { printf("Empty\n"); return -1; }
    struct Node *n = head;
    int x = n->data;
    head = n->next;
    free(n);
    return x;
}

int main() {
    push(1); push(2); push(3);
    printf("%d\n", pop());   // 3
    printf("%d\n", pop());   // 2
    return 0;
}
```

**Task:** Add a `peek()` function that returns the head's data without removing the node, and print `peek()` before the first `pop()`.
