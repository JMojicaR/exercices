## Exercise 1: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a C program that reads a non-negative integer and prints its factorial using a `for` loop. Factorial of 0 is 1.

**Given Input:** `5`

**Expected Output:**
```
Factorial of 5 is 120
```

### Concepts
- `scanf`/`printf`
- `for` loop accumulator
- `unsigned long long` for larger results

### Example / Starter Code

```c
#include <stdio.h>

int main(void) {
    int n;
    unsigned long long factorial = 1;

    printf("Enter a number: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++) {
        factorial *= i;
    }

    printf("Factorial of %d is %llu\n", n, factorial);
    return 0;
}
```

## Exercise 2: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a C program that prints the first `n` terms of the Fibonacci sequence (`0, 1, 1, 2, 3, 5, …`).

**Given Input:** `7`

**Expected Output:**
```
0
1
1
2
3
5
8
```

### Concepts
- `for` loop
- Swapping variables with a temporary value
- Formatted output

### Example / Starter Code

```c
#include <stdio.h>

int main(void) {
    int n, a = 0, b = 1;

    printf("How many terms? ");
    scanf("%d", &n);

    for (int i = 0; i < n; i++) {
        printf("%d\n", a);
        int next = a + b;
        a = b;
        b = next;
    }
    return 0;
}
```

## Exercise 3: Palindrome Check

**Difficulty:** Basic

### Problem
Write a C program that reads a string and checks whether it is a palindrome (case-insensitive) by comparing characters from both ends.

**Given Input:** `racecar`

**Expected Output:**
```
racecar is a palindrome
```

### Concepts
- `char` arrays and `strlen()`
- Two-pointer comparison
- `tolower()` from `<ctype.h>`

### Example / Starter Code

```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main(void) {
    char str[100];
    printf("Enter a string: ");
    scanf("%99s", str);

    int len = strlen(str);
    int isPalindrome = 1;

    for (int i = 0; i < len / 2; i++) {
        if (tolower(str[i]) != tolower(str[len - 1 - i])) {
            isPalindrome = 0;
            break;
        }
    }

    if (isPalindrome) {
        printf("%s is a palindrome\n", str);
    } else {
        printf("%s is not a palindrome\n", str);
    }
    return 0;
}
```

## Exercise 4: Prime Number Check

**Difficulty:** Basic

### Problem
Write a C program that reads a positive integer and determines whether it is a prime number.

**Given Input:** `29`

**Expected Output:**
```
29 is a prime number
```

### Concepts
- `for` loop with `break`
- Modulo operator `%`
- `sqrt()` from `<math.h>` (link with `-lm`)

### Example / Starter Code

```c
#include <stdio.h>
#include <math.h>

int main(void) {
    int n, isPrime = 1;

    printf("Enter a number: ");
    scanf("%d", &n);

    if (n <= 1) {
        isPrime = 0;
    } else {
        for (int i = 2; i <= sqrt(n); i++) {
            if (n % i == 0) {
                isPrime = 0;
                break;
            }
        }
    }

    if (isPrime) {
        printf("%d is a prime number\n", n);
    } else {
        printf("%d is not a prime number\n", n);
    }
    return 0;
}
```

## Exercise 5: Sum of Digits

**Difficulty:** Basic

### Problem
Write a C program that reads a positive integer and prints the sum of its digits.

**Given Input:** `12345`

**Expected Output:**
```
Sum of digits: 15
```

### Concepts
- `while` loop
- Modulo `%` and integer division `/`
- Digit extraction

### Example / Starter Code

```c
#include <stdio.h>

int main(void) {
    int n, total = 0;

    printf("Enter a number: ");
    scanf("%d", &n);

    while (n > 0) {
        total += n % 10;
        n /= 10;
    }

    printf("Sum of digits: %d\n", total);
    return 0;
}
```
