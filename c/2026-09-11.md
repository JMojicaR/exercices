## Exercise 1: Hello, World! and Variables
- **Difficulty:** Easy
- **Description:** Print "Hello, World!" and declare variables of type `int`, `float`, and `char`, printing each with `printf` and the correct format specifier.
- **Concepts:** `#include <stdio.h>`, `main()`, `printf`, format specifiers (`%d`, `%f`, `%c`)
- **Starter code:**
```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");

    int age = 36;
    float height = 1.75f;
    char initial = 'A';

    // TODO: print each variable with a label
    return 0;
}
```

- **Concepts:** loops, accumulator, integer multiplication
- **Starter code:**
```c

    int n = 5;
    long long fact = 1;

    // TODO: compute n! with a loop

}
```
