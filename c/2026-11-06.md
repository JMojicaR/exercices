## Exercise 1: Find Maximum & Minimum
**Difficulty:** Basic
**Concepts:** fixed-size array, `sizeof`, `for` loop, comparisons

Find and print the smallest and largest values in an integer array.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int numbers[] = {3, 1, 4, 1, 5, 9, 2};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int min = numbers[0], max = numbers[0];
    for (int i = 1; i < size; i++) {
        if (numbers[i] < min) min = numbers[i];
        if (numbers[i] > max) max = numbers[i];
    }
    printf("min = %d, max = %d\n", min, max); /* min = 1, max = 9 */
    return 0;
}
```

**Task:** Wrap the logic in a `void min_max(int arr[], int size, int *min, int *max)` function that writes the results through pointer parameters.

## Exercise 2: Sum of Elements
**Difficulty:** Basic
**Concepts:** array iteration, accumulator, `sizeof`

Compute and print the sum of all elements in an integer array.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int numbers[] = {1, 2, 3, 4, 5};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int total = 0;
    for (int i = 0; i < size; i++) {
        total += numbers[i];
    }
    printf("sum = %d\n", total); /* sum = 15 */
    return 0;
}
```

**Task:** Extract a `int sum(int arr[], int size)` function, then compute and print the average as a `double` using `total / (double)size`.

## Exercise 3: Reverse an Array
**Difficulty:** Basic
**Concepts:** fixed-size arrays, reverse indexing, `for` loop

Copy the elements of an array into a second array in reverse order and print the result.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int numbers[] = {1, 2, 3, 4};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int reversed[4];
    for (int i = 0; i < size; i++) {
        reversed[i] = numbers[size - 1 - i];
    }
    for (int i = 0; i < size; i++) {
        printf("%d ", reversed[i]);
    }
    printf("\n"); /* 4 3 2 1 */
    return 0;
}
```

**Task:** Reverse the array **in place** using a two-pointer swap (swap `numbers[i]` with `numbers[size - 1 - i]` for `i` up to `size / 2`).

## Exercise 4: Count Occurrences
**Difficulty:** Basic
**Concepts:** `for` loop, equality `==`, counter

Count how many times a target value appears in an integer array.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int numbers[] = {1, 2, 3, 2, 4, 2};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int target = 2, count = 0;
    for (int i = 0; i < size; i++) {
        if (numbers[i] == target) count++;
    }
    printf("count of %d = %d\n", target, count); /* count of 2 = 3 */
    return 0;
}
```

**Task:** Write a `int count(int arr[], int size, int target)` function, then extend it to find the element that appears most often (the mode).

## Exercise 5: Remove Duplicates
**Difficulty:** Basic
**Concepts:** nested loops, temporary array, flag variable

Build a new array containing each value only once, preserving the original order of first appearance.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int numbers[] = {1, 2, 2, 3, 4, 4, 4, 5};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int unique[8];
    int u_size = 0;
    for (int i = 0; i < size; i++) {
        int found = 0;
        for (int j = 0; j < u_size; j++) {
            if (unique[j] == numbers[i]) { found = 1; break; }
        }
        if (!found) unique[u_size++] = numbers[i];
    }
    for (int i = 0; i < u_size; i++) {
        printf("%d ", unique[i]);
    }
    printf("\n"); /* 1 2 3 4 5 */
    return 0;
}
```

**Task:** Modify the program so the array size is read from the user with `scanf` (dynamic via `malloc`), and handle the case of an empty input.
