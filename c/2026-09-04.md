## Exercise 1: Bubble Sort

**Difficulty:** Basic

### Problem
Write a program that sorts an integer array in ascending order using bubble sort.

**Given Input:** `{64, 34, 25, 12, 22, 11, 90}`

**Expected Output:**
```
Sorted: 11 12 22 25 34 64 90
```

### Concepts
- `sizeof` to compute array length
- Nested `for` loops
- Swap with a temporary variable

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int n = sizeof(arr) / sizeof(arr[0]);

    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }

    printf("Sorted: ");
    for (int i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");
    return 0;
}
```

## Exercise 2: Linear Search

**Difficulty:** Basic

### Problem
Write a program with a `linear_search` function that returns the index of a target value in an array, or `-1` if absent.

**Given Input:** array `{10, 23, 45, 70, 11, 15}`, target `70`

**Expected Output:**
```
Found at index 3
```

### Concepts
- Function with array + length parameters
- `for` loop
- `-1` sentinel return

### Example / Starter Code

```c
#include <stdio.h>

int linear_search(int arr[], int n, int target) {
    for (int i = 0; i < n; i++)
        if (arr[i] == target) return i;
    return -1;
}

int main() {
    int nums[] = {10, 23, 45, 70, 11, 15};
    int n = sizeof(nums) / sizeof(nums[0]);
    int index = linear_search(nums, n, 70);

    if (index != -1) printf("Found at index %d\n", index);
    else printf("Not found\n");
    return 0;
}
```

## Exercise 3: Anagram Check

**Difficulty:** Basic

### Problem
Write a program that checks whether two strings are anagrams using a character-frequency counting table (ignoring case).

**Given Input:** `"listen"`, `"silent"`

**Expected Output:**
```
Anagram
```

### Concepts
- `strlen()`, `tolower()`
- Frequency array `int count[256]`
- Early length check

### Example / Starter Code

```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int is_anagram(char *s1, char *s2) {
    int count[256] = {0};
    if (strlen(s1) != strlen(s2)) return 0;

    for (int i = 0; s1[i]; i++) {
        count[(unsigned char)tolower(s1[i])]++;
        count[(unsigned char)tolower(s2[i])]--;
    }
    for (int i = 0; i < 256; i++)
        if (count[i] != 0) return 0;
    return 1;
}

int main() {
    printf(is_anagram("listen", "silent") ? "Anagram\n" : "Not an anagram\n");
    return 0;
}
```

## Exercise 4: Greatest Common Divisor (GCD)

**Difficulty:** Basic

### Problem
Write a program that computes the GCD of two positive integers using the Euclidean algorithm.

**Given Input:** `48`, `18`

**Expected Output:**
```
GCD: 6
```

### Concepts
- `while` loop
- Modulo `%`
- Function with return value

### Example / Starter Code

```c
#include <stdio.h>

int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int main() {
    printf("GCD: %d\n", gcd(48, 18));
    return 0;
}
```

## Exercise 5: Armstrong Number Check

**Difficulty:** Basic

### Problem
Write a program that checks whether a number is an Armstrong number (needs `<math.h>` for `pow`).

**Given Input:** `153`

**Expected Output:**
```
Armstrong
```

### Concepts
- Digit counting and extraction with `%` and `/`
- `pow()` from `<math.h>`
- Casting to `int`

### Example / Starter Code

```c
#include <stdio.h>
#include <math.h>

int is_armstrong(int n) {
    int original = n, digits = 0, total = 0;
    while (original > 0) { original /= 10; digits++; }

    original = n;
    while (original > 0) {
        int digit = original % 10;
        total += (int)pow(digit, digits);
        original /= 10;
    }
    return total == n;
}

int main() {
    printf(is_armstrong(153) ? "Armstrong\n" : "Not Armstrong\n");
    return 0;
}
```
