## Exercise 1: Check Leap Year

**Difficulty:** Basic

### Problem
Write a C program that checks whether a year is a leap year. A year is a leap year if it is divisible by 4, except century years which must be divisible by 400.

**Given Input:** `is_leap_year(2024)`

**Expected Output:**
```
2000 -> Leap year
1900 -> Not a leap year
2024 -> Leap year
2023 -> Not a leap year
```

### Concepts
- `stdio.h` and `printf`
- Modulo operator (`%`)
- Logical operators (`&&`, `||`) and the ternary operator

### Example / Starter Code

```c
#include <stdio.h>

int is_leap_year(int year) {
    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
        return 1;
    }
    return 0;
}

int main() {
    int years[] = {2000, 1900, 2024, 2023};
    for (int i = 0; i < 4; i++) {
        printf("%d -> %s\n", years[i], is_leap_year(years[i]) ? "Leap year" : "Not a leap year");
    }
    return 0;
}
```

## Exercise 2: GCD (HCF) of Two Numbers

**Difficulty:** Basic

### Problem
Write a C program that computes the GCD (also called HCF) of two positive integers using the Euclidean algorithm.

**Given Input:** `gcd(48, 18)`

**Expected Output:**
```
GCD of 48 and 18: 6
```

### Concepts
- `while` loop
- Euclidean algorithm with `%`
- Function with parameters and return value

### Example / Starter Code

```c
#include <stdio.h>

int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int main() {
    printf("GCD of 48 and 18: %d\n", gcd(48, 18));
    return 0;
}
```

## Exercise 3: Print ASCII Value of a Character

**Difficulty:** Basic

### Problem
Write a C program that prints the ASCII value of a given character. The `%d` format specifier prints a `char` as its integer ASCII code.

**Given Input:** `char ch = 'A'`

**Expected Output:**
```
ASCII value of A is 65
```

### Concepts
- `char` data type
- ASCII encoding
- Format specifiers `%c` and `%d`

### Example / Starter Code

```c
#include <stdio.h>

    char ch = 'A';
    printf("ASCII value of %c is %d\n", ch, ch);

}
```

## Exercise 4: Count Number of Digits in an Integer

**Difficulty:** Basic

### Problem
Write a C program that counts how many digits are in an integer by repeatedly dividing by 10. Handle zero as a special case (it has 1 digit).

**Given Input:** `count_digits(12345)`

**Expected Output:**
```
Digits in 12345: 5
Digits in 0: 1
```

### Concepts
- Integer division `/`
- `while` loop with a counter
- Handling the zero edge case

### Example / Starter Code

```c
#include <stdio.h>

int count_digits(int n) {
    if (n == 0) return 1;
    if (n < 0) n = -n;
    int count = 0;
    while (n > 0) {
        n /= 10;
        count++;
    }
    return count;
}

int main() {
    printf("Digits in 12345: %d\n", count_digits(12345));
    printf("Digits in 0: %d\n", count_digits(0));
    return 0;
}
```

## Exercise 5: Sum of Even and Odd Numbers up to n

**Difficulty:** Basic

### Problem
Write a C program that calculates and prints the sum of all even numbers and the sum of all odd numbers from 1 to `n` (inclusive).

**Given Input:** `n = 10`

**Expected Output:**
```
Sum of even numbers up to 10: 30
Sum of odd numbers up to 10: 25
```

### Concepts
- `for` loop
- Modulo operator to test even/odd
- Accumulator variables

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int n = 10;
    int sum_even = 0, sum_odd = 0;
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 0) {
            sum_even += i;
        } else {
            sum_odd += i;
        }
    }
    printf("Sum of even numbers up to %d: %d\n", n, sum_even);
    printf("Sum of odd numbers up to %d: %d\n", n, sum_odd);
    return 0;
}
```
