## Exercise 1: Hello, World!
**Difficulty:** Basic
**Concepts:** `#include`, `main`, `printf`, return value.

Write the classic "Hello, World!" program.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```

**Task:** Modify it to print your name and a short message on separate lines.

## Exercise 2: Sum of Two Numbers
**Difficulty:** Basic
**Concepts:** `scanf`, format specifiers (`%d`), variables, arithmetic.

Read two integers from the user and print their sum.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int a, b;
    printf("Enter first number: ");
    scanf("%d", &a);
    printf("Enter second number: ");
    scanf("%d", &b);

    printf("Sum: %d\n", a + b);
    return 0;
}
```

**Task:** Also print the difference, product, and quotient (watch integer division).

## Exercise 3: Even or Odd
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator, `scanf`.

Read an integer and print whether it is even or odd.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int num;
    printf("Enter an integer: ");
    scanf("%d", &num);

    if (num % 2 == 0) {
        printf("Even\n");
    } else {
        printf("Odd\n");
    }
    return 0;
}
```

**Task:** Print "Zero" when the number is 0.

## Exercise 4: Factorial
**Difficulty:** Basic
**Concepts:** Loops (`for`/`while`), accumulator variables, overflow awareness.

Compute the factorial of a non-negative integer N.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int n;
    long long fact = 1;

    printf("Enter N: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++) {
        fact *= i;
    }

    printf("%d! = %lld\n", n, fact);
    return 0;
}
```

**Task:** Add a check that rejects negative input.

## Exercise 5: Average of an Array
**Difficulty:** Basic
**Concepts:** Arrays, loops, floating-point output (`%f`/`%.2f`).

Compute the average of the elements in a fixed array.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int numbers[] = {4, 7, 1, 9, 3, 8};
    int n = sizeof(numbers) / sizeof(numbers[0]);
    int sum = 0;

    for (int i = 0; i < n; i++) {
        sum += numbers[i];
    }

    printf("Average: %.2f\n", (double)sum / n);
    return 0;
}
```

**Task:** Also find and print the minimum and maximum values.
