# C — Basic Exercises (2026-11-14)
Sources: GeeksforGeeks, Programiz, Codeforwin, cppreference.com

Theme: **Structs** — C has no classes, so the OOP-equivalent basics are `struct` definitions, struct variables, functions that take `struct` pointers, arrays of structs, and `strcmp`-based search.

## Exercise 1: Define a Book Struct
**Difficulty:** Basic
**Concepts:** `struct`, field access with `.`, initialization, `printf`

Define a `struct Book` with `title`, `author`, and `year` fields, create a variable, and print its fields.

**Starter code:**
```c
#include <stdio.h>

struct Book {
    char title[100];
    char author[100];
    int year;
};

int main(void) {
    struct Book book = {"1984", "George Orwell", 1949};
    printf("%s by %s (%d)\n", book.title, book.author, book.year);
    return 0;
}
```

**Task:** Add a `float price` field to the struct and print it alongside the other fields.

## Exercise 2: Create and Use Multiple Structs
**Difficulty:** Basic
**Concepts:** arrays of structs, loops, field access

Create an array of three books and print each one using a loop.

**Starter code:**
```c
#include <stdio.h>

struct Book {
    char title[100];
    char author[100];
    int year;
};

int main(void) {
    struct Book books[3] = {
        {"1984", "George Orwell", 1949},
        {"Dune", "Frank Herbert", 1965},
        {"Neuromancer", "William Gibson", 1984},
    };

    for (int i = 0; i < 3; i++) {
        printf("%s by %s (%d)\n", books[i].title, books[i].author, books[i].year);
    }
    return 0;
}
```

**Task:** Add a `float price` field and print the total price of all three books.

## Exercise 3: Functions That Take a Struct Pointer
**Difficulty:** Basic
**Concepts:** passing `struct` by pointer, `->` operator, helper functions

Write functions that operate on a `struct Book *` to compute derived values.

**Starter code:**
```c
#include <stdio.h>

struct Book {
    char title[100];
    char author[100];
    int year;
    float price;
};

int book_age(struct Book *b, int current_year) {
    return current_year - b->year;
}

float discounted_price(struct Book *b, float percent) {
    return b->price * (1 - percent / 100.0f);
}

int main(void) {
    struct Book book = {"Dune", "Frank Herbert", 1965, 15.99f};
    printf("Age: %d\n", book_age(&book, 2026));
    printf("Discounted price: %.2f\n", discounted_price(&book, 20));
    return 0;
}
```

**Task:** Add a `void apply_discount(struct Book *b, float percent)` function that modifies `b->price` directly, and print the result.

## Exercise 4: Modify a Struct via Pointer
**Difficulty:** Basic
**Concepts:** mutating struct fields through a pointer, passing addresses

Write a function that updates a struct's field in place, and observe the change in the caller.

**Starter code:**
```c
#include <stdio.h>
#include <string.h>

struct Book {
    char title[100];
    char author[100];
    int year;
};

void retitle(struct Book *b, const char *new_title) {
    strcpy(b->title, new_title);
}

int main(void) {
    struct Book book = {"1984", "George Orwell", 1949};
    retitle(&book, "Nineteen Eighty-Four");
    printf("New title: %s\n", book.title);
    return 0;
}
```

**Task:** Write a `void add_year(struct Book *b)` that increments `b->year` by 1, and demonstrate that changes persist after the call returns.

## Exercise 5: Search an Array of Structs
**Difficulty:** Basic
**Concepts:** `strcmp`, searching arrays, returning a pointer, `NULL`

Write a function that finds a book by title in an array of structs and returns a pointer to it.

**Starter code:**
```c
#include <stdio.h>
#include <string.h>

struct Book {
    char title[100];
    char author[100];
    int year;
};

struct Book *find_by_title(struct Book *books, int count, const char *title) {
    for (int i = 0; i < count; i++) {
        if (strcmp(books[i].title, title) == 0) {
            return &books[i];
        }
    }
    return NULL;
}

int main(void) {
    struct Book books[3] = {
        {"1984", "George Orwell", 1949},
        {"Dune", "Frank Herbert", 1965},
        {"Neuromancer", "William Gibson", 1984},
    };

    struct Book *found = find_by_title(books, 3, "Dune");
    if (found != NULL) {
        printf("Found: %s by %s (%d)\n", found->title, found->author, found->year);
    } else {
        printf("Not found.\n");
    }
    return 0;
}
```

**Task:** Make the search case-insensitive by writing a helper that compares with `tolower()` (from `<ctype.h>`), and test it with a lowercase query.
