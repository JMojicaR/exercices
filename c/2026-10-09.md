## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** for loop, functions, scanf/printf

Compute the factorial of a non-negative integer using a function.

**Starter code:**
```c
#include <stdio.h>

long factorial(int n) {
    long result = 1;
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
    return result;
}

int main(void) {
    int n;
    printf("Enter a non-negative integer: ");
    scanf("%d", &n);
    printf("%d! = %ld\n", n, factorial(n));
    return 0;
}
```

**Task:** Guard against negative input by printing an error message and exiting early.

## Exercise 2: Prime Number Check
**Difficulty:** Basic
**Concepts:** for loop, modulo, break

Read an integer and print whether it is prime.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int n, isPrime = 1;
    printf("Enter a positive integer: ");
    scanf("%d", &n);
    if (n <= 1) isPrime = 0;
    for (int i = 2; i * i <= n && isPrime; i++) {
        if (n % i == 0) isPrime = 0;
    }
    printf("%d is %sprime\n", n, isPrime ? "" : "not ");
    return 0;
}
```

**Task:** Print all primes between 2 and 100 using a nested loop.

## Exercise 3: Palindrome Number
**Difficulty:** Basic
**Concepts:** while loop, modulo, integer division

Check whether a number is a palindrome (same forward and backward, e.g. 121).

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int original, reversed = 0, temp;
    printf("Enter a number: ");
    scanf("%d", &original);
    temp = original;
    while (temp > 0) {
        reversed = reversed * 10 + temp % 10;
        temp /= 10;
    }
    printf("%d is %sa palindrome\n", original, original == reversed ? "" : "not ");
    return 0;
}
```

**Task:** Extend the program to work for negative numbers by reporting them as non-palindromes.

## Exercise 4: Simple Interest
**Difficulty:** Basic
**Concepts:** variables, arithmetic, float, printf formatting

Calculate simple interest from principal, rate, and time using the formula `SI = (P * R * T) / 100`.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    float principal, rate, time, interest;
    printf("Enter principal, rate (%%), and time (years): ");
    scanf("%f %f %f", &principal, &rate, &time);
    interest = (principal * rate * time) / 100.0;
    printf("Simple interest: %.2f\n", interest);
    return 0;
}
```

**Task:** Also print the total amount (principal + interest).

## Exercise 5: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** arrays, for loop

Sum the elements of an integer array.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int numbers[] = {5, 10, 15, 20, 25};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int sum = 0;
    for (int i = 0; i < size; i++) {
        sum += numbers[i];
    }
    printf("Sum: %d\n", sum);
    return 0;
}
```

**Task:** Also compute the average and the largest element of the array.
