## Exercise 1: Sum of Natural Numbers (1 to n)
**Difficulty:** Basic
**Concepts:** `printf`/`scanf`, loops, accumulation, data types.

Write a program that reads `n` and prints the sum `1 + 2 + … + n`.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, sum = 0;

    printf("Enter a positive integer: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++) {
        sum += i;
    }

    printf("Sum = %d\n", sum);
    return 0;
}
```

**Task:** Also compute the sum using the closed-form formula `n * (n + 1) / 2` and compare.

## Exercise 2: Reverse a Number
**Difficulty:** Basic
**Concepts:** `while` loop, `%` and `/`, integer arithmetic.

Write a program that reverses an integer (e.g. 4321 → 1234).

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, reversed = 0;

    printf("Enter a number: ");
    scanf("%d", &n);

    while (n != 0) {
        int digit = n % 10;
        reversed = reversed * 10 + digit;
        n /= 10;
    }

    printf("Reversed = %d\n", reversed);
    return 0;
}
```

**Task:** Also count how many digits the original number has.

## Exercise 3: Check Prime Number
**Difficulty:** Basic
**Concepts:** Loops, conditionals, boolean flags, early termination.

Write a program that checks whether a number is prime.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, isPrime = 1;

    printf("Enter a number: ");
    scanf("%d", &n);

    if (n < 2) {
        isPrime = 0;
    }
    for (int i = 2; i * i <= n && isPrime; i++) {
        if (n % i == 0) {
            isPrime = 0;
        }
    }

    if (isPrime) {
        printf("%d is prime\n", n);
    } else {
        printf("%d is not prime\n", n);
    }
    return 0;
}
```

**Task:** Print all prime numbers between 1 and 100.

## Exercise 4: Factorial
**Difficulty:** Basic
**Concepts:** Loops, accumulator, function definition, `long` type.

Write a program that computes the factorial of a number using a function.

**Starter code:**
```c
#include <stdio.h>

long factorial(int n) {
    long result = 1;
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
    return result;
}

int main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);
    printf("%d! = %ld\n", n, factorial(n));
    return 0;
}
```

**Task:** Add a recursive version and compare the two results.

## Exercise 5: String Length (without `strlen`)
**Difficulty:** Basic
**Concepts:** Strings/char arrays, null terminator `'\0'`, loops.

Write a program that counts the number of characters in a string without using the `strlen()` function.

**Starter code:**
```c
#include <stdio.h>

int main() {
    char str[100];
    int length = 0;

    printf("Enter a string: ");
    scanf("%99s", str);

    while (str[length] != '\0') {
        length++;
    }

    printf("Length = %d\n", length);
    return 0;
}
```

**Task:** Read a full line with spaces using `fgets` and count the characters.
