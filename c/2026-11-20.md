## Exercise 1: Character Frequency Counter
**Difficulty:** Basic
**Concepts:** arrays as counters, indexing by character, `string.h`, printing results

Count how many times each letter appears in a string using an array of 26 counters.

**Starter code:**
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char text[] = "hello";
    int count[26] = {0};

    for (int i = 0; text[i] != '\0'; i++) {
        char ch = text[i];
        if (ch >= 'a' && ch <= 'z') {
            count[ch - 'a']++;
        }
    }

    for (int i = 0; i < 26; i++) {
        if (count[i] > 0) {
            printf("%c: %d\n", 'a' + i, count[i]);
        }
    }
    return 0;
}
```

**Task:** Also handle uppercase letters by converting them with `tolower()` (from `<ctype.h>`) before indexing.

## Exercise 2: Lookup Table — Month Names
**Difficulty:** Basic
**Concepts:** arrays of string pointers (`char *[]`), index lookup, bounds checking

Return the name of a month given its number (1–12).

**Starter code:**
```c
#include <stdio.h>

const char *month_name(int month) {
    static const char *months[] = {
        "", "January", "February", "March", "April", "May", "June",
        "July", "August", "September", "October", "November", "December"
    };
    if (month < 1 || month > 12) {
        return "Invalid month";
    }
    return months[month];
}

int main(void) {
    printf("%s\n", month_name(3));   // March
    printf("%s\n", month_name(13));  // Invalid month
    return 0;
}
```

**Task:** Add a function that takes a month name and returns its number by looping over the array with `strcmp()`.

## Exercise 3: Simple Key-Value Store with a Struct Array
**Difficulty:** Basic
**Concepts:** `struct`, arrays of structs, linear search, `strcmp`

Store name→age pairs in a struct array and look up a person's age.

**Starter code:**
```c
#include <stdio.h>
#include <string.h>

struct Person {
    char name[20];
    int age;
};

int find_age(struct Person people[], int n, const char *name) {
    for (int i = 0; i < n; i++) {
        if (strcmp(people[i].name, name) == 0) {
            return people[i].age;
        }
    }
    return -1;  // not found
}

int main(void) {
    struct Person people[3] = {
        {"Alice", 25}, {"Bob", 30}, {"Carol", 22}
    };

    int age = find_age(people, 3, "Bob");
    printf("Bob is %d years old\n", age);  // 30

    age = find_age(people, 3, "Dave");
    printf("Dave found? %s\n", age == -1 ? "no" : "yes");
    return 0;
}
```

**Task:** Add a `set_age` function that updates an existing person's age, or appends a new person if the name isn't found (returning the new count).

## Exercise 4: Count Digit Frequencies
**Difficulty:** Basic
**Concepts:** `%` and `/` to extract digits, a 10-element counter array, `long`/`int` handling

Count how many times each digit (0–9) appears in an integer.

**Starter code:**
```c
#include <stdio.h>

void count_digits(long n, int counts[10]) {
    if (n == 0) {
        counts[0] = 1;
        return;
    }
    while (n > 0) {
        counts[n % 10]++;
        n /= 10;
    }
}

int main(void) {
    int counts[10] = {0};
    count_digits(122333, counts);

    for (int i = 0; i < 10; i++) {
        if (counts[i] > 0) {
            printf("%d: %d\n", i, counts[i]);
        }
    }
    return 0;
}
```

**Task:** Handle negative numbers by converting them to positive first (e.g. take the absolute value), and add a test for `-1020`.

## Exercise 5: Parallel-Array Lookup
**Difficulty:** Basic
**Concepts:** two parallel arrays acting as key→value pairs, loops, bounds handling

Store product names in one array and their prices in a second, and look up a price.

**Starter code:**
```c
#include <stdio.h>
#include <string.h>

double get_price(const char *products[], const double prices[],
                 int n, const char *name) {
    for (int i = 0; i < n; i++) {
        if (strcmp(products[i], name) == 0) {
            return prices[i];
        }
    }
    return -1.0;  // not found
}

int main(void) {
    const char *products[] = {"apple", "banana", "cherry"};
    double prices[] = {1.20, 0.80, 2.50};

    double p = get_price(products, prices, 3, "banana");
    printf("banana costs %.2f\n", p);  // 0.80

    p = get_price(products, prices, 3, "grape");
    printf("grape found? %s\n", p < 0 ? "no" : "yes");
    return 0;
}
```

**Task:** Print every product and price in a table using `printf("%-10s $%.2f\n", ...)` to left-align the names.
