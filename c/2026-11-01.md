## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** functions, `for` loop, `long long`, `printf` format specifiers

Compute `n!` and return it as a `long long`.

**Starter code:**
```c
#include <stdio.h>

long long factorial(int n) {
    long long result = 1;
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
    return result;
}

int main(void) {
    printf("%lld\n", factorial(5)); // 120
    printf("%lld\n", factorial(0)); // 1
    return 0;
}
```

**Task:** Read `n` from the user with `scanf` and print the result. Handle negative input by printing an error.

## Exercise 2: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** `for` loop, variable swapping, `printf`, integer arithmetic

Print the first `n` Fibonacci numbers (`0, 1, 1, 2, 3, 5, 8, …`).

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int n = 7, a = 0, b = 1;
    for (int i = 0; i < n; i++) {
        printf("%d ", a);
        int next = a + b;
        a = b;
        b = next;
    }
    printf("\n"); // 0 1 1 2 3 5 8
    return 0;
}
```

**Task:** Refactor the loop into a `fibonacci(int n)` function that prints the sequence, and read `n` from the user.

## Exercise 3: Check Prime Number
**Difficulty:** Basic
**Concepts:** functions returning `int` (boolean), `%`, `<math.h>` (`sqrt`), loops

Return `1` if a number is prime, `0` otherwise.

**Starter code:**
```c
#include <stdio.h>
#include <math.h>

int is_prime(int n) {
    if (n < 2) return 0;
    for (int i = 2; i <= sqrt(n); i++) {
        if (n % i == 0) return 0;
    }
    return 1;
}

int main(void) {
    printf("%d\n", is_prime(7));  // 1
    printf("%d\n", is_prime(10)); // 0
    return 0;
}
```

**Task:** Write a `print_primes(int limit)` function that prints every prime up to `limit` on one line.

## Exercise 4: Sum of Digits
**Difficulty:** Basic
**Concepts:** `%` and `/`, `while` loop, digit extraction, integer return

Return the sum of the individual digits of a number.

**Starter code:**
```c
#include <stdio.h>

int sum_of_digits(int n) {
    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }
    return sum;
}

int main(void) {
    printf("%d\n", sum_of_digits(1234)); // 10
    return 0;
}
```

**Task:** Extend the function to also compute the product of the digits and print both.

## Exercise 5: Greatest Common Divisor (GCD)
**Difficulty:** Basic
**Concepts:** Euclidean algorithm, `while` loop, temporary variable, `%`

Compute the greatest common divisor of two integers.

**Starter code:**
```c
#include <stdio.h>

int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int main(void) {
    printf("%d\n", gcd(48, 18)); // 6
    printf("%d\n", gcd(100, 35)); // 5
    return 0;
}
```

**Task:** Add an `lcm(int a, int b)` function using `lcm(a, b) = a / gcd(a, b) * b`.
