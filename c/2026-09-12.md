## Exercise 1: Simple Calculator
- **Difficulty:** Easy
- **Description:** Read two numbers and an operator from the user and print the result using a `switch` statement. Handle division by zero.
- **Concepts:** `scanf`, `switch`, format specifiers, arithmetic
- **Starter code:**
```c
#include <stdio.h>

int main(void) {
    double a, b;
    char op;
    printf("Enter a op b (e.g. 5 + 3): ");
    scanf("%lf %c %lf", &a, &op, &b);

    switch (op) {
        case '+': printf("%.2f\n", a + b); break;
        // TODO: add cases for '-', '*', '/'
        default:  printf("Unknown operator\n");
    }
    return 0;
}
```
