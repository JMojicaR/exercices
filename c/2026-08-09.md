## Exercise 1: Print Name, DOB, and Mobile Number

### Problem
Write a C program to print your name, date of birth, and mobile number.

**Expected Output:**
```
Name    : Alexandra Abramov
DOB     : July 14, 1975
Mobile  : 99-9999999999
```

### Concepts
- `printf()` function for formatted output
- Basic C program structure (`main` function)
- Including standard I/O header (`stdio.h`)
- String literals

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    printf("Name    : Alexandra Abramov\n");
    printf("DOB     : July 14, 1975\n");
    printf("Mobile  : 99-9999999999\n");

    return 0;
}
```

## Exercise 2: Get the C Version

### Problem
Write a C program to get the C version you are using. Use the `__STDC_VERSION__` macro to determine the C standard version.

**Expected Output:**
```
We are using C18!
```

### Concepts
- Preprocessor macros (`__STDC_VERSION__`)
- Conditional compilation (`#if`, `#elif`, `#else`, `#endif`)
- C standard versions (C89, C99, C11, C17/C18, C23)
- `printf()` for output

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    #if __STDC_VERSION__ >= 202311L
        printf("We are using C23!\n");
    #elif __STDC_VERSION__ >= 201710L
        printf("We are using C18!\n");
    #elif __STDC_VERSION__ >= 201112L
        printf("We are using C11!\n");
    #elif __STDC_VERSION__ >= 199901L
        printf("We are using C99!\n");
    #else
        printf("We are using C89/C90!\n");
    #endif

    return 0;
}
```

## Exercise 3: Print a Block F Using Hash (#)

### Problem
Write a C program to print a block letter 'F' using the hash character (#), where the 'F' has a height of six characters and a width of five and four characters.

**Expected Output:**
```
######
#
#
#####
#
#
#
```

### Concepts
- `printf()` with newline characters
- Pattern printing using repeated `printf()` calls
- Understanding output formatting

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    printf("######\n");
    printf("#\n");
    printf("#\n");
    printf("#####\n");
    printf("#\n");
    printf("#\n");
    printf("#\n");

    return 0;
}
```

## Exercise 4: Print Characters in Reverse

### Problem
Write a C program to print the given characters in reverse order.

**Test Characters:** `'X'`, `'M'`, `'L'`

**Expected Output:**
```
The reverse of XML is LMX
```

### Concepts
- `char` data type
- Array of characters
- Reversing order by iterating from the end
- `printf()` with character format specifier (`%c`)

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    char char1 = 'X', char2 = 'M', char3 = 'L';

    printf("The reverse of %c%c%c is %c%c%c\n",
           char1, char2, char3,
           char3, char2, char1);

    return 0;
}
```

## Exercise 5: Compute Perimeter and Area of a Rectangle

### Problem
Write a C program to compute the perimeter and area of a rectangle with a height of 7 inches and a width of 5 inches.

**Formulas:**
- Perimeter = `2 * (height + width)`
- Area = `height * width`

**Expected Output:**
```
Perimeter of the rectangle = 24 inches
Area of the rectangle = 35 square inches
```

### Concepts
- Variable declaration and initialization (`int`)
- Arithmetic expressions
- `printf()` with format specifiers (`%d`)
- Basic geometry calculations

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int height = 7;
    int width = 5;

    int perimeter = 2 * (height + width);
    int area = height * width;

    printf("Perimeter of the rectangle = %d inches\n", perimeter);
    printf("Area of the rectangle = %d square inches\n", area);

    return 0;
}
```
