# C Basic Coding Exercises - 2026-07-25

## Exercise 1: Hello, World!
- **Description**: Write a C program that prints `"Hello, World!"` to the console. This is the classic first program — it introduces the structure of a C program, the `main()` function, the `#include` preprocessor directive, and the `printf()` output function.
- **Difficulty**: Beginner
- **Concepts**: `printf`, `main`, `#include`, basic program structure
- **Example/Starter Code**:
```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

## Exercise 2: Simple Calculator (Addition)
- **Description**: Write a program that asks the user for two integers, adds them together, and prints the result. This exercise introduces `scanf()` for reading user input, variable declarations (`int`), and basic arithmetic operations.
- **Difficulty**: Beginner
- **Concepts**: `scanf`, `printf`, variables, arithmetic operators, integer types
- **Example/Starter Code**:
```c
#include <stdio.h>

int main() {
    int num1, num2, sum;

    printf("Enter first number: ");
    scanf("%d", &num1);

    printf("Enter second number: ");
    scanf("%d", &num2);

    sum = num1 + num2;

    printf("Sum: %d + %d = %d\n", num1, num2, sum);
    return 0;
}
```

## Exercise 3: Check Even or Odd
- **Description**: Write a program that reads an integer from the user and determines whether it is even or odd. This exercise teaches the modulo operator (`%`) and introduces the `if-else` conditional statement, which is fundamental for decision-making in programs.
- **Difficulty**: Beginner
- **Concepts**: `if-else`, modulo operator (`%`), conditional logic, `scanf`
- **Example/Starter Code**:
```c
#include <stdio.h>

int main() {
    int number;

    printf("Enter an integer: ");
    scanf("%d", &number);

    if (number % 2 == 0) {
        printf("%d is even.\n", number);
    } else {
        printf("%d is odd.\n", number);
    }

    return 0;
}
```

## Exercise 4: Factorial of a Number
- **Description**: Write a program that calculates the factorial of a non-negative integer entered by the user. The factorial of `n` (written as `n!`) is the product of all integers from 1 to `n`. This exercise introduces `for` loops and multiplication accumulation — core patterns in iterative computation.
- **Difficulty**: Beginner
- **Concepts**: `for` loop, iteration, accumulation, `scanf`, `printf`
- **Example/Starter Code**:
```c
#include <stdio.h>

int main() {
    int n, i;
    long long factorial = 1;

    printf("Enter a non-negative integer: ");
    scanf("%d", &n);

    if (n < 0) {
        printf("Factorial is not defined for negative numbers.\n");
    } else {
        for (i = 1; i <= n; i++) {
            factorial *= i;
        }
        printf("Factorial of %d = %lld\n", n, factorial);
    }

    return 0;
}
```

## Exercise 5: Fibonacci Series
- **Description**: Write a program that prints the first `n` terms of the Fibonacci sequence. The Fibonacci sequence starts with 0 and 1, and each subsequent term is the sum of the two preceding ones. This exercise combines `for` loops with multiple-variable tracking and introduces array usage for storing sequences.
- **Difficulty**: Beginner
- **Concepts**: `for` loop, arrays, sequence generation, multiple-variable updates
- **Example/Starter Code**:
```c
#include <stdio.h>

int main() {
    int n, i;
    int fib[100];

    printf("Enter the number of terms: ");
    scanf("%d", &n);

    fib[0] = 0;
    fib[1] = 1;

    for (i = 2; i < n; i++) {
        fib[i] = fib[i - 1] + fib[i - 2];
    }

    printf("Fibonacci Series: ");
    for (i = 0; i < n; i++) {
        printf("%d ", fib[i]);
    }
    printf("\n");

    return 0;
}
```
