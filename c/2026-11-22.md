## Exercise 1: Create and Traverse a Linked List
**Difficulty:** Basic
**Concepts:** `struct` with a self-referencing pointer, `malloc`, `NULL`, pointer traversal

**Starter code:**
```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;

int main(void) {
    Node *head = malloc(sizeof(Node));
    head->value = 10;
    head->next = malloc(sizeof(Node));
    head->next->value = 20;
    head->next->next = malloc(sizeof(Node));
    head->next->next->value = 30;
    head->next->next->next = NULL;

    for (Node *cur = head; cur != NULL; cur = cur->next) {
        printf("%d ", cur->value);
    }
    printf("\n");   // prints: 10 20 30
    return 0;
}
```

**Task:** Write a `print_list(Node *head)` function that prints values separated by `" -> "` and ends with `"NULL"`.

## Exercise 2: Append a Node to the End
**Difficulty:** Basic
**Concepts:** allocating a new node, walking to the tail, empty-list edge case

**Starter code:**
```c
Node *append(Node *head, int value) {
    Node *new_node = malloc(sizeof(Node));
    new_node->value = value;
    new_node->next = NULL;

    if (head == NULL) return new_node;

    Node *cur = head;
    while (cur->next != NULL) {
        cur = cur->next;
    }
    cur->next = new_node;
    return head;
}
```

**Task:** Append `1..5` to an empty list (`NULL`) in a loop and print the list.

## Exercise 3: Length and Sum of a Linked List
**Difficulty:** Basic
**Concepts:** counting during traversal, accumulating a total

**Starter code:**
```c
int length(Node *head) {
    int count = 0;
    for (Node *cur = head; cur != NULL; cur = cur->next) {
        count++;
    }
    return count;
}

int sum(Node *head) {
    int total = 0;
    for (Node *cur = head; cur != NULL; cur = cur->next) {
        total += cur->value;
    }
    return total;
}
```

**Task:** Build `7 -> 8 -> 9` and verify `length` returns `3` and `sum` returns `24`.

## Exercise 4: Search for a Value
**Difficulty:** Basic
**Concepts:** early `return`, pointer traversal, comparing integers

**Starter code:**
```c
int contains(Node *head, int target) {
    for (Node *cur = head; cur != NULL; cur = cur->next) {
        if (cur->value == target) return 1;   /* true */
    }
    return 0;   /* false */
}
```

**Task:** Write `int index_of(Node *head, int target)` returning the 0-based index of the first match, or `-1`.

## Exercise 5: Delete the First Matching Node
**Difficulty:** Basic
**Concepts:** rewiring pointers, `free`ing removed nodes, head-removal case

**Starter code:**
```c
Node *delete_value(Node *head, int value) {
    if (head == NULL) return NULL;
    if (head->value == value) {
        Node *new_head = head->next;
        free(head);
        return new_head;
    }
    Node *cur = head;
    while (cur->next != NULL && cur->next->value != value) {
        cur = cur->next;
    }
    if (cur->next != NULL) {
        Node *to_delete = cur->next;
        cur->next = to_delete->next;
        free(to_delete);
    }
    return head;
}
```

**Task:** Test removing the head, a middle node, and a missing value from `10 -> 20 -> 30`. Remember that forgetting `free` causes memory leaks.
