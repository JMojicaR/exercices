## 1. Hello, World!
**Description:** Write the minimal C program that prints a greeting to standard output.
**Difficulty:** Basic
**Concepts:** `#include`, `main()` function, `printf()`, return value.
**Starter code:**
```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```

## 2. Even or Odd
**Description:** Read an integer from the user and print whether it is even or odd.
**Difficulty:** Basic
**Concepts:** `scanf()`, conditionals, modulo operator.
**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);
    if (n % 2 == 0) {
        printf("%d is even\n", n);
    } else {
        printf("%d is odd\n", n);
    }
    return 0;
}
```

## 3. Sum of N Numbers
**Description:** Read N integers into an array and compute their sum.
**Difficulty:** Basic
**Concepts:** Arrays, `for` loop, indexing, `scanf()`.
**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int n, sum = 0;
    printf("How many numbers? ");
    scanf("%d", &n);

    int arr[n];
    for (int i = 0; i < n; i++) {
        printf("Enter number %d: ", i + 1);
        scanf("%d", &arr[i]);
        sum += arr[i];
    }
    printf("Sum: %d\n", sum);
    return 0;
}
```

## 4. Factorial
**Description:** Compute the factorial of a non-negative integer using a loop.
**Difficulty:** Basic
**Concepts:** Loops, function definition, integer types.
**Starter code:**
```c
#include <stdio.h>

long factorial(int n) {
    long result = 1;
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
    return result;
}

int main(void) {
    int n = 5;
    printf("%d! = %ld\n", n, factorial(n));
    return 0;
}
```

## 5. Reverse an Array
**Description:** Read an array of integers and print it in reverse order.
**Difficulty:** Basic
**Concepts:** Arrays, loop indices, array indexing from the end.
**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int arr[] = {1, 2, 3, 4, 5};
    int size = sizeof(arr) / sizeof(arr[0]);

    printf("Reversed: ");
    for (int i = size - 1; i >= 0; i--) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    return 0;
}
```
