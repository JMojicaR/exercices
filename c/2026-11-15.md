# C — Basic Exercises (2026-11-15)
Sources: GeeksforGeeks, tutorialspoint, cppreference.com (C), Programiz

Theme: **Error Handling in C** — return error codes, `NULL` checks, `errno` with `strerror`/`perror`, `scanf` return values, and `strtol` end-pointer detection. C has no exceptions, so errors are signalled through return values and `errno`.

## Exercise 1: Return Error Codes
**Difficulty:** Basic
**Concepts:** out-parameters (`int *result`), return `0`/`-1` success/error convention

Signal failure by returning a non-zero code and write the answer through a pointer.

**Starter code:**
```c
#include <stdio.h>

int divide(int a, int b, int *result) {
    if (b == 0) {
        return -1; /* error: division by zero */
    }
    *result = a / b;
    return 0; /* success */
}

int main(void) {
    int result;
    if (divide(10, 0, &result) != 0) {
        printf("Error: division by zero\n");
    } else {
        printf("Result: %d\n", result);
    }
    return 0;
}
```

**Task:** Change the error code to a distinct value (e.g. `-2`) for a new `b < 0` case, and handle it separately in `main`.

## Exercise 2: NULL Pointer Checks
**Difficulty:** Basic
**Concepts:** `fopen`, `NULL` check, exiting with a non-zero status

Check whether a file opened successfully before using the handle.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    FILE *file = fopen("missing.txt", "r");
    if (file == NULL) {
        printf("Error: could not open file\n");
        return 1;
    }
    fclose(file);
    return 0;
}
```

**Task:** Open an actual file (e.g. `"data.txt"`) after creating it, and print a success message when `file` is not `NULL`.

## Exercise 3: errno, strerror, and perror
**Difficulty:** Basic
**Concepts:** `errno`, `strerror(errno)`, `perror`, including `<errno.h>` and `<string.h>`

Read the system error code and print a human-readable description.

**Starter code:**
```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void) {
    FILE *file = fopen("no_such_file.txt", "r");
    if (file == NULL) {
        printf("errno = %d: %s\n", errno, strerror(errno));
        perror("fopen");
        return 1;
    }
    fclose(file);
    return 0;
}
```

**Task:** Trigger a different error (e.g. `fopen` on a path inside a non-existent directory) and compare the new `errno` value and message.

## Exercise 4: Checking scanf's Return Value
**Difficulty:** Basic
**Concepts:** `scanf` return count, detecting failed input conversion

Verify that `scanf` actually read a value before using it.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int number;
    printf("Enter an integer: ");
    if (scanf("%d", &number) != 1) {
        printf("Error: invalid input\n");
        return 1;
    }
    printf("You entered: %d\n", number);
    return 0;
}
```

**Task:** Read two integers in one `scanf` call and check that the return value equals `2` before doing any arithmetic with them.

## Exercise 5: strtol End-Pointer Detection
**Difficulty:** Basic
**Concepts:** `strtol`, `endptr`, detecting partial conversions and no-digit strings

Distinguish full, partial, and failed numeric conversions.

**Starter code:**
```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    char input[] = "123abc";
    char *endptr;
    long value = strtol(input, &endptr, 10);

    if (endptr == input) {
        printf("Error: no digits found\n");
    } else if (*endptr != '\0') {
        printf("Partial conversion: %ld (leftover: \"%s\")\n", value, endptr);
    } else {
        printf("Fully converted: %ld\n", value);
    }
    return 0;
}
```

**Task:** Test the same code with the strings `"42"` and `"abc"` and confirm all three branches print correctly.
