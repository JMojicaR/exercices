## Exercise 1: Sum of Natural Numbers

**Difficulty:** Basic

### Problem
Write a C program that calculates the sum of the first `n` natural numbers (1 to n).

**Given Input:** `n = 10`

**Expected Output:**
```
Sum of first 10 natural numbers = 55
```

### Concepts
- `for` loops
- Accumulator variable
- `printf` formatted output

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int n = 10;
    int sum = 0;

    for (int i = 1; i <= n; i++) {
        sum += i;
    }

    printf("Sum of first %d natural numbers = %d\n", n, sum);
    return 0;
}
```

## Exercise 2: Reverse a Number

**Difficulty:** Basic

### Problem
Write a C program that reverses the digits of an integer.

**Given Input:** `1234`

**Expected Output:**
```
Reversed number: 4321
```

### Concepts
- `while` loops
- Modulo (`%`) and integer division (`/`)
- Building a number digit by digit

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int num = 1234;
    int reversed = 0;

    while (num != 0) {
        reversed = reversed * 10 + num % 10;
        num /= 10;
    }

    printf("Reversed number: %d\n", reversed);
    return 0;
}
```

## Exercise 3: Palindrome Number

**Difficulty:** Basic

### Problem
Write a C program that checks whether a given integer is a palindrome (reads the same forward and backward).

**Given Input:** `121`

**Expected Output:**
```
121 is a palindrome
```

### Concepts
- Preserving the original number in a separate variable
- Reversing digits with a `while` loop
- `if / else` branching

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int num = 121;
    int original = num;
    int reversed = 0;

    while (num != 0) {
        reversed = reversed * 10 + num % 10;
        num /= 10;
    }

    if (original == reversed)
        printf("%d is a palindrome\n", original);
    else
        printf("%d is not a palindrome\n", original);

    return 0;
}
```

## Exercise 4: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a C program that finds the largest of three integers.

**Given Input:** `a = 10, b = 25, c = 15`

**Expected Output:**
```
Largest: 25
```

### Concepts
- Nested ternary operator (`?:`)
- Comparison operators

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int a = 10, b = 25, c = 15;
    int max;

    max = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);

    printf("Largest: %d\n", max);
    return 0;
}
```

## Exercise 5: Check Vowel or Consonant

**Difficulty:** Basic

### Problem
Write a C program that checks whether a given character is a vowel or a consonant (case-insensitive).

**Given Input:** `'e'`

**Expected Output:**
```
e is a vowel
```

### Concepts
- `char` type
- `tolower()` from `<ctype.h>`
- `if / else` with logical OR (`||`)

### Example / Starter Code

```c
#include <stdio.h>
#include <ctype.h>

int main() {
    char ch = 'e';
    ch = tolower(ch);

    if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u')
        printf("%c is a vowel\n", ch);
    else
        printf("%c is a consonant\n", ch);

    return 0;
}
```
