## Exercise 1: Even or Odd Checker
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator `%`, function definition, `printf()`

Write a function that takes an `int` and prints whether it is even or odd.

**Starter code:**
```c
#include <stdio.h>

void even_or_odd(int n) {
    if (n % 2 == 0) {
        printf("%d is even\n", n);
    } else {
        printf("%d is odd\n", n);
    }
}

int main(void) {
    even_or_odd(4);  /* 4 is even */
    even_or_odd(7);  /* 7 is odd */
    return 0;
}
```

**Task:** Read the number from the user with `scanf("%d", &n)` and check its return value to confirm the input was a valid integer.

## Exercise 2: Print Numbers 1 to N
**Difficulty:** Basic
**Concepts:** `for` loop, loop variable, increment `i++`, `printf()`

Print every integer from 1 up to and including `N`, one per line.

**Starter code:**
```c
#include <stdio.h>

void print_range(int n) {
    for (int i = 1; i <= n; i++) {
        printf("%d\n", i);
    }
}

int main(void) {
    print_range(5);
    /* 1
       2
       3
       4
       5 */
    return 0;
}
```

**Task:** Modify the loop to print only odd numbers using `i += 2`. Then rewrite the loop with a `while` loop that counts upward.

## Exercise 3: Countdown
**Difficulty:** Basic
**Concepts:** `while` loop, decrementing a counter, loop condition

Print a countdown from `N` down to 1, then print `"Liftoff!"`.

**Starter code:**
```c
#include <stdio.h>

void countdown(int n) {
    while (n > 0) {
        printf("%d\n", n);
        n--;
    }
    printf("Liftoff!\n");
}

int main(void) {
    countdown(5);
    /* 5
       4
       3
       2
       1
       Liftoff! */
    return 0;
}
```

**Task:** Add a guard so that `n <= 0` prints `"Nothing to count"`. Then rewrite the countdown using a `for` loop (`for (int i = n; i > 0; i--)`).

## Exercise 4: Grade Classifier
**Difficulty:** Basic
**Concepts:** `if`/`else if`/`else` ladder, comparison operators, `return`

Convert a numeric score (0–100) into a letter grade: 90+ → A, 80–89 → B, 70–79 → C, 60–69 → D, below 60 → F.

**Starter code:**
```c
#include <stdio.h>

char classify(int score) {
    if (score >= 90) {
        return 'A';
    } else if (score >= 80) {
        return 'B';
    } else if (score >= 70) {
        return 'C';
    } else if (score >= 60) {
        return 'D';
    } else {
        return 'F';
    }
}

int main(void) {
    printf("%c\n", classify(95)); /* A */
    printf("%c\n", classify(83)); /* B */
    printf("%c\n", classify(57)); /* F */
    return 0;
}
```

**Task:** Rewrite using a `switch` statement on `score / 10`. Then handle scores outside 0–100 by returning `'X'` (for "invalid").

## Exercise 5: Sum of Even Numbers up to N
**Difficulty:** Basic
**Concepts:** `for` loop + `if` condition, accumulator variable, `+=`

Return the sum of every even number from 2 up to and including `N`.

**Starter code:**
```c
#include <stdio.h>

int sum_even(int n) {
    int total = 0;
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 0) {
            total += i;
        }
    }
    return total;
}

int main(void) {
    printf("%d\n", sum_even(10)); /* 2 + 4 + 6 + 8 + 10 = 30 */
    printf("%d\n", sum_even(7));  /* 2 + 4 + 6 = 12 */
    return 0;
}
```

**Task:** Rewrite using `i += 2` so the conditional is unnecessary, and add a `sum_odd(int n)` function. Compare `sum_even(n) + sum_odd(n)` against `n*(n+1)/2` for a given `n`.
