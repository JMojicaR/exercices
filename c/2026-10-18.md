## Exercise 1: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** variables, temporary variable, `printf`

Swap the values of two variables.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int a = 5, b = 10, temp;

    temp = a;
    a = b;
    b = temp;

    printf("a = %d, b = %d\n", a, b);
    return 0;
}
```

**Task:** Swap again using arithmetic (no temporary variable): `a = a + b; b = a - b; a = a - b;`.

## Exercise 2: Area of a Circle
**Difficulty:** Basic
**Concepts:** `#define`, `scanf`, `printf`, `float`

Compute the area of a circle given its radius (`area = π × r²`).

**Starter code:**
```c
#include <stdio.h>
#define PI 3.14159

int main() {
    float radius, area;

    printf("Enter radius: ");
    scanf("%f", &radius);

    area = PI * radius * radius;

    printf("Area: %.2f\n", area);
    return 0;
}
```

**Task:** Also compute and print the circumference (`2 * PI * radius`).

## Exercise 3: Positive, Negative or Zero
**Difficulty:** Basic
**Concepts:** `if / else if / else`, comparison operators, `scanf`

Classify a number as positive, negative, or zero.

**Starter code:**
```c
#include <stdio.h>

int main() {
    float n;

    printf("Enter a number: ");
    scanf("%f", &n);

    if (n > 0)
        printf("Positive\n");
    else if (n < 0)
        printf("Negative\n");
    else
        printf("Zero\n");

    return 0;
}
```

**Task:** Extend it to also report whether a whole number is even or odd.

## Exercise 4: Power of a Number (xⁿ)
**Difficulty:** Basic
**Concepts:** `for` loop, `math.h`, `pow()`, accumulation

Compute `base` raised to the power `exp`.

**Starter code:**
```c
#include <stdio.h>
#include <math.h>

int main() {
    double base, exp, result;

    printf("Base: ");
    scanf("%lf", &base);
    printf("Exponent: ");
    scanf("%lf", &exp);

    result = pow(base, exp);

    printf("%.2f^%.2f = %.2f\n", base, exp, result);
    return 0;
}
```

**Task:** Rewrite it with a `for` loop (for non-negative integer exponents) instead of `pow()`. Remember to link with `-lm` when using `math.h` (`gcc file.c -lm`).

## Exercise 5: Reverse a Number
**Difficulty:** Basic
**Concepts:** `while` loop, modulo (`%`), integer division (`/`)

Reverse the digits of an integer (e.g. 1234 → 4321).

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, rev = 0;

    printf("Enter a number: ");
    scanf("%d", &n);

    while (n != 0) {
        rev = rev * 10 + n % 10;
        n /= 10;
    }

    printf("Reversed: %d\n", rev);
    return 0;
}
```

**Task:** Confirm it also works for negative numbers (the `while (n != 0)` condition handles them automatically).
