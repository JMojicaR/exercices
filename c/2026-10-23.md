## Exercise 1: Print the ASCII Value of a Character
**Difficulty:** Basic
**Concepts:** `char` type, `printf` with `%d`, characters as integers

Given a character, print its ASCII value.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    char ch = 'A';
    printf("ASCII value of %c is %d\n", ch, ch);
    return 0;
}
```

**Task:** Use `scanf("%c", &ch)` to read a character from the user and print its ASCII value, then print the character back using `%c`.

## Exercise 2: Check Vowel or Consonant
**Difficulty:** Basic
**Concepts:** `if / else`, logical operators (`||`, `&&`), `char`

Read a letter and report whether it is a vowel or a consonant.

**Starter code:**
```c
#include <stdio.h>
#include <ctype.h>

int main(void) {
    char ch = 'e';
    ch = tolower(ch);

    if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u')
        printf("%c is a vowel\n", ch);
    else
        printf("%c is a consonant\n", ch);

    return 0;
}
```

**Task:** Add a check with `isalpha(ch)` from `<ctype.h>` so non-letter characters print "Not a letter".

## Exercise 3: Maximum and Minimum in an Array
**Difficulty:** Basic
**Concepts:** arrays, `for` loops, comparisons

Find the largest and smallest values in an integer array.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int numbers[] = {45, 12, 78, 34, 89, 23};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int max = numbers[0];
    int min = numbers[0];

    for (int i = 1; i < size; i++) {
        if (numbers[i] > max) max = numbers[i];
        if (numbers[i] < min) min = numbers[i];
    }

    printf("Max: %d, Min: %d\n", max, min);
    return 0;
}
```

**Task:** Also compute the sum and average (as a `float`) of the array.

## Exercise 4: Simple Calculator
**Difficulty:** Basic
**Concepts:** `switch`, arithmetic operators, `scanf`

Build a calculator that reads two numbers and an operator and prints the result.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    double a, b;
    char op;

    printf("Enter expression (e.g. 10 + 5): ");
    scanf("%lf %c %lf", &a, &op, &b);

    switch (op) {
        case '+': printf("%.2f\n", a + b); break;
        case '-': printf("%.2f\n", a - b); break;
        case '*': printf("%.2f\n", a * b); break;
        case '/':
            if (b != 0) printf("%.2f\n", a / b);
            else printf("Cannot divide by zero\n");
            break;
        default: printf("Invalid operator\n");
    }
    return 0;
}
```

**Task:** Add a `%` case using `(int)a % (int)b` for integer operands.

## Exercise 5: Print Prime Numbers in a Range
**Difficulty:** Basic
**Concepts:** nested loops, `break`, boolean flags

Print every prime number between two given bounds (e.g. 10 and 50).

**Starter code:**
```c
#include <stdio.h>
#include <stdbool.h>

int main(void) {
    int start = 10, end = 50;

    for (int num = start; num <= end; num++) {
        bool isPrime = num >= 2;
        for (int i = 2; i * i <= num; i++) {
            if (num % i == 0) {
                isPrime = false;
                break;
            }
        }
        if (isPrime) printf("%d ", num);
    }
    printf("\n");
    return 0;
}
```

**Task:** Extract the check into a `bool is_prime(int n)` function and count the primes printed.
