## Exercise 1: Hello World

**Difficulty:** Basic

### Problem
Write a C program that prints "Hello, World!" and then prints the values of an integer and a float variable.

**Expected Output:**
```
Hello, World!
Number: 42, Pi: 3.14
```

### Concepts
- `#include <stdio.h>`
- `main()` function
- `printf()` with format specifiers (`%d`, `%f`)

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int number = 42;
    float pi = 3.14f;

    printf("Hello, World!\n");
    printf("Number: %d, Pi: %.2f\n", number, pi);

    return 0;
}
```

## Exercise 2: Even or Odd

**Difficulty:** Basic

### Problem
Write a C program that reads an integer and prints whether it is even or odd.

**Given Input:** `7`

**Expected Output:**
```
Enter a number: 7
7 is Odd
```

### Concepts
- `scanf()` for input
- `if`/`else` and the modulo operator `%`

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int number;

    printf("Enter a number: ");
    scanf("%d", &number);

    if (number % 2 == 0) {
        printf("%d is Even\n", number);
    } else {
        printf("%d is Odd\n", number);
    }

    return 0;
}
```

## Exercise 3: Sum of Numbers 1 to N

**Difficulty:** Basic

### Problem
Write a C program that reads a positive integer `n` and prints the sum of all integers from 1 to `n`.

**Given Input:** `10`

**Expected Output:**
```
Sum from 1 to 10 is 55
```

### Concepts
- `for` loop
- Accumulator variable

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int n, total = 0;

    printf("Enter a positive integer: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++) {
        total += i;
    }

    printf("Sum from 1 to %d is %d\n", n, total);

    return 0;
}
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a C program that counts the vowels (a, e, i, o, u) in a string, ignoring case.

**Given Input:** `"Hello World"`

**Expected Output:**
```
Number of vowels: 3
```

### Concepts
- Character arrays (strings)
- `strlen()` from `<string.h>`
- `tolower()` from `<ctype.h>`

### Example / Starter Code

```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    char text[] = "Hello World";
    int count = 0;

    for (int i = 0; i < strlen(text); i++) {
        char c = tolower(text[i]);
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            count++;
        }
    }

    printf("Number of vowels: %d\n", count);

    return 0;
}
```

## Exercise 5: Sum and Average of an Array

**Difficulty:** Basic

### Problem
Write a C program that computes the sum and average of the elements in an integer array.

**Given Input:** `{10, 20, 30, 40, 50}`

**Expected Output:**
```
Sum: 150, Average: 30.00
```

### Concepts
- Arrays
- `for` loop traversal
- Integer vs floating-point division

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int sum = 0;

    for (int i = 0; i < size; i++) {
        sum += numbers[i];
    }

    float average = (float)sum / size;

    printf("Sum: %d, Average: %.2f\n", sum, average);

    return 0;
}
```
