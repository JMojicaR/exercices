## Exercise 1: Fibonacci Series
**Difficulty:** Basic
**Concepts:** Loops, Arithmetic, Variables

Print the first `n` Fibonacci numbers, where each number after the first two is the sum of the two preceding ones (0, 1, 1, 2, 3, 5, ...).

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n = 10;
    int a = 0, b = 1, next;

    printf("%d %d ", a, b);
    for (int i = 3; i <= n; i++) {
        next = a + b;
        printf("%d ", next);
        a = b;
        b = next;
    }
    printf("\n");
    return 0;
}
```

**Task:** Modify the program to ask the user for `n` and print the Fibonacci numbers separated by commas.

## Exercise 2: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** Variables, Temporary Variable, Assignment

Read two integers and exchange their values so that the first variable holds the second's original value and vice versa.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int x = 5, y = 10;

    printf("Before swap: x = %d, y = %d\n", x, y);

    int temp = x;
    x = y;
    y = temp;

    printf("After swap: x = %d, y = %d\n", x, y);
    return 0;
}
```

**Task:** Rewrite the swap so it works without using a temporary variable, then have the user enter both values.

## Exercise 3: Leap Year Check
**Difficulty:** Basic
**Concepts:** Conditionals, Modulo, Logical Operators

Determine whether a given year is a leap year. A year is a leap year if it is divisible by 4, but century years must also be divisible by 400.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int year = 2026;

    if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
        printf("%d is a leap year.\n", year);
    } else {
        printf("%d is not a leap year.\n", year);
    }
    return 0;
}
```

**Task:** Ask the user for a year and print the result for several years entered one after another.

## Exercise 4: Sum of Digits
**Difficulty:** Basic
**Concepts:** Loops, Modulo, Integer Division

Compute the sum of the individual digits of a positive integer (e.g. 1234 gives 1 + 2 + 3 + 4 = 10).

**Starter code:**
```c
#include <stdio.h>

int main() {
    int num = 1234;
    int sum = 0;

    while (num != 0) {
        sum += num % 10;
        num /= 10;
    }

    printf("Sum of digits = %d\n", sum);
    return 0;
}
```

**Task:** Also count how many digits the number has, and read the number from the user.

## Exercise 5: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** Conditionals, Comparison, Nested if-else

Find and print the largest of three integers.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int a = 12, b = 25, c = 9;
    int largest = a;

    if (b > largest) {
        largest = b;
    }
    if (c > largest) {
        largest = c;
    }

    printf("The largest number is %d\n", largest);
    return 0;
}
```

**Task:** Extend the program to also find the smallest of the three numbers and read all three values from the user.
