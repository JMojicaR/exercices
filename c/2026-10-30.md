## Exercise 1: Linear Search
**Difficulty:** Basic
**Concepts:** `for` loop, array indexing, function parameters (array + size), comparison

Write a function that searches for a target value in an array and returns its index, or `-1` if not found.

**Starter code:**
```c
#include <stdio.h>

int linear_search(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) {
            return i;
        }
    }
    return -1;
}

int main(void) {
    int numbers[] = {10, 23, 45, 70, 11, 15};
    int n = sizeof(numbers) / sizeof(numbers[0]);
    printf("%d\n", linear_search(numbers, n, 70)); // expected: 3
    printf("%d\n", linear_search(numbers, n, 99)); // expected: -1
    return 0;
}
```

**Task:** Modify the function to print each element it checks before returning, so you can watch the search proceed.

## Exercise 2: Binary Search
**Difficulty:** Basic
**Concepts:** `while` loop, midpoint index, sorted input, integer arithmetic

Search for a target in a *sorted* array using binary search, halving the search range each step.

**Starter code:**
```c
#include <stdio.h>

int binary_search(int arr[], int n, int target) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] == target) return mid;
        if (arr[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}

int main(void) {
    int sorted[] = {1, 3, 5, 7, 9, 11, 13};
    int n = sizeof(sorted) / sizeof(sorted[0]);
    printf("%d\n", binary_search(sorted, n, 9)); // expected: 4
    printf("%d\n", binary_search(sorted, n, 4)); // expected: -1
    return 0;
}
```

**Task:** Print `low`, `high`, and `mid` at the start of each iteration to visualize how the range shrinks.

## Exercise 3: Bubble Sort
**Difficulty:** Basic
**Concepts:** nested `for` loops, swapping with a temp variable, comparison operators

Sort an array in ascending order using bubble sort (repeatedly swap adjacent out-of-order elements).

**Starter code:**
```c
#include <stdio.h>

void bubble_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

int main(void) {
    int data[] = {64, 34, 25, 12, 22, 11, 90};
    int n = sizeof(data) / sizeof(data[0]);
    bubble_sort(data, n);
    for (int i = 0; i < n; i++) printf("%d ", data[i]);
    printf("\n"); // expected: 11 12 22 25 34 64 90
    return 0;
}
```

**Task:** Add an `int swapped` flag that stops early when a full pass makes no swaps, and print how many passes ran.

## Exercise 4: Find Minimum and Maximum
**Difficulty:** Basic
**Concepts:** iteration, comparison, output parameters via pointers, edge cases

Find the smallest and largest values in an array in a single pass, storing results through pointers.

**Starter code:**
```c
#include <stdio.h>

void find_min_max(int arr[], int n, int *min, int *max) {
    if (n <= 0) return;
    *min = *max = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] < *min) *min = arr[i];
        if (arr[i] > *max) *max = arr[i];
    }
}

int main(void) {
    int nums[] = {45, 2, 78, 13, 9, 54};
    int n = sizeof(nums) / sizeof(nums[0]);
    int min, max;
    find_min_max(nums, n, &min, &max);
    printf("Min: %d Max: %d\n", min, max); // Min: 2 Max: 78
    return 0;
}
```

**Task:** Also return the *index* of the min and max elements through two more pointer parameters.

## Exercise 5: Selection Sort
**Difficulty:** Basic
**Concepts:** nested loops, index tracking, swapping, finding the minimum in a sub-range

Sort an array using selection sort: repeatedly find the smallest remaining element and move it to the front.

**Starter code:**
```c
#include <stdio.h>

void selection_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min_idx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[min_idx]) min_idx = j;
        }
        int temp = arr[i];
        arr[i] = arr[min_idx];
        arr[min_idx] = temp;
    }
}

int main(void) {
    int data[] = {29, 10, 14, 37, 13};
    int n = sizeof(data) / sizeof(data[0]);
    selection_sort(data, n);
    for (int i = 0; i < n; i++) printf("%d ", data[i]);
    printf("\n"); // expected: 10 13 14 29 37
    return 0;
}
```

**Task:** Sort in *descending* order by changing a single comparison, and skip the swap when `min_idx == i`.
