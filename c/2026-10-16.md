## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** arrays, strings, loops, strlen

Read a string and print it reversed.

**Starter code:**
```c
#include <stdio.h>
#include <string.h>

int main() {
    char str[100];
    printf("Enter a string: ");
    fgets(str, sizeof(str), stdin);
    str[strcspn(str, "\n")] = '\0';

    int len = strlen(str);
    printf("Reversed: ");
    for (int i = len - 1; i >= 0; i--) {
        putchar(str[i]);
    }
    printf("\n");
    return 0;
}
```

**Task:** Reverse the string in place by swapping characters with two indexes.

## Exercise 2: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** conditionals, scanf, comparisons

Read three numbers and print the largest.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int a, b, c;
    printf("Enter three numbers: ");
    scanf("%d %d %d", &a, &b, &c);

    int largest = a;
    if (b > largest) largest = b;
    if (c > largest) largest = c;

    printf("Largest: %d\n", largest);
    return 0;
}
```

**Task:** Also print the smallest of the three numbers.

## Exercise 3: Multiplication Table
**Difficulty:** Basic
**Concepts:** for loop, printf

Print the multiplication table (1 to 10) for a given number.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);

    for (int i = 1; i <= 10; i++) {
        printf("%d x %d = %d\n", n, i, n * i);
    }
    return 0;
}
```

**Task:** Print the table in reverse order (from 10 down to 1).

## Exercise 4: Armstrong Number
**Difficulty:** Basic
**Concepts:** while loop, modulo, pow, digit counting

Check whether a number is an Armstrong number.

**Starter code:**
```c
#include <stdio.h>
#include <math.h>

int main() {
    int n, original, remainder, digits = 0;
    double sum = 0.0;

    printf("Enter a positive integer: ");
    scanf("%d", &n);
    original = n;

    for (int temp = n; temp != 0; temp /= 10) {
        digits++;
    }

    for (int temp = n; temp != 0; temp /= 10) {
        remainder = temp % 10;
        sum += pow(remainder, digits);
    }

    if ((int)sum == original) {
        printf("%d is an Armstrong number\n", original);
    } else {
        printf("%d is not an Armstrong number\n", original);
    }
    return 0;
}
```

**Task:** Print all Armstrong numbers between 1 and 1000.

## Exercise 5: Count Digits in a Number
**Difficulty:** Basic
**Concepts:** while loop, integer division, counting

Count the digits of an integer.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, count = 0;
    printf("Enter an integer: ");
    scanf("%d", &n);

    if (n == 0) {
        count = 1;
    } else {
        while (n != 0) {
            n /= 10;
            count++;
        }
    }

    printf("Number of digits: %d\n", count);
    return 0;
}
```

**Task:** Count the digits of a negative number correctly (ignoring the sign).
