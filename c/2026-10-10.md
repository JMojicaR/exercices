## Exercise 1: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** loops, variables, stdio

Print the first `n` numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...).

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, a = 0, b = 1, next;
    printf("How many Fibonacci numbers? ");
    scanf("%d", &n);

    for (int i = 0; i < n; i++) {
        printf("%d ", a);
        next = a + b;
        a = b;
        b = next;
    }
    printf("\n");
    return 0;
}
```

**Task:** Print only the Fibonacci numbers below a user-specified limit.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** if/else, modulo, scanf/printf

Read an integer and print whether it is even or odd.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n;
    printf("Enter an integer: ");
    scanf("%d", &n);

    if (n % 2 == 0)
        printf("%d is even\n", n);
    else
        printf("%d is odd\n", n);
    return 0;
}
```

**Task:** Read several numbers in a loop until the user enters 0, classifying each one.

## Exercise 3: Sum of Digits
**Difficulty:** Basic
**Concepts:** while loop, modulo, integer division

Compute the sum of the digits of a positive integer (e.g. 1234 → 10).

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, sum = 0;
    printf("Enter a positive integer: ");
    scanf("%d", &n);

    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }
    printf("Sum of digits: %d\n", sum);
    return 0;
}
```

**Task:** Also print the number of digits and the product of the digits.

## Exercise 4: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** variables, temporary variable

Read two numbers and swap their values, printing the result before and after.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int a, b, temp;
    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    printf("Before: a = %d, b = %d\n", a, b);
    temp = a;
    a = b;
    b = temp;
    printf("After:  a = %d, b = %d\n", a, b);
    return 0;
}
```

**Task:** Swap two numbers without using a temporary variable (using addition/subtraction or XOR).

## Exercise 5: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** nested if/else, comparison operators

Read three numbers and print the largest.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int a, b, c, largest;
    printf("Enter three numbers: ");
    scanf("%d %d %d", &a, &b, &c);

    largest = a;
    if (b > largest) largest = b;
    if (c > largest) largest = c;

    printf("Largest: %d\n", largest);
    return 0;
}
```

**Task:** Also print the smallest, and sort the three numbers in ascending order.
