## Exercise 1: Hello, Name!
**Difficulty:** Basic
**Concepts:** `printf`, `scanf`, strings (char arrays), standard I/O.

Write a program that asks the user for their name and prints a greeting.

**Starter code:**
```c
#include <stdio.h>

int main() {
    char name[50];
    printf("Enter your name: ");
    scanf("%s", name);
    printf("Hello, %s!\n", name);
    return 0;
}
```

**Task:** Use `fgets` instead of `scanf` so names with spaces work correctly.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** Modulo (`%`), `if`/`else`, input.

Write a program that reads an integer and prints whether it is even or odd.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);
    if (n % 2 == 0)
        printf("%d is even\n", n);
    else
        printf("%d is odd\n", n);
    return 0;
}
```

**Task:** Use the ternary operator `(n % 2 == 0) ? ... : ...` instead of `if`/`else`.

## Exercise 3: Sum of Natural Numbers
**Difficulty:** Basic
**Concepts:** Loops (`for`), accumulator variables.

Write a program that reads `n` and prints the sum of natural numbers from 1 to `n`.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, sum = 0;
    printf("Enter n: ");
    scanf("%d", &n);
    for (int i = 1; i <= n; i++)
        sum += i;
    printf("Sum 1..%d = %d\n", n, sum);
    return 0;
}
```

**Task:** Solve it using the closed formula `n * (n + 1) / 2` and verify both approaches agree.

## Exercise 4: Positive, Negative, or Zero
**Difficulty:** Basic
**Concepts:** `if`/`else if`/`else`, relational operators.

Write a program that reads a number and reports whether it is positive, negative, or zero.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);
    if (n > 0)
        printf("Positive\n");
    else if (n < 0)
        printf("Negative\n");
    else
        printf("Zero\n");
    return 0;
}
```

**Task:** Repeat the check for five inputs using a `for` loop.

## Exercise 5: Largest Element in an Array
**Difficulty:** Basic
**Concepts:** Arrays, `sizeof`, loops, comparison.

Write a program that finds the largest value in an integer array.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int arr[] = {3, 7, 2, 9, 5};
    int size = sizeof(arr) / sizeof(arr[0]);
    int largest = arr[0];
    for (int i = 1; i < size; i++)
        if (arr[i] > largest)
            largest = arr[i];
    printf("Largest: %d\n", largest);
    return 0;
}
```

**Task:** Also compute the sum and average of the array elements.
