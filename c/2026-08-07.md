## Exercise 1: Hello, Input/Output
**Difficulty:** ★☆☆☆☆  
**Concepts:** `printf()`, `scanf()`, variables, data types

### Description
Write a C program that asks the user for two integers, computes their sum, difference, product, quotient, and remainder, and prints all results in a formatted way.

### Starter Code
```c
#include <stdio.h>

int main() {
    int a, b;

    printf("Enter first number: ");
    scanf("%d", &a);
    printf("Enter second number: ");
    scanf("%d", &b);

    // Your code here — compute and print sum, difference, product, quotient, remainder

    return 0;
}
```

## Exercise 5: Pointer Basics — Swap Two Numbers
**Difficulty:** ★★☆☆☆  
**Concepts:** Pointers, pass-by-reference, function parameters

### Description
Write a function `void swap(int *a, int *b)` that swaps the values of two integers using pointers. In `main()`, declare two variables, print them before and after calling `swap()`.

### Starter Code
```c
#include <stdio.h>

void swap(int *a, int *b) {
    // Your code here
}

int main() {
    int x = 5, y = 10;
    printf("Before swap: x = %d, y = %d\n", x, y);
    swap(&x, &y);
    printf("After swap:  x = %d, y = %d\n", x, y);
    // Expected: x = 10, y = 5
    return 0;
}
```
