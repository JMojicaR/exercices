## Exercise 1: Print a Right-Angled Triangle of Stars
**Difficulty:** Basic
**Concepts:** nested `for` loops, `scanf()`, `printf()`

Print a right-angled triangle of `*` where the number of rows is user-supplied.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int rows;
    printf("Enter number of rows: ");
    scanf("%d", &rows);

    for (int i = 1; i <= rows; i++) {
        for (int j = 1; j <= i; j++) {
            printf("*");
        }
        printf("\n");
    }
    return 0;
}
```

**Task:** Print an inverted triangle instead, then print numbers (`1`, `22`, `333`, …) using the same nested-loop structure.

## Exercise 2: Print Floyd's Triangle
**Difficulty:** Basic
**Concepts:** nested loops, running counter, `printf`

Print Floyd's triangle — consecutive numbers arranged in rows of increasing length.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int rows, num = 1;
    printf("Enter number of rows: ");
    scanf("%d", &rows);

    for (int i = 1; i <= rows; i++) {
        for (int j = 1; j <= i; j++) {
            printf("%d ", num);
            num++;
        }
        printf("\n");
    }
    return 0;
}
```

**Task:** Right-align the triangle with leading spaces, and start the counter at a user-supplied value.

## Exercise 3: Count Uppercase and Lowercase Letters
**Difficulty:** Basic
**Concepts:** `char`, `<ctype.h>` (`isupper()` / `islower()`), `fgets()`

Count how many uppercase and lowercase letters a string contains.

**Starter code:**
```c
#include <stdio.h>
#include <ctype.h>

int main() {
    char text[200];
    printf("Enter a string: ");
    fgets(text, sizeof(text), stdin);

    int upper = 0, lower = 0;
    for (int i = 0; text[i] != '\0'; i++) {
        if (isupper(text[i])) upper++;
        else if (islower(text[i])) lower++;
    }

    printf("Uppercase: %d, Lowercase: %d\n", upper, lower);
    return 0;
}
```

**Task:** Also count digits (`isdigit()`) and whitespace (`isspace()`), and print a full breakdown.

## Exercise 4: Remove All Spaces from a String
**Difficulty:** Basic
**Concepts:** character arrays, index tracking, null terminator

Remove every space from an input string and print the result (in place).

**Starter code:**
```c
#include <stdio.h>

int main() {
    char text[200];
    printf("Enter a string: ");
    fgets(text, sizeof(text), stdin);

    int j = 0;
    for (int i = 0; text[i] != '\0'; i++) {
        if (text[i] != ' ') {
            text[j++] = text[i];
        }
    }
    text[j] = '\0';

    printf("Without spaces: %s\n", text);
    return 0;
}
```

**Task:** Also strip tabs and newlines by checking with `isspace()` from `<ctype.h>`.

## Exercise 5: Find the Largest Digit in a Number
**Difficulty:** Basic
**Concepts:** `%` and `/`, `while` loop, max tracking

Read a whole number and print its largest single digit.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int num, largest = 0;
    printf("Enter a number: ");
    scanf("%d", &num);

    while (num > 0) {
        int digit = num % 10;
        if (digit > largest) largest = digit;
        num /= 10;
    }

    printf("Largest digit: %d\n", largest);
    return 0;
}
```

**Task:** Also find the smallest digit, and handle negative input using `abs()` from `<stdlib.h>`.
