## Exercise 1: Write Text to a File
**Difficulty:** Basic
**Concepts:** `fopen` with `"w"` mode, `fprintf`, `fclose`, checking for `NULL`

Write a program that creates a file named `notes.txt` and writes two lines into it. Always check that `fopen` didn't return `NULL` and close the file with `fclose`.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("notes.txt", "w");
    if (fp == NULL) {
        printf("Could not open file.\n");
        return 1;
    }
    fprintf(fp, "First line\n");
    fprintf(fp, "Second line\n");
    fclose(fp);
    printf("File written.\n");
    return 0;
}
```

**Task:** Write the numbers 1 through 5, one per line, using a `for` loop and `fprintf(fp, "%d\n", i);`.

## Exercise 2: Read a File Character by Character
**Difficulty:** Basic
**Concepts:** `fopen` with `"r"` mode, `fgetc`, `EOF`, `putchar`

Write a program that opens `notes.txt` and prints its contents to the screen one character at a time.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("notes.txt", "r");
    if (fp == NULL) {
        printf("Could not open file.\n");
        return 1;
    }
    int ch;
    while ((ch = fgetc(fp)) != EOF) {
        putchar(ch);
    }
    fclose(fp);
    return 0;
}
```

**Task:** Rewrite it with `fgets(buffer, sizeof(buffer), fp)` to read a whole line at a time, and print each line with `fputs`.

## Exercise 3: Append a Line to a File
**Difficulty:** Basic
**Concepts:** `fopen` with `"a"` (append) mode, preserving existing content

Write a program that adds a new line to the end of `notes.txt` without deleting what is already there.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("notes.txt", "a");
    if (fp == NULL) {
        printf("Could not open file.\n");
        return 1;
    }
    fprintf(fp, "Appended line\n");
    fclose(fp);
    printf("Appended.\n");
    return 0;
}
```

**Task:** Append the numbers 1 through 5 in a loop, then read the file back to confirm the original lines are still present.

## Exercise 4: Count Lines in a File
**Difficulty:** Basic
**Concepts:** `fgets`, line counting, buffers

Write a program that opens `notes.txt` and counts how many lines it contains.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("notes.txt", "r");
    if (fp == NULL) {
        printf("Could not open file.\n");
        return 1;
    }
    char buffer[256];
    int lines = 0;
    while (fgets(buffer, sizeof(buffer), fp) != NULL) {
        lines++;
    }
    fclose(fp);
    printf("Lines: %d\n", lines);
    return 0;
}
```

**Task:** Also count the total number of characters by summing `strlen(buffer)` (include `<string.h>`). Then count how many words by splitting each line on spaces.

## Exercise 5: Copy a File
**Difficulty:** Basic
**Concepts:** opening two files at once, `fgetc`/`fputc` loop, reading and writing

Write a program that copies the contents of `notes.txt` into a new file named `notes_copy.txt`.

**Starter code:**
```c
#include <stdio.h>

int main(void) {
    FILE *src = fopen("notes.txt", "r");
    FILE *dst = fopen("notes_copy.txt", "w");
    if (src == NULL || dst == NULL) {
        printf("Could not open files.\n");
        return 1;
    }
    int ch;
    while ((ch = fgetc(src)) != EOF) {
        fputc(ch, dst);
    }
    fclose(src);
    fclose(dst);
    printf("Copied.\n");
    return 0;
}
```

**Task:** Copy line-by-line using `fgets`/`fputs` instead of character-by-character, and print each line to the screen as it is copied.
