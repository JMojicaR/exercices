## Exercise 1: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** Variables, `printf`/`scanf`, temporary variable, pointer-free swap.

Write a program that swaps two integer values using a temporary variable.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int a, b, temp;

    printf("Enter a: ");
    scanf("%d", &a);
    printf("Enter b: ");
    scanf("%d", &b);

    temp = a;
    a = b;
    b = temp;

    printf("After swap: a = %d, b = %d\n", a, b);
    return 0;
}
```

**Task:** Implement a second swap using only arithmetic (`a = a + b; b = a - b; a = a - b;`) and compare.

## Exercise 2: Count Digits in an Integer
**Difficulty:** Basic
**Concepts:** Loops, integer division, `while`, counting.

Write a program that counts how many digits are in a user-entered integer.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, count = 0;

    printf("Enter an integer: ");
    scanf("%d", &n);

    int num = n < 0 ? -n : n; // handle negatives
    do {
        count++;
        num /= 10;
    } while (num != 0);

    printf("Digits in %d: %d\n", n, count);
    return 0;
}
```

**Task:** Extend the program to also print the sum of the digits (e.g., 123 → 6).

## Exercise 3: Fibonacci Series
**Difficulty:** Basic
**Concepts:** Loops, variable swapping, sequence generation.

Write a program that prints the first `n` Fibonacci numbers.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, a = 0, b = 1, next;

    printf("How many terms? ");
    scanf("%d", &n);

    for (int i = 0; i < n; i++) {
        printf("%d ", a);
        next = a + b;
        a = b;
        b = next;
    }
    printf("\n");
    return 0;
}
```

**Task:** Store the values in an `int` array and print them in reverse order.

## Exercise 4: Vowel or Consonant (switch)
**Difficulty:** Basic
**Concepts:** `switch` statement, characters, `scanf` with ` %c`, `tolower()`.

Write a program that reads a single letter and reports whether it is a vowel or a consonant.

**Starter code:**
```c
#include <stdio.h>
#include <ctype.h>

int main() {
    char ch;

    printf("Enter a letter: ");
    scanf(" %c", &ch);
    ch = tolower(ch);

    switch (ch) {
        case 'a': case 'e': case 'i': case 'o': case 'u':
            printf("%c is a vowel.\n", ch);
            break;
        default:
            printf("%c is a consonant.\n", ch);
    }
    return 0;
}
```

**Task:** Add a check so non-letter characters (digits, punctuation) print "Not a letter".

## Exercise 5: GCD of Two Numbers
**Difficulty:** Basic
**Concepts:** Loops, modulus, Euclid's algorithm, functions.

Write a program that finds the greatest common divisor (GCD) of two positive integers.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int a, b;

    printf("Enter two positive integers: ");
    scanf("%d %d", &a, &b);

    int x = a, y = b;
    while (y != 0) {
        int r = x % y;
        x = y;
        y = r;
    }

    printf("GCD(%d, %d) = %d\n", a, b, x);
    return 0;
}
```

**Task:** Move the GCD logic into a function `int gcd(int a, int b)` and call it from `main`.
