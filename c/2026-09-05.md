## 2. Even or Odd
- **Description**: Read an integer from the user and print whether it is even or odd.
- **Difficulty**: Beginner
- **Concepts**: `scanf()`, `%` operator, `if/else`
- **Example/Starter code**:
```c
#include <stdio.h>

int main() {
    int number;
    printf("Enter a number: ");
    scanf("%d", &number);
    if (number % 2 == 0) {
        printf("%d is even\n", number);
    } else {
        printf("%d is odd\n", number);
    }
    return 0;
}
```

## 3. Sum of First N Numbers
- **Description**: Take a positive integer N and print the sum of all integers from 1 to N.
- **Difficulty**: Beginner
- **Concepts**: `for` loops, accumulation, `scanf()`
- **Example/Starter code**:
```c
#include <stdio.h>

int main() {
    int n, sum = 0;
    printf("Enter a positive integer: ");
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    printf("Sum from 1 to %d is %d\n", n, sum);
    return 0;
}
```

## 4. Factorial
- **Description**: Write a program that computes the factorial of a non-negative integer n.
- **Difficulty**: Beginner
- **Concepts**: `for` loops, accumulation
- **Example/Starter code**:
```c
#include <stdio.h>

int main() {
    int n;
    long long result = 1;
    printf("Enter a number: ");
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
    printf("Factorial of %d is %lld\n", n, result);
    return 0;
}
```

## 5. Reverse a String
- **Description**: Read a string from the user and print it in reverse order.
- **Difficulty**: Beginner
- **Concepts**: Character arrays, `strlen()`, loops
- **Example/Starter code**:
```c
#include <stdio.h>
#include <string.h>

int main() {
    char str[100];
    printf("Enter a string: ");
    scanf("%s", str);
    int len = strlen(str);
    printf("Reversed: ");
    for (int i = len - 1; i >= 0; i--) {
        printf("%c", str[i]);
    }
    printf("\n");
    return 0;
}
```
