## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** character arrays, `strlen()`, in-place swapping, `for` loop

Reverse a string in place by swapping characters from the two ends.

**Starter code:**
```c
#include <stdio.h>
#include <string.h>

void reverse_string(char str[]) {
    int n = strlen(str);
    for (int i = 0; i < n / 2; i++) {
        char temp = str[i];
        str[i] = str[n - 1 - i];
        str[n - 1 - i] = temp;
    }
}

int main(void) {
    char s[] = "hello";
    reverse_string(s);
    printf("%s\n", s);  // expected: olleh
    return 0;
}
```

**Task:** Write a version that writes the reversed string into a *separate* output buffer instead of modifying the input.

## Exercise 2: Check Palindrome
**Difficulty:** Basic
**Concepts:** `strlen()`, `tolower()`, two-pointer comparison, `int` return for true/false

Check whether a string reads the same forwards and backwards (ignoring case).

**Starter code:**
```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int is_palindrome(const char str[]) {
    int n = strlen(str);
    for (int i = 0; i < n / 2; i++) {
        if (tolower(str[i]) != tolower(str[n - 1 - i])) {
            return 0;
        }
    }
    return 1;
}

int main(void) {
    printf("%d\n", is_palindrome("Radar"));  // expected: 1 (true)
    printf("%d\n", is_palindrome("hello"));  // expected: 0 (false)
    return 0;
}
```

**Task:** Ignore spaces and punctuation so `"A man, a plan, a canal: Panama"` returns `1`.

## Exercise 3: Count Vowels
**Difficulty:** Basic
**Concepts:** null-terminated string iteration, `tolower()`, `switch` or `||`, counter

Count how many vowels (a, e, i, o, u) appear in a string, case-insensitively.

**Starter code:**
```c
#include <stdio.h>
#include <ctype.h>

int count_vowels(const char str[]) {
    int count = 0;
    for (int i = 0; str[i] != '\0'; i++) {
        char c = tolower(str[i]);
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            count++;
        }
    }
    return count;
}

int main(void) {
    printf("%d\n", count_vowels("hello world"));  // expected: 3
    return 0;
}
```

**Task:** Also count consonants and print both totals.

## Exercise 4: Count Character Occurrences
**Difficulty:** Basic
**Concepts:** string iteration, `char` parameters, null terminator, counter

Count how many times a given character appears in a string.

**Starter code:**
```c
#include <stdio.h>

int count_char(const char str[], char ch) {
    int count = 0;
    for (int i = 0; str[i] != '\0'; i++) {
        if (str[i] == ch) {
            count++;
        }
    }
    return count;
}

int main(void) {
    printf("%d\n", count_char("banana", 'a'));  // expected: 3
    return 0;
}
```

**Task:** Make the search case-insensitive using `tolower()` on both characters.

## Exercise 5: Count Words
**Difficulty:** Basic
**Concepts:** whitespace detection (`' '`, `'\t'`, `'\n'`), in-word state flag, loops

Count the number of words in a sentence, where words are separated by whitespace.

**Starter code:**
```c
#include <stdio.h>

int count_words(const char str[]) {
    int count = 0;
    int in_word = 0;
    for (int i = 0; str[i] != '\0'; i++) {
        if (str[i] == ' ' || str[i] == '\t' || str[i] == '\n') {
            in_word = 0;
        } else if (!in_word) {
            in_word = 1;
            count++;
        }
    }
    return count;
}

int main(void) {
    printf("%d\n", count_words("I love programming"));  // expected: 3
    return 0;
}
```

**Task:** Print each word on its own line as you count them.
