## 1. Even or Odd Checker
**Description:** Read an integer and print whether it is even or odd using the modulo operator.
**Difficulty:** Basic
**Concepts:** `printf`/`scanf`, `if/else`, modulo `%`.
**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int number;
    printf("Enter a number: ");
    scanf("%d", &number);

    if (number % 2 == 0) {
        printf("%d is even\n", number);
    } else {
        printf("%d is odd\n", number);
    }
    return 0;
}
```

## 2. Sum of Digits
**Description:** Given a positive integer, compute the sum of its digits with a loop (e.g. 123 → 6).
**Difficulty:** Basic
**Concepts:** `while` loop, modulo `%`, integer division.
**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int num, sum = 0;
    printf("Enter a number: ");
    scanf("%d", &num);

    while (num > 0) {
        sum += num % 10;
        num /= 10;
    }
    printf("Sum of digits: %d\n", sum);
    return 0;
}
```

## 3. Largest Element in an Array
**Description:** Fill an array with values from the user (or a fixed list) and find the largest element.
**Difficulty:** Basic
**Concepts:** Arrays, `for` loop, indexing, comparison.
**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int arr[5];
    int i, max;

    printf("Enter 5 integers:\n");
    for (i = 0; i < 5; i++) {
        scanf("%d", &arr[i]);
    }

    max = arr[0];
    for (i = 1; i < 5; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    printf("Largest element: %d\n", max);
    return 0;
}
```

## 4. Reverse a String
**Description:** Read a string and print it in reverse using a character array and `strlen()`.
**Difficulty:** Basic
**Concepts:** `char[]`, `strlen()`, `for` loop, null terminator.
**Starter code:**
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char str[100];
    printf("Enter a string: ");
    scanf("%99s", str);

    for (int i = (int)strlen(str) - 1; i >= 0; i--) {
        putchar(str[i]);
    }
    putchar('\n');
    return 0;
}
```

## 5. Fibonacci Series
**Description:** Print the first N terms of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...) using a loop.
**Difficulty:** Basic
**Concepts:** `for` loop, variable swapping, `scanf`.
**Starter code:**
```c
#include <stdio.h>

int main(void) {
    int n, a = 0, b = 1, next;
    printf("How many terms? ");
    scanf("%d", &n);

    for (int i = 0; i < n; i++) {
        printf("%d ", a);
        next = a + b;
        a = b;
        b = next;
    }
    printf("\n");
    return 0;
}
```
