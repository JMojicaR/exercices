## Exercise 1: Create and Print a Matrix
**Difficulty:** Basic
**Concepts:** 2D arrays, nested `for` loops, `printf`

Declare a 2D array and print it row by row.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int matrix[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };
    int rows = 3, cols = 3;

    printf("Matrix:\n");
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            printf("%d ", matrix[i][j]);
        }
        printf("\n");
    }
    return 0;
}
```

**Task:** Read the matrix values from the user with `scanf`, then print only the last row and last column.

## Exercise 2: Matrix Addition
**Difficulty:** Basic
**Concepts:** 2D arrays, element-wise addition

Add two matrices and print the result.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int a[2][2] = {{1, 2}, {3, 4}};
    int b[2][2] = {{5, 6}, {7, 8}};
    int result[2][2];
    int rows = 2, cols = 2;

    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            result[i][j] = a[i][j] + b[i][j];
        }
    }

    printf("Sum matrix:\n");
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            printf("%d ", result[i][j]);
        }
        printf("\n");
    }
    return 0;
}
```

**Task:** Compute the subtraction (`a - b`) and read both matrices from the user instead of hard-coding them.

## Exercise 3: Matrix Transpose
**Difficulty:** Basic
**Concepts:** row/column swapping, flipped-size array

Transpose a matrix (swap rows and columns).

**Starter code:**
```c
#include <stdio.h>

int main() {
    int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int rows = 2, cols = 3;
    int transpose[3][2];

    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            transpose[j][i] = matrix[i][j];
        }
    }

    printf("Transpose:\n");
    for (int i = 0; i < cols; i++) {
        for (int j = 0; j < rows; j++) {
            printf("%d ", transpose[i][j]);
        }
        printf("\n");
    }
    return 0;
}
```

**Task:** Move the transpose logic into a function `void transpose(int src[][3], int dst[][2], int rows, int cols)`.

## Exercise 4: Sum of the Main Diagonal
**Difficulty:** Basic
**Concepts:** square matrices, single loop, index tracking

Sum the main diagonal (top-left to bottom-right) of a square matrix.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int matrix[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
    int n = 3;
    int total = 0;

    for (int i = 0; i < n; i++) {
        total += matrix[i][i];
    }

    printf("Sum of main diagonal: %d\n", total);
    return 0;
}
```

**Task:** Add the anti-diagonal using `matrix[i][n - 1 - i]` and print both totals.

## Exercise 5: Sum of Each Row and Each Column
**Difficulty:** Basic
**Concepts:** nested loops, running totals

Print the sum of every row and every column.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int matrix[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
    int rows = 3, cols = 3;

    printf("Row sums:\n");
    for (int i = 0; i < rows; i++) {
        int rowSum = 0;
        for (int j = 0; j < cols; j++) {
            rowSum += matrix[i][j];
        }
        printf("Row %d: %d\n", i, rowSum);
    }

    printf("Column sums:\n");
    for (int j = 0; j < cols; j++) {
        int colSum = 0;
        for (int i = 0; i < rows; i++) {
            colSum += matrix[i][j];
        }
        printf("Col %d: %d\n", j, colSum);
    }
    return 0;
}
```

**Task:** Report the grand total of all elements and the row/column with the largest sum.
