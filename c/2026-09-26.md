## Exercise 1: Add Two Integers
**Difficulty:** Basic
**Concepts:** `printf()`, `scanf()`, variables, arithmetic, `main`.

Write a program that reads two integers and prints their sum.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int a, b;

    printf("Enter two integers: ");
    scanf("%d %d", &a, &b);

    printf("Sum: %d\n", a + b);
    return 0;
}
```

**Task:** Also print the difference, product, and quotient (watch out for integer division).

## Exercise 2: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** Conditionals (`if`/`else if`/`else`), comparison operators.

Write a program that reads three numbers and prints the largest.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int a, b, c, largest;

    printf("Enter three numbers: ");
    scanf("%d %d %d", &a, &b, &c);

    largest = a;
    if (b > largest) largest = b;
    if (c > largest) largest = c;

    printf("Largest: %d\n", largest);
    return 0;
}
```

**Task:** Also find and print the smallest of the three numbers.

## Exercise 3: Factorial
**Difficulty:** Basic
**Concepts:** Loops (`for`), accumulation, `unsigned long long` for large values.

Write a program that computes the factorial of a non-negative integer.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n;
    unsigned long long result = 1;

    printf("Enter a non-negative integer: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++) {
        result *= i;
    }

    printf("%d! = %llu\n", n, result);
    return 0;
}
```

**Task:** Add a check that rejects negative input before computing the factorial.

## Exercise 4: Reverse a Number
**Difficulty:** Basic
**Concepts:** `while` loop, modulo (`%`), integer division (`/`).

Write a program that reads an integer and prints it with its digits reversed.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, reversed = 0, remainder;

    printf("Enter an integer: ");
    scanf("%d", &n);

    while (n != 0) {
        remainder = n % 10;
        reversed = reversed * 10 + remainder;
        n /= 10;
    }

    printf("Reversed: %d\n", reversed);
    return 0;
}
```

**Task:** Also print the sum of the digits of the original number.

## Exercise 5: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** Arrays, `for` loops, indexing, `sizeof` to get length.

Write a program that computes the sum and average of an array of numbers.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};
    int length = sizeof(numbers) / sizeof(numbers[0]);
    int sum = 0;

    for (int i = 0; i < length; i++) {
        sum += numbers[i];
    }

    printf("Sum: %d\n", sum);
    printf("Average: %.2f\n", (float)sum / length);
    return 0;
}
```

**Task:** Find and print the maximum element in the array.
