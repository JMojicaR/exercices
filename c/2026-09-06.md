## 1. Temperature Converter
- **Description**: Read a Celsius temperature and convert it to Fahrenheit (`F = C × 9/5 + 32`).
- **Difficulty**: Beginner
- **Concepts**: `printf`/`scanf`, `float`, arithmetic, format specifiers
- **Example/Starter code**:
```c
#include <stdio.h>

int main() {
    float celsius, fahrenheit;
    printf("Enter temperature in Celsius: ");
    scanf("%f", &celsius);
    fahrenheit = celsius * 9 / 5 + 32;
    printf("%.2f C = %.2f F\n", celsius, fahrenheit);
    return 0;
}
```

## 2. Area and Circumference of a Circle
- **Description**: Read the radius of a circle and print its area (`π·r²`) and circumference (`2·π·r`).
- **Difficulty**: Beginner
- **Concepts**: `#define` constants, `float`, arithmetic, `printf`
- **Example/Starter code**:
```c
#include <stdio.h>
#define PI 3.14159

int main() {
    float radius, area, circumference;
    printf("Enter radius: ");
    scanf("%f", &radius);
    area = PI * radius * radius;
    circumference = 2 * PI * radius;
    printf("Area = %.2f\n", area);
    printf("Circumference = %.2f\n", circumference);
    return 0;
}
```

## 3. Multiplication Table
- **Description**: Print the multiplication table (1 to 10) for a number entered by the user.
- **Difficulty**: Beginner
- **Concepts**: `for` loops, `scanf`, `printf`
- **Example/Starter code**:
```c
#include <stdio.h>

int main() {
    int n, i;
    printf("Enter a number: ");
    scanf("%d", &n);
    for (i = 1; i <= 10; i++) {
        printf("%d x %d = %d\n", n, i, n * i);
    }
    return 0;
}
```

## 4. Count the Vowels
- **Description**: Count how many vowels (`a`, `e`, `i`, `o`, `u`) appear in a string, ignoring case.
- **Difficulty**: Beginner
- **Concepts**: Character arrays, `tolower()`, `for` loops, `ctype.h`
- **Example/Starter code**:
```c
#include <stdio.h>
#include <ctype.h>

int main() {
    char text[] = "hello world";
    int count = 0;
    for (int i = 0; text[i] != '\0'; i++) {
        char c = tolower(text[i]);
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            count++;
        }
    }
    printf("Vowel count: %d\n", count);
    return 0;
}
```

## 5. Fibonacci Series
- **Description**: Print the first N numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...).
- **Difficulty**: Beginner
- **Concepts**: `for` loops, integer variables, iterative updates
- **Example/Starter code**:
```c
#include <stdio.h>

int main() {
    int n = 10, a = 0, b = 1, next, i;
    printf("%d\n", a);
    for (i = 1; i < n; i++) {
        printf("%d\n", b);
        next = a + b;
        a = b;
        b = next;
    }
    return 0;
}
```
