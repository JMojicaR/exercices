## Exercise 1: Sum of Natural Numbers

**Difficulty:** Basic

### Problem
Write a program that reads an integer `n` and prints the sum of natural numbers from `1` to `n`.

**Given Input:** `10`

**Expected Output:**
```
Sum = 55
```

### Concepts
- `scanf` for input
- `for` loop
- Accumulator variable

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int n, sum = 0;
    printf("Enter a number: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++) {
        sum += i;
    }

    printf("Sum = %d\n", sum);
    return 0;
}
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that reads three integers and prints the largest.

**Given Input:** `12 7 19`

**Expected Output:**
```
Largest = 19
```

### Concepts
- `if / else if`
- Logical operators (`&&`)
- Relational comparisons

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int a, b, c, largest;
    printf("Enter three numbers: ");
    scanf("%d %d %d", &a, &b, &c);

    if (a >= b && a >= c)
        largest = a;
    else if (b >= a && b >= c)
        largest = b;
    else
        largest = c;

    printf("Largest = %d\n", largest);
    return 0;
}
```

## Exercise 3: Simple Calculator with switch

**Difficulty:** Basic

### Problem
Write a program that reads two numbers and an operator (`+`, `-`, `*`, `/`) and prints the result using a `switch` statement.

**Given Input:** `10 5 *`

**Expected Output:**
```
Result = 50
```

### Concepts
- `switch` statement
- `scanf` with `%c` (note: skip whitespace)
- Division by zero guard

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    double a, b, result;
    char op;
    printf("Enter expression (a op b): ");
    scanf("%lf %c %lf", &a, &op, &b);

    switch (op) {
        case '+': result = a + b; break;
        case '-': result = a - b; break;
        case '*': result = a * b; break;
        case '/':
            if (b != 0) result = a / b;
            else { printf("Cannot divide by zero\n"); return 1; }
            break;
        default: printf("Unknown operator\n"); return 1;
    }

    printf("Result = %.2f\n", result);
    return 0;
}
```

## Exercise 4: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that prints the multiplication table of a number `n` from `1` to `10`.

**Given Input:** `5`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
```

### Concepts
- `for` loop
- `printf` formatting

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);

    for (int i = 1; i <= 10; i++) {
        printf("%d x %d = %d\n", n, i, n * i);
    }
    return 0;
}
```

## Exercise 5: Reverse a String

**Difficulty:** Basic

### Problem
Write a program that reads a string and prints it reversed by swapping characters in place.

**Given Input:** `hello`

**Expected Output:**
```
olleh
```

### Concepts
- Character arrays (`char[]`) and null terminator
- `strlen()` from `<string.h>`
- Swapping with a temporary variable

### Example / Starter Code

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str[100];
    printf("Enter a string: ");
    scanf("%s", str);

    int len = strlen(str);
    for (int i = 0; i < len / 2; i++) {
        char temp = str[i];
        str[i] = str[len - 1 - i];
        str[len - 1 - i] = temp;
    }

    printf("Reversed = %s\n", str);
    return 0;
}
```
