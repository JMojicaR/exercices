## Exercise 1: Simple Calculator with switch
**Difficulty:** Basic
**Concepts:** switch, scanf, printf, arithmetic operators

Read an operator and two numbers, then perform the requested operation.

**Starter code:**
```c
#include <stdio.h>

int main() {
    char op;
    double a, b;

    printf("Enter operator (+, -, *, /): ");
    scanf(" %c", &op);
    printf("Enter two numbers: ");
    scanf("%lf %lf", &a, &b);

    switch (op) {
        case '+': printf("%.2f\n", a + b); break;
        case '-': printf("%.2f\n", a - b); break;
        case '*': printf("%.2f\n", a * b); break;
        case '/':
            if (b != 0) printf("%.2f\n", a / b);
            else printf("Cannot divide by zero\n");
            break;
        default: printf("Invalid operator\n");
    }
    return 0;
}
```

**Task:** Add a `%` (modulo) case that works only for integer operands.

## Exercise 2: Sum of Natural Numbers
**Difficulty:** Basic
**Concepts:** for loop, accumulator, scanf

Compute the sum of all natural numbers from 1 to `n`.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n, sum = 0;
    printf("Enter a positive integer: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    printf("Sum from 1 to %d is %d\n", n, sum);
    return 0;
}
```

**Task:** Rewrite it using the formula `n * (n + 1) / 2` and compare the results.

## Exercise 3: Power of a Number
**Difficulty:** Basic
**Concepts:** for loop, multiplication, data types

Compute `base` raised to `exponent` using a loop (no `pow()`).

**Starter code:**
```c
#include <stdio.h>

int main() {
    int base, exp;
    long long result = 1;

    printf("Enter base and exponent: ");
    scanf("%d %d", &base, &exp);

    for (int i = 0; i < exp; i++) {
        result *= base;
    }
    printf("%d^%d = %lld\n", base, exp, result);
    return 0;
}
```

**Task:** Handle a negative exponent by printing `1 / result`.

## Exercise 4: Find the Smallest Element in an Array
**Difficulty:** Basic
**Concepts:** arrays, for loop, comparison

Read an array of integers and print its smallest element.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n;
    printf("Enter number of elements: ");
    scanf("%d", &n);

    int arr[n];
    printf("Enter %d numbers: ", n);
    for (int i = 0; i < n; i++) scanf("%d", &arr[i]);

    int min = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] < min) min = arr[i];
    }
    printf("Smallest element: %d\n", min);
    return 0;
}
```

**Task:** Also print the index (position) of the smallest element.

## Exercise 5: Count Occurrences of a Character
**Difficulty:** Basic
**Concepts:** strings, fgets, loops, character comparison

Count how many times a given character appears in a string.

**Starter code:**
```c
#include <stdio.h>

int main() {
    char str[100], ch;
    int count = 0;

    printf("Enter a string: ");
    fgets(str, sizeof(str), stdin);
    printf("Enter a character: ");
    scanf(" %c", &ch);

    for (int i = 0; str[i] != '\0'; i++) {
        if (str[i] == ch) count++;
    }
    printf("'%c' appears %d times\n", ch, count);
    return 0;
}
```

**Task:** Count occurrences of both uppercase and lowercase versions of the character (case-insensitive).
