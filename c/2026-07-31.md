## Exercise 1: Hello World and Basic I/O

**Title:** Hello, C! — printf and scanf

**Description:** Write a C program that prints "Hello, World!" and then asks the user for their name and age, printing a personalized greeting. Practice using `printf()` and `scanf()`.

**Difficulty:** ★☆☆☆☆ (Very Easy)

**Concepts Practiced:**
- `#include <stdio.h>`
- `main()` function
- `printf()` for output
- `scanf()` for input
- Variables (`char[]`, `int`)
- Format specifiers (`%s`, `%d`)

**Starter Code:**
```c
// Exercise 1: Hello, C!
#include <stdio.h>

int main() {
    char name[50];
    int age;

    printf("Hello, World!\n");
    printf("Enter your name: ");
    scanf("%s", name);
    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Welcome, %s! You are %d years old.\n", name, age);

    return 0;
}
```

## Exercise 2: Basic Calculator

**Title:** Arithmetic Calculator with Switch

**Description:** Write a C program that reads two numbers and an operator (+, -, *, /) from the user and performs the calculation. Use a `switch` statement. Handle division by zero gracefully.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- `scanf()` for numeric input
- `switch` statement
- Arithmetic operators
- `float` data type
- Division by zero check

**Starter Code:**
```c
// Exercise 2: Basic Calculator
#include <stdio.h>

int main() {
    float num1, num2, result;
    char operator;

    printf("Enter first number: ");
    scanf("%f", &num1);
    printf("Enter operator (+, -, *, /): ");
    scanf(" %c", &operator);
    printf("Enter second number: ");
    scanf("%f", &num2);

    switch (operator) {
        case '+': result = num1 + num2; break;
        case '-': result = num1 - num2; break;
        case '*': result = num1 * num2; break;
        case '/':
            if (num2 != 0)
                result = num1 / num2;
            else {
                printf("Error: Division by zero!\n");
                return 1;
            }
            break;
        default:
            printf("Invalid operator!\n");
            return 1;
    }

    printf("Result: %.2f\n", result);
    return 0;
}
```

## Exercise 3: Fibonacci Series

**Title:** Generate Fibonacci Sequence

**Description:** Write a C program that generates and prints the Fibonacci series up to a user-specified number of terms. The Fibonacci series starts with 0 and 1, and each subsequent term is the sum of the two preceding terms.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- `for` loops
- Variable swapping
- `printf()` formatting
- User input with `scanf()`
- Sequence generation algorithms

**Starter Code:**
```c
// Exercise 3: Fibonacci Series
#include <stdio.h>

int main() {
    int n, first = 0, second = 1, next;

    printf("Enter the number of terms: ");
    scanf("%d", &n);

    printf("Fibonacci Series: ");
    for (int i = 0; i < n; i++) {
        if (i <= 1)
            next = i;
        else {
            next = first + second;
            first = second;
            second = next;
        }
        printf("%d ", next);
    }
    printf("\n");
    return 0;
}
```

## Exercise 4: Palindrome Checker

**Title:** Check if a String is a Palindrome

**Description:** Write a C program that checks whether a given string is a palindrome (reads the same forwards and backwards). Use character arrays and compare characters from both ends.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Character arrays (strings)
- `strlen()` from `<string.h>`
- `for` loops
- Character comparison
- String input with `scanf()`

**Starter Code:**
```c
// Exercise 4: Palindrome Checker
#include <stdio.h>
#include <string.h>
#include <stdbool.h>

bool isPalindrome(char str[]) {
    int left = 0;
    int right = strlen(str) - 1;

    while (left < right) {
        if (str[left] != str[right])
            return false;
        left++;
        right--;
    }
    return true;
}

int main() {
    char word[100];

    printf("Enter a word: ");
    scanf("%s", word);

    if (isPalindrome(word))
        printf("\"%s\" is a palindrome.\n", word);
    else
        printf("\"%s\" is NOT a palindrome.\n", word);

    return 0;
}
```

## Exercise 5: Array Reversal

**Title:** Reverse an Array In-Place

**Description:** Write a C program that takes an array of integers from the user, reverses it in-place (without using a second array), and prints both the original and reversed arrays.

**Difficulty:** ★★★☆☆ (Moderate)

**Concepts Practiced:**
- Array declaration and initialization
- Array indexing
- In-place swapping algorithm
- User input for arrays
- Loops for array traversal

**Starter Code:**
```c
// Exercise 5: Array Reversal
#include <stdio.h>

int main() {
    int arr[100], n;

    printf("Enter number of elements (max 100): ");
    scanf("%d", &n);

    printf("Enter %d integers:\n", n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }

    printf("Original array: ");
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    // Reverse in-place
    for (int i = 0; i < n / 2; i++) {
        int temp = arr[i];
        arr[i] = arr[n - 1 - i];
        arr[n - 1 - i] = temp;
    }

    printf("Reversed array: ");
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    return 0;
}
```
