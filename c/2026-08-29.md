## Exercise 1: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that reads an integer `n` and prints its multiplication table from 1 to 10 using a `for` loop.

**Given Input:** `5`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

### Concepts
- `scanf()` for input
- `for` loop
- `printf()` with format specifiers

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);

    for (int i = 1; i <= 10; i++) {
        printf("%d x %d = %d\n", n, i, n * i);
    }
    return 0;
}
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that reads three integers and prints the largest using a comparison-based approach.

**Given Input:** `10 25 15`

**Expected Output:**
```
Largest: 25
```

### Concepts
- `scanf()` for multiple inputs
- `if` statements
- Comparison operators

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int a, b, c;
    printf("Enter three numbers: ");
    scanf("%d %d %d", &a, &b, &c);

    int largest = a;
    if (b > largest) largest = b;
    if (c > largest) largest = c;

    printf("Largest: %d\n", largest);
    return 0;
}
```

## Exercise 3: Reverse a String

**Difficulty:** Basic

### Problem
Write a program that reads a string, reverses it in place by swapping characters, and prints the result.

**Given Input:** `hello`

**Expected Output:**
```
Reversed: olleh
```

### Concepts
- Character arrays and `char`
- `strlen()` from `<string.h>`
- In-place swapping with a temporary variable

### Example / Starter Code

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str[100];
    printf("Enter a string: ");
    scanf("%99s", str);

    int len = strlen(str);
    for (int i = 0; i < len / 2; i++) {
        char temp = str[i];
        str[i] = str[len - 1 - i];
        str[len - 1 - i] = temp;
    }

    printf("Reversed: %s\n", str);
    return 0;
}
```

## Exercise 4: Leap Year Checker

**Difficulty:** Basic

### Problem
Write a program that reads a year and prints whether it is a leap year using the modulo operator and boolean logic.

**Given Input:** `2024`

**Expected Output:**
```
2024 is a leap year
```

### Concepts
- Modulo operator `%`
- Boolean logic with `&&` and `||`
- `if`/`else`

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    int year;
    printf("Enter a year: ");
    scanf("%d", &year);

    if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0))
        printf("%d is a leap year\n", year);
    else
        printf("%d is not a leap year\n", year);

    return 0;
}
```

## Exercise 5: Simple Calculator

**Difficulty:** Basic

### Problem
Write a program that reads two numbers and an operator (`+`, `-`, `*`, `/`) and prints the result using a `switch` statement. Handle division by zero.

**Given Input:** `8 2 /`

**Expected Output:**
```
Result: 4.00
```

### Concepts
- `switch` statement
- `double` arithmetic
- Division-by-zero handling

### Example / Starter Code

```c
#include <stdio.h>

int main() {
    double a, b;
    char op;
    printf("Enter two numbers: ");
    scanf("%lf %lf", &a, &b);
    printf("Enter operator (+, -, *, /): ");
    scanf(" %c", &op);

    switch (op) {
        case '+': printf("Result: %.2f\n", a + b); break;
        case '-': printf("Result: %.2f\n", a - b); break;
        case '*': printf("Result: %.2f\n", a * b); break;
        case '/':
            if (b != 0) printf("Result: %.2f\n", a / b);
            else printf("Error: division by zero\n");
            break;
        default: printf("Invalid operator\n");
    }
    return 0;
}
```
