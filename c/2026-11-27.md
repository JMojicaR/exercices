## Exercise 1: Define a Node and Build a Small Tree
**Difficulty:** Basic
**Concepts:** `struct`, `malloc`, pointer fields, linking nodes

**Starter code:**
```c
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int value;
    struct Node *left;
    struct Node *right;
};

struct Node *new_node(int value) {
    struct Node *n = malloc(sizeof(struct Node));
    n->value = value;
    n->left = NULL;
    n->right = NULL;
    return n;
}

int main(void) {
    //         8
    //        / \
    //       3   10
    struct Node *root = new_node(8);
    root->left  = new_node(3);
    root->right = new_node(10);
    return 0;
}
```

**Task:** Build the full tree below and print `root->left->right->value`:
```
       8
      / \
     3   10
    / \    \
   1   6    14
```
(Expected output: `6`.)

## Exercise 2: Insert a Value into the BST
**Difficulty:** Basic
**Concepts:** recursion with pointers, allocating a node only at the empty spot

**Starter code:**
```c
struct Node *insert(struct Node *node, int value) {
    if (node == NULL) return new_node(value);
    if (value < node->value)
        node->left = insert(node->left, value);
    else
        node->right = insert(node->right, value);
    return node;
}

int main(void) {
    struct Node *root = NULL;
    int values[] = {8, 3, 10, 1, 6};
    for (int i = 0; i < 5; i++) {
        root = insert(root, values[i]);
    }
    return 0;
}
```

**Task:** Insert `14`, `4`, and `7`, then write a recursive `print_tree` that prints `value (left, right)` for each node to verify the structure. Remember to `free` all nodes when done.

## Exercise 3: Search for a Value
**Difficulty:** Basic
**Concepts:** recursive search, `0`/`1` return (C has no `bool` without `<stdbool.h>`)

**Starter code:**
```c
#include <stdbool.h>

bool contains(struct Node *node, int value) {
    if (node == NULL) return false;
    if (node->value == value) return true;
    if (value < node->value) return contains(node->left, value);
    return contains(node->right, value);
}

int main(void) {
    struct Node *root = NULL;
    int values[] = {8, 3, 10, 1, 6, 14, 4, 7};
    for (int i = 0; i < 8; i++) {
        root = insert(root, values[i]);
    }
    printf("%d\n", contains(root, 6));   // 1
    printf("%d\n", contains(root, 12));  // 0
    return 0;
}
```

**Task:** Modify `contains` to return the depth (steps from the root) where the value is found, or `-1` if absent.

## Exercise 4: In-Order Traversal (Sorted Output)
**Difficulty:** Basic
**Concepts:** left → current → right recursion, `printf` during traversal

**Starter code:**
```c
void inorder(struct Node *node) {
    if (node == NULL) return;
    inorder(node->left);
    printf("%d ", node->value);
    inorder(node->right);
}

int main(void) {
    struct Node *root = NULL;
    int values[] = {8, 3, 10, 1, 6, 14, 4, 7};
    for (int i = 0; i < 8; i++) {
        root = insert(root, values[i]);
    }
    inorder(root);  // 1 3 4 6 7 8 10 14
    printf("\n");
    return 0;
}
```

**Task:** Add a `preorder` function (current → left → right) and print both. Confirm `inorder` is sorted and `preorder` begins with `8`.

## Exercise 5: Find the Minimum and Maximum
**Difficulty:** Basic
**Concepts:** following `left`/`right` chains with a `while` loop over pointers

**Starter code:**
```c
int min_value(struct Node *node) {
    while (node->left != NULL) {
        node = node->left;
    }
    return node->value;
}

int max_value(struct Node *node) {
    while (node->right != NULL) {
        node = node->right;
    }
    return node->value;
}

int main(void) {
    struct Node *root = NULL;
    int values[] = {8, 3, 10, 1, 6, 14, 4, 7};
    for (int i = 0; i < 8; i++) {
        root = insert(root, values[i]);
    }
    printf("%d\n", min_value(root));  // 1
    printf("%d\n", max_value(root));  // 14
    return 0;
}
```

**Task:** Rewrite both functions using recursion instead of a `while` loop, and write a `free_tree` function that recursively frees every node.
