## Exercise 5: Factorial with Functions — Functions & Recursion

| Field | Detail |
|-------|--------|
| **Difficulty** | ★★☆☆☆ |
| **Concepts** | Function definition, recursion, `long long`, base case |

**Description:**  
Write a recursive function `long long factorial(int n)` and call it from `main()`.  
Test with `n = 5` (expected: 120) and `n = 10` (expected: 3628800).

**Starter Code:**
```c
#include <stdio.h>

// TODO: Define factorial function

int main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);

    printf("%d! = %lld\n", n, factorial(n));
    return 0;
}
```
