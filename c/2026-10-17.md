## Exercise 1: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** arrays, `for` loop, accumulation

Compute the sum of all elements in an integer array.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};
    int length = sizeof(numbers) / sizeof(numbers[0]);
    int sum = 0;

    for (int i = 0; i < length; i++) {
        sum += numbers[i];
    }

    printf("Sum: %d\n", sum);
    return 0;
}
```

**Task:** Read the array elements from the user instead of hard-coding them.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** modulo operator (`%`), `if/else`

Check whether a number is even or odd.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int n = 7;

    if (n % 2 == 0) {
        printf("%d is even\n", n);
    } else {
        printf("%d is odd\n", n);
    }
    return 0;
}
```

**Task:** Read the number from the user with `scanf`.

## Exercise 3: Celsius to Fahrenheit
**Difficulty:** Basic
**Concepts:** arithmetic, `float`/`double`, input/output

Convert Celsius to Fahrenheit using `F = C × 9/5 + 32`.

**Starter code:**
```c
#include <stdio.h>

int main() {
    float celsius = 20.0;
    float fahrenheit = (celsius * 9 / 5) + 32;

    printf("%.1f°C = %.1f°F\n", celsius, fahrenheit);
    return 0;
}
```

**Task:** Read the Celsius value from the user and also convert Fahrenheit back to Celsius.

## Exercise 4: Find the Smallest Number
**Difficulty:** Basic
**Concepts:** arrays, comparison, loops

Find the smallest value in an integer array.

**Starter code:**
```c
#include <stdio.h>

int main() {
    int numbers[] = {45, 12, 78, 4, 33};
    int length = sizeof(numbers) / sizeof(numbers[0]);
    int smallest = numbers[0];

    for (int i = 1; i < length; i++) {
        if (numbers[i] < smallest) {
            smallest = numbers[i];
        }
    }

    printf("Smallest: %d\n", smallest);
    return 0;
}
```

**Task:** Also find the largest value in the same array.

## Exercise 5: Simple Interest
**Difficulty:** Basic
**Concepts:** variables, arithmetic, `float`

Calculate simple interest using `SI = (P × R × T) / 100`.

**Starter code:**
```c
#include <stdio.h>

int main() {
    float principal = 1000, rate = 5, time = 3;
    float interest = (principal * rate * time) / 100;

    printf("Simple interest: %.2f\n", interest);
    return 0;
}
```

**Task:** Also print the total amount (principal + interest).
