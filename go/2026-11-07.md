# Go — Basic Exercises (2026-11-07)
Sources: A Tour of Go, Go by Example, GeeksforGeeks, go.dev

Theme: **Control Flow — Conditionals & Loops** — branching with `if`/`else` (and `switch`), iterating with `for` (Go's only loop construct), and combining loops with conditions to accumulate results.

## Exercise 1: Even or Odd Checker
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator `%`, function definition, `fmt.Println()`

Write a function that takes an `int` and prints whether it is even or odd.

**Starter code:**
```go
package main

import "fmt"

func evenOrOdd(n int) {
	if n%2 == 0 {
		fmt.Printf("%d is even\n", n)
	} else {
		fmt.Printf("%d is odd\n", n)
	}
}

func main() {
	evenOrOdd(4) // 4 is even
	evenOrOdd(7) // 7 is odd
}
```

**Task:** Rewrite using Go's `if` initializer statement (`if n, err := ...; err == nil { ... }`), or read from `os.Args[1]` with `strconv.Atoi`. Handle the error case.

## Exercise 2: Print Numbers 1 to N
**Difficulty:** Basic
**Concepts:** `for` loop (classic C-style), loop variable, increment `i++`, `fmt.Println()`

Print every integer from 1 up to and including `N`, one per line.

**Starter code:**
```go
package main

import "fmt"

func printRange(n int) {
	for i := 1; i <= n; i++ {
		fmt.Println(i)
	}
}

func main() {
	printRange(5)
	// 1
	// 2
	// 3
	// 4
	// 5
}
```

**Task:** Modify the loop to print only odd numbers using `i += 2`. Then rewrite it with Go's `range` keyword over a slice (`for _, v := range []int{...}`).

## Exercise 3: Countdown
**Difficulty:** Basic
**Concepts:** `for` as a `while` loop (`for n > 0`), decrementing a counter

Print a countdown from `N` down to 1, then print `"Liftoff!"`.

**Starter code:**
```go
package main

import "fmt"

func countdown(n int) {
	for n > 0 {
		fmt.Println(n)
		n--
	}
	fmt.Println("Liftoff!")
}

func main() {
	countdown(5)
	// 5
	// 4
	// 3
	// 2
	// 1
	// Liftoff!
}
```

**Task:** Add a guard so that `n <= 0` prints `"Nothing to count"`. Then rewrite the countdown with a classic C-style `for i := n; i > 0; i--` loop.

## Exercise 4: Grade Classifier
**Difficulty:** Basic
**Concepts:** `if`/`else if`/`else` ladder, comparison operators, `switch` without an expression

Convert a numeric score (0–100) into a letter grade: 90+ → A, 80–89 → B, 70–79 → C, 60–69 → D, below 60 → F.

**Starter code:**
```go
package main

import "fmt"

func classify(score int) string {
	if score >= 90 {
		return "A"
	} else if score >= 80 {
		return "B"
	} else if score >= 70 {
		return "C"
	} else if score >= 60 {
		return "D"
	} else {
		return "F"
	}
}

func main() {
	fmt.Println(classify(95)) // A
	fmt.Println(classify(83)) // B
	fmt.Println(classify(57)) // F
}
```

**Task:** Rewrite using a `switch` statement (`switch { case score >= 90: ... }`, i.e. no expression). Then handle scores outside 0–100 by returning `"Invalid"`.

## Exercise 5: Sum of Even Numbers up to N
**Difficulty:** Basic
**Concepts:** `for` loop + `if` condition, accumulator variable, `+=`

Return the sum of every even number from 2 up to and including `N`.

**Starter code:**
```go
package main

import "fmt"

func sumEven(n int) int {
	total := 0
	for i := 1; i <= n; i++ {
		if i%2 == 0 {
			total += i
		}
	}
	return total
}

func main() {
	fmt.Println(sumEven(10)) // 2 + 4 + 6 + 8 + 10 = 30
	fmt.Println(sumEven(7))  // 2 + 4 + 6 = 12
}
```

**Task:** Rewrite using `i += 2` so the conditional is unnecessary, and add a `sumOdd(n int) int` function. Compare `sumEven(n) + sumOdd(n)` against `n*(n+1)/2` for a given `n`.
