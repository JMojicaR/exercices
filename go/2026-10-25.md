Theme: **2D arrays / matrices** — create, add, transpose, and summarize matrices using slices of slices.

## Exercise 1: Create and Print a Matrix
**Difficulty:** Basic
**Concepts:** slices of slices (`[][]int`), `range`, `fmt.Printf`

Build a 2D slice and print it row by row.

**Starter code:**
```go
package main

import "fmt"

func main() {
    matrix := [][]int{
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9},
    }

    fmt.Println("Matrix:")
    for _, row := range matrix {
        for _, val := range row {
            fmt.Printf("%d ", val)
        }
        fmt.Println()
    }
}
```

**Task:** Print the matrix in reverse row order, then print only the first and last column of each row.

## Exercise 2: Matrix Addition
**Difficulty:** Basic
**Concepts:** slices, `make([][]int, n)`, element-wise addition

Add two matrices and print the result.

**Starter code:**
```go
package main

import "fmt"

func main() {
    a := [][]int{{1, 2}, {3, 4}}
    b := [][]int{{5, 6}, {7, 8}}
    rows, cols := len(a), len(a[0])
    result := make([][]int, rows)
    for i := range result {
        result[i] = make([]int, cols)
    }

    for i := 0; i < rows; i++ {
        for j := 0; j < cols; j++ {
            result[i][j] = a[i][j] + b[i][j]
        }
    }

    fmt.Println("Sum matrix:")
    for _, row := range result {
        fmt.Println(row)
    }
}
```

**Task:** Compute subtraction (`a - b`), and wrap the addition in a `func add(a, b [][]int) [][]int` function.

## Exercise 3: Matrix Transpose
**Difficulty:** Basic
**Concepts:** row/column swapping, flipped-size slice

Transpose a matrix (swap rows and columns).

**Starter code:**
```go
package main

import "fmt"

func main() {
    matrix := [][]int{{1, 2, 3}, {4, 5, 6}}
    rows, cols := len(matrix), len(matrix[0])
    transpose := make([][]int, cols)
    for i := range transpose {
        transpose[i] = make([]int, rows)
    }

    for i := 0; i < rows; i++ {
        for j := 0; j < cols; j++ {
            transpose[j][i] = matrix[i][j]
        }
    }

    fmt.Println("Transpose:")
    for _, row := range transpose {
        fmt.Println(row)
    }
}
```

**Task:** Write a `func transpose(m [][]int) [][]int` and verify that transposing twice returns the original.

## Exercise 4: Sum of the Main Diagonal
**Difficulty:** Basic
**Concepts:** square matrices, single loop, index tracking

Sum the main diagonal (top-left to bottom-right) of a square matrix.

**Starter code:**
```go
package main

import "fmt"

func main() {
    matrix := [][]int{
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9},
    }
    n := len(matrix)
    total := 0

    for i := 0; i < n; i++ {
        total += matrix[i][i]
    }

    fmt.Println("Sum of main diagonal:", total)
}
```

**Task:** Add the anti-diagonal using `matrix[i][n-1-i]` and print both sums.

## Exercise 5: Sum of Each Row and Each Column
**Difficulty:** Basic
**Concepts:** nested loops, running totals

Print the sum of every row and every column.

**Starter code:**
```go
package main

import "fmt"

func main() {
    matrix := [][]int{
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9},
    }
    rows, cols := len(matrix), len(matrix[0])

    fmt.Println("Row sums:")
    for i := 0; i < rows; i++ {
        rowSum := 0
        for j := 0; j < cols; j++ {
            rowSum += matrix[i][j]
        }
        fmt.Printf("Row %d: %d\n", i, rowSum)
    }

    fmt.Println("Column sums:")
    for j := 0; j < cols; j++ {
        colSum := 0
        for i := 0; i < rows; i++ {
            colSum += matrix[i][j]
        }
        fmt.Printf("Col %d: %d\n", j, colSum)
    }
}
```

**Task:** Report the grand total of all elements and the row/column with the largest sum.
