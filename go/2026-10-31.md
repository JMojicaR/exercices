## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** `[]rune`, two-index swap loop, `string()` conversion, `fmt.Println`

Write a function that returns the input string reversed.

**Starter code:**
```go
package main

import "fmt"

func reverseString(s string) string {
    runes := []rune(s)
    for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
        runes[i], runes[j] = runes[j], runes[i]
    }
    return string(runes)
}

func main() {
    fmt.Println(reverseString("hello"))  // expected: olleh
}
```

**Task:** Build the reversed string with `for _, r := range` and a `strings.Builder` instead of swapping.

## Exercise 2: Check Palindrome
**Difficulty:** Basic
**Concepts:** `strings.ToLower`, `[]rune`, two-pointer comparison, `bool`

Check whether a string reads the same forwards and backwards (ignoring case).

**Starter code:**
```go
package main

import (
    "fmt"
    "strings"
)

func isPalindrome(s string) bool {
    runes := []rune(strings.ToLower(s))
    for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
        if runes[i] != runes[j] {
            return false
        }
    }
    return true
}

func main() {
    fmt.Println(isPalindrome("Radar"))  // expected: true
    fmt.Println(isPalindrome("hello"))  // expected: false
}
```

**Task:** Ignore spaces and punctuation so `"A man, a plan, a canal: Panama"` returns `true`.

## Exercise 3: Count Vowels
**Difficulty:** Basic
**Concepts:** `range`, `strings.ContainsRune`, `strings.ToLower`, counter

Count how many vowels (a, e, i, o, u) appear in a string, case-insensitively.

**Starter code:**
```go
package main

import (
    "fmt"
    "strings"
)

func countVowels(s string) int {
    vowels := "aeiou"
    count := 0
    for _, ch := range strings.ToLower(s) {
        if strings.ContainsRune(vowels, ch) {
            count++
        }
    }
    return count
}

func main() {
    fmt.Println(countVowels("hello world"))  // expected: 3
}
```

**Task:** Return both the vowel and consonant counts from a single function.

## Exercise 4: Count Character Occurrences
**Difficulty:** Basic
**Concepts:** `range`, `rune` comparison, counter, function parameters

Count how many times a given character appears in a string.

**Starter code:**
```go
package main

import "fmt"

func countChar(s string, ch rune) int {
    count := 0
    for _, c := range s {
        if c == ch {
            count++
        }
    }
    return count
}

func main() {
    fmt.Println(countChar("banana", 'a'))  // expected: 3
}
```

**Task:** Also count using `strings.Count(s, string(ch))` and compare the two results.

## Exercise 5: Count Words
**Difficulty:** Basic
**Concepts:** `strings.Fields`, `len`, the `strings` package

Count the number of words in a sentence (words separated by whitespace).

**Starter code:**
```go
package main

import (
    "fmt"
    "strings"
)

func countWords(sentence string) int {
    return len(strings.Fields(sentence))
}

func main() {
    fmt.Println(countWords("I love programming"))  // expected: 3
}
```

**Task:** Print each word on its own line by ranging over the slice returned by `strings.Fields`.
