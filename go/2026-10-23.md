## Exercise 1: Print the ASCII Value of a Character
**Difficulty:** Basic
**Concepts:** `rune`, integer conversion, `fmt.Printf`

Given a character, print its ASCII value.

**Starter code:**
```go
package main

import "fmt"

func main() {
    ch := 'A'
    fmt.Printf("ASCII value of %c is %d\n", ch, ch)
}
```

**Task:** Loop over a string with `for _, c := range "ABC"` printing each rune and its code, and convert a code back with `rune(65)`.

## Exercise 2: Check Vowel or Consonant
**Difficulty:** Basic
**Concepts:** `switch`, `strings.ToLower`, rune handling

Read a letter and report whether it is a vowel or a consonant.

**Starter code:**
```go
package main

import "fmt"

func main() {
    ch := 'e'

    switch ch {
    case 'a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U':
        fmt.Printf("%c is a vowel\n", ch)
    default:
        fmt.Printf("%c is a consonant\n", ch)
    }
}
```

**Task:** Read the letter with `fmt.Scanf("%c", &ch)` and use `unicode.IsLetter` from the `unicode` package to reject non-letters.

## Exercise 3: Maximum and Minimum in a Slice
**Difficulty:** Basic
**Concepts:** slices, `for` loops, comparisons

Find the largest and smallest values in a slice of integers.

**Starter code:**
```go
package main

import "fmt"

func main() {
    numbers := []int{45, 12, 78, 34, 89, 23}
    max := numbers[0]
    min := numbers[0]

    for _, n := range numbers {
        if n > max {
            max = n
        }
        if n < min {
            min = n
        }
    }

    fmt.Println("Max:", max, "Min:", min)
}
```

**Task:** Handle an empty slice, and also compute the sum and average (as a `float64`).

## Exercise 4: Simple Calculator
**Difficulty:** Basic
**Concepts:** `switch`, arithmetic operators, functions

Write a function that takes two numbers and an operator and returns the result.

**Starter code:**
```go
package main

import (
    "errors"
    "fmt"
)

func calculate(a, b float64, op string) (float64, error) {
    switch op {
    case "+":
        return a + b, nil
    case "-":
        return a - b, nil
    case "*":
        return a * b, nil
    case "/":
        if b == 0 {
            return 0, errors.New("cannot divide by zero")
        }
        return a / b, nil
    default:
        return 0, errors.New("invalid operator")
    }
}

func main() {
    if result, err := calculate(10, 5, "+"); err == nil {
        fmt.Println("Result:", result)
    } else {
        fmt.Println("Error:", err)
    }
}
```

**Task:** Add a `"%"` case using `math.Mod`, and read inputs from the user with `fmt.Scan`.

## Exercise 5: Print Prime Numbers in a Range
**Difficulty:** Basic
**Concepts:** functions, nested loops, `bool`, modular arithmetic

Print every prime number between two given bounds (e.g. 10 and 50).

**Starter code:**
```go
package main

import "fmt"

func isPrime(n int) bool {
    if n < 2 {
        return false
    }
    for i := 2; i*i <= n; i++ {
        if n%i == 0 {
            return false
        }
    }
    return true
}

func main() {
    for num := 10; num <= 50; num++ {
        if isPrime(num) {
            fmt.Print(num, " ")
        }
    }
    fmt.Println()
}
```

**Task:** Collect the primes into a slice, print the count, and make the bounds configurable via function parameters.
