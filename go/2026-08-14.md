## Exercise 1: Check Even or Odd

### Problem
Write a program that reads an integer and prints whether it is even or odd.

**Given Input:** `7`

**Expected Output:**
```
7 is odd
```

### Concepts
- `fmt.Scan` for input
- Modulo operator (`%`)
- `if-else` statements

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    var number int
    fmt.Print("Enter an integer: ")
    fmt.Scan(&number)

    if number%2 == 0 {
        fmt.Printf("%d is even\n", number)
    } else {
        fmt.Printf("%d is odd\n", number)
    }
}
```

## Exercise 2: Factorial of a Number

### Problem
Write a program that calculates the factorial of a non-negative integer using a loop.

**Given Input:** `5`

**Expected Output:**
```
Factorial of 5 = 120
```

### Concepts
- `for` loops
- Accumulator pattern
- `uint64` for larger values

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    var n int
    fmt.Print("Enter a non-negative integer: ")
    fmt.Scan(&n)

    factorial := 1
    for i := 1; i <= n; i++ {
        factorial *= i
    }

    fmt.Printf("Factorial of %d = %d\n", n, factorial)
}
```

## Exercise 3: Reverse a String

### Problem
Write a program that reverses a given string using a loop (or runes for Unicode safety).

**Given Input:** `"hello"`

**Expected Output:**
```
olleh
```

### Concepts
- `string` indexing by byte vs. rune
- `for` loops
- Building a new string

### Example / Starter Code

```go
package main

import "fmt"

func reverseString(s string) string {
    runes := []rune(s)
    for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
        runes[i], runes[j] = runes[j], runes[i]
    }
    return string(runes)
}

func main() {
    fmt.Println(reverseString("hello"))   // "olleh"
}
```

## Exercise 4: Sum of a Slice

### Problem
Write a program that returns the sum of all elements in a slice of integers.

**Given Input:** `[]int{1, 2, 3, 4, 5}`

**Expected Output:**
```
15
```

### Concepts
- Slices and the `range` keyword
- Accumulator pattern
- Function signatures with slices

### Example / Starter Code

```go
package main

import "fmt"

func sumSlice(nums []int) int {
    sum := 0
    for _, n := range nums {
        sum += n
    }
    return sum
}

func main() {
    nums := []int{1, 2, 3, 4, 5}
    fmt.Println(sumSlice(nums))   // 15
}
```

## Exercise 5: Check Prime Number

### Problem
Write a program that checks whether a given positive integer is prime.

**Given Input:** `13`

**Expected Output:**
```
13 is prime
```

### Concepts
- `for` loops with `break`
- Modulo operator
- Boolean flag variable

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    var n int
    fmt.Print("Enter a positive integer: ")
    fmt.Scan(&n)

    isPrime := true
    if n < 2 {
        isPrime = false
    } else {
        for i := 2; i <= n/2; i++ {
            if n%i == 0 {
                isPrime = false
                break
            }
        }
    }

    if isPrime {
        fmt.Printf("%d is prime\n", n)
    } else {
        fmt.Printf("%d is not prime\n", n)
    }
}
```
