## Exercise 4: Palindrome Checker
**Difficulty:** ★★☆☆☆  
**Concepts:** `rune` type, string indexing, `unicode` package, loop

### Description

## Exercise 5: Concurrent Counter (Goroutines Intro)
**Difficulty:** ★★☆☆☆  
**Concepts:** Goroutines, channels, `sync.WaitGroup`

### Description
Write a program that launches 5 goroutines. Each goroutine counts from 1 to 10 and sends each number through a shared channel. The main goroutine reads from the channel and prints all values. Use a `sync.WaitGroup` to wait for all goroutines to finish.

### Starter Code
```go
package main

import (
    "fmt"
    "sync"
)

func counter(id int, ch chan<- string, wg *sync.WaitGroup) {
    defer wg.Done()
    for i := 1; i <= 10; i++ {
        ch <- fmt.Sprintf("Goroutine %d: %d", id, i)
    }
}

func main() {
    ch := make(chan string)
    var wg sync.WaitGroup

    for i := 1; i <= 5; i++ {
        wg.Add(1)
        go counter(i, ch, &wg)
    }

    // Your code here — read from channel, close after goroutines finish
}
```
