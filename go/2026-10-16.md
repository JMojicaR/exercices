## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** runes, range, strings

Write a function that reverses a string.

**Starter code:**
```go
package main

import "fmt"

func reverseString(s string) string {
	runes := []rune(s)
	for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
		runes[i], runes[j] = runes[j], runes[i]
	}
	return string(runes)
}

func main() {
	fmt.Println("Reversed:", reverseString("hello"))
}
```

**Task:** Reverse the string by building a new string in a loop, appending from the end.

## Exercise 2: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** conditionals, integer comparison

Write a function that returns the largest of three integers.

**Starter code:**
```go
package main

import "fmt"

func largestOfThree(a, b, c int) int {
	largest := a
	if b > largest {
		largest = b
	}
	if c > largest {
		largest = c
	}
	return largest
}

func main() {
	fmt.Println("Largest:", largestOfThree(3, 9, 5))
}
```

**Task:** Read the three numbers from standard input using `fmt.Scan`.

## Exercise 3: Multiplication Table
**Difficulty:** Basic
**Concepts:** for loop, fmt.Printf

Print the multiplication table (1 to 10) for a given number.

**Starter code:**
```go
package main

import "fmt"

func main() {
	n := 5
	for i := 1; i <= 10; i++ {
		fmt.Printf("%d x %d = %d\n", n, i, n*i)
	}
}
```

**Task:** Print tables for all numbers from 1 to 5.

## Exercise 4: Armstrong Number
**Difficulty:** Basic
**Concepts:** for loop, modulo, pow, string length

Check whether a number is an Armstrong number.

**Starter code:**
```go
package main

import (
	"fmt"
	"math"
	"strconv"
)

func isArmstrong(n int) bool {
	digits := float64(len(strconv.Itoa(n)))
	sum := 0
	num := n

	for num > 0 {
		digit := num % 10
		sum += int(math.Pow(float64(digit), digits))
		num /= 10
	}

	return sum == n
}

func main() {
	fmt.Println(isArmstrong(153)) // true
}
```

**Task:** Print all Armstrong numbers between 1 and 1000.

## Exercise 5: Count Digits in a Number
**Difficulty:** Basic
**Concepts:** for loop, integer division, counting

Write a function that counts the digits of an integer.

**Starter code:**
```go
package main

import "fmt"

func countDigits(n int) int {
	if n == 0 {
		return 1
	}
	count := 0
	for n != 0 {
		n /= 10
		count++
	}
	return count
}

func main() {
	fmt.Println("Digits:", countDigits(12345)) // 5
}
```

**Task:** Also count digits using `len(strconv.Itoa(n))` and verify both agree.
