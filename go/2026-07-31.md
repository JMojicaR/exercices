## Exercise 1: Hello World and Variables

**Title:** Hello, Go! — Package Main and fmt

**Description:** Write a Go program that prints "Hello, World!" and then demonstrates variable declaration using `var`, short declaration (`:=`), and constants. Show the zero values of common types.

**Difficulty:** ★☆☆☆☆ (Very Easy)

**Concepts Practiced:**
- `package main` and `func main()`
- `import "fmt"`
- `var` keyword
- Short variable declaration (`:=`)
- Constants (`const`)
- Zero values

**Starter Code:**
```go
// Exercise 1: Hello, Go!
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")

    // Variable declaration styles
    var name string = "Alice"
    age := 25
    const CurrentYear = 2026

    fmt.Printf("Name: %s\n", name)
    fmt.Printf("Age: %d\n", age)
    fmt.Printf("Born: %d\n", CurrentYear-age)

    // Zero values
    var emptyInt int
    var emptyString string
    var emptyBool bool
    fmt.Printf("Zero values: int=%d, string=%q, bool=%t\n",
        emptyInt, emptyString, emptyBool)
}
```

## Exercise 2: FizzBuzz

**Title:** Classic FizzBuzz with For Loop

**Description:** Write a Go program that prints numbers from 1 to 50. For multiples of 3, print "Fizz" instead. For multiples of 5, print "Buzz". For multiples of both 3 and 5, print "FizzBuzz".

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- `for` loop (Go's only loop)
- `if`/`else if`/`else`
- Modulo operator (`%`)
- `fmt.Println` / `fmt.Print`
- Boolean logic with `&&`

**Starter Code:**
```go
// Exercise 2: FizzBuzz
package main

import "fmt"

func main() {
    for i := 1; i <= 50; i++ {
        if i%3 == 0 && i%5 == 0 {
            fmt.Println("FizzBuzz")
        } else if i%3 == 0 {
            fmt.Println("Fizz")
        } else if i%5 == 0 {
            fmt.Println("Buzz")
        } else {
            fmt.Println(i)
        }
    }
}
```

## Exercise 3: Palindrome Checker

**Title:** String Palindrome Detector

**Description:** Write a Go program that checks if a given string is a palindrome. Handle both cases: case-sensitive and case-insensitive checking. Use Go's `rune` type to support Unicode characters.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- String manipulation
- `[]rune` conversion for Unicode
- `for` loop with index
- `strings.ToLower()` from `strings` package
- Function creation and return values

**Starter Code:**
```go
// Exercise 3: Palindrome Checker
package main

import (
    "fmt"
    "strings"
)

func isPalindrome(s string) bool {
    // Convert to lowercase for case-insensitive comparison
    s = strings.ToLower(s)
    runes := []rune(s)
    for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
        if runes[i] != runes[j] {
            return false
        }
    }
    return true
}

func main() {
    words := []string{"racecar", "hello", "Madam", "Go", "civic"}
    for _, word := range words {
        result := "NOT a palindrome"
        if isPalindrome(word) {
            result = "a palindrome"
        }
        fmt.Printf("%q is %s\n", word, result)
    }
}
```

## Exercise 4: Factorial Calculator

**Title:** Iterative and Recursive Factorial

**Description:** Write a Go program with two functions that calculate the factorial of a number: one iterative (using a loop) and one recursive. Handle the edge case of n = 0 (0! = 1).

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Function signatures with parameters and returns
- `for` loop
- Recursive functions
- `uint64` for large results
- Input handling

**Starter Code:**
```go
// Exercise 4: Factorial Calculator
package main

import "fmt"

func factorialIterative(n uint64) uint64 {
    result := uint64(1)
    for i := uint64(1); i <= n; i++ {
        result *= i
    }
    return result
}

func factorialRecursive(n uint64) uint64 {
    if n == 0 || n == 1 {
        return 1
    }
    return n * factorialRecursive(n-1)
}

func main() {
    numbers := []uint64{0, 1, 5, 10, 15}
    for _, n := range numbers {
        fmt.Printf("%d! = %d (iterative), %d (recursive)\n",
            n, factorialIterative(n), factorialRecursive(n))
    }
}
```

## Exercise 5: Simple Calculator with Switch

**Title:** Interactive Calculator

**Description:** Write a Go program that takes two numbers and an operator from the user, then performs the calculation using a `switch` statement. Handle division by zero and invalid operators. Use `fmt.Scan` for input.

**Difficulty:** ★★★☆☆ (Moderate)

**Concepts Practiced:**
- `switch` statement (without expression)
- `fmt.Scan` for user input
- Error handling
- `float64` arithmetic
- `continue` and `break`

**Starter Code:**
```go
// Exercise 5: Simple Calculator
package main

import "fmt"

func main() {
    var num1, num2, result float64
    var operator string

    fmt.Print("Enter first number: ")
    fmt.Scan(&num1)

    fmt.Print("Enter operator (+, -, *, /): ")
    fmt.Scan(&operator)

    fmt.Print("Enter second number: ")
    fmt.Scan(&num2)

    switch operator {
    case "+":
        result = num1 + num2
    case "-":
        result = num1 - num2
    case "*":
        result = num1 * num2
    case "/":
        if num2 != 0 {
            result = num1 / num2
        } else {
            fmt.Println("Error: Division by zero!")
            return
        }
    default:
        fmt.Println("Error: Invalid operator!")
        return
    }

    fmt.Printf("%.2f %s %.2f = %.2f\n", num1, operator, num2, result)
}
```
