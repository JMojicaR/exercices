## Exercise 1: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that prints the multiplication table of a number `n` from 1 to 10 using a `for` loop and `fmt.Printf`.

**Given Input:** `5`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

### Concepts
- `for` loop (Go's only loop construct)
- `fmt.Printf` with format verbs (`%d`)
- Short variable declaration (`:=`)

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    n := 5
    for i := 1; i <= 10; i++ {
        fmt.Printf("%d x %d = %d\n", n, i, n*i)
    }
}
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that finds the largest of three numbers using `if` statements.

**Given Input:** `10 25 15` (hard-coded)

**Expected Output:**
```
Largest: 25
```

### Concepts
- `if` statements
- Comparison operators
- Short variable declaration

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    a, b, c := 10, 25, 15

    largest := a
    if b > largest {
        largest = b
    }
    if c > largest {
        largest = c
    }

    fmt.Println("Largest:", largest)
}
```

## Exercise 3: Reverse a String

**Difficulty:** Basic

### Problem
Write a program that reverses a string by converting it to a slice of runes, swapping elements, and converting it back.

**Given Input:** `hello`

**Expected Output:**
```
Reversed: olleh
```

### Concepts
- `[]rune` for Unicode-safe strings
- Swapping with multiple assignment
- `len()` on a slice

### Example / Starter Code

```go
package main

import "fmt"

func reverse(s string) string {
    r := []rune(s)
    for i, j := 0, len(r)-1; i < j; i, j = i+1, j-1 {
        r[i], r[j] = r[j], r[i]
    }
    return string(r)
}

func main() {
    fmt.Println("Reversed:", reverse("hello"))
}
```

## Exercise 4: Leap Year Checker

**Difficulty:** Basic

### Problem
Write a program that checks whether a year is a leap year using the modulo operator and boolean logic.

**Given Input:** `2024`

**Expected Output:**
```
2024 is a leap year
```

### Concepts
- Modulo operator `%`
- Boolean logic with `&&` and `||`
- `if`/`else`

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    year := 2024
    isLeap := (year%4 == 0 && year%100 != 0) || (year%400 == 0)

    if isLeap {
        fmt.Printf("%d is a leap year\n", year)
    } else {
        fmt.Printf("%d is not a leap year\n", year)
    }
}
```

## Exercise 5: Simple Calculator

**Difficulty:** Basic

### Problem
Write a program that performs a basic arithmetic operation using a `switch` statement. Handle division by zero and invalid operators.

**Given Input:** `8 2 /` (hard-coded)

**Expected Output:**
```
Result: 4
```

### Concepts
- `switch` statement (without a condition expression)
- Floating-point arithmetic (`float64`)
- Division-by-zero handling

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    a, b := 8.0, 2.0
    op := "/"

    switch op {
    case "+":
        fmt.Println("Result:", a+b)
    case "-":
        fmt.Println("Result:", a-b)
    case "*":
        fmt.Println("Result:", a*b)
    case "/":
        if b != 0 {
            fmt.Println("Result:", a/b)
        } else {
            fmt.Println("Error: division by zero")
        }
    default:
        fmt.Println("Invalid operator")
    }
}
```
