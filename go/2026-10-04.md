## Exercise 1: Fibonacci Series
**Difficulty:** Basic
**Concepts:** slices, for loops, append

Generate the first `n` Fibonacci numbers and return them as a slice.

**Starter code:**
```go
package main

import "fmt"

func fibonacci(n int) []int {
	seq := []int{0, 1}
	for i := 2; i < n; i++ {
		seq = append(seq, seq[i-1]+seq[i-2])
	}
	return seq
}

func main() {
	fmt.Println(fibonacci(10))
}
```

**Task:** Extend `main` to print only the even Fibonacci numbers in the series.

## Exercise 2: GCD of Two Numbers
**Difficulty:** Basic
**Concepts:** for loops, multiple assignment

Compute the greatest common divisor of two integers.

**Starter code:**
```go
package main

import "fmt"

func gcd(a, b int) int {
	for b != 0 {
		a, b = b, a%b
	}
	return a
}

func main() {
	fmt.Println(gcd(48, 18))
}
```

**Task:** Extend `main` to compute the GCD of two numbers read from standard input.

## Exercise 3: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** variables, multiple assignment

Swap the values of two variables without a temporary variable.

**Starter code:**
```go
package main

import "fmt"

func main() {
	a, b := 5, 10
	a, b = b, a
	fmt.Println(a, b)
}
```

**Task:** Write a `swap` function that returns two swapped values, then call it from `main`.

## Exercise 4: Count Words in a String
**Difficulty:** Basic
**Concepts:** strings, Fields, len

Count the number of words in a string.

**Starter code:**
```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "the quick brown fox"
	words := strings.Fields(text)
	fmt.Println(len(words))
}
```

**Task:** Extend the program to also print each word and its length.

## Exercise 5: Leap Year Check
**Difficulty:** Basic
**Concepts:** functions, boolean logic

Determine whether a given year is a leap year.

**Starter code:**
```go
package main

import "fmt"

func isLeap(year int) bool {
	return year%4 == 0 && (year%100 != 0 || year%400 == 0)
}

func main() {
	fmt.Println(isLeap(2024))
}
```

**Task:** Extend `main` to print all leap years between 2000 and 2100.
