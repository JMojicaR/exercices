## Exercise 1: Even or Odd
**Difficulty:** Basic
**Concepts:** `fmt`, functions, `%` operator, `main`, slices.

Write a program that classifies a slice of numbers as even or odd.

**Starter code:**
```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2, 3, 4, 5, 6}

	for _, n := range numbers {
		if n%2 == 0 {
			fmt.Printf("%d is even\n", n)
		} else {
			fmt.Printf("%d is odd\n", n)
		}
	}
}
```

**Task:** Read a number from stdin with `fmt.Scan` and classify just that one number.

## Exercise 2: Reverse a String
**Difficulty:** Basic
**Concepts:** Strings, `[]rune`, loops, Unicode handling.

Write a function that reverses a string (handling Unicode correctly with runes).

**Starter code:**
```go
package main

import "fmt"

func reverse(s string) string {
	runes := []rune(s)
	for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
		runes[i], runes[j] = runes[j], runes[i]
	}
	return string(runes)
}

func main() {
	fmt.Println(reverse("hello")) // "olleh"
}
```

**Task:** Reverse a full sentence and print it, keeping spaces intact.

## Exercise 3: Sum of a Slice
**Difficulty:** Basic
**Concepts:** Slices, `for range`, accumulation, `float64` conversion.

Write a program that computes the sum and average of a slice of integers.

**Starter code:**
```go
package main

import "fmt"

func main() {
	numbers := []int{12, 7, 45, 3, 28}

	sum := 0
	for _, n := range numbers {
		sum += n
	}

	average := float64(sum) / float64(len(numbers))
	fmt.Println("Sum =", sum)
	fmt.Printf("Average = %.2f\n", average)
}
```

**Task:** Also find and print the maximum value in the slice.

## Exercise 4: Factorial
**Difficulty:** Basic
**Concepts:** Functions, loops, `uint64`, return values.

Write a function that returns `n!` and print factorials from 0 to 10.

**Starter code:**
```go
package main

import "fmt"

func factorial(n uint64) uint64 {
	result := uint64(1)
	for i := uint64(1); i <= n; i++ {
		result *= i
	}
	return result
}

func main() {
	for n := uint64(0); n <= 10; n++ {
		fmt.Printf("%d! = %d\n", n, factorial(n))
	}
}
```

**Task:** Write a recursive version and compare results.

## Exercise 5: Check Prime Number
**Difficulty:** Basic
**Concepts:** Functions, loops, `math.Sqrt`, boolean return.

Write a function that reports whether a number is prime.

**Starter code:**
```go
package main

import (
	"fmt"
	"math"
)

func isPrime(n int) bool {
	if n < 2 {
		return false
	}
	for i := 2; i <= int(math.Sqrt(float64(n))); i++ {
		if n%i == 0 {
			return false
		}
	}
	return true
}

func main() {
	for n := 1; n <= 20; n++ {
		if isPrime(n) {
			fmt.Println(n, "is prime")
		}
	}
}
```

**Task:** Print all prime numbers between 1 and 100.
