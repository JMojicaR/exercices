## Exercise 1: Hello, Name!
**Difficulty:** Basic
**Concepts:** `bufio`, `os.Stdin`, `strings.TrimSpace`, packages.

Write a program that reads the user's name and prints a greeting.

**Starter code:**
```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"strings"
)

func main() {
	reader := bufio.NewReader(os.Stdin)
	fmt.Print("Enter your name: ")
	name, _ := reader.ReadString('\n')
	fmt.Println("Hello,", strings.TrimSpace(name), "!")
}
```

**Task:** Also read a number and print it doubled.

## Exercise 2: Sum of Two Numbers
**Difficulty:** Basic
**Concepts:** `fmt.Scan`, variables, `var`, arithmetic.

Write a program that reads two integers and prints their sum.

**Starter code:**
```go
package main

import "fmt"

func main() {
	var a, b int
	fmt.Print("Enter two numbers: ")
	fmt.Scan(&a, &b)
	fmt.Println("Sum:", a+b)
}
```

**Task:** Also print the difference and product.

## Exercise 3: Even or Odd
**Difficulty:** Basic
**Concepts:** Modulo (`%`), `if`/`else`, input.

Write a program that reads an integer and prints whether it is even or odd.

**Starter code:**
```go
package main

import "fmt"

func main() {
	var n int
	fmt.Print("Enter a number: ")
	fmt.Scan(&n)
	if n%2 == 0 {
		fmt.Println(n, "is even")
	} else {
		fmt.Println(n, "is odd")
	}
}
```

**Task:** Loop over a slice of numbers and classify each one as even or odd.

## Exercise 4: Factorial
**Difficulty:** Basic
**Concepts:** `for` loops, accumulator variables, `Printf`.

Write a program that computes the factorial of a number.

**Starter code:**
```go
package main

import "fmt"

func main() {
	n := 5
	f := 1
	for i := 1; i <= n; i++ {
		f *= i
	}
	fmt.Printf("%d! = %d\n", n, f)
}
```

**Task:** Read `n` from the user and handle `n = 0` (should print `0! = 1`).

## Exercise 5: Count Vowels
**Difficulty:** Basic
**Concepts:** `range` over strings, `switch`, `strings.ToLower`, runes.

Write a program that counts the vowels in a string.

**Starter code:**
```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := strings.ToLower("Hello World")
	count := 0
	for _, c := range text {
		switch c {
		case 'a', 'e', 'i', 'o', 'u':
			count++
		}
	}
	fmt.Println("Vowels:", count)
}
```

**Task:** Count consonants as well (letters that are not vowels, ignoring spaces).
