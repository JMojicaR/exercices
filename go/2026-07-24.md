## Exercise 4: Struct Methods — Circle and Rectangle
**Difficulty:** ⭐⭐ Basic  
**Concepts:** Structs, methods, interfaces, math

**Description:** Define a `Shape` interface with `Area() float64` and `Perimeter() float64`. Implement it for `Circle` and `Rectangle` structs. Write a `describeShape(s Shape)` function that prints the shape's area and perimeter. Create instances and test in `main()`.

**Starter Code:**
```go
package main

import (
    "fmt"
    "math"
)

type Shape interface {
    Area() float64
    Perimeter() float64
}

type Circle struct {
    Radius float64
}

// Implement Area() and Perimeter() for Circle

type Rectangle struct {
    Width  float64
    Height float64
}

// Implement Area() and Perimeter() for Rectangle

func describeShape(s Shape) {
    fmt.Printf("Area: %.2f, Perimeter: %.2f\n", s.Area(), s.Perimeter())
}

func main() {
    c := Circle{Radius: 5.0}
    r := Rectangle{Width: 4.0, Height: 7.0}

    fmt.Println("Circle:")
    describeShape(c)
    fmt.Println("Rectangle:")
    describeShape(r)
}
```

**Expected Learning:** `type` keyword, `struct` definition, method syntax (`func (c Circle) Area()`), interface definition, implicit interface satisfaction, `math.Pi`.
