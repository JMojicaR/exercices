## Exercise 4: Palindrome Checker

### Problem
Write a Go function `isPalindrome(s string) bool` that checks whether a given string reads the same forwards and backwards (ignoring case). Test it with a few strings in `main()`.

### Concepts
- `string` type
- `for` loop with index
- `len()` function
- `strings.ToLower()` from `"strings"` package
- Boolean return values

### Example/Starter Code
```go
package main

import (
    "fmt"
    "strings"
)

func isPalindrome(s string) bool {
    s = strings.ToLower(s)
    // TODO: Check if s is a palindrome

    return false
}

func main() {
    words := []string{"racecar", "hello", "Madam", "Go"}
    for _, w := range words {
        fmt.Printf("'%s' is palindrome: %v\n", w, isPalindrome(w))
    }
}
```

## Exercise 5: Simple Calculator with Switch

### Problem
Write a Go program that performs basic arithmetic operations (add, subtract, multiply, divide) on two numbers. Use a `switch` statement to select the operation. Handle division by zero gracefully.

### Concepts
- `switch` statement
- Functions (operation functions)
- Error handling (division by zero check)
- `fmt.Scan()` or hardcoded values

### Example/Starter Code
```go
package main

import "fmt"

func main() {
    var a, b float64 = 10, 5
    var operator string = "+"

    // TODO: Use a switch on the operator to perform the correct calculation
    // Supported operators: "+", "-", "*", "/"
    // Print the result

    result := 0.0
    switch operator {
    case "+":
        result = a + b
    // TODO: Add cases for "-", "*", "/"
    default:
        fmt.Println("Unknown operator")
        return
    }

    fmt.Printf("%.2f %s %.2f = %.2f\n", a, operator, b, result)
}
```
