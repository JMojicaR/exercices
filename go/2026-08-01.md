**Difficulty:** Basic

**Description:**

## Exercise 5: Simple Error Handling — Safe Division
**Difficulty:** Basic

**Description:**
Write a function `safeDivide` that divides two integers and returns both the result and an error. If the divisor is zero, return an error with a descriptive message. In `main`, call the function with valid and invalid inputs and handle the error. This exercise introduces Go's idiomatic error handling pattern.

**Concepts:**
- Multiple return values
- The `error` interface and `errors.New`
- Error handling with `if err != nil`
- `fmt.Errorf` for formatted error messages

**Starter Code:**
```go
package main

import (
    "errors"
    "fmt"
)

func safeDivide(a, b float64) (float64, error) {
    // TODO: Divide a by b safely
    // Return an error if b is zero
    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}

func main() {
    // Test with valid division
    result, err := safeDivide(10, 2)
    if err != nil {
        fmt.Println("Error:", err)
    } else {
        fmt.Printf("10 / 2 = %.1f\n", result)
    }

    // Test with division by zero
    result, err = safeDivide(5, 0)
    if err != nil {
        fmt.Println("Error:", err)
    } else {
        fmt.Printf("5 / 0 = %.1f\n", result)
    }
}
```
