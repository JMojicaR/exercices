## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** functions, `for` loop, `:=`, named return, `fmt.Println`

Compute `n!` and return it as an `int`.

**Starter code:**
```go
package main

import "fmt"

func factorial(n int) int {
	result := 1
	for i := 1; i <= n; i++ {
		result *= i
	}
	return result
}

func main() {
	fmt.Println(factorial(5)) // 120
	fmt.Println(factorial(0)) // 1
}
```

**Task:** Rewrite the function using recursion, returning `1` when `n <= 1`.

## Exercise 2: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** slices, `append`, multiple assignment `a, b = b, a+b`

Return the first `n` Fibonacci numbers as a slice.

**Starter code:**
```go
package main

import "fmt"

func fibonacci(n int) []int {
	seq := []int{}
	a, b := 0, 1
	for i := 0; i < n; i++ {
		seq = append(seq, a)
		a, b = b, a+b
	}
	return seq
}

func main() {
	fmt.Println(fibonacci(7)) // [0 1 1 2 3 5 8]
}
```

**Task:** Add an `nthFibonacci(n int) int` function that returns only the `n`-th value (0-indexed).

## Exercise 3: Check Prime Number
**Difficulty:** Basic
**Concepts:** `bool` return, `math.Sqrt`, `float64` cast, `for` loop

Return `true` if a number is prime, `false` otherwise.

**Starter code:**
```go
package main

import (
	"fmt"
	"math"
)

func isPrime(n int) bool {
	if n < 2 {
		return false
	}
	for i := 2; i <= int(math.Sqrt(float64(n))); i++ {
		if n%i == 0 {
			return false
		}
	}
	return true
}

func main() {
	fmt.Println(isPrime(7))  // true
	fmt.Println(isPrime(10)) // false
}
```

**Task:** Write a `countPrimes(limit int) int` function that returns the number of primes below `limit`.

## Exercise 4: Sum of Digits
**Difficulty:** Basic
**Concepts:** `%` and `/`, `for` (as `while`) loop, digit extraction

Return the sum of the individual digits of a number.

**Starter code:**
```go
package main

import "fmt"

func sumOfDigits(n int) int {
	sum := 0
	for n > 0 {
		sum += n % 10
		n /= 10
	}
	return sum
}

func main() {
	fmt.Println(sumOfDigits(1234)) // 10
}
```

**Task:** Rewrite it using `strconv.Itoa(n)` and iterating over the string's runes.

## Exercise 5: Greatest Common Divisor (GCD)
**Difficulty:** Basic
**Concepts:** Euclidean algorithm, `for` loop, multiple assignment, `%`

Compute the greatest common divisor of two integers.

**Starter code:**
```go
package main

import "fmt"

func gcd(a, b int) int {
	for b != 0 {
		a, b = b, a%b
	}
	return a
}

func main() {
	fmt.Println(gcd(48, 18)) // 6
	fmt.Println(gcd(100, 35)) // 5
}
```

**Task:** Add an `lcm(a, b int) int` function using `lcm(a, b) = a / gcd(a, b) * b`.
