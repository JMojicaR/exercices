## Exercise 5: Error Handling
- **Description**: Write a function `Divide(a, b float64) (float64, error)` that performs division. If `b` is zero, return an error with the message "cannot divide by zero". Otherwise, return the quotient and a nil error. In `main()`, call `Divide` with several pairs of numbers (including a division by zero), check the error using idiomatic Go patterns, and print either the result or the error message. Also write a `SafeDivide` wrapper function that recovers from a panic using `defer` and `recover`.
- **Difficulty**: Beginner
- **Concepts**: error handling, errors.New, fmt.Errorf, multiple return values, if err != nil, defer, panic, recover
- **Example/Starter Code**:
```go
package main

import (
    "errors"
    "fmt"
)

// Divide returns the quotient of a/b, or an error if b is zero.
func Divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("cannot divide by zero")
    }
    return a / b, nil
}

// SafeDivide recovers from panics during division.
func SafeDivide(a, b float64) (result float64, err error) {
    defer func() {
        if r := recover(); r != nil {
            err = fmt.Errorf("panic recovered: %v", r)
        }
    }()

    result, err = Divide(a, b)
    return
}

func main() {
    testCases := [][2]float64{
        {10, 2},
        {7, 3},
        {5, 0},
        {100, 25},
    }

    for _, tc := range testCases {
        a, b := tc[0], tc[1]
        result, err := Divide(a, b)
        if err != nil {
            fmt.Printf("Divide(%v, %v) → error: %v\n", a, b, err)
        } else {
            fmt.Printf("Divide(%v, %v) = %v\n", a, b, result)
        }
    }

    // Bonus: test SafeDivide
    safeResult, safeErr := SafeDivide(8, 0)
    fmt.Printf("SafeDivide(8, 0) = %v, err = %v\n", safeResult, safeErr)
}
```
