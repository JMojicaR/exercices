## Exercise 1: Hello World

**Difficulty:** Basic

### Problem
Write a Go program that prints "Hello, World!" and then prints the value of a string and an integer variable.

**Expected Output:**
```
Hello, World!
Name: Alice, Age: 25
```

### Concepts
- `package main` and `func main()`
- `fmt.Println`
- Variable declaration with `:=`

### Example / Starter Code

```go
package main

import "fmt"

func main() {
	name := "Alice"
	age := 25

	fmt.Println("Hello, World!")
	fmt.Println("Name:", name, "Age:", age)
}
```

## Exercise 2: Even or Odd

**Difficulty:** Basic

### Problem
Write a Go program that reads an integer and prints whether it is even or odd.

**Given Input:** `7`

**Expected Output:**
```
Enter a number: 7
7 is Odd
```

### Concepts
- `fmt.Scan` for input
- `if`/`else` and the modulo operator `%`

### Example / Starter Code

```go
package main

import "fmt"

func main() {
	var number int

	fmt.Print("Enter a number: ")
	fmt.Scan(&number)

	if number%2 == 0 {
		fmt.Printf("%d is Even\n", number)
	} else {
		fmt.Printf("%d is Odd\n", number)
	}
}
```

## Exercise 3: Sum of Numbers 1 to N

**Difficulty:** Basic

### Problem
Write a Go program that computes the sum of all integers from 1 to `n` using a `for` loop.

**Given Input:** `10`

**Expected Output:**
```
Sum from 1 to 10 is 55
```

### Concepts
- `for` loop (Go's only loop)
- Accumulator variable

### Example / Starter Code

```go
package main

import "fmt"

func main() {
	n := 10
	total := 0

	for i := 1; i <= n; i++ {
		total += i
	}

	fmt.Printf("Sum from 1 to %d is %d\n", n, total)
}
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a Go program that counts the vowels (a, e, i, o, u) in a string, ignoring case.

**Given Input:** `"Hello World"`

**Expected Output:**
```
Number of vowels: 3
```

### Concepts
- `for _, c := range text` over a string (runes)
- `strings.ToLower`
- `switch` statement

### Example / Starter Code

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := strings.ToLower("Hello World")
	count := 0

	for _, c := range text {
		switch c {
		case 'a', 'e', 'i', 'o', 'u':
			count++
		}
	}

	fmt.Println("Number of vowels:", count)
}
```

## Exercise 5: Find the Maximum in a Slice

**Difficulty:** Basic

### Problem
Write a Go program that finds and prints the largest value in an integer slice.

**Given Input:** `[]int{12, 5, 8, 130, 44}`

**Expected Output:**
```
Maximum is 130
```

### Concepts
- Slices
- `for _, v := range` loop
- Tracking a running maximum

### Example / Starter Code

```go
package main

import "fmt"

func main() {
	numbers := []int{12, 5, 8, 130, 44}

	max := numbers[0]
	for _, v := range numbers {
		if v > max {
			max = v
		}
	}

	fmt.Println("Maximum is", max)
}
```
