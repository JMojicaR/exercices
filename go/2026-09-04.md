## Exercise 1: Bubble Sort

**Difficulty:** Basic

### Problem
Write a program that sorts an `[]int` slice in ascending order using bubble sort.

**Given Input:** `[]int{64, 34, 25, 12, 22, 11, 90}`

**Expected Output:**
```
Sorted: [11 12 22 25 34 64 90]
```

### Concepts
- Slices and `len()`
- Nested `for` loops
- Tuple assignment swap `a, b = b, a`

### Example / Starter Code

```go
package main

import "fmt"

func bubbleSort(arr []int) {
    n := len(arr)
    for i := 0; i < n-1; i++ {
        for j := 0; j < n-i-1; j++ {
            if arr[j] > arr[j+1] {
                arr[j], arr[j+1] = arr[j+1], arr[j]
            }
        }
    }
}

func main() {
    nums := []int{64, 34, 25, 12, 22, 11, 90}
    bubbleSort(nums)
    fmt.Println("Sorted:", nums)
}
```

## Exercise 2: Linear Search

**Difficulty:** Basic

### Problem
Write a program with a `linearSearch` function that returns the index of a target value in a slice, or `-1` if absent.

**Given Input:** `[]int{10, 23, 45, 70, 11, 15}`, target `70`

**Expected Output:**
```
Found at index 3
```

### Concepts
- `for i, v := range`
- Multiple return value pattern (index + found)
- `-1` sentinel

### Example / Starter Code

```go
package main

import "fmt"

func linearSearch(arr []int, target int) int {
    for i, v := range arr {
        if v == target {
            return i
        }
    }
    return -1
}

func main() {
    nums := []int{10, 23, 45, 70, 11, 15}
    index := linearSearch(nums, 70)
    if index != -1 {
        fmt.Printf("Found at index %d\n", index)
    } else {
        fmt.Println("Not found")
    }
}
```

## Exercise 3: Anagram Check

**Difficulty:** Basic

### Problem
Write a program that checks whether two strings are anagrams, ignoring case.

**Given Input:** `"listen"`, `"silent"`

**Expected Output:**
```
Anagram
```

### Concepts
- `strings.ToLower`, `strings.Split`, `strings.Join`
- `sort.Strings`
- Rune handling

### Example / Starter Code

```go
package main

import (
    "fmt"
    "sort"
    "strings"
)

func isAnagram(s1, s2 string) bool {
    a := strings.Split(strings.ToLower(s1), "")
    b := strings.Split(strings.ToLower(s2), "")
    sort.Strings(a)
    sort.Strings(b)
    return strings.Join(a, "") == strings.Join(b, "")
}

func main() {
    if isAnagram("listen", "silent") {
        fmt.Println("Anagram")
    } else {
        fmt.Println("Not an anagram")
    }
}
```

## Exercise 4: Greatest Common Divisor (GCD)

**Difficulty:** Basic

### Problem
Write a program that computes the GCD of two integers using the Euclidean algorithm.

**Given Input:** `48`, `18`

**Expected Output:**
```
GCD: 6
```

### Concepts
- `for` loop as `while`
- Modulo `%`
- Tuple assignment

### Example / Starter Code

```go
package main

import "fmt"

func gcd(a, b int) int {
    for b != 0 {
        a, b = b, a%b
    }
    return a
}

func main() {
    fmt.Println("GCD:", gcd(48, 18))
}
```

## Exercise 5: Armstrong Number Check

**Difficulty:** Basic

### Problem
Write a program that checks whether a number is an Armstrong number.

**Given Input:** `153`

**Expected Output:**
```
Armstrong
```

### Concepts
- `strconv.Itoa`
- `range` over a string (runes)
- `math.Pow` with `float64` conversions

### Example / Starter Code

```go
package main

import (
    "fmt"
    "math"
    "strconv"
)

func isArmstrong(n int) bool {
    s := strconv.Itoa(n)
    power := float64(len(s))
    total := 0.0
    for _, c := range s {
        total += math.Pow(float64(c-'0'), power)
    }
    return int(total) == n
}

func main() {
    if isArmstrong(153) {
        fmt.Println("Armstrong")
    } else {
        fmt.Println("Not Armstrong")
    }
}
```
