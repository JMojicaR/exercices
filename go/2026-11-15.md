# Go — Basic Exercises (2026-11-15)
Sources: A Tour of Go, Go by Example, GeeksforGeeks, go.dev

Theme: **Error Handling in Go** — returning `error` values, `errors.New`, `fmt.Errorf` with context, checking errors from the standard library, `panic`/`recover`, and custom error types. Go has no exceptions; errors are ordinary return values.

## Exercise 1: Returning an error Value
**Difficulty:** Basic
**Concepts:** `error` return type, `errors.New`, `nil` for success, the `if err != nil` idiom

Return an error from a function and check it at the call site.

**Starter code:**
```go
package main

import (
    "errors"
    "fmt"
)

func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}

func main() {
    result, err := divide(10, 0)
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    fmt.Println("Result:", result)
}
```

**Task:** Call `divide(10, 2)` and confirm the result prints while `err` stays `nil`.

## Exercise 2: fmt.Errorf with Context
**Difficulty:** Basic
**Concepts:** `fmt.Errorf`, formatting the error message with values

Include the offending values in the error message.

**Starter code:**
```go
package main

import "fmt"

func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("cannot divide %v by %v", a, b)
    }
    return a / b, nil
}

func main() {
    if _, err := divide(10, 0); err != nil {
        fmt.Println("Error:", err)
    }
}
```

**Task:** Add a check for negative `b` that returns `fmt.Errorf("negative divisor %v is not allowed", b)` and call it.

## Exercise 3: Checking strconv.Atoi Errors
**Difficulty:** Basic
**Concepts:** `strconv.Atoi`, `continue` on error, iterating a slice of strings

Parse a slice of strings, skipping and reporting the non-numeric entries.

**Starter code:**
```go
package main

import (
    "fmt"
    "strconv"
)

func main() {
    inputs := []string{"10", "abc", "5"}
    for _, s := range inputs {
        n, err := strconv.Atoi(s)
        if err != nil {
            fmt.Printf("'%s' is not a number\n", s)
            continue
        }
        fmt.Println("Parsed:", n)
    }
}
```

**Task:** Sum only the successfully parsed numbers and print the total at the end.

## Exercise 4: panic and recover
**Difficulty:** Basic
**Concepts:** `panic`, `defer`, `recover`, stopping a panic from crashing the program

Recover from a panic inside a deferred function.

**Starter code:**
```go
package main

import "fmt"

func safeFunction() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("Recovered from panic:", r)
        }
    }()
    panic("something went wrong")
}

func main() {
    fmt.Println("Before")
    safeFunction()
    fmt.Println("After")
}
```

**Task:** Remove the `recover` call and observe that the program crashes before printing "After" — then restore it.

## Exercise 5: A Custom Error Type
**Difficulty:** Basic
**Concepts:** implementing the `error` interface (`Error() string`), a struct holding error details

Define a custom error type that carries extra information.

**Starter code:**
```go
package main

import "fmt"

type NegativeAgeError struct {
    Age int
}

func (e NegativeAgeError) Error() string {
    return fmt.Sprintf("age cannot be negative: %d", e.Age)
}

func checkAge(age int) error {
    if age < 0 {
        return NegativeAgeError{Age: age}
    }
    return nil
}

func main() {
    if err := checkAge(-1); err != nil {
        fmt.Println("Error:", err)
    }
}
```

**Task:** Add a `TooOldError` type for `age > 150` and use `switch err.(type)` in `main` to print a different message for each error type.
