## Exercise 3: Goroutines and Channels

**Title:** Concurrent Number Squaring with Goroutines

**Description:**  
Write a program that squares a slice of integers concurrently using goroutines. Each goroutine should square one number and send the result through a channel. The main goroutine should collect all results and print them in order. Use a buffered channel or wait for all goroutines to finish with a `sync.WaitGroup`.

**Concepts Practiced:** Goroutines, channels, `sync.WaitGroup`, concurrency, `go` keyword

**Difficulty:** Basic

**Starter Code:**
```go
package main

import (
	"fmt"
	"sync"
)

	// Square the number and send to channel
	// Decrement the WaitGroup
}

func main() {
	numbers := []int{2, 4, 6, 8, 10}
	resultChan := make(chan int, len(numbers))
	var wg sync.WaitGroup

	for _, n := range numbers {
		wg.Add(1)
		go squareWorker(n, resultChan, &wg)
	}

	// Wait for all workers to finish, then close the channel
	go func() {
		wg.Wait()
		close(resultChan)
	}()

	// Collect and print results
	squares := make([]int, 0, len(numbers))
	for result := range resultChan {
		squares = append(squares, result)
	}

	fmt.Println("Squares:", squares)
	// Expected (order may vary): Squares: [4 16 36 64 100]
}
```
