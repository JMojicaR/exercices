## Exercise 3: Greeting Function — Functions & Multiple Returns

| Field | Detail |
|-------|--------|
| **Difficulty** | ★★☆☆☆ |
| **Concepts** | Functions, multiple return values, `error`, `fmt.Sprintf` |

**Description:**  
Write a function `greet(name string) (string, error)` that returns a greeting.  
If `name` is empty, return an error. In `main()`, handle the error.

**Starter Code:**
```go
package main

import (
    "errors"
    "fmt"
)

func greet(name string) (string, error) {
    if name == "" {
        return "", errors.New("name cannot be empty")
    }
    // TODO: Return greeting
}

func main() {
    msg, err := greet("Alice")
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    fmt.Println(msg)

    // Test with empty name
    msg2, err2 := greet("")
    if err2 != nil {
        fmt.Println("Error:", err2)
    }
}
```

## Exercise 5: Simple Struct & Methods — Structs

| Field | Detail |
|-------|--------|
| **Difficulty** | ★★★☆☆ |
| **Concepts** | `type ... struct`, methods with value receiver and pointer receiver, `fmt.Printf` |

**Description:**  
Define a `Circle` struct with a `Radius` field (float64).  
Implement methods:
- `Area() float64` — returns π * r²
- `Scale(factor float64)` — multiplies radius by factor (pointer receiver)

**Starter Code:**
```go
package main

import (
    "fmt"
    "math"
)

type Circle struct {
    Radius float64
}

// TODO: Area() float64 — value receiver
// TODO: Scale(factor float64) — pointer receiver

func main() {
    c := Circle{Radius: 5.0}
    fmt.Printf("Area: %.2f\n", c.Area())

    c.Scale(2.0)
    fmt.Printf("After scaling, radius: %.2f, area: %.2f\n", c.Radius, c.Area())
}
```
