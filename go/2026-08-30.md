## Exercise 1: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a Go program that reads a non-negative integer and prints its factorial using a `for` loop. Factorial of 0 is 1.

**Given Input:** `5`

**Expected Output:**
```
Factorial of 5 is 120
```

### Concepts
- `fmt.Scan` for input
- `for` loop accumulator
- `uint64` type

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    var n int
    fmt.Print("Enter a number: ")
    fmt.Scan(&n)

    factorial := uint64(1)
    for i := 1; i <= n; i++ {
        factorial *= uint64(i)
    }

    fmt.Printf("Factorial of %d is %d\n", n, factorial)
}
```

## Exercise 2: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a Go program that prints the first `n` terms of the Fibonacci sequence (`0, 1, 1, 2, 3, 5, …`).

**Given Input:** `7`

**Expected Output:**
```
0
1
1
2
3
5
8
```

### Concepts
- `for` loop (Go's only loop)
- Short variable declaration `:=`
- Multiple assignment swap

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    var n int
    fmt.Print("How many terms? ")
    fmt.Scan(&n)

    a, b := 0, 1
    for i := 0; i < n; i++ {
        fmt.Println(a)
        a, b = b, a+b
    }
}
```

## Exercise 3: Palindrome Check

**Difficulty:** Basic

### Problem
Write a Go program that reads a string and checks whether it is a palindrome (case-insensitive), using a rune slice.

**Given Input:** `Racecar`

**Expected Output:**
```
racecar is a palindrome
```

### Concepts
- `strings.ToLower`
- `[]rune` for Unicode-safe handling
- Two-pointer comparison

### Example / Starter Code

```go
package main

import (
    "fmt"
    "strings"
)

func main() {
    var text string
    fmt.Print("Enter a string: ")
    fmt.Scan(&text)

    runes := []rune(strings.ToLower(text))
    isPalindrome := true
    for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
        if runes[i] != runes[j] {
            isPalindrome = false
            break
        }
    }

    if isPalindrome {
        fmt.Printf("%s is a palindrome\n", text)
    } else {
        fmt.Printf("%s is not a palindrome\n", text)
    }
}
```

## Exercise 4: Prime Number Check

**Difficulty:** Basic

### Problem
Write a Go program that reads a positive integer and determines whether it is a prime number.

**Given Input:** `29`

**Expected Output:**
```
29 is a prime number
```

### Concepts
- `for` loop with `break`
- Modulo operator `%`
- `math.Sqrt` for early exit

### Example / Starter Code

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    var n int
    fmt.Print("Enter a number: ")
    fmt.Scan(&n)

    isPrime := n > 1
    for i := 2; isPrime && float64(i) <= math.Sqrt(float64(n)); i++ {
        if n%i == 0 {
            isPrime = false
        }
    }

    if isPrime {
        fmt.Printf("%d is a prime number\n", n)
    } else {
        fmt.Printf("%d is not a prime number\n", n)
    }
}
```

## Exercise 5: Sum of Digits

**Difficulty:** Basic

### Problem
Write a Go program that reads a positive integer and prints the sum of its digits.

**Given Input:** `12345`

**Expected Output:**
```
Sum of digits: 15
```

### Concepts
- `for` loop as a `while` loop
- Modulo `%` and integer division `/`
- Digit extraction

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    var n int
    fmt.Print("Enter a number: ")
    fmt.Scan(&n)

    total := 0
    for n > 0 {
        total += n % 10
        n /= 10
    }

    fmt.Printf("Sum of digits: %d\n", total)
}
```
