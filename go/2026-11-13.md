## Exercise 1: Write Text to a File
**Difficulty:** Basic
**Concepts:** `os.WriteFile`, `[]byte` conversion, error handling with `if err != nil`

Write a program that creates a file named `notes.txt` and writes two lines into it. `os.WriteFile` creates the file if it doesn't exist and overwrites it if it does.

**Starter code:**
```go
package main

import (
	"fmt"
	"os"
)

func main() {
	content := []byte("First line\nSecond line\n")
	err := os.WriteFile("notes.txt", content, 0644)
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	fmt.Println("File written.")
}
```

**Task:** Build the content by joining a `[]string` slice with `strings.Join(lines, "\n")`, then write it. Explain what the `0644` permission argument means.

## Exercise 2: Read an Entire File
**Difficulty:** Basic
**Concepts:** `os.ReadFile`, `string` conversion, error handling

Write a program that reads the whole contents of `notes.txt` and prints it.

**Starter code:**
```go
package main

import (
	"fmt"
	"os"
)

func main() {
	data, err := os.ReadFile("notes.txt")
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	fmt.Print(string(data))
}
```

**Task:** Read the file line-by-line with `bufio.Scanner`, printing each line with its index. Remember to check `scanner.Err()` after the loop.

## Exercise 3: Append a Line to a File
**Difficulty:** Basic
**Concepts:** `os.OpenFile` with `O_APPEND`, `WriteString`

Write a program that adds a new line to the end of `notes.txt` without deleting the existing content.

**Starter code:**
```go
package main

import (
	"fmt"
	"os"
)

func main() {
	f, err := os.OpenFile("notes.txt", os.O_APPEND|os.O_WRONLY, 0644)
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	defer f.Close()

	if _, err := f.WriteString("Appended line\n"); err != nil {
		fmt.Println("Error:", err)
		return
	}
	fmt.Println("Appended.")
}
```

**Task:** Use a loop to append the numbers 1 through 5 with `fmt.Fprintf(f, "%d\n", i)`. Then read the file back to confirm the original lines remain.

## Exercise 4: Count Lines and Words
**Difficulty:** Basic
**Concepts:** `bufio.Scanner`, `strings.Fields`, counters

Write a program that opens `notes.txt` and reports the number of lines and the total number of words it contains.

**Starter code:**
```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"strings"
)

func main() {
	f, err := os.Open("notes.txt")
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	defer f.Close()

	scanner := bufio.NewScanner(f)
	lines := 0
	words := 0
	for scanner.Scan() {
		lines++
		words += len(strings.Fields(scanner.Text()))
	}
	if err := scanner.Err(); err != nil {
		fmt.Println("Error:", err)
		return
	}
	fmt.Println("Lines:", lines)
	fmt.Println("Words:", words)
}
```

**Task:** Also count characters with `len(scanner.Text())`. Then count how many lines contain "the" (case-insensitive) using `strings.Contains(strings.ToLower(scanner.Text()), "the")`.

## Exercise 5: Copy a File
**Difficulty:** Basic
**Concepts:** `io.Copy`, `os.Create`, `os.Open`, deferred closes

Write a program that copies the contents of `notes.txt` into a new file named `notes_copy.txt`.

**Starter code:**
```go
package main

import (
	"fmt"
	"io"
	"os"
)

func main() {
	src, err := os.Open("notes.txt")
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	defer src.Close()

	dst, err := os.Create("notes_copy.txt")
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	defer dst.Close()

	bytesCopied, err := io.Copy(dst, src)
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	fmt.Printf("Copied %d bytes.\n", bytesCopied)
}
```

**Task:** Check whether `notes_copy.txt` already exists with `os.Stat` (treating a "not exists" error as OK) and warn before overwriting. Then copy line-by-line with a `Scanner` instead of `io.Copy`.
