## Exercise 1: Number Guessing Game
**Difficulty:** Basic
**Concepts:** math/rand, bufio, strconv.Atoi, for loop

Generate a random number between 1 and 100 and let the user guess with hints.

**Starter code:**
```go
package main

import (
	"bufio"
	"fmt"
	"math/rand"
	"os"
	"strconv"
	"strings"
)

func main() {
	target := rand.Intn(100) + 1
	reader := bufio.NewReader(os.Stdin)

	for {
		fmt.Print("Guess a number (1-100): ")
		input, _ := reader.ReadString('\n')
		guess, err := strconv.Atoi(strings.TrimSpace(input))
		if err != nil {
			continue
		}
		if guess < target {
			fmt.Println("Too low!")
		} else if guess > target {
			fmt.Println("Too high!")
		} else {
			fmt.Println("You guessed it!")
			break
		}
	}
}
```

**Task:** Count the number of attempts and print it when the player wins.

## Exercise 2: Simple Calculator with switch
**Difficulty:** Basic
**Concepts:** switch, fmt.Scan, arithmetic

Read an operator and two numbers, then print the result.

**Starter code:**
```go
package main

import "fmt"

func main() {
	var op string
	var a, b float64
	fmt.Print("Enter operator (+, -, *, /): ")
	fmt.Scan(&op)
	fmt.Print("Enter two numbers: ")
	fmt.Scan(&a, &b)

	switch op {
	case "+":
		fmt.Println(a + b)
	case "-":
		fmt.Println(a - b)
	case "*":
		fmt.Println(a * b)
	case "/":
		if b != 0 {
			fmt.Println(a / b)
		} else {
			fmt.Println("Cannot divide by zero")
		}
	default:
		fmt.Println("Invalid operator")
	}
}
```

**Task:** Wrap the calculator in a loop that exits when the user enters `q`.

## Exercise 3: Sum of Natural Numbers
**Difficulty:** Basic
**Concepts:** for loop, accumulator

Compute the sum of all natural numbers from 1 to `n`.

**Starter code:**
```go
package main

import "fmt"

func main() {
	n := 10
	sum := 0
	for i := 1; i <= n; i++ {
		sum += i
	}
	fmt.Printf("Sum from 1 to %d is %d\n", n, sum)
}
```

**Task:** Verify against the formula `n * (n + 1) / 2` for several values of `n`.

## Exercise 4: Count Words in a String
**Difficulty:** Basic
**Concepts:** strings.Fields, len

Count the number of words in a string.

**Starter code:**
```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "The quick brown fox jumps over the lazy dog"
	words := strings.Fields(text)
	fmt.Println("Number of words:", len(words))
}
```

**Task:** Read the text from `fmt.Scan`/a reader and handle empty input (should print 0).

## Exercise 5: Find the Smallest Element in a Slice
**Difficulty:** Basic
**Concepts:** slices, range, comparison

Find the smallest value in a slice of integers.

**Starter code:**
```go
package main

import "fmt"

func main() {
	numbers := []int{34, 15, 88, 2, 42}
	min := numbers[0]
	for _, n := range numbers {
		if n < min {
			min = n
		}
	}
	fmt.Println("Smallest element:", min)
}
```

**Task:** Write a `smallest(s []int) int` function and call it with your own test slices.
