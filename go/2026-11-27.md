## Exercise 1: Define a Node and Build a Small Tree
**Difficulty:** Basic
**Concepts:** `struct`, pointer fields, `&Node{...}` composite literals

**Starter code:**
```go
package main

type Node struct {
    Value       int
    Left, Right *Node
}

func main() {
    //         8
    //        / \
    //       3   10
    root := &Node{Value: 8}
    root.Left  = &Node{Value: 3}
    root.Right = &Node{Value: 10}
}
```

**Task:** Build the full tree below and print `root.Left.Right.Value`:
```
       8
      / \
     3   10
    / \    \
   1   6    14
```
(Expected output: `6`.)

## Exercise 2: Insert a Value into the BST
**Difficulty:** Basic
**Concepts:** recursive function returning `*Node`, `nil` base case

**Starter code:**
```go
func insert(n *Node, value int) *Node {
    if n == nil {
        return &Node{Value: value}
    }
    if value < n.Value {
        n.Left = insert(n.Left, value)
    } else {
        n.Right = insert(n.Right, value)
    }
    return n
}

func main() {
    var root *Node
    for _, v := range []int{8, 3, 10, 1, 6} {
        root = insert(root, v)
    }
}
```

**Task:** Insert `14`, `4`, and `7`, then write a recursive `printTree(n *Node)` that prints `value (left, right)` for each node to confirm the structure.

## Exercise 3: Search for a Value
**Difficulty:** Basic
**Concepts:** recursive search, pruning half the tree, `bool` return

**Starter code:**
```go
func contains(n *Node, value int) bool {
    if n == nil {
        return false
    }
    if value == n.Value {
        return true
    } else if value < n.Value {
        return contains(n.Left, value)
    }
    return contains(n.Right, value)
}

func main() {
    var root *Node
    for _, v := range []int{8, 3, 10, 1, 6, 14, 4, 7} {
        root = insert(root, v)
    }
    fmt.Println(contains(root, 6))   // true
    fmt.Println(contains(root, 12))  // false
}
```

**Task:** Modify `contains` to return the depth (steps from the root) where the value is found, or `-1` if absent.

## Exercise 4: In-Order Traversal (Sorted Output)
**Difficulty:** Basic
**Concepts:** left → current → right recursion, appending to a slice via pointer

**Starter code:**
```go
func inorder(n *Node, out *[]int) {
    if n == nil {
        return
    }
    inorder(n.Left, out)
    *out = append(*out, n.Value)
    inorder(n.Right, out)
}

func main() {
    var root *Node
    for _, v := range []int{8, 3, 10, 1, 6, 14, 4, 7} {
        root = insert(root, v)
    }
    var out []int
    inorder(root, &out)
    fmt.Println(out)  // [1 3 4 6 7 8 10 14]
}
```

**Task:** Add a `preorder(n *Node, out *[]int)` function (current → left → right). Print both traversals and confirm `inorder` is sorted while `preorder` begins with `8`.

## Exercise 5: Find the Minimum and Maximum
**Difficulty:** Basic
**Concepts:** following `Left`/`Right` chains with a `for` loop

**Starter code:**
```go
func minValue(n *Node) int {
    for n.Left != nil {
        n = n.Left
    }
    return n.Value
}

func maxValue(n *Node) int {
    for n.Right != nil {
        n = n.Right
    }
    return n.Value
}

func main() {
    var root *Node
    for _, v := range []int{8, 3, 10, 1, 6, 14, 4, 7} {
        root = insert(root, v)
    }
    fmt.Println(minValue(root))  // 1
    fmt.Println(maxValue(root))  // 14
}
```

**Task:** Rewrite both functions using recursion instead of a `for` loop.
