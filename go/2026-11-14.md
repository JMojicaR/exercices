## Exercise 1: Define a Book Struct
**Difficulty:** Basic
**Concepts:** `type ... struct`, field access, `fmt.Println`

Define a `Book` struct with `Title`, `Author`, `Year`, and `Price` fields, create a value, and print its fields.

**Starter code:**
```go
package main

import "fmt"

type Book struct {
    Title  string
    Author string
    Year   int
    Price  float64
}

func main() {
    book := Book{
        Title:  "1984",
        Author: "George Orwell",
        Year:   1949,
        Price:  12.50,
    }

    fmt.Printf("%s by %s (%d) — $%.2f\n", book.Title, book.Author, book.Year, book.Price)
}
```

**Task:** Add a `Pages int` field and print it alongside the other fields.

## Exercise 2: Create and Use Multiple Values
**Difficulty:** Basic
**Concepts:** slices of structs, `range`, method calls

Store three `Book` values in a slice and print each one with a `range` loop.

**Starter code:**
```go
package main

import "fmt"

type Book struct {
    Title  string
    Author string
    Year   int
}

func (b Book) Describe() string {
    return fmt.Sprintf("%s by %s (%d)", b.Title, b.Author, b.Year)
}

func main() {
    books := []Book{
        {Title: "1984", Author: "George Orwell", Year: 1949},
        {Title: "Dune", Author: "Frank Herbert", Year: 1965},
        {Title: "Neuromancer", Author: "William Gibson", Year: 1984},
    }

    for _, b := range books {
        fmt.Println(b.Describe())
    }
}
```

**Task:** Add a `Price float64` field and print the total price of all books by summing inside the loop.

## Exercise 3: Methods with Value Receivers
**Difficulty:** Basic
**Concepts:** methods, value receiver `(b Book)`, return values

Add methods that compute derived values from the struct's fields.

**Starter code:**
```go
package main

import "fmt"

type Book struct {
    Title  string
    Author string
    Year   int
    Price  float64
}

func (b Book) Age(currentYear int) int {
    return currentYear - b.Year
}

func (b Book) DiscountedPrice(percent float64) float64 {
    return b.Price * (1 - percent/100)
}

func main() {
    book := Book{Title: "Dune", Author: "Frank Herbert", Year: 1965, Price: 15.99}
    fmt.Println("Age:", book.Age(2026))
    fmt.Printf("Discounted: %.2f\n", book.DiscountedPrice(20))
}
```

**Task:** Add an `IsClassic(currentYear int) bool` method returning `true` when the book is 50+ years old, and test it on several books.

## Exercise 4: Methods with Pointer Receivers
**Difficulty:** Basic
**Concepts:** pointer receiver `(b *Book)`, in-place mutation, `&` address-of

Add a method that modifies the struct's fields in place using a pointer receiver.

**Starter code:**
```go
package main

import "fmt"

type Book struct {
    Title  string
    Author string
    Year   int
    Price  float64
}

func (b *Book) ApplyDiscount(percent float64) {
    b.Price *= 1 - percent/100
}

func main() {
    book := Book{Title: "1984", Author: "George Orwell", Year: 1949, Price: 12.50}
    fmt.Printf("Before: $%.2f\n", book.Price)
    book.ApplyDiscount(20)
    fmt.Printf("After: $%.2f\n", book.Price)
}
```

**Task:** Add a `Retitle(newTitle string)` method using a pointer receiver, and demonstrate it. Note that Go automatically takes the address of `book` when calling a pointer-receiver method.

## Exercise 5: A Library That Holds Books
**Difficulty:** Basic
**Concepts:** composition, slices, `nil` return, search methods

Build a `Library` struct that stores `Book` values in a slice and can add, list, and find them.

**Starter code:**
```go
package main

import "fmt"
import "strings"

type Book struct {
    Title  string
    Author string
    Year   int
}

func (b Book) Describe() string {
    return fmt.Sprintf("%s by %s (%d)", b.Title, b.Author, b.Year)
}

type Library struct {
    Books []Book
}

func (l *Library) Add(book Book) {
    l.Books = append(l.Books, book)
}

func (l *Library) Find(title string) *Book {
    for i := range l.Books {
        if strings.EqualFold(l.Books[i].Title, title) {
            return &l.Books[i]
        }
    }
    return nil
}

func (l *Library) List() {
    for _, b := range l.Books {
        fmt.Println(b.Describe())
    }
}

func main() {
    lib := Library{}
    lib.Add(Book{Title: "Dune", Author: "Frank Herbert", Year: 1965})
    lib.Add(Book{Title: "1984", Author: "George Orwell", Year: 1949})
    lib.List()

    found := lib.Find("dune")
    if found != nil {
        fmt.Println("Found:", found.Describe())
    }
}
```

**Task:** Add a `Count() int` method and a `BooksByYear(year int) []Book` method using a slice append inside a loop.
