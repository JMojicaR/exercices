## Exercise 1: Check Leap Year

**Difficulty:** Basic

### Problem
Write a function that checks whether a given year is a leap year using the standard rules (divisible by 400 is leap, divisible by 100 is not, divisible by 4 is leap). Print the result for a sample year.

**Given Input:** `isLeapYear(2024)`

**Expected Output:**
```
2024 is a leap year.
```

### Concepts
- Function definitions and return types
- `if` / `else` branching
- Modulo operator (`%`)
- `fmt.Printf` formatting

### Example / Starter Code

```go
package main

import "fmt"

func isLeapYear(year int) bool {
    if year%400 == 0 {
        return true
    }
    if year%100 == 0 {
        return false
    }
    return year%4 == 0
}

func main() {
    year := 2024
    if isLeapYear(year) {
        fmt.Printf("%d is a leap year.\n", year)
    } else {
        fmt.Printf("%d is not a leap year.\n", year)
    }
}
```

## Exercise 2: GCD of Two Numbers

**Difficulty:** Basic

### Problem
Write a function that computes the greatest common divisor (GCD) of two positive integers using the Euclidean algorithm (repeated modulo). Print the GCD of a sample pair.

**Given Input:** `gcd(48, 18)`

**Expected Output:**
```
GCD of 48 and 18 is 6
```

### Concepts
- `for` loops (Go's only loop construct)
- Multiple assignment (`a, b = b, a%b`)
- Euclidean algorithm
- Named return values and parameter lists

### Example / Starter Code

```go
package main

import "fmt"

func gcd(a, b int) int {
    for b != 0 {
        a, b = b, a%b
    }
    return a
}

func main() {
    a, b := 48, 18
    fmt.Printf("GCD of %d and %d is %d\n", a, b, gcd(a, b))
}
```

## Exercise 3: Count Digits in an Integer

**Difficulty:** Basic

### Problem
Write a function that counts how many digits are in a given integer (ignoring the sign). Print the digit count for a sample number.

**Given Input:** `countDigits(12345)`

**Expected Output:**
```
12345 has 5 digits.
```

### Concepts
- `for` loop as a `while` loop
- Handling negative numbers
- Integer division
- Accumulator counting pattern

### Example / Starter Code

```go
package main

import "fmt"

func countDigits(number int) int {
    if number < 0 {
        number = -number
    }
    count := 0
    for number > 0 {
        number /= 10
        count++
    }
    return count
}

func main() {
    number := 12345
    fmt.Printf("%d has %d digits.\n", number, countDigits(number))
}
```

## Exercise 4: Check Positive / Negative / Zero

**Difficulty:** Basic

### Problem
Write a function that returns a string describing whether an integer is positive, negative, or zero. Print the result for a sample number.

**Given Input:** `checkNumber(-7)`

**Expected Output:**
```
-7 is negative.
```

### Concepts
- `if` / `else if` / `else` branching
- Returning strings from functions
- Comparison operators (`>`, `<`)

### Example / Starter Code

```go
package main

import "fmt"

func checkNumber(num int) string {
    if num > 0 {
        return "positive"
    } else if num < 0 {
        return "negative"
    }
    return "zero"
}

func main() {
    num := -7
    fmt.Printf("%d is %s.\n", num, checkNumber(num))
}
```

## Exercise 5: Sum of Even Numbers from 1 to n

**Difficulty:** Basic

### Problem
Write a function that sums all even numbers from 1 to `n` (inclusive) using a loop and an `if` check for evenness. Print the result for a sample `n`.

**Given Input:** `sumOfEvenNumbers(10)`

**Expected Output:**
```
Sum of even numbers from 1 to 10 is 30
```

### Concepts
- `for` loops with a range of indices
- Modulo operator for even-number checks
- Accumulator (`sum += i`)
- Short variable declaration (`:=`)

### Example / Starter Code

```go
package main

import "fmt"

func sumOfEvenNumbers(n int) int {
    sum := 0
    for i := 1; i <= n; i++ {
        if i%2 == 0 {
            sum += i
        }
    }
    return sum
}

func main() {
    n := 10
    fmt.Printf("Sum of even numbers from 1 to %d is %d\n", n, sumOfEvenNumbers(n))
}
```
