## Exercise 1: Hello, Name!
**Difficulty:** Basic
**Concepts:** `package main`, `import "fmt"`, `fmt.Scanln`, `fmt.Printf`.

Write a program that reads the user's name and greets them.

**Starter code:**
```go
package main

import "fmt"

func main() {
    var name string

    fmt.Print("What is your name? ")
    fmt.Scanln(&name)

    fmt.Printf("Hello, %s!\n", name)
}
```

**Task:** Read the user's age and print a message that includes both name and age.

## Exercise 2: Leap Year Checker
**Difficulty:** Basic
**Concepts:** Conditionals, modulo, logical operators (`&&`, `||`).

Write a program that reads a year and reports whether it is a leap year.

**Starter code:**
```go
package main

import "fmt"

func main() {
    var year int
    fmt.Print("Enter a year: ")
    fmt.Scanln(&year)

    if year%400 == 0 || (year%4 == 0 && year%100 != 0) {
        fmt.Println("Leap year")
    } else {
        fmt.Println("Not a leap year")
    }
}
```

**Task:** Print the next leap year after the one the user entered.

## Exercise 3: Fibonacci Series
**Difficulty:** Basic
**Concepts:** Loops, multiple variable assignment, sequence updating.

Write a program that prints the first N Fibonacci numbers.

**Starter code:**
```go
package main

import "fmt"

func main() {
    var n int
    fmt.Print("How many terms? ")
    fmt.Scanln(&n)

    a, b := 0, 1
    for i := 0; i < n; i++ {
        fmt.Printf("%d ", a)
        a, b = b, a+b
    }
    fmt.Println()
}
```

**Task:** Print the Fibonacci numbers separated by commas.

## Exercise 4: Reverse a String
**Difficulty:** Basic
**Concepts:** Strings, `[]rune`, loops, indexing.

Write a program that reads a string and prints it reversed (handling Unicode characters correctly with runes).

**Starter code:**
```go
package main

import "fmt"

func main() {
    var text string
    fmt.Print("Enter a string: ")
    fmt.Scanln(&text)

    runes := []rune(text)
    for i := len(runes) - 1; i >= 0; i-- {
        fmt.Printf("%c", runes[i])
    }
    fmt.Println()
}
```

**Task:** Check whether the string is a palindrome.

## Exercise 5: Sum of a Slice
**Difficulty:** Basic
**Concepts:** Slices, `range`, accumulation, length.

Write a program that computes the sum and average of a slice of numbers.

**Starter code:**
```go
package main

import "fmt"

func main() {
    numbers := []int{15, 22, 8, 37, 4}

    sum := 0
    for _, n := range numbers {
        sum += n
    }

    average := float64(sum) / float64(len(numbers))

    fmt.Println("Sum:", sum)
    fmt.Printf("Average: %.2f\n", average)
}
```

**Task:** Find and print the maximum and minimum values in the slice.
