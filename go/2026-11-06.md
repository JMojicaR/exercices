## Exercise 1: Find Maximum & Minimum
**Difficulty:** Basic
**Concepts:** slice literal, `range`, multiple assignment, comparisons

Find and print the smallest and largest values in a slice of integers.

**Starter code:**
```go
package main

import "fmt"

func main() {
	numbers := []int{3, 1, 4, 1, 5, 9, 2}
	min, max := numbers[0], numbers[0]
	for _, n := range numbers {
		if n < min {
			min = n
		}
		if n > max {
			max = n
		}
	}
	fmt.Printf("min = %d, max = %d\n", min, max) // min = 1, max = 9
}
```

**Task:** Refactor into a `func minMax(nums []int) (int, int)` function that returns both values, and handle the empty-slice case.

## Exercise 2: Sum of Elements
**Difficulty:** Basic
**Concepts:** slice, `range`, `:=`, accumulator

Compute and print the sum of all elements in a slice of integers.

**Starter code:**
```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2, 3, 4, 5}
	total := 0
	for _, n := range numbers {
		total += n
	}
	fmt.Printf("sum = %d\n", total) // sum = 15
}
```

**Task:** Wrap the loop in a `func sum(nums []int) int` function, then compute the average as a `float64` using `float64(total) / float64(len(numbers))`.

## Exercise 3: Reverse a Slice
**Difficulty:** Basic
**Concepts:** `make`, `append`, reverse indexing

Build a new slice holding the elements of the input in reverse order.

**Starter code:**
```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2, 3, 4}
	reversed := make([]int, 0, len(numbers))
	for i := len(numbers) - 1; i >= 0; i-- {
		reversed = append(reversed, numbers[i])
	}
	fmt.Println(reversed) // [4 3 2 1]
}
```

**Task:** Reverse the slice **in place** using a two-pointer swap: for `i, j := 0, len(numbers)-1; i < j; i, j = i+1, j-1 { numbers[i], numbers[j] = numbers[j], numbers[i] }`.

## Exercise 4: Count Occurrences
**Difficulty:** Basic
**Concepts:** slice, `range`, equality `==`, counter

Count how many times a target value appears in a slice of integers.

**Starter code:**
```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2, 3, 2, 4, 2}
	target := 2
	count := 0
	for _, n := range numbers {
		if n == target {
			count++
		}
	}
	fmt.Printf("count of %d = %d\n", target, count) // count of 2 = 3
}
```

**Task:** Build a frequency map `map[int]int` counting every distinct value, then print the full table.

## Exercise 5: Remove Duplicates
**Difficulty:** Basic
**Concepts:** slices, `map`, membership test via map, `append`

Build a new slice containing each value only once, preserving the original order.

**Starter code:**
```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2, 2, 3, 4, 4, 4, 5}
	unique := []int{}
	seen := map[int]bool{}
	for _, n := range numbers {
		if !seen[n] {
			seen[n] = true
			unique = append(unique, n)
		}
	}
	fmt.Println(unique) // [1 2 3 4 5]
}
```

**Task:** Rewrite without a map, using a nested loop to check whether each element already appears in `unique` — and discuss which approach is faster.
