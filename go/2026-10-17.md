## Exercise 1: Sum of Slice Elements
**Difficulty:** Basic
**Concepts:** slices, `for range` loop, accumulation

Compute the sum of all elements in a slice of integers.

**Starter code:**
```go
package main

import "fmt"

func main() {
    numbers := []int{10, 20, 30, 40, 50}
    sum := 0
    for _, n := range numbers {
        sum += n
    }
    fmt.Println("Sum:", sum)
}
```

**Task:** Write a `func sumSlice(nums []int) int` function that returns the sum.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** modulo operator (`%`), `if/else`

Check whether a number is even or odd.

**Starter code:**
```go
package main

import "fmt"

func main() {
    n := 7
    if n%2 == 0 {
        fmt.Println(n, "is even")
    } else {
        fmt.Println(n, "is odd")
    }
}
```

**Task:** Write a `func isEven(n int) bool` function and loop over numbers 1–10.

## Exercise 3: Celsius to Fahrenheit
**Difficulty:** Basic
**Concepts:** functions, `float64`, arithmetic

Convert Celsius to Fahrenheit using `F = C × 9/5 + 32`.

**Starter code:**
```go
package main

import "fmt"

func cToF(celsius float64) float64 {
    return (celsius * 9 / 5) + 32
}

func main() {
    fmt.Printf("20°C = %.1f°F\n", cToF(20))
}
```

**Task:** Add an `fToC` function that converts Fahrenheit back to Celsius.

## Exercise 4: Find the Smallest Number
**Difficulty:** Basic
**Concepts:** slices, comparison, loops

Find the smallest value in a slice.

**Starter code:**
```go
package main

import "fmt"

func main() {
    numbers := []int{45, 12, 78, 4, 33}
    smallest := numbers[0]
    for _, n := range numbers {
        if n < smallest {
            smallest = n
        }
    }
    fmt.Println("Smallest:", smallest)
}
```

**Task:** Also find the largest value in the same slice.

## Exercise 5: Simple Interest
**Difficulty:** Basic
**Concepts:** functions, `float64`, arithmetic

Calculate simple interest using `SI = (P × R × T) / 100`.

**Starter code:**
```go
package main

import "fmt"

func simpleInterest(principal, rate, time float64) float64 {
    return (principal * rate * time) / 100
}

func main() {
    fmt.Println("Simple interest:", simpleInterest(1000, 5, 3))
}
```

**Task:** Also return the total amount (principal + interest).
