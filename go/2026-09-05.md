## 1. Hello, World!

- **Difficulty**: Beginner

}

## 2. Even or Odd
- **Description**: Read an integer from the user and print whether it is even or odd.
- **Difficulty**: Beginner
- **Concepts**: `fmt.Scan()`, `%` operator, `if/else`
- **Example/Starter code**:
```go
package main

import "fmt"

func main() {
    var number int
    fmt.Print("Enter a number: ")
    fmt.Scan(&number)
    if number%2 == 0 {
        fmt.Println(number, "is even")
    } else {
        fmt.Println(number, "is odd")
    }
}
```

## 3. Sum of First N Numbers
- **Description**: Compute and print the sum of all integers from 1 to N.
- **Difficulty**: Beginner
- **Concepts**: `for` loop (Go's only loop construct), accumulation
- **Example/Starter code**:
```go
package main

import "fmt"

func main() {
    n := 10
    sum := 0
    for i := 1; i <= n; i++ {
        sum += i
    }
    fmt.Printf("Sum from 1 to %d is %d\n", n, sum) // 55
}
```

## 4. Factorial
- **Description**: Write a function that computes the factorial of a non-negative integer n.
- **Difficulty**: Beginner
- **Concepts**: Functions, `for` loops, return values
- **Example/Starter code**:
```go
package main

import "fmt"

func factorial(n int) int {
    result := 1
    for i := 1; i <= n; i++ {
        result *= i
    }
    return result
}

func main() {
    fmt.Println("Factorial of 5 is", factorial(5)) // 120
}
```

## 5. Palindrome Check
- **Description**: Write a program that checks whether a given string reads the same forwards and backwards.
- **Difficulty**: Beginner
- **Concepts**: Strings, `for` loop, rune comparison
- **Example/Starter code**:
```go
package main

import "fmt"

func isPalindrome(s string) bool {
    runes := []rune(s)
    for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
        if runes[i] != runes[j] {
            return false
        }
    }
    return true
}

func main() {
    word := "racecar"
    if isPalindrome(word) {
        fmt.Println(word, "is a palindrome")
    } else {
        fmt.Println(word, "is not a palindrome")
    }
}
```
