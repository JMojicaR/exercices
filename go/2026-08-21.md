## Exercise 1: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that finds and prints the largest of three integers.

**Given Input:** `a = 12, b = 7, c = 19`

**Expected Output:**
```
Largest = 19
```

### Concepts
- `if / else if`
- Logical operators
- `fmt.Println`

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    a, b, c := 12, 7, 19
    largest := a

    if b > largest {
        largest = b
    }
    if c > largest {
        largest = c
    }

    fmt.Println("Largest =", largest)
}
```

## Exercise 2: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that prints the multiplication table of a number `n` from `1` to `10`.

**Given Input:** `n = 5`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
```

### Concepts
- `for` loop as the only loop construct
- `fmt.Printf` formatting

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    n := 5
    for i := 1; i <= 10; i++ {
        fmt.Printf("%d x %d = %d\n", n, i, n*i)
    }
}
```

## Exercise 3: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a program that prints the first `n` terms of the Fibonacci sequence.

**Given Input:** `n = 7`

**Expected Output:**
```
0 1 1 2 3 5 8
```

### Concepts
- Multiple assignment (`a, b = b, a+b`)
- `for` loop
- `fmt.Print`

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    n := 7
    a, b := 0, 1
    for i := 0; i < n; i++ {
        fmt.Print(a, " ")
        a, b = b, a+b
    }
    fmt.Println()
}
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a function `countVowels(s string) int` that returns the number of vowels in `s`, ignoring case.

**Given Input:** `countVowels("Hello World")`

**Expected Output:**
```
3
```

### Concepts
- `strings.ToLower` and `strings.ContainsRune`
- `range` over a string
- Function with a return value

### Example / Starter Code

```go
package main

import (
    "fmt"
    "strings"
)

func countVowels(s string) int {
    vowels := "aeiou"
    s = strings.ToLower(s)
    count := 0
    for _, ch := range s {
        if strings.ContainsRune(vowels, ch) {
            count++
        }
    }
    return count
}

func main() {
    fmt.Println(countVowels("Hello World"))   // 3
    fmt.Println(countVowels("Go"))            // 1
}
```

## Exercise 5: Simple Calculator with switch

**Difficulty:** Basic

### Problem
Write a program that performs `+`, `-`, `*`, `/` on two numbers using a `switch` on an operator string.

**Given Input:** `a = 10, b = 5, op = "*"`

**Expected Output:**
```
50
```

### Concepts
- `switch` with multiple cases
- Arithmetic with `float64`
- Division-by-zero guard

### Example / Starter Code

```go
package main

import "fmt"

func main() {
    a, b := 10.0, 5.0
    op := "*"
    var result float64

    switch op {
    case "+":
        result = a + b
    case "-":
        result = a - b
    case "*":
        result = a * b
    case "/":
        if b != 0 {
            result = a / b
        } else {
            fmt.Println("Cannot divide by zero")
            return
        }
    default:
        fmt.Println("Unknown operator")
        return
    }

    fmt.Println(result)
}
```
