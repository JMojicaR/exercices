## 1. Temperature Converter
- **Description**: Read a Celsius temperature and convert it to Fahrenheit (`F = C × 9/5 + 32`).
- **Difficulty**: Beginner
- **Concepts**: `fmt.Scan`, `float64`, arithmetic, `Printf` formatting
- **Example/Starter code**:
```go
package main

import "fmt"

func main() {
    var celsius float64
    fmt.Print("Enter temperature in Celsius: ")
    fmt.Scan(&celsius)
    fahrenheit := celsius*9/5 + 32
    fmt.Printf("%.2f C = %.2f F\n", celsius, fahrenheit)
}
```

## 2. Count the Vowels
- **Description**: Count how many vowels (`a`, `e`, `i`, `o`, `u`) appear in a string, ignoring case.
- **Difficulty**: Beginner
- **Concepts**: `range` over strings, `strings.ToLower`, `strings.ContainsRune`
- **Example/Starter code**:
```go
package main

import (
    "fmt"
    "strings"
)

func main() {
    text := "hello world"
    vowels := "aeiou"
    count := 0
    for _, ch := range strings.ToLower(text) {
        if strings.ContainsRune(vowels, ch) {
            count++
        }
    }
    fmt.Println("Vowel count:", count)
}
```

## 3. Fibonacci Series
- **Description**: Print the first N numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...).
- **Difficulty**: Beginner
- **Concepts**: `for` loops, multiple assignment `a, b = b, a+b`
- **Example/Starter code**:
```go
package main

import "fmt"

func main() {
    n := 10
    a, b := 0, 1
    fmt.Println(a)
    for i := 1; i < n; i++ {
        fmt.Println(b)
        a, b = b, a+b
    }
}
```

## 4. Sum of Digits
- **Description**: Given an integer, compute the sum of its digits (e.g. 12345 → 15).
- **Difficulty**: Beginner
- **Concepts**: `for` loops (as `while`), `%` and `/` operators
- **Example/Starter code**:
```go
package main

import "fmt"

func main() {
    num := 12345
    sum := 0
    for num > 0 {
        sum += num % 10
        num /= 10
    }
    fmt.Println("Sum of digits:", sum)
}
```

## 5. Average of a Slice
- **Description**: Compute and print the average of a slice of integers.
- **Difficulty**: Beginner
- **Concepts**: slices, `range`, `float64` conversion, `len()`
- **Example/Starter code**:
```go
package main

import "fmt"

func main() {
    numbers := []int{10, 20, 30, 40, 50}
    sum := 0
    for _, n := range numbers {
        sum += n
    }
    avg := float64(sum) / float64(len(numbers))
    fmt.Printf("Average: %.2f\n", avg)
}
```
