# Go — Basic Exercises (2026-10-18)
Sources: A Tour of Go, Go by Example, GeeksforGeeks

## Exercise 1: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** short variable declaration `:=`, multiple assignment, `fmt`

Swap the values of two variables.

**Starter code:**
```go
package main

import "fmt"

func main() {
    a, b := 5, 10

    a, b = b, a

    fmt.Printf("a = %d, b = %d\n", a, b)
}
```

**Task:** Swap again using a temporary variable (the more explicit approach).

## Exercise 2: Area of a Circle
**Difficulty:** Basic
**Concepts:** `math.Pi`, `math.Pow`, `fmt.Printf`, formatting verbs

Compute the area of a circle given its radius (`area = π × r²`).

**Starter code:**
```go
package main

import (
    "fmt"
    "math"
)

func main() {
    radius := 5.0
    area := math.Pi * radius * radius

    fmt.Printf("Area: %.2f\n", area)
}
```

**Task:** Also print the circumference using `2 * math.Pi * radius`.

## Exercise 3: Positive, Negative or Zero
**Difficulty:** Basic
**Concepts:** `if / else if / else`, comparison operators

Classify a number as positive, negative, or zero.

**Starter code:**
```go
package main

import "fmt"

func main() {
    n := -3

    if n > 0 {
        fmt.Println("Positive")
    } else if n < 0 {
        fmt.Println("Negative")
    } else {
        fmt.Println("Zero")
    }
}
```

**Task:** Read the number from the user with `fmt.Scan(&n)` and classify it.

## Exercise 4: Power of a Number (xⁿ)
**Difficulty:** Basic
**Concepts:** `math.Pow`, `float64`, type conversions

Compute `base` raised to the power `exp`.

**Starter code:**
```go
package main

import (
    "fmt"
    "math"
)

func main() {
    base, exp := 2.0, 5.0

    result := math.Pow(base, exp)

    fmt.Printf("%.0f^%.0f = %.0f\n", base, exp, result)
}
```

**Task:** Implement your own integer `pow` using a `for` loop and a mutable accumulator.

## Exercise 5: Reverse a Number
**Difficulty:** Basic
**Concepts:** `for` loop (Go's only loop), `%` and `/` integer arithmetic

Reverse the digits of an integer (e.g. 1234 → 4321).

**Starter code:**
```go
package main

import "fmt"

func main() {
    n := 1234
    rev := 0

    for n != 0 {
        rev = rev*10 + n%10
        n /= 10
    }

    fmt.Println("Reversed:", rev)
}
```

**Task:** Confirm it also works for negative numbers (the `for n != 0` condition handles them automatically).
