## Exercise 1: FizzBuzz
**Difficulty:** Basic
**Concepts:** for loop, if/else, modulo, fmt

Print numbers from 1 to a given `n`, replacing multiples of 3 with "Fizz", multiples of 5 with "Buzz", and multiples of both with "FizzBuzz".

**Starter code:**
```go
package main

import "fmt"

func main() {
	n := 15
	for i := 1; i <= n; i++ {
		switch {
		case i%15 == 0:
			fmt.Println("FizzBuzz")
		case i%3 == 0:
			fmt.Println("Fizz")
		case i%5 == 0:
			fmt.Println("Buzz")
		default:
			fmt.Println(i)
		}
	}
}
```

**Task:** Read `n` from standard input using `fmt.Scan` and let the user choose custom divisors.

## Exercise 2: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** for loop, variables, slices

Generate the first `n` numbers of the Fibonacci sequence and print them.

**Starter code:**
```go
package main

import "fmt"

func main() {
	n := 10
	a, b := 0, 1
	for i := 0; i < n; i++ {
		fmt.Print(a, " ")
		a, b = b, a+b
	}
	fmt.Println()
}
```

**Task:** Store the sequence in a slice and print only the values below a user-specified limit.

## Exercise 3: Reverse a String
**Difficulty:** Basic
**Concepts:** runes, for loop, string conversion

Write a function that reverses a string, correctly handling multi-byte (UTF-8) characters.

**Starter code:**
```go
package main

import "fmt"

func reverse(s string) string {
	runes := []rune(s)
	for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
		runes[i], runes[j] = runes[j], runes[i]
	}
	return string(runes)
}

func main() {
	fmt.Println(reverse("hola"))
	fmt.Println(reverse("Go语言"))
}
```

**Task:** Write a function that checks whether a string is a palindrome (ignoring case).

## Exercise 4: Largest Element in a Slice
**Difficulty:** Basic
**Concepts:** slices, range, comparisons

Find the largest value in a slice of integers.

**Starter code:**
```go
package main

import "fmt"

func main() {
	numbers := []int{12, 45, 7, 89, 23, 5}
	max := numbers[0]
	for _, v := range numbers {
		if v > max {
			max = v
		}
	}
	fmt.Println("Largest:", max)
}
```

**Task:** Also find the smallest value and the sum of all elements.

## Exercise 5: Temperature Converter
**Difficulty:** Basic
**Concepts:** functions, float64, return values

Write functions to convert Celsius to Fahrenheit and back. Fahrenheit = Celsius × 9/5 + 32.

**Starter code:**
```go
package main

import "fmt"

func celsiusToFahrenheit(c float64) float64 {
	return c*9/5 + 32
}

func fahrenheitToCelsius(f float64) float64 {
	return (f - 32) * 5 / 9
}

func main() {
	fmt.Printf("20°C = %.1f°F\n", celsiusToFahrenheit(20))
	fmt.Printf("68°F = %.1f°C\n", fahrenheitToCelsius(68))
}
```

**Task:** Read a temperature and target unit from standard input and print the converted value.
