## Exercise 5: Simple Calculator
- **Difficulty:** Easy
- **Description:** Build a calculator that takes two `float64` values and an operator string (`+`, `-`, `*`, `/`) and returns the result using a `switch` statement. For division, check for zero and return an error.
- **Concepts:** `switch`, `float64`, multiple return values `(float64, error)`, error handling
- **Starter code:**
```go
package main

import (
    "errors"
    "fmt"
)

func calculate(a float64, op string, b float64) (float64, error) {
    switch op {
    case "+":
        return a + b, nil
    // TODO: add cases for '-', '*'
    case "/":
        if b == 0 {
            return 0, errors.New("cannot divide by zero")
        }
        return a / b, nil
    default:
        return 0, errors.New("invalid operator")
    }
}

func main() {
    if r, err := calculate(10, "/", 0); err != nil {
        fmt.Println("Error:", err)
    } else {
        fmt.Println(r)
    }
}
```
