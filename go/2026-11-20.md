## Exercise 1: Create a Map & Read with the Comma-Ok Idiom
**Difficulty:** Basic
**Concepts:** `map[string]int`, `make`, zero-value vs missing key, `value, ok :=`

Store and retrieve student grades, distinguishing "absent" from "zero".

**Starter code:**
```go
package main

import "fmt"

func main() {
    grades := map[string]int{
        "Alice": 85,
        "Bob":   72,
        "Carol": 90,
    }

    fmt.Println(grades["Alice"])   // 85
    fmt.Println(grades["Dave"])    // 0 (missing keys return zero value)

    value, ok := grades["Dave"]
    fmt.Println("Dave present?", ok, "value:", value)

    grades["Dave"] = 78            // add
    grades["Bob"] = 75             // update
    fmt.Println(grades)
}
```

**Task:** Look up a key that is present but mapped to `0`, and show that `ok` is `true` even though the value is zero.

## Exercise 2: Count Word Frequencies
**Difficulty:** Basic
**Concepts:** `strings.Fields`, incrementing with the comma-ok idiom, `++`

Count how many times each word appears in a sentence.

**Starter code:**
```go
package main

import (
    "fmt"
    "strings"
)

func main() {
    sentence := "the cat and the dog and the bird"
    counts := map[string]int{}

    for _, word := range strings.Fields(sentence) {
        counts[word]++
    }

    fmt.Println(counts)
    // map[and:2 bird:1 cat:1 dog:1 the:3]
}
```

**Task:** Print the results in sorted key order by collecting keys into a slice and calling `sort.Strings(keys)` before ranging.

## Exercise 3: Range Over a Map
**Difficulty:** Basic
**Concepts:** `for key, value := range m`, unordered iteration, `len(m)`

List every country and its capital.

**Starter code:**
```go
package main

import "fmt"

func main() {
    capitals := map[string]string{
        "Mexico": "Mexico City",
        "France": "Paris",
        "Japan":  "Tokyo",
    }

    for country, capital := range capitals {
        fmt.Printf("%s -> %s\n", country, capital)
    }

    fmt.Println("Number of entries:", len(capitals))
}
```

**Task:** Write a second loop that ranges over only the values and prints just the capitals.

## Exercise 4: Delete & Check Existence
**Difficulty:** Basic
**Concepts:** `delete`, checking with the comma-ok idiom, `len`

Manage an inventory and safely remove an item.

**Starter code:**
```go
package main

import "fmt"

func main() {
    stock := map[string]int{
        "apples":  10,
        "bananas": 5,
        "cherries": 20,
    }

    if _, exists := stock["bananas"]; exists {
        delete(stock, "bananas")
    }

    _, exists := stock["bananas"]
    fmt.Println("Has bananas?", exists)
    fmt.Println("Total items:", len(stock))
}
```

**Task:** Capture the value before deleting (`n, _ := stock["bananas"]`) and print how many bananas were removed.

## Exercise 5: Find the Key with the Maximum Value
**Difficulty:** Basic
**Concepts:** ranging, tracking the current max, handling an empty map

Find the student with the highest grade.

**Starter code:**
```go
package main

import "fmt"

func main() {
    grades := map[string]int{
        "Alice": 85,
        "Bob":   72,
        "Carol": 90,
        "Dave":  78,
    }

    bestName := ""
    bestGrade := -1

    for name, grade := range grades {
        if grade > bestGrade {
            bestGrade = grade
            bestName = name
        }
    }

    fmt.Printf("%s has the highest grade: %d\n", bestName, bestGrade)
}
```

**Task:** Handle the empty-map case: if `len(grades) == 0`, print `"No students"` and return early.
