## Exercise 1: Palindrome
**Difficulty:** Basic
**Concepts:** strings, runes, loops

Check whether a word reads the same forwards and backwards.

**Starter code:**
```go
package main

import (
	"fmt"
	"strings"
)

func isPalindrome(s string) bool {
	s = strings.ToLower(s)
	runes := []rune(s)
	for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
		if runes[i] != runes[j] {
			return false
		}
	}
	return true
}

func main() {
	word := "radar"
	fmt.Printf("%q is palindrome: %v\n", word, isPalindrome(word))
}
```

**Task:** Read the word from standard input using `fmt.Scanln`.

## Exercise 2: Factorial
**Difficulty:** Basic
**Concepts:** functions, for loop, uint64

Compute the factorial of a non-negative integer.

**Starter code:**
```go
package main

import "fmt"

func factorial(n uint64) uint64 {
	var result uint64 = 1
	for i := uint64(1); i <= n; i++ {
		result *= i
	}
	return result
}

func main() {
	var n uint64 = 6
	fmt.Printf("%d! = %d\n", n, factorial(n))
}
```

**Task:** Print the factorial of every number from 0 to 10 in a loop.

## Exercise 3: Prime Number Check
**Difficulty:** Basic
**Concepts:** for loop, modulo

Write a function that returns whether a number is prime.

**Starter code:**
```go
package main

import "fmt"

func isPrime(n int) bool {
	if n <= 1 {
		return false
	}
	for i := 2; i*i <= n; i++ {
		if n%i == 0 {
			return false
		}
	}
	return true
}

func main() {
	n := 17
	fmt.Printf("%d is prime: %v\n", n, isPrime(n))
}
```

**Task:** Print all primes between 2 and 50.

## Exercise 4: Sum of a Slice
**Difficulty:** Basic
**Concepts:** slices, range

Compute the sum of the integers in a slice.

**Starter code:**
```go
package main

import "fmt"

func sumSlice(numbers []int) int {
	total := 0
	for _, n := range numbers {
		total += n
	}
	return total
}

func main() {
	numbers := []int{2, 4, 6, 8, 10}
	fmt.Println("Sum:", sumSlice(numbers))
}
```

**Task:** Also compute and print the average (as `float64`) and the maximum value.

## Exercise 5: Multiplication Table
**Difficulty:** Basic
**Concepts:** for loop, fmt.Printf

Print the multiplication table (1–10) for a given number.

**Starter code:**
```go
package main

import "fmt"

func main() {
	n := 7
	for i := 1; i <= 10; i++ {
		fmt.Printf("%d x %d = %d\n", n, i, n*i)
	}
}
```

**Task:** Print the full 10×10 multiplication table using nested loops.
