## Exercise 1: Slice as a Stack
**Difficulty:** Basic
**Concepts:** `append` (push), slicing to pop, LIFO order, `len` for emptiness

Go has no built-in stack type; a slice with `append` and slicing works as a stack.

**Starter code:**
```go
package main

import "fmt"

func main() {
    var stack []string

    stack = append(stack, "a")   // push
    stack = append(stack, "b")
    stack = append(stack, "c")
    fmt.Println(stack)           // [a b c]

    top := stack[len(stack)-1]   // peek (top)
    fmt.Println(top)             // c

    stack = stack[:len(stack)-1] // pop
    fmt.Println(stack)           // [a b]
    fmt.Println(len(stack) == 0) // false
}
```

**Task:** Push the integers `1..5` onto a stack and pop them all, printing each. The output should be `5 4 3 2 1`.

## Exercise 2: Slice as a Queue
**Difficulty:** Basic
**Concepts:** `append` (enqueue), slicing front (dequeue), FIFO order

Use a slice as a queue: append to the back and remove from the front.

**Starter code:**
```go
package main

import "fmt"

func main() {
    var q []string

    q = append(q, "a")   // enqueue (back)
    q = append(q, "b")
    q = append(q, "c")
    fmt.Println(q)       // [a b c]

    first := q[0]        // peek (front)
    fmt.Println(first)   // a

    q = q[1:]            // dequeue (remove front)
    fmt.Println(q)       // [b c]
}
```

**Task:** Enqueue the numbers `1..5` and dequeue them all, printing each. The output should be `1 2 3 4 5`.

## Exercise 3: Balanced Parentheses Checker
**Difficulty:** Basic
**Concepts:** `[]rune` stack, `switch`, early `false` on mismatch

Use a stack of runes to check balanced brackets.

**Starter code:**
```go
package main

import "fmt"

func isBalanced(s string) bool {
    var stack []rune
    for _, ch := range s {
        switch ch {
        case '(', '[', '{':
            stack = append(stack, ch)
        case ')', ']', '}':
            if len(stack) == 0 {
                return false
            }
            open := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            if (ch == ')' && open != '(') ||
                (ch == ']' && open != '[') ||
                (ch == '}' && open != '{') {
                return false
            }
        }
    }
    return len(stack) == 0
}

func main() {
    fmt.Println(isBalanced("(a[b]{c})"))   // true
    fmt.Println(isBalanced("([)]"))        // false
}
```

**Task:** Add a test for the input `"((("` and confirm it returns `false` (unmatched openers remain on the stack).

## Exercise 4: Reverse a String with a Stack
**Difficulty:** Basic
**Concepts:** `[]rune` stack, `strings.Builder`, popping to rebuild

Push each rune and pop them off to reverse the string (rune-safe for Unicode).

**Starter code:**
```go
package main

import (
    "fmt"
    "strings"
)

func reverseString(text string) string {
    var stack []rune
    for _, ch := range text {
        stack = append(stack, ch)
    }
    var b strings.Builder
    for len(stack) > 0 {
        b.WriteRune(stack[len(stack)-1])
        stack = stack[:len(stack)-1]
    }
    return b.String()
}

func main() {
    fmt.Println(reverseString("hello"))   // "olleh"
}
```

**Task:** Modify the function to skip vowels, so `reverseString("hello")` returns `"llh"`.

## Exercise 5: Process a FIFO Job Queue
**Difficulty:** Basic
**Concepts:** `for len(q) > 0`, dequeuing in a loop, arrival-order processing

Simulate a job queue that processes tasks in FIFO order.

**Starter code:**
```go
package main

import "fmt"

func main() {
    var jobs []string
    jobs = append(jobs, "download")
    jobs = append(jobs, "compile")
    jobs = append(jobs, "deploy")

    for len(jobs) > 0 {
        job := jobs[0]
        jobs = jobs[1:]
        fmt.Println("Processing:", job)
    }
    fmt.Println("All jobs done:", len(jobs) == 0)
}
```

**Task:** Print the remaining number of jobs (using `len(jobs)`) inside the loop before each dequeue.
