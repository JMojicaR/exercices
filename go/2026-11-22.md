Sources: A Tour of Go, Go by Example, GeeksforGeeks, DEV Community

Theme: **Linked Lists** — `struct` nodes with pointers, building and traversing a list, append, count/sum, search, and delete.

## Exercise 1: Define a Node and Build a List
**Difficulty:** Basic
**Concepts:** `struct`, pointers (`*Node`), composite literals (`&Node{...}`), `nil`, `for`-loop traversal

**Starter code:**
```go
package main

import "fmt"

type Node struct {
    Value int
    Next  *Node
}

func main() {
    head := &Node{Value: 10}
    head.Next = &Node{Value: 20}
    head.Next.Next = &Node{Value: 30}

    for cur := head; cur != nil; cur = cur.Next {
        fmt.Print(cur.Value, " ")
    }
    fmt.Println()   // prints: 10 20 30
}
```

**Task:** Write a `printList(head *Node)` function that prints values separated by `" -> "` and ends with `"nil"`.

## Exercise 2: Append a Node to the End
**Difficulty:** Basic
**Concepts:** walking to the tail, `nil` head edge case, `&Node{}` allocation

**Starter code:**
```go
func appendNode(head *Node, value int) *Node {
    if head == nil {
        return &Node{Value: value}
    }
    cur := head
    for cur.Next != nil {
        cur = cur.Next
    }
    cur.Next = &Node{Value: value}
    return head
}
```

**Task:** Append `1..5` to an empty list (`nil`) in a loop and print the result.

## Exercise 3: Length and Sum of a Linked List
**Difficulty:** Basic
**Concepts:** counting during traversal, accumulating a total

**Starter code:**
```go
func length(head *Node) int {
    count := 0
    for cur := head; cur != nil; cur = cur.Next {
        count++
    }
    return count
}

func sum(head *Node) int {
    total := 0
    for cur := head; cur != nil; cur = cur.Next {
        total += cur.Value
    }
    return total
}
```

**Task:** Build `4 -> 6 -> 8` and verify `length` returns `3` and `sum` returns `18`.

## Exercise 4: Search for a Value
**Difficulty:** Basic
**Concepts:** early `return`, comparing values with `==`

**Starter code:**
```go
func contains(head *Node, target int) bool {
    for cur := head; cur != nil; cur = cur.Next {
        if cur.Value == target {
            return true
        }
    }
    return false
}
```

**Task:** Write `indexOf(head *Node, target int) int` returning the 0-based index of the first match, or `-1`.

## Exercise 5: Delete the First Matching Node
**Difficulty:** Basic
**Concepts:** rewiring `Next` pointers, head-removal special case

**Starter code:**
```go
func deleteNode(head *Node, value int) *Node {
    if head == nil {
        return nil
    }
    if head.Value == value {
        return head.Next
    }
    cur := head
    for cur.Next != nil && cur.Next.Value != value {
        cur = cur.Next
    }
    if cur.Next != nil {
        cur.Next = cur.Next.Next
    }
    return head
}
```

**Task:** Test removing the head, a middle node, and a missing value from `10 -> 20 -> 30`.
