## Exercise 1: Hello, World!
**Difficulty:** Basic
**Concepts:** `package main`, `import`, `fmt.Println`.

Write the classic "Hello, World!" program.

**Starter code:**
```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}
```

**Task:** Use `fmt.Printf` to print a formatted greeting with your name.

## Exercise 2: Read Input and Sum
**Difficulty:** Basic
**Concepts:** `fmt.Scan`/`fmt.Scanln`, variables, arithmetic.

Read two integers and print their sum.

**Starter code:**
```go
package main

import "fmt"

func main() {
    var a, b int
    fmt.Print("Enter first number: ")
    fmt.Scan(&a)
    fmt.Print("Enter second number: ")
    fmt.Scan(&b)

    fmt.Println("Sum:", a+b)
}
```

**Task:** Also print the difference and product.

## Exercise 3: Even or Odd
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator, functions with return values.

Write a function that reports whether a number is even or odd.

**Starter code:**
```go
package main

import "fmt"

func evenOrOdd(n int) string {
    if n%2 == 0 {
        return "even"
    }
    return "odd"
}

func main() {
    fmt.Println(evenOrOdd(7)) // odd
}
```

**Task:** Return "zero" when the input is 0.

## Exercise 4: Print 1 to N
**Difficulty:** Basic
**Concepts:** `for` loops (Go's only loop), `fmt.Print`.

Print the numbers from 1 to 20 on one line.

**Starter code:**
```go
package main

import "fmt"

func main() {
    for i := 1; i <= 20; i++ {
        fmt.Print(i, " ")
    }
    fmt.Println()
}
```

**Task:** Print only the even numbers between 1 and 20.

## Exercise 5: Sum of a Slice
**Difficulty:** Basic
**Concepts:** Slices, `for` loops, `len`, `range`.

Compute the sum and average of a slice of integers.

**Starter code:**
```go
package main

import "fmt"

func main() {
    numbers := []int{4, 7, 1, 9, 3, 8}
    sum := 0

    for _, n := range numbers {
        sum += n
    }

    fmt.Println("Sum:", sum)
    fmt.Println("Average:", float64(sum)/float64(len(numbers)))
}
```

**Task:** Find and print the minimum and maximum values.
