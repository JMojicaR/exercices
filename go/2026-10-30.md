## Exercise 1: Linear Search
**Difficulty:** Basic
**Concepts:** `for` loop, slice indexing, comparison, multiple return values

Write a function that searches for a target value in a slice and returns its index and a boolean found flag.

**Starter code:**
```go
package main

import "fmt"

func linearSearch(arr []int, target int) (int, bool) {
    for i, v := range arr {
        if v == target {
            return i, true
        }
    }
    return -1, false
}

func main() {
    numbers := []int{10, 23, 45, 70, 11, 15}
    fmt.Println(linearSearch(numbers, 70)) // expected: 3 true
    fmt.Println(linearSearch(numbers, 99)) // expected: -1 false
}
```

**Task:** Modify the function to count and return how many times the target appears in the slice.

## Exercise 2: Binary Search
**Difficulty:** Basic
**Concepts:** `for` loop (as `while`), midpoint index, sorted input, integer arithmetic

Search for a target in a *sorted* slice using binary search, halving the search range each step.

**Starter code:**
```go
package main

import "fmt"

func binarySearch(arr []int, target int) (int, bool) {
    low, high := 0, len(arr)-1
    for low <= high {
        mid := low + (high-low)/2
        if arr[mid] == target {
            return mid, true
        }
        if arr[mid] < target {
            low = mid + 1
        } else {
            high = mid - 1
        }
    }
    return -1, false
}

func main() {
    sorted := []int{1, 3, 5, 7, 9, 11, 13}
    fmt.Println(binarySearch(sorted, 9)) // expected: 4 true
    fmt.Println(binarySearch(sorted, 4)) // expected: -1 false
}
```

**Task:** Print `low`, `high`, and `mid` at the start of each iteration to visualize how the range shrinks.

## Exercise 3: Bubble Sort
**Difficulty:** Basic
**Concepts:** nested `for` loops, swapping, comparison operators, slice mutation in place

Sort a slice in ascending order using bubble sort (repeatedly swap adjacent out-of-order elements).

**Starter code:**
```go
package main

import "fmt"

func bubbleSort(arr []int) {
    n := len(arr)
    for i := 0; i < n-1; i++ {
        for j := 0; j < n-1-i; j++ {
            if arr[j] > arr[j+1] {
                arr[j], arr[j+1] = arr[j+1], arr[j] // parallel assignment swap
            }
        }
    }
}

func main() {
    data := []int{64, 34, 25, 12, 22, 11, 90}
    bubbleSort(data)
    fmt.Println(data) // expected: [11 12 22 25 34 64 90]
}
```

**Task:** Add a `swapped` flag that breaks out of the outer loop early when a pass makes no swaps.

## Exercise 4: Find Minimum and Maximum
**Difficulty:** Basic
**Concepts:** iteration, comparison, named return values, empty-slice edge case

Find and return the smallest and largest values in a slice in a single pass.

**Starter code:**
```go
package main

import "fmt"

func findMinMax(arr []int) (int, int, bool) {
    if len(arr) == 0 {
        return 0, 0, false
    }
    min, max := arr[0], arr[0]
    for _, v := range arr {
        if v < min {
            min = v
        }
        if v > max {
            max = v
        }
    }
    return min, max, true
}

func main() {
    nums := []int{45, 2, 78, 13, 9, 54}
    lo, hi, ok := findMinMax(nums)
    fmt.Println("Min:", lo, "Max:", hi, "found:", ok) // Min: 2 Max: 78 found: true
}
```

**Task:** Also return the *indices* of the min and max elements by tracking them inside the loop.

## Exercise 5: Selection Sort
**Difficulty:** Basic
**Concepts:** nested loops, index tracking, swapping, finding the minimum in a sub-range

Sort a slice using selection sort: repeatedly find the smallest remaining element and move it to the front.

**Starter code:**
```go
package main

import "fmt"

func selectionSort(arr []int) {
    n := len(arr)
    for i := 0; i < n-1; i++ {
        minIdx := i
        for j := i + 1; j < n; j++ {
            if arr[j] < arr[minIdx] {
                minIdx = j
            }
        }
        arr[i], arr[minIdx] = arr[minIdx], arr[i]
    }
}

func main() {
    data := []int{29, 10, 14, 37, 13}
    selectionSort(data)
    fmt.Println(data) // expected: [10 13 14 29 37]
}
```

**Task:** Sort in *descending* order by changing a single comparison, and skip the swap when `minIdx == i`.
