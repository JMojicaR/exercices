- **Difficulty**: Basic
- **Concepts**: Function syntax, multiple return values, named returns, error handling pattern
- **Description**: Write a function `divide` that takes two float64 numbers and returns the result and an error. Return an error when dividing by zero. Also write a function returning two values (quotient and remainder) for integer division.

### Example/Starter Code
```go

    "errors"
    "fmt"
)

    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}

// intDivide returns quotient and remainder
func intDivide(a, b int) (quotient, remainder int) {
    quotient = a / b
    remainder = a % b
    return // naked return
}

func main() {
    // TODO: Call divide(10, 2) and handle the error

    // TODO: Call intDivide(17, 5) and print both values

        fmt.Println("10 / 2 =", result)
    }

    fmt.Printf("17 / 5 = %d remainder %d\n", q, r)
```

## Exercise 3: Structs and Methods
- **Difficulty**: Basic
- **Concepts**: Struct definition, methods with value and pointer receivers, constructors
- **Description**: Define a `Circle` struct with a `radius` field. Implement methods: `Area()` (value receiver), `Scale(factor)` (pointer receiver to mutate), and a constructor `NewCircle`. Print results to demonstrate value vs pointer semantics.

### Example/Starter Code
```go
package main

import (
    "fmt"
    "math"
)

type Circle struct {
    Radius float64
}

// NewCircle is a constructor function
func NewCircle(radius float64) *Circle {
    return &Circle{Radius: radius}
}

// Area uses a value receiver (doesn't modify the struct)
func (c Circle) Area() float64 {
    return math.Pi * c.Radius * c.Radius
}

// Scale uses a pointer receiver (modifies the struct)
func (c *Circle) Scale(factor float64) {
    c.Radius *= factor
}

func main() {
    c := NewCircle(5.0)
    fmt.Printf("Radius: %.2f, Area: %.2f\n", c.Radius, c.Area())
    
    c.Scale(2.0)
    fmt.Printf("After scaling 2x - Radius: %.2f, Area: %.2f\n", c.Radius, c.Area())
```

## Exercise 4: Goroutines and Channels
- **Difficulty**: Basic
- **Concepts**: Goroutines (go keyword), channels (make, send, receive), sync.WaitGroup
- **Description**: Spawn three goroutines that each sleep for a different duration and send a message through a channel. The main function should receive and print all three messages. Use a buffered channel to avoid blocking.

### Example/Starter Code
```go
package main

import (
    "fmt"
    "time"
)

func worker(id int, delay time.Duration, ch chan<- string) {
    time.Sleep(delay)
    ch <- fmt.Sprintf("Worker %d finished after %v", id, delay)
}

func main() {
    ch := make(chan string, 3) // buffered channel
    
    go worker(1, 300*time.Millisecond, ch)
    go worker(2, 100*time.Millisecond, ch)
    go worker(3, 200*time.Millisecond, ch)
    
    // Receive all 3 messages
    for i := 0; i < 3; i++ {
        msg := <-ch
        fmt.Println(msg)
    }
    
    fmt.Println("All workers done!")
```
