## Exercise 1: Sum of a Slice
**Difficulty:** Basic
**Concepts:** Slices, `for range`, `fmt`, accumulator variables.

Write a program that sums the numbers in a slice.

**Starter code:**
```go
package main

import "fmt"

func main() {
    numbers := []int{5, 10, 15, 20, 25}

    sum := 0
    for _, n := range numbers {
        sum += n
    }

    fmt.Println("Sum:", sum)
}
```

**Task:** Compute and print the average as a `float64`.

## Exercise 2: Word Frequency Counter (maps)
**Difficulty:** Basic
**Concepts:** Maps, `strings.Fields`, `strings.ToLower`, iteration.

Count how many times each word appears in a sentence using a map.

**Starter code:**
```go
package main

import (
    "fmt"
    "strings"
)

func main() {
    text := "go is fun and go is fast"
    words := strings.Fields(strings.ToLower(text))

    counts := make(map[string]int)
    for _, w := range words {
        counts[w]++
    }

    for word, freq := range counts {
        fmt.Printf("%s: %d\n", word, freq)
    }
}
```

**Task:** Print the words sorted alphabetically (collect keys, `sort.Strings`, then iterate).

## Exercise 3: FizzBuzz
**Difficulty:** Basic
**Concepts:** Loops, conditionals, modulus (`%`).

Print numbers 1 to 30, but print "Fizz" for multiples of 3, "Buzz" for multiples of 5, and "FizzBuzz" for both.

**Starter code:**
```go
package main

import "fmt"

func main() {
    for i := 1; i <= 30; i++ {
        if i%3 == 0 && i%5 == 0 {
            fmt.Println("FizzBuzz")
        } else if i%3 == 0 {
            fmt.Println("Fizz")
        } else if i%5 == 0 {
            fmt.Println("Buzz")
        } else {
            fmt.Println(i)
        }
    }
}
```

**Task:** Add a "FizzBuzzBang" case for numbers divisible by 7.

## Exercise 4: Person Struct with a Method
**Difficulty:** Basic
**Concepts:** Structs, methods (receiver), `fmt.Printf`.

Define a `Person` struct and a method that returns a greeting.

**Starter code:**
```go
package main

import "fmt"

type Person struct {
    Name string
    Age  int
}

func (p Person) Greet() string {
    return fmt.Sprintf("Hi, I'm %s and I'm %d years old.", p.Name, p.Age)
}

func main() {
    p := Person{Name: "Carlos", Age: 31}
    fmt.Println(p.Greet())
}
```

**Task:** Add an `isAdult() bool` method and print whether the person is an adult.

## Exercise 5: Reverse a String
**Difficulty:** Basic
**Concepts:** Runes, `range`, string handling, UTF-8 awareness.

Reverse a string by converting it to a rune slice.

**Starter code:**
```go
package main

import "fmt"

func reverse(s string) string {
    runes := []rune(s)
    for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
        runes[i], runes[j] = runes[j], runes[i]
    }
    return string(runes)
}

func main() {
    fmt.Println(reverse("hello"))      // olleh
    fmt.Println(reverse("Go!"))        // !oG
}
```

**Task:** Test it with a string containing non-ASCII characters (e.g., "góła") and confirm it still reverses correctly.
