## Exercise 3: Factorial
- **Difficulty:** Easy
- **Description:** Write a recursive function `factorial(n int) int` that returns n!, and print `factorial(5)`.
- **Concepts:** recursion, base case
- **Starter code:**
```go
package main

import "fmt"

func factorial(n int) int {
    if n == 0 {
        return 1
    }
    return n * factorial(n-1)
}

func main() {
    fmt.Println(factorial(5)) // 120
}
```
