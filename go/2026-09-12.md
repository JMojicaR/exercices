## Exercise 3: Reverse a String
- **Difficulty:** Easy
- **Description:** Write a function `reverse(s string) string` that reverses a string using a `[]rune` and a loop.
- **Concepts:** `[]rune`, loops, string conversion, UTF-8 safety
- **Starter code:**
```go
package main

import "fmt"

func reverse(s string) string {
    runes := []rune(s)
    for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
        runes[i], runes[j] = runes[j], runes[i]
    }
    return string(runes)
}

func main() {
    fmt.Println(reverse("hello")) // "olleh"
}
```
