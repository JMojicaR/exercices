## Exercise 1: Print a Right-Angled Triangle of Stars
**Difficulty:** Basic
**Concepts:** `for` loops, `fmt.Scan()`, `strings.Repeat()`, `fmt.Println()`

Print a right-angled triangle of `*` where the number of rows is user-supplied.

**Starter code:**
```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	var rows int
	fmt.Print("Enter number of rows: ")
	fmt.Scan(&rows)

	for i := 1; i <= rows; i++ {
		fmt.Println(strings.Repeat("*", i))
	}
}
```

**Task:** Print an inverted triangle instead, then print numbers (`1`, `22`, `333`, …) using a nested loop rather than `Repeat()`.

## Exercise 2: Print Floyd's Triangle
**Difficulty:** Basic
**Concepts:** nested loops, running counter, `fmt.Print`

Print Floyd's triangle — consecutive numbers arranged in rows of increasing length.

**Starter code:**
```go
package main

import "fmt"

func main() {
	var rows int
	fmt.Print("Enter number of rows: ")
	fmt.Scan(&rows)

	num := 1
	for i := 1; i <= rows; i++ {
		for j := 1; j <= i; j++ {
			fmt.Print(num, " ")
			num++
		}
		fmt.Println()
	}
}
```

**Task:** Right-align the triangle with leading spaces, and start the counter at a user-supplied value.

## Exercise 3: Count Uppercase and Lowercase Letters
**Difficulty:** Basic
**Concepts:** `range` over string (runes), `unicode.IsUpper()` / `IsLower()`

Count how many uppercase and lowercase letters a string contains.

**Starter code:**
```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"unicode"
)

func main() {
	fmt.Print("Enter a string: ")
	scanner := bufio.NewScanner(os.Stdin)
	scanner.Scan()
	text := scanner.Text()

	upper, lower := 0, 0
	for _, ch := range text {
		if unicode.IsUpper(ch) {
			upper++
		} else if unicode.IsLower(ch) {
			lower++
		}
	}

	fmt.Printf("Uppercase: %d, Lowercase: %d\n", upper, lower)
}
```

**Task:** Also count digits (`unicode.IsDigit`) and whitespace (`unicode.IsSpace`), and print a full breakdown.

## Exercise 4: Remove All Spaces from a String
**Difficulty:** Basic
**Concepts:** `strings.ReplaceAll()`, string manipulation

Remove every space from an input string and print the result.

**Starter code:**
```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"strings"
)

func main() {
	fmt.Print("Enter a string: ")
	scanner := bufio.NewScanner(os.Stdin)
	scanner.Scan()
	text := scanner.Text()

	noSpaces := strings.ReplaceAll(text, " ", "")
	fmt.Println("Without spaces:", noSpaces)
}
```

**Task:** Remove all whitespace by building the result with `strings.Map(func(r rune) rune { ... }, text)`.

## Exercise 5: Find the Largest Digit in a Number
**Difficulty:** Basic
**Concepts:** `%` and `/`, `for` as `while`, max tracking

Read a whole number and print its largest single digit.

**Starter code:**
```go
package main

import "fmt"

func main() {
	var num int
	fmt.Print("Enter a number: ")
	fmt.Scan(&num)

	largest := 0
	for num > 0 {
		digit := num % 10
		if digit > largest {
			largest = digit
		}
		num /= 10
	}

	fmt.Println("Largest digit:", largest)
}
```

**Task:** Also find the smallest digit, and handle negative input by taking the absolute value.
