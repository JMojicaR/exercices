# Go — Basic Exercises (2026-09-19)

Level: **Basic** · Sources referenced: Tour of Go, W3Schools, Go by Example, Programiz

---

## 1. Hello, World!
**Description:** Write a minimal Go program that prints a greeting.
**Difficulty:** Basic
**Concepts:** `package main`, `import "fmt"`, `func main()`, `fmt.Println()`.
**Starter code:**
```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}
```

## 2. Even or Odd
**Description:** Determine whether a given integer is even or odd.
**Difficulty:** Basic
**Concepts:** Variable declaration (`:=`), conditionals, modulo operator.
**Starter code:**
```go
package main

import "fmt"

func main() {
    n := 7
    if n%2 == 0 {
        fmt.Printf("%d is even\n", n)
    } else {
        fmt.Printf("%d is odd\n", n)
    }
}
```

## 3. Sum of Numbers 1 to N
**Description:** Compute the sum of all integers from 1 to N using a loop.
**Difficulty:** Basic
**Concepts:** `for` loop (Go's only loop construct), accumulator variable.
**Starter code:**
```go
package main

import "fmt"

func main() {
    n := 10
    sum := 0
    for i := 1; i <= n; i++ {
        sum += i
    }
    fmt.Printf("Sum from 1 to %d is %d\n", n, sum)
}
```

## 4. Factorial
**Description:** Compute the factorial of a number using a function and a loop.
**Difficulty:** Basic
**Concepts:** Function definitions, return values, loops.
**Starter code:**
```go
package main

import "fmt"

func factorial(n int) int {
    result := 1
    for i := 1; i <= n; i++ {
        result *= i
    }
    return result
}

func main() {
    fmt.Printf("5! = %d\n", factorial(5))
}
```

## 5. FizzBuzz
**Description:** Print numbers 1 to 100, replacing multiples of 3 with "Fizz", multiples of 5 with "Buzz", and multiples of both with "FizzBuzz".
**Difficulty:** Basic
**Concepts:** `for` loop, `if`/`else if`/`else`, modulo operator, order of conditions.
**Starter code:**
```go
package main

import "fmt"

func main() {
    for i := 1; i <= 100; i++ {
        if i%15 == 0 {
            fmt.Println("FizzBuzz")
        } else if i%3 == 0 {
            fmt.Println("Fizz")
        } else if i%5 == 0 {
            fmt.Println("Buzz")
        } else {
            fmt.Println(i)
        }
    }
}
```
