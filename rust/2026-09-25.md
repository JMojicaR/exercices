## Exercise 1: Hello, World!
**Difficulty:** Basic
**Concepts:** `fn main`, `println!` macro, string literals.

Write the classic "Hello, World!" program.

**Starter code:**
```rust
fn main() {
    println!("Hello, World!");
}
```

**Task:** Use `println!` with a formatted placeholder to print your name: `println!("Hello, {}!", "Ana");`

## Exercise 2: Read Input and Sum
**Difficulty:** Basic
**Concepts:** `std::io`, `read_line`, `trim`, `parse`, `Result`/`expect`.

Read two numbers from the user and print their sum.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();

    println!("Enter first number: ");
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let a: i32 = input.trim().parse().expect("Not a number");

    input.clear();
    println!("Enter second number: ");
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let b: i32 = input.trim().parse().expect("Not a number");

    println!("Sum: {}", a + b);
}
```

**Task:** Also print the difference and product.

## Exercise 3: Even or Odd
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator, function definitions.

Write a function that returns `true` if a number is even, then use it in `main`.

**Starter code:**
```rust
fn is_even(n: i32) -> bool {
    n % 2 == 0
}

fn main() {
    let num = 7;
    if is_even(num) {
        println!("{} is even", num);
    } else {
        println!("{} is odd", num);
    }
}
```

**Task:** Handle zero explicitly and print "zero".

## Exercise 4: Print 1 to N
**Difficulty:** Basic
**Concepts:** `for` loops, ranges (`1..=n`), `while` loops.

Print the numbers from 1 to N.

**Starter code:**
```rust
fn main() {
    let n = 10;

    for i in 1..=n {
        print!("{} ", i);
    }
    println!();
}
```

**Task:** Reimplement it with a `while` loop and a mutable counter.

## Exercise 5: Sum of a Vec
**Difficulty:** Basic
**Concepts:** `Vec`, iteration (`.iter()`), `.sum()`, ownership basics.

Compute the sum and average of a `Vec<i32>`.

**Starter code:**
```rust
fn main() {
    let numbers = vec![4, 7, 1, 9, 3, 8];
    let sum: i32 = numbers.iter().sum();
    let average = sum as f64 / numbers.len() as f64;

    println!("Sum: {}", sum);
    println!("Average: {:.2}", average);
}
```

**Task:** Find the minimum and maximum without using built-in min/max methods (use a loop).
