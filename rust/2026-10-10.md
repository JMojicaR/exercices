## Exercise 1: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** Vec, loops, integer types

Generate the first `n` numbers of the Fibonacci sequence and store them in a `Vec`.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("How many Fibonacci numbers? ");
    io::stdin().read_line(&mut input).unwrap();
    let n: usize = input.trim().parse().unwrap();

    let mut seq = vec![0u64, 1u64];
    for i in 2..n {
        let next = seq[i - 1] + seq[i - 2];
        seq.push(next);
    }
    seq.truncate(n);
    println!("{:?}", seq);
}
```

**Task:** Print only the Fibonacci numbers below a user-specified limit.

## Exercise 2: FizzBuzz
**Difficulty:** Basic
**Concepts:** for loop, match, modulo

Print numbers from 1 to a given `n`, replacing multiples of 3 with "Fizz", multiples of 5 with "Buzz", and multiples of both with "FizzBuzz".

**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter n: ");
    io::stdin().read_line(&mut input).unwrap();
    let n: u32 = input.trim().parse().unwrap();

    for i in 1..=n {
        match (i % 3, i % 5) {
            (0, 0) => println!("FizzBuzz"),
            (0, _) => println!("Fizz"),
            (_, 0) => println!("Buzz"),
            _ => println!("{}", i),
        }
    }
}
```

**Task:** Rewrite the logic using plain `if`/`else if` instead of `match`.

## Exercise 3: Sum of Digits
**Difficulty:** Basic
**Concepts:** loop, modulo, integer division

Compute the sum of the digits of a positive integer (e.g. 1234 → 10).

**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter a positive integer: ");
    io::stdin().read_line(&mut input).unwrap();
    let mut n: u32 = input.trim().parse().unwrap();

    let mut sum = 0;
    while n > 0 {
        sum += n % 10;
        n /= 10;
    }
    println!("Sum of digits: {}", sum);
}
```

**Task:** Also print the number of digits and the product of the digits.

## Exercise 4: Largest Element in a Vec
**Difficulty:** Basic
**Concepts:** iterators, Option, unwrap

Find the largest value in a `Vec<i32>` using the `max` iterator method.

**Starter code:**
```rust
fn main() {
    let numbers = vec![12, 45, 7, 89, 23, 5];
    let max = numbers.iter().max();
    match max {
        Some(&m) => println!("Largest: {}", m),
        None => println!("The list is empty"),
    }
}
```

**Task:** Also find the smallest value and the sum of all elements.

## Exercise 5: Temperature Converter
**Difficulty:** Basic
**Concepts:** functions, f64, return values

Write functions to convert Celsius to Fahrenheit and back. Fahrenheit = Celsius × 9/5 + 32.

**Starter code:**
```rust
fn celsius_to_fahrenheit(c: f64) -> f64 {
    c * 9.0 / 5.0 + 32.0
}

fn fahrenheit_to_celsius(f: f64) -> f64 {
    (f - 32.0) * 5.0 / 9.0
}

fn main() {
    println!("20°C = {:.1}°F", celsius_to_fahrenheit(20.0));
    println!("68°F = {:.1}°C", fahrenheit_to_celsius(68.0));
}
```

**Task:** Read a temperature and target unit from standard input and print the converted value.
