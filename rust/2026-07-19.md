## Exercise 1: Ownership and String Manipulation

**Title:** Greeting Generator with Ownership

**Description:**  
Write a function `greet(name: String) -> String` that takes ownership of a `String` and returns a new greeting `String` (e.g., `"Hello, Alice!"`). Then write another function `greet_borrow(name: &str) -> String` that borrows the name and returns a greeting. Demonstrate the difference between ownership transfer and borrowing.

**Concepts Practiced:** Ownership, borrowing (`&str` vs `String`), references, returning owned values

**Difficulty:** Basic

**Starter Code:**
```rust
fn greet(name: String) -> String {
    // Take ownership of `name` and return a greeting
}

fn greet_borrow(name: &str) -> String {
    // Borrow `name` and return a greeting
}

fn main() {
    let name = String::from("Alice");

    // Ownership transfer
    let greeting1 = greet(name);
    println!("{}", greeting1);  // Hello, Alice!
    // println!("{}", name);    // This would NOT compile — name was moved

    // Borrowing
    let name2 = String::from("Bob");
    let greeting2 = greet_borrow(&name2);
    println!("{}", greeting2);  // Hello, Bob!
    println!("{}", name2);      // This IS allowed — name2 is only borrowed

    // Borrowing from a string literal
    let greeting3 = greet_borrow("Charlie");
    println!("{}", greeting3);  // Hello, Charlie!
}
```

## Exercise 5: Word Count with HashMap

**Title:** Count Word Frequencies Using `HashMap`

**Description:**  
Write a function `word_count(text: &str) -> HashMap<String, u32>` that splits the input string into words (by whitespace) and returns a `HashMap` counting how many times each word appears. Convert words to lowercase for case-insensitive counting.

**Concepts Practiced:** `HashMap<K, V>`, `entry().or_insert()`, string splitting, iteration, collections

**Difficulty:** Basic

**Starter Code:**
```rust
use std::collections::HashMap;

fn word_count(text: &str) -> HashMap<String, u32> {
    // Split by whitespace, lowercase each word, count frequencies
    HashMap::new()
}

fn main() {
    let text = "the cat and the dog and the bird";
    let counts = word_count(text);

    // Print counts sorted alphabetically
    let mut words: Vec<(&String, &u32)> = counts.iter().collect();
    words.sort_by(|a, b| a.0.cmp(b.0));

    for (word, count) in words {
        println!("{}: {}", word, count);
    }
    // Expected:
    // and: 2
    // bird: 1
    // cat: 1
    // dog: 1
    // the: 3

    println!("\nEmpty string: {} unique words", word_count("").len());  // Expected: 0
}
```
