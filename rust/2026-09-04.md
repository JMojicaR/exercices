## Exercise 1: Bubble Sort

**Difficulty:** Basic

### Problem
Write a function that sorts a `Vec<i32>` in ascending order using bubble sort (in place).

**Given Input:** `vec![64, 34, 25, 12, 22, 11, 90]`

**Expected Output:**
```
Sorted: [11, 12, 22, 25, 34, 64, 90]
```

### Concepts
- `&mut Vec<i32>` mutable borrow
- `.len()` and `.swap()`
- Nested `for` loops

### Example / Starter Code

```rust
fn bubble_sort(arr: &mut Vec<i32>) {
    let n = arr.len();
    for i in 0..n {
        for j in 0..n - i - 1 {
            if arr[j] > arr[j + 1] {
                arr.swap(j, j + 1);
            }
        }
    }
}

fn main() {
    let mut nums = vec![64, 34, 25, 12, 22, 11, 90];
    bubble_sort(&mut nums);
    println!("Sorted: {:?}", nums);
}
```

## Exercise 2: Linear Search

**Difficulty:** Basic

### Problem
Write a function that returns the index of a target value in a slice as an `Option<usize>`, or `None` if absent.

**Given Input:** `[10, 23, 45, 70, 11, 15]`, target `70`

**Expected Output:**
```
Found at index 3
```

### Concepts
- Slice parameter `&[i32]`
- `.iter().enumerate()`
- `Option` and `match`

### Example / Starter Code

```rust
fn linear_search(arr: &[i32], target: i32) -> Option<usize> {
    for (i, &item) in arr.iter().enumerate() {
        if item == target {
            return Some(i);
        }
    }
    None
}

fn main() {
    let nums = [10, 23, 45, 70, 11, 15];
    match linear_search(&nums, 70) {
        Some(i) => println!("Found at index {}", i),
        None => println!("Not found"),
    }
}
```

## Exercise 3: Anagram Check

**Difficulty:** Basic

### Problem
Write a function that checks whether two strings are anagrams, ignoring case.

**Given Input:** `"listen"`, `"silent"`

**Expected Output:**
```
Anagram
```

### Concepts
- `.to_lowercase()` and `.chars()`
- `Vec<char>` sort
- Slice comparison `==`

### Example / Starter Code

```rust
fn is_anagram(s1: &str, s2: &str) -> bool {
    let mut a: Vec<char> = s1.to_lowercase().chars().collect();
    let mut b: Vec<char> = s2.to_lowercase().chars().collect();
    a.sort();
    b.sort();
    a == b
}

fn main() {
    println!("{}", if is_anagram("listen", "silent") { "Anagram" } else { "Not an anagram" });
}
```

## Exercise 4: Greatest Common Divisor (GCD)

**Difficulty:** Basic

### Problem
Write a function that computes the GCD of two unsigned integers using the Euclidean algorithm.

**Given Input:** `48`, `18`

**Expected Output:**
```
GCD: 6
```

### Concepts
- Mutable `mut` parameters
- `while` loop
- Modulo `%`

### Example / Starter Code

```rust
fn gcd(mut a: u32, mut b: u32) -> u32 {
    while b != 0 {
        let temp = b;
        b = a % b;
        a = temp;
    }
    a
}

fn main() {
    println!("GCD: {}", gcd(48, 18));
}
```

## Exercise 5: Armstrong Number Check

**Difficulty:** Basic

### Problem
Write a function that checks whether a number is an Armstrong number.

**Given Input:** `153`

**Expected Output:**
```
Armstrong
```

### Concepts
- `to_string()` and `len()`
- Iterator `.map()` + `.sum()`
- `u32::pow` and `to_digit()`

### Example / Starter Code

```rust
fn is_armstrong(n: u32) -> bool {
    let s = n.to_string();
    let power = s.len() as u32;
    let total: u32 = s.chars()
        .map(|c| c.to_digit(10).unwrap().pow(power))
        .sum();
    total == n
}

fn main() {
    println!("{}", if is_armstrong(153) { "Armstrong" } else { "Not Armstrong" });
}
```
