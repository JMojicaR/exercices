Theme: **Linked Lists** — `struct` nodes with `Option<Box<Node>>`, building and traversing a list, append, count/sum, search, and delete.

## Exercise 1: Define a Node and Build a List
**Difficulty:** Basic
**Concepts:** `struct`, `Box<T>` for heap allocation, `Option` for "maybe a next node", `while let` traversal

Rust has no `null`; an absent next node is `None` inside an `Option`.

**Starter code:**
```rust
#[derive(Debug)]
struct Node {
    value: i32,
    next: Option<Box<Node>>,
}

fn print_list(mut head: &Option<Box<Node>>) {
    while let Some(node) = head {
        print!("{} ", node.value);
        head = &node.next;
    }
    println!();
}

fn main() {
    let mut head: Option<Box<Node>> = None;
    head = Some(Box::new(Node { value: 10, next: head }));
    head = Some(Box::new(Node { value: 20, next: head }));
    head = Some(Box::new(Node { value: 30, next: head }));
    print_list(&head);   // prints: 30 20 10
}
```

**Task:** Change `print_list` so values print separated by `" -> "` and end with `"None"`.

## Exercise 2: Append a Node to the End
**Difficulty:** Basic
**Concepts:** `&mut` references, walking to the tail, replacing `None` with `Some(new_node)`

**Starter code:**
```rust
fn append(mut head: Option<Box<Node>>, value: i32) -> Option<Box<Node>> {
    let new_node = Box::new(Node { value, next: None });
    let mut current = &mut head;
    while let Some(node) = current {
        current = &mut node.next;
    }
    *current = Some(new_node);
    head
}
```

**Task:** Append the numbers `1..=5` into an empty list using `for i in 1..=5 { head = append(head, i); }` and print the result.

## Exercise 3: Length and Sum of a Linked List
**Difficulty:** Basic
**Concepts:** shared references (`&`), counting and accumulating during traversal

**Starter code:**
```rust
fn length(head: &Option<Box<Node>>) -> usize {
    let mut count = 0;
    let mut current = head;
    while let Some(node) = current {
        count += 1;
        current = &node.next;
    }
    count
}

fn sum(head: &Option<Box<Node>>) -> i32 {
    let mut total = 0;
    let mut current = head;
    while let Some(node) = current {
        total += node.value;
        current = &node.next;
    }
    total
}
```

**Task:** Build `3 -> 6 -> 9` and verify `length` returns `3` and `sum` returns `18`.

## Exercise 4: Search for a Value
**Difficulty:** Basic
**Concepts:** early `return`, `bool`, comparing with `==`

**Starter code:**
```rust
fn contains(head: &Option<Box<Node>>, target: i32) -> bool {
    let mut current = head;
    while let Some(node) = current {
        if node.value == target {
            return true;
        }
        current = &node.next;
    }
    false
}
```

**Task:** Write `index_of(head, target) -> Option<usize>` returning the 0-based index of the first match, or `None`.

## Exercise 5: Delete the First Matching Node
**Difficulty:** Basic
**Concepts:** `Option::take()` to move a value out, rewiring `next`, head-removal case

**Starter code:**
```rust
fn delete(mut head: Option<Box<Node>>, value: i32) -> Option<Box<Node>> {
    let mut current = &mut head;
    while let Some(node) = current {
        if node.value == value {
            *current = node.next.take();
            break;
        }
        current = &mut node.next;
    }
    head
}
```

**Task:** Test removing the head, a middle node, and a missing value from a list `10 -> 20 -> 30`. Note how `take()` avoids a partial move out of `node.next`.
