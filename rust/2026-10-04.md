## Exercise 1: Fibonacci (iterative)
**Difficulty:** Basic
**Concepts:** loops, variables, tuples

Write a function that computes the nth Fibonacci number using an iterative loop instead of recursion.

**Starter code:**
```rust
fn fib(n: u32) -> u32 {
    if n == 0 {
        return 0;
    }
    let (mut a, mut b) = (0, 1);
    for _ in 1..n {
        let next = a + b;
        a = b;
        b = next;
    }
    b
}

fn main() {
    let n = 10;
    println!("fib({}) = {}", n, fib(n));
}
```

**Task:** Modify `main` to print the first 15 Fibonacci numbers on a single line.

## Exercise 2: GCD of Two Numbers
**Difficulty:** Basic
**Concepts:** while loops, arithmetic

Compute the greatest common divisor of two positive integers.

**Starter code:**
```rust
fn gcd(a: u32, b: u32) -> u32 {
    let (mut a, mut b) = (a, b);
    while b != 0 {
        let t = b;
        b = a % b;
        a = t;
    }
    a
}

fn main() {
    println!("gcd(48, 18) = {}", gcd(48, 18));
}
```

**Task:** Extend `main` to read two numbers from the command line and print their GCD.

## Exercise 3: Count Words in a String
**Difficulty:** Basic
**Concepts:** string slices, iterators, whitespace

Count how many whitespace-separated words appear in a string.

**Starter code:**
```rust
fn count_words(s: &str) -> usize {
    s.split_whitespace().count()
}

fn main() {
    let text = "the quick brown fox";
    println!("{} words", count_words(text));
}
```

**Task:** Extend the function to also count punctuation-only tokens (like `!`) as non-words.

## Exercise 4: Find Maximum in a Vec
**Difficulty:** Basic
**Concepts:** Vec, slices, loops, references

Return the largest value in a vector of integers.

**Starter code:**
```rust
fn max_in_vec(v: &[i32]) -> i32 {
    let mut max = v[0];
    for &x in v {
        if x > max {
            max = x;
        }
    }
    max
}

fn main() {
    let nums = vec![3, 7, 2, 9, 4];
    println!("max = {}", max_in_vec(&nums));
}
```

**Task:** Extend the function to return both the maximum value and its index.

## Exercise 5: Rectangle Struct with area() method
**Difficulty:** Basic
**Concepts:** structs, impl blocks, methods

Define a `Rectangle` struct and give it an `area` method.

**Starter code:**
```rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

fn main() {
    let r = Rectangle { width: 5, height: 3 };
    println!("area = {}", r.area());
}
```

**Task:** Add a `can_hold` method that reports whether one rectangle fits inside another.
