## Exercise 5: Rectangle Area Calculator
- **Description**: Define a `Rectangle` struct with `width` and `height` fields (both `u32`). Then implement an `impl` block with two methods: `area()` that returns the rectangle's area, and `can_hold()` that takes another `Rectangle` and returns `true` if `self` can fully contain it. Use the `dbg!` macro to inspect values during development. This exercise teaches `struct` definitions, `impl` blocks, methods with `&self`, and the `dbg!` debugging macro.
- **Difficulty**: Beginner
- **Concepts**: `struct`, `impl` blocks, methods (`&self`), `dbg!` macro, ownership & borrowing
- **Source**: Rust by Example — [Structs](https://doc.rust-lang.org/rust-by-example/custom_types/structs.html)
- **Example/Starter Code**:
```rust
// Define a Rectangle struct with width and height fields.
// TODO: Add the struct definition here.
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    /// Returns the area of the rectangle (width × height).
    // TODO: Implement area()
    fn area(&self) -> u32 {
        self.width * self.height
    }

    /// Returns true if `self` can fully contain `other`.
    // TODO: Implement can_hold()
    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width >= other.width && self.height >= other.height
    }
}

fn main() {
    let rect1 = Rectangle { width: 30, height: 50 };
    let rect2 = Rectangle { width: 10, height: 40 };
    let rect3 = Rectangle { width: 60, height: 45 };

    // Use dbg! to print debug info during development
    dbg!(&rect1);

    println!("The area of rect1 is {} square pixels.", rect1.area());
    println!("Can rect1 hold rect2? {}", rect1.can_hold(&rect2));
    println!("Can rect1 hold rect3? {}", rect1.can_hold(&rect3));
}
```
