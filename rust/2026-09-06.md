## 1. Temperature Converter
- **Description**: Read a Celsius temperature from standard input and convert it to Fahrenheit (`F = C × 9/5 + 32`).
- **Difficulty**: Beginner
- **Concepts**: `std::io`, `read_line`, `parse()`, `f64`, `println!`
- **Example/Starter code**:
```rust
use std::io;

fn main() {
    println!("Enter temperature in Celsius: ");
    let mut input = String::new();
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let celsius: f64 = input.trim().parse().expect("Please enter a number");
    let fahrenheit = celsius * 9.0 / 5.0 + 32.0;
    println!("{celsius} C = {fahrenheit} F");
}
```

## 2. Count the Vowels
- **Description**: Count how many vowels appear in a string, ignoring case.
- **Difficulty**: Beginner
- **Concepts**: `chars()`, iterators, `filter` + `count`, `to_ascii_lowercase`
- **Example/Starter code**:
```rust
fn main() {
    let text = "hello world";
    let vowels = ['a', 'e', 'i', 'o', 'u'];
    let count = text.chars()
        .filter(|c| vowels.contains(&c.to_ascii_lowercase()))
        .count();
    println!("Vowel count: {count}");
}
```

## 3. Fibonacci Series
- **Description**: Print the first N numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...).
- **Difficulty**: Beginner
- **Concepts**: mutable variables, `for` loops, arithmetic
- **Example/Starter code**:
```rust
fn main() {
    let n = 10;
    let (mut a, mut b) = (0, 1);
    println!("{a}");
    for _ in 1..n {
        println!("{b}");
        let next = a + b;
        a = b;
        b = next;
    }
}
```

## 4. Sum of Digits
- **Description**: Given an integer, compute the sum of its digits (e.g. 12345 → 15).
- **Difficulty**: Beginner
- **Concepts**: `while` loops, mutable variables, `%` and `/` operators
- **Example/Starter code**:
```rust
fn main() {
    let mut num = 12345;
    let mut sum = 0;
    while num > 0 {
        sum += num % 10;
        num /= 10;
    }
    println!("Sum of digits: {sum}");
}
```

## 5. Average of an Array
- **Description**: Compute and print the average of a fixed array of numbers.
- **Difficulty**: Beginner
- **Concepts**: arrays, `iter()`, `sum()`, `len()`, casting to `f64`
- **Example/Starter code**:
```rust
fn main() {
    let numbers = [10, 20, 30, 40, 50];
    let sum: i32 = numbers.iter().sum();
    let avg = sum as f64 / numbers.len() as f64;
    println!("Average: {avg}");
}
```
