## Exercise 1: Hello World & Ownership Basics
**Difficulty:** ★☆☆☆☆  
**Concepts:** println!, variables (let/mut), ownership, String vs &str  

**Description:**  
Write a Rust program that demonstrates variable binding, mutability, and basic ownership. Create a function that takes ownership of a String and another that borrows a reference.

**Example Starter Code:**
```rust
fn take_ownership(s: String) {
    println!("I own: {}", s);
    // s is dropped here
}

fn borrow_string(s: &str) {
    println!("I borrowed: {}", s);
    // s is NOT dropped — just a reference
}

fn main() {
    // Immutable variable
    let name = "Alice";
    println!("Hello, {}!", name);
    
    // Mutable variable
    let mut age = 25;
    println!("Age: {}", age);
    age += 1;
    println!("Next year: {}", age);
    
    // String (heap-allocated, owned)
    let greeting = String::from("Welcome to Rust!");
    println!("{}", greeting);
    
    // Ownership transfer
    take_ownership(greeting);
    // greeting is no longer valid here!
    // println!("{}", greeting);  // This would NOT compile
    
    // Borrowing
    let message = String::from("Learning ownership");
    borrow_string(&message);      // Borrow as &str
    println!("Still valid: {}", message);  // Still works!
    
    // Shadowing
    let value = 5;
    let value = value + 3;
    let value = value * 2;
    println!("Shadowed value: {}", value);
}
```

**Expected Output:**
```
Hello, Alice!
Age: 25
Next year: 26
Welcome to Rust!
I own: Welcome to Rust!
I borrowed: Learning ownership
Still valid: Learning ownership
Shadowed value: 16
```

## Exercise 2: Guessing Game
**Difficulty:** ★★☆☆☆  
**Concepts:** User input, match, loops, external crates, Result handling  

**Description:**  
Implement a number guessing game. The program generates a random number (using the `rand` crate) and the user guesses until they get it right, with "too high" or "too low" hints.

**Example Starter Code:**
```rust
use rand::Rng;
use std::io;
use std::cmp::Ordering;

fn main() {
    println!("=== Guessing Game ===");
    
    let secret_number = rand::thread_rng().gen_range(1..=100);
    let mut attempts = 0;
    
    loop {
        println!("\nEnter your guess (1-100): ");
        
        let mut guess = String::new();
        io::stdin()
            .read_line(&mut guess)
            .expect("Failed to read line");
        
        let guess: u32 = match guess.trim().parse() {
            Ok(num) => num,
            Err(_) => {
                println!("Please enter a valid number!");
                continue;
            }
        };
        
        attempts += 1;
        println!("You guessed: {}", guess);
        
        match guess.cmp(&secret_number) {
            Ordering::Less => println!("Too small!"),
            Ordering::Greater => println!("Too big!"),
            Ordering::Equal => {
                println!("You win! The number was {}.", secret_number);
                println!("It took you {} attempts.", attempts);
                
                match attempts {
                    1..=3 => println!("Amazing!"),
                    4..=7 => println!("Good job!"),
                    _ => println!("Keep practicing!"),
                }
                break;
            }
        }
    }
}
```

> **Note:** Add `rand = "0.8"` to your `Cargo.toml` under `[dependencies]`.

## Exercise 3: Structs & Methods
**Difficulty:** ★★★☆☆  
**Concepts:** Structs, impl blocks, methods, associated functions, derive traits  

**Description:**  
Define a `Rectangle` struct with width and height. Implement methods to calculate area, perimeter, and check if it can hold another rectangle. Use the `#[derive(Debug)]` trait for printing.

**Example Starter Code:**
```rust
#[derive(Debug)]
struct Rectangle {
    width: f64,
    height: f64,
}

impl Rectangle {
    // Associated function (constructor)
    fn new(width: f64, height: f64) -> Self {
        Rectangle { width, height }
    }
    
    // Square constructor
    fn square(size: f64) -> Self {
        Rectangle {
            width: size,
            height: size,
        }
    }
    
    // Methods (take &self)
    fn area(&self) -> f64 {
        self.width * self.height
    }
    
    fn perimeter(&self) -> f64 {
        2.0 * (self.width + self.height)
    }
    
    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }
    
    fn is_square(&self) -> bool {
        self.width == self.height
    }
}

fn main() {
    let rect1 = Rectangle::new(30.0, 50.0);
    let rect2 = Rectangle::new(10.0, 40.0);
    let square = Rectangle::square(25.0);
    
    println!("rect1: {:?}", rect1);
    println!("  Area: {}", rect1.area());
    println!("  Perimeter: {}", rect1.perimeter());
    println!("  Is square? {}", rect1.is_square());
    
    println!("\nrect2: {:?}", rect2);
    println!("\nsquare: {:?}", square);
    println!("  Is square? {}", square.is_square());
    
    println!("\nCan rect1 hold rect2? {}", rect1.can_hold(&rect2));
}
```

## Exercise 4: Vector Operations
**Difficulty:** ★★☆☆☆  
**Concepts:** Vectors, iterators, closures, functional methods  

**Description:**  
Work with `Vec<i32>`. Perform operations using iterators: map, filter, fold, and collect. Find min, max, sum, and create filtered subsets.

**Example Starter Code:**
```rust
fn main() {
    let numbers = vec![15, 3, 22, 8, 45, 12, 7, 31, 9, 50];
    
    println!("Original: {:?}", numbers);
    
    // Double each number
    let doubled: Vec<i32> = numbers.iter().map(|x| x * 2).collect();
    println!("Doubled:   {:?}", doubled);
    
    // Filter: keep only even numbers
    let evens: Vec<&i32> = numbers.iter().filter(|&&x| x % 2 == 0).collect();
    println!("Evens:     {:?}", evens);
    
    // Filter: numbers greater than 20
    let large: Vec<&i32> = numbers.iter().filter(|&&x| x > 20).collect();
    println!("Large (>20): {:?}", large);
    
    // Sum using fold
    let sum: i32 = numbers.iter().fold(0, |acc, &x| acc + x);
    println!("Sum:       {}", sum);
    
    // Min and max
    let min = numbers.iter().min().unwrap();
    let max = numbers.iter().max().unwrap();
    println!("Min:       {}", min);
    println!("Max:       {}", max);
    
    // Average
    let avg = sum as f64 / numbers.len() as f64;
    println!("Average:   {:.2}", avg);
    
    // Chaining: sum of squares of even numbers
    let sum_squares_evens: i32 = numbers
        .iter()
        .filter(|&&x| x % 2 == 0)
        .map(|&x| x * x)
        .sum();
    println!("Sum of squares of evens: {}", sum_squares_evens);
}
```

## Exercise 5: Pattern Matching
**Difficulty:** ★★★☆☆  
**Concepts:** Enums, match expressions, Option, if let, Result  

**Description:**  
Define an enum representing different shapes. Use pattern matching to calculate the area based on the shape variant. Handle `Option` and `Result` types.

**Example Starter Code:**
```rust
enum Shape {
    Circle(f64),                 // radius
    Rectangle(f64, f64),         // width, height
    Triangle(f64, f64),          // base, height
}

impl Shape {
    fn area(&self) -> f64 {
        match self {
            Shape::Circle(radius) => std::f64::consts::PI * radius * radius,
            Shape::Rectangle(width, height) => width * height,
            Shape::Triangle(base, height) => 0.5 * base * height,
        }
    }
    
    fn describe(&self) -> String {
        match self {
            Shape::Circle(r) => format!("Circle with radius {}", r),
            Shape::Rectangle(w, h) => format!("Rectangle {}x{}", w, h),
            Shape::Triangle(b, h) => format!("Triangle with base {} and height {}", b, h),
        }
    }
}

fn divide(a: f64, b: f64) -> Result<f64, String> {
    if b == 0.0 {
        Err(String::from("Cannot divide by zero"))
    } else {
        Ok(a / b)
    }
}

fn main() {
    let shapes = vec![
        Shape::Circle(5.0),
        Shape::Rectangle(4.0, 7.0),
        Shape::Triangle(3.0, 6.0),
    ];
    
    println!("=== Shape Area Calculator ===\n");
    
    for shape in &shapes {
        println!("{}", shape.describe());
        println!("  Area: {:.2}\n", shape.area());
    }
    
    // Match with if let
    if let Shape::Circle(radius) = &shapes[0] {
        println!("First shape is a circle with radius {}!", radius);
    }
    
    // Result handling with match
    println!("\n=== Division Tests ===");
    let test_cases = vec![(10.0, 2.0), (5.0, 0.0), (15.0, 3.0)];
    
    for (a, b) in test_cases {
        match divide(a, b) {
            Ok(result) => println!("{} / {} = {}", a, b, result),
            Err(e) => println!("{} / {} -> {}", a, b, e),
        }
    }
    
    // Option handling
    let numbers = vec![Some(1), None, Some(3), Some(5), None];
    let sum: i32 = numbers.iter()
        .filter_map(|&x| x)    // Keep only Some values
        .sum();
    println!("\nSum of Some values: {}", sum);
}
```
