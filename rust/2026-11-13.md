# Rust — Basic Exercises (2026-11-13)
Sources: The Rust Book, Rust by Example, Rust std docs, Rustlings

Theme: **File I/O** — reading and writing files with `std::fs`, `OpenOptions`, and `BufReader` (with `Result` error handling).

## Exercise 1: Write Text to a File
**Difficulty:** Basic
**Concepts:** `std::fs::write`, `Result`/`?` operator, `fn main() -> Result<()>`

Write a program that creates a file named `notes.txt` and writes two lines into it. `fs::write` creates the file if it doesn't exist and overwrites it if it does.

**Starter code:**
```rust
use std::fs;

fn main() -> std::io::Result<()> {
    fs::write("notes.txt", "First line\nSecond line\n")?;
    println!("File written.");
    Ok(())
}
```

**Task:** Handle the error manually with a `match` instead of `?`, printing a custom message on failure. Then write multiple lines by joining a `Vec<&str>` with `"\n"`.

## Exercise 2: Read an Entire File
**Difficulty:** Basic
**Concepts:** `std::fs::read_to_string`, `String`, `?` operator

Write a program that reads the whole contents of `notes.txt` and prints it.

**Starter code:**
```rust
use std::fs;

fn main() -> std::io::Result<()> {
    let content = fs::read_to_string("notes.txt")?;
    println!("{}", content);
    Ok(())
}
```

**Task:** Read the file line-by-line using `BufReader` and a `for line in reader.lines()` loop, printing each line with its index.

## Exercise 3: Append a Line to a File
**Difficulty:** Basic
**Concepts:** `OpenOptions::new().append(true)`, `write_all`

Write a program that adds a new line to the end of `notes.txt` without deleting the existing content.

**Starter code:**
```rust
use std::fs::OpenOptions;
use std::io::Write;

fn main() -> std::io::Result<()> {
    let mut file = OpenOptions::new().append(true).open("notes.txt")?;
    writeln!(file, "Appended line")?;
    println!("Appended.");
    Ok(())
}
```

**Task:** Use a loop to append the numbers 1 through 5, one per line. Then read the file back to confirm the original lines remain.

## Exercise 4: Count Lines and Words
**Difficulty:** Basic
**Concepts:** `BufReader`, `.lines()`, `str::split_whitespace`, iterators

Write a program that opens `notes.txt` and reports the number of lines and the total number of words it contains.

**Starter code:**
```rust
use std::fs::File;
use std::io::{self, BufRead};

fn main() -> io::Result<()> {
    let file = File::open("notes.txt")?;
    let reader = io::BufReader::new(file);

    let mut lines = 0;
    let mut words = 0;
    for line in reader.lines() {
        let line = line?;
        lines += 1;
        words += line.split_whitespace().count();
    }
    println!("Lines: {}", lines);
    println!("Words: {}", words);
    Ok(())
}
```

**Task:** Also count characters with `line.chars().count()`. Then use `.filter()` on `reader.lines()` to count how many lines contain the word "the" (case-insensitive).

## Exercise 5: Copy a File
**Difficulty:** Basic
**Concepts:** `std::fs::copy`, `Path::exists`, error handling

Write a program that copies the contents of `notes.txt` into a new file named `notes_copy.txt`, warning if the destination already exists.

**Starter code:**
```rust
use std::fs;
use std::path::Path;

fn main() -> std::io::Result<()> {
    let target = Path::new("notes_copy.txt");
    if target.exists() {
        println!("Destination already exists. Overwriting...");
    }
    fs::copy("notes.txt", "notes_copy.txt")?;
    println!("Copied.");
    Ok(())
}
```

**Task:** Rewrite the copy manually with `fs::read` and `fs::write`, printing the number of bytes copied. Then use `match` to give a friendly message when the source file is missing.
