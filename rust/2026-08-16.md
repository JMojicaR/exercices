## Exercise 1: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a function that returns the factorial of a non-negative integer using a loop.

**Given Input:** `factorial(5)`

**Expected Output:**
```
120
```

### Concepts
- `fn` with a return type
- `for` loop over a range (`1..=n`)
- Mutable accumulator variable

### Example / Starter Code

```rust
fn factorial(n: u64) -> u64 {
    let mut result = 1;
    for i in 1..=n {
        result *= i;
    }
    result
}

fn main() {
    println!("{}", factorial(5));   // 120
    println!("{}", factorial(0));   // 1
}
```

## Exercise 2: Reverse a String

**Difficulty:** Basic

### Problem
Write a function that returns the given string reversed.

**Given Input:** `reverse_string("hello")`

**Expected Output:**
```
"olleh"
```

### Concepts
- `chars()` iterator
- `.rev()` and `.collect()`
- Returning a `String`

### Example / Starter Code

```rust
fn reverse_string(s: &str) -> String {
    s.chars().rev().collect()
}

fn main() {
    println!("{}", reverse_string("hello"));    // "olleh"
    println!("{}", reverse_string("Rust"));     // "tsuR"
}
```

## Exercise 3: FizzBuzz

**Difficulty:** Basic

### Problem
Write a program that prints `1` to `n`. For multiples of `3`, print `"Fizz"`; multiples of `5`, print `"Buzz"`; multiples of both, print `"FizzBuzz"`; otherwise print the number.

**Given Input:** `n = 15`

### Concepts
- `for` loop with a range
- `if / else if / else` branching
- `println!` macro

### Example / Starter Code

```rust
fn main() {
    for i in 1..=15 {
        if i % 15 == 0 {
            println!("FizzBuzz");
        } else if i % 3 == 0 {
            println!("Fizz");
        } else if i % 5 == 0 {
            println!("Buzz");
        } else {
            println!("{}", i);
        }
    }
}
```

## Exercise 4: Sum of a Vector's Elements

**Difficulty:** Basic

### Problem
Write a function that returns the sum of all elements in a slice of integers.

**Given Input:** `sum(&[1, 2, 3, 4, 5])`

**Expected Output:**
```
15
```

### Concepts
- Slices (`&[i32]`)
- `.iter()` and `.sum()`
- Passing a `Vec` as a slice via `&vec`

### Example / Starter Code

```rust
fn sum(numbers: &[i32]) -> i32 {
    numbers.iter().sum()
}

fn main() {
    let nums = vec![1, 2, 3, 4, 5];
    println!("{}", sum(&nums));   // 15
}
```

## Exercise 5: Palindrome Check

**Difficulty:** Basic

### Problem
Write a function that returns `true` if a string is a palindrome (ignoring case) and `false` otherwise.

**Given Input:**
- `is_palindrome("racecar")`
- `is_palindrome("hello")`

**Expected Output:**
- `true`
- `false`

### Concepts
- `.to_lowercase()`
- `chars()` and `.rev()`
- `Iterator::eq` to compare forward and reverse iterators

### Example / Starter Code

```rust
fn is_palindrome(s: &str) -> bool {
    let s = s.to_lowercase();
    s.chars().eq(s.chars().rev())
}

fn main() {
    println!("{}", is_palindrome("racecar"));   // true
    println!("{}", is_palindrome("hello"));     // false
}
```
