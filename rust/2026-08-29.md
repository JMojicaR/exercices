## Exercise 1: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that reads an integer `n` and prints its multiplication table from 1 to 10 using a `for` loop over a range.

**Given Input:** `5`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

### Concepts
- Reading input with `std::io`
- Parsing with `trim().parse()`
- `for` loop over a range (`1..=10`)

### Example / Starter Code

```rust
use std::io;

fn main() {
    println!("Enter a number: ");
    let mut input = String::new();
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let n: i32 = input.trim().parse().expect("Not a number");

    for i in 1..=10 {
        println!("{} x {} = {}", n, i, n * i);
    }
}
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that finds the largest of three numbers using `if`/`else if`/`else` expressions.

**Given Input:** `10 25 15` (hard-coded)

**Expected Output:**
```
Largest: 25
```

### Concepts
- `if` as an expression
- Comparison operators (`>=`, `&&`)
- Variable binding with `let`

### Example / Starter Code

```rust
fn main() {
    let a = 10;
    let b = 25;
    let c = 15;

    let largest = if a >= b && a >= c {
        a
    } else if b >= a && b >= c {
        b
    } else {
        c
    };

    println!("Largest: {}", largest);
}
```

## Exercise 3: Reverse a String

**Difficulty:** Basic

### Problem
Write a program that reverses a string using an iterator over its characters.

**Given Input:** `hello`

**Expected Output:**
```
Reversed: olleh
```

### Concepts
- `String::from`
- `.chars()`, `.rev()`, `.collect()`
- `String` vs `&str`

### Example / Starter Code

```rust
fn main() {
    let text = String::from("hello");
    let reversed: String = text.chars().rev().collect();
    println!("Reversed: {}", reversed);
}
```

## Exercise 4: Leap Year Checker

**Difficulty:** Basic

### Problem
Write a program that checks whether a year is a leap year using the modulo operator and boolean logic.

**Given Input:** `2024`

**Expected Output:**
```
2024 is a leap year
```

### Concepts
- Modulo operator `%`
- Boolean logic with `&&` and `||`
- `if`/`else`

### Example / Starter Code

```rust
fn main() {
    let year = 2024;
    let is_leap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);

    if is_leap {
        println!("{} is a leap year", year);
    } else {
        println!("{} is not a leap year", year);
    }
}
```

## Exercise 5: Simple Calculator

**Difficulty:** Basic

### Problem
Write a program that performs a basic arithmetic operation using a `match` expression. Handle division by zero.

**Given Input:** `8 2 /` (hard-coded)

**Expected Output:**
```
Result: 4
```

### Concepts
- `match` expression
- Floating-point arithmetic (`f64`)
- Handling edge cases with `if` inside a match arm

### Example / Starter Code

```rust
fn main() {
    let a = 8.0;
    let b = 2.0;
    let op = '/';

    let result = match op {
        '+' => a + b,
        '-' => a - b,
        '*' => a * b,
        '/' => if b != 0.0 { a / b } else { f64::NAN },
        _ => f64::NAN,
    };

    println!("Result: {}", result);
}
```
