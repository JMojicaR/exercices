Theme: **String Manipulation** — reverse a string, check palindromes, count vowels, count character occurrences, and count words using iterators, `chars()`, and `&str`/`String`.

## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** `chars()`, iterator `.rev()`, `.collect()`, `String`, `&str`

Write a function that returns the input string reversed.

**Starter code:**
```rust
fn reverse_string(s: &str) -> String {
    s.chars().rev().collect()
}

fn main() {
    println!("{}", reverse_string("hello"));  // expected: olleh
}
```

**Task:** Handle multi-byte Unicode correctly and verify by reversing `"Rust 🦀"`.

## Exercise 2: Check Palindrome
**Difficulty:** Basic
**Concepts:** `.to_lowercase()`, `String` comparison, `.chars().rev()`, `bool`

Check whether a string reads the same forwards and backwards (ignoring case).

**Starter code:**
```rust
fn is_palindrome(s: &str) -> bool {
    let lower: String = s.to_lowercase();
    lower == lower.chars().rev().collect::<String>()
}

fn main() {
    println!("{}", is_palindrome("Radar"));  // expected: true
    println!("{}", is_palindrome("hello"));  // expected: false
}
```

**Task:** Compare characters from both ends with two pointers, avoiding an extra reversed `String`.

## Exercise 3: Count Vowels
**Difficulty:** Basic
**Concepts:** `.filter()`, closures, `.contains()`, `.count()`, `usize`

Count how many vowels (a, e, i, o, u) appear in a string, case-insensitively.

**Starter code:**
```rust
fn count_vowels(s: &str) -> usize {
    s.chars()
        .filter(|c| "aeiouAEIOU".contains(*c))
        .count()
}

fn main() {
    println!("{}", count_vowels("hello world"));  // expected: 3
}
```

**Task:** Also count the consonants and return a `(usize, usize)` tuple `(vowels, consonants)`.

## Exercise 4: Count Character Occurrences
**Difficulty:** Basic
**Concepts:** `.chars()`, `.filter()`, closures, `char` parameter

Count how many times a given character appears in a string.

**Starter code:**
```rust
fn count_char(s: &str, ch: char) -> usize {
    s.chars().filter(|&c| c == ch).count()
}

fn main() {
    println!("{}", count_char("banana", 'a'));  // expected: 3
}
```

**Task:** Rewrite it with a `for` loop and a mutable counter instead of `.filter().count()`.

## Exercise 5: Count Words
**Difficulty:** Basic
**Concepts:** `.split_whitespace()`, `.count()`, iterators

Count the number of words in a sentence (words separated by whitespace).

**Starter code:**
```rust
fn count_words(sentence: &str) -> usize {
    sentence.split_whitespace().count()
}

fn main() {
    println!("{}", count_words("I love programming"));  // expected: 3
}
```

**Task:** Collect the words into a `Vec<&str>` and print them one per line before returning the count.
