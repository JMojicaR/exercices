## Exercise 1: `Vec` as a Stack
**Difficulty:** Basic
**Concepts:** `Vec::push`, `Vec::pop` (returns `Option`), `Vec::last`, LIFO order

A `Vec` acts as a stack: `push` adds to the end and `pop` removes from the end (returning `Option<T>`).

**Starter code:**
```rust
fn main() {
    let mut stack: Vec<&str> = Vec::new();

    stack.push("a");   // push
    stack.push("b");
    stack.push("c");

    println!("{:?}", stack.last());   // Some("c")
    let top = stack.pop();            // removes and returns Option<&str>
    println!("{:?}", top);            // Some("c")
    println!("{:?}", stack);          // ["a", "b"]
    println!("{}", stack.is_empty()); // false
}
```

**Task:** Push the integers `1..=5` onto a stack and pop them all in a loop, printing each. The output should be `5 4 3 2 1`.

## Exercise 2: `VecDeque` as a Queue
**Difficulty:** Basic
**Concepts:** `VecDeque::push_back`, `pop_front`, `front`, FIFO order

`VecDeque` is a double-ended queue that gives O(1) push/pop at both ends — ideal for FIFO.

**Starter code:**
```rust
use std::collections::VecDeque;

fn main() {
    let mut q: VecDeque<&str> = VecDeque::new();

    q.push_back("a");   // enqueue (back)
    q.push_back("b");
    q.push_back("c");

    println!("{:?}", q.front());      // Some("a")
    let first = q.pop_front();        // dequeue (front)
    println!("{:?}", first);          // Some("a")
    println!("{:?}", q.front());      // Some("b")
    println!("{}", q.len());          // 2
}
```

**Task:** Enqueue the numbers `1..=5` and dequeue them all, printing each. The output should be `1 2 3 4 5`.

## Exercise 3: Balanced Parentheses Checker
**Difficulty:** Basic
**Concepts:** `Vec<char>` stack, `match`, early `false` on mismatch

Use a character stack to check balanced brackets.

**Starter code:**
```rust
fn is_balanced(s: &str) -> bool {
    let mut stack: Vec<char> = Vec::new();
    for ch in s.chars() {
        match ch {
            '(' | '[' | '{' => stack.push(ch),
            ')' | ']' | '}' => {
                let open = match stack.pop() {
                    Some(c) => c,
                    None => return false,
                };
                let ok = match ch {
                    ')' => open == '(',
                    ']' => open == '[',
                    '}' => open == '{',
                    _ => false,
                };
                if !ok { return false; }
            }
            _ => {}
        }
    }
    stack.is_empty()
}

fn main() {
    println!("{}", is_balanced("(a[b]{c})"));   // true
    println!("{}", is_balanced("([)]"));        // false
}
```

**Task:** Add a test for the input `"((("` and confirm it returns `false` (unmatched openers remain on the stack).

## Exercise 4: Reverse a String with a Stack
**Difficulty:** Basic
**Concepts:** push chars, pop to rebuild, `String` building

Push each character and pop them off to reverse the string.

**Starter code:**
```rust
fn reverse_string(text: &str) -> String {
    let mut stack: Vec<char> = Vec::new();
    for ch in text.chars() {
        stack.push(ch);
    }
    let mut result = String::new();
    while let Some(ch) = stack.pop() {
        result.push(ch);
    }
    result
}

fn main() {
    println!("{}", reverse_string("hello"));   // "olleh"
}
```

**Task:** Modify the function to skip digits, so `reverse_string("h1e2l3lo")` returns `"olleh"`.

## Exercise 5: `VecDeque` as a Double-Ended Queue
**Difficulty:** Basic
**Concepts:** `push_front`/`push_back`, `pop_front`/`pop_back`, using both ends

A deque allows adding/removing from both ends. Simulate a job queue that lets you insert a "priority" job at the front.

**Starter code:**
```rust
use std::collections::VecDeque;

fn main() {
    let mut jobs: VecDeque<&str> = VecDeque::new();
    jobs.push_back("download");
    jobs.push_back("compile");
    jobs.push_back("deploy");

    // A high-priority job jumps to the front:
    jobs.push_front("urgent-restart");

    while let Some(job) = jobs.pop_front() {
        println!("Processing: {}", job);
    }
}
```

**Task:** Also add a `pop_back()` demo: after the loop, push two jobs and remove one from the back, printing which job was removed last.
