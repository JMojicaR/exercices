## Exercise 1: Print the ASCII Value of a Character
**Difficulty:** Basic
**Concepts:** `char`, casting with `as`, `println!`

Given a character, print its ASCII (Unicode scalar) value.

**Starter code:**
```rust
fn main() {
    let ch = 'A';
    println!("ASCII value of {} is {}", ch, ch as u32);
}
```

**Task:** Loop over a slice of chars (`for c in ['A', 'B', 'C']`) printing each code, and convert a code back using `char::from_u32(65)`.

## Exercise 2: Check Vowel or Consonant
**Difficulty:** Basic
**Concepts:** `match`, `char::to_ascii_lowercase`, string handling

Read a letter and report whether it is a vowel or a consonant.

**Starter code:**
```rust
fn main() {
    let ch = 'e';
    let lower = ch.to_ascii_lowercase();

    match lower {
        'a' | 'e' | 'i' | 'o' | 'u' => println!("{} is a vowel", ch),
        _ => println!("{} is a consonant", ch),
    }
}
```

**Task:** Use `ch.is_alphabetic()` to print "Not a letter" for non-letter characters, and read the character from stdin.

## Exercise 3: Maximum and Minimum in a Vector
**Difficulty:** Basic
**Concepts:** `Vec`, iterators, `iter().max()` / `min()`, `unwrap`

Find the largest and smallest values in a vector of numbers.

**Starter code:**
```rust
fn main() {
    let numbers = vec![45, 12, 78, 34, 89, 23];

    let max = numbers.iter().max().unwrap();
    let min = numbers.iter().min().unwrap();

    println!("Max: {}, Min: {}", max, min);
}
```

**Task:** Rewrite it with a manual loop that tracks `max` and `min` without using iterator helpers, and handle an empty vector gracefully.

## Exercise 4: Simple Calculator
**Difficulty:** Basic
**Concepts:** `match`, arithmetic operators, `parse()`, `Result`

Write a function that takes two numbers and an operator and returns the result.

**Starter code:**
```rust
fn calculate(a: f64, op: char, b: f64) -> Result<f64, String> {
    match op {
        '+' => Ok(a + b),
        '-' => Ok(a - b),
        '*' => Ok(a * b),
        '/' => {
            if b != 0.0 { Ok(a / b) }
            else { Err("Cannot divide by zero".to_string()) }
        }
        _ => Err("Invalid operator".to_string()),
    }
}

fn main() {
    match calculate(10.0, '/', 2.0) {
        Ok(result) => println!("Result: {}", result),
        Err(e) => println!("Error: {}", e),
    }
}
```

**Task:** Add a `'%'` case, and read the inputs from `stdin` using `read_line` and `parse()`.

## Exercise 5: Print Prime Numbers in a Range
**Difficulty:** Basic
**Concepts:** functions, loops, `bool`, modular arithmetic

Print every prime number between two given bounds (e.g. 10 and 50).

**Starter code:**
```rust
fn is_prime(n: u32) -> bool {
    if n < 2 {
        return false;
    }
    let mut i = 2;
    while i * i <= n {
        if n % i == 0 {
            return false;
        }
        i += 1;
    }
    true
}

fn main() {
    for num in 10..=50 {
        if is_prime(num) {
            print!("{} ", num);
        }
    }
    println!();
}
```

**Task:** Collect the primes into a `Vec<u32>` and print the count, and make the bounds configurable.
