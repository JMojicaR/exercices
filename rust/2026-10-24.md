## Exercise 1: Print a Right-Angled Triangle of Stars
**Difficulty:** Basic
**Concepts:** `for` loops, ranges, `String::repeat()`, `println!`

Print a right-angled triangle of `*` where the number of rows is user-supplied.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter number of rows: ");
    io::stdin().read_line(&mut input).unwrap();
    let rows: usize = input.trim().parse().unwrap();

    for i in 1..=rows {
        println!("{}", "*".repeat(i));
    }
}
```

**Task:** Print an inverted triangle instead, then print numbers (`1`, `22`, `333`, …) using a nested loop rather than `repeat()`.

## Exercise 2: Print Floyd's Triangle
**Difficulty:** Basic
**Concepts:** nested loops, mutable counter, `print!` vs `println!`

Print Floyd's triangle — consecutive numbers arranged in rows of increasing length.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter number of rows: ");
    io::stdin().read_line(&mut input).unwrap();
    let rows: usize = input.trim().parse().unwrap();

    let mut num = 1;
    for i in 1..=rows {
        for _ in 0..i {
            print!("{} ", num);
            num += 1;
        }
        println!();
    }
}
```

**Task:** Right-align the triangle with leading spaces, and start the counter at a user-supplied value.

## Exercise 3: Count Uppercase and Lowercase Letters
**Difficulty:** Basic
**Concepts:** `char::is_uppercase()` / `is_lowercase()`, string iteration, mutation

Count how many uppercase and lowercase letters a string contains.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter a string: ");
    io::stdin().read_line(&mut input).unwrap();

    let (mut upper, mut lower) = (0, 0);
    for ch in input.chars() {
        if ch.is_uppercase() {
            upper += 1;
        } else if ch.is_lowercase() {
            lower += 1;
        }
    }

    println!("Uppercase: {}, Lowercase: {}", upper, lower);
}
```

**Task:** Also count digits (`is_ascii_digit()`) and whitespace (`is_whitespace()`), and print a full breakdown.

## Exercise 4: Remove All Spaces from a String
**Difficulty:** Basic
**Concepts:** `str::replace()`, iterators + `filter` + `collect`

Remove every space from an input string and print the result.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter a string: ");
    io::stdin().read_line(&mut input).unwrap();

    let no_spaces = input.replace(' ', "");
    println!("Without spaces: {}", no_spaces.trim_end());
}
```

**Task:** Remove all whitespace using an iterator: `input.chars().filter(|c| !c.is_whitespace()).collect::<String>()`.

## Exercise 5: Find the Largest Digit in a Number
**Difficulty:** Basic
**Concepts:** `%` and `/`, `loop` or `while`, `max()`, `abs()`

Read a whole number and print its largest single digit.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter a number: ");
    io::stdin().read_line(&mut input).unwrap();
    let mut num: i32 = input.trim().parse().unwrap();

    let mut largest = 0;
    num = num.abs();

    while num > 0 {
        let digit = num % 10;
        if digit > largest {
            largest = digit;
        }
        num /= 10;
    }

    println!("Largest digit: {}", largest);
}
```

**Task:** Also find the smallest digit, and extract the digits into a `Vec<i32>` so you can use `iter().max()` / `iter().min()`.
