## Exercise 1: Read a Name and Greet
**Difficulty:** Basic
**Concepts:** `String`, `std::io`, `read_line`, `trim`, `println!`.

Write a program that reads the user's name and greets them.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut name = String::new();

    println!("What is your name?");
    io::stdin()
        .read_line(&mut name)
        .expect("Failed to read line");

    let name = name.trim();
    println!("Hello, {}!", name);
}
```

**Task:** Also read the user's age and print "Hello, {name}, you are {age} years old."

## Exercise 2: Sum of a Vec
**Difficulty:** Basic
**Concepts:** `Vec`, `for` loops, `iter()`, `sum()`, mutability.

Write a program that sums the numbers in a vector, once with a loop and once with `iter().sum()`.

**Starter code:**
```rust
fn main() {
    let numbers = vec![10, 20, 30, 40, 50];

    let mut sum = 0;
    for n in &numbers {
        sum += n;
    }
    println!("Loop sum: {}", sum);

    let iter_sum: i32 = numbers.iter().sum();
    println!("Iterator sum: {}", iter_sum);
}
```

**Task:** Compute the average by dividing the sum by the vector's length (watch the integer division).

## Exercise 3: Rectangle Struct with Area Method
**Difficulty:** Basic
**Concepts:** `struct`, `impl`, methods, associated functions.

Define a `Rectangle` struct with `width` and `height`, and an `area()` method.

**Starter code:**
```rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

fn main() {
    let rect = Rectangle { width: 30, height: 50 };
    println!("Area: {} square pixels", rect.area());
}
```

**Task:** Add a `perimeter()` method and an associated function `Rectangle::square(size)` that creates a square.

## Exercise 4: Enum Direction with match
**Difficulty:** Basic
**Concepts:** `enum`, `match`, pattern matching.

Define a `Direction` enum and a function that prints where each direction points.

**Starter code:**
```rust
enum Direction {
    North,
    South,
    East,
    West,
}

fn describe(d: Direction) {
    match d {
        Direction::North => println!("North points up"),
        Direction::South => println!("South points down"),
        Direction::East  => println!("East points right"),
        Direction::West  => println!("West points left"),
    }
}

fn main() {
    describe(Direction::North);
    describe(Direction::West);
}
```

**Task:** Add a `NorthEast` variant and a `Direction::Northeast` arm, plus a `match` that returns a `&str` instead of printing.

## Exercise 5: Ownership — Passing a String to a Function
**Difficulty:** Basic
**Concepts:** Ownership, moves, borrowing (`&`), `clone`.

Observe what happens when a `String` is moved into a function versus borrowed.

**Starter code:**
```rust
fn takes_ownership(s: String) {
    println!("Inside: {}", s);
} // s is dropped here

fn borrows(s: &String) {
    println!("Borrowed: {}", s);
}

fn main() {
    let s = String::from("hello");

    borrows(&s);   // borrows, still usable
    println!("Still usable: {}", s);

    takes_ownership(s); // s is moved
    // println!("{}", s); // ERROR: s was moved!
}
```

**Task:** Uncomment the last `println!` and note the compile error; then fix it by passing `s.clone()` to `takes_ownership`.
