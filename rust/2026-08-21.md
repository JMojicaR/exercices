## Exercise 1: Even or Odd Check

**Difficulty:** Basic

### Problem
Write a function `is_even(n: i32) -> bool` that returns `true` if `n` is even and `false` otherwise.

**Given Input:** `is_even(4)`, `is_even(7)`

**Expected Output:**
```
true
false
```

### Concepts
- Function signatures with return types
- Modulo operator (`%`)
- Booleans and `println!`

### Example / Starter Code

```rust
fn is_even(n: i32) -> bool {
    n % 2 == 0
}

fn main() {
    println!("{}", is_even(4));   // true
    println!("{}", is_even(7));   // false
}
```

## Exercise 2: Sum of Natural Numbers

**Difficulty:** Basic

### Problem
Write a function `sum_natural(n: i32) -> i32` that returns the sum of natural numbers from `1` to `n`.

**Given Input:** `sum_natural(10)`

**Expected Output:**
```
55
```

### Concepts
- `for` loop over a range (`1..=n`)
- Mutable accumulator (`let mut`)
- Integer return values

### Example / Starter Code

```rust
fn sum_natural(n: i32) -> i32 {
    let mut sum = 0;
    for i in 1..=n {
        sum += i;
    }
    sum
}

fn main() {
    println!("{}", sum_natural(10));   // 55
}
```

## Exercise 3: Largest Element in a Vector

**Difficulty:** Basic

### Problem
Write a function `largest(v: &[i32]) -> i32` that returns the largest element of a slice, without using the built-in `iter().max()`.

**Given Input:** `largest(&[3, 7, 2, 9, 5])`

**Expected Output:**
```
9
```

### Concepts
- Slices (`&[i32]`)
- Iterating with `for` / `iter()`
- Running maximum and comparisons

### Example / Starter Code

```rust
fn largest(v: &[i32]) -> i32 {
    let mut biggest = v[0];
    for &num in v {
        if num > biggest {
            biggest = num;
        }
    }
    biggest
}

fn main() {
    println!("{}", largest(&[3, 7, 2, 9, 5]));   // 9
}
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a function `count_vowels(s: &str) -> usize` that returns the number of vowels (`a, e, i, o, u`) in a string, ignoring case.

**Given Input:** `count_vowels("Hello World")`

**Expected Output:**
```
3
```

### Concepts
- `&str` parameters
- `to_lowercase()`
- `chars()` iteration and `contains`

### Example / Starter Code

```rust
fn count_vowels(s: &str) -> usize {
    s.to_lowercase()
        .chars()
        .filter(|c| "aeiou".contains(*c))
        .count()
}

fn main() {
    println!("{}", count_vowels("Hello World"));   // 3
    println!("{}", count_vowels("Rust"));          // 1
}
```

## Exercise 5: Celsius ↔ Fahrenheit Converter

**Difficulty:** Basic

### Problem
Write two functions `to_fahrenheit(c: f64) -> f64` and `to_celsius(f: f64) -> f64`.

**Given Input:**
- `to_fahrenheit(0.0)` → `32.0`
- `to_celsius(32.0)` → `0.0`

**Expected Output:**
```
32
0
```

### Concepts
- `f64` type and arithmetic
- Multiple functions
- Return expressions (no semicolon)

### Example / Starter Code

```rust
fn to_fahrenheit(c: f64) -> f64 {
    c * 9.0 / 5.0 + 32.0
}

fn to_celsius(f: f64) -> f64 {
    (f - 32.0) * 5.0 / 9.0
}

fn main() {
    println!("{}", to_fahrenheit(0.0));   // 32
    println!("{}", to_celsius(32.0));     // 0
}
```
