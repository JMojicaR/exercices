## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** functions, `for` loop with ranges, `mut` variables, `u64`

Compute `n!` and return it as a `u64`.

**Starter code:**
```rust
fn factorial(n: u64) -> u64 {
    let mut result = 1;
    for i in 1..=n {
        result *= i;
    }
    result
}

fn main() {
    println!("{}", factorial(5)); // 120
    println!("{}", factorial(0)); // 1
}
```

**Task:** Rewrite the function using recursion, with a `// TODO` for the `n == 0` base case.

## Exercise 2: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** `Vec<u64>`, `push`, mutable tuple binding, `for` loop

Return the first `n` Fibonacci numbers as a `Vec<u64>`.

**Starter code:**
```rust
fn fibonacci(n: u32) -> Vec<u64> {
    let mut seq = Vec::new();
    let (mut a, mut b) = (0u64, 1u64);
    for _ in 0..n {
        seq.push(a);
        let next = a + b;
        a = b;
        b = next;
    }
    seq
}

fn main() {
    println!("{:?}", fibonacci(7)); // [0, 1, 1, 2, 3, 5, 8]
}
```

**Task:** Add an `nth_fibonacci(n: u32) -> u64` function that returns only the `n`-th value.

## Exercise 3: Check Prime Number
**Difficulty:** Basic
**Concepts:** `bool` return, `f64::sqrt` cast, `for` loop, early return

Return `true` if a number is prime, `false` otherwise.

**Starter code:**
```rust
fn is_prime(n: u64) -> bool {
    if n < 2 {
        return false;
    }
    for i in 2..=((n as f64).sqrt() as u64) {
        if n % i == 0 {
            return false;
        }
    }
    true
}

fn main() {
    println!("{}", is_prime(7));  // true
    println!("{}", is_prime(10)); // false
}
```

**Task:** Write a `count_primes(limit: u64) -> u64` function that returns the number of primes below `limit`.

## Exercise 4: Sum of Digits
**Difficulty:** Basic
**Concepts:** `mut` parameters, `%` and `/`, `while` loop

Return the sum of the individual digits of a number.

**Starter code:**
```rust
fn sum_of_digits(mut n: u64) -> u64 {
    let mut sum = 0;
    while n > 0 {
        sum += n % 10;
        n /= 10;
    }
    sum
}

fn main() {
    println!("{}", sum_of_digits(1234)); // 10
}
```

**Task:** Rewrite it using `n.to_string()` and `chars()`, mapping each char back to a digit.

## Exercise 5: Greatest Common Divisor (GCD)
**Difficulty:** Basic
**Concepts:** Euclidean algorithm, `mut` parameters, `while` loop, `%`

Compute the greatest common divisor of two integers.

**Starter code:**
```rust
fn gcd(mut a: u64, mut b: u64) -> u64 {
    while b != 0 {
        let temp = b;
        b = a % b;
        a = temp;
    }
    a
}

fn main() {
    println!("{}", gcd(48, 18)); // 6
    println!("{}", gcd(100, 35)); // 5
}
```

**Task:** Add an `lcm(a: u64, b: u64) -> u64` function using `lcm(a, b) = a / gcd(a, b) * b`.
