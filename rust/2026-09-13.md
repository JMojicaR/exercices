## Exercise 1: FizzBuzz
- **Difficulty:** Easy
- **Description:** Print the numbers 1 to 20. For multiples of 3 print `"Fizz"`, for multiples of 5 print `"Buzz"`, for multiples of both print `"FizzBuzz"`, otherwise print the number.
- **Concepts:** `for` loop, ranges `1..=20`, `if`/`else if`/`else`, modulo `%`, `println!`
- **Starter code:**
```rust
fn main() {
    for i in 1..=20 {
        if i % 15 == 0 {
            println!("FizzBuzz");
        } else if i % 3 == 0 {
            println!("Fizz");
        } else if i % 5 == 0 {
            println!("Buzz");
        } else {
            // TODO: print the number itself
            println!("{}", i);
        }
    }
}
```
