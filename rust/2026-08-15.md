## Exercise 1: Nth Fibonacci Number

**Difficulty:** Basic

### Problem
Write a function `fibonacci(n)` that returns the nth Fibonacci number (0-indexed, so `fibonacci(0) = 0`).

**Given Input:** `fibonacci(10)`

**Expected Output:**
```
55
```

### Concepts
- Function signatures with explicit types
- Mutable bindings (`let mut`)
- `for` loops with ranges
- Tuple-style sequential updates

### Example / Starter Code

```rust
fn fibonacci(n: u32) -> u32 {
    let mut a = 0;
    let mut b = 1;

    for _ in 0..n {
        let next = a + b;
        a = b;
        b = next;
    }
    a
}

fn main() {
    println!("fib(10) = {}", fibonacci(10)); // 55
}
```

## Exercise 2: Even or Odd Check

**Difficulty:** Basic

### Problem
Write a function `is_even(n)` that returns `true` if a number is even and `false` otherwise.

**Given Input:**
- `is_even(4)`
- `is_even(7)`

**Expected Output:**
- `true`
- `false`

### Concepts
- Boolean return type
- Modulo operator (`%`)
- Expression-based returns (no `return` keyword needed)

### Example / Starter Code

```rust
fn is_even(n: i32) -> bool {
    n % 2 == 0
}

fn main() {
    println!("{}", is_even(4));  // true
    println!("{}", is_even(7));  // false
}
```

## Exercise 3: Min and Max in a Vector

**Difficulty:** Basic

### Problem
Write a program that finds the smallest and largest values in a vector of integers.

**Given Input:** `vec![3, 1, 7, 4, 9, 2]`

**Expected Output:**
```
min = 1, max = 9
```

### Concepts
- Creating vectors with `vec!`
- Iterator methods `.iter()`, `.min()`, `.max()`
- `Option` handling with `.unwrap()`

### Example / Starter Code

```rust
fn main() {
    let nums = vec![3, 1, 7, 4, 9, 2];

    let min = nums.iter().min().unwrap();
    let max = nums.iter().max().unwrap();

    println!("min = {}, max = {}", min, max);
}
```

## Exercise 4: Count Vowels

**Difficulty:** Basic

### Problem
Write a function `count_vowels(s)` that counts the vowels (`a, e, i, o, u`) in a string, ignoring case.

**Given Input:** `count_vowels("Hello World")`

**Expected Output:**
```
3
```

### Concepts
- String slices (`&str`)
- `.to_lowercase()` and `.chars()` iterator
- `.filter()` with a closure
- `.contains()` for membership

### Example / Starter Code

```rust
fn count_vowels(s: &str) -> usize {
    s.to_lowercase()
        .chars()
        .filter(|c| "aeiou".contains(*c))
        .count()
}

fn main() {
    println!("{}", count_vowels("Hello World")); // 3
}
```

## Exercise 5: Check Prime Number

**Difficulty:** Basic

### Problem
Write a function `is_prime(n)` that returns `true` if `n` is prime and `false` otherwise.

**Given Input:**
- `is_prime(11)`
- `is_prime(15)`

**Expected Output:**
- `true`
- `false`

### Concepts
- Early return with `return` keyword
- Casting to `f64` for `sqrt()`
- Inclusive ranges (`..=`)

### Example / Starter Code

```rust
fn is_prime(n: u32) -> bool {
    if n < 2 {
        return false;
    }
    for i in 2..=((n as f64).sqrt() as u32) {
        if n % i == 0 {
            return false;
        }
    }
    true
}

fn main() {
    println!("{}", is_prime(11)); // true
    println!("{}", is_prime(15)); // false
}
```
