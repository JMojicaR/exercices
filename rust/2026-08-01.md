## Exercise 3: FizzBuzz
**Difficulty:** Basic

**Description:**
Write a program that prints the numbers from 1 to 30. For multiples of 3, print "Fizz" instead of the number. For multiples of 5, print "Buzz". For numbers that are multiples of both 3 and 5, print "FizzBuzz". This exercise covers loops, conditionals, and the `match` expression.

**Concepts:**
- `for` loops with ranges (`1..=30`)
- `if` / `else if` / `else` conditionals
- The `match` expression
- Remainder operator (`%`)
- Printing with `println!`

**Starter Code:**
```rust
fn main() {
    for i in 1..=30 {
        // TODO: Print "Fizz", "Buzz", "FizzBuzz", or the number
        if i % 3 == 0 && i % 5 == 0 {
            println!("FizzBuzz");
        } else if i % 3 == 0 {
            println!("Fizz");
        } else if i % 5 == 0 {
            println!("Buzz");
        } else {
            println!("{}", i);
        }
    }
}
```

## Exercise 5: Simple Struct — Rectangle Area
**Difficulty:** Basic

**Description:**

- Defining structs with named fields
- `impl` blocks for adding methods
- Method syntax (`&self`)
- Field access (dot notation)

**Starter Code:**
```rust
struct Rectangle {
    width: f64,
    height: f64,
}

impl Rectangle {
    // TODO: Define an area method that returns width * height
    fn area(&self) -> f64 {
        0.0
    }
}

fn main() {
    let rect = Rectangle { width: 5.0, height: 3.0 };
    println!("The area of a {}x{} rectangle is {}", rect.width, rect.height, rect.area());

```
