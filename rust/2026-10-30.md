## Exercise 1: Linear Search
**Difficulty:** Basic
**Concepts:** `for` loop, `Vec`, indexing, `Option<usize>`, `enumerate()`

Write a function that searches for a target value in a slice and returns its index as an `Option<usize>`.

**Starter code:**
```rust
fn linear_search(arr: &[i32], target: i32) -> Option<usize> {
    for i in 0..arr.len() {
        if arr[i] == target {
            return Some(i);
        }
    }
    None
}

fn main() {
    let numbers = vec![10, 23, 45, 70, 11, 15];
    println!("{:?}", linear_search(&numbers, 70)); // expected: Some(3)
    println!("{:?}", linear_search(&numbers, 99)); // expected: None
}
```

**Task:** Rewrite the loop using `.iter().enumerate()` and `find()`, returning `Option<usize>`.

## Exercise 2: Binary Search
**Difficulty:** Basic
**Concepts:** `while` loop, `usize` indexing, sorted input, midpoint arithmetic

Search for a target in a *sorted* slice using binary search, halving the search range each step.

**Starter code:**
```rust
fn binary_search(arr: &[i32], target: i32) -> Option<usize> {
    let mut low = 0usize;
    let mut high = arr.len();

    while low < high {
        let mid = low + (high - low) / 2;
        if arr[mid] == target {
            return Some(mid);
        } else if arr[mid] < target {
            low = mid + 1;
        } else {
            high = mid;
        }
    }
    None
}

fn main() {
    let sorted = vec![1, 3, 5, 7, 9, 11, 13];
    println!("{:?}", binary_search(&sorted, 9)); // expected: Some(4)
    println!("{:?}", binary_search(&sorted, 4)); // expected: None
}
```

**Task:** Print `low`, `high`, and `mid` at the start of each iteration to visualize how the range shrinks.

## Exercise 3: Bubble Sort
**Difficulty:** Basic
**Concepts:** nested `for` loops, `swap()`, mutable borrows, comparison operators

Sort a vector in ascending order using bubble sort (repeatedly swap adjacent out-of-order elements).

**Starter code:**
```rust
fn bubble_sort(arr: &mut [i32]) {
    let n = arr.len();
    for i in 0..n {
        for j in 0..(n - 1 - i) {
            if arr[j] > arr[j + 1] {
                arr.swap(j, j + 1);
            }
        }
    }
}

fn main() {
    let mut data = vec![64, 34, 25, 12, 22, 11, 90];
    bubble_sort(&mut data);
    println!("{:?}", data); // expected: [11, 12, 22, 25, 34, 64, 90]
}
```

**Task:** Add a `swapped` flag that breaks out of the outer loop early when a pass makes no swaps.

## Exercise 4: Find Minimum and Maximum
**Difficulty:** Basic
**Concepts:** iteration, `Option`, `fold`/manual loop, `Option<(i32, i32)>` return, empty-slice edge case

Find and return the smallest and largest values in a slice in a single pass.

**Starter code:**
```rust
fn find_min_max(arr: &[i32]) -> Option<(i32, i32)> {
    let first = *arr.first()?;
    let mut min = first;
    let mut max = first;
    for &v in arr {
        if v < min { min = v; }
        if v > max { max = v; }
    }
    Some((min, max))
}

fn main() {
    let nums = vec![45, 2, 78, 13, 9, 54];
    println!("{:?}", find_min_max(&nums)); // expected: Some((2, 78))
    println!("{:?}", find_min_max(&vec![])); // expected: None
}
```

**Task:** Also return the *indices* of the min and max elements using `.iter().enumerate()`.

## Exercise 5: Selection Sort
**Difficulty:** Basic
**Concepts:** nested loops, index tracking, `swap()`, finding the minimum in a sub-range

Sort a vector using selection sort: repeatedly find the smallest remaining element and move it to the front.

**Starter code:**
```rust
fn selection_sort(arr: &mut [i32]) {
    let n = arr.len();
    for i in 0..n {
        let mut min_idx = i;
        for j in (i + 1)..n {
            if arr[j] < arr[min_idx] {
                min_idx = j;
            }
        }
        if min_idx != i {
            arr.swap(i, min_idx);
        }
    }
}

fn main() {
    let mut data = vec![29, 10, 14, 37, 13];
    selection_sort(&mut data);
    println!("{:?}", data); // expected: [10, 13, 14, 29, 37]
}
```

**Task:** Sort in *descending* order by changing a single comparison operator.
