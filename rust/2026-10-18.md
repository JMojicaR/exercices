Sources: The Rust Book, Rust by Example, Rustlings

## Exercise 1: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** `mut` variables, ownership, temporary variable

Swap the values of two variables.

**Starter code:**
```rust
fn main() {
    let mut a = 5;
    let mut b = 10;

    let temp = a;
    a = b;
    b = temp;

    println!("a = {}, b = {}", a, b);
}
```

**Task:** Replace the manual swap with `std::mem::swap(&mut a, &mut b);`.

## Exercise 2: Area of a Circle
**Difficulty:** Basic
**Concepts:** `const`, `f64`, formatting with `{:.2}`

Compute the area of a circle given its radius (`area = π × r²`).

**Starter code:**
```rust
fn main() {
    const PI: f64 = 3.14159;
    let radius: f64 = 5.0;

    let area = PI * radius * radius;

    println!("Area: {:.2}", area);
}
```

**Task:** Read the radius from standard input using `std::io::stdin()` and parse it with `.trim().parse::<f64>()`.

## Exercise 3: Positive, Negative or Zero
**Difficulty:** Basic
**Concepts:** `if / else if / else`, floating-point comparison

Classify a number as positive, negative, or zero.

**Starter code:**
```rust
fn main() {
    let n: f64 = -3.0;

    if n > 0.0 {
        println!("Positive");
    } else if n < 0.0 {
        println!("Negative");
    } else {
        println!("Zero");
    }
}
```

**Task:** Read the number from the user and parse it with `trim().parse::<f64>()` (use a `match` on the `Result`).

## Exercise 4: Power of a Number (xⁿ)
**Difficulty:** Basic
**Concepts:** `i64::pow`, `u32` exponent, integer overflow

Compute `base` raised to the power `exp` using Rust's built-in `pow`.

**Starter code:**
```rust
fn main() {
    let base: i64 = 2;
    let exp: u32 = 5;

    let result = base.pow(exp);

    println!("{}^{} = {}", base, exp, result);
}
```

**Task:** Implement your own `pow` using a `for` loop and a mutable accumulator.

## Exercise 5: Reverse a Number
**Difficulty:** Basic
**Concepts:** `mut`, `while` loop, `%` and `/` integer arithmetic

Reverse the digits of an integer (e.g. 1234 → 4321).

**Starter code:**
```rust
fn main() {
    let mut n: i32 = 1234;
    let mut rev: i32 = 0;

    while n != 0 {
        rev = rev * 10 + n % 10;
        n /= 10;
    }

    println!("Reversed: {}", rev);
}
```

**Task:** Confirm it also works for negative numbers (the `while n != 0` condition handles them automatically).
