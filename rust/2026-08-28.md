## Exercise 1: Hello World

**Difficulty:** Basic

### Problem
Write a Rust program that prints "Hello, World!" and then prints the value of an integer and a string variable.

**Expected Output:**
```
Hello, World!
Name: Alice, Age: 25
```

### Concepts
- `fn main()`
- `println!` macro with `{}` placeholders
- `let` bindings (immutable by default)

### Example / Starter Code

```rust
fn main() {
    let name = "Alice";
    let age = 25;

    println!("Hello, World!");
    println!("Name: {}, Age: {}", name, age);
}
```

## Exercise 2: Even or Odd

**Difficulty:** Basic

### Problem
Write a Rust program (using a function `is_even`) that determines whether a number is even or odd.

**Given Input:** `7`

**Expected Output:**
```
7 is Odd
```

### Concepts
- Function definitions with return types
- `if`/`else` and the modulo operator `%`

### Example / Starter Code

```rust
fn is_even(n: i32) -> bool {
    n % 2 == 0
}

fn main() {
    let number = 7;

    if is_even(number) {
        println!("{} is Even", number);
    } else {
        println!("{} is Odd", number);
    }
}
```

## Exercise 3: Sum of Numbers 1 to N

**Difficulty:** Basic

### Problem
Write a Rust program that computes the sum of all integers from 1 to `n` using a `for` loop over a range.

**Given Input:** `10`

**Expected Output:**
```
Sum from 1 to 10 is 55
```

### Concepts
- `for i in 1..=n` inclusive range
- Accumulator variable (`let mut`)

### Example / Starter Code

```rust
fn main() {
    let n = 10;
    let mut total = 0;

    for i in 1..=n {
        total += i;
    }

    println!("Sum from 1 to {} is {}", n, total);
}
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a Rust program that counts the vowels (a, e, i, o, u) in a string, ignoring case.

**Given Input:** `"Hello World"`

**Expected Output:**
```
Number of vowels: 3
```

### Concepts
- `String` and `.chars()` iterator
- `.to_lowercase()`
- `contains()` check on a vowel slice

### Example / Starter Code

```rust
fn count_vowels(text: &str) -> u32 {
    let vowels = ['a', 'e', 'i', 'o', 'u'];
    let mut count = 0;

    for c in text.to_lowercase().chars() {
        if vowels.contains(&c) {
            count += 1;
        }
    }

    count
}

fn main() {
    let count = count_vowels("Hello World");
    println!("Number of vowels: {}", count);
}
```

## Exercise 5: Sum of a Vec

**Difficulty:** Basic

### Problem
Write a Rust program that stores numbers in a `Vec<i32>` and computes their sum. Do it once with a loop and once with the iterator `.iter().sum()`.

**Given Input:** `vec![10, 20, 30, 40, 50]`

**Expected Output:**
```
Sum is 150
```

### Concepts
- `Vec` and the `vec!` macro
- `for` loop over a collection (by reference)
- Iterator `.iter().sum()`

### Example / Starter Code

```rust
fn main() {
    let numbers = vec![10, 20, 30, 40, 50];

    // Loop version
    let mut sum = 0;
    for n in &numbers {
        sum += n;
    }

    // Iterator version
    let sum_iter: i32 = numbers.iter().sum();

    println!("Sum is {}", sum_iter);
}
```
