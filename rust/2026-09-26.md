## Exercise 1: Hello, Name!
**Difficulty:** Basic
**Concepts:** `fn main`, `println!`, `std::io`, `read_line`, mutability.

Write a program that reads the user's name from standard input and greets them.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut name = String::new();

    println!("What is your name?");
    io::stdin()
        .read_line(&mut name)
        .expect("Failed to read line");

    let name = name.trim();
    println!("Hello, {}!", name);
}
```

**Task:** Read the user's age too and print a message that includes both name and age.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** Parsing (`parse()`), conditionals, modulo, `match` or `if`/`else`.

Write a program that reads an integer and reports whether it is even or odd.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter an integer:");
    io::stdin().read_line(&mut input).expect("Failed to read line");

    let num: i32 = input.trim().parse().expect("Please enter a valid integer");

    if num % 2 == 0 {
        println!("Even");
    } else {
        println!("Odd");
    }
}
```

**Task:** Handle invalid (non-numeric) input gracefully instead of panicking.

## Exercise 3: FizzBuzz
**Difficulty:** Basic
**Concepts:** Loops (`for .. in ..`), ranges, conditionals, modulo.

Write a program that prints 1 to 20, replacing multiples of 3 with "Fizz", 5 with "Buzz", and both with "FizzBuzz".

**Starter code:**
```rust
fn main() {
    for i in 1..=20 {
        if i % 15 == 0 {
            println!("FizzBuzz");
        } else if i % 3 == 0 {
            println!("Fizz");
        } else if i % 5 == 0 {
            println!("Buzz");
        } else {
            println!("{}", i);
        }
    }
}
```

**Task:** Let the upper limit be read from standard input instead of hardcoding 20.

## Exercise 4: Factorial
**Difficulty:** Basic
**Concepts:** Functions, `for` loops, `u64`, return values.

Write a function that computes the factorial of a non-negative integer.

**Starter code:**
```rust
fn factorial(n: u64) -> u64 {
    let mut result = 1;
    for i in 1..=n {
        result *= i;
    }
    result
}

fn main() {
    println!("5! = {}", factorial(5));
}
```

**Task:** Implement `factorial` using recursion instead of a loop.

## Exercise 5: Sum of a Vec
**Difficulty:** Basic
**Concepts:** `Vec<i32>`, iteration (`for`/`.iter()`), accumulator, `iter().sum()`.

Write a program that computes the sum and average of a vector of numbers.

**Starter code:**
```rust
fn main() {
    let numbers = vec![10, 20, 30, 40, 50];

    let sum: i32 = numbers.iter().sum();
    let average = sum as f64 / numbers.len() as f64;

    println!("Sum: {}", sum);
    println!("Average: {:.2}", average);
}
```

**Task:** Compute the sum manually with a `for` loop, and also find the maximum value.
