## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** functions, loops, u64, range

Compute the factorial of a non-negative integer.

**Starter code:**
```rust
fn factorial(n: u64) -> u64 {
    let mut result = 1;
    for i in 1..=n {
        result *= i;
    }
    result
}

fn main() {
    let n = 5;
    println!("{}! = {}", n, factorial(n));
}
```

**Task:** Rewrite `factorial` using recursion and test `n = 0`.

## Exercise 2: Prime Number Check
**Difficulty:** Basic
**Concepts:** for loop, modulo, bool

Write a function that returns whether a number is prime.

**Starter code:**
```rust
fn is_prime(n: u64) -> bool {
    if n <= 1 {
        return false;
    }
    for i in 2..=(n as f64).sqrt() as u64 {
        if n % i == 0 {
            return false;
        }
    }
    true
}

fn main() {
    let n = 29;
    println!("{} is {}prime", n, if is_prime(n) { "" } else { "not " });
}
```

**Task:** Print all primes between 2 and 50 using `is_prime`.

## Exercise 3: Count Vowels in a String
**Difficulty:** Basic
**Concepts:** String, chars, match

Count the vowels in a string, case-insensitively.

**Starter code:**
```rust
fn count_vowels(text: &str) -> usize {
    text.chars()
        .filter(|c| matches!(c.to_ascii_lowercase(), 'a' | 'e' | 'i' | 'o' | 'u'))
        .count()
}

fn main() {
    let text = "Hello World";
    println!("Vowel count: {}", count_vowels(text));
}
```

**Task:** Return a tuple of the five individual vowel counts instead of a single total.

## Exercise 4: Reverse a String
**Difficulty:** Basic
**Concepts:** iterators, collect, String

Reverse the characters of a string using an iterator.

**Starter code:**
```rust
fn reverse(text: &str) -> String {
    text.chars().rev().collect()
}

fn main() {
    let original = "rust";
    println!("{} -> {}", original, reverse(original));
}
```

**Task:** Write the reverse manually by building a `String` with a `for` loop and `push`.

## Exercise 5: Average of a Vec
**Difficulty:** Basic
**Concepts:** Vec, iter, sum, len

Compute the average of the numbers in a `Vec<f64>`.

**Starter code:**
```rust
fn average(numbers: &[f64]) -> f64 {
    let sum: f64 = numbers.iter().sum();
    sum / numbers.len() as f64
}

fn main() {
    let numbers = vec![4.0, 8.0, 15.0, 16.0, 23.0, 42.0];
    println!("Average: {}", average(&numbers));
}
```

**Task:** Also compute the minimum and maximum values.
