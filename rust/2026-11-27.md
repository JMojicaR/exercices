## Exercise 1: Define a Node and Build a Small Tree
**Difficulty:** Basic
**Concepts:** `struct`, `Option<Box<Node>>` for recursive types, `Box` to allocate on the heap

A recursive type like a tree node must be heap-allocated (`Box`) so the compiler can compute its size. An empty child is `None`.

**Starter code:**
```rust
#[derive(Debug)]
struct Node {
    value: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

impl Node {
    fn new(value: i32) -> Node {
        Node { value, left: None, right: None }
    }
}

fn main() {
    //         8
    //        / \
    //       3   10
    let mut root = Node::new(8);
    root.left  = Some(Box::new(Node::new(3)));
    root.right = Some(Box::new(Node::new(10)));
}
```

**Task:** Build the full tree below and print the value of the right child of the left child (`root.left` → `right`):
```
       8
      / \
     3   10
    / \    \
   1   6    14
```
(Expected output: `6`.)

## Exercise 2: Insert a Value into the BST
**Difficulty:** Basic
**Concepts:** `&mut self` method, `match` on `Option`, `Box::new` for new nodes

**Starter code:**
```rust
impl Node {
    fn insert(&mut self, value: i32) {
        if value < self.value {
            match self.left {
                Some(ref mut l) => l.insert(value),
                None => self.left = Some(Box::new(Node::new(value))),
            }
        } else {
            match self.right {
                Some(ref mut r) => r.insert(value),
                None => self.right = Some(Box::new(Node::new(value))),
            }
        }
    }
}

fn main() {
    let mut root = Node::new(8);
    for v in [3, 10, 1, 6] {
        root.insert(v);
    }
}
```

**Task:** Insert `14`, `4`, and `7` and print `root` with `{:?}` (thanks to `#[derive(Debug)]`) to confirm the structure.

## Exercise 3: Search for a Value
**Difficulty:** Basic
**Concepts:** function over `&Option<Box<Node>>`, pattern matching, recursion

**Starter code:**
```rust
fn contains(node: &Option<Box<Node>>, value: i32) -> bool {
    match node {
        None => false,
        Some(n) => {
            if n.value == value {
                true
            } else if value < n.value {
                contains(&n.left, value)
            } else {
                contains(&n.right, value)
            }
        }
    }
}

fn main() {
    let mut root = Node::new(8);
    for v in [3, 10, 1, 6, 14, 4, 7] {
        root.insert(v);
    }
    println!("{}", contains(&Some(Box::new(root)), 6));   // true
    println!("{}", contains(&Some(Box::new(root)), 12));  // false — see Task
}
```

**Task:** Modify `contains` to return the depth (steps from the root) where the value is found, or `-1` if absent. (Hint: use `i32` return and add 1 on each recursive call.)

## Exercise 4: In-Order Traversal (Sorted Output)
**Difficulty:** Basic
**Concepts:** recursion (left → current → right), `Vec<i32>` accumulation, `if let`

**Starter code:**
```rust
fn inorder(node: &Option<Box<Node>>, out: &mut Vec<i32>) {
    if let Some(n) = node {
        inorder(&n.left, out);
        out.push(n.value);
        inorder(&n.right, out);
    }
}

fn main() {
    let mut root = Node::new(8);
    for v in [3, 10, 1, 6, 14, 4, 7] {
        root.insert(v);
    }
    let mut out = Vec::new();
    inorder(&Some(Box::new(root)), &mut out);
    println!("{:?}", out);  // [1, 3, 4, 6, 7, 8, 10, 14]
}
```

**Task:** Add a `preorder(node, out)` function (current → left → right). Print both traversals and confirm `inorder` is sorted while `preorder` begins with `8`.

## Exercise 5: Find the Minimum and Maximum
**Difficulty:** Basic
**Concepts:** recursive descent down `left`/`right`, pattern matching on `Option`

**Starter code:**
```rust
fn min_value(node: &Node) -> i32 {
    match &node.left {
        Some(l) => min_value(l),
        None => node.value,
    }
}

fn max_value(node: &Node) -> i32 {
    match &node.right {
        Some(r) => max_value(r),
        None => node.value,
    }
}

fn main() {
    let mut root = Node::new(8);
    for v in [3, 10, 1, 6, 14, 4, 7] {
        root.insert(v);
    }
    println!("{}", min_value(&root));  // 1
    println!("{}", max_value(&root));  // 14
}
```

**Task:** Write an iterative (loop-based) version of `min_value` using `while let Some(n) = current` and reassigning `current = &n.left`.
