## Exercise 2: Even or Odd
- **Difficulty:** Easy
- **Description:** Read an integer and print whether it is even or odd using an `if`/`else` expression.
- **Concepts:** `let mut`, parsing (`parse::<i32>()`), `%` operator, `if`/`else`
- **Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let n: i32 = input.trim().parse().expect("Please enter a number");

    if n % 2 == 0 {
        println!("{} is even", n);
    } else {
        println!("{} is odd", n);
```

## Exercise 3: Reverse a String
- **Difficulty:** Easy
- **Description:** Write a function `reverse(s: &str) -> String` that returns the reversed string using `chars().rev().collect()`.
- **Concepts:** `&str` vs `String`, iterators, `collect()`
- **Starter code:**
```rust
fn reverse(s: &str) -> String {
    s.chars().rev().collect()
}

fn main() {
    println!("{}", reverse("hello")); // "olleh"
}
```

## Exercise 4: Fibonacci Sequence
- **Difficulty:** Easy
- **Description:** Print the first N Fibonacci numbers using a loop. Read N from the user.
- **Concepts:** mutable variables, loops, tuple-like updates
- **Starter code:**
```rust
fn main() {
    let n = 10; // TODO: read n from stdin

    let (mut a, mut b) = (0u64, 1u64);
    for _ in 0..n {
        println!("{}", a);
        let next = a + b;
        a = b;
        b = next;
    }
}
```
