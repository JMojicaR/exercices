## Exercise 1: Hello, Ownership!
**Difficulty:** ★☆☆☆☆  
**Concepts:** `println!`, `let`, `let mut`, ownership (move vs clone), string types (`&str` vs `String`)

### Description
Write a program that:
1. Creates an owned `String` containing "Hello".
2. Creates a reference to it with `&`.
3. Passes the reference to a function that prints it.
4. Creates a mutable `String`, appends " world!" to it, and prints it.

### Starter Code
```rust
fn print_greeting(s: &str) {
    println!("{}", s);
}

    let greeting = String::from("Hello");
    print_greeting(&greeting);

    let mut message = String::from("Hello");
    // Your code here — append " world!" and print
```

## Exercise 3: Vector Statistics
**Difficulty:** ★★☆☆☆  
**Concepts:** `Vec<T>`, `for` loops, references, `iter()`, basic algorithms

### Description
Given a `Vec<i32>`, compute and print the sum, average (as `f64`), minimum, and maximum. Use a manual loop (not `.iter().sum()` for the first attempt, then try the iterator version). Handle the empty vector case.

### Starter Code
```rust
fn main() {
    let numbers = vec![15, 3, 42, 8, 23, 7, 19, 11];

    if numbers.is_empty() {
        println!("Vector is empty!");
        return;
    }

    let mut sum = 0;
    let mut min = numbers[0];
    let mut max = numbers[0];

    // Your code here — compute sum, min, max

    let avg = sum as f64 / numbers.len() as f64;
    println!("Sum: {}", sum);
    println!("Average: {:.2}", avg);
    println!("Min: {}", min);
    println!("Max: {}", max);
}
```

## Exercise 4: Palindrome Checker
**Difficulty:** ★★☆☆☆  
**Concepts:** `String`, `chars()`, `filter()`, `collect()`, `rev()`, string manipulation

### Description
Write a function `fn is_palindrome(s: &str) -> bool` that checks if a string is a palindrome, ignoring case and non-alphanumeric characters. Use iterators and `collect` to build the cleaned string.

### Starter Code
```rust
fn is_palindrome(s: &str) -> bool {
    let cleaned: String = s
        .chars()
        .filter(|c| c.is_alphanumeric())
        .map(|c| c.to_ascii_lowercase())
        .collect();

    // Your code here — check if cleaned is a palindrome
    false
}

fn main() {
    println!("{}", is_palindrome("racecar"));                        // true
    println!("{}", is_palindrome("A man, a plan, a canal: Panama")); // true
    println!("{}", is_palindrome("hello"));                          // false
}
```

**Difficulty:** ★★☆☆☆

### Description
