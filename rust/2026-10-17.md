## Exercise 1: Sum of Vector Elements
**Difficulty:** Basic
**Concepts:** `Vec`, `for` loop, iterators, `iter().sum()`

Compute the sum of all elements in a vector.

**Starter code:**
```rust
fn main() {
    let numbers = vec![10, 20, 30, 40, 50];
    let mut sum = 0;
    for n in &numbers {
        sum += n;
    }
    println!("Sum: {}", sum);
}
```

**Task:** Rewrite it using `numbers.iter().sum::<i32>()`.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** modulo operator (`%`), `if/else`

Check whether a number is even or odd.

**Starter code:**
```rust
fn main() {
    let n = 7;
    if n % 2 == 0 {
        println!("{} is even", n);
    } else {
        println!("{} is odd", n);
    }
}
```

**Task:** Write a `fn is_even(n: i32) -> bool` function and call it.

## Exercise 3: Celsius to Fahrenheit
**Difficulty:** Basic
**Concepts:** functions, `f64`, arithmetic, return values

Convert Celsius to Fahrenheit using `F = C × 9/5 + 32`.

**Starter code:**
```rust
fn c_to_f(celsius: f64) -> f64 {
    (celsius * 9.0 / 5.0) + 32.0
}

fn main() {
    println!("20°C = {}°F", c_to_f(20.0));
}
```

**Task:** Add an `f_to_c` function that converts Fahrenheit back to Celsius.

## Exercise 4: Find the Smallest Number
**Difficulty:** Basic
**Concepts:** iterators, comparison, `iter().min()`

Find the smallest value in a vector.

**Starter code:**
```rust
fn main() {
    let numbers = vec![45, 12, 78, 4, 33];
    let mut smallest = numbers[0];
    for &n in &numbers {
        if n < smallest {
            smallest = n;
        }
    }
    println!("Smallest: {}", smallest);
}
```

**Task:** Solve it with `numbers.iter().min().unwrap()`.

## Exercise 5: Simple Interest
**Difficulty:** Basic
**Concepts:** functions, `f64`, arithmetic

Calculate simple interest using `SI = (P × R × T) / 100`.

**Starter code:**
```rust
fn simple_interest(principal: f64, rate: f64, time: f64) -> f64 {
    (principal * rate * time) / 100.0
}

fn main() {
    println!("Simple interest: {}", simple_interest(1000.0, 5.0, 3.0));
}
```

**Task:** Also return the total amount (principal + interest).
