## Exercise 1: Create and Print a Matrix
**Difficulty:** Basic
**Concepts:** `Vec<Vec<i32>>`, iterating with `&`, `print!`/`println!`

Build a matrix as a vector of vectors and print it row by row.

**Starter code:**
```rust
fn main() {
    let matrix = vec![
        vec![1, 2, 3],
        vec![4, 5, 6],
        vec![7, 8, 9],
    ];

    println!("Matrix:");
    for row in &matrix {
        for val in row {
            print!("{} ", val);
        }
        println!();
    }
}
```

**Task:** Print the matrix in reverse row order, and print each row using the `{:?}` debug formatter.

## Exercise 2: Matrix Addition
**Difficulty:** Basic
**Concepts:** nested `Vec`, mutable result matrix, `vec![0; cols]`

Add two matrices and print the result.

**Starter code:**
```rust
fn main() {
    let a = vec![vec![1, 2], vec![3, 4]];
    let b = vec![vec![5, 6], vec![7, 8]];
    let rows = a.len();
    let cols = a[0].len();
    let mut result = vec![vec![0; cols]; rows];

    for i in 0..rows {
        for j in 0..cols {
            result[i][j] = a[i][j] + b[i][j];
        }
    }

    println!("Sum matrix:");
    for row in &result {
        println!("{:?}", row);
    }
}
```

**Task:** Compute subtraction (`a - b`), and use `zip` on iterators instead of index loops for one of the two.

## Exercise 3: Matrix Transpose
**Difficulty:** Basic
**Concepts:** row/column swapping, flipped-size `Vec`

Transpose a matrix (swap rows and columns).

**Starter code:**
```rust
fn main() {
    let matrix = vec![vec![1, 2, 3], vec![4, 5, 6]];
    let rows = matrix.len();
    let cols = matrix[0].len();
    let mut transpose = vec![vec![0; rows]; cols];

    for i in 0..rows {
        for j in 0..cols {
            transpose[j][i] = matrix[i][j];
        }
    }

    println!("Transpose:");
    for row in &transpose {
        println!("{:?}", row);
    }
}
```

**Task:** Write a `fn transpose(m: &Vec<Vec<i32>>) -> Vec<Vec<i32>>` function and verify double transposition returns the original.

## Exercise 4: Sum of the Main Diagonal
**Difficulty:** Basic
**Concepts:** square matrices, single loop, index tracking

Sum the main diagonal (top-left to bottom-right) of a square matrix.

**Starter code:**
```rust
fn main() {
    let matrix = vec![
        vec![1, 2, 3],
        vec![4, 5, 6],
        vec![7, 8, 9],
    ];
    let n = matrix.len();
    let mut total = 0;

    for i in 0..n {
        total += matrix[i][i];
    }

    println!("Sum of main diagonal: {}", total);
}
```

**Task:** Add the anti-diagonal using `matrix[i][n - 1 - i]` and print both sums.

## Exercise 5: Sum of Each Row and Each Column
**Difficulty:** Basic
**Concepts:** iterators, `sum()`, nested loops

Print the sum of every row and every column.

**Starter code:**
```rust
fn main() {
    let matrix = vec![
        vec![1, 2, 3],
        vec![4, 5, 6],
        vec![7, 8, 9],
    ];
    let rows = matrix.len();
    let cols = matrix[0].len();

    println!("Row sums:");
    for i in 0..rows {
        let row_sum: i32 = matrix[i].iter().sum();
        println!("Row {}: {}", i, row_sum);
    }

    println!("Column sums:");
    for j in 0..cols {
        let mut col_sum = 0;
        for i in 0..rows {
            col_sum += matrix[i][j];
        }
        println!("Col {}: {}", j, col_sum);
    }
}
```

**Task:** Compute column sums with iterators (`(0..cols).map(|j| matrix.iter().map(|row| row[j]).sum())`) and report the grand total.
