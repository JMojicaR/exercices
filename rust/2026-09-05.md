## 2. Even or Odd
- **Description**: Read an integer from standard input and print whether it is even or odd.
- **Difficulty**: Beginner
- **Concepts**: `std::io`, reading input, `%` operator, `if/else`
- **Example/Starter code**:
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter a number: ");
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let number: i32 = input.trim().parse().expect("Please enter a valid number");

    if number % 2 == 0 {
        println!("{} is even", number);
    } else {
        println!("{} is odd", number);
    }
}
```

## 3. Sum of First N Numbers
- **Description**: Compute and print the sum of all integers from 1 to N using a `for` loop.
- **Difficulty**: Beginner
- **Concepts**: `for` loops, ranges (`1..=n`), accumulation, mutable variables
- **Example/Starter code**:
```rust
fn main() {
    let n = 10;
    let mut sum = 0;
    for i in 1..=n {
        sum += i;
    }
    println!("Sum from 1 to {} is {}", n, sum); // 55
}
```

## 4. Factorial
- **Description**: Write a function that computes the factorial of a non-negative integer n.
- **Difficulty**: Beginner
- **Concepts**: Functions, `for` loops, return values
- **Example/Starter code**:
```rust
fn factorial(n: u64) -> u64 {
    let mut result = 1;
    for i in 1..=n {
        result *= i;
    }
    result
}

fn main() {
    println!("Factorial of 5 is {}", factorial(5)); // 120
}
```

## 5. Reverse a String
- **Description**: Write a function that reverses a given string.
- **Difficulty**: Beginner
- **Concepts**: `chars()`, iterators, `rev()`, `collect()`
- **Example/Starter code**:
```rust
fn reverse_string(s: &str) -> String {
    s.chars().rev().collect()
}

fn main() {
    let word = "hello";
    println!("Reversed: {}", reverse_string(word)); // olleh
}
```
