## Exercise 1: Check Leap Year

**Difficulty:** Basic

### Problem
Write a function that checks whether a given year is a leap year using the standard rules (divisible by 400 is leap, divisible by 100 is not, divisible by 4 is leap). Print the result for a sample year.

**Given Input:** `is_leap_year(2024)`

**Expected Output:**
```
2024 is a leap year.
```

### Concepts
- Function definitions with return types
- `if` / `else if` / `else` expressions
- Modulo operator (`%`)
- `println!` macro

### Example / Starter Code

```rust
fn is_leap_year(year: i32) -> bool {
    if year % 400 == 0 {
        true
    } else if year % 100 == 0 {
        false
    } else if year % 4 == 0 {
        true
    } else {
        false
    }
}

fn main() {
    let year = 2024;
    if is_leap_year(year) {
        println!("{} is a leap year.", year);
    } else {
        println!("{} is not a leap year.", year);
    }
}
```

## Exercise 2: GCD of Two Numbers

**Difficulty:** Basic

### Problem
Write a function that computes the greatest common divisor (GCD) of two positive integers using the Euclidean algorithm (repeated modulo). Print the GCD of a sample pair.

**Given Input:** `gcd(48, 18)`

**Expected Output:**
```
GCD of 48 and 18 is 6
```

### Concepts
- `while` loops
- Mutable function parameters (`mut a`, `mut b`)
- Euclidean algorithm
- Tuple-style value swap in `let temp = b;`

### Example / Starter Code

```rust
fn gcd(mut a: u32, mut b: u32) -> u32 {
    while b != 0 {
        let temp = b;
        b = a % b;
        a = temp;
    }
    a
}

fn main() {
    let a = 48;
    let b = 18;
    println!("GCD of {} and {} is {}", a, b, gcd(a, b));
}
```

## Exercise 3: Count Digits in an Integer

**Difficulty:** Basic

### Problem
Write a function that counts how many digits are in a given integer (ignoring the sign). Print the digit count for a sample number.

**Given Input:** `count_digits(12345)`

**Expected Output:**
```
12345 has 5 digits.
```

### Concepts
- `loop` with `break`
- `.abs()` on integers
- Integer division
- Accumulator counting pattern

### Example / Starter Code

```rust
fn count_digits(mut number: i32) -> u32 {
    let mut count = 0;
    number = number.abs();
    loop {
        count += 1;
        number /= 10;
        if number == 0 {
            break;
        }
    }
    count
}

fn main() {
    let number = 12345;
    println!("{} has {} digits.", number, count_digits(number));
}
```

## Exercise 4: Sum of Even Numbers

**Difficulty:** Basic

### Problem
Write a function that sums all even numbers from 1 to `n` (inclusive) using a loop and an `if` check for evenness. Print the result for a sample `n`.

**Given Input:** `sum_of_even_numbers(10)`

**Expected Output:**
```
Sum of even numbers from 1 to 10 is 30
```

### Concepts
- `for` loops with ranges (`1..=n`)
- Modulo operator for even-number checks
- Accumulator (`sum += i`)
- Immutable vs mutable bindings

### Example / Starter Code

```rust
fn sum_of_even_numbers(n: u32) -> u32 {
    let mut sum = 0;
    for i in 1..=n {
        if i % 2 == 0 {
            sum += i;
        }
    }
    sum
}

fn main() {
    let n = 10;
    println!("Sum of even numbers from 1 to {} is {}", n, sum_of_even_numbers(n));
}
```

## Exercise 5: Simple Calculator (match)

**Difficulty:** Basic

### Problem
Write a function that performs basic arithmetic (`+`, `-`, `*`, `/`) on two numbers using a `match` statement, handling division by zero. Print the results for a couple of sample operations.

**Given Input:** `calculate(10.0, 5.0, '+')` and `calculate(10.0, 5.0, '/')`

**Expected Output:**
```
10 + 5 = 15
10 / 5 = 2
```

### Concepts
- `match` statement with multiple arms
- `Result` and `Ok` / `Err`
- Floating-point arithmetic (`f64`)
- Guarding against division by zero

### Example / Starter Code

```rust
fn calculate(a: f64, b: f64, op: char) -> Result<f64, &'static str> {
    match op {
        '+' => Ok(a + b),
        '-' => Ok(a - b),
        '*' => Ok(a * b),
        '/' => {
            if b == 0.0 {
                Err("division by zero")
            } else {
                Ok(a / b)
            }
        }
        _ => Err("invalid operator"),
    }
}

fn main() {
    let a = 10.0;
    let b = 5.0;

    match calculate(a, b, '+') {
        Ok(result) => println!("{} + {} = {}", a, b, result),
        Err(e) => println!("Error: {}", e),
    }

    match calculate(a, b, '/') {
        Ok(result) => println!("{} / {} = {}", a, b, result),
        Err(e) => println!("Error: {}", e),
    }
}
```
