## Exercise 1: Hello, Name!
**Difficulty:** Basic
**Concepts:** `std::io`, mutable variables, `read_line`, `trim`.

Write a program that reads the user's name and prints a greeting.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut name = String::new();
    println!("Enter your name:");
    io::stdin().read_line(&mut name).expect("Failed to read line");
    let name = name.trim();
    println!("Hello, {}!", name);
}
```

**Task:** Also read the user's age and print "You are N years old".

## Exercise 2: Sum of Two Numbers
**Difficulty:** Basic
**Concepts:** Parsing (`parse::<i32>()`), `unwrap`, string clearing.

Write a program that reads two integers and prints their sum.

**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter first number:");
    io::stdin().read_line(&mut input).unwrap();
    let a: i32 = input.trim().parse().unwrap();

    input.clear();
    println!("Enter second number:");
    io::stdin().read_line(&mut input).unwrap();
    let b: i32 = input.trim().parse().unwrap();

    println!("Sum: {}", a + b);
}
```

**Task:** Handle invalid input with `match` on `.parse()` instead of `unwrap`.

## Exercise 3: Multiplication Table
**Difficulty:** Basic
**Concepts:** `for` loops, inclusive ranges (`1..=10`), formatting.

Write a program that prints the multiplication table (1–10) for a fixed number.

**Starter code:**
```rust
fn main() {
    let n = 5;
    for i in 1..=10 {
        println!("{} x {} = {}", n, i, n * i);
    }
}
```

**Task:** Read `n` from the user instead of hardcoding it.

## Exercise 4: Palindrome Checker
**Difficulty:** Basic
**Concepts:** String iteration (`chars()`), `rev()`, `collect`.

Write a program that checks whether a string is a palindrome.

**Starter code:**
```rust
fn main() {
    let word = "racecar";
    let reversed: String = word.chars().rev().collect();
    if word == reversed {
        println!("{} is a palindrome", word);
    } else {
        println!("{} is NOT a palindrome", word);
    }
}
```

**Task:** Make the check case-insensitive by calling `.to_lowercase()` on both strings.

## Exercise 5: Largest Element in a Vec
**Difficulty:** Basic
**Concepts:** `Vec`, `for` loops, references (`&`), comparison.

Write a program that finds the largest number in a vector of integers.

**Starter code:**
```rust
fn main() {
    let nums = vec![3, 7, 2, 9, 5];
    let mut largest = nums[0];
    for &n in &nums {
        if n > largest {
            largest = n;
        }
    }
    println!("Largest: {}", largest);
}
```

**Task:** Also compute the sum and average of the vector (watch out for integer division).
