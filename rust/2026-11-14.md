## Exercise 1: Define a Book Struct
**Difficulty:** Basic
**Concepts:** `struct`, field access, `String`, `println!`

Define a `Book` struct with `title`, `author`, `year`, and `price` fields, create an instance, and print its fields.

**Starter code:**
```rust
struct Book {
    title: String,
    author: String,
    year: u32,
    price: f64,
}

fn main() {
    let book = Book {
        title: String::from("1984"),
        author: String::from("George Orwell"),
        year: 1949,
        price: 12.50,
    };

    println!("{} by {} ({}) — ${:.2}", book.title, book.author, book.year, book.price);
}
```

**Task:** Add a `pages: u32` field and print it along with the other fields.

## Exercise 2: Create and Use Multiple Instances
**Difficulty:** Basic
**Concepts:** `Vec`, `for` loops, references, `derive(Debug)`

Store three `Book` instances in a `Vec` and print each one with a loop.

**Starter code:**
```rust
#[derive(Debug)]
struct Book {
    title: String,
    author: String,
    year: u32,
}

fn main() {
    let books = vec![
        Book { title: String::from("1984"), author: String::from("George Orwell"), year: 1949 },
        Book { title: String::from("Dune"), author: String::from("Frank Herbert"), year: 1965 },
        Book { title: String::from("Neuromancer"), author: String::from("William Gibson"), year: 1984 },
    ];

    for book in &books {
        println!("{} by {} ({})", book.title, book.author, book.year);
    }
}
```

**Task:** Add a `price: f64` field and print the total price of all books by summing inside the loop (or with `.iter().map(...).sum::<f64>()`).

## Exercise 3: Associated Functions and Methods
**Difficulty:** Basic
**Concepts:** `impl`, `Book::new` (associated function), `&self` methods, return values

Add an `impl Book` block with a `new` constructor and methods that compute derived values.

**Starter code:**
```rust
struct Book {
    title: String,
    author: String,
    year: u32,
    price: f64,
}

impl Book {
    fn new(title: &str, author: &str, year: u32, price: f64) -> Book {
        Book {
            title: String::from(title),
            author: String::from(author),
            year,
            price,
        }
    }

    fn age(&self, current_year: u32) -> u32 {
        current_year - self.year
    }

    fn discounted_price(&self, percent: f64) -> f64 {
        self.price * (1.0 - percent / 100.0)
    }
}

fn main() {
    let book = Book::new("Dune", "Frank Herbert", 1965, 15.99);
    println!("Age: {}", book.age(2026));
    println!("Discounted: {:.2}", book.discounted_price(20.0));
}
```

**Task:** Add an `is_classic(&self, current_year: u32) -> bool` method returning `true` when the book is 50+ years old, and test it on several books.

## Exercise 4: Methods That Mutate
**Difficulty:** Basic
**Concepts:** `&mut self`, mutable borrows, in-place mutation

Add a method that modifies the book's own `price` field in place.

**Starter code:**
```rust
struct Book {
    title: String,
    author: String,
    year: u32,
    price: f64,
}

impl Book {
    fn apply_discount(&mut self, percent: f64) {
        self.price *= 1.0 - percent / 100.0;
    }
}

fn main() {
    let mut book = Book {
        title: String::from("1984"),
        author: String::from("George Orwell"),
        year: 1949,
        price: 12.50,
    };

    println!("Before: ${:.2}", book.price);
    book.apply_discount(20.0);
    println!("After: ${:.2}", book.price);
}
```

**Task:** Add a `retitle(&mut self, new_title: &str)` method that replaces the title, and demonstrate it. Note that `book` must be declared `mut` for these methods to work.

## Exercise 5: A Library That Holds Books
**Difficulty:** Basic
**Concepts:** composition, `Vec<Book>`, `Option<&Book>` return type, search

Build a `Library` struct that stores `Book` values in a `Vec` and can add, list, and find them.

**Starter code:**
```rust
struct Book {
    title: String,
    author: String,
    year: u32,
}

impl Book {
    fn describe(&self) -> String {
        format!("{} by {} ({})", self.title, self.author, self.year)
    }
}

struct Library {
    books: Vec<Book>,
}

impl Library {
    fn new() -> Library {
        Library { books: Vec::new() }
    }

    fn add(&mut self, book: Book) {
        self.books.push(book);
    }

    fn find(&self, title: &str) -> Option<&Book> {
        self.books.iter().find(|b| b.title == title)
    }

    fn list(&self) {
        for book in &self.books {
            println!("{}", book.describe());
        }
    }
}

fn main() {
    let mut lib = Library::new();
    lib.add(Book { title: String::from("Dune"), author: String::from("Frank Herbert"), year: 1965 });
    lib.add(Book { title: String::from("1984"), author: String::from("George Orwell"), year: 1949 });
    lib.list();

    match lib.find("Dune") {
        Some(book) => println!("Found: {}", book.describe()),
        None => println!("Not found"),
    }
}
```

**Task:** Add a `count(&self) -> usize` method and a `books_by_year(&self, year: u32) -> Vec<&Book>` method using `.filter(...).collect()`.
