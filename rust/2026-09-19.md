# Rust — Basic Exercises (2026-09-19)

Level: **Basic** · Sources referenced: The Rust Book, Rust by Example, W3Schools, Rustlings

---

## 1. Hello, World!
**Description:** Write a minimal Rust program that prints a greeting using the `println!` macro.
**Difficulty:** Basic
**Concepts:** `fn main`, macros (`println!`), `cargo new`/`rustc`.
**Starter code:**
```rust
fn main() {
    println!("Hello, World!");
}
```

## 2. Even or Odd
**Description:** Determine whether a given integer is even or odd using the modulo operator.
**Difficulty:** Basic
**Concepts:** Variables (`let`), immutability, conditionals, `%` operator.
**Starter code:**
```rust
fn main() {
    let n = 7;
    if n % 2 == 0 {
        println!("{} is even", n);
    } else {
        println!("{} is odd", n);
    }
}
```

## 3. Sum of Array Elements
**Description:** Compute the sum of all elements in an array.
**Difficulty:** Basic
**Concepts:** Arrays (`[T; N]`), `.iter()`, `.sum()`, or manual loop.
**Starter code:**
```rust
fn main() {
    let numbers = [1, 2, 3, 4, 5];
    let sum: i32 = numbers.iter().sum();
    println!("Sum: {}", sum);
}
```

## 4. Factorial
**Description:** Compute the factorial of a number using a loop.
**Difficulty:** Basic
**Concepts:** Loops (`for` over a range), mutable variables (`mut`), range types.
**Starter code:**
```rust
fn factorial(n: u64) -> u64 {
    let mut result = 1;
    for i in 1..=n {
        result *= i;
    }
    result
}

fn main() {
    println!("5! = {}", factorial(5));
}
```

## 5. FizzBuzz
**Description:** Print numbers 1 to 100, replacing multiples of 3 with "Fizz", multiples of 5 with "Buzz", and multiples of both with "FizzBuzz".
**Difficulty:** Basic
**Concepts:** `for` loop, `if`/`else if`/`else`, modulo operator, `match` (optional).
**Starter code:**
```rust
fn main() {
    for i in 1..=100 {
        if i % 15 == 0 {
            println!("FizzBuzz");
        } else if i % 3 == 0 {
            println!("Fizz");
        } else if i % 5 == 0 {
            println!("Buzz");
        } else {
            println!("{}", i);
        }
    }
}
```
