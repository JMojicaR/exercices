## Exercise 1: Create a HashMap & Insert/Get
**Difficulty:** Basic
**Concepts:** `HashMap::new`, `insert`, `get`, `Option` return, ownership of keys

Store and retrieve student grades by name.

**Starter code:**
```rust
use std::collections::HashMap;

fn main() {
    let mut grades: HashMap<&str, i32> = HashMap::new();

    grades.insert("Alice", 85);
    grades.insert("Bob", 72);
    grades.insert("Carol", 90);

    println!("Alice: {:?}", grades.get("Alice"));   // Some(85)
    println!("Dave: {:?}", grades.get("Dave"));     // None

    grades.insert("Bob", 75);                       // update
    println!("{:?}", grades);
}
```

**Task:** Use `match` on `grades.get("Alice")` to print `"Grade is 85"` when `Some`, and `"Not found"` when `None`.

## Exercise 2: Count Word Frequencies with the Entry API
**Difficulty:** Basic
**Concepts:** `.entry()`, `or_insert`, `split_whitespace`, mutable references

Count how many times each word appears in a sentence.

**Starter code:**
```rust
use std::collections::HashMap;

fn main() {
    let sentence = "the cat and the dog and the bird";
    let mut counts: HashMap<&str, i32> = HashMap::new();

    for word in sentence.split_whitespace() {
        let counter = counts.entry(word).or_insert(0);
        *counter += 1;
    }

    for (word, count) in &counts {
        println!("{}: {}", word, count);
    }
}
```

**Task:** Use `or_insert_with` instead of `or_insert` and pass a closure that computes the initial value.

## Exercise 3: Iterate Keys & Values
**Difficulty:** Basic
**Concepts:** `.keys()`, `.values()`, `.iter()`, sorted output with `BTreeMap`

List all keys, all values, and key-value pairs of a map.

**Starter code:**
```rust
use std::collections::HashMap;

fn main() {
    let prices = HashMap::from([
        ("apple", 1.2),
        ("banana", 0.8),
        ("cherry", 2.5),
    ]);

    println!("Keys:");
    for key in prices.keys() {
        println!("  {}", key);
    }

    println!("Values:");
    for value in prices.values() {
        println!("  ${:.2}", value);
    }
}
```

**Task:** Print the pairs in alphabetical order by inserting them into a `std::collections::BTreeMap` and iterating that.

## Exercise 4: ContainsKey & Remove
**Difficulty:** Basic
**Concepts:** `contains_key`, `remove`, `len`, `is_empty`

Manage an inventory and safely remove an item.

**Starter code:**
```rust
use std::collections::HashMap;

fn main() {
    let mut stock = HashMap::from([
        ("apples", 10),
        ("bananas", 5),
        ("cherries", 20),
    ]);

    if stock.contains_key("bananas") {
        let removed = stock.remove("bananas");
        println!("Removed bananas: {:?}", removed);   // Some(5)
    }

    println!("Has bananas? {}", stock.contains_key("bananas"));
    println!("Total items: {}", stock.len());
}
```

**Task:** Add `stock.clear()` at the end and confirm with `stock.is_empty()` that the map is now empty.

## Exercise 5: Find the Key with the Maximum Value
**Difficulty:** Basic
**Concepts:** iterating with `iter()`, tracking max, `Option` and `unwrap_or`, tuple destructuring

Find the student with the highest grade.

**Starter code:**
```rust
use std::collections::HashMap;

fn main() {
    let grades = HashMap::from([
        ("Alice", 85),
        ("Bob", 72),
        ("Carol", 90),
        ("Dave", 78),
    ]);

    let mut best_name = "";
    let mut best_grade = i32::MIN;

    for (&name, &grade) in &grades {
        if grade > best_grade {
            best_grade = grade;
            best_name = name;
        }
    }

    println!("{} has the highest grade: {}", best_name, best_grade);
}
```

**Task:** Rewrite the loop using `grades.iter().max_by_key(|&(_, v)| *v)` and print the result as an `Option`.
