## Exercise 1: Find Maximum & Minimum
**Difficulty:** Basic
**Concepts:** arrays, `.iter()`, `mut`, comparisons

Find and print the smallest and largest values in an array of integers.

**Starter code:**
```rust
fn main() {
    let numbers = [3, 1, 4, 1, 5, 9, 2];
    let mut min = numbers[0];
    let mut max = numbers[0];
    for &n in numbers.iter() {
        if n < min { min = n; }
        if n > max { max = n; }
    }
    println!("min = {}, max = {}", min, max); // min = 1, max = 9
}
```

**Task:** Replace the loop with `numbers.iter().min()` and `numbers.iter().max()`, and unwrap the `Option<&i32>` results safely (e.g. with `.unwrap()` or a `match`).

## Exercise 2: Sum of Elements
**Difficulty:** Basic
**Concepts:** arrays, `.iter()`, accumulator, integer types

Compute and print the sum of all elements in an array of integers.

**Starter code:**
```rust
fn main() {
    let numbers = [1, 2, 3, 4, 5];
    let mut total = 0;
    for &n in numbers.iter() {
        total += n;
    }
    println!("sum = {}", total); // sum = 15
}
```

**Task:** Replace the loop with `numbers.iter().sum::<i32>()`, and compute the average by casting to `f64`.

## Exercise 3: Reverse a Vector
**Difficulty:** Basic
**Concepts:** `Vec`, `Vec::new()`, `.push()`, reverse iteration

Build a new vector holding the elements of the input in reverse order.

**Starter code:**
```rust
fn main() {
    let numbers = vec![1, 2, 3, 4];
    let mut reversed = Vec::new();
    for i in (0..numbers.len()).rev() {
        reversed.push(numbers[i]);
    }
    println!("{:?}", reversed); // [4, 3, 2, 1]
}
```

**Task:** Use `numbers.iter().rev().cloned().collect::<Vec<_>>()` as a more idiomatic alternative, and try `numbers.reverse()` to reverse in place (requires `mut`).

## Exercise 4: Count Occurrences
**Difficulty:** Basic
**Concepts:** `Vec`, `.iter()`, equality, counter

Count how many times a target value appears in a vector of integers.

**Starter code:**
```rust
fn main() {
    let numbers = vec![1, 2, 3, 2, 4, 2];
    let target = 2;
    let mut count = 0;
    for &n in numbers.iter() {
        if n == target { count += 1; }
    }
    println!("count of {} = {}", target, count); // count of 2 = 3
}
```

**Task:** Rewrite using `numbers.iter().filter(|&&n| n == target).count()`, and explain the `&&` in the closure pattern.

## Exercise 5: Remove Duplicates
**Difficulty:** Basic
**Concepts:** `Vec`, `.contains()`, membership test, order preservation

Build a new vector containing each value only once, preserving the original order.

**Starter code:**
```rust
fn main() {
    let numbers = vec![1, 2, 2, 3, 4, 4, 4, 5];
    let mut unique: Vec<i32> = Vec::new();
    for &n in numbers.iter() {
        if !unique.contains(&n) {
            unique.push(n);
        }
    }
    println!("{:?}", unique); // [1, 2, 3, 4, 5]
}
```

**Task:** Rewrite using `std::collections::HashSet` to track seen values, and compare how `HashSet` differs from checking the `Vec` directly.
