## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** String, chars, rev, collect

Write a function that reverses a string.

**Starter code:**
```rust
fn reverse_string(s: &str) -> String {
    s.chars().rev().collect()
}

fn main() {
    let s = String::from("hello");
    println!("Reversed: {}", reverse_string(&s));
}
```

**Task:** Reverse the string using a loop and `push` instead of `rev()`.

## Exercise 2: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** conditionals, integer comparison

Write a function that returns the largest of three integers.

**Starter code:**
```rust
fn largest_of_three(a: i32, b: i32, c: i32) -> i32 {
    let mut largest = a;
    if b > largest {
        largest = b;
    }
    if c > largest {
        largest = c;
    }
    largest
}

fn main() {
    println!("Largest: {}", largest_of_three(3, 9, 5));
}
```

**Task:** Rewrite using `a.max(b).max(c)` and confirm the same result.

## Exercise 3: Multiplication Table
**Difficulty:** Basic
**Concepts:** for loop, range, println! formatting

Print the multiplication table (1 to 10) for a given number.

**Starter code:**
```rust
fn multiplication_table(n: i32) {
    for i in 1..=10 {
        println!("{} x {} = {}", n, i, n * i);
    }
}

fn main() {
    multiplication_table(5);
}
```

**Task:** Print tables for all numbers from 1 to 5.

## Exercise 4: Armstrong Number
**Difficulty:** Basic
**Concepts:** while loop, modulo, pow, string length

Check whether a number is an Armstrong number.

**Starter code:**
```rust
fn is_armstrong(n: u32) -> bool {
    let digits = n.to_string().len() as u32;
    let mut sum = 0;
    let mut num = n;

    while num > 0 {
        let digit = num % 10;
        sum += digit.pow(digits);
        num /= 10;
    }

    sum == n
}

fn main() {
    println!("{}", is_armstrong(153)); // true
}
```

**Task:** Print all Armstrong numbers between 1 and 1000.

## Exercise 5: Count Digits in a Number
**Difficulty:** Basic
**Concepts:** while loop, integer division, counting

Write a function that counts the digits of an integer.

**Starter code:**
```rust
fn count_digits(n: u32) -> u32 {
    let mut count = 0;
    let mut num = n;

    if num == 0 {
        return 1;
    }

    while num > 0 {
        num /= 10;
        count += 1;
    }

    count
}

fn main() {
    println!("Digits: {}", count_digits(12345)); // 5
}
```

**Task:** Also count digits using `n.to_string().len()` and verify both agree.
