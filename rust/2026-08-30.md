## Exercise 1: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a Rust program that reads a non-negative integer and prints its factorial. Factorial of 0 is 1.

**Given Input:** `5`

**Expected Output:**
```
Factorial of 5 is 120
```

### Concepts
- Reading input with `std::io::stdin()`
- `for` loop with a range accumulator
- `u64` type

### Example / Starter Code

```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter a number: ");
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let n: u64 = input.trim().parse().expect("Not a number");

    let mut factorial: u64 = 1;
    for i in 1..=n {
        factorial *= i;
    }

    println!("Factorial of {} is {}", n, factorial);
}
```

## Exercise 2: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a Rust program that prints the first `n` terms of the Fibonacci sequence (`0, 1, 1, 2, 3, 5, …`).

**Given Input:** `7`

**Expected Output:**
```
0
1
1
2
3
5
8
```

### Concepts
- `let mut` bindings and reassignment
- `for` loop over a range
- `println!` macro

### Example / Starter Code

```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("How many terms? ");
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let n: u32 = input.trim().parse().expect("Not a number");

    let (mut a, mut b) = (0u64, 1u64);
    for _ in 0..n {
        println!("{}", a);
        let next = a + b;
        a = b;
        b = next;
    }
}
```

## Exercise 3: Palindrome Check

**Difficulty:** Basic

### Problem
Write a Rust program that reads a string and checks whether it is a palindrome (case-insensitive).

**Given Input:** `Racecar`

**Expected Output:**
```
racecar is a palindrome
```

### Concepts
- `String::to_lowercase()`
- `chars().eq(chars().rev())` iterator comparison
- `if`/`else`

### Example / Starter Code

```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter a string: ");
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let text = input.trim().to_lowercase();

    let is_palindrome = text.chars().eq(text.chars().rev());

    if is_palindrome {
        println!("{} is a palindrome", text);
    } else {
        println!("{} is not a palindrome", text);
    }
}
```

## Exercise 4: Prime Number Check

**Difficulty:** Basic

### Problem
Write a Rust program that reads a positive integer and determines whether it is a prime number.

**Given Input:** `29`

**Expected Output:**
```
29 is a prime number
```

### Concepts
- `for` loop with `break`
- Modulo operator `%`
- `f64::sqrt` for early exit

### Example / Starter Code

```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter a number: ");
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let n: u64 = input.trim().parse().expect("Not a number");

    let mut is_prime = n > 1;
    if is_prime {
        let limit = (n as f64).sqrt() as u64;
        for i in 2..=limit {
            if n % i == 0 {
                is_prime = false;
                break;
            }
        }
    }

    if is_prime {
        println!("{} is a prime number", n);
    } else {
        println!("{} is not a prime number", n);
    }
}
```

## Exercise 5: Sum of Digits

**Difficulty:** Basic

### Problem
Write a Rust program that reads a positive integer and prints the sum of its digits.

**Given Input:** `12345`

**Expected Output:**
```
Sum of digits: 15
```

### Concepts
- `while` loop
- Modulo `%` and integer division `/`
- Digit extraction

### Example / Starter Code

```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter a number: ");
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let mut n: u64 = input.trim().parse().expect("Not a number");

    let mut total = 0u64;
    while n > 0 {
        total += n % 10;
        n /= 10;
    }

    println!("Sum of digits: {}", total);
}
```
