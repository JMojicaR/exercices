## Exercise 1: Even or Odd Function
**Difficulty:** Basic
**Concepts:** Functions, return types, `%` operator, `main`, formatting.

Write a function that returns `true` if a number is even, and call it from `main`.

**Starter code:**
```rust
fn is_even(n: i32) -> bool {
    n % 2 == 0
}

fn main() {
    let numbers = [1, 2, 3, 4, 5, 6];
    for n in numbers {
        println!("{} is even: {}", n, is_even(n));
    }
}
```

**Task:** Add an `is_positive` function and print both results for each number.

## Exercise 2: Reverse a String
**Difficulty:** Basic
**Concepts:** Strings, `chars()`, `rev()`, `collect()`, iteration.

Write a program that reverses a string.

**Starter code:**
```rust
fn reverse_string(s: &str) -> String {
    s.chars().rev().collect()
}

fn main() {
    let text = "hello";
    println!("{} -> {}", text, reverse_string(text));
}
```

**Task:** Reverse a whole sentence read from stdin and print the result.

## Exercise 3: Sum of a Vec
**Difficulty:** Basic
**Concepts:** `Vec<i32>`, iterators, `sum()`, loops.

Write a program that computes the sum of a vector of integers.

**Starter code:**
```rust
fn main() {
    let numbers: Vec<i32> = vec![10, 20, 30, 40, 50];

    let sum: i32 = numbers.iter().sum();
    let average = sum as f64 / numbers.len() as f64;

    println!("Sum = {}", sum);
    println!("Average = {}", average);
}
```

**Task:** Compute the sum using a `for` loop instead of the `sum()` iterator method.

## Exercise 4: Factorial
**Difficulty:** Basic
**Concepts:** Loops, mutable variables, `u64`, ranges.

Write a program that computes `n!` using a loop.

**Starter code:**
```rust
fn factorial(n: u64) -> u64 {
    let mut result = 1;
    for i in 1..=n {
        result *= i;
    }
    result
}

fn main() {
    for n in 0..=10 {
        println!("{}! = {}", n, factorial(n));
    }
}
```

**Task:** Write a recursive version and compare results.

## Exercise 5: A Book Struct with a Method
**Difficulty:** Basic
**Concepts:** `struct`, `impl`, methods, `String`, constructing instances.

Define a `Book` struct with a method to describe the book, then create and print instances.

**Starter code:**
```rust
struct Book {
    title: String,
    author: String,
    pages: u32,
}

impl Book {
    fn describe(&self) -> String {
        format!("{} by {} ({} pages)", self.title, self.author, self.pages)
    }
}

fn main() {
    let book = Book {
        title: String::from("1984"),
        author: String::from("George Orwell"),
        pages: 328,
    };
    println!("{}", book.describe());
}
```

**Task:** Add an `is_long()` method returning `self.pages > 300` and print its result.
