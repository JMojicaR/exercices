## Exercise 3: Factorial
- **Difficulty:** Easy
- **Description:** Write a recursive function `factorial(n: u64) -> u64` that returns n!, and print `factorial(5)`.
- **Concepts:** recursion, base case, unsigned integers
- **Starter code:**
```rust
fn factorial(n: u64) -> u64 {
    if n == 0 {
        1
    } else {
        n * factorial(n - 1)
    }
}

fn main() {
    println!("{}", factorial(5)); // 120
}
```
