## Exercise 1: FizzBuzz

### Problem
Write a function that iterates from 1 to `n` and prints `"Fizz"` for multiples of 3, `"Buzz"` for multiples of 5, `"FizzBuzz"` for multiples of both, and the number otherwise.

**Given Input:** `fizzbuzz(15)`

**Expected Output (last few lines):**
```
13
14
FizzBuzz
```

### Concepts
- `for` loops with ranges (`1..=n`)
- Modulo operator (`%`)
- `if / else if / else` chains
- `println!` macro

### Example / Starter Code

```rust
fn fizzbuzz(n: u32) {
    for i in 1..=n {
        if i % 15 == 0 {
            println!("FizzBuzz");
        } else if i % 3 == 0 {
            println!("Fizz");
        } else if i % 5 == 0 {
            println!("Buzz");
        } else {
            println!("{}", i);
        }
    }
}

fn main() {
    fizzbuzz(15);
}
```

## Exercise 2: Factorial (Loop)

### Problem
Write a function that computes the factorial of a non-negative integer using a loop.

**Given Input:** `factorial(5)`

**Expected Output:**
```
120
```

### Concepts
- `for` loops
- Mutable accumulator variable (`let mut`)
- Numeric types (`u64`)

### Example / Starter Code

```rust
fn factorial(n: u64) -> u64 {
    let mut result = 1u64;
    for i in 1..=n {
        result *= i;
    }
    result
}

fn main() {
    println!("{}", factorial(5));   // 120
}
```

## Exercise 3: Sum of a Vector

### Problem
Write a function that returns the sum of all elements in a `Vec<i32>`.

**Given Input:** `sum_vec(vec![1, 2, 3, 4, 5])`

**Expected Output:**
```
15
```

### Concepts
- Iterating with `.iter()`
- Iterator consumers (`.sum()`)
- Slice vs. `Vec` references (`&[i32]`)

### Example / Starter Code

```rust
fn sum_vec(numbers: &[i32]) -> i32 {
    numbers.iter().sum()
}

fn main() {
    let nums = vec![1, 2, 3, 4, 5];
    println!("{}", sum_vec(&nums));   // 15
}
```

## Exercise 4: Reverse a String

### Problem
Write a function that reverses a string.

**Given Input:** `reverse_string("hello")`

**Expected Output:**
```
olleh
```

### Concepts
- `chars()` iterator
- `.rev()` to reverse an iterator
- `.collect::<String>()`

### Example / Starter Code

```rust
fn reverse_string(s: &str) -> String {
    s.chars().rev().collect()
}

fn main() {
    println!("{}", reverse_string("hello"));   // "olleh"
}
```

## Exercise 5: Check Palindrome

### Problem
Write a function that returns `true` if a string is a palindrome (ignoring case).

**Given Input:**
- `is_palindrome("racecar")`
- `is_palindrome("hello")`

**Expected Output:**
- `true`
- `false`

### Concepts
- `.to_lowercase()` for normalization
- Reversing strings
- Boolean return values

### Example / Starter Code

```rust
fn is_palindrome(s: &str) -> bool {
    let normalized: String = s.to_lowercase();
    let reversed: String = normalized.chars().rev().collect();
    normalized == reversed
}

fn main() {
    println!("{}", is_palindrome("racecar"));   // true
    println!("{}", is_palindrome("hello"));     // false
}
```
