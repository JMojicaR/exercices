## Exercise 1: Number Guessing Game
**Difficulty:** Basic
**Concepts:** loop, match, Result, std::io, parsing

The classic guessing game from *The Rust Programming Language*. The program generates a target number and gives "too low"/"too high" feedback.

**Starter code:**
```rust
use std::io;
use std::cmp::Ordering;

fn main() {
    let target = 42; // try rand::thread_rng().gen_range(1..=100) after adding `rand`
    loop {
        println!("Guess a number (1-100):");
        let mut guess = String::new();
        io::stdin().read_line(&mut guess).expect("Failed to read line");

        let guess: i32 = match guess.trim().parse() {
            Ok(n) => n,
            Err(_) => continue,
        };

        match guess.cmp(&target) {
            Ordering::Less => println!("Too low!"),
            Ordering::Greater => println!("Too high!"),
            Ordering::Equal => {
                println!("You guessed it!");
                break;
            }
        }
    }
}
```

**Task:** Add the `rand` crate and generate a truly random target instead of the hard-coded 42.

## Exercise 2: Sum of Natural Numbers
**Difficulty:** Basic
**Concepts:** ranges, iterator sum, integer types

Compute the sum of integers from 1 to `n` using an iterator.

**Starter code:**
```rust
fn main() {
    let n = 10;
    let sum: i32 = (1..=n).sum();
    println!("Sum from 1 to {} is {}", n, sum);
}
```

**Task:** Write the same sum with a `for` loop and an accumulator, and compare results.

## Exercise 3: Find the Smallest Element in a Vec
**Difficulty:** Basic
**Concepts:** Vec, iterators, Option, match

Find the smallest value in a vector of integers.

**Starter code:**
```rust
fn main() {
    let numbers = vec![34, 15, 88, 2, 42];
    let min = numbers.iter().min();

    match min {
        Some(m) => println!("Smallest element: {}", m),
        None => println!("The vector is empty"),
    }
}
```

**Task:** Find the smallest element with an explicit `for` loop instead of `.min()`.

## Exercise 4: Count Words in a String
**Difficulty:** Basic
**Concepts:** &str, split_whitespace, iterator count

Count the number of words in a string.

**Starter code:**
```rust
fn main() {
    let text = "The quick brown fox jumps over the lazy dog";
    let count = text.split_whitespace().count();
    println!("Number of words: {}", count);
}
```

**Task:** Write a function `word_count(text: &str) -> usize` and test it on an empty string.

## Exercise 5: Power of a Number
**Difficulty:** Basic
**Concepts:** integer methods, type annotations, u32/i64

Compute `base` raised to `exponent`.

**Starter code:**
```rust
fn main() {
    let base = 2i64;
    let exp = 10u32;
    let result = base.pow(exp);
    println!("{}^{} = {}", base, exp, result);
}
```

**Task:** Write your own `power` function using a loop, and verify it against `.pow()`.
