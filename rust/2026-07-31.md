## Exercise 1: Hello World and Variables

**Title:** Hello, Rust! — Variables and Mutability

**Description:** Write a Rust program that prints "Hello, World!" and then creates immutable and mutable variables. Show how Rust handles variable binding, type inference, and the difference between `let` and `let mut`.

**Difficulty:** ★☆☆☆☆ (Very Easy)

**Concepts Practiced:**
- `fn main()`
- `println!` macro
- `let` (immutable) vs `let mut` (mutable)
- Type inference
- String types (`&str`, `String`)

**Starter Code:**
```rust
// Exercise 1: Hello, Rust!
fn main() {
    println!("Hello, World!");

    // Immutable variable
    let name = "Alice";
    println!("Hello, {}!", name);

    // Mutable variable
    let mut age = 25;
    println!("Age: {}", age);
    age += 1;
    println!("Next year: {}", age);

    // Constants
    const CURRENT_YEAR: i32 = 2026;
    let birth_year = CURRENT_YEAR - age;
    println!("You were born around {}", birth_year);
}
```

## Exercise 2: Guessing Game

**Title:** Number Guessing Game

**Description:** Write a simple number guessing game in Rust. The program picks a random number between 1 and 100, and the user tries to guess it. After each guess, indicate if it's too high, too low, or correct.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- `use std::io;` for input
- `match` expressions
- `loop` for infinite loops
- `rand` crate (external dependency)
- Error handling with `expect()`

**Starter Code:**
```rust
// Exercise 2: Guessing Game (no external crate — manual "random")
use std::io;

fn main() {
    // For simplicity, use a fixed number (or use rand crate)
    let secret_number: u32 = 42;

    println!("I'm thinking of a number between 1 and 100.");

    loop {
        println!("Enter your guess:");

        let mut guess = String::new();
        io::stdin()
            .read_line(&mut guess)
            .expect("Failed to read line");

        let guess: u32 = match guess.trim().parse() {
            Ok(num) => num,
            Err(_) => {
                println!("Please enter a valid number!");
                continue;
            }
        };

        match guess.cmp(&secret_number) {
            std::cmp::Ordering::Less => println!("Too low!"),
            std::cmp::Ordering::Greater => println!("Too high!"),
            std::cmp::Ordering::Equal => {
                println!("You win! The number was {}.", secret_number);
                break;
            }
        }
    }
}
```

## Exercise 3: Temperature Converter

**Title:** Function-Based Temperature Converter

**Description:** Write Rust functions to convert between Celsius and Fahrenheit. The function should return the converted value. Call both functions and print results with formatted output.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Function definition with `fn`
- Parameter and return types
- Arithmetic expressions
- `f64` floating point type
- Format specifiers in `println!`

**Starter Code:**
```rust
// Exercise 3: Temperature Converter
fn celsius_to_fahrenheit(celsius: f64) -> f64 {
    (celsius * 9.0 / 5.0) + 32.0
}

fn fahrenheit_to_celsius(fahrenheit: f64) -> f64 {
    (fahrenheit - 32.0) * 5.0 / 9.0
}

fn main() {
    let temps_c = [0.0, 10.0, 20.0, 30.0, 100.0];

    println!("Celsius → Fahrenheit:");
    for &c in &temps_c {
        println!("  {:.1}°C = {:.1}°F", c, celsius_to_fahrenheit(c));
    }

    let boiling_f = 212.0;
    let freezing_f = 32.0;
    println!("\nFahrenheit → Celsius:");
    println!("  {:.1}°F = {:.1}°C", boiling_f, fahrenheit_to_celsius(boiling_f));
    println!("  {:.1}°F = {:.1}°C", freezing_f, fahrenheit_to_celsius(freezing_f));
}
```

## Exercise 4: Fibonacci Sequence

**Title:** Generate Fibonacci Numbers

**Description:** Write a Rust program that generates the Fibonacci sequence up to a specified number of terms. Use a loop (not recursion) to generate the sequence and print each term.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- `for` loops
- Tuple destructuring / variable swapping
- `u64` integer type
- Sequence generation
- Print formatting

**Starter Code:**
```rust
// Exercise 4: Fibonacci Sequence
fn main() {
    let n_terms: u32 = 15;
    let mut a: u64 = 0;
    let mut b: u64 = 1;

    println!("Fibonacci sequence ({} terms):", n_terms);

    for i in 0..n_terms {
        if i == 0 {
            print!("{}", a);
        } else if i == 1 {
            print!(", {}", b);
        } else {
            let next = a + b;
            print!(", {}", next);
            a = b;
            b = next;
        }
    }
    println!();
}
```

## Exercise 5: Ownership and Borrowing Basics

**Title:** String Ownership and References

**Description:** Write a Rust program that demonstrates Rust's ownership system. Create a function that takes ownership of a `String`, one that borrows a `&String`, and one that takes a mutable reference. Show what compiles and what doesn't.

**Difficulty:** ★★★☆☆ (Moderate)

**Concepts Practiced:**
- Ownership rules
- Borrowing (`&T`)
- Mutable references (`&mut T`)
- Move semantics
- `clone()`

**Starter Code:**
```rust
// Exercise 5: Ownership and Borrowing
fn take_ownership(s: String) {
    println!("Owned: {}", s);
    // s is dropped here
}

fn borrow(s: &String) {
    println!("Borrowed: {}", s);
    // s is still valid after this
}

fn modify(s: &mut String) {
    s.push_str(" (modified)");
}

fn main() {
    // Ownership move
    let s1 = String::from("hello");
    println!("Before move: {}", s1);
    take_ownership(s1);
    // println!("After move: {}", s1); // ERROR: s1 was moved!

    // Borrowing (immutable reference)
    let s2 = String::from("world");
    borrow(&s2);
    println!("Still valid: {}", s2); // OK: s2 was only borrowed

    // Mutable reference
    let mut s3 = String::from("rust");
    modify(&mut s3);
    println!("After modification: {}", s3);

    // Clone instead of move
    let s4 = String::from("clone me");
    let s5 = s4.clone();
    println!("Original: {}, Clone: {}", s4, s5); // Both valid
}
```
