## 1. Even or Odd Checker
**Description:** Read an integer from stdin and print whether it is even or odd using `match`.
**Difficulty:** Basic
**Concepts:** `std::io`, `read_line`, `.parse()`, `match`, modulo `%`.
**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter a number: ");
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let n: i32 = input.trim().parse().expect("Not a number");

    match n % 2 {
        0 => println!("{} is even", n),
        _ => println!("{} is odd", n),
    }
}
```

## 2. Sum from 1 to N
**Description:** Compute the sum of all integers from 1 to N using a range and the `sum()` iterator method.
**Difficulty:** Basic
**Concepts:** Ranges (`1..=n`), iterators, `.sum()`, type inference.
**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter N: ");
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let n: u32 = input.trim().parse().expect("Not a number");

    let total: u32 = (1..=n).sum();
    println!("Sum from 1 to {} is {}", n, total);
}
```

## 3. Reverse a String
**Description:** Read a string and print it reversed using the `chars()` iterator and `rev()`.
**Difficulty:** Basic
**Concepts:** `chars()`, `rev()`, `collect::<String>()`, ownership of `String`.
**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Enter a string: ");
    io::stdin().read_line(&mut input).expect("Failed to read line");

    let reversed: String = input.trim().chars().rev().collect();
    println!("Reversed: {}", reversed);
}
```

## 4. Fibonacci (First N Terms)
**Description:** Print the first N terms of the Fibonacci sequence using a loop and a `Vec`.
**Difficulty:** Basic
**Concepts:** `Vec`, `for` loop, indexing, tuple swap, mutable variables.
**Starter code:**
```rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("How many terms? ");
    io::stdin().read_line(&mut input).expect("Failed to read line");
    let n: usize = input.trim().parse().expect("Not a number");

    let mut a = 0u64;
    let mut b = 1u64;
    for _ in 0..n {
        print!("{} ", a);
        let next = a + b;
        a = b;
        b = next;
    }
    println!();
}
```

## 5. Count Vowels (Ownership & References)
**Description:** Write a function `count_vowels(text: &str) -> usize` that counts vowels, demonstrating borrowing a string without taking ownership.
**Difficulty:** Basic
**Concepts:** `&str` references, borrowing, `chars()`, `match`, `usize`.
**Starter code:**
```rust
fn count_vowels(text: &str) -> usize {
    let mut count = 0;
    for ch in text.chars() {
        match ch.to_ascii_lowercase() {
            'a' | 'e' | 'i' | 'o' | 'u' => count += 1,
            _ => {}
        }
    }
    count
}

fn main() {
    let sentence = String::from("Hello Rust");
    println!("Vowels: {}", count_vowels(&sentence));
    // sentence is still valid here (it was borrowed, not moved)
    println!("Still owned: {}", sentence);
}
```
