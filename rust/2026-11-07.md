## Exercise 1: Even or Odd Checker
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator `%`, `fn`, `println!`

Write a function that takes an integer and prints whether it is even or odd.

**Starter code:**
```rust
fn even_or_odd(n: i32) {
    if n % 2 == 0 {
        println!("{} is even", n);
    } else {
        println!("{} is odd", n);
    }
}

fn main() {
    even_or_odd(4); // 4 is even
    even_or_odd(7); // 7 is odd
}
```

**Task:** Since `if` is an expression in Rust, rewrite the function so it returns a `&str` (`"even"` or `"odd"`) directly from the `if`/`else`, then print the result in `main`.

## Exercise 2: Print Numbers 1 to N
**Difficulty:** Basic
**Concepts:** `for` loop, range `1..=n` (inclusive), loop variable, `println!`

Print every integer from 1 up to and including `N`, one per line.

**Starter code:**
```rust
fn print_range(n: u32) {
    for i in 1..=n {
        println!("{}", i);
    }
}

fn main() {
    print_range(5);
    // 1
    // 2
    // 3
    // 4
    // 5
}
```

**Task:** Modify the range to print only even numbers using `.step_by(2)`. Then print only odd numbers using `(1..=n).filter(|i| i % 2 != 0)` with a `for` loop over the iterator.

## Exercise 3: Countdown
**Difficulty:** Basic
**Concepts:** `while` loop, decrementing a counter, loop condition

Print a countdown from `N` down to 1, then print `"Liftoff!"`.

**Starter code:**
```rust
fn countdown(mut n: i32) {
    while n > 0 {
        println!("{}", n);
        n -= 1;
    }
    println!("Liftoff!");
}

fn main() {
    countdown(5);
    // 5
    // 4
    // 3
    // 2
    // 1
    // Liftoff!
}
```

**Task:** Add a guard so that `n <= 0` prints `"Nothing to count"`. Then rewrite the countdown using a `for` loop over `(1..=n).rev()` and note that it doesn't need `mut`.

## Exercise 4: Grade Classifier
**Difficulty:** Basic
**Concepts:** `match` expressions, ranges in match arms, `if`/`else`, `&str` return

Convert a numeric score (0–100) into a letter grade: 90+ → A, 80–89 → B, 70–79 → C, 60–69 → D, below 60 → F.

**Starter code:**
```rust
fn classify(score: i32) -> &'static str {
    if score >= 90 {
        "A"
    } else if score >= 80 {
        "B"
    } else if score >= 70 {
        "C"
    } else if score >= 60 {
        "D"
    } else {
        "F"
    }
}

fn main() {
    println!("{}", classify(95)); // A
    println!("{}", classify(83)); // B
    println!("{}", classify(57)); // F
}
```

**Task:** Rewrite using `match` with range arms (`90..=100 => "A"`, `80..=89 => "B"`, ...). Then add an `_ => "Invalid"` arm for scores outside 0–100.

## Exercise 5: Sum of Even Numbers up to N
**Difficulty:** Basic
**Concepts:** `for` loop + `if` condition, mutable accumulator, `+=`

Return the sum of every even number from 2 up to and including `N`.

**Starter code:**
```rust
fn sum_even(n: u32) -> u32 {
    let mut total = 0;
    for i in 1..=n {
        if i % 2 == 0 {
            total += i;
        }
    }
    total
}

fn main() {
    println!("{}", sum_even(10)); // 2 + 4 + 6 + 8 + 10 = 30
    println!("{}", sum_even(7));  // 2 + 4 + 6 = 12
}
```

**Task:** Rewrite using `(2..=n).step_by(2).sum()` — no loop, no `mut`. Then add a `sum_odd(n)` using `.filter()` and compare `sum_even(n) + sum_odd(n)` against `n*(n+1)/2` for a given `n`.
