## Exercise 1: Greeting API (query + route params)

**Difficulty:** Basic

### Problem
Build an Express app with:
1. `GET /` — returns `{"message": "Welcome"}`.
2. `GET /greet?name=<string>` — greets by query param (default `"World"`).
3. `GET /users/:id` — returns `{"userId": <id>}`.

**Example request:** `GET /greet?name=Alice`

**Expected response:** `{"message": "Hello, Alice!"}`

### Concepts
- `app.get()` with query and route params
- `req.query` and `req.params`
- `res.json()`

### HTTP Method(s)
`GET`

### Example / Starter Code

```js
const express = require("express");
const app = express();
app.use(express.json());

app.get("/", (req, res) => {
  res.json({ message: "Welcome" });
});

app.get("/greet", (req, res) => {
  const name = req.query.name || "World";
  res.json({ message: `Hello, ${name}!` });
});

app.get("/users/:id", (req, res) => {
  res.json({ userId: req.params.id });
});

app.listen(3000, () => console.log("Server on http://localhost:3000"));
```

## Exercise 2: Users CRUD (in-memory)

**Difficulty:** Basic

### Problem
Build a Users API backed by an in-memory array. Implement `GET /users`, `POST /users`, `GET /users/:id`, `PUT /users/:id`, and `DELETE /users/:id`.

**Example request:** `POST /users` with body `{"name": "Alice", "email": "alice@example.com"}`

**Expected response:** `201` → `{"id": 1, "name": "Alice", "email": "alice@example.com"}`

### Concepts
- `express.json()` body parsing
- Route params and `req.body`
- Status codes `201`, `404`

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```js
const express = require("express");
const app = express();
app.use(express.json());

let users = [];
let nextId = 1;

app.get("/users", (req, res) => res.json(users));

app.post("/users", (req, res) => {
  const user = { id: nextId++, name: req.body.name, email: req.body.email };
  users.push(user);
  res.status(201).json(user);
});

app.get("/users/:id", (req, res) => {
  const user = users.find((u) => u.id === Number(req.params.id));
  if (!user) return res.status(404).json({ error: "User not found" });
  res.json(user);
});

app.put("/users/:id", (req, res) => {
  const user = users.find((u) => u.id === Number(req.params.id));
  if (!user) return res.status(404).json({ error: "User not found" });
  user.name = req.body.name ?? user.name;
  user.email = req.body.email ?? user.email;
  res.json(user);
});

app.delete("/users/:id", (req, res) => {
  const id = Number(req.params.id);
  const user = users.find((u) => u.id === id);
  if (!user) return res.status(404).json({ error: "User not found" });
  users = users.filter((u) => u.id !== id);
  res.json({ message: "User deleted" });
});

app.listen(3000, () => console.log("Server on http://localhost:3000"));
```

## Exercise 3: Logging Middleware + 404/Error Handlers

**Difficulty:** Basic

### Problem
Add:
1. A logging middleware that prints the HTTP method and path of each request.
2. A JSON `404` handler for unknown routes.
3. A JSON error handler for `500` errors.

**Example request:** `GET /unknown`

**Expected response:** `404` → `{"error": "Not found"}`

### Concepts
- `app.use()` middleware with `next()`
- `app.use()` at the end for 404
- Four-argument error handler `(err, req, res, next)`

### HTTP Method(s)
All (wrapped by middleware)

### Example / Starter Code

```js
const express = require("express");
const app = express();
app.use(express.json());

// Logging middleware
app.use((req, res, next) => {
  console.log(`${req.method} ${req.path}`);
  next();
});

app.get("/users", (req, res) => res.json([]));

// 404 handler
app.use((req, res) => {
  res.status(404).json({ error: "Not found" });
});

// Error handler
app.use((err, req, res, next) => {
  console.error(err);
  res.status(500).json({ error: "Internal server error" });
});

app.listen(3000, () => console.log("Server on http://localhost:3000"));
```
