## Exercise 1: Hello World API Server

- **Description**: Create your first Express server. Set up a basic Node.js project with `npm init`, install Express, and create a server that listens on port 3000. Define three routes: a `GET /` route that returns `"Hello, World!"`, a `GET /about` route that returns a JSON object with your app's name and version, and a catch-all `GET *` route that returns a 404 status with a custom JSON error message `{ error: "Not found" }`. Test all routes using a browser or curl.
- **Difficulty**: Beginner
- **Concepts**: Express setup, `npm init`, `app.get()`, route parameters, `res.json()`, `res.status()`, port listening, catch-all/wildcard routes
- **Example/Starter Code**:
```js
// Run: npm init -y && npm install express
// File: server.js
const express = require('express');
const app = express();
const port = 3000;

// GET / — plain text response
app.get('/', (req, res) => {
  // Your code here
});

// GET /about — JSON response
app.get('/about', (req, res) => {
  // Your code here: return { name: "...", version: "1.0.0" }
});

// Catch-all 404 — must be defined AFTER all other routes
app.get('*', (req, res) => {
  // Your code here: status 404, JSON { error: "Not found" }
});

app.listen(port, () => {
  console.log(`Server running at http://localhost:${port}`);
});
```

## Exercise 3: Request Logging Middleware

- **Description**: Write a custom middleware function that logs every incoming request to the console. The log should include the request method, URL, and a timestamp. Then, add request timing: record the time before the request is processed and log the total time taken **after** the response is sent (use `res.on('finish', ...)`). Finally, add a condition that skips logging for any request to `/health` (a health-check endpoint you should also create, which returns `{ status: "ok" }`). This exercise teaches how middleware works, the request-response lifecycle, and how to conditionally execute middleware.
