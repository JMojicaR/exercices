## Exercise 1: Greeting API (Query & Route Params)

**Difficulty:** Basic

### Problem
Build an Express API with:
1. `GET /` — returns a welcome message.
2. `GET /greet?name=<string>` — returns a personalized greeting; default to `"World"`.

**Example request:** `GET /greet?name=Alice`

**Expected response:** `{"message": "Hello, Alice!"}`

### Concepts
- `app.get()`
- `req.query` for query parameters
- `res.json()`

### HTTP Method(s)
`GET`

### Example / Starter Code

```javascript
const express = require('express');
const app = express();
const PORT = 3000;

app.get('/', (req, res) => {
    res.json({ message: 'Welcome to the Express exercises' });
});

app.get('/greet', (req, res) => {
    const name = req.query.name || 'World';
    res.json({ message: `Hello, ${name}!` });
});

app.listen(PORT, () => console.log(`Server running on port ${PORT}`));
```

## Exercise 2: Students CRUD (in-memory)

**Difficulty:** Basic

### Problem
Build a Students API backed by an in-memory array. Implement:
1. `GET /students` — list all students.
2. `POST /students` — create a student (returns `201`).
3. `GET /students/:id` — fetch one student.
4. `PUT /students/:id` — update a student.
5. `DELETE /students/:id` — delete a student.

Return `404` for missing students.

### Concepts
- `express.json()` middleware for parsing bodies
- Route params (`:id`)
- `res.status()` for status codes
- Array `find`, `push`, `splice`

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```javascript
const express = require('express');
const app = express();
app.use(express.json());

let students = [];
let nextId = 1;

app.get('/students', (req, res) => {
    res.json(students);
});

app.post('/students', (req, res) => {
    const student = { id: nextId++, ...req.body };
    students.push(student);
    res.status(201).json(student);
});

app.get('/students/:id', (req, res) => {
    const student = students.find(s => s.id === Number(req.params.id));
    if (!student) return res.status(404).json({ error: 'Student not found' });
    res.json(student);
});

app.put('/students/:id', (req, res) => {
    const student = students.find(s => s.id === Number(req.params.id));
    if (!student) return res.status(404).json({ error: 'Student not found' });
    Object.assign(student, req.body);
    res.json(student);
});

app.delete('/students/:id', (req, res) => {
    const index = students.findIndex(s => s.id === Number(req.params.id));
    if (index === -1) return res.status(404).json({ error: 'Student not found' });
    students.splice(index, 1);
    res.json({ message: 'Student deleted' });
});

app.listen(3000, () => console.log('Server running on port 3000'));
```

## Exercise 3: Logging Middleware + 404/500 Handlers

**Difficulty:** Basic

### Problem
Add a logging middleware that prints the method and path of every request, then register a `404` catch-all handler and an error-handling middleware for `500` errors. Include a route that throws to test the error handler.

**Example request:** `GET /nonexistent`

**Expected response:** `404` → `{"error": "Not Found"}`

### Concepts
- `app.use()` for middleware
- `req.method` and `req.path`
- 4-argument error handler `(err, req, res, next)`

### HTTP Method(s)
`GET` (applies to all)

### Example / Starter Code

```javascript
const express = require('express');
const app = express();

// Logging middleware
app.use((req, res, next) => {
    console.log(`${req.method} ${req.path}`);
    next();
});

app.get('/boom', (req, res) => {
    throw new Error('Something went wrong');
});

// 404 catch-all
app.use((req, res) => {
    res.status(404).json({ error: 'Not Found' });
});

// Error-handling middleware (4 args)
app.use((err, req, res, next) => {
    console.error(err.message);
    res.status(500).json({ error: 'Internal Server Error' });
});

app.listen(3000, () => console.log('Server running on port 3000'));
```
