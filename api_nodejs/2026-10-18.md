# Node.js / Express — API Exercises (2026-10-18)
Sources: Express official docs, MDN, freeCodeCamp

Theme: **Comments API** — build a small REST API to manage blog comments.

## Exercise 1: App Setup + GET Endpoints
**Difficulty:** Basic
**Concepts:** `express()`, `app.get`, `res.json`, listening on a port

Create an Express app with a health-check route and a route that returns all comments.

**Starter code:**
```javascript
const express = require("express");
const app = express();

const comments = [
    { id: 1, postId: 101, author: "alice", text: "Great post!" },
    { id: 2, postId: 101, author: "bob", text: "Thanks for sharing." },
];

app.get("/health", (req, res) => {
    res.json({ status: "ok" });
});

app.get("/comments", (req, res) => {
    res.json(comments);
});

app.listen(3000, () => {
    console.log("Server running on http://localhost:3000");
});
```

**Task:** Add a `GET /comments/count` endpoint that returns `{ "count": comments.length }`.

## Exercise 2: POST + JSON Body + Validation
**Difficulty:** Basic
**Concepts:** `express.json()`, `app.post`, `req.body`, `201` status, validation

Add an endpoint to create a comment, parsing and validating the JSON request body.

**Starter code:**
```javascript
const express = require("express");
const app = express();
app.use(express.json());

const comments = [];
let nextId = 1;

app.post("/comments", (req, res) => {
    const { postId, author, text } = req.body;
    if (!postId || !author || !text) {
        return res.status(400).json({ error: "postId, author, and text are required" });
    }
    const comment = { id: nextId++, postId, author, text };
    comments.push(comment);
    res.status(201).json(comment);
});

app.listen(3000, () => {
    console.log("Server running on http://localhost:3000");
});
```

**Task:** Add `app.get("/comments/:id")` that returns a single comment or a 404 if not found.

## Exercise 3: PUT + DELETE + Error Middleware
**Difficulty:** Basic
**Concepts:** `app.put`, `app.delete`, route params, 404 error middleware

Add endpoints to update and delete a comment, plus a catch-all error handler.

**Starter code:**
```javascript
const express = require("express");
const app = express();
app.use(express.json());

const comments = [];

app.put("/comments/:id", (req, res) => {
    const id = Number(req.params.id);
    const comment = comments.find((c) => c.id === id);
    if (!comment) {
        return res.status(404).json({ error: "Comment not found" });
    }
    comment.text = req.body.text ?? comment.text;
    comment.author = req.body.author ?? comment.author;
    res.json(comment);
});

app.delete("/comments/:id", (req, res) => {
    const id = Number(req.params.id);
    const index = comments.findIndex((c) => c.id === id);
    if (index === -1) {
        return res.status(404).json({ error: "Comment not found" });
    }
    comments.splice(index, 1);
    res.json({ message: "Comment deleted" });
});

// Catch-all error middleware (must be registered last)
app.use((req, res) => {
    res.status(404).json({ error: "Route not found" });
});

app.listen(3000, () => {
    console.log("Server running on http://localhost:3000");
});
```

**Task:** Add an error-handling middleware with four arguments `(err, req, res, next)` that returns a 500 response, and trigger it by throwing inside a route.
