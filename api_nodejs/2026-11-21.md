## Exercise 1: POST /tasks — Create with Validation
**Difficulty:** Basic
**Concepts:** Express app, `app.post`, `express.json()` body parsing, request validation, JSON responses

Create a `POST /tasks` endpoint that reads a JSON body and enqueues a new task.

**Starter code:**
```javascript
const express = require("express");
const app = express();
app.use(express.json());

const tasks = [];   // in-memory queue
let nextId = 1;

app.post("/tasks", (req, res) => {
  const { name } = req.body;
  if (!name) {
    return res.status(400).json({ error: "name is required" });
  }
  const task = { id: nextId++, name };
  tasks.push(task);   // enqueue
  res.status(201).json(task);
});

app.listen(3000, () => console.log("listening on :3000"));
```

**Task:** Add a `priority` field that defaults to `"normal"` when missing from the request body.

## Exercise 2: GET /tasks and GET /tasks/:id — List & Find
**Difficulty:** Basic
**Concepts:** GET endpoints, route parameters (`req.params`), 404 handling, JSON responses

Add endpoints to list all tasks and to find one task by id.

**Starter code:**
```javascript
const express = require("express");
const app = express();

const tasks = [{ id: 1, name: "compile" }];

app.get("/tasks", (req, res) => {
  res.json(tasks);
});

app.get("/tasks/:id", (req, res) => {
  const id = Number(req.params.id);
  const task = tasks.find((t) => t.id === id);
  if (!task) {
    return res.status(404).json({ error: "task not found" });
  }
  res.json(task);
});

app.listen(3000, () => console.log("listening on :3000"));
```

**Task:** Add a `GET /tasks/next` endpoint that dequeues (removes and returns) the first task, returning 404 when the queue is empty.

## Exercise 3: PUT and DELETE /tasks/:id — Update, Remove, Error Middleware
**Difficulty:** Basic
**Concepts:** PUT/DELETE endpoints, route parameters, error-handling middleware, 404 fallback, basic CRUD

Add update/delete endpoints plus a 404 fallback and a JSON error-handling middleware.

**Starter code:**
```javascript
const express = require("express");
const app = express();
app.use(express.json());

let tasks = [{ id: 1, name: "compile" }];

app.put("/tasks/:id", (req, res) => {
  const id = Number(req.params.id);
  const task = tasks.find((t) => t.id === id);
  if (!task) return res.status(404).json({ error: "task not found" });
  const { name } = req.body;
  if (!name) return res.status(400).json({ error: "name is required" });
  task.name = name;
  res.json(task);
});

app.delete("/tasks/:id", (req, res) => {
  const id = Number(req.params.id);
  const before = tasks.length;
  tasks = tasks.filter((t) => t.id !== id);
  if (tasks.length === before) {
    return res.status(404).json({ error: "task not found" });
  }
  res.json({ removed: id });
});

// 404 fallback (must be registered after all routes)
app.use((req, res) => {
  res.status(404).json({ error: "route not found" });
});

// Error-handling middleware (4 args)
app.use((err, req, res, next) => {
  console.error(err.message);
  res.status(500).json({ error: "internal server error" });
});

app.listen(3000, () => console.log("listening on :3000"));
```

**Task:** Add a `DELETE /tasks` endpoint that clears the whole queue and returns `{ removed: <count> }`.
