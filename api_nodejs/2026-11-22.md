# Node.js / Express — API Exercises (2026-11-22)
Sources: Express docs, freeCodeCamp, GeeksforGeeks, DEV Community

Theme: **Notes CRUD API** — in-memory array of notes with GET (list + by id), POST with validation, PUT/DELETE, and error/404 middleware.

## Exercise 1: Read — Server Setup and GET Routes
**Difficulty:** Basic
**Concepts:** `express()`, `app.use(express.json())` middleware, `app.get`, route params, `res.json`, `app.listen`

**Starter code:**
```javascript
const express = require("express");
const app = express();
app.use(express.json());   // parse JSON request bodies

let notes = [
  { id: 1, title: "Buy milk", body: "Remember to buy milk" },
  { id: 2, title: "Call mom", body: "Call mom on Sunday" },
];

app.get("/notes", (req, res) => {
  res.json(notes);
});

app.get("/notes/:id", (req, res) => {
  const note = notes.find((n) => n.id === Number(req.params.id));
  if (!note) return res.status(404).json({ error: "Note not found" });
  res.json(note);
});

app.listen(3000, () => console.log("Server on http://localhost:3000"));
```

**Task:** Run `node app.js` and hit `GET /notes` and `GET /notes/2` with `curl`. Confirm `/notes/99` returns a 404 JSON body.

## Exercise 2: Create — POST with Validation
**Difficulty:** Basic
**Concepts:** `app.post`, reading `req.body`, validation, `201` status, id generation

**Starter code:**
```javascript
app.post("/notes", (req, res) => {
  const { title, body } = req.body;
  if (!title || !body) {
    return res.status(400).json({ error: "title and body are required" });
  }
  const id = notes.length
    ? Math.max(...notes.map((n) => n.id)) + 1
    : 1;
  const note = { id, title, body };
  notes.push(note);
  res.status(201).json(note);
});
```

**Task:** POST `{"title": "Gym", "body": "Leg day"}` and confirm a `201` with a new id. Then POST `{}` and confirm a `400` error.

## Exercise 3: Update and Delete — PUT/DELETE + Error and 404 Middleware
**Difficulty:** Basic
**Concepts:** `app.put`, `app.delete`, `splice`, fallback 404 middleware, error-handling middleware

**Starter code:**
```javascript
app.put("/notes/:id", (req, res) => {
  const note = notes.find((n) => n.id === Number(req.params.id));
  if (!note) return res.status(404).json({ error: "Note not found" });
  const { title, body } = req.body;
  if (title !== undefined) note.title = title;
  if (body !== undefined) note.body = body;
  res.json(note);
});

app.delete("/notes/:id", (req, res) => {
  const idx = notes.findIndex((n) => n.id === Number(req.params.id));
  if (idx === -1) return res.status(404).json({ error: "Note not found" });
  const [removed] = notes.splice(idx, 1);
  res.json({ deleted: removed });
});

// 404 fallback for unknown routes
app.use((req, res) => res.status(404).json({ error: "Route not found" }));

// central error handler (4-argument signature)
app.use((err, req, res, next) => {
  console.error(err);
  res.status(500).json({ error: "Internal server error" });
});
```

**Task:** PUT note `1` with a new title, then DELETE it, then GET `/notes/1` and confirm 404. Also hit an unknown route like `/foo` and confirm the fallback 404 JSON.
