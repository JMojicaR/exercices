## Exercise 1: GET with Route and Query Parameters
- **Difficulty:** Easy
- **Description:** Create an Express app with `GET /` returning a JSON welcome message, a `GET /greet/:name` route parameter endpoint, and a `GET /add?a=&b=` query-parameter endpoint that returns the sum.
- **Concepts:** `express()`, route handlers, `req.params`, `req.query`, `res.json()`
- **Starter code:**
```javascript
const express = require("express");
const app = express();

app.get("/", (req, res) => {
  res.json({ message: "Welcome!" });
});

app.get("/greet/:name", (req, res) => {
  res.json({ message: `Hello, ${req.params.name}!` });
});

app.get("/add", (req, res) => {
  const a = Number(req.query.a);
  const b = Number(req.query.b);

```
