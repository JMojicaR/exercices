# Node.js / Express — Basic API Exercises

Date: 2026-09-11 | Level: Beginner | Sources: Express docs, MDN, freeCodeCamp (adapted)

## Exercise 1: Hello, World! GET Endpoint
- **Difficulty:** Easy
- **Description:** Create an Express server with `GET /` returning a JSON greeting and `GET /hello/:name` returning a personalized greeting.
- **Concepts:** `require("express")`, `app.get`, route params (`req.params`), `res.json`
- **Starter code:**
```javascript
const express = require("express");
const app = express();
const PORT = 3000;

app.get("/", (req, res) => {
  res.json({ message: "Hello, World!" });
});

app.get("/hello/:name", (req, res) => {
  // TODO: return a personalized greeting
  res.json({});
});

app.listen(PORT, () => console.log(`Listening on http://localhost:${PORT}`));
```
