## Exercise 1: Greeting API

**Difficulty:** Basic

### Problem
Build an Express API with two greeting endpoints:
1. `GET /greet?name=<string>` — returns a greeting using the query parameter.
2. `GET /greet/:name` — returns a greeting using the route parameter.

Default to `"World"` when no query name is provided.

**Example request:** `GET /greet?name=Alice`

**Expected response:** `{"message": "Hello, Alice!"}`

### Concepts
- `app.get()` routes
- `req.query` and `req.params`
- `res.json()`

### HTTP Method(s)
`GET`

### Example / Starter Code

```javascript
const express = require('express');
const app = express();
const port = 3000;

app.get('/greet', (req, res) => {
  const name = req.query.name || 'World';
  res.json({ message: `Hello, ${name}!` });
});

app.get('/greet/:name', (req, res) => {
  res.json({ message: `Hello, ${req.params.name}!` });
});

app.listen(port, () => {
  console.log(`API listening on http://localhost:${port}`);
});
```

## Exercise 2: Tasks CRUD (in-memory)

**Difficulty:** Basic

### Problem
Build a Tasks API backed by an in-memory array. Implement:
1. `GET /tasks` — list all tasks.
2. `POST /tasks` — create a task from JSON `{"title": ...}`.
3. `GET /tasks/:id` — fetch one task.
4. `PUT /tasks/:id` — update a task.
5. `DELETE /tasks/:id` — delete a task.

Return `201` on create and `404` for missing tasks.

### Concepts
- `express.json()` body parsing
- `req.params` and `req.body`
- Array methods (`find`, `filter`, `push`)
- Status codes (`res.status(...).json(...)`)

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```javascript
const express = require('express');
const app = express();
app.use(express.json());

let tasks = [];
let nextId = 1;

app.get('/tasks', (req, res) => res.json(tasks));

app.post('/tasks', (req, res) => {
  const task = { id: nextId++, title: req.body.title, done: false };
  tasks.push(task);
  res.status(201).json(task);
});

app.get('/tasks/:id', (req, res) => {
  const task = tasks.find(t => t.id === parseInt(req.params.id));
  if (!task) return res.status(404).json({ error: 'Task not found' });
  res.json(task);
});

app.put('/tasks/:id', (req, res) => {
  const task = tasks.find(t => t.id === parseInt(req.params.id));
  if (!task) return res.status(404).json({ error: 'Task not found' });
  task.title = req.body.title ?? task.title;
  task.done = req.body.done ?? task.done;
  res.json(task);
});

app.delete('/tasks/:id', (req, res) => {
  const id = parseInt(req.params.id);
  tasks = tasks.filter(t => t.id !== id);
  res.json({ message: 'Task deleted' });
});

app.listen(3000, () => console.log('API on http://localhost:3000'));
```

## Exercise 3: Logging Middleware + 404 & Error Handlers

**Difficulty:** Basic

### Problem
Add a logging middleware that prints every request's method and path, a JSON 404 handler for unmatched routes, and a central error-handling middleware that returns a JSON 500 response.

### Concepts
- `app.use()` middleware ordering
- 404 catch-all handler
- Error-handling middleware signature (`err, req, res, next`)

### HTTP Method(s)
`GET` (any)

### Example / Starter Code

```javascript
const express = require('express');
const app = express();
app.use(express.json());

// Logging middleware
app.use((req, res, next) => {
  console.log(`${req.method} ${req.path}`);
  next();
});

app.get('/', (req, res) => res.json({ message: 'API is running' }));

// 404 handler (must be after all routes)
app.use((req, res) => {
  res.status(404).json({ error: 'Not found' });
});

// Central error handler (4 args is required)
app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).json({ error: 'Internal server error' });
});

app.listen(3000, () => console.log('API on http://localhost:3000'));
```
