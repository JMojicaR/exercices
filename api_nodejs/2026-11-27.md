## Exercise 1: Basic GET Endpoints
**Difficulty:** Basic
**Concepts:** Express app, routes, `res.json`, route parameters

**Starter code:**
```javascript
const express = require("express");
const app = express();
const PORT = 3000;

app.get("/", (req, res) => {
  res.json({ message: "Flights API is running" });
});

app.get("/flights/:id", (req, res) => {
  res.json({ flight_id: Number(req.params.id) });
});

app.listen(PORT, () => console.log(`Listening on ${PORT}`));
```

**Task:** Add a `GET /health` endpoint returning `{ "status": "ok" }` and a `GET /flights` endpoint returning a static array of two flights (each with `id`, `airline`, `origin`, `destination`, `price`).

## Exercise 2: Full CRUD with an In-Memory Array
**Difficulty:** Basic
**Concepts:** `express.json()` middleware, `req.body`, GET/POST/PUT/DELETE, status codes

**Starter code:**
```javascript
const express = require("express");
const app = express();
app.use(express.json());

let flights = [
  { id: 1, airline: "AeroMex", origin: "MEX", destination: "CUN", price: 1200 },
];

app.get("/flights", (req, res) => {
  res.json(flights);
});

app.get("/flights/:id", (req, res) => {
  const flight = flights.find((f) => f.id === Number(req.params.id));
  if (!flight) return res.status(404).json({ error: "not found" });
  res.json(flight);
});

app.post("/flights", (req, res) => {
  const newId = Math.max(...flights.map((f) => f.id)) + 1;
  const flight = { id: newId, ...req.body };
  flights.push(flight);
  res.status(201).json(flight);
});
```

**Task:** Add `PUT /flights/:id` (update `airline`, `origin`, `destination`, `price`) and `DELETE /flights/:id` (return `204` on success). Return `404` when the id does not exist.

## Exercise 3: Middleware and Error Handling
**Difficulty:** Basic
**Concepts:** custom middleware, `next()`, error-handling middleware (`err, req, res, next`)

**Starter code:**
```javascript
// Logging middleware
app.use((req, res, next) => {
  console.log(`${req.method} ${req.path}`);
  next();
});

app.post("/flights", (req, res) => {
  const required = ["airline", "origin", "destination", "price"];
  const missing = required.filter((field) => req.body[field] === undefined);
  if (missing.length > 0) {
    return res.status(400).json({ error: "missing fields", fields: missing });
  }
  const newId = Math.max(...flights.map((f) => f.id)) + 1;
  const flight = { id: newId, ...req.body };
  flights.push(flight);
  res.status(201).json(flight);
});

// 404 catch-all
app.use((req, res) => {
  res.status(404).json({ error: "resource not found" });
});

// Error-handling middleware (4 args)
app.use((err, req, res, next) => {
  console.error(err.message);
  res.status(500).json({ error: "internal server error" });
});
```

**Task:** Extract the missing-field validation into a reusable `validateFlight` middleware that sets `res.locals.flight` or returns `400`, and use it on both `POST /flights` and `PUT /flights/:id`.
