## Exercise 1: GET Routes with Query Parameters
- **Difficulty:** Easy
- **Description:** Create an Express server with a GET `/` route and a `/greet` route that reads a `name` query parameter (defaulting to `"World"`). Respond with JSON.
- **Concepts:** `express()`, `app.get`, `req.query`, `res.json`, `app.listen`
- **Starter code:**
```javascript
const express = require('express');
const app = express();
const PORT = 3000;

app.get('/', (req, res) => {
  res.json({ message: 'Welcome to the Express API' });
});

app.get('/greet', (req, res) => {
  const name = req.query.name || 'World';

});

app.listen(PORT, () => console.log(`Listening on http://localhost:${PORT}`));
```

## Exercise 3: In-Memory Todo CRUD API
- **Difficulty:** Easy
- **Description:** Build a full CRUD API for todos stored in an array. Implement GET (list all), GET by id, POST (add), PUT (update), and DELETE (remove). Return 404 with `{ error: 'Todo not found' }` when an id is missing.
- **Concepts:** CRUD, array storage, `req.params`, HTTP methods, `res.status()`, 404 handling
- **Starter code:**
```javascript
const express = require('express');
const app = express();
app.use(express.json());

let todos = [];
let nextId = 1;

app.get('/todos', (req, res) => res.json(todos));

app.post('/todos', (req, res) => {
  const todo = { id: nextId++, title: req.body.title, done: false };
  todos.push(todo);
  res.status(201).json(todo);
});

```
