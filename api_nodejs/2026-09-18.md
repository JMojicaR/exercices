- **Difficulty:** Easy

```javascript

const PORT = 3000;

  const name = req.query.name || 'world';

});
```

## Exercise 3: In-Memory Users CRUD with Error-Handling Middleware
- **Difficulty:** Easy
- **Description:** Build a full CRUD API for users stored in an in-memory array. Implement GET (list), GET by id, POST (create), PUT (update), and DELETE (remove). Add a 404 handler for missing users and a final error-handling middleware.
- **Concepts:** CRUD, in-memory storage, route parameters, error-handling middleware, status codes
- **Starter code:**
```javascript
const express = require('express');
const app = express();
const PORT = 3000;

app.use(express.json());

let users = [];
let nextId = 1;

app.get('/api/users', (req, res) => {
  res.json(users);
});

app.post('/api/users', (req, res) => {
  const user = { id: nextId++, ...req.body };
  users.push(user);
  res.status(201).json(user);
});
```
