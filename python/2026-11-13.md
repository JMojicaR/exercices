## Exercise 1: Write Text to a File
**Difficulty:** Basic
**Concepts:** `open()` with `"w"` mode, `.write()`, `with` statement (context manager)

Write a program that creates a file named `notes.txt` and writes two lines of text into it. Opening a file with mode `"w"` creates it if it doesn't exist and overwrites it if it does.

**Starter code:**
```python
with open("notes.txt", "w") as f:
    f.write("First line\n")
    f.write("Second line\n")

print("File written.")
```

**Task:** Write the same lines using `f.writelines(["a\n", "b\n", "c\n"])`, then confirm the file's contents using `open("notes.txt").read()`.

## Exercise 2: Read an Entire File
**Difficulty:** Basic
**Concepts:** `open()` with `"r"` mode, `.read()`, `.readline()`, `.readlines()`

Write a program that reads the whole contents of `notes.txt` and prints it.

**Starter code:**
```python
with open("notes.txt", "r") as f:
    content = f.read()

print(content)
```

**Task:** Print the file using a `for line in f:` loop instead of `.read()`, and observe how the newlines behave. Then try `f.readlines()` and print the resulting list.

## Exercise 3: Append a Line to a File
**Difficulty:** Basic

## Exercise 4: Count Lines and Words
**Difficulty:** Basic
**Concepts:** reading line-by-line, `str.split()`, `len()`, counters

Write a program that opens `notes.txt` and reports how many lines it has and how many words (space-separated tokens) it contains in total.

**Starter code:**
```python
line_count = 0
word_count = 0

with open("notes.txt", "r") as f:
    for line in f:
        line_count += 1
        word_count += len(line.split())

print(f"Lines: {line_count}")
print(f"Words: {word_count}")
```

**Task:** Also count characters (excluding newlines) with `len(line.rstrip("\n"))`. Then count how many lines contain the word "the" (case-insensitive).

## Exercise 5: Copy a File
**Difficulty:** Basic
**Concepts:** reading from one file and writing to another, opening two files at once

Write a program that copies the contents of `notes.txt` into a new file named `notes_copy.txt`.

**Starter code:**
```python
with open("notes.txt", "r") as source, open("notes_copy.txt", "w") as target:
    target.write(source.read())

print("Copied.")
```

**Task:** Copy line-by-line instead of all at once, and print each line as it is copied. Then check whether `notes_copy.txt` already exists with `os.path.exists()` before overwriting it.
