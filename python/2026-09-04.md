## Exercise 1: Bubble Sort

**Difficulty:** Basic

### Problem
Write a function that sorts a list of integers in ascending order using the bubble sort algorithm (repeatedly swap adjacent elements that are out of order).

**Given Input:** `[64, 34, 25, 12, 22, 11, 90]`

**Expected Output:**
```
Sorted: [11, 12, 22, 25, 34, 64, 90]
```

### Concepts
- Nested `for` loops
- Adjacent element comparison and swap
- In-place list mutation

### Example / Starter Code

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        for j in range(n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

nums = [64, 34, 25, 12, 22, 11, 90]
print("Sorted:", bubble_sort(nums))
```

## Exercise 2: Linear Search

**Difficulty:** Basic

### Problem
Write a function that searches a list for a target value and returns its index, or `-1` if it is not present.

**Given Input:** list `[10, 23, 45, 70, 11, 15]`, target `70`

**Expected Output:**
```
70 found at index 3
```

### Concepts
- `for` loop with `enumerate()`
- Early return / `break`
- Return `-1` sentinel for "not found"

### Example / Starter Code

```python
def linear_search(arr, target):
    for i, value in enumerate(arr):
        if value == target:
            return i
    return -1

nums = [10, 23, 45, 70, 11, 15]
index = linear_search(nums, 70)
print(f"70 found at index {index}" if index != -1 else "70 not found")
```

## Exercise 3: Anagram Check

**Difficulty:** Basic

### Problem
Write a function that checks whether two strings are anagrams (they contain the same letters, ignoring case and order).

**Given Input:** `"listen"`, `"silent"`

**Expected Output:**
```
Anagram
```

### Concepts
- `str.lower()` case normalization
- `sorted()` on strings
- String comparison

### Example / Starter Code

```python
def is_anagram(s1, s2):
    return sorted(s1.lower()) == sorted(s2.lower())

print("Anagram" if is_anagram("listen", "silent") else "Not an anagram")
```

## Exercise 4: Greatest Common Divisor (GCD)

**Difficulty:** Basic

### Problem
Write a function that computes the greatest common divisor of two positive integers using the Euclidean algorithm.

**Given Input:** `48`, `18`

**Expected Output:**
```
GCD: 6
```

### Concepts
- `while` loop
- Modulo operator `%`
- Repeated assignment (Euclidean algorithm)

### Example / Starter Code

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

print("GCD:", gcd(48, 18))
```

## Exercise 5: Armstrong Number Check

**Difficulty:** Basic

### Problem
Write a function that checks whether a number is an Armstrong number: a number equal to the sum of its own digits each raised to the power of the number of digits.

**Given Input:** `153`

**Expected Output:**
```
Armstrong
```

### Concepts
- `str()` conversion and `len()`
- List comprehension with `**`
- `sum()` aggregation

### Example / Starter Code

```python
def is_armstrong(n):
    digits = str(n)
    power = len(digits)
    total = sum(int(d) ** power for d in digits)
    return total == n

print("Armstrong" if is_armstrong(153) else "Not Armstrong")
```
