## Exercise 1: Simple Calculator
**Difficulty:** Basic
**Concepts:** Variables, `input()`, type conversion (`float()`), conditionals, arithmetic operators.

Write a program that reads two numbers and an operator (`+`, `-`, `*`, `/`) and prints the result of the operation.

**Starter code:**
```python
a = float(input("Enter first number: "))
b = float(input("Enter second number: "))
op = input("Enter operator (+, -, *, /): ")

if op == "+":
    print(a + b)
elif op == "-":
    print(a - b)
elif op == "*":
    print(a * b)
elif op == "/":
    print(a / b)
else:
    print("Unknown operator")
```

**Task:** Add `%` (modulo) and `**` (power) operators, and handle division by zero gracefully.

## Exercise 2: Sum of Natural Numbers
**Difficulty:** Basic
**Concepts:** Loops, `range()`, the built-in `sum()`, integer input.

Write a program that reads a positive integer `n` and prints the sum of all natural numbers from 1 to `n`.

**Starter code:**
```python
n = int(input("Enter n: "))

total = sum(range(1, n + 1))
print("Sum 1..", n, "=", total)
```

**Task:** Reimplement the sum using a `for` loop (without `sum()`) and confirm both give the same result.

## Exercise 3: Factorial
**Difficulty:** Basic
**Concepts:** Loops (`for`), accumulator variables, integer overflow awareness.

Write a program that reads a non-negative integer and prints its factorial (`n! = 1 × 2 × … × n`, with `0! = 1`).

**Starter code:**
```python
n = int(input("Enter a number: "))

fact = 1
for i in range(1, n + 1):
    fact *= i

print(f"{n}! = {fact}")
```

**Task:** Rewrite it recursively with a `factorial(n)` function, then compare outputs for `n = 0` and `n = 5`.

## Exercise 4: Palindrome Checker
**Difficulty:** Basic
**Concepts:** String slicing (`[::-1]`), `lower()`, string methods, conditionals.

Write a program that checks whether a given string reads the same forwards and backwards (ignoring case).

**Starter code:**
```python
text = input("Enter a string: ").lower()

if text == text[::-1]:
    print("Palindrome")
else:
    print("Not a palindrome")
```

**Task:** Ignore spaces and punctuation too (e.g. "A man, a plan, a canal: Panama" should be a palindrome).

## Exercise 5: Reverse a String
**Difficulty:** Basic
**Concepts:** String slicing, indexing, iteration.

Write a program that reads a string and prints it reversed.

**Starter code:**
```python
text = input("Enter a string: ")

print("Reversed:", text[::-1])
```

**Task:** Reverse the string character-by-character using a `for` loop instead of slicing.
