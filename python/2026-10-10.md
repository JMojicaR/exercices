## Exercise 1: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** loops, lists, variable swapping

Print the first `n` numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...), where each number is the sum of the two before it.

**Starter code:**
```python
n = int(input("How many Fibonacci numbers? "))
a, b = 0, 1
sequence = []
for _ in range(n):
    sequence.append(a)
    a, b = b, a + b
print(sequence)
```

**Task:** Modify it to print only the Fibonacci numbers that are less than or equal to a user-specified limit.

## Exercise 2: Sum of Digits
**Difficulty:** Basic
**Concepts:** while loop, modulo, integer division

Read a positive integer and print the sum of its digits. For example, 1234 → 10.

**Starter code:**
```python
n = int(input("Enter a positive integer: "))
total = 0
while n > 0:
    total += n % 10
    n //= 10
print("Sum of digits:", total)
```

**Task:** Also count how many digits the number has and print the product of its digits.

## Exercise 3: Greatest Common Divisor (GCD)
**Difficulty:** Basic
**Concepts:** Euclidean algorithm, while loop, remainder

Compute the greatest common divisor of two positive integers using the Euclidean algorithm.

**Starter code:**
```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
while b != 0:
    a, b = b, a % b
print("GCD:", a)
```

**Task:** Write the same algorithm as a recursive function and test it with several pairs.

## Exercise 4: FizzBuzz
**Difficulty:** Basic
**Concepts:** for loop, range, modulo, conditional logic

Print the numbers from 1 to a given `n`. For multiples of 3 print "Fizz", for multiples of 5 print "Buzz", and for multiples of both print "FizzBuzz".

**Starter code:**
```python
n = int(input("Enter a number: "))
for i in range(1, n + 1):
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
```

**Task:** Let the user choose custom "Fizz" and "Buzz" numbers instead of hard-coding 3 and 5.

## Exercise 5: Leap Year Check
**Difficulty:** Basic
**Concepts:** conditionals, modulo, boolean logic

Read a year and print whether it is a leap year. A year is a leap year if it is divisible by 4, except years divisible by 100, unless they are also divisible by 400.

**Starter code:**
```python
year = int(input("Enter a year: "))
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(year, "is a leap year")
else:
    print(year, "is not a leap year")
```

**Task:** Print all leap years between two given years.
