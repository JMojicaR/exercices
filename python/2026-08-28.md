## Exercise 1: Hello World & Variables

**Difficulty:** Basic

### Problem
Write a program that prints "Hello, World!" and then prints the value of three variables: an integer `age = 25`, a float `height = 1.75`, and a string `name = "Alice"`. Use an f-string to combine them into a single sentence.

**Given Input:** (none — variables are hard-coded)

**Expected Output:**
```
Hello, World!
Alice is 25 years old and 1.75 meters tall.
```

### Concepts
- `print()` function
- Variables and basic data types (`int`, `float`, `str`)
- f-strings for string formatting

### Example / Starter Code

```python
age = 25
height = 1.75
name = "Alice"

print("Hello, World!")
print(f"{name} is {age} years old and {height} meters tall.")
```

## Exercise 2: Even or Odd

**Difficulty:** Basic

### Problem
Write a program that asks the user for an integer and prints whether it is "Even" or "Odd" using the modulo operator `%`.

**Given Input:** `7`

**Expected Output:**
```
Enter a number: 7
7 is Odd
```

### Concepts
- `input()` and `int()` type conversion
- `if`/`else` conditional
- Modulo operator `%`

### Example / Starter Code

```python
number = int(input("Enter a number: "))

if number % 2 == 0:
    print(f"{number} is Even")
else:
    print(f"{number} is Odd")
```

## Exercise 3: Sum of Numbers 1 to N

**Difficulty:** Basic

### Problem
Write a program that takes a positive integer `n` and prints the sum of all integers from 1 to `n` using a `for` loop.

**Given Input:** `10`

**Expected Output:**
```
Sum from 1 to 10 is 55
```

### Concepts
- `for` loop with `range()`
- Accumulator variable

### Example / Starter Code

```python
n = int(input("Enter a positive integer: "))

total = 0
for i in range(1, n + 1):
    total += i

print(f"Sum from 1 to {n} is {total}")
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a program that counts how many vowels (a, e, i, o, u) appear in a given string (case-insensitive).

**Given Input:** `"Hello World"`

**Expected Output:**
```
Number of vowels: 3
```

### Concepts
- Iterating over a string with `for`
- `in` membership operator
- `.lower()` string method

### Example / Starter Code

```python
text = input("Enter a string: ").lower()
vowels = "aeiou"
count = 0

for char in text:
    if char in vowels:
        count += 1

print("Number of vowels:", count)
```

## Exercise 5: Find Max & Min in a List

**Difficulty:** Basic

### Problem
Given a list of numbers, find and print the maximum and minimum values. First use the built-in `max()`/`min()`, then write a loop-based version.

**Given Input:** `[12, 5, 8, 130, 44]`

**Expected Output:**
```
Max: 130, Min: 5
```

### Concepts
- Python lists
- Built-in `max()` and `min()`
- Loop-based min/max with a variable

### Example / Starter Code

```python
numbers = [12, 5, 8, 130, 44]

print("Max:", max(numbers), "Min:", min(numbers))

# Loop-based version
maximum = numbers[0]
minimum = numbers[0]
for num in numbers:
    if num > maximum:
        maximum = num
    if num < minimum:
        minimum = num

print("Max:", maximum, "Min:", minimum)
```
