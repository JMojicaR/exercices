## Exercise 1: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a program that reads a non-negative integer `n` and prints its factorial (`n! = 1 × 2 × … × n`). Factorial of 0 is 1.

**Given Input:** `5`

**Expected Output:**
```
Factorial of 5 is 120
```

### Concepts
- `for` loop accumulator
- `input()` and `int()` conversion
- Handling the `0!` edge case

### Example / Starter Code

```python
n = int(input("Enter a number: "))

factorial = 1
for i in range(1, n + 1):
    factorial *= i

print(f"Factorial of {n} is {factorial}")
```

## Exercise 2: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a program that reads an integer `n` and prints the first `n` terms of the Fibonacci sequence (`0, 1, 1, 2, 3, 5, 8, …`), each on a new line.

**Given Input:** `7`

**Expected Output:**
```
0
1
1
2
3
5
8
```

### Concepts
- Multiple variable assignment (`a, b = b, a + b`)
- `for` loop with `range()`
- Sequence generation

### Example / Starter Code

```python
n = int(input("How many terms? "))

a, b = 0, 1
for _ in range(n):
    print(a)
    a, b = b, a + b
```

## Exercise 3: Palindrome Check

**Difficulty:** Basic

### Problem
Write a program that reads a string and checks whether it is a palindrome (reads the same forwards and backwards, ignoring letter case).

**Given Input:** `Racecar`

**Expected Output:**
```
Racecar is a palindrome
```

### Concepts
- String slicing with negative step (`[::-1]`)
- Case normalization (`.lower()`)
- `if`/`else` comparison

### Example / Starter Code

```python
text = input("Enter a string: ").lower()

if text == text[::-1]:
    print(f"{text} is a palindrome")
else:
    print(f"{text} is not a palindrome")
```

## Exercise 4: Prime Number Check

**Difficulty:** Basic

### Problem
Write a program that reads a positive integer and determines whether it is a prime number (a number greater than 1 divisible only by 1 and itself).

**Given Input:** `29`

**Expected Output:**
```
29 is a prime number
```

### Concepts
- `for` loop with `range()` and `break`
- Modulo operator `%`
- Early-exit optimization (check divisors up to `√n`)

### Example / Starter Code

```python
n = int(input("Enter a number: "))

if n <= 1:
    is_prime = False
else:
    is_prime = True
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            is_prime = False
            break

if is_prime:
    print(f"{n} is a prime number")
else:
    print(f"{n} is not a prime number")
```

## Exercise 5: Sum of Digits

**Difficulty:** Basic

### Problem
Write a program that reads a positive integer and prints the sum of its digits.

**Given Input:** `12345`

**Expected Output:**
```
Sum of digits: 15
```

### Concepts
- `while` loop
- Modulo `%` and integer division `//`
- Digit extraction

### Example / Starter Code

```python
n = int(input("Enter a number: "))

total = 0
while n > 0:
    total += n % 10
    n //= 10

print("Sum of digits:", total)
```
