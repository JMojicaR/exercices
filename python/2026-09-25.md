## Exercise 1: Hello, Name!
**Difficulty:** Basic
**Concepts:** `print()`, `input()`, variables, string formatting.

Write a program that asks the user for their name and greets them.

**Starter code:**
```python
name = input("What is your name? ")
print("Hello, " + name + "! Welcome to Python.")
```

**Task:** Extend it to also ask for the user's age and print a message that includes both.

## Exercise 3: Even or Odd
**Difficulty:** Basic
**Concepts:** Conditionals (`if`/`else`), modulo operator (`%`).

Write a program that reads an integer and tells the user whether it is even or odd.

**Starter code:**
```python
num = int(input("Enter an integer: "))

if num % 2 == 0:
    print("Even")
else:
    print("Odd")
```

**Task:** Also handle negative numbers and zero correctly.

## Exercise 4: Sum of 1 to N
**Difficulty:** Basic
**Concepts:** Loops (`for` and `while`), range, accumulator variables.

Write a program that computes the sum of all integers from 1 to N (inclusive).

**Starter code:**
```python
n = int(input("Enter N: "))
total = 0

for i in range(1, n + 1):
    total += i

print("Sum:", total)
```

**Task:** Reimplement it using a `while` loop, then verify both give the same answer.
