## Exercise 1: Print a Right-Angled Triangle of Stars
**Difficulty:** Basic
**Concepts:** nested `for` loops, `range()`, string repetition

Print a right-angled triangle of `*` where the number of rows is user-supplied.

**Starter code:**
```python
rows = int(input("Enter number of rows: "))

for i in range(1, rows + 1):
    print("*" * i)
```

**Task:** Print an inverted triangle instead, and then print numbers (`1`, `22`, `333`, …) using a nested loop rather than string repetition.

## Exercise 2: Print Floyd's Triangle
**Difficulty:** Basic
**Concepts:** nested loops, running counter, `print(..., end=...)`

Print Floyd's triangle — consecutive numbers arranged in rows of increasing length.

**Starter code:**
```python
rows = int(input("Enter number of rows: "))
num = 1

for i in range(1, rows + 1):
    for j in range(i):
        print(num, end=" ")
        num += 1
    print()
```

**Task:** Right-align the triangle (pad each row with spaces first) and start the counter at a user-supplied value.

## Exercise 3: Count Uppercase and Lowercase Letters
**Difficulty:** Basic
**Concepts:** string iteration, `isupper()` / `islower()`, counters

Count how many uppercase and lowercase letters a string contains.

**Starter code:**
```python
text = input("Enter a string: ")
upper = 0
lower = 0

for ch in text:
    if ch.isupper():
        upper += 1
    elif ch.islower():
        lower += 1

print("Uppercase:", upper, "Lowercase:", lower)
```

**Task:** Also count digits (`isdigit()`) and spaces (`isspace()`), and print a full breakdown.

## Exercise 4: Remove All Spaces from a String
**Difficulty:** Basic
**Concepts:** string building, character filtering, `replace()`

Remove every space from an input string and print the result.

**Starter code:**
```python
text = input("Enter a string: ")
no_spaces = ""

for ch in text:
    if ch != " ":
        no_spaces += ch

print("Without spaces:", no_spaces)
```

**Task:** Rewrite using `text.replace(" ", "")`, then remove tabs and newlines too (use `isspace()`).

## Exercise 5: Find the Largest Digit in a Number
**Difficulty:** Basic
**Concepts:** `%` and `//`, `while` loop, max tracking

Read a whole number and print its largest single digit.

**Starter code:**
```python
num = int(input("Enter a number: "))
largest = 0

while num > 0:
    digit = num % 10
    if digit > largest:
        largest = digit
    num //= 10

print("Largest digit:", largest)
```

**Task:** Also find the smallest digit, and make the code handle negative input correctly (work with the absolute value).
