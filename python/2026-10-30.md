## Exercise 1: Linear Search
**Difficulty:** Basic
**Concepts:** `for` loop, `range()`, list indexing, comparison, early `return`

Write a function that searches for a target value in a list and returns its index, or `-1` if it is not found.

**Starter code:**
```python
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1

numbers = [10, 23, 45, 70, 11, 15]
print(linear_search(numbers, 70))  # expected: 3
print(linear_search(numbers, 99))  # expected: -1
```

**Task:** Modify the function to also return how many comparisons it made before finding (or missing) the target.

## Exercise 2: Binary Search
**Difficulty:** Basic
**Concepts:** `while` loop, integer division `//`, midpoint index, sorted input

Search for a target in a *sorted* list using binary search, halving the search range each step.

**Starter code:**
```python
def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

sorted_nums = [1, 3, 5, 7, 9, 11, 13]
print(binary_search(sorted_nums, 9))   # expected: 4
print(binary_search(sorted_nums, 4))   # expected: -1
```

**Task:** Add a counter so the function returns the number of loop iterations performed.

## Exercise 3: Bubble Sort
**Difficulty:** Basic
**Concepts:** nested `for` loops, swapping via tuple assignment, comparison operators

Sort a list in ascending order using bubble sort (repeatedly swap adjacent out-of-order elements).

**Starter code:**
```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

data = [64, 34, 25, 12, 22, 11, 90]
print(bubble_sort(data))  # expected: [11, 12, 22, 25, 34, 64, 90]
```

**Task:** Add an "early exit" that stops early when a full pass makes no swaps (list already sorted).

## Exercise 4: Find Minimum and Maximum
**Difficulty:** Basic
**Concepts:** iteration, comparison, tracking state variables, empty-list edge case

Find and return the smallest and largest values in a list in a single pass.

**Starter code:**
```python
def find_min_max(arr):
    if not arr:
        return None, None
    minimum = maximum = arr[0]
    for val in arr:
        if val < minimum:
            minimum = val
        if val > maximum:
            maximum = val
    return minimum, maximum

nums = [45, 2, 78, 13, 9, 54]
low, high = find_min_max(nums)
print("Min:", low, "Max:", high)  # Min: 2 Max: 78
```

**Task:** Return the *indices* of the min and max elements as well as their values.

## Exercise 5: Selection Sort
**Difficulty:** Basic
**Concepts:** nested loops, index tracking, swapping, finding the minimum in a sub-range

Sort a list using selection sort: repeatedly find the smallest remaining element and move it to the front.

**Starter code:**
```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

data = [29, 10, 14, 37, 13]
print(selection_sort(data))  # expected: [10, 13, 14, 29, 37]
```

**Task:** Sort in *descending* order by changing a single comparison operator.
