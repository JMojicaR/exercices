## Exercise 1: Define a Node and Build a Linked List
**Difficulty:** Basic
**Concepts:** class with `__init__`, object references, `while`-loop traversal

A linked list is a chain of nodes. Each node holds a value and a reference to the next node (`None` marks the end).

**Starter code:**
```python
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

# Build the list 10 -> 20 -> 30 by hand
head = Node(10)
head.next = Node(20)
head.next.next = Node(30)

current = head
while current is not None:
    print(current.value, end=" ")
    current = current.next
# prints: 10 20 30
```

**Task:** Write a function `print_list(head)` that prints every value separated by `" -> "` and ends with `"None"` (e.g. `10 -> 20 -> 30 -> None`).

## Exercise 2: Append a Node to the End
**Difficulty:** Basic
**Concepts:** walking to the last node, edge case of an empty list (`None` head)

**Starter code:**
```python
def append(head, value):
    if head is None:
        return Node(value)
    current = head
    while current.next is not None:
        current = current.next
    current.next = Node(value)
    return head

head = Node(10)
append(head, 20)
append(head, 30)
# list is now 10 -> 20 -> 30
```

**Task:** Build an empty list (`head = None`) and append the numbers `1..5` in a loop. Print the list to confirm it reads `1 -> 2 -> 3 -> 4 -> 5 -> None`.

## Exercise 3: Length and Sum of a Linked List
**Difficulty:** Basic
**Concepts:** counting during traversal, accumulating a running total

**Starter code:**
```python
def length(head):
    count = 0
    current = head
    while current is not None:
        count += 1
        current = current.next
    return count

def total(head):
    s = 0
    current = head
    while current is not None:
        s += current.value
        current = current.next
    return s
```

**Task:** Create a list `2 -> 4 -> 6 -> 8` and call both functions. Verify `length` returns `4` and `total` returns `20`.

## Exercise 4: Search for a Value
**Difficulty:** Basic
**Concepts:** early `return`, comparing values during traversal

**Starter code:**
```python
def contains(head, target):
    current = head
    while current is not None:
        if current.value == target:
            return True
        current = current.next
    return False

head = Node(10)
append(head, 20)
append(head, 30)
print(contains(head, 20))   # True
print(contains(head, 99))   # False
```

**Task:** Modify `contains` to return the *position* (0-based index) of the first match, or `-1` if not found.

## Exercise 5: Delete the First Matching Node
**Difficulty:** Basic
**Concepts:** updating the `next` pointer, handling the head-deletion case

**Starter code:**
```python
def delete(head, value):
    if head is None:
        return None
    if head.value == value:
        return head.next          # new head
    current = head
    while current.next is not None and current.next.value != value:
        current = current.next
    if current.next is not None:
        current.next = current.next.next
    return head

head = Node(10)
append(head, 20)
append(head, 30)
head = delete(head, 20)
# list is now 10 -> 30
```

**Task:** Test `delete` on three cases: removing the head, removing a middle node, and removing a value that does not exist (list should be unchanged).
