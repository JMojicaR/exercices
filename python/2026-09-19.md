## 1. Hello, World! and User Input
**Description:** Print a greeting to the console, then read the user's name and print a personalized greeting. This is the classic first program that introduces I/O.
**Difficulty:** Basic
**Concepts:** `print()`, `input()`, string concatenation, f-strings.
**Starter code:**
```python
name = input("What is your name? ")
print(f"Hello, {name}! Welcome to Python.")
```

---

## 2. Even or Odd Checker
**Description:** Read an integer from the user and determine whether it is even or odd using the modulo operator.
**Difficulty:** Basic
**Concepts:** Conditionals (`if`/`else`), modulo operator `%`, type conversion `int()`.
**Starter code:**
```python
number = int(input("Enter a number: "))
if number % 2 == 0:
    print(f"{number} is even")
else:
    print(f"{number} is odd")
```

## 3. Sum of Numbers 1 to N
**Description:** Ask the user for a positive integer N and compute the sum of all integers from 1 to N using a loop.
**Difficulty:** Basic
**Concepts:** `for` loop, `range()`, accumulator variable.
**Starter code:**
```python
n = int(input("Enter N: "))
total = 0
for i in range(1, n + 1):
    total += i
print(f"Sum from 1 to {n} is {total}")
```

## 4. List Statistics (Max, Min, Average)
**Description:** Given a list of numbers, find and print the maximum, minimum, and average values without relying on built-ins like `sum()` or `max()`.
**Difficulty:** Basic
**Concepts:** Lists, list iteration, comparison logic, indexing.
**Starter code:**
```python
numbers = [12, 5, 8, 20, 3]
maximum = numbers[0]
minimum = numbers[0]
total = 0
for n in numbers:
    if n > maximum:
        maximum = n
    if n < minimum:
        minimum = n
    total += n
print("Max:", maximum)
print("Min:", minimum)
print("Average:", total / len(numbers))
```

## 5. FizzBuzz
**Description:** Print the numbers 1 to 100, but for multiples of 3 print "Fizz", for multiples of 5 print "Buzz", and for multiples of both print "FizzBuzz".
**Difficulty:** Basic
**Concepts:** `for` loop, `if`/`elif`/`else`, modulo operator, order of conditions.
**Starter code:**
```python
for i in range(1, 101):
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
```
