## Exercise 1: Define a Node and Build a Small Tree
**Difficulty:** Basic
**Concepts:** class with `__init__`, `left`/`right` references, building a tree by hand

A binary search tree is a tree where every left child is smaller than its parent and every right child is larger. Each node holds a value and two child references.

**Starter code:**
```python
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

# Build the tree by hand:
#         8
#        / \
#       3   10
root = Node(8)
root.left = Node(3)
root.right = Node(10)
```

**Task:** Extend the tree so it looks like this, then print `root.left.right.value`:
```
       8
      / \
     3   10
    / \    \
   1   6    14
```
(Expected output: `6`.)

## Exercise 2: Insert a Value into the BST
**Difficulty:** Basic
**Concepts:** recursion, comparing values to choose left vs right, base case of an empty node

Insertion walks down the tree: go left if the new value is smaller, right otherwise, until it reaches an empty spot.

**Starter code:**
```python
def insert(node, value):
    if node is None:
        return Node(value)
    if value < node.value:
        node.left = insert(node.left, value)
    else:
        node.right = insert(node.right, value)
    return node

root = None
for v in [8, 3, 10, 1, 6]:
    root = insert(root, v)
```

**Task:** Insert `14`, `4`, and `7` into the tree above. Then write a helper that prints each node's value and its left/right child values (or `None`) to confirm the tree is built correctly.

## Exercise 3: Search for a Value
**Difficulty:** Basic
**Concepts:** recursive search, pruning half the tree on each step, early `return`

**Starter code:**
```python
def contains(node, value):
    if node is None:
        return False
    if node.value == value:
        return True
    if value < node.value:
        return contains(node.left, value)
    return contains(node.right, value)

root = None
for v in [8, 3, 10, 1, 6, 14, 4, 7]:
    root = insert(root, v)

print(contains(root, 6))   # True
print(contains(root, 12))  # False
```

**Task:** Modify `contains` to return the *depth* (number of steps from the root) where the value is found, or `-1` if it is not present.

## Exercise 4: In-Order Traversal (Sorted Output)
**Difficulty:** Basic
**Concepts:** recursion order (left → current → right), building a result list

An in-order traversal visits nodes left-subtree first, then the node, then the right subtree — which prints all values in sorted order.

**Starter code:**
```python
def inorder(node):
    if node is None:
        return []
    return inorder(node.left) + [node.value] + inorder(node.right)

root = None
for v in [8, 3, 10, 1, 6, 14, 4, 7]:
    root = insert(root, v)

print(inorder(root))  # [1, 3, 4, 6, 7, 8, 10, 14]
```

**Task:** Write a second function `preorder(node)` (current → left → right) and print both traversals. Confirm `preorder` starts with `8` and that `inorder` is fully sorted.

## Exercise 5: Find the Minimum and Maximum
**Difficulty:** Basic
**Concepts:** following the leftmost/rightmost chain, loops over linked references

The smallest value is found by following `left` pointers to the very end; the largest by following `right` pointers.

**Starter code:**
```python
def min_value(node):
    while node.left is not None:
        node = node.left
    return node.value

def max_value(node):
    while node.right is not None:
        node = node.right
    return node.value

root = None
for v in [8, 3, 10, 1, 6, 14, 4, 7]:
    root = insert(root, v)

print(min_value(root))  # 1
print(max_value(root))  # 14
```

**Task:** Rewrite `min_value` and `max_value` using recursion instead of a `while` loop.
