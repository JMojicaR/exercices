## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** string slicing `[::-1]`, indexing, return values

Write a function that returns the input string reversed.

**Starter code:**
```python
def reverse_string(s):
    return s[::-1]

print(reverse_string("hello"))   # expected: olleh
print(reverse_string("Python"))  # expected: nohtyP
```

**Task:** Rewrite the function using a `for` loop that builds the reversed string character by character instead of slicing.

## Exercise 2: Check Palindrome
**Difficulty:** Basic
**Concepts:** string comparison, `.lower()`, slicing, conditional return

Check whether a string reads the same forwards and backwards (ignoring case).

**Starter code:**
```python
def is_palindrome(s):
    s = s.lower()
    return s == s[::-1]

print(is_palindrome("Radar"))  # expected: True
print(is_palindrome("hello"))  # expected: False
```

**Task:** Extend the function to ignore spaces and punctuation (e.g. `"A man, a plan, a canal: Panama"` should return `True`).

## Exercise 3: Count Vowels
**Difficulty:** Basic
**Concepts:** `for` loop, `in` membership, string iteration, counter variable

Count how many vowels (a, e, i, o, u) appear in a string, case-insensitively.

**Starter code:**
```python
def count_vowels(s):
    vowels = "aeiouAEIOU"
    count = 0
    for ch in s:
        if ch in vowels:
            count += 1
    return count

print(count_vowels("hello world"))  # expected: 3
```

**Task:** Also count the consonants and return both counts as a tuple `(vowels, consonants)`.

## Exercise 4: Count Character Occurrences
**Difficulty:** Basic
**Concepts:** `.count()` string method, function parameters, string arguments

Count how many times a given character appears in a string.

**Starter code:**
```python
def count_char(s, ch):
    return s.count(ch)

print(count_char("banana", "a"))  # expected: 3
print(count_char("hello", "l"))   # expected: 2
```

**Task:** Rewrite the function using a `for` loop, without the `.count()` method.

## Exercise 5: Count Words
**Difficulty:** Basic
**Concepts:** `.split()`, `len()`, whitespace handling

Count the number of words in a sentence (words separated by spaces).

**Starter code:**
```python
def count_words(sentence):
    return len(sentence.split())

print(count_words("I love programming"))  # expected: 3
print(count_words("One two three four"))  # expected: 4
```

**Task:** Make the function robust to multiple consecutive spaces and leading/trailing spaces.
