## Exercise 1: Create and Print a Matrix
**Difficulty:** Basic
**Concepts:** nested lists, `input()`, nested `for` loops, `print(..., end=...)`

Read a matrix from the user (one row per line) and print it back in a neat grid.

**Starter code:**
```python
rows = int(input("Enter number of rows: "))
cols = int(input("Enter number of columns: "))

matrix = []
print("Enter elements row by row:")
for i in range(rows):
    row = list(map(int, input().split()))
    matrix.append(row)

print("Matrix:")
for row in matrix:
    for val in row:
        print(val, end=" ")
    print()
```

**Task:** Print the matrix in reverse row order, then print only the border elements (first/last row and first/last column).

## Exercise 2: Matrix Addition
**Difficulty:** Basic
**Concepts:** nested lists, list comprehension, element-wise addition

Add two matrices of the same size and print the result.

**Starter code:**
```python
a = [[1, 2], [3, 4]]
b = [[5, 6], [7, 8]]
rows = len(a)
cols = len(a[0])

result = [[0] * cols for _ in range(rows)]

for i in range(rows):
    for j in range(cols):
        result[i][j] = a[i][j] + b[i][j]

print("Sum matrix:")
for row in result:
    print(row)
```

**Task:** Also compute the difference (`a - b`), and validate that both matrices have the same dimensions before adding.

## Exercise 3: Matrix Transpose
**Difficulty:** Basic
**Concepts:** swapping row/column indices, dynamic list sizing

Transpose a matrix (swap rows and columns) and print the result.

**Starter code:**
```python
matrix = [[1, 2, 3],
          [4, 5, 6]]

rows = len(matrix)
cols = len(matrix[0])

transpose = [[0] * rows for _ in range(cols)]

for i in range(rows):
    for j in range(cols):
        transpose[j][i] = matrix[i][j]

print("Transpose:")
for row in transpose:
    print(row)
```

**Task:** Write a one-liner transpose using `zip(*matrix)` and `list(map(list, ...))`.

## Exercise 4: Sum of the Main Diagonal
**Difficulty:** Basic
**Concepts:** square matrices, single loop, index tracking

For a square matrix, sum the elements on the main diagonal (top-left to bottom-right).

**Starter code:**
```python
matrix = [[1, 2, 3],
          [4, 5, 6],
          [7, 8, 9]]

n = len(matrix)
total = 0

for i in range(n):
    total += matrix[i][i]

print("Sum of main diagonal:", total)
```

**Task:** Also sum the anti-diagonal (top-right to bottom-left) and print both totals.

## Exercise 5: Sum of Each Row and Each Column
**Difficulty:** Basic
**Concepts:** nested loops, running totals, `sum()`

Print the sum of every row and every column of a matrix.

**Starter code:**
```python
matrix = [[1, 2, 3],
          [4, 5, 6],
          [7, 8, 9]]

rows = len(matrix)
cols = len(matrix[0])

print("Row sums:")
for i in range(rows):
    print(f"Row {i}: {sum(matrix[i])}")

print("Column sums:")
for j in range(cols):
    col_sum = 0
    for i in range(rows):
        col_sum += matrix[i][j]
    print(f"Col {j}: {col_sum}")
```

**Task:** Use `zip(*matrix)` to compute column sums in a single loop, and report the overall total of all elements.
