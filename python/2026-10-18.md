## Exercise 1: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** variables, temporary variable, tuple unpacking

Read two numbers and swap their values.

**Starter code:**
```python
a = 5
b = 10

# Using a temporary variable
temp = a
a = b
b = temp

print("a =", a, "b =", b)
```

**Task:** Swap again without a temporary variable using Python's tuple unpacking: `a, b = b, a`.

## Exercise 2: Area of a Circle
**Difficulty:** Basic
**Concepts:** arithmetic, `math.pi`, `float`, input/output

Compute the area of a circle given its radius (`area = π × r²`).

**Starter code:**
```python
import math

radius = float(input("Enter radius: "))
area = math.pi * radius ** 2
print("Area:", round(area, 2))
```

**Task:** Also print the circumference using `2 * math.pi * radius`.

## Exercise 3: Positive, Negative or Zero
**Difficulty:** Basic
**Concepts:** `if / elif / else`, comparison operators

Classify a number as positive, negative, or zero.

**Starter code:**
```python
n = float(input("Enter a number: "))
if n > 0:
    print("Positive")
elif n < 0:
    print("Negative")
else:
    print("Zero")
```

**Task:** Extend it to also report whether the number is even or odd when it is a whole number.

## Exercise 4: Power of a Number (xⁿ)
**Difficulty:** Basic
**Concepts:** loops, accumulation, `**` operator, `pow()`

Compute `base` raised to the power `exp` using a loop.

**Starter code:**
```python
base = int(input("Base: "))
exp = int(input("Exponent: "))

result = 1
for _ in range(exp):
    result *= base

print(base, "^", exp, "=", result)
```

**Task:** Rewrite the same computation using the `**` operator and then using `pow(base, exp)`.

## Exercise 5: Reverse a Number
**Difficulty:** Basic
**Concepts:** `while` loop, modulo (`%`), integer division (`//`)

Reverse the digits of an integer (e.g. 1234 → 4321).

**Starter code:**
```python
n = int(input("Enter a number: "))
rev = 0
while n > 0:
    rev = rev * 10 + n % 10
    n //= 10
print("Reversed:", rev)
```

**Task:** Handle negative numbers by reversing the digits and keeping the sign.
