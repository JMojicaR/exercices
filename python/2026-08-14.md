## Exercise 1: FizzBuzz

### Problem
Write a program that iterates through integers from 1 to 50. For each multiple of three, print `"Fizz"` instead of the number; for each multiple of five, print `"Buzz"`. For numbers that are multiples of both three and five, print `"FizzBuzz"`. Otherwise, print the number itself.

**Expected Output:**
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
...
14
FizzBuzz
```

### Concepts
- `for` loops with `range()`
- Modulo operator (`%`) for divisibility checks
- `if / elif / else` conditional branching

### Example / Starter Code

```python
for i in range(1, 51):
    if i % 3 == 0 and i % 5 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
```

## Exercise 2: Check Prime Number

### Problem
Write a function that accepts a positive integer and returns `True` if it is a prime number and `False` otherwise. A prime number is greater than 1 and divisible only by 1 and itself.

**Given Input:**
- `is_prime(11)`
- `is_prime(15)`

**Expected Output:**
- `True`
- `False`

### Concepts
- Function definitions with a boolean return value
- `for` loops with early `break`
- Divisibility via the modulo operator
- Optimization: iterate only up to `sqrt(n)`

### Example / Starter Code

```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

print(is_prime(11))   # True
print(is_prime(15))   # False
```

## Exercise 3: Palindrome String Check

### Problem
Write a function that checks whether a given string reads the same forward and backward (ignoring case and spaces). Return `True` if it is a palindrome, otherwise `False`.

**Given Input:**
- `is_palindrome("racecar")`
- `is_palindrome("hello")`

**Expected Output:**
- `True`
- `False`

### Concepts
- String normalization (`.lower()`, removing spaces)
- String slicing with `[::-1]` to reverse
- String comparison

### Example / Starter Code

```python
def is_palindrome(text):
    # Normalize: lowercase and remove spaces
    normalized = text.lower().replace(" ", "")
    # Reverse using slicing
    reversed_text = normalized[::-1]
    return normalized == reversed_text

print(is_palindrome("racecar"))   # True
print(is_palindrome("hello"))     # False
print(is_palindrome("A man a plan a canal Panama"))  # True
```

## Exercise 4: Count Vowels and Consonants

### Problem
Write a program that takes a string and counts how many vowels (`a, e, i, o, u`) and consonants it contains. Ignore non-letter characters.

**Given Input:** `"Hello, World!"`

**Expected Output:**
```
Vowels: 3
Consonants: 7
```

### Concepts
- `for` loops over strings
- String membership checks (`in`)
- `.lower()` for case-insensitivity
- `.isalpha()` to ignore non-letters

### Example / Starter Code

```python
text = "Hello, World!"
vowels = "aeiou"
vowel_count = 0
consonant_count = 0

for char in text.lower():
    if char.isalpha():
        if char in vowels:
            vowel_count += 1
        else:
            consonant_count += 1

print("Vowels:", vowel_count)
print("Consonants:", consonant_count)
```

## Exercise 5: Factorial of a Number

### Problem
Write a function that calculates the factorial of a non-negative integer using a loop. The factorial of `n` (written `n!`) is the product of all positive integers from 1 to `n`.

**Given Input:** `factorial(5)`

**Expected Output:**
```
120
```

### Concepts
- `for` loops for accumulation
- Accumulator pattern (initializing a result variable)
- `while` loop alternative

### Example / Starter Code

```python
def factorial(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

print(factorial(5))   # 120
print(factorial(0))   # 1
```
