## Exercise 1: Hello, World! & User Input
**Difficulty:** ★☆☆☆☆  
**Concepts:** Print statements, variables, user input, string formatting  

**Description:**  
Write a program that asks the user for their name and age, then prints a greeting message that includes both. Calculate and display the year they were born (approximately).

**Example Starter Code:**
```python
# Get user's name and age
name = input("Enter your name: ")
age = int(input("Enter your age: "))

# Calculate birth year
current_year = 2026
birth_year = current_year - age

# Print greeting
print(f"Hello, {name}! You are {age} years old.")
print(f"You were born around {birth_year}.")
```

**Expected Output:**
```
Enter your name: Alice
Enter your age: 25
Hello, Alice! You are 25 years old.
You were born around 2001.
```

## Exercise 2: Simple Calculator
**Difficulty:** ★★☆☆☆  
**Concepts:** Functions, arithmetic operators, conditional statements  

**Description:**  
Create a calculator program with four functions: `add(a, b)`, `subtract(a, b)`, `multiply(a, b)`, and `divide(a, b)`. The program should ask the user which operation they want to perform and two numbers, then display the result. Handle division by zero.

**Example Starter Code:**
```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "Error: Cannot divide by zero!"
    return a / b

# Get user input
print("Operations: +, -, *, /")
op = input("Choose an operation: ")
num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))

# Perform the operation
if op == '+':
    result = add(num1, num2)
elif op == '-':
    result = subtract(num1, num2)
elif op == '*':
    result = multiply(num1, num2)
elif op == '/':
    result = divide(num1, num2)
else:
    result = "Invalid operation!"

print(f"Result: {result}")
```

## Exercise 3: List Manipulation
**Difficulty:** ★★☆☆☆  
**Concepts:** Lists, loops, list methods  

**Description:**  
Write a program that creates a list of numbers, then performs the following operations:
1. Add a new number to the end
2. Remove the first occurrence of a specific number
3. Sort the list
4. Find the sum, minimum, and maximum values
5. Print the final list

**Example Starter Code:**
```python
# Initial list
numbers = [5, 2, 8, 1, 9, 3]

# Step 1: Append a number
numbers.append(7)
print(f"After append: {numbers}")

# Step 2: Remove a specific number
numbers.remove(2)  # Remove the first occurrence of 2
print(f"After remove: {numbers}")

# Step 3: Sort the list
numbers.sort()
print(f"After sort: {numbers}")

# Step 4: Calculate statistics
list_sum = sum(numbers)
list_min = min(numbers)
list_max = max(numbers)

print(f"Sum: {list_sum}")
print(f"Minimum: {list_min}")
print(f"Maximum: {list_max}")
print(f"Final list: {numbers}")
```

**Expected Output:**
```
After append: [5, 2, 8, 1, 9, 3, 7]
After remove: [5, 8, 1, 9, 3, 7]
After sort: [1, 3, 5, 7, 8, 9]
Sum: 33
Minimum: 1
Maximum: 9
Final list: [1, 3, 5, 7, 8, 9]
```

## Exercise 4: Temperature Converter
**Difficulty:** ★★☆☆☆  
**Concepts:** Functions, type conversion, user input, conditional logic  

**Description:**  
Create a temperature converter that can convert between Celsius and Fahrenheit. The user should specify the conversion direction and the temperature value. Use the formulas:
- Celsius to Fahrenheit: `F = (C × 9/5) + 32`
- Fahrenheit to Celsius: `C = (F - 32) × 5/9`

**Example Starter Code:**
```python
def celsius_to_fahrenheit(celsius):
    return (celsius * 9/5) + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5/9

print("Temperature Converter")
print("1. Celsius to Fahrenheit")
print("2. Fahrenheit to Celsius")

choice = input("Choose conversion (1 or 2): ")

if choice == '1':
    celsius = float(input("Enter temperature in Celsius: "))
    fahrenheit = celsius_to_fahrenheit(celsius)
    print(f"{celsius}°C = {fahrenheit:.1f}°F")
elif choice == '2':
    fahrenheit = float(input("Enter temperature in Fahrenheit: "))
    celsius = fahrenheit_to_celsius(fahrenheit)
    print(f"{fahrenheit}°F = {celsius:.1f}°C")
else:
    print("Invalid choice!")
```

## Exercise 5: Palindrome Checker
**Difficulty:** ★★★☆☆  
**Concepts:** String manipulation, loops, string methods  

**Description:**  
Write a function that checks if a given string is a palindrome (reads the same forwards and backwards). The check should be case-insensitive and ignore spaces and punctuation. For example, "A man, a plan, a canal: Panama" should be recognized as a palindrome.

**Example Starter Code:**
```python
def is_palindrome(text):
    # Remove non-alphanumeric characters and convert to lowercase
    cleaned = ''.join(char.lower() for char in text if char.isalnum())
    
    # Compare with reversed version
    return cleaned == cleaned[::-1]

# Test cases
test_strings = [
    "racecar",
    "hello",
    "A man, a plan, a canal: Panama",
    "Was it a car or a cat I saw?",
    "Python"
]

for s in test_strings:
    result = "Yes" if is_palindrome(s) else "No"
    print(f'"{s}" → Palindrome? {result}')
```

**Expected Output:**
```
"racecar" → Palindrome? Yes
"hello" → Palindrome? No
"A man, a plan, a canal: Panama" → Palindrome? Yes
"Was it a car or a cat I saw?" → Palindrome? Yes
"Python" → Palindrome? No
```
