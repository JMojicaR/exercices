## Exercise 1: Temperature Converter (Celsius ↔ Fahrenheit)
**Difficulty:** Basic
**Concepts:** Functions, arithmetic, `input()`/`float()`, conditional choice, f-strings.

Write a program that lets the user choose a direction and convert a temperature between Celsius and Fahrenheit using the formulas `F = C * 9/5 + 32` and `C = (F - 32) * 5/9`.

**Starter code:**
```python
def celsius_to_fahrenheit(c):
    return c * 9 / 5 + 32

def fahrenheit_to_celsius(f):
    return (f - 32) * 5 / 9

choice = input("Convert (C)elsius or (F)ahrenheit? ").strip().upper()
value = float(input("Enter the temperature: "))

if choice == "C":
    print(f"{value}°C = {celsius_to_fahrenheit(value):.2f}°F")
elif choice == "F":
    print(f"{value}°F = {fahrenheit_to_celsius(value):.2f}°C")
else:
    print("Invalid choice.")
```

**Task:** Keep looping until the user types "quit", and round results to 2 decimals.

## Exercise 2: Factorial
**Difficulty:** Basic
**Concepts:** `for` loops, accumulator pattern, range, recursion (optional).

Write a program that reads a non-negative integer and prints its factorial (`n! = 1 × 2 × … × n`, with `0! = 1`).

**Starter code:**
```python
n = int(input("Enter a number: "))

factorial = 1
for i in range(1, n + 1):
    factorial *= i

print(f"{n}! = {factorial}")
```

**Task:** Also write a recursive version `def fact(n):` and confirm both return the same result.

## Exercise 3: Palindrome Checker
**Difficulty:** Basic
**Concepts:** Strings, slicing/loops, case handling, comparison.

Write a program that checks whether a word or phrase reads the same backward as forward (ignoring spaces and case).

**Starter code:**
```python
text = input("Enter a word or phrase: ").lower()
cleaned = text.replace(" ", "")

if cleaned == cleaned[::-1]:
    print(f"'{text}' is a palindrome!")
else:
    print(f"'{text}' is not a palindrome.")
```

**Task:** Rewrite the check without using slicing — compare characters in a loop.

## Exercise 4: Count Vowels and Consonants
**Difficulty:** Basic
**Concepts:** Strings, loops, `in` operator, `lower()`, counters, conditionals.

Read a sentence and count how many vowels (`a e i o u`) and consonants it contains.

**Starter code:**
```python
text = input("Enter a sentence: ").lower()
vowels = "aeiou"

vowel_count = 0
consonant_count = 0

for char in text:
    if char.isalpha():
        if char in vowels:
            vowel_count += 1
        else:
            consonant_count += 1

print("Vowels:", vowel_count)
print("Consonants:", consonant_count)
```

**Task:** Also count and print the number of digits and spaces.

## Exercise 5: Multiplication Table
**Difficulty:** Basic
**Concepts:** Nested loops, `range()`, formatted output, string formatting.

Write a program that prints the multiplication table (1 to 10) for a number entered by the user.

**Starter code:**
```python
n = int(input("Enter a number: "))

for i in range(1, 11):
    print(f"{n} x {i} = {n * i}")
```

**Task:** Print a full 1–10 × 1–10 grid using nested loops, aligned in columns.
