## Exercise 1: Find Maximum & Minimum
**Difficulty:** Basic
**Concepts:** `for` loop, list indexing, comparisons, tuple return

Return the smallest and largest values in a list of numbers as a `(min, max)` tuple.

**Starter code:**
```python
def find_min_max(numbers):
    minimum = maximum = numbers[0]
    for n in numbers[1:]:
        if n < minimum:
            minimum = n
        if n > maximum:
            maximum = n
    return minimum, maximum

print(find_min_max([3, 1, 4, 1, 5, 9, 2]))  # expected: (1, 9)
```

**Task:** Rewrite the function using the built-ins `min()` and `max()`, and handle an empty list by returning `None`.

## Exercise 2: Sum of Elements
**Difficulty:** Basic
**Concepts:** `for` loop, accumulator variable, `+=`

Return the sum of all numbers in a list.

**Starter code:**
```python
def total(numbers):
    result = 0
    for n in numbers:
        result += n
    return result

print(total([1, 2, 3, 4, 5]))  # expected: 15
```

**Task:** Replace the loop with the built-in `sum()`. Then extend the function to return the average (mean) of the list as a `float`.

## Exercise 3: Reverse a List
**Difficulty:** Basic
**Concepts:** `for` + `range()`, reverse indexing, `.append()`

Return a new list with the elements in reverse order (do not modify the original).

**Starter code:**
```python
def reverse_list(items):
    reversed_items = []
    for i in range(len(items) - 1, -1, -1):
        reversed_items.append(items[i])
    return reversed_items

print(reverse_list([1, 2, 3, 4]))  # expected: [4, 3, 2, 1]
```

**Task:** Rewrite using slice syntax `items[::-1]`, and also try the in-place `items.reverse()` and note how it differs from returning a new list.

## Exercise 4: Count Occurrences
**Difficulty:** Basic
**Concepts:** `for` loop, equality `==`, counter variable

Return how many times a given target value appears in a list.

**Starter code:**
```python
def count_occurrences(items, target):
    count = 0
    for item in items:
        if item == target:
            count += 1
    return count

print(count_occurrences([1, 2, 3, 2, 4, 2], 2))  # expected: 3
```

**Task:** Replace the loop with `items.count(target)`. Then write a variant that returns a dictionary of counts for *every* element (a frequency table).

## Exercise 5: Remove Duplicates
**Difficulty:** Basic
**Concepts:** membership test `in`, list building, preserving order

Return a new list containing each element only once, preserving the original order.

**Starter code:**
```python
def remove_duplicates(items):
    unique = []
    for item in items:
        if item not in unique:
            unique.append(item)
    return unique

print(remove_duplicates([1, 2, 2, 3, 4, 4, 4, 5]))  # expected: [1, 2, 3, 4, 5]
```

**Task:** Rewrite using `list(dict.fromkeys(items))` (order-preserving) and compare with `list(set(items))` — explain why the `set` version may lose ordering.
