## Exercise 4: Factorial Calculator
- **Difficulty:** Easy
- **Description:** Write a function `factorial(n)` that returns n! (n factorial). Handle the base case `0! == 1`. Solve once with a loop and once with recursion.
- **Concepts:** functions, recursion, base case, loops
- **Starter code:**
```python
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

print(factorial(5))  # should print 120
```
