## Exercise 1: try/except Basics
**Difficulty:** Basic
**Concepts:** `try`, `except`, `ZeroDivisionError`, returning a safe fallback

Write a `safe_divide` function that never crashes — it returns an error message when the denominator is zero.

**Starter code:**
```python
def safe_divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return "Cannot divide by zero"

print(safe_divide(10, 2))   # 5.0
print(safe_divide(10, 0))   # Cannot divide by zero
```

**Task:** Add a second `except TypeError` block that returns `"Both values must be numbers"` when `a` or `b` isn't a number (e.g. `safe_divide("x", 2)`).

## Exercise 2: Multiple except Blocks + else
**Difficulty:** Basic
**Concepts:** catching `ValueError` vs `TypeError`, `int()`, the `else` clause

Write a `convert_to_int` function that handles the two different ways a conversion can fail.

**Starter code:**
```python
def convert_to_int(text):
    try:
        return int(text)
    except ValueError:
        return "Not a valid integer"
    except TypeError:
        return "Input is not a string or number"

print(convert_to_int("42"))    # 42
print(convert_to_int("hello")) # Not a valid integer
print(convert_to_int(None))    # Input is not a string or number
```

**Task:** Add an `else` clause that prints `"Converted successfully"` before returning, and verify it runs only when no exception was raised.

## Exercise 3: try/except/else/finally
**Difficulty:** Basic
**Concepts:** full exception flow, `input()`, `int()`, `finally` for cleanup, `else` for the happy path

Build a small division prompt that separates the happy path from cleanup.

**Starter code:**
```python
def read_divide():
    try:
        numerator = int(input("Numerator: "))
        denominator = int(input("Denominator: "))
        result = numerator / denominator
    except ValueError:
        print("Please enter valid integers.")
    except ZeroDivisionError:
        print("Denominator cannot be zero.")
    else:
        print(f"Result: {result}")
    finally:
        print("Division attempt finished.")

read_divide()
```

**Task:** Wrap the whole prompt in a `while True` loop so it keeps asking until a valid division completes, then `break`.

## Exercise 4: raise + Custom Exception
**Difficulty:** Basic
**Concepts:** `raise`, defining an `Exception` subclass, `except ... as e`

Define your own `NegativeAgeError` and raise it from a validation function.

**Starter code:**
```python
class NegativeAgeError(Exception):
    pass

def set_age(age):
    if age < 0:
        raise NegativeAgeError("Age cannot be negative")
    return age

try:
    set_age(-5)
except NegativeAgeError as e:
    print(f"Error: {e}")
```

**Task:** Extend `set_age` to raise a `ValueError("Age is unrealistically high")` when `age > 150`, and add a matching `except ValueError` block.

## Exercise 5: Robust Parsing of a List
**Difficulty:** Basic
**Concepts:** looping with `try`/`except`, `(ValueError, TypeError)` tuple catch, skipping bad values

Parse a mixed list into floats, skipping (and reporting) the entries that fail.

**Starter code:**
```python
def parse_numbers(values):
    numbers = []
    for v in values:
        try:
            numbers.append(float(v))
        except (ValueError, TypeError):
            print(f"Skipping invalid value: {v!r}")
    return numbers

print(parse_numbers(["1.5", "2", "x", "3.7", None]))
```

**Task:** Return a tuple `(numbers, rejected)` instead, collecting every rejected value into a list, so the caller can see both the parsed numbers and the failures.
