## Exercise 1: Even or Odd
- **Difficulty:** Easy
- **Description:** Read an integer from the user and print whether it is "Even" or "Odd" using the modulo operator `%`. Extend it to also report whether the number is positive, negative, or zero.
- **Concepts:** `input()`, `int()` conversion, `if`/`elif`/`else`, modulo `%`
- **Starter code:**
```python

if num % 2 == 0:
    print(f"{num} is Even")
else:
    print(f"{num} is Odd")
```

## Exercise 5: Sum of Digits
- **Difficulty:** Easy
- **Description:** Read an integer and print the sum of its digits. For example, `1234` → `10`. Use a `while` loop with `% 10` and `// 10`. Handle negative numbers by working with `abs()`.
- **Concepts:** `while` loop, integer division `//`, modulo `%`, `abs()`
- **Starter code:**
```python
num = abs(int(input("Enter an integer: ")))
total = 0

while num > 0:
    total += num % 10   # add last digit
    num //= 10          # remove last digit

print(total)

# TODO: verify with 1234 (should print 10)
```
