## Exercise 1: Number Guessing Game
**Difficulty:** Basic
**Concepts:** while loop, random module, conditionals, user input

Pick a random number between 1 and 100 and keep asking the user to guess it, telling them "too low" or "too high" until they get it right.

**Starter code:**
```python
import random

target = random.randint(1, 100)
guess = None

while guess != target:
    guess = int(input("Guess a number between 1 and 100: "))
    if guess < target:
        print("Too low!")
    elif guess > target:
        print("Too high!")

print("You guessed it!")
```

**Task:** Count the number of attempts and print it when the player wins.

## Exercise 3: Perfect Number Check
**Difficulty:** Basic
**Concepts:** for loop, range, modulo, divisors

A perfect number equals the sum of its proper divisors (excluding itself). For example, 6 = 1 + 2 + 3. Check whether a number is perfect.

**Starter code:**
```python
n = int(input("Enter a positive integer: "))
total = 0
for i in range(1, n):
    if n % i == 0:
        total += i

if total == n:
    print(n, "is a perfect number")
else:
    print(n, "is not a perfect number")
```

**Task:** Print all perfect numbers between 1 and 10,000.

## Exercise 4: Sum of Natural Numbers
**Difficulty:** Basic
**Concepts:** for loop, range, accumulator

Compute the sum of all natural numbers from 1 up to a given `n`.

**Starter code:**
```python
n = int(input("Enter a positive integer: "))
total = 0
for i in range(1, n + 1):
    total += i

print("Sum from 1 to", n, "is", total)
```

**Task:** Do the same calculation using the formula `n * (n + 1) // 2` and verify both agree.

## Exercise 5: Character Frequency
**Difficulty:** Basic
**Concepts:** string iteration, loops, counting

Count how many times a given character appears in a string.

**Starter code:**
```python
text = input("Enter a string: ")
char = input("Enter a character to count: ")

count = 0
for c in text:
    if c == char:
        count += 1

print(f"'{char}' appears {count} times")
```

**Task:** Use `text.count(char)` instead and confirm it gives the same answer.
