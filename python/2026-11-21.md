## Exercise 1: Build a Stack with a List
**Difficulty:** Basic
**Concepts:** `append()` (push), `pop()` (pop), LIFO order, `len()` for emptiness

A stack follows **LIFO** (Last-In, First-Out). Python lists already provide `append()` and `pop()` which work as a stack.

**Starter code:**
```python
stack = []

stack.append("a")   # push
stack.append("b")
stack.append("c")
print(stack)        # ['a', 'b', 'c']

top = stack.pop()   # removes and returns the last item
print(top)          # 'c'
print(stack)        # ['a', 'b']
print(len(stack) == 0)   # False — still has items
```

**Task:** Write a function `push_and_pop(items)` that pushes every item from a list onto a stack, then pops them all and returns the popped values as a list. Verify the result is the reverse of the input order.

## Exercise 2: Build a Queue with `collections.deque`
**Difficulty:** Basic
**Concepts:** `deque`, `append()` (enqueue), `popleft()` (dequeue), FIFO order

A queue follows **FIFO** (First-In, First-Out). `list.pop(0)` is slow for long lists; `collections.deque` gives O(1) removal from both ends.

**Starter code:**
```python
from collections import deque

q = deque()
q.append("a")      # enqueue (add to back)
q.append("b")
q.append("c")
print(list(q))     # ['a', 'b', 'c']

first = q.popleft()  # dequeue (remove from front)
print(first)         # 'a'
print(list(q))       # ['b', 'c']
```

**Task:** Write a loop that enqueues the numbers `1..5`, then dequeues and prints them one by one until the queue is empty. The printed order should be `1 2 3 4 5`.

## Exercise 3: Balanced Parentheses Checker
**Difficulty:** Basic
**Concepts:** stack for matching pairs, dictionary of matching brackets, early exit on mismatch

Use a stack to decide whether every opening bracket has a matching closing bracket in the right order.

**Starter code:**
```python
def is_balanced(s):
    stack = []
    pairs = {")": "(", "]": "[", "}": "{"}
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in ")]}":
            if not stack or stack.pop() != pairs[ch]:
                return False
    return len(stack) == 0

print(is_balanced("(a[b]{c})"))   # True
print(is_balanced("([)]"))        # False
```

**Task:** Extend the function so it also returns `False` for strings with an empty top when a closing bracket appears, and add a test for the string `"((("` (should be `False` because of unmatched openers).

## Exercise 4: Reverse a String with a Stack
**Difficulty:** Basic
**Concepts:** push characters, pop to rebuild, string building with `join`

Push every character onto a stack, then pop them all — the popped order is the reverse.

**Starter code:**
```python
def reverse_string(text):
    stack = []
    for ch in text:
        stack.append(ch)
    reversed_chars = []
    while stack:
        reversed_chars.append(stack.pop())
    return "".join(reversed_chars)

print(reverse_string("hello"))   # "olleh"
```

**Task:** Rewrite the function without the `reversed_chars` list — instead, build the result by adding popped characters directly to a string with `+=`, and confirm it still prints `"olleh"`.

## Exercise 5: Implement a Queue Using Two Stacks
**Difficulty:** Basic
**Concepts:** using two stacks (inbox/outbox) to simulate FIFO, moving elements between stacks

You can simulate a queue with two stacks: push everything to an *in* stack, and when you need to dequeue, move items over to an *out* stack (which reverses them back to FIFO order).

**Starter code:**
```python
class TwoStackQueue:
    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def enqueue(self, item):
        self.in_stack.append(item)

    def dequeue(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
        return self.out_stack.pop()

q = TwoStackQueue()
q.enqueue(1); q.enqueue(2); q.enqueue(3)
print(q.dequeue())   # 1
print(q.dequeue())   # 2
```

**Task:** Add an `is_empty()` method that returns `True` only when *both* stacks are empty, and test it before and after dequeuing all items.
