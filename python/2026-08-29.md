## Exercise 1: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that takes an integer `n` and prints its multiplication table from 1 to 10 using a `for` loop and an f-string.

**Given Input:** `5`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

### Concepts
- `for` loop with `range()`
- f-strings for formatted output
- `input()` and `int()` conversion

### Example / Starter Code

```python
n = int(input("Enter a number: "))

for i in range(1, 11):
    print(f"{n} x {i} = {n * i}")
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that reads three integers and prints the largest one using `if`/`elif`/`else`.

**Given Input:** `10 25 15`

**Expected Output:**
```
Largest: 25
```

### Concepts
- Comparison operators (`>=`, `and`)
- `if`/`elif`/`else` branching
- `int(input())`

### Example / Starter Code

```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
c = int(input("Enter third number: "))

if a >= b and a >= c:
    largest = a
elif b >= a and b >= c:
    largest = b
else:
    largest = c

print("Largest:", largest)
```

## Exercise 3: Reverse a String

**Difficulty:** Basic

### Problem
Write a program that reads a string and prints it reversed using string slicing.

**Given Input:** `hello`

**Expected Output:**
```
Reversed: olleh
```

### Concepts
- String slicing with a negative step (`[::-1]`)
- String immutability in Python

### Example / Starter Code

```python
text = input("Enter a string: ")
reversed_text = text[::-1]
print("Reversed:", reversed_text)
```

## Exercise 4: Leap Year Checker

**Difficulty:** Basic

### Problem
Write a program that reads a year and determines whether it is a leap year. A year is a leap year if it is divisible by 4, except century years which must be divisible by 400.

**Given Input:** `2024`

**Expected Output:**
```
2024 is a leap year
```

### Concepts
- Modulo operator `%`
- Boolean logic with `and`/`or`
- `if`/`else`

### Example / Starter Code

```python
year = int(input("Enter a year: "))

if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year} is a leap year")
else:
    print(f"{year} is not a leap year")
```

## Exercise 5: Simple Calculator

**Difficulty:** Basic

### Problem
Write a program that reads two numbers and an operator (`+`, `-`, `*`, `/`) and prints the result. Handle division by zero and invalid operators gracefully.

**Given Input:** `8 2 /`

**Expected Output:**
```
Result: 4.0
```

### Concepts
- `if`/`elif`/`else` (or `match` statement)
- Arithmetic operators
- Division-by-zero handling

### Example / Starter Code

```python
a = float(input("Enter first number: "))
b = float(input("Enter second number: "))
op = input("Enter operator (+, -, *, /): ")

if op == '+':
    result = a + b
elif op == '-':
    result = a - b
elif op == '*':
    result = a * b
elif op == '/':
    result = a / b if b != 0 else "Error: division by zero"
else:
    result = "Invalid operator"

print("Result:", result)
```
