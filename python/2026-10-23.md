## Exercise 1: Print the ASCII Value of a Character
**Difficulty:** Basic
**Concepts:** `ord()`, `chr()`, characters vs integers

Given a single character, print its ASCII (Unicode code point) value.

**Starter code:**
```python
ch = input("Enter a character: ")
print("ASCII value of", ch, "is", ord(ch))
```

**Task:** Also do the reverse — read an integer code and print its character using `chr()`. Verify `ord(chr(65)) == 65`.

## Exercise 2: Check Vowel or Consonant
**Difficulty:** Basic
**Concepts:** `if / elif / else`, `in` membership, string handling

Read a single letter and report whether it is a vowel or a consonant.

**Starter code:**
```python
ch = input("Enter a letter: ").lower()
vowels = "aeiou"

if ch in vowels:
    print(ch, "is a vowel")
else:
    print(ch, "is a consonant")
```

**Task:** Validate that the input is a single alphabetic character first (using `isalpha()` and length check); otherwise print "Invalid input".

## Exercise 3: Maximum and Minimum in a List
**Difficulty:** Basic
**Concepts:** lists, loops, `max()` / `min()`, comparisons

Find the largest and smallest numbers in a list of numbers.

**Starter code:**
```python
numbers = [45, 12, 78, 34, 89, 23]
maximum = numbers[0]
minimum = numbers[0]

for n in numbers:
    if n > maximum:
        maximum = n
    if n < minimum:
        minimum = n

print("Max:", maximum, "Min:", minimum)
```

**Task:** Rewrite it using the built-in `max(numbers)` and `min(numbers)`, then ask the user for the numbers instead of hardcoding them.

## Exercise 4: Simple Calculator
**Difficulty:** Basic
**Concepts:** `if / elif`, arithmetic operators, input parsing

Build a calculator that takes two numbers and an operator (`+`, `-`, `*`, `/`) and prints the result.

**Starter code:**
```python
a = float(input("First number: "))
b = float(input("Second number: "))
op = input("Operator (+, -, *, /): ")

if op == "+":
    print("Result:", a + b)
elif op == "-":
    print("Result:", a - b)
elif op == "*":
    print("Result:", a * b)
elif op == "/":
    print("Result:", a / b)
else:
    print("Invalid operator")
```

**Task:** Handle division by zero gracefully, and loop so the user can perform multiple calculations until they type `quit`.

## Exercise 5: Print Prime Numbers in a Range
**Difficulty:** Basic
**Concepts:** nested `for` loops, `break`, flags, modulo (`%`)

Print every prime number between two given bounds (e.g. 10 and 50).

**Starter code:**
```python
start, end = 10, 50

for num in range(start, end + 1):
    if num < 2:
        continue
    is_prime = True
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            is_prime = False
            break
    if is_prime:
        print(num, end=" ")
```

**Task:** Count how many primes were found and print the total, and make `start`/`end` user-supplied.
