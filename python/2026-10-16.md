## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** string slicing, indexing, strings

Read a string and print it reversed.

**Starter code:**
```python
text = input("Enter a string: ")
reversed_text = text[::-1]
print("Reversed:", reversed_text)
```

## Exercise 2: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** conditionals, comparisons, input

Read three numbers and print the largest one.

**Starter code:**
```python
a = float(input("Enter first number: "))
b = float(input("Enter second number: "))
c = float(input("Enter third number: "))

largest = a
if b > largest:
    largest = b
if c > largest:
    largest = c

print("The largest number is", largest)
```

## Exercise 4: Armstrong Number
**Difficulty:** Basic
**Concepts:** while loop, modulo, floor division, exponent

An Armstrong number equals the sum of its digits each raised to the power of the number of digits (e.g. 153 = 1³ + 5³ + 3³). Check whether a number is an Armstrong number.

**Starter code:**
```python
n = int(input("Enter a positive integer: "))
num = n
digits = len(str(n))
total = 0

while num > 0:
    digit = num % 10
    total += digit ** digits
    num //= 10

if total == n:
    print(n, "is an Armstrong number")
else:
    print(n, "is not an Armstrong number")
```

**Task:** Print all Armstrong numbers between 1 and 1000.

## Exercise 5: Count Digits in a Number
**Difficulty:** Basic
**Concepts:** while loop, integer division, counting

Count how many digits a given integer has.

**Starter code:**
```python
n = abs(int(input("Enter an integer: ")))
count = 0

while n > 0:
    n //= 10
    count += 1

print("Number of digits:", count)
```

**Task:** Handle the case where the input is 0 correctly (it has 1 digit).
