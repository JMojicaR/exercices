## Exercise 1: Sum of Natural Numbers

**Difficulty:** Basic

### Problem
Write a function that returns the sum of all natural numbers from `1` to `n` (1 + 2 + ... + n).

**Given Input:** `sum_natural(10)`

**Expected Output:**
```
55
```

### Concepts
- `for` loop with `range()`
- Accumulator pattern
- Arithmetic progression (optional: `n * (n + 1) // 2`)

### Example / Starter Code

```python
def sum_natural(n):
    total = 0
    for i in range(1, n + 1):
        total += i
    return total

print(sum_natural(10))   # 55
print(sum_natural(100))  # 5050
```

## Exercise 2: Find the Largest Number in a List

**Difficulty:** Basic

### Problem
Write a function that returns the largest number in a list of integers without using the built-in `max()`.

**Given Input:** `largest([3, 7, 2, 9, 5])`

**Expected Output:**
```
9
```

### Concepts
- Iterating over a list with `for`
- Tracking a running maximum
- Comparisons with `if`

### Example / Starter Code

```python
def largest(numbers):
    biggest = numbers[0]
    for num in numbers:
        if num > biggest:
            biggest = num
    return biggest

print(largest([3, 7, 2, 9, 5]))   # 9
print(largest([-1, -5, -3]))      # -1
```

## Exercise 3: Prime Number Check

**Difficulty:** Basic

### Problem
Write a function that returns `True` if a number is prime and `False` otherwise. A prime is greater than 1 and divisible only by 1 and itself.

**Given Input:**
- `is_prime(7)`
- `is_prime(10)`

**Expected Output:**
- `True`
- `False`

### Concepts
- Modulo operator (`%`)
- Divisibility testing up to `sqrt(n)`
- Early `return` / `break`

### Example / Starter Code

```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

print(is_prime(7))    # True
print(is_prime(10))   # False
print(is_prime(2))    # True
```

## Exercise 4: Reverse a String

**Difficulty:** Basic

### Problem
Write a function that returns its input string reversed.

**Given Input:** `reverse_string("hello")`

**Expected Output:**
```
olleh
```

### Concepts
- String slicing with a negative step (`[::-1]`)
- (Alternative) building a result with a loop

### Example / Starter Code

```python
def reverse_string(s):
    return s[::-1]

print(reverse_string("hello"))     # olleh
print(reverse_string("Python"))    # nohtyP
```

## Exercise 5: Celsius ↔ Fahrenheit Converter

**Difficulty:** Basic

### Problem
Write two functions: `to_fahrenheit(c)` and `to_celsius(f)` using the formulas `F = C * 9/5 + 32` and `C = (F - 32) * 5/9`.

**Given Input:**
- `to_fahrenheit(0)` → `32.0`
- `to_celsius(32)` → `0.0`

**Expected Output:**
```
32.0
0.0
```

### Concepts
- Defining and calling functions
- Arithmetic with floats
- Returning computed values

### Example / Starter Code

```python
def to_fahrenheit(c):
    return c * 9 / 5 + 32

def to_celsius(f):
    return (f - 32) * 5 / 9

print(to_fahrenheit(0))    # 32.0
print(to_celsius(32))      # 0.0
print(to_fahrenheit(100))  # 212.0
```
