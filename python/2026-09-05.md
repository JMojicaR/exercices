## 2. Even or Odd
- **Description**: Ask the user for a number and print whether it is even or odd. Use the modulo operator to determine divisibility by 2.
- **Difficulty**: Beginner
- **Concepts**: `input()`, type conversion with `int()`, `%` operator, `if/else`
- **Example/Starter code**:
```python
number = int(input("Enter a number: "))
if number % 2 == 0:
    print(f"{number} is even")
else:
    print(f"{number} is odd")
```

## 3. Sum of First N Numbers
- **Description**: Take a positive integer N and print the sum of all integers from 1 to N (i.e. 1 + 2 + ... + N).
- **Difficulty**: Beginner
- **Concepts**: `for` loops, `range()`, accumulation, `input()`
- **Example/Starter code**:
```python
n = int(input("Enter a positive integer: "))
total = 0
for i in range(1, n + 1):
    total += i
print(f"Sum from 1 to {n} is {total}")
```

## 4. Reverse a String

- **Difficulty**: Beginner

## 5. FizzBuzz
- **Description**: Print the numbers from 1 to N. For multiples of 3 print "Fizz", for multiples of 5 print "Buzz", and for multiples of both print "FizzBuzz".
- **Difficulty**: Beginner
- **Concepts**: `for` loops, `%` operator, `if/elif/else`, `range()`
- **Example/Starter code**:
```python
n = int(input("Enter N: "))
for i in range(1, n + 1):
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
```
