## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** `for` loop, accumulator variable, `range()`, `math.factorial`

Compute `n! = 1 × 2 × … × n` (with `0! = 1`).

**Starter code:**
```python
def factorial(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

print(factorial(5))  # expected: 120
print(factorial(0))  # expected: 1
```

**Task:** Rewrite the function using recursion — `factorial(n) = n * factorial(n - 1)` with base case `factorial(0) = 1`.

## Exercise 2: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** `for` loop, tuple assignment, variable swapping, list building

Print the first `n` Fibonacci numbers (`0, 1, 1, 2, 3, 5, 8, …`).

**Starter code:**
```python
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        print(a, end=" ")
        a, b = b, a + b
    print()

fibonacci(7)  # expected: 0 1 1 2 3 5 8
```

**Task:** Return the numbers as a `list` instead of printing them, and handle `n = 0` (empty list) and `n = 1` (just `[0]`).

## Exercise 3: Check Prime Number
**Difficulty:** Basic
**Concepts:** modulo `%`, `for` + `range`, early return, `math.sqrt`

Return `True` if a number is prime, `False` otherwise.

**Starter code:**
```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

print(is_prime(7))   # expected: True
print(is_prime(10))  # expected: False
```

**Task:** Write a second function that returns a list of all primes up to a given limit.

## Exercise 4: Sum of Digits
**Difficulty:** Basic
**Concepts:** `//` (floor division), `%` (modulo), `while` loop, digit extraction

Return the sum of the individual digits of a number.

**Starter code:**
```python
def sum_of_digits(n):
    total = 0
    while n > 0:
        total += n % 10
        n //= 10
    return total

print(sum_of_digits(1234))  # expected: 10
```

**Task:** Rewrite it using `sum(int(ch) for ch in str(n))` and compare both approaches.

## Exercise 5: Greatest Common Divisor (GCD)
**Difficulty:** Basic
**Concepts:** Euclidean algorithm, `while` loop, `%`, `math.gcd`

Compute the greatest common divisor of two integers.

**Starter code:**
```python
def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a

print(gcd(48, 18))  # expected: 6
print(gcd(100, 35)) # expected: 5
```

**Task:** Add an `lcm(a, b)` function using `lcm(a, b) = a * b // gcd(a, b)`.
