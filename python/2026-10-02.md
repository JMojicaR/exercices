## Exercise 1: Guess the Number
**Difficulty:** Basic
**Concepts:** `random` module, `while` loop, conditionals, `int()` conversion, input validation.

Write a program that picks a random number between 1 and 20 and lets the user guess it, giving "too high" / "too low" hints until they get it right.

**Starter code:**
```python
import random

secret = random.randint(1, 20)
guess = None
attempts = 0

while guess != secret:
    guess = int(input("Guess a number (1-20): "))
    attempts += 1
    if guess < secret:
        print("Too low!")
    elif guess > secret:
        print("Too high!")

print(f"Correct! You took {attempts} attempts.")
```

**Task:** Add a limit of 5 attempts — after that, print "Game over" and reveal the secret number.

## Exercise 2: Fibonacci Series
**Difficulty:** Basic
**Concepts:** Loops (`while`/`for`), multiple assignment, lists, sequence generation.

Write a program that prints the first `n` Fibonacci numbers (0, 1, 1, 2, 3, 5, …), where `n` is read from the user.

**Starter code:**
```python
n = int(input("How many Fibonacci numbers? "))

a, b = 0, 1
count = 0

while count < n:
    print(a, end=" ")
    a, b = b, a + b
    count += 1
print()
```

**Task:** Store the sequence in a list and print the list, then print only the even-indexed Fibonacci numbers.

## Exercise 3: Word Counter
**Difficulty:** Basic
**Concepts:** String splitting (`split()`), dictionaries, `for` loops, counting.

Read a sentence and count how many times each word appears, printing a word-frequency table.

**Starter code:**
```python
sentence = input("Enter a sentence: ").lower()
words = sentence.split()

counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1

for word, freq in counts.items():
    print(f"{word}: {freq}")
```

**Task:** Sort the output so the most frequent words are printed first.

## Exercise 4: Largest and Smallest in a List
**Difficulty:** Basic
**Concepts:** Lists, loops, comparison logic, no use of `max()`/`min()`.

Write a program that finds the largest and smallest numbers in a list *without* using the built-in `max()` or `min()`.

**Starter code:**
```python
numbers = [34, 7, 23, 32, 5, 62, 18]

largest = numbers[0]
smallest = numbers[0]

for num in numbers:
    if num > largest:
        largest = num
    if num < smallest:
        smallest = num

print("Largest:", largest)
print("Smallest:", smallest)
```

**Task:** Let the user enter the numbers one at a time (ending with an empty line) instead of a fixed list.

## Exercise 5: Rock, Paper, Scissors
**Difficulty:** Basic
**Concepts:** `random` module, string comparison, `while` loop, `input()`, conditionals.

Build a Rock-Paper-Scissors game where the user plays against the computer.

**Starter code:**
```python
import random

choices = ["rock", "paper", "scissors"]
computer = random.choice(choices)

player = input("Choose rock, paper, or scissors: ").lower()
print("Computer chose:", computer)

if player == computer:
    print("It's a tie!")
elif (player == "rock" and computer == "scissors") or \
     (player == "paper" and computer == "rock") or \
     (player == "scissors" and computer == "paper"):
    print("You win!")
else:
    print("You lose!")
```

**Task:** Wrap the game in a loop so it keeps playing until the user types "quit", and keep a running score.
