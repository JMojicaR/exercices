## 1. Temperature Converter (Celsius ↔ Fahrenheit)
**Description:** Write a program that asks the user for a temperature and a scale ("C" or "F"), then converts it to the other scale. Use `C = (F - 32) * 5/9` and `F = C * 9/5 + 32`.
**Difficulty:** Basic
**Concepts:** Functions, arithmetic, `input()`, `float()`, conditionals, f-strings.
**Starter code:**
```python
def to_fahrenheit(c):
    return c * 9 / 5 + 32

def to_celsius(f):
    return (f - 32) * 5 / 9

temp = float(input("Enter temperature: "))
scale = input("Scale (C/F): ").upper()

if scale == "C":
    print(f"{temp}C = {to_fahrenheit(temp):.1f}F")
elif scale == "F":
    print(f"{temp}F = {to_celsius(temp):.1f}C")
else:
    print("Unknown scale")
```

## 2. Count Vowels in a String
**Description:** Read a sentence from the user and count how many vowels (a, e, i, o, u) it contains, ignoring case.
**Difficulty:** Basic
**Concepts:** String iteration, `in` operator, `.lower()`, counter variable.
**Starter code:**
```python
text = input("Enter a sentence: ").lower()
vowels = "aeiou"
count = 0
for ch in text:
    if ch in vowels:
        count += 1
print(f"Vowel count: {count}")
```

## 3. Multiplication Table
**Description:** Given a number N from the user, print its multiplication table from 1 to 10 in the form `N x i = result`.
**Difficulty:** Basic
**Concepts:** `for` loop, `range()`, formatted output.
**Starter code:**
```python
n = int(input("Enter a number: "))
for i in range(1, 11):
    print(f"{n} x {i} = {n * i}")
```

## 4. Palindrome Check
**Description:** Check whether a given word or phrase reads the same forwards and backwards (ignoring spaces and case).
**Difficulty:** Basic
**Concepts:** String reversal, `.replace()`, `.lower()`, string slicing `[::-1]`.
**Starter code:**
```python
text = input("Enter a word: ").lower().replace(" ", "")
if text == text[::-1]:
    print("It is a palindrome")
else:
    print("It is NOT a palindrome")
```

## 5. Fibonacci Sequence (First N Terms)
**Description:** Ask the user for N and print the first N terms of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...).
**Difficulty:** Basic
**Concepts:** Loops, variable swapping, lists, accumulator pattern.
**Starter code:**
```python
n = int(input("How many terms? "))
a, b = 0, 1
for _ in range(n):
    print(a, end=" ")
    a, b = b, a + b
print()
```
