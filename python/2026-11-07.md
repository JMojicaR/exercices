## Exercise 1: Even or Odd Checker
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator `%`, comparison, `print()`

Write a function that takes an integer and prints whether it is even or odd.

**Starter code:**
```python
def even_or_odd(n):
    if n % 2 == 0:
        print(f"{n} is even")
    else:
        print(f"{n} is odd")

even_or_odd(4)   # 4 is even
even_or_odd(7)   # 7 is odd
```

**Task:** Read the number from the user with `input()`, convert it with `int()`, and handle non-numeric input gracefully with a `try`/`except`.

## Exercise 2: Print Numbers 1 to N
**Difficulty:** Basic
**Concepts:** `for` loop, `range()`, loop variable

Print every integer from 1 up to and including `N`, one per line.

**Starter code:**
```python
def print_range(n):
    for i in range(1, n + 1):
        print(i)

print_range(5)
# 1
# 2
# 3
# 4
# 5
```

**Task:** Change `range()` so the function prints only the odd numbers from 1 to `N` (`range(1, n + 1, 2)`). Then add a step parameter so the caller controls the increment.

## Exercise 3: Countdown
**Difficulty:** Basic
**Concepts:** `while` loop, decrementing a counter, loop condition

Print a countdown from `N` down to 1, then print `"Liftoff!"`.

**Starter code:**
```python
def countdown(n):
    while n > 0:
        print(n)
        n -= 1
    print("Liftoff!")

countdown(5)
# 5
# 4
# 3
# 2
# 1
# Liftoff!
```

**Task:** Guard against invalid input — if `n <= 0`, print `"Nothing to count"`. Then rewrite the same countdown using a `for` loop with `range(n, 0, -1)`.

## Exercise 4: Grade Classifier
**Difficulty:** Basic
**Concepts:** `if`/`elif`/`else` ladder, comparison operators, multiple conditions

Convert a numeric score (0–100) into a letter grade using a standard scale: 90+ → A, 80–89 → B, 70–79 → C, 60–69 → D, below 60 → F.

**Starter code:**
```python
def classify(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    elif score >= 60:
        return "D"
    else:
        return "F"

print(classify(95))  # A
print(classify(83))  # B
print(classify(57))  # F
```

**Task:** Add input validation — if the score is outside 0–100, return `"Invalid"`. Then add a `+`/`-` suffix for the last digit (e.g. 87 → `B+`).

## Exercise 5: Sum of Even Numbers up to N
**Difficulty:** Basic
**Concepts:** `for` loop + `if` condition, accumulator variable, `+=`

Return the sum of every even number from 2 up to and including `N`.

**Starter code:**
```python
def sum_even(n):
    total = 0
    for i in range(1, n + 1):
        if i % 2 == 0:
            total += i
    return total

print(sum_even(10))  # 2 + 4 + 6 + 8 + 10 = 30
print(sum_even(7))   # 2 + 4 + 6 = 12
```

**Task:** Rewrite using `range(2, n + 1, 2)` to skip the conditional entirely. Then write a `sum_odd(n)` variant and compare the two results against `n*(n+1)//2` for a given `n`.
