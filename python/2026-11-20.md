## Exercise 1: Create & Access a Dictionary
**Difficulty:** Basic
**Concepts:** `dict` literal, key access with `[]`, `.get()`, adding and updating entries

Build a dictionary of student grades, then read values safely.

**Starter code:**
```python
grades = {"Alice": 85, "Bob": 72, "Carol": 90}

print(grades["Alice"])        # 85
print(grades.get("Bob"))      # 72
print(grades.get("Dave"))     # None (no error)

grades["Dave"] = 78            # add a new key
grades["Bob"] = 75             # update an existing key
print(grades)                  # {'Alice': 85, 'Bob': 75, 'Carol': 90, 'Dave': 78}
```

**Task:** Add a second argument to `.get("Dave", ...)` so it returns `"Not found"` instead of `None`, and print it.

## Exercise 2: Count Character Frequencies
**Difficulty:** Basic
**Concepts:** looping over a string, `dict.get` as a counter, membership with `in`

Count how many times each character appears in a string.

**Starter code:**
```python
def char_count(text):
    counts = {}
    for ch in text:
        if ch in counts:
            counts[ch] += 1
        else:
            counts[ch] = 1
    return counts

print(char_count("hello"))   # {'h': 1, 'e': 1, 'l': 2, 'o': 1}
```

**Task:** Rewrite the `if`/`else` block as a single line using `counts.get(ch, 0)`.

## Exercise 3: Merge Two Dictionaries
**Difficulty:** Basic
**Concepts:** `dict.update()`, the `**` unpacking operator, key precedence on conflict

Combine two dictionaries into one, where the second one wins on duplicate keys.

**Starter code:**
```python
menu_a = {"coffee": 2.5, "tea": 1.8}
menu_b = {"tea": 2.0, "muffin": 3.2}

merged = menu_a.copy()
merged.update(menu_b)
print(merged)   # {'coffee': 2.5, 'tea': 2.0, 'muffin': 3.2}
```

**Task:** Produce the same result with a single expression: `merged2 = {**menu_a, **menu_b}` and confirm the two results are equal.

## Exercise 4: Find the Key with the Maximum Value
**Difficulty:** Basic
**Concepts:** iterating `.items()`, `max()` with a `key`, comparing values

Return the name of the student with the highest grade.

**Starter code:**
```python
grades = {"Alice": 85, "Bob": 72, "Carol": 90, "Dave": 78}

best_student = None
best_grade = -1
for name, grade in grades.items():
    if grade > best_grade:
        best_student = name
        best_grade = grade

print(best_student)   # Carol
```

**Task:** Replace the whole loop with `best = max(grades, key=grades.get)` and print `best`.

## Exercise 5: Nested Dictionaries & Comprehension
**Difficulty:** Basic
**Concepts:** nested `dict`, accessing inner keys, dictionary comprehension

Store each student's grades per subject, then compute each student's average.

**Starter code:**
```python
scores = {
    "Alice": {"math": 90, "english": 85},
    "Bob":   {"math": 70, "english": 78},
    "Carol": {"math": 88, "english": 95},
}

averages = {}
for name, subjects in scores.items():
    averages[name] = sum(subjects.values()) / len(subjects)

print(averages)   # {'Alice': 87.5, 'Bob': 74.0, 'Carol': 91.5}
```

**Task:** Rewrite the loop as a dictionary comprehension: `averages = {name: sum(s.values()) / len(s) for name, s in scores.items()}`.
