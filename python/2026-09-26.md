## Exercise 1: Temperature Converter (Celsius → Fahrenheit)
**Difficulty:** Basic
**Concepts:** Variables, arithmetic, type conversion (`float()`), f-strings.

Write a program that reads a temperature in Celsius and converts it to Fahrenheit using the formula `F = (C × 9/5) + 32`.

**Starter code:**
```python
celsius = float(input("Enter temperature in Celsius: "))

fahrenheit = (celsius * 9 / 5) + 32
print(f"{celsius}°C is {fahrenheit}°F")
```

**Task:** Extend it to also convert Fahrenheit back to Celsius using `C = (F − 32) × 5/9`.

## Exercise 2: Leap Year Checker
**Difficulty:** Basic
**Concepts:** Conditionals (`if`/`elif`/`else`), modulo (`%`), logical operators (`and`, `or`).

Write a program that reads a year and tells the user whether it is a leap year. A year is a leap year if it is divisible by 4, except centuries (divisible by 100) which must also be divisible by 400.

**Starter code:**
```python
year = int(input("Enter a year: "))

if year % 4 == 0:
    print("Leap year")
else:
    print("Not a leap year")
```

**Task:** Fix the logic so it correctly handles century years (e.g. 1900 is NOT a leap year, 2000 IS).

## Exercise 3: Multiplication Table
**Difficulty:** Basic
**Concepts:** Loops (`for`), `range()`, string formatting.

Write a program that prints the multiplication table (1 through 10) for a given number.

**Starter code:**
```python
n = int(input("Enter a number: "))

for i in range(1, 11):
    print(f"{n} x {i} = {n * i}")
```

**Task:** Print tables for all numbers from 1 to 5 using a nested loop.

## Exercise 4: Count Vowels in a String
**Difficulty:** Basic
**Concepts:** Strings, iteration, membership (`in`), string methods (`lower()`).

Write a program that counts how many vowels (a, e, i, o, u) appear in a given string.

**Starter code:**
```python
text = input("Enter some text: ").lower()
vowels = "aeiou"
count = 0

for char in text:
    if char in vowels:
        count += 1

print("Vowel count:", count)
```

**Task:** Also count consonants (letters that are not vowels, ignoring spaces and punctuation).
