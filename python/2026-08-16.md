## Exercise 1: Even or Odd Check

**Difficulty:** Basic

### Problem
Write a function that takes an integer and returns `True` if it is even, `False` if it is odd.

**Given Input:**
- `is_even(4)`
- `is_even(7)`

**Expected Output:**
- `True`
- `False`

### Concepts
- Modulo operator (`%`)
- Boolean return values
- Function definition and arguments

### Example / Starter Code

```python
def is_even(n):
    return n % 2 == 0

print(is_even(4))    # True
print(is_even(7))    # False
```

## Exercise 2: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a function that returns the factorial of a non-negative integer `n` (n! = 1 × 2 × … × n). Return `1` for `0`.

**Given Input:** `factorial(5)`

**Expected Output:**
```
120
```

### Concepts
- `for` loops with `range()`
- Accumulator pattern
- Multiplying an accumulating variable

### Example / Starter Code

```python
def factorial(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

print(factorial(5))    # 120
print(factorial(0))    # 1
```

## Exercise 3: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a function that counts how many vowels (`a, e, i, o, u`) appear in a string, ignoring case.

**Given Input:** `count_vowels("Hello World")`

**Expected Output:**
```
3
```

### Concepts
- `.lower()` for case-insensitive comparison
- `in` membership test
- Generator expressions with `sum()`

### Example / Starter Code

```python
def count_vowels(s):
    vowels = "aeiou"
    return sum(1 for ch in s.lower() if ch in vowels)

print(count_vowels("Hello World"))   # 3
print(count_vowels("Python"))        # 1
```

## Exercise 4: FizzBuzz

**Difficulty:** Basic

### Problem
Write a function that prints the numbers from `1` to `n`. For multiples of `3`, print `"Fizz"`; for multiples of `5`, print `"Buzz"`; for multiples of both, print `"FizzBuzz"`; otherwise print the number.

**Given Input:** `fizzbuzz(15)`

**Expected Output (first lines):**
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

### Concepts
- `for` loop with `range()`
- `if / elif / else` branching
- Divisibility via the modulo operator

### Example / Starter Code

```python
def fizzbuzz(n):
    for i in range(1, n + 1):
        if i % 15 == 0:
            print("FizzBuzz")
        elif i % 3 == 0:
            print("Fizz")
        elif i % 5 == 0:
            print("Buzz")
        else:
            print(i)

fizzbuzz(15)
```

## Exercise 5: Palindrome Check

**Difficulty:** Basic

### Problem
Write a function that returns `True` if a string reads the same forwards and backwards (ignoring case), and `False` otherwise.

**Given Input:**
- `is_palindrome("racecar")`
- `is_palindrome("hello")`

**Expected Output:**
- `True`
- `False`

### Concepts
- String slicing with a negative step (`[::-1]`)
- `.lower()` normalization
- String comparison

### Example / Starter Code

```python
def is_palindrome(s):
    s = s.lower()
    return s == s[::-1]

print(is_palindrome("racecar"))   # True
print(is_palindrome("hello"))     # False
```
