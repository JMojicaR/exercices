## Exercise 1: FizzBuzz
- **Description**: Write a program that prints the numbers from 1 to 100. For multiples of 3, print "Fizz" instead of the number. For multiples of 5, print "Buzz". For numbers that are multiples of both 3 and 5, print "FizzBuzz". This classic exercise tests your understanding of loops, conditionals, and the modulo operator.
- **Difficulty**: Beginner
- **Concepts**: for loops, if/elif/else conditionals, modulo operator, print function
- **Example/Starter Code**:
```python
def fizzbuzz():
    for i in range(1, 101):
        if i % 3 == 0 and i % 5 == 0:
            print("FizzBuzz")
        elif i % 3 == 0:
            print("Fizz")
        elif i % 5 == 0:
            print("Buzz")
        else:
            print(i)

# Uncomment to run:

```

## Exercise 2: Palindrome Checker
- **Description**: Write a function that checks whether a given string is a palindrome — a word, phrase, or sequence that reads the same forwards and backwards. Ignore spaces, punctuation, and capitalization. Examples: "racecar" → True, "A man a plan a canal Panama" → True, "hello" → False.
- **Difficulty**: Beginner
- **Concepts**: string manipulation, string methods (lower, replace), slicing, functions
- **Example/Starter Code**:
```python
def is_palindrome(s: str) -> bool:
    # Remove non-alphanumeric characters and convert to lowercase
    cleaned = ''.join(char.lower() for char in s if char.isalnum())
    # Compare the string with its reverse
    return cleaned == cleaned[::-1]

# Test cases
print(is_palindrome("racecar"))                       # True
print(is_palindrome("A man, a plan, a canal: Panama")) # True
print(is_palindrome("hello"))                          # False
```

## Exercise 3: Temperature Converter
- **Description**: Write a program that converts temperatures between Celsius and Fahrenheit. The user should be able to choose the conversion direction (C→F or F→C) and enter a temperature value. Display the converted result rounded to one decimal place. Formulas: F = (C × 9/5) + 32 and C = (F − 32) × 5/9.
- **Difficulty**: Beginner
- **Concepts**: user input (input()), type conversion (float), functions, conditionals, f-strings
- **Example/Starter Code**:
```python
def celsius_to_fahrenheit(celsius: float) -> float:
    return (celsius * 9/5) + 32

def fahrenheit_to_celsius(fahrenheit: float) -> float:
    return (fahrenheit - 32) * 5/9

def main():
    print("Temperature Converter")
    print("1. Celsius to Fahrenheit")
    print("2. Fahrenheit to Celsius")

    choice = input("Choose an option (1 or 2): ")

    if choice == "1":
        temp = float(input("Enter temperature in Celsius: "))
        result = celsius_to_fahrenheit(temp)
        print(f"{temp}°C = {result:.1f}°F")
    elif choice == "2":
        temp = float(input("Enter temperature in Fahrenheit: "))
        result = fahrenheit_to_celsius(temp)
        print(f"{temp}°F = {result:.1f}°C")
    else:
        print("Invalid choice!")

# Uncomment to run:
# main()
```

## Exercise 4: Number Guessing Game
- **Description**: Build a game where the program randomly selects a number between 1 and 100, and the player has to guess it. After each guess, the program tells the player whether the guess is too high, too low, or correct. Track the number of attempts and display it when the player wins. Add a limit of 10 guesses to make it challenging.
- **Difficulty**: Beginner
- **Concepts**: random module, while loops, if/elif/else, user input, counters, break statement
- **Example/Starter Code**:
```python
import random

def number_guessing_game():
    secret_number = random.randint(1, 100)
    attempts = 0
    max_attempts = 10

    print("I'm thinking of a number between 1 and 100.")
    print(f"You have {max_attempts} guesses!")

    while attempts < max_attempts:
        try:
            guess = int(input(f"Guess #{attempts + 1}: "))
        except ValueError:
            print("Please enter a valid number.")
            continue

        attempts += 1

        if guess < secret_number:
            print("Too low!")
        elif guess > secret_number:
            print("Too high!")
        else:
            print(f"Correct! You guessed it in {attempts} attempts.")
            return

    print(f"Out of guesses! The number was {secret_number}.")

# Uncomment to run:
# number_guessing_game()
```

## Exercise 5: Simple Calculator
- **Description**: Create a command-line calculator that takes two numbers and an operator (+, -, *, /) as input and returns the result. Handle edge cases such as division by zero and invalid operators. The program should keep running until the user types "quit". Use a dictionary to map operator symbols to functions for clean, extensible code.
- **Difficulty**: Beginner
- **Concepts**: dictionaries, functions as values, while loops, exception handling (ZeroDivisionError), user input
- **Example/Starter Code**:
```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "Error: Cannot divide by zero!"
    return a / b

OPERATORS = {
    "+": add,
    "-": subtract,
    "*": multiply,
    "/": divide,
}

def simple_calculator():
    print("Simple Calculator (type 'quit' to exit)")
    print("Supported operators: +, -, *, /")

    while True:
        command = input("\nEnter calculation (e.g., 5 + 3): ").strip()

        if command.lower() == "quit":
            print("Goodbye!")
            break

        parts = command.split()
        if len(parts) != 3:
            print("Invalid format. Use: number operator number")
            continue

        try:
            num1 = float(parts[0])
            operator = parts[1]
            num2 = float(parts[2])
        except ValueError:
            print("Invalid numbers. Please try again.")
            continue

        if operator not in OPERATORS:
            print(f"Unknown operator '{operator}'. Use +, -, *, or /")
            continue

        result = OPERATORS[operator](num1, num2)
        print(f"{num1} {operator} {num2} = {result}")

# Uncomment to run:
# simple_calculator()
```
