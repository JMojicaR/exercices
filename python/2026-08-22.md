## Exercise 1: Check Leap Year

**Difficulty:** Basic

### Problem
Write a function that takes a year as input and returns `True` if it is a leap year, otherwise `False`. A year is a leap year if it is divisible by 4, except century years which must be divisible by 400.

**Given Input:** `is_leap_year(2024)`

**Expected Output:**
```
2000 -> Leap year
1900 -> Not a leap year
2024 -> Leap year
2023 -> Not a leap year
```

### Concepts
- Modulo operator (`%`)
- Boolean logic (`and`, `or`)
- `if` / `else` conditions

### Example / Starter Code

```python
def is_leap_year(year):
    if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
        return True
    return False

# Driver
for y in [2000, 1900, 2024, 2023]:
    print(y, "->", "Leap year" if is_leap_year(y) else "Not a leap year")
```

## Exercise 2: GCD of Two Numbers

**Difficulty:** Basic

### Problem
Write a function that computes the Greatest Common Divisor (GCD) of two positive integers using the Euclidean algorithm (repeated modulo).

**Given Input:** `gcd(48, 18)`

**Expected Output:**
```
GCD of 48 and 18: 6
```

### Concepts
- `while` loop
- Euclidean algorithm (`a, b = b, a % b`)
- Variable reassignment / tuple swapping

### Example / Starter Code

```python
def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a

# Driver
print("GCD of 48 and 18:", gcd(48, 18))
```

## Exercise 3: Count Digits in a Number

**Difficulty:** Basic

### Problem
Write a function that counts how many digits are in a given integer by repeatedly dividing by 10. Handle zero as a special case (it has 1 digit).

**Given Input:** `count_digits(12345)`

**Expected Output:**
```
Digits in 12345: 5
Digits in 0: 1
```

### Concepts
- Integer (floor) division `//`
- `while` loop with a counter
- Handling the zero edge case

### Example / Starter Code

```python
def count_digits(n):
    n = abs(n)
    if n == 0:
        return 1
    count = 0
    while n > 0:
        n //= 10
        count += 1
    return count

# Driver
print("Digits in 12345:", count_digits(12345))
print("Digits in 0:", count_digits(0))
```

## Exercise 4: Sum of Even Numbers in a Range

**Difficulty:** Basic

### Problem
Write a function that returns the sum of all even numbers between `start` and `end` (inclusive).

**Given Input:** `sum_even(1, 10)`

**Expected Output:**
```
Sum of even numbers from 1 to 10: 30
```

### Concepts
- `for` loop with `range()`
- Modulo to test evenness
- Accumulator variable

### Example / Starter Code

```python
def sum_even(start, end):
    total = 0
    for num in range(start, end + 1):
        if num % 2 == 0:
            total += num
    return total

# Driver
print("Sum of even numbers from 1 to 10:", sum_even(1, 10))
```

## Exercise 5: Multiplication Table

**Difficulty:** Basic

### Problem
Write a function that prints the multiplication table (1 to 10) for a given number.

**Given Input:** `multiplication_table(5)`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

### Concepts
- `for` loop with `range(1, 11)`
- f-strings for formatted output
- Multiplication and string formatting

### Example / Starter Code

```python
def multiplication_table(n):
    for i in range(1, 11):
        print(f"{n} x {i} = {n * i}")

# Driver
multiplication_table(5)
```
