## 1. Temperature Converter
- **Description**: Write a program that converts a temperature from Celsius to Fahrenheit using the formula `F = C × 9/5 + 32`. Ask the user for a Celsius value and print the Fahrenheit result.
- **Difficulty**: Beginner
- **Concepts**: `input()`, `float()` type conversion, arithmetic operators, f-strings
- **Example/Starter code**:
```python
celsius = float(input("Enter temperature in Celsius: "))
fahrenheit = celsius * 9 / 5 + 32
print(f"{celsius}°C = {fahrenheit}°F")
```

## 2. Count the Vowels
- **Description**: Read a string from the user and count how many vowels (`a`, `e`, `i`, `o`, `u`) it contains, ignoring case.
- **Difficulty**: Beginner
- **Concepts**: Strings, `.lower()`, loops, `in` operator, generators
- **Example/Starter code**:
```python
text = input("Enter a string: ").lower()
vowels = "aeiou"
count = sum(1 for ch in text if ch in vowels)
print(f"Vowel count: {count}")
```

## 3. Multiplication Table
- **Description**: Given a number, print its multiplication table from 1 to 10 in the form `n x i = result`.
- **Difficulty**: Beginner
- **Concepts**: `for` loops, `range()`, f-string formatting, `input()`
- **Example/Starter code**:
```python
n = int(input("Enter a number: "))
for i in range(1, 11):
    print(f"{n} x {i} = {n * i}")
```

## 4. Largest of Three Numbers

- **Difficulty**: Beginner

## 5. Leap Year Check
- **Description**: Determine whether a given year is a leap year. A year is a leap year if it is divisible by 4, except years divisible by 100 unless they are also divisible by 400.
- **Difficulty**: Beginner
- **Concepts**: `if/elif/else`, modulo operator `%`, boolean logic with `and`/`or`
- **Example/Starter code**:
```python
year = int(input("Enter a year: "))
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year} is a leap year")
else:
    print(f"{year} is not a leap year")
```
