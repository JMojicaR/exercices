## Exercise 1: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** loops, variables, swapping

Write a program that prints the first `n` numbers of the Fibonacci sequence. Each number (after the first two) is the sum of the two before it.

**Starter code:**
```python
n = int(input("How many Fibonacci numbers? "))
a, b = 0, 1
for _ in range(n):
    print(a, end=" ")
    a, b = b, a + b
```

**Task:** Modify the loop so it prints only the even Fibonacci numbers up to the first `n` terms.

## Exercise 2: Sum of Digits of an Integer
**Difficulty:** Basic
**Concepts:** while loop, modulo, integer division

Take a positive integer from the user and print the sum of its digits.

**Starter code:**
```python
number = int(input("Enter a positive integer: "))
total = 0
while number > 0:
    total += number % 10
    number //= 10
print("Sum of digits:", total)
```

**Task:** Also print the product of the digits alongside the sum.

## Exercise 3: GCD of Two Numbers
**Difficulty:** Basic
**Concepts:** functions, while loop, Euclidean algorithm

Compute the greatest common divisor (GCD) of two integers using the Euclidean algorithm.

**Starter code:**
```python
def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a

x = int(input("Enter first number: "))
y = int(input("Enter second number: "))
print("GCD:", gcd(x, y))
```

**Task:** Extend the program to also print the least common multiple (LCM) of the two numbers.

## Exercise 5: Simple Calculator
**Difficulty:** Basic
**Concepts:** input, if/elif, arithmetic operators

Build a calculator that reads two numbers and an operator (`+`, `-`, `*`, `/`) and prints the result.

**Starter code:**
```python
a = float(input("Enter first number: "))
b = float(input("Enter second number: "))
op = input("Enter operator (+, -, *, /): ")

if op == "+":
    print(a + b)
elif op == "-":
    print(a - b)
elif op == "*":
    print(a * b)
elif op == "/":
    print(a / b)
else:
    print("Invalid operator")
```

**Task:** Add a check that prevents division by zero and prints a friendly message instead.
