## Exercise 3: Add Instance Methods
**Difficulty:** Basic
**Concepts:** methods, `self`, return values, calling methods on objects

Add methods to `Book` that compute derived values from the object's own attributes.

**Starter code:**
```python
class Book:
    def __init__(self, title, author, year, price):
        self.title = title
        self.author = author
        self.year = year
        self.price = price

    def age(self, current_year):
        return current_year - self.year

    def discount(self, percent):
        return self.price * (1 - percent / 100)

book = Book("Dune", "Frank Herbert", 1965, 15.99)
print(book.age(2026))
print(f"{book.discount(20):.2f}")
```

## Exercise 4: Encapsulation with @property
**Difficulty:** Basic
**Concepts:** `@property`, getter/setter, private attribute convention (`_price`), validation

Protect the `price` attribute so it can't be set to a negative value by routing access through a property.

**Starter code:**
```python
class Book:
    def __init__(self, title, author, year, price):
        self.title = title
        self.author = author
        self.year = year
        self._price = price

    @property
    def price(self):
        return self._price

    @price.setter
    def price(self, value):
        if value < 0:
            raise ValueError("price cannot be negative")
        self._price = value

book = Book("1984", "George Orwell", 1949, 12.50)
print(book.price)
book.price = 10.00
print(book.price)
```

## Exercise 5: A Library That Holds Books
**Difficulty:** Basic
**Concepts:** composition, a class holding a list of objects, methods that search and summarize

Build a `Library` class that stores `Book` objects and can add, list, and find them.

**Starter code:**
```python
class Book:
    def __init__(self, title, author, year):
        self.title = title
        self.author = author
        self.year = year

    def __str__(self):
        return f"{self.title} by {self.author} ({self.year})"

class Library:
    def __init__(self):
        self.books = []

    def add(self, book):
        self.books.append(book)

    def find(self, title):
        for b in self.books:
            if b.title.lower() == title.lower():
                return b
        return None

    def list_books(self):
        for b in self.books:
            print(b)

lib = Library()
lib.add(Book("Dune", "Frank Herbert", 1965))
lib.add(Book("1984", "George Orwell", 1949))
lib.list_books()
print(lib.find("dune"))
```

**Task:** Add a `count()` method and a `books_by_year(year)` method that returns a list of all books published in a given year.
