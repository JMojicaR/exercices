## Exercise 1: Palindrome Check
**Difficulty:** Basic
**Concepts:** strings, slicing, conditional logic

Write a program that reads a word and tells the user whether it is a palindrome (reads the same forwards and backwards), ignoring letter case.

**Starter code:**
```python
word = input("Enter a word: ").lower()
if word == word[::-1]:
    print(word, "is a palindrome")
else:
    print(word, "is not a palindrome")
```

**Task:** Extend it so it also checks whether a full sentence is a palindrome, ignoring spaces and punctuation.

## Exercise 2: Prime Number Check
**Difficulty:** Basic
**Concepts:** for loop, modulo, break, boolean flags

Read a positive integer and print whether it is prime (only divisible by 1 and itself).

**Starter code:**
```python
n = int(input("Enter a positive integer: "))
is_prime = n > 1
for i in range(2, int(n ** 0.5) + 1):
    if n % i == 0:
        is_prime = False
        break
print(n, "is prime" if is_prime else "is not prime")
```

**Task:** Print all prime numbers between 2 and the given number.

## Exercise 3: Factorial
**Difficulty:** Basic
**Concepts:** functions, loops, or recursion

Compute the factorial of a non-negative integer `n` (the product of all integers from 1 to n).

**Starter code:**
```python
def factorial(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

n = int(input("Enter a non-negative integer: "))
print(f"{n}! = {factorial(n)}")
```

**Task:** Rewrite `factorial` using recursion, then handle the `n == 0` case explicitly.

## Exercise 4: Count Vowels in a String
**Difficulty:** Basic
**Concepts:** strings, for loop, membership operator

Count how many vowels (a, e, i, o, u) appear in a user-entered string, case-insensitively.

**Starter code:**
```python
text = input("Enter some text: ").lower()
vowels = "aeiou"
count = 0
for ch in text:
    if ch in vowels:
        count += 1
print("Vowel count:", count)
```

**Task:** Also report the count of each individual vowel using a dictionary.

## Exercise 5: Average of a List
**Difficulty:** Basic
**Concepts:** lists, sum, len, input, split

Read a list of numbers from the user (space-separated) and print their average.

**Starter code:**
```python
raw = input("Enter numbers separated by spaces: ")
numbers = [int(x) for x in raw.split()]
average = sum(numbers) / len(numbers)
print("Average:", average)
```

**Task:** Guard against an empty input, and also print the smallest and largest values.
