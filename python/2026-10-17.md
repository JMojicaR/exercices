## Exercise 1: Sum of List Elements
**Difficulty:** Basic
**Concepts:** lists, `for` loop, accumulation, `sum()`

Read a list of numbers and print their total.

**Starter code:**
```python
numbers = [10, 20, 30, 40, 50]
total = 0
for n in numbers:
    total += n
print("Sum:", total)
```

**Task:** Rewrite it using Python's built-in `sum()` and also accept comma-separated numbers from the user.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** modulo operator (`%`), `if/else`

Check whether a number is even or odd.

**Starter code:**
```python
n = int(input("Enter an integer: "))
if n % 2 == 0:
    print(n, "is even")
else:
    print(n, "is odd")
```

**Task:** Print all even numbers from 1 to a user-supplied limit.

## Exercise 3: Celsius to Fahrenheit
**Difficulty:** Basic
**Concepts:** arithmetic, input/output, float conversion

Convert a temperature from Celsius to Fahrenheit using `F = C × 9/5 + 32`.

**Starter code:**
```python
celsius = float(input("Enter temperature in Celsius: "))
fahrenheit = (celsius * 9/5) + 32
print(f"{celsius}°C = {fahrenheit}°F")
```

**Task:** Add a function that also converts Fahrenheit back to Celsius (`C = (F − 32) × 5/9`).

## Exercise 4: Find the Smallest Number
**Difficulty:** Basic
**Concepts:** lists, comparison, `min()`

Find the smallest value in a list of numbers.

**Starter code:**
```python
numbers = [45, 12, 78, 4, 33]
smallest = numbers[0]
for n in numbers:
    if n < smallest:
        smallest = n
print("Smallest:", smallest)
```

**Task:** Solve the same problem using the built-in `min()` function.

## Exercise 5: Simple Interest
**Difficulty:** Basic
**Concepts:** variables, arithmetic, input

Calculate simple interest using `SI = (P × R × T) / 100`.

**Starter code:**
```python
principal = float(input("Principal amount: "))
rate = float(input("Annual rate (%): "))
time = float(input("Time (years): "))

interest = (principal * rate * time) / 100
print("Simple interest:", interest)
```

**Task:** Also print the total amount (principal + interest).
