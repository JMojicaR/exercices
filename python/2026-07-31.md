## Exercise 1: Hello World and Basic Input/Output

**Title:** Hello, Python! — Variables and User Input

**Description:** Write a Python program that asks the user for their name and age, then prints a personalized greeting including the year they were born (assume current year is 2026).

**Difficulty:** ★☆☆☆☆ (Very Easy)

**Concepts Practiced:**
- `print()` function
- `input()` function
- Variables and data types
- String formatting (f-strings)
- Basic arithmetic

**Starter Code:**
```python
# Exercise 1: Hello, Python!
name = input("Enter your name: ")
age = int(input("Enter your age: "))
birth_year = 2026 - age
print(f"Hello {name}! You were born in {birth_year}.")
```

## Exercise 2: Simple Calculator

**Title:** Basic Arithmetic Calculator

**Description:** Write a Python program that takes two numbers and an operator (+, -, *, /) from the user and performs the corresponding arithmetic operation. Handle division by zero gracefully.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Arithmetic operators (+, -, *, /)
- Conditional statements (`if`/`elif`/`else`)
- Type conversion (`int()`, `float()`)
- Error handling (division by zero)

**Starter Code:**
```python
# Exercise 2: Simple Calculator
num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))
operator = input("Enter operator (+, -, *, /): ")

if operator == "+":
    result = num1 + num2
elif operator == "-":
    result = num1 - num2
elif operator == "*":
    result = num1 * num2
elif operator == "/":
    if num2 != 0:
        result = num1 / num2
    else:
        result = "Error: Division by zero"
else:
    result = "Invalid operator"

print(f"Result: {result}")
```

## Exercise 3: Even or Odd Checker

**Title:** Even or Odd Number Identifier

**Description:** Write a Python program that takes an integer from the user and determines whether it is even or odd. Extend it to also check if the number is positive, negative, or zero.

**Difficulty:** ★☆☆☆☆ (Very Easy)

**Concepts Practiced:**
- Modulo operator (`%`)
- Conditional statements
- Comparison operators
- Nested conditions

**Starter Code:**
```python
# Exercise 3: Even or Odd Checker
number = int(input("Enter an integer: "))

# Check even/odd
if number % 2 == 0:
    print(f"{number} is even.")
else:
    print(f"{number} is odd.")

# Check sign
if number > 0:
    print("It is positive.")
elif number < 0:
    print("It is negative.")
else:
    print("It is zero.")
```

## Exercise 4: FizzBuzz

**Title:** Classic FizzBuzz Challenge

**Description:** Write a Python program that prints numbers from 1 to 50. For multiples of 3, print "Fizz" instead of the number. For multiples of 5, print "Buzz". For numbers that are multiples of both 3 and 5, print "FizzBuzz".

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- `for` loops
- `range()` function
- Modulo operator
- Conditional statements (`if`/`elif`/`else`)
- String output formatting

**Starter Code:**
```python
# Exercise 4: FizzBuzz
for i in range(1, 51):
    if i % 3 == 0 and i % 5 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
```

## Exercise 5: List Operations

**Title:** List Manipulation — Sum, Max, Min, and Filter

**Description:** Write a Python program that creates a list of 10 integers (user-provided or predefined). Perform the following operations:
1. Calculate the sum of all elements
2. Find the maximum and minimum values
3. Create a new list containing only even numbers
4. Reverse the list and print it

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Python lists
- List methods (`append`, `reverse`)
- List comprehensions
- Built-in functions (`sum`, `max`, `min`)
- Iteration

**Starter Code:**
```python
# Exercise 5: List Operations
numbers = [12, 7, 9, 24, 18, 5, 3, 30, 15, 8]

# 1. Sum
total = sum(numbers)
print(f"Sum: {total}")

# 2. Max and Min
print(f"Maximum: {max(numbers)}")
print(f"Minimum: {min(numbers)}")

# 3. Even numbers only
evens = [num for num in numbers if num % 2 == 0]
print(f"Even numbers: {evens}")

# 4. Reverse the list
numbers.reverse()
print(f"Reversed: {numbers}")
```
