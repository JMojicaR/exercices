# Programming Exercises Summary — 2026-11-20

Weekly collection of basic coding exercises across 9 languages and 3 API frameworks.

## Languages (5 exercises each)

| Language | Exercises | Folder | Theme / Topics |
|----------|-----------|--------|----------------|
| Python | 5 | `python/` | Dictionaries — creating/accessing, `get()`, character-frequency counting, merging (`update`/`**`), `max(key=...)`, nested dicts + comprehensions |
| JavaScript | 5 | `js/` | Objects & Maps — object literals, bracket notation, frequency counting, `Object.keys/values/entries`, spread merge, the `Map` class |
| Java | 5 | `java/` | HashMap — `put`/`get`/`getOrDefault`, word-frequency counting, `entrySet` iteration, `containsKey`/`remove`, finding max-value key |
| C | 5 | `c/` | Key-value lookups — array frequency counters, string lookup tables, `struct`-array stores with linear search, digit counting, parallel-array lookup |
| C++ | 5 | `cpp/` | std::map & unordered_map — insert/access, `istringstream` frequency counting, `find`/`erase`/`count`, `emplace` insert-or-update, `max_element` |
| C# | 5 | `csharp/` | Dictionary<TKey,TValue> — indexer/`Add`/`TryGetValue`, word-frequency counting, `KeyValuePair` iteration, `ContainsKey`/`Remove`, LINQ max |
| Rust | 5 | `rust/` | HashMap — `insert`/`get`/`Option`, the `entry` API with `or_insert`, `keys`/`values` iteration, `contains_key`/`remove`, `max_by_key` |
| Go | 5 | `go/` | Maps — `make`/literal, comma-ok idiom, `strings.Fields` frequency counting, `range` iteration, `delete`, max-value key |
| Erlang | 5 | `erlang/` | Maps — `maps:get/3`, `=>` vs `:=`, `maps:update_with`, `keys`/`values`/`to_list`, `is_key`/`remove`, `maps:fold` for max |
