## Exercise 1: Even or Odd Checker
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator `%`, function definition, `std::cout`

Write a function that takes an `int` and prints whether it is even or odd.

**Starter code:**
```cpp
#include <iostream>

void even_or_odd(int n) {
    if (n % 2 == 0) {
        std::cout << n << " is even\n";
    } else {
        std::cout << n << " is odd\n";
    }
}

int main() {
    even_or_odd(4);  // 4 is even
    even_or_odd(7);  // 7 is odd
    return 0;
}
```

**Task:** Read the number from the user with `std::cin >> n` and check `std::cin.fail()` to confirm the input was a valid integer.

## Exercise 2: Print Numbers 1 to N
**Difficulty:** Basic
**Concepts:** `for` loop, loop variable, increment `i++`, `std::cout`

Print every integer from 1 up to and including `N`, one per line.

**Starter code:**
```cpp
#include <iostream>

void print_range(int n) {
    for (int i = 1; i <= n; i++) {
        std::cout << i << "\n";
    }
}

int main() {
    print_range(5);
    // 1
    // 2
    // 3
    // 4
    // 5
    return 0;
}
```

**Task:** Modify the loop to print only even numbers using `i += 2`. Then rewrite it with a range-based `for` loop (`for (int i : std::vector<int>{...})`) over a `std::vector`.

## Exercise 3: Countdown
**Difficulty:** Basic
**Concepts:** `while` loop, decrementing a counter, loop condition

Print a countdown from `N` down to 1, then print `"Liftoff!"`.

**Starter code:**
```cpp
#include <iostream>

void countdown(int n) {
    while (n > 0) {
        std::cout << n << "\n";
        n--;
    }
    std::cout << "Liftoff!\n";
}

int main() {
    countdown(5);
    // 5
    // 4
    // 3
    // 2
    // 1
    // Liftoff!
    return 0;
}
```

**Task:** Add a guard so that `n <= 0` prints `"Nothing to count"`. Then rewrite the countdown using a `do`/`while` loop and explain the difference in behavior for `n <= 0`.

## Exercise 4: Grade Classifier
**Difficulty:** Basic
**Concepts:** `if`/`else if`/`else` ladder, comparison operators, `return`

Convert a numeric score (0–100) into a letter grade: 90+ → A, 80–89 → B, 70–79 → C, 60–69 → D, below 60 → F.

**Starter code:**
```cpp
#include <iostream>

char classify(int score) {
    if (score >= 90) {
        return 'A';
    } else if (score >= 80) {
        return 'B';
    } else if (score >= 70) {
        return 'C';
    } else if (score >= 60) {
        return 'D';
    } else {
        return 'F';
    }
}

int main() {
    std::cout << classify(95) << "\n"; // A
    std::cout << classify(83) << "\n"; // B
    std::cout << classify(57) << "\n"; // F
    return 0;
}
```

**Task:** Rewrite using a `switch` statement on `score / 10` (with `case 10: case 9:`). Then handle scores outside 0–100 by returning `'X'` (invalid).

## Exercise 5: Sum of Even Numbers up to N
**Difficulty:** Basic
**Concepts:** `for` loop + `if` condition, accumulator variable, `+=`

Return the sum of every even number from 2 up to and including `N`.

**Starter code:**
```cpp
#include <iostream>

int sum_even(int n) {
    int total = 0;
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 0) {
            total += i;
        }
    }
    return total;
}

int main() {
    std::cout << sum_even(10) << "\n"; // 2 + 4 + 6 + 8 + 10 = 30
    std::cout << sum_even(7) << "\n";  // 2 + 4 + 6 = 12
    return 0;
}
```

**Task:** Rewrite using `i += 2` so the conditional is unnecessary, and add a `sum_odd(int n)` function. Compare `sum_even(n) + sum_odd(n)` against `n*(n+1)/2` for a given `n`.
