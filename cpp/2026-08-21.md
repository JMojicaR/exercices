## Exercise 1: Sum of Natural Numbers

**Difficulty:** Basic

### Problem
Write a program that reads an integer `n` and prints the sum of natural numbers from `1` to `n`.

**Given Input:** `10`

**Expected Output:**
```
Sum = 55
```

### Concepts
- `cin` / `cout` I/O
- `for` loop
- Accumulator

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, sum = 0;
    cout << "Enter a number: ";
    cin >> n;

    for (int i = 1; i <= n; i++) {
        sum += i;
    }

    cout << "Sum = " << sum << endl;
    return 0;
}
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that reads three integers and prints the largest.

**Given Input:** `12 7 19`

**Expected Output:**
```
Largest = 19
```

### Concepts
- `if / else if`
- Logical operators
- (Alternative) `std::max`

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c, largest;
    cout << "Enter three numbers: ";
    cin >> a >> b >> c;

    if (a >= b && a >= c)
        largest = a;
    else if (b >= a && b >= c)
        largest = b;
    else
        largest = c;

    cout << "Largest = " << largest << endl;
    return 0;
}
```

## Exercise 3: Simple Calculator with switch

**Difficulty:** Basic

### Problem
Write a program that reads two numbers and an operator and prints the result using a `switch` statement.

**Given Input:** `10 5 *`

**Expected Output:**
```
Result = 50
```

### Concepts
- `switch` statement
- Arithmetic operators
- Division-by-zero guard

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    double a, b, result;
    char op;
    cout << "Enter expression (a op b): ";
    cin >> a >> op >> b;

    switch (op) {
        case '+': result = a + b; break;
        case '-': result = a - b; break;
        case '*': result = a * b; break;
        case '/':
            if (b != 0) result = a / b;
            else { cout << "Cannot divide by zero" << endl; return 1; }
            break;
        default: cout << "Unknown operator" << endl; return 1;
    }

    cout << "Result = " << result << endl;
    return 0;
}
```

## Exercise 4: Prime Number Check

**Difficulty:** Basic

### Problem
Write a function `isPrime(int n)` that returns `true` if `n` is prime and `false` otherwise.

**Given Input:** `isPrime(7)`, `isPrime(10)`

**Expected Output:**
```
1 (true)
0 (false)
```

### Concepts
- Function definition and `bool` return
- Modulo divisibility
- Loop up to `sqrt(n)`

### Example / Starter Code

```cpp
#include <iostream>
#include <cmath>
using namespace std;

bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= sqrt(n); i++) {
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    cout << isPrime(7) << endl;   // 1
    cout << isPrime(10) << endl;  // 0
    return 0;
}
```

## Exercise 5: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a program that prints the first `n` terms of the Fibonacci sequence.

**Given Input:** `n = 7`

**Expected Output:**
```
0 1 1 2 3 5 8
```

### Concepts
- Loop with two tracking variables
- Variable reassignment
- `cout` output

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter n: ";
    cin >> n;

    int a = 0, b = 1;
    for (int i = 0; i < n; i++) {
        cout << a << " ";
        int next = a + b;
        a = b;
        b = next;
    }
    cout << endl;
    return 0;
}
```
