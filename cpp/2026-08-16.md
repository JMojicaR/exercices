## Exercise 1: Even or Odd Check

**Difficulty:** Basic

### Problem
Write a C++ program that checks whether an integer is even or odd and prints the result.

**Given Input:** `7`

**Expected Output:**
```
7 is odd
```

### Concepts
- `if / else` statements
- The modulo operator (`%`)
- `cout` and `endl`

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int num = 7;
    if (num % 2 == 0) {
        cout << num << " is even" << endl;
    } else {
        cout << num << " is odd" << endl;
    }
    return 0;
}
```

## Exercise 2: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a C++ program that computes and prints the factorial of a non-negative integer.

**Given Input:** `5`

**Expected Output:**
```
Factorial of 5 is 120
```

### Concepts
- `for` loop
- Accumulator pattern
- `long` type for larger results

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    long fact = 1;
    for (int i = 1; i <= n; i++) {
        fact *= i;
    }
    cout << "Factorial of " << n << " is " << fact << endl;   // 120
    return 0;
}
```

## Exercise 3: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a C++ program that finds and prints the largest of three integers.

**Given Input:** `a = 10, b = 25, c = 15`

**Expected Output:**
```
Largest: 25
```

### Concepts
- `if` comparisons
- Tracking a running maximum
- Logical comparison operators

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 25, c = 15;
    int largest = a;
    if (b > largest) largest = b;
    if (c > largest) largest = c;
    cout << "Largest: " << largest << endl;   // 25
    return 0;
}
```

## Exercise 4: Reverse a String

**Difficulty:** Basic

### Problem
Write a C++ program that prints a given string in reverse order.

**Given Input:** `"hello"`

**Expected Output:**
```
olleh
```

### Concepts
- `<string>` and `std::string`
- `std::reverse` from `<algorithm>`
- Iterators (`begin()` / `end()`)

### Example / Starter Code

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    string str = "hello";
    reverse(str.begin(), str.end());
    cout << str << endl;   // "olleh"
    return 0;
}
```

## Exercise 5: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a C++ program that counts the number of vowels (`a, e, i, o, u`, case-insensitive) in a string.

**Given Input:** `"Hello World"`

**Expected Output:**
```
Vowels: 3
```

### Concepts
- Range-based `for` loop over a string
- `tolower()` for case-insensitivity
- Character comparison with `||`

### Example / Starter Code

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string str = "Hello World";
    int count = 0;
    for (char ch : str) {
        ch = tolower(ch);
        if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u') {
            count++;
        }
    }
    cout << "Vowels: " << count << endl;   // 3
    return 0;
}
```
