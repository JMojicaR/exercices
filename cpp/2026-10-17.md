## Exercise 1: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** arrays, range-based `for`, accumulation, `std::vector`

Compute the sum of all elements in an array.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[] = {10, 20, 30, 40, 50};
    int sum = 0;

    for (int n : numbers) {
        sum += n;
    }

    cout << "Sum: " << sum << endl;
    return 0;
}
```

**Task:** Read the array elements from the user and use `std::vector` instead of a raw array.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** modulo operator (`%`), `if/else`

Check whether a number is even or odd.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 7;

    if (n % 2 == 0) {
        cout << n << " is even" << endl;
    } else {
        cout << n << " is odd" << endl;
    }
    return 0;
}
```

**Task:** Read the number from the user with `cin`.

## Exercise 3: Celsius to Fahrenheit
**Difficulty:** Basic
**Concepts:** arithmetic, functions, `double`

Convert Celsius to Fahrenheit using `F = C × 9/5 + 32`.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

double cToF(double celsius) {
    return (celsius * 9 / 5) + 32;
}

int main() {
    cout << "20°C = " << cToF(20) << "°F" << endl;
    return 0;
}
```

**Task:** Add an `fToC` function that converts Fahrenheit back to Celsius.

## Exercise 4: Find the Smallest Number
**Difficulty:** Basic
**Concepts:** arrays, comparison, loops

Find the smallest value in an integer array.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[] = {45, 12, 78, 4, 33};
    int smallest = numbers[0];

    for (int n : numbers) {
        if (n < smallest) smallest = n;
    }

    cout << "Smallest: " << smallest << endl;
    return 0;
}
```

**Task:** Also find the largest value using `std::min_element` / `std::max_element` from `<algorithm>`.

## Exercise 5: Simple Interest
**Difficulty:** Basic
**Concepts:** variables, arithmetic, `double`

Calculate simple interest using `SI = (P × R × T) / 100`.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    double principal = 1000, rate = 5, time = 3;
    double interest = (principal * rate * time) / 100;

    cout << "Simple interest: " << interest << endl;
    return 0;
}
```

**Task:** Also print the total amount (principal + interest).
