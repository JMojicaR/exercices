## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** `std::string`, reverse iterators `rbegin()`/`rend()`, constructor

Write a function that returns the input string reversed.

**Starter code:**
```cpp
#include <iostream>
#include <string>

std::string reverse_string(const std::string& s) {
    return std::string(s.rbegin(), s.rend());
}

int main() {
    std::cout << reverse_string("hello") << std::endl;  // expected: olleh
    return 0;
}
```

**Task:** Rewrite it using `std::reverse` from `<algorithm>`, and again with a manual index loop.

## Exercise 2: Check Palindrome
**Difficulty:** Basic
**Concepts:** `std::tolower`, `std::reverse`, string comparison, `std::boolalpha`

Check whether a string reads the same forwards and backwards (ignoring case).

**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <algorithm>
#include <cctype>

bool is_palindrome(const std::string& s) {
    std::string lower;
    for (char c : s) {
        lower += std::tolower(c);
    }
    std::string rev = lower;
    std::reverse(rev.begin(), rev.end());
    return lower == rev;
}

int main() {
    std::cout << std::boolalpha << is_palindrome("Radar") << std::endl;  // true
    std::cout << std::boolalpha << is_palindrome("hello") << std::endl;  // false
    return 0;
}
```

**Task:** Compare from both ends with two indices instead of building a reversed copy.

## Exercise 3: Count Vowels
**Difficulty:** Basic
**Concepts:** range-based `for` loop, `std::tolower`, counter, `std::string`

Count how many vowels (a, e, i, o, u) appear in a string, case-insensitively.

**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <cctype>

int count_vowels(const std::string& s) {
    int count = 0;
    for (char c : s) {
        c = std::tolower(c);
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            count++;
        }
    }
    return count;
}

int main() {
    std::cout << count_vowels("hello world") << std::endl;  // expected: 3
    return 0;
}
```

**Task:** Use `std::string::find` with a vowel string instead of the chain of `||` comparisons.

## Exercise 4: Count Character Occurrences
**Difficulty:** Basic
**Concepts:** `std::count` from `<algorithm>`, iterators, function parameters

Count how many times a given character appears in a string.

**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <algorithm>

int count_char(const std::string& s, char ch) {
    return std::count(s.begin(), s.end(), ch);
}

int main() {
    std::cout << count_char("banana", 'a') << std::endl;  // expected: 3
    return 0;
}
```

**Task:** Rewrite it using a range-based `for` loop without `<algorithm>`.

## Exercise 5: Count Words
**Difficulty:** Basic
**Concepts:** `std::istringstream`, extraction operator, `while` loop

Count the number of words in a sentence (words separated by whitespace).

**Starter code:**
```cpp
#include <iostream>
#include <sstream>
#include <string>

int count_words(const std::string& sentence) {
    std::istringstream iss(sentence);
    std::string word;
    int count = 0;
    while (iss >> word) {
        count++;
    }
    return count;
}

int main() {
    std::cout << count_words("I love programming") << std::endl;  // expected: 3
    return 0;
}
```

**Task:** Also print each extracted word on its own line.
