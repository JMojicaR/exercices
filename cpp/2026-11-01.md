## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** functions, `for` loop, `unsigned long long`, `std::cout`

Compute `n!` and return it as an `unsigned long long`.

**Starter code:**
```cpp
#include <iostream>

unsigned long long factorial(int n) {
    unsigned long long result = 1;
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
    return result;
}

int main() {
    std::cout << factorial(5) << "\n"; // 120
    std::cout << factorial(0) << "\n"; // 1
    return 0;
}
```

**Task:** Read `n` from `std::cin` and print the result, guarding against negative input.

## Exercise 2: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** `std::vector`, `push_back`, range-based `for`, variable swapping

Return the first `n` Fibonacci numbers in a `std::vector<int>`.

**Starter code:**
```cpp
#include <iostream>
#include <vector>

std::vector<int> fibonacci(int n) {
    std::vector<int> seq;
    int a = 0, b = 1;
    for (int i = 0; i < n; i++) {
        seq.push_back(a);
        int next = a + b;
        a = b;
        b = next;
    }
    return seq;
}

int main() {
    for (int x : fibonacci(7)) {
        std::cout << x << " "; // 0 1 1 2 3 5 8
    }
    std::cout << "\n";
    return 0;
}
```

**Task:** Add an `nth_fibonacci(int n)` function that returns only the `n`-th number (0-indexed).

## Exercise 3: Check Prime Number
**Difficulty:** Basic
**Concepts:** `bool` return, `std::sqrt` from `<cmath>`, `std::boolalpha`, loops

Return `true` if a number is prime, `false` otherwise.

**Starter code:**
```cpp
#include <iostream>
#include <cmath>

bool is_prime(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= std::sqrt(n); i++) {
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    std::cout << std::boolalpha << is_prime(7) << "\n";  // true
    std::cout << std::boolalpha << is_prime(10) << "\n"; // false
    return 0;
}
```

**Task:** Write a `count_primes(int limit)` function that returns the number of primes below `limit`.

## Exercise 4: Sum of Digits
**Difficulty:** Basic
**Concepts:** `%` and `/`, `while` loop, digit extraction, `int` return

Return the sum of the individual digits of a number.

**Starter code:**
```cpp
#include <iostream>

int sum_of_digits(int n) {
    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }
    return sum;
}

int main() {
    std::cout << sum_of_digits(1234) << "\n"; // 10
    return 0;
}
```

**Task:** Rewrite it using `std::string` and `std::stoi`, then compare the two implementations.

## Exercise 5: Greatest Common Divisor (GCD)
**Difficulty:** Basic
**Concepts:** `<numeric>` (`std::gcd`), Euclidean algorithm, `while` loop

Compute the greatest common divisor of two integers.

**Starter code:**
```cpp
#include <iostream>
#include <numeric>

int main() {
    std::cout << std::gcd(48, 18) << "\n";  // 6
    std::cout << std::gcd(100, 35) << "\n"; // 5
    return 0;
}
```

**Task:** Re-implement `std::gcd` yourself as `gcd(int a, int b)` using the Euclidean algorithm, then add an `lcm` function.
