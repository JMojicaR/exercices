## Exercise 1: Number Guessing Game
**Difficulty:** Basic
**Concepts:** rand/srand, while loop, iostream

Generate a random number between 1 and 100 and let the user guess with hints.

**Starter code:**
```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    srand(static_cast<unsigned>(time(0)));
    int target = rand() % 100 + 1;
    int guess = 0;

    while (guess != target) {
        std::cout << "Guess a number (1-100): ";
        std::cin >> guess;
        if (guess < target) std::cout << "Too low!\n";
        else if (guess > target) std::cout << "Too high!\n";
    }
    std::cout << "You guessed it!\n";
    return 0;
}
```

**Task:** Count the attempts and print them when the player wins.

## Exercise 2: Simple Calculator with switch
**Difficulty:** Basic
**Concepts:** switch, cin/cout, arithmetic

Read an operator and two numbers, then print the result.

**Starter code:**
```cpp
#include <iostream>

int main() {
    char op;
    double a, b;
    std::cout << "Enter operator (+, -, *, /): ";
    std::cin >> op;
    std::cout << "Enter two numbers: ";
    std::cin >> a >> b;

    switch (op) {
        case '+': std::cout << a + b << "\n"; break;
        case '-': std::cout << a - b << "\n"; break;
        case '*': std::cout << a * b << "\n"; break;
        case '/':
            if (b != 0) std::cout << a / b << "\n";
            else std::cout << "Cannot divide by zero\n";
            break;
        default: std::cout << "Invalid operator\n";
    }
    return 0;
}
```

**Task:** Put the switch in a loop so the user can repeat calculations until they type `q`.

## Exercise 3: Sum of Even Numbers
**Difficulty:** Basic
**Concepts:** for loop, accumulator, modulo

Compute the sum of all even numbers from 1 up to `n`.

**Starter code:**
```cpp
#include <iostream>

int main() {
    int n, sum = 0;
    std::cout << "Enter a positive integer: ";
    std::cin >> n;

    for (int i = 2; i <= n; i += 2) {
        sum += i;
    }
    std::cout << "Sum of even numbers up to " << n << " is " << sum << "\n";
    return 0;
}
```

**Task:** Write a second version that sums odd numbers instead.

## Exercise 4: Find the Smallest Element in a Vector
**Difficulty:** Basic
**Concepts:** vector, range-based for loop, comparison

Find the smallest value in a `std::vector<int>`.

**Starter code:**
```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> arr = {34, 15, 88, 2, 42};
    int min = arr[0];

    for (int x : arr) {
        if (x < min) min = x;
    }
    std::cout << "Smallest element: " << min << "\n";
    return 0;
}
```

**Task:** Use `std::min_element` from `<algorithm>` and confirm the same result.

## Exercise 5: Count Words in a String
**Difficulty:** Basic
**Concepts:** getline, stringstream, string

Count the number of words in a line entered by the user.

**Starter code:**
```cpp
#include <iostream>
#include <sstream>
#include <string>

int main() {
    std::string line;
    std::cout << "Enter a sentence: ";
    std::getline(std::cin, line);

    std::istringstream stream(line);
    std::string word;
    int count = 0;
    while (stream >> word) count++;

    std::cout << "Number of words: " << count << "\n";
    return 0;
}
```

**Task:** Also print each word on its own line.
