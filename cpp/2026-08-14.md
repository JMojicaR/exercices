## Exercise 1: Check Positive, Negative, or Zero

### Problem
Write a program that reads a number and prints whether it is positive, negative, or zero.

**Given Input:** `-5`

**Expected Output:**
```
The number is negative
```

### Concepts
- `cin` for input
- `if / else if / else` chains
- Comparison operators

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int number;
    cout << "Enter a number: ";
    cin >> number;

    if (number > 0)
        cout << "The number is positive" << endl;
    else if (number < 0)
        cout << "The number is negative" << endl;
    else
        cout << "The number is zero" << endl;

    return 0;
}
```

## Exercise 2: Factorial of a Number

### Problem
Write a program that computes the factorial of a non-negative integer using a loop.

**Given Input:** `6`

**Expected Output:**
```
Factorial of 6 = 720
```

### Concepts
- `for` loops
- Accumulator pattern
- `long long` for larger results

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    long long factorial = 1;

    cout << "Enter a non-negative integer: ";
    cin >> n;

    for (int i = 1; i <= n; i++) {
        factorial *= i;
    }

    cout << "Factorial of " << n << " = " << factorial << endl;
    return 0;
}
```

## Exercise 3: Check Palindrome String

### Problem
Write a program that checks whether a given string is a palindrome using the `<algorithm>` library's `std::reverse`.

**Given Input:** `"radar"`

**Expected Output:**
```
radar is a palindrome
```

### Concepts
- `std::string`
- `std::reverse` from `<algorithm>`
- String comparison with `==`

### Example / Starter Code

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    string original, reversed;
    cout << "Enter a string: ";
    cin >> original;

    reversed = original;
    reverse(reversed.begin(), reversed.end());

    if (original == reversed)
        cout << original << " is a palindrome" << endl;
    else
        cout << original << " is not a palindrome" << endl;

    return 0;
}
```

## Exercise 4: Largest of Three Numbers

### Problem
Write a program that reads three numbers and prints the largest one.

**Given Input:** `10, 25, 15`

**Expected Output:**
```
The largest number is 25
```

### Concepts
- Nested `if-else`
- Relational and logical operators (`&&`)
- Comparison logic

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cout << "Enter three numbers: ";
    cin >> a >> b >> c;

    if (a >= b && a >= c)
        cout << "The largest number is " << a << endl;
    else if (b >= a && b >= c)
        cout << "The largest number is " << b << endl;
    else
        cout << "The largest number is " << c << endl;

    return 0;
}
```

## Exercise 5: Reverse a Number

### Problem
Write a program that reverses the digits of a given integer (e.g., `12345` becomes `54321`).

**Given Input:** `12345`

**Expected Output:**
```
Reversed number: 54321
```

### Concepts
- `while` loop
- Modulo (`%`) and integer division (`/`)
- Building a number digit by digit

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, reversed = 0;

    cout << "Enter an integer: ";
    cin >> n;

    while (n != 0) {
        int digit = n % 10;
        reversed = reversed * 10 + digit;
        n /= 10;
    }

    cout << "Reversed number: " << reversed << endl;
    return 0;
}
```
