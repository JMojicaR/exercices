## Exercise 1: Sum of Two Numbers

### Problem
Write a C++ program that reads two integers from the user and prints their sum. This exercise practices basic input/output using `cin` and `cout`.

### Concepts
- `#include <iostream>`
- `std::cin`, `std::cout`
- Variable declaration (`int`)
- Basic arithmetic (`+`)

### Example/Starter Code
```cpp
#include <iostream>

int main() {
    int num1, num2;

    std::cout << "Enter first number: ";
    std::cin >> num1;

    std::cout << "Enter second number: ";
    std::cin >> num2;

    // TODO: Calculate and print the sum of num1 and num2

    return 0;
}
```

**Expected Output:**
```
Enter first number: 25
Enter second number: 39
The sum is: 64
```
