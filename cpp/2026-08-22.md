## Exercise 1: Check Leap Year

**Difficulty:** Basic

### Problem
Write a function that checks whether a given year is a leap year using the rules: divisible by 400 is a leap year, divisible by 100 is not, and divisible by 4 is. Print the result for a sample year.

**Given Input:** `isLeapYear(2024)`

**Expected Output:**
```
2024 is a leap year.
```

### Concepts
- Function definition and return types
- Modulo operator (`%`)
- `if` / `else if` / `else` conditionals
- Boolean logic

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

bool isLeapYear(int year) {
    if (year % 400 == 0) return true;
    if (year % 100 == 0) return false;
    if (year % 4 == 0) return true;
    return false;
}

int main() {
    int year = 2024;
    if (isLeapYear(year))
        cout << year << " is a leap year." << endl;
    else
        cout << year << " is not a leap year." << endl;
    return 0;
}
```

## Exercise 2: GCD of Two Numbers

**Difficulty:** Basic

### Problem
Write a function that computes the greatest common divisor (GCD) of two positive integers using the Euclidean algorithm (repeated modulo). Print the GCD of a sample pair.

**Given Input:** `gcd(48, 18)`

**Expected Output:**
```
GCD of 48 and 18 is 6
```

### Concepts
- `while` loops
- Euclidean algorithm
- Swapping values with a temporary variable
- Passing parameters by value

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int main() {
    int a = 48, b = 18;
    cout << "GCD of " << a << " and " << b << " is " << gcd(a, b) << endl;
    return 0;
}
```

## Exercise 3: Swap Two Numbers Using References

**Difficulty:** Basic

### Problem
Write a function that swaps two integers using reference parameters so the changes are reflected in the caller. Print the values before and after the swap.

**Given Input:** `swapNumbers(a, b)` where `a = 5`, `b = 10`

**Expected Output:**
```
Before swap: a = 5, b = 10
After swap: a = 10, b = 5
```

### Concepts
- Reference parameters (`int &x`)
- Temporary variable for swapping
- Function call-by-reference vs call-by-value

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

void swapNumbers(int &x, int &y) {
    int temp = x;
    x = y;
    y = temp;
}

int main() {
    int a = 5, b = 10;
    cout << "Before swap: a = " << a << ", b = " << b << endl;
    swapNumbers(a, b);
    cout << "After swap: a = " << a << ", b = " << b << endl;
    return 0;
}
```

## Exercise 4: Check Positive / Negative / Zero

**Difficulty:** Basic

### Problem
Write a program that reads an integer and prints whether it is positive, negative, or zero using conditional statements.

**Given Input:** `num = -7`

**Expected Output:**
```
-7 is negative.
```

### Concepts
- `if` / `else if` / `else` branching
- Comparison operators (`>`, `<`)
- Reading a single integer value

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int num = -7;

    if (num > 0)
        cout << num << " is positive." << endl;
    else if (num < 0)
        cout << num << " is negative." << endl;
    else
        cout << num << " is zero." << endl;

    return 0;
}
```

## Exercise 5: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that prints the multiplication table of a given number from 1 to 10 using a loop.

**Given Input:** `n = 5`

**Expected Output:**
```
Multiplication table of 5:
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

### Concepts
- `for` loops
- Arithmetic operations
- String output with `cout`

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    cout << "Multiplication table of " << n << ":" << endl;

    for (int i = 1; i <= 10; i++) {
        cout << n << " x " << i << " = " << n * i << endl;
    }

    return 0;
}
```
