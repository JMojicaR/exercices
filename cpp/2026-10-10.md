## Exercise 1: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** loops, variables, iostream

Print the first `n` numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...).

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, a = 0, b = 1, next;
    cout << "How many Fibonacci numbers? ";
    cin >> n;

    for (int i = 0; i < n; i++) {
        cout << a << " ";
        next = a + b;
        a = b;
        b = next;
    }
    cout << endl;
    return 0;
}
```

**Task:** Print only the Fibonacci numbers below a user-specified limit.

## Exercise 2: Reverse a Number
**Difficulty:** Basic
**Concepts:** while loop, modulo, integer arithmetic

Read an integer and print its digits in reverse order (e.g. 1234 → 4321).

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, reversed = 0;
    cout << "Enter a number: ";
    cin >> n;

    while (n != 0) {
        reversed = reversed * 10 + n % 10;
        n /= 10;
    }
    cout << "Reversed: " << reversed << endl;
    return 0;
}
```

**Task:** Check whether the original number is a palindrome.

## Exercise 3: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** if/else, comparison operators

Read three numbers and print the largest.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c, largest;
    cout << "Enter three numbers: ";
    cin >> a >> b >> c;

    largest = a;
    if (b > largest) largest = b;
    if (c > largest) largest = c;

    cout << "Largest: " << largest << endl;
    return 0;
}
```

**Task:** Also print the smallest and sort the three numbers in ascending order.

## Exercise 4: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** std::swap, references, variables

Read two numbers and swap their values using `std::swap`.

**Starter code:**
```cpp
#include <iostream>
#include <utility>
using namespace std;

int main() {
    int a, b;
    cout << "Enter two numbers: ";
    cin >> a >> b;

    cout << "Before: a = " << a << ", b = " << b << endl;
    swap(a, b);
    cout << "After:  a = " << a << ", b = " << b << endl;
    return 0;
}
```

**Task:** Implement your own swap function that takes two references.

## Exercise 5: Multiplication Table
**Difficulty:** Basic
**Concepts:** nested loops, formatted output

Print the multiplication table (1 through 10) for a given number.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter a number: ";
    cin >> n;

    for (int i = 1; i <= 10; i++) {
        cout << n << " x " << i << " = " << n * i << endl;
    }
    return 0;
}
```

**Task:** Print a full 1–10 × 1–10 multiplication grid using nested loops.
