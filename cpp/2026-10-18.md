## Exercise 1: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** variables, temporary variable, `std::swap`, `cout`

Swap the values of two variables.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 10;

    int temp = a;
    a = b;
    b = temp;

    cout << "a = " << a << ", b = " << b << endl;
    return 0;
}
```

**Task:** Replace the manual swap with the standard `std::swap(a, b);` (include `<utility>` or `<algorithm>`).

## Exercise 2: Area of a Circle
**Difficulty:** Basic
**Concepts:** `const`, `cin`/`cout`, `double`, arithmetic

Compute the area of a circle given its radius (`area = π × r²`).

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    const double PI = 3.14159;
    double radius;

    cout << "Enter radius: ";
    cin >> radius;

    double area = PI * radius * radius;

    cout << "Area: " << area << endl;
    return 0;
}
```

**Task:** Also print the circumference (`2 * PI * radius`), and try `M_PI` from `<cmath>` (note it may not be available on all compilers).

## Exercise 3: Positive, Negative or Zero
**Difficulty:** Basic
**Concepts:** `if / else if / else`, comparison operators, `cin`

Classify a number as positive, negative, or zero.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    double n;

    cout << "Enter a number: ";
    cin >> n;

    if (n > 0)
        cout << "Positive" << endl;
    else if (n < 0)
        cout << "Negative" << endl;
    else
        cout << "Zero" << endl;

    return 0;
}
```

**Task:** Extend it to also report whether a whole number is even or odd.

## Exercise 4: Power of a Number (xⁿ)
**Difficulty:** Basic
**Concepts:** `for` loop, accumulation, `pow()` from `<cmath>`

Compute `base` raised to the power `exp` using a loop.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int base, exp;
    long long result = 1;

    cout << "Base: ";
    cin >> base;
    cout << "Exponent: ";
    cin >> exp;

    for (int i = 0; i < exp; i++) {
        result *= base;
    }

    cout << base << "^" << exp << " = " << result << endl;
    return 0;
}
```

**Task:** Rewrite using `pow(base, exp)` from `<cmath>` (it returns a `double`).

## Exercise 5: Reverse a Number
**Difficulty:** Basic
**Concepts:** `while` loop, modulo (`%`), integer division (`/`)

Reverse the digits of an integer (e.g. 1234 → 4321).

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, rev = 0;

    cout << "Enter a number: ";
    cin >> n;

    while (n != 0) {
        rev = rev * 10 + n % 10;
        n /= 10;
    }

    cout << "Reversed: " << rev << endl;
    return 0;
}
```

**Task:** Confirm it also works for negative numbers (the `while (n != 0)` condition handles them automatically).
