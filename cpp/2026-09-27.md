## Exercise 1: Add Two Numbers
**Difficulty:** Basic
**Concepts:** `cin`/`cout`, variables, arithmetic, `using namespace std`.

Write a program that reads two integers and prints their sum.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "Enter two numbers: ";
    cin >> a >> b;
    cout << "Sum: " << a + b << endl;
    return 0;
}
```

**Task:** Also print the difference, product, and (integer) quotient.

## Exercise 2: Multiplication Table
**Difficulty:** Basic
**Concepts:** `for` loop, output formatting.

Write a program that prints the multiplication table (1–10) for a given number.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter a number: ";
    cin >> n;
    for (int i = 1; i <= 10; i++)
        cout << n << " x " << i << " = " << n * i << endl;
    return 0;
}
```

**Task:** Use nested loops to print tables for every number from 1 to 5.

## Exercise 3: Factorial
**Difficulty:** Basic
**Concepts:** Loops, accumulator variables, `long long` for larger results.

Write a program that reads a non-negative integer and prints its factorial.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter a number: ";
    cin >> n;
    long long f = 1;
    for (int i = 1; i <= n; i++)
        f *= i;
    cout << n << "! = " << f << endl;
    return 0;
}
```

**Task:** Handle `n = 0` (should print `0! = 1`) and test with `n = 20`.

## Exercise 4: Check if a Number is Prime
**Difficulty:** Basic
**Concepts:** Loops, `bool`, `break`, divisibility, early exit.

Write a program that reads a number and prints whether it is prime.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter a number: ";
    cin >> n;
    bool isPrime = n > 1;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            isPrime = false;
            break;
        }
    }
    cout << n << (isPrime ? " is prime" : " is not prime") << endl;
    return 0;
}
```

**Task:** Print all prime numbers from 2 to 100 using this logic in a loop.

## Exercise 5: Palindrome String
**Difficulty:** Basic
**Concepts:** `std::string`, reverse iterators, string comparison.

Write a program that reads a string and checks whether it is a palindrome.

**Starter code:**
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cout << "Enter a string: ";
    cin >> s;
    string rev(s.rbegin(), s.rend());
    cout << (s == rev ? "Palindrome" : "Not a palindrome") << endl;
    return 0;
}
```

**Task:** Make the check case-insensitive by converting the string to lowercase first.
