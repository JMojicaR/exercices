## 1. Temperature Converter
- **Description**: Read a Celsius temperature and convert it to Fahrenheit (`F = C × 9/5 + 32`).
- **Difficulty**: Beginner
- **Concepts**: `iostream`, `cin`/`cout`, `double`, arithmetic operators
- **Example/Starter code**:
```cpp
#include <iostream>
using namespace std;

int main() {
    double celsius, fahrenheit;
    cout << "Enter temperature in Celsius: ";
    cin >> celsius;
    fahrenheit = celsius * 9 / 5 + 32;
    cout << celsius << " C = " << fahrenheit << " F" << endl;
    return 0;
}
```

## 2. Area of a Circle
- **Description**: Read the radius of a circle and print its area (`π·r²`).
- **Difficulty**: Beginner
- **Concepts**: `const` variables, `double`, `cin`/`cout`
- **Example/Starter code**:
```cpp
#include <iostream>
using namespace std;
const double PI = 3.14159;

int main() {
    double radius;
    cout << "Enter radius: ";
    cin >> radius;
    cout << "Area = " << PI * radius * radius << endl;
    return 0;
}
```

## 3. Count the Vowels
- **Description**: Count how many vowels (`a`, `e`, `i`, `o`, `u`) appear in a string, ignoring case.
- **Difficulty**: Beginner
- **Concepts**: `std::string`, `tolower()`, range-based `for`, `string::find`
- **Example/Starter code**:
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string text = "hello world";
    string vowels = "aeiou";
    int count = 0;
    for (char c : text) {
        c = tolower(c);
        if (vowels.find(c) != string::npos) {
            count++;
        }
    }
    cout << "Vowel count: " << count << endl;
    return 0;
}
```

## 4. Fibonacci Series
- **Description**: Print the first N numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, ...).
- **Difficulty**: Beginner
- **Concepts**: `for` loops, integer variables, iterative updates
- **Example/Starter code**:
```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 10, a = 0, b = 1;
    cout << a << endl;
    for (int i = 1; i < n; i++) {
        cout << b << endl;
        int next = a + b;
        a = b;
        b = next;
    }
    return 0;
}
```

## 5. Sum of Digits
- **Description**: Given an integer, compute the sum of its digits (e.g. 12345 → 15).
- **Difficulty**: Beginner
- **Concepts**: `while` loops, modulo `%` and integer division `/`
- **Example/Starter code**:
```cpp
#include <iostream>
using namespace std;

int main() {
    int num = 12345, sum = 0;
    while (num > 0) {
        sum += num % 10;
        num /= 10;
    }
    cout << "Sum of digits: " << sum << endl;
    return 0;
}
```
