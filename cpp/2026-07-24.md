## Exercise 1: Student Grade Calculator
**Difficulty:** ⭐ Basic  
**Concepts:** Vectors, loops, I/O streams, conditionals

**Description:** Write a C++ program that asks the user to enter grades for 5 students, stores them in a `std::vector<int>`, calculates the class average, and prints each student's grade along with a letter grade (A: 90+, B: 80-89, C: 70-79, D: 60-69, F: <60).

**Starter Code:**
```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    vector<int> grades(5);
    double sum = 0;

    // Input grades
    for (int i = 0; i < 5; i++) {
        cout << "Enter grade for student " << (i + 1) << ": ";
        cin >> grades[i];
        sum += grades[i];
    }

    // Your code: print each grade with letter, then average
    double average = sum / 5;
    cout << "\nClass Average: " << average << endl;

    return 0;
}
```

**Expected Learning:** `std::vector`, `cin`/`cout`, `for` loop, `if/else if` chains, arithmetic operations, `using namespace std`.
