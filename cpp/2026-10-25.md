## Exercise 1: Create and Print a Matrix
**Difficulty:** Basic
**Concepts:** `std::vector`, nested range `for` loops, `cout`

Build a 2D vector and print it row by row.

**Starter code:**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<vector<int>> matrix = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    cout << "Matrix:\n";
    for (const auto& row : matrix) {
        for (int val : row) {
            cout << val << " ";
        }
        cout << "\n";
    }
    return 0;
}
```

**Task:** Read the matrix from the user with `cin` (ask for rows and columns first), then print only the first and last row.

## Exercise 2: Matrix Addition
**Difficulty:** Basic
**Concepts:** 2D vectors, element-wise addition, sized vector construction

Add two matrices and print the sum.

**Starter code:**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<vector<int>> a = {{1, 2}, {3, 4}};
    vector<vector<int>> b = {{5, 6}, {7, 8}};
    int rows = a.size(), cols = a[0].size();
    vector<vector<int>> result(rows, vector<int>(cols));

    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            result[i][j] = a[i][j] + b[i][j];
        }
    }

    for (const auto& row : result) {
        for (int val : row) {
            cout << val << " ";
        }
        cout << "\n";
    }
    return 0;
}
```

**Task:** Compute subtraction (`a - b`), and wrap the addition in a function that returns `vector<vector<int>>`.

## Exercise 3: Matrix Transpose
**Difficulty:** Basic
**Concepts:** row/column swapping, flipped-size vector

Transpose a matrix (swap rows and columns).

**Starter code:**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<vector<int>> matrix = {{1, 2, 3}, {4, 5, 6}};
    int rows = matrix.size(), cols = matrix[0].size();
    vector<vector<int>> transpose(cols, vector<int>(rows));

    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            transpose[j][i] = matrix[i][j];
        }
    }

    for (const auto& row : transpose) {
        for (int val : row) {
            cout << val << " ";
        }
        cout << "\n";
    }
    return 0;
}
```

**Task:** Write a `transpose()` function and verify that transposing twice returns the original matrix.

## Exercise 4: Sum of the Main Diagonal
**Difficulty:** Basic
**Concepts:** square matrices, single loop, index tracking

Sum the main diagonal (top-left to bottom-right) of a square matrix.

**Starter code:**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<vector<int>> matrix = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
    int n = matrix.size();
    int total = 0;

    for (int i = 0; i < n; i++) {
        total += matrix[i][i];
    }

    cout << "Sum of main diagonal: " << total << "\n";
    return 0;
}
```

**Task:** Add the anti-diagonal using `matrix[i][n - 1 - i]` and print both sums.

## Exercise 5: Sum of Each Row and Each Column
**Difficulty:** Basic
**Concepts:** nested loops, running totals, range-based `for`

Print the sum of every row and every column.

**Starter code:**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<vector<int>> matrix = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
    int rows = matrix.size(), cols = matrix[0].size();

    cout << "Row sums:\n";
    for (int i = 0; i < rows; i++) {
        int rowSum = 0;
        for (int j = 0; j < cols; j++) {
            rowSum += matrix[i][j];
        }
        cout << "Row " << i << ": " << rowSum << "\n";
    }

    cout << "Column sums:\n";
    for (int j = 0; j < cols; j++) {
        int colSum = 0;
        for (int i = 0; i < rows; i++) {
            colSum += matrix[i][j];
        }
        cout << "Col " << j << ": " << colSum << "\n";
    }
    return 0;
}
```

**Task:** Use `std::accumulate` for row sums and report the grand total of all elements.
