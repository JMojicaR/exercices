## Exercise 1: Bubble Sort

**Difficulty:** Basic

### Problem
Write a program that sorts a `vector<int>` in ascending order using bubble sort.

**Given Input:** `{64, 34, 25, 12, 22, 11, 90}`

**Expected Output:**
```
Sorted: 11 12 22 25 34 64 90
```

### Concepts
- `std::vector` and `.size()`
- Nested `for` loops
- `std::swap`

### Example / Starter Code

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr = {64, 34, 25, 12, 22, 11, 90};
    int n = arr.size();

    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - i - 1; j++)
            if (arr[j] > arr[j + 1])
                swap(arr[j], arr[j + 1]);

    cout << "Sorted: ";
    for (int x : arr) cout << x << " ";
    cout << endl;
    return 0;
}
```

## Exercise 2: Linear Search

**Difficulty:** Basic

### Problem
Write a function that returns the index of a target value in a vector, or `-1` if absent.

**Given Input:** vector `{10, 23, 45, 70, 11, 15}`, target `70`

**Expected Output:**
```
Found at index 3
```

### Concepts
- `const vector<int>&` parameter
- Range-based `for` with index (or classic `for`)
- Early `return`

### Example / Starter Code

```cpp
#include <iostream>
#include <vector>
using namespace std;

int linearSearch(const vector<int>& arr, int target) {
    for (size_t i = 0; i < arr.size(); i++)
        if (arr[i] == target) return i;
    return -1;
}

int main() {
    vector<int> nums = {10, 23, 45, 70, 11, 15};
    int index = linearSearch(nums, 70);
    if (index != -1) cout << "Found at index " << index << endl;
    else cout << "Not found" << endl;
    return 0;
}
```

## Exercise 3: Anagram Check

**Difficulty:** Basic

### Problem
Write a function that checks whether two strings are anagrams, ignoring case.

**Given Input:** `"listen"`, `"silent"`

**Expected Output:**
```
Anagram
```

### Concepts
- `std::transform` + `::tolower`
- `std::sort` on strings
- String `==` comparison

### Example / Starter Code

```cpp
#include <iostream>
#include <algorithm>
#include <string>
using namespace std;

bool isAnagram(string s1, string s2) {
    transform(s1.begin(), s1.end(), s1.begin(), ::tolower);
    transform(s2.begin(), s2.end(), s2.begin(), ::tolower);
    sort(s1.begin(), s1.end());
    sort(s2.begin(), s2.end());
    return s1 == s2;
}

int main() {
    cout << (isAnagram("listen", "silent") ? "Anagram" : "Not an anagram") << endl;
    return 0;
}
```

## Exercise 4: Greatest Common Divisor (GCD)

**Difficulty:** Basic

### Problem
Write a function that computes the GCD of two positive integers using the Euclidean algorithm.

**Given Input:** `48`, `18`

**Expected Output:**
```
GCD: 6
```

### Concepts
- `while` loop
- Modulo `%`
- Local variable swap

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int main() {
    cout << "GCD: " << gcd(48, 18) << endl;
    return 0;
}
```

## Exercise 5: Armstrong Number Check

**Difficulty:** Basic

### Problem
Write a function that checks whether a number is an Armstrong number.

**Given Input:** `153`

**Expected Output:**
```
Armstrong
```

### Concepts
- `std::to_string`
- Range-based `for` over string
- `std::pow` with `<cmath>`

### Example / Starter Code

```cpp
#include <iostream>
#include <cmath>
#include <string>
using namespace std;

bool isArmstrong(int n) {
    string s = to_string(n);
    int power = s.size(), total = 0;
    for (char c : s)
        total += pow(c - '0', power);
    return total == n;
}

int main() {
    cout << (isArmstrong(153) ? "Armstrong" : "Not Armstrong") << endl;
    return 0;
}
```
