## Exercise 1: Fibonacci Series
**Difficulty:** Basic
**Concepts:** Loops, Vectors, Arithmetic

Generate the first `n` Fibonacci numbers using a `std::vector` so the whole series can be stored and printed.

**Starter code:**
```cpp
#include <iostream>
#include <vector>

int main() {
    int n = 10;
    std::vector<int> fib = {0, 1};

    for (int i = 2; i < n; i++) {
        fib.push_back(fib[i - 1] + fib[i - 2]);
    }

    for (int num : fib) {
        std::cout << num << " ";
    }
    std::cout << std::endl;
    return 0;
}
```

**Task:** Let the user choose how many terms to generate and print each term with its index (e.g. "F(3) = 2").

## Exercise 2: Swap Two Numbers Using References
**Difficulty:** Basic
**Concepts:** Functions, References, Pass by Reference

Write a function that swaps two integers using reference parameters so the change is visible to the caller.

**Starter code:**
```cpp
#include <iostream>

void swap(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 5, y = 10;
    std::cout << "Before: " << x << " " << y << std::endl;

    swap(x, y);

    std::cout << "After: " << x << " " << y << std::endl;
    return 0;
}
```

**Task:** Add a second overload of `swap` that works on `double` values and demonstrate it in `main`.

## Exercise 3: GCD (Euclidean Algorithm)
**Difficulty:** Basic
**Concepts:** Loops, Recursion, Modulo

Compute the greatest common divisor of two positive integers using Euclid's algorithm, which repeatedly replaces the larger number with the remainder.

**Starter code:**
```cpp
#include <iostream>

int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int main() {
    int x = 48, y = 18;
    std::cout << "GCD of " << x << " and " << y << " is " << gcd(x, y) << std::endl;
    return 0;
}
```

**Task:** Read the two numbers from the user and also print their least common multiple (LCM) using the GCD.

## Exercise 4: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** Conditionals, Standard Algorithms, Functions

Find the largest of three integers using `std::max` and also with an explicit conditional expression.

**Starter code:**
```cpp
#include <iostream>
#include <algorithm>

int main() {
    int a = 12, b = 25, c = 9;

    int largest = std::max(a, std::max(b, c));

    std::cout << "The largest number is " << largest << std::endl;
    return 0;
}
```

**Task:** Read the three numbers from the user and print them in descending order.

## Exercise 5: Rectangle Class (area and perimeter)
**Difficulty:** Basic
**Concepts:** Classes, Constructors, Member Functions

Define a `Rectangle` class that stores width and height and provides methods to compute area and perimeter.

**Starter code:**
```cpp
#include <iostream>

class Rectangle {
private:
    double width;
    double height;

public:
    Rectangle(double w, double h) : width(w), height(h) {}

    double area() {
        return width * height;
    }

    double perimeter() {
        return 2 * (width + height);
    }
};

int main() {
    Rectangle rect(5.0, 3.0);
    std::cout << "Area: " << rect.area() << std::endl;
    std::cout << "Perimeter: " << rect.perimeter() << std::endl;
    return 0;
}
```

**Task:** Add a method that checks whether the rectangle is a square and prints both results for a user-supplied width and height.
