## Exercise 1: Define a Node and Build a List
**Difficulty:** Basic
**Concepts:** constructor, `nullptr`, `new`, pointer traversal, `std::cout`

**Starter code:**
```cpp
#include <iostream>

struct Node {
    int value;
    Node *next;
    Node(int v) : value(v), next(nullptr) {}
};

int main() {
    Node *head = new Node(10);
    head->next = new Node(20);
    head->next->next = new Node(30);

    for (Node *cur = head; cur != nullptr; cur = cur->next) {
        std::cout << cur->value << " ";
    }
    std::cout << "\n";   // prints: 10 20 30
    return 0;
}
```

**Task:** Write a `print_list(Node *head)` function that prints values separated by `" -> "` and ends with `"nullptr"`.

## Exercise 2: Append a Node to the End
**Difficulty:** Basic
**Concepts:** allocating with `new`, walking to the tail, empty-list edge case

**Starter code:**
```cpp
Node *append(Node *head, int value) {
    if (head == nullptr) return new Node(value);
    Node *cur = head;
    while (cur->next != nullptr) {
        cur = cur->next;
    }
    cur->next = new Node(value);
    return head;
}
```

**Task:** Append `1..5` to an empty list (`nullptr`) in a loop and print the list.

## Exercise 3: Length and Sum of a Linked List
**Difficulty:** Basic
**Concepts:** counting during traversal, accumulating a total

**Starter code:**
```cpp
int length(Node *head) {
    int count = 0;
    for (Node *cur = head; cur != nullptr; cur = cur->next) count++;
    return count;
}

int sum(Node *head) {
    int total = 0;
    for (Node *cur = head; cur != nullptr; cur = cur->next) total += cur->value;
    return total;
}
```

**Task:** Build `9 -> 8 -> 7` and verify `length` returns `3` and `sum` returns `24`.

## Exercise 4: Search for a Value
**Difficulty:** Basic
**Concepts:** early `return`, comparing integers, `bool` return type

**Starter code:**
```cpp
bool contains(Node *head, int target) {
    for (Node *cur = head; cur != nullptr; cur = cur->next) {
        if (cur->value == target) return true;
    }
    return false;
}
```

**Task:** Write `int index_of(Node *head, int target)` returning the 0-based index of the first match, or `-1`.

## Exercise 5: Delete the First Matching Node
**Difficulty:** Basic
**Concepts:** rewiring pointers, freeing with `delete`, head-removal case

**Starter code:**
```cpp
Node *delete_value(Node *head, int value) {
    if (head == nullptr) return nullptr;
    if (head->value == value) {
        Node *new_head = head->next;
        delete head;
        return new_head;
    }
    Node *cur = head;
    while (cur->next != nullptr && cur->next->value != value) {
        cur = cur->next;
    }
    if (cur->next != nullptr) {
        Node *to_delete = cur->next;
        cur->next = to_delete->next;
        delete to_delete;
    }
    return head;
}
```

**Task:** Test removing the head, a middle node, and a missing value from `10 -> 20 -> 30`. Forgetting `delete` causes memory leaks.
