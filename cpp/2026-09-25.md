## Exercise 1: Hello, World!
**Difficulty:** Basic
**Concepts:** `#include <iostream>`, `std::cout`, `main`, namespace.

Write the classic "Hello, World!" program.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

**Task:** Print your name and a short message on separate lines.

## Exercise 2: Read Input and Sum
**Difficulty:** Basic
**Concepts:** `std::cin`, extraction operator (`>>`), variables, arithmetic.

Read two numbers from the user and print their sum.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    double a, b;
    cout << "Enter first number: ";
    cin >> a;
    cout << "Enter second number: ";
    cin >> b;

    cout << "Sum: " << a + b << endl;
    return 0;
}
```

**Task:** Also print the difference, product, and quotient.

## Exercise 3: Even or Odd
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator, `cin`.

Read an integer and print whether it is even or odd.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int num;
    cout << "Enter an integer: ";
    cin >> num;

    if (num % 2 == 0) {
        cout << "Even" << endl;
    } else {
        cout << "Odd" << endl;
    }
    return 0;
}
```

**Task:** Add a branch that prints "Zero" when the number is 0.

## Exercise 4: Print 1 to N
**Difficulty:** Basic
**Concepts:** Loops (`for`/`while`), incrementing counters.

Print the numbers from 1 to N (read from the user).

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter N: ";
    cin >> n;

    for (int i = 1; i <= n; i++) {
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```

**Task:** Reimplement it with a `while` loop.

## Exercise 5: Vector Average
**Difficulty:** Basic
**Concepts:** `std::vector`, loops, range-based `for`, `size()`.

Compute the average of the elements in a `vector<int>`.

**Starter code:**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {4, 7, 1, 9, 3, 8};
    int sum = 0;

    for (int n : numbers) {
        sum += n;
    }

    cout << "Average: " << (double)sum / numbers.size() << endl;
    return 0;
}
```

**Task:** Also find and print the minimum and maximum using a loop.
