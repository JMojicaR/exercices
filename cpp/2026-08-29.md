## Exercise 1: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that reads an integer `n` and prints its multiplication table from 1 to 10 using a `for` loop.

**Given Input:** `5`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

### Concepts
- `std::cin` and `std::cout`
- `for` loop
- `std::endl` / `\n`

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter a number: ";
    cin >> n;

    for (int i = 1; i <= 10; i++) {
        cout << n << " x " << i << " = " << n * i << endl;
    }
    return 0;
}
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that reads three integers and prints the largest using a comparison-based approach.

**Given Input:** `10 25 15`

**Expected Output:**
```
Largest: 25
```

### Concepts
- `std::cin` for multiple inputs
- `if` statements
- Comparison operators

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cout << "Enter three numbers: ";
    cin >> a >> b >> c;

    int largest = a;
    if (b > largest) largest = b;
    if (c > largest) largest = c;

    cout << "Largest: " << largest << endl;
    return 0;
}
```

## Exercise 3: Reverse a String

**Difficulty:** Basic

### Problem
Write a program that reads a string (including spaces) and prints it reversed using `std::reverse`.

**Given Input:** `hello`

**Expected Output:**
```
Reversed: olleh
```

### Concepts
- `std::string`
- `std::getline` and `std::cin`
- `std::reverse` from `<algorithm>`

### Example / Starter Code

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    string text;
    cout << "Enter a string: ";
    getline(cin, text);

    reverse(text.begin(), text.end());
    cout << "Reversed: " << text << endl;
    return 0;
}
```

## Exercise 4: Leap Year Checker

**Difficulty:** Basic

### Problem
Write a program that reads a year and prints whether it is a leap year using the modulo operator and boolean logic.

**Given Input:** `2024`

**Expected Output:**
```
2024 is a leap year
```

### Concepts
- Modulo operator `%`
- Boolean logic with `&&` and `||`
- Ternary operator (`? :`)

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    cout << "Enter a year: ";
    cin >> year;

    bool isLeap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
    cout << year << (isLeap ? " is a leap year" : " is not a leap year") << endl;
    return 0;
}
```

## Exercise 5: Simple Calculator

**Difficulty:** Basic

### Problem
Write a program that reads two numbers and an operator (`+`, `-`, `*`, `/`) and prints the result using a `switch` statement. Handle division by zero.

**Given Input:** `8 2 /`

**Expected Output:**
```
Result: 4
```

### Concepts
- `switch` statement
- `double` arithmetic
- Division-by-zero handling

### Example / Starter Code

```cpp
#include <iostream>
using namespace std;

int main() {
    double a, b;
    char op;
    cout << "Enter two numbers: ";
    cin >> a >> b;
    cout << "Enter operator (+, -, *, /): ";
    cin >> op;

    switch (op) {
        case '+': cout << "Result: " << a + b << endl; break;
        case '-': cout << "Result: " << a - b << endl; break;
        case '*': cout << "Result: " << a * b << endl; break;
        case '/':
            if (b != 0) cout << "Result: " << a / b << endl;
            else cout << "Error: division by zero" << endl;
            break;
        default: cout << "Invalid operator" << endl;
    }
    return 0;
}
```
