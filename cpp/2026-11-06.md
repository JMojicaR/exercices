## Exercise 1: Find Maximum & Minimum
**Difficulty:** Basic
**Concepts:** `std::vector`, range-based `for`, comparisons

Find and print the smallest and largest values in a vector of integers.

**Starter code:**
```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers = {3, 1, 4, 1, 5, 9, 2};
    int min = numbers[0], max = numbers[0];
    for (int n : numbers) {
        if (n < min) min = n;
        if (n > max) max = n;
    }
    std::cout << "min = " << min << ", max = " << max << '\n'; // min = 1, max = 9
    return 0;
}
```

**Task:** Rewrite using `std::minmax_element(numbers.begin(), numbers.end())` from `<algorithm>` and print the values it points to.

## Exercise 2: Sum of Elements
**Difficulty:** Basic
**Concepts:** `std::vector`, range-based `for`, accumulator

Compute and print the sum of all elements in a vector of integers.

**Starter code:**
```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers = {1, 2, 3, 4, 5};
    int total = 0;
    for (int n : numbers) {
        total += n;
    }
    std::cout << "sum = " << total << '\n'; // sum = 15
    return 0;
}
```

**Task:** Replace the loop with `std::accumulate(numbers.begin(), numbers.end(), 0)` from `<numeric>`, then compute the average as a `double`.

## Exercise 3: Reverse a Vector
**Difficulty:** Basic
**Concepts:** `std::vector`, reverse indexing, `.push_back()`

Build a new vector holding the elements of the input in reverse order.

**Starter code:**
```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers = {1, 2, 3, 4};
    std::vector<int> reversed;
    for (int i = (int)numbers.size() - 1; i >= 0; i--) {
        reversed.push_back(numbers[i]);
    }
    for (int n : reversed) {
        std::cout << n << ' ';
    }
    std::cout << '\n'; // 4 3 2 1
    return 0;
}
```

**Task:** Use `std::reverse(numbers.begin(), numbers.end())` from `<algorithm>` to reverse in place, and compare with building a new vector.

## Exercise 4: Count Occurrences
**Difficulty:** Basic
**Concepts:** range-based `for`, equality `==`, counter

Count how many times a target value appears in a vector of integers.

**Starter code:**
```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers = {1, 2, 3, 2, 4, 2};
    int target = 2;
    int count = 0;
    for (int n : numbers) {
        if (n == target) count++;
    }
    std::cout << "count of " << target << " = " << count << '\n'; // count of 2 = 3
    return 0;
}
```

**Task:** Replace the loop with `std::count(numbers.begin(), numbers.end(), target)` from `<algorithm>`.

## Exercise 5: Remove Duplicates
**Difficulty:** Basic
**Concepts:** `std::vector`, `std::find`, membership test, order preservation

Build a new vector containing each value only once, preserving the original order.

**Starter code:**
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> numbers = {1, 2, 2, 3, 4, 4, 4, 5};
    std::vector<int> unique;
    for (int n : numbers) {
        if (std::find(unique.begin(), unique.end(), n) == unique.end()) {
            unique.push_back(n);
        }
    }
    for (int n : unique) {
        std::cout << n << ' ';
    }
    std::cout << '\n'; // 1 2 3 4 5
    return 0;
}
```

**Task:** Try the sort-then-deduplicate idiom: sort the vector, then use `std::unique` + `.erase()` to collapse consecutive duplicates.
