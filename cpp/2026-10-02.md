## Exercise 1: Area of a Circle
**Difficulty:** Basic
**Concepts:** `iostream`, `cin`/`cout`, constants (`const`), `<cmath>`, arithmetic.

Write a program that reads a radius and prints the area of a circle using `const double PI`.

**Starter code:**
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    const double PI = 3.14159;
    double radius;

    cout << "Enter radius: ";
    cin >> radius;

    double area = PI * pow(radius, 2);

    cout << "Area: " << area << endl;
    return 0;
}
```

**Task:** Also print the circumference (`2 * PI * radius`) formatted to 2 decimal places.

## Exercise 2: Swap Two Numbers (by reference)
**Difficulty:** Basic
**Concepts:** Functions, reference parameters (`&`), pass-by-reference.

Write a function `swap()` that swaps two integers using reference parameters.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

void swap(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 5, y = 10;
    cout << "Before: x = " << x << ", y = " << y << endl;

    swap(x, y);

    cout << "After: x = " << x << ", y = " << y << endl;
    return 0;
}
```

**Task:** Overload `swap` to also swap two `double` values.

## Exercise 3: Check Palindrome
**Difficulty:** Basic
**Concepts:** Strings, `std::string`, loops, string comparison, `tolower`.

Write a program that checks whether a string reads the same forwards and backwards.

**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <cctype>
using namespace std;

int main() {
    string word;
    cout << "Enter a word: ";
    cin >> word;

    string reversed(word.rbegin(), word.rend());

    if (word == reversed)
        cout << word << " is a palindrome." << endl;
    else
        cout << word << " is not a palindrome." << endl;
    return 0;
}
```

**Task:** Make the check case-insensitive and ignore spaces so "Never odd or even" works.

## Exercise 4: Fibonacci Series
**Difficulty:** Basic
**Concepts:** Loops, variable swapping, sequence generation.

Write a program that prints the first `n` Fibonacci numbers.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "How many terms? ";
    cin >> n;

    int a = 0, b = 1;
    for (int i = 0; i < n; i++) {
        cout << a << " ";
        int next = a + b;
        a = b;
        b = next;
    }
    cout << endl;
    return 0;
}
```

**Task:** Print only the Fibonacci numbers that are multiples of 3.

## Exercise 5: A Simple Student Class
**Difficulty:** Basic
**Concepts:** Classes, member variables, methods, constructors, objects.

Define a `Student` class with `name` and `age`, plus a method to print the student's details.

**Starter code:**
```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int age;

    Student(string n, int a) {
        name = n;
        age = a;
    }

    void display() {
        cout << "Name: " << name << ", Age: " << age << endl;
    }
};

int main() {
    Student s1("Luis", 20);
    s1.display();
    return 0;
}
```

**Task:** Add a `grade` field and a `bool isAdult()` method that returns `age >= 18`.
