## Exercise 1: Hello World & I/O Streams
**Difficulty:** ★☆☆☆☆  
**Concepts:** iostream, cin/cout, string, namespace, getline  

**Description:**  
Write a C++ program that collects user information (name, age, favorite programming language) and displays a formatted summary using `cout`.

**Example Starter Code:**
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name, language;
    int age;
    
    cout << "=== User Profile ===\n";
    
    cout << "Enter your name: ";
    getline(cin, name);
    
    cout << "Enter your age: ";
    cin >> age;
    cin.ignore();  // Clear the newline from buffer
    
    cout << "Enter favorite programming language: ";
    getline(cin, language);
    
    cout << "\n--- Profile Summary ---\n";
    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Favorite Language: " << language << endl;
    cout << "Birth Year: " << (2026 - age) << endl;
    
    return 0;
}
```

**Expected Output:**
```
=== User Profile ===
Enter your name: Charlie
Enter your age: 22
Enter favorite programming language: C++

--- Profile Summary ---
Name: Charlie
Age: 22
Favorite Language: C++
Birth Year: 2004
```

## Exercise 2: Function Overloading
**Difficulty:** ★★☆☆☆  
**Concepts:** Function overloading, templates (optional), arithmetic  

**Description:**  
Create a calculator class or set of overloaded functions. Use function overloading to handle different data types (int and double). Implement `add()`, `multiply()`, and `max()` for both int and double types.

**Example Starter Code:**
```cpp
#include <iostream>
using namespace std;

// Overloaded add functions
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }

// Overloaded multiply functions
int multiply(int a, int b) { return a * b; }
double multiply(double a, double b) { return a * b; }

// Overloaded max functions
int max(int a, int b) { return (a > b) ? a : b; }
double max(double a, double b) { return (a > b) ? a : b; }

int main() {
    int intA = 10, intB = 20;
    double doubleA = 12.5, doubleB = 7.3;
    
    cout << "--- Integer Operations ---\n";
    cout << intA << " + " << intB << " = " << add(intA, intB) << endl;
    cout << intA << " * " << intB << " = " << multiply(intA, intB) << endl;
    cout << "max(" << intA << ", " << intB << ") = " << max(intA, intB) << endl;
    
    cout << "\n--- Double Operations ---\n";
    cout << doubleA << " + " << doubleB << " = " << add(doubleA, doubleB) << endl;
    cout << doubleA << " * " << doubleB << " = " << multiply(doubleA, doubleB) << endl;
    cout << "max(" << doubleA << ", " << doubleB << ") = " << max(doubleA, doubleB) << endl;
    
    return 0;
}
```

**Expected Output:**
```
--- Integer Operations ---
10 + 20 = 30
10 * 20 = 200
max(10, 20) = 20

--- Double Operations ---
12.5 + 7.3 = 19.8
12.5 * 7.3 = 91.25
max(12.5, 7.3) = 12.5
```

## Exercise 3: Vector Operations
**Difficulty:** ★★☆☆☆  
**Concepts:** vectors, iterators, algorithms, push_back, sort  

**Description:**  
Use `std::vector` to create a dynamic list of numbers. Perform operations: add elements, remove elements, sort, find min/max, and calculate the average.

**Example Starter Code:**
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;

int main() {
    vector<int> numbers;
    
    // Add elements
    numbers.push_back(42);
    numbers.push_back(7);
    numbers.push_back(19);
    numbers.push_back(3);
    numbers.push_back(88);
    numbers.push_back(15);
    
    cout << "Initial vector: ";
    for (int n : numbers) cout << n << " ";
    cout << endl;
    
    // Sort
    sort(numbers.begin(), numbers.end());
    cout << "Sorted: ";
    for (int n : numbers) cout << n << " ";
    cout << endl;
    
    // Remove an element
    numbers.erase(remove(numbers.begin(), numbers.end(), 19), numbers.end());
    cout << "After removing 19: ";
    for (int n : numbers) cout << n << " ";
    cout << endl;
    
    // Min and Max
    auto [minIt, maxIt] = minmax_element(numbers.begin(), numbers.end());
    cout << "Min: " << *minIt << endl;
    cout << "Max: " << *maxIt << endl;
    
    // Sum and Average
    int sum = accumulate(numbers.begin(), numbers.end(), 0);
    double avg = static_cast<double>(sum) / numbers.size();
    cout << "Sum: " << sum << endl;
    cout << "Average: " << avg << endl;
    
    return 0;
}
```

## Exercise 4: Rectangle Class
**Difficulty:** ★★★☆☆  
**Concepts:** Classes, constructors, methods, encapsulation  

**Description:**  
Create a `Rectangle` class with private width and height fields. Include a constructor, getters/setters, and methods to calculate area, perimeter, and check if the rectangle is a square.

**Example Starter Code:**
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

class Rectangle {
private:
    double width;
    double height;

public:
    // Constructor
    Rectangle(double w, double h) : width(w), height(h) {}
    
    // Default constructor
    Rectangle() : width(1.0), height(1.0) {}
    
    // Setters
    void setWidth(double w) { width = (w > 0) ? w : 1.0; }
    void setHeight(double h) { height = (h > 0) ? h : 1.0; }
    
    // Getters
    double getWidth() const { return width; }
    double getHeight() const { return height; }
    
    // Calculated properties
    double area() const { return width * height; }
    double perimeter() const { return 2 * (width + height); }
    bool isSquare() const { return width == height; }
    
    void display() const {
        cout << "Rectangle [" << width << " x " << height << "]" << endl;
        cout << "  Area: " << area() << endl;
        cout << "  Perimeter: " << perimeter() << endl;
        cout << "  Is square? " << (isSquare() ? "Yes" : "No") << endl;
    }
};

int main() {
    Rectangle r1(5.0, 3.0);
    Rectangle r2(4.0, 4.0);
    Rectangle r3;  // Default 1x1
    
    cout << "=== Rectangle #1 ===" << endl;
    r1.display();
    
    cout << "\n=== Rectangle #2 ===" << endl;
    r2.display();
    
    cout << "\n=== Rectangle #3 ===" << endl;
    r3.display();
    
    return 0;
}
```

## Exercise 5: File I/O
**Difficulty:** ★★★☆☆  
**Concepts:** fstream, file reading/writing, stringstream  

**Description:**  
Write a program that:
1. Creates a text file and writes some data to it
2. Reads the file back and displays the content
3. Appends additional data
4. Reads and counts the number of lines and words

**Example Starter Code:**
```cpp
#include <iostream>
#include <fstream>
#include <string>
#include <sstream>
using namespace std;

int main() {
    // 1. Write to file
    ofstream outFile("notes.txt");
    outFile << "Line 1: Hello, C++ file I/O!\n";
    outFile << "Line 2: This is a basic exercise.\n";
    outFile << "Line 3: Learning to read and write files.\n";
    outFile.close();
    cout << "File written successfully.\n\n";
    
    // 2. Read from file
    ifstream inFile("notes.txt");
    string line;
    cout << "--- File Contents ---\n";
    while (getline(inFile, line)) {
        cout << line << endl;
    }
    inFile.close();
    
    // 3. Append to file
    ofstream appendFile("notes.txt", ios::app);
    appendFile << "Line 4: This line was appended!\n";
    appendFile.close();
    
    // 4. Count lines and words
    inFile.open("notes.txt");
    int lineCount = 0, wordCount = 0;
    while (getline(inFile, line)) {
        lineCount++;
        stringstream ss(line);
        string word;
        while (ss >> word) {
            wordCount++;
        }
    }
    inFile.close();
    
    cout << "\n--- Statistics ---\n";
    cout << "Lines: " << lineCount << endl;
    cout << "Words: " << wordCount << endl;
    
    return 0;
}
```
