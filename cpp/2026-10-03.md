## Exercise 1: Check Prime Number
**Difficulty:** Basic
**Concepts:** `iostream`, loops, conditionals, boolean flags, `cmath`.

Write a program that reads a number and reports whether it is prime.

**Starter code:**
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int n;
    cout << "Enter a number: ";
    cin >> n;

    bool isPrime = n >= 2;
    for (int i = 2; i <= sqrt(n) && isPrime; i++) {
        if (n % i == 0) {
            isPrime = false;
        }
    }

    cout << n << (isPrime ? " is prime" : " is not prime") << endl;
    return 0;
}
```

**Task:** Print all prime numbers between 1 and 100.

## Exercise 2: Reverse a Number
**Difficulty:** Basic
**Concepts:** `while` loop, integer arithmetic, input/output.

Write a program that reverses an integer's digits.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, reversed = 0;
    cout << "Enter a number: ";
    cin >> n;

    while (n != 0) {
        int digit = n % 10;
        reversed = reversed * 10 + digit;
        n /= 10;
    }

    cout << "Reversed = " << reversed << endl;
    return 0;
}
```

**Task:** Also count the number of digits in the original number.

## Exercise 3: Sum and Average of an Array
**Difficulty:** Basic
**Concepts:** Arrays, `for` loops, accumulation, `double` division.

Write a program that computes the sum and average of an array of integers.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[] = {12, 7, 45, 3, 28, 15};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int sum = 0;

    for (int i = 0; i < size; i++) {
        sum += numbers[i];
    }

    double average = static_cast<double>(sum) / size;
    cout << "Sum = " << sum << endl;
    cout << "Average = " << average << endl;
    return 0;
}
```

**Task:** Also find and print the largest and smallest values in the array.

## Exercise 4: Factorial (Recursive)
**Difficulty:** Basic
**Concepts:** Functions, recursion, base case, return values.

Write a recursive function that returns `n!`.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

long factorial(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

int main() {
    int n;
    cout << "Enter a number: ";
    cin >> n;
    cout << n << "! = " << factorial(n) << endl;
    return 0;
}
```

**Task:** Write an iterative version and compare the results.

## Exercise 5: A Simple Book Class
**Difficulty:** Basic
**Concepts:** Classes, member variables, constructors, member functions, objects.

Define a `Book` class with `title`, `author`, and `pages`, a constructor, and a method to display its info.

**Starter code:**
```cpp
#include <iostream>
#include <string>
using namespace std;

class Book {
public:
    string title;
    string author;
    int pages;

    Book(string t, string a, int p) : title(t), author(a), pages(p) {}

    void display() {
        cout << title << " by " << author << " (" << pages << " pages)" << endl;
    }
};

int main() {
    Book b1("1984", "George Orwell", 328);
    b1.display();
    return 0;
}
```

**Task:** Add a `bool isLong()` method that returns true if `pages > 300`, and test it.
