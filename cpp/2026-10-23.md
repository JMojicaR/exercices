## Exercise 1: Print the ASCII Value of a Character
**Difficulty:** Basic
**Concepts:** `char` type, implicit casting, `cout`

Given a character, print its ASCII value.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    char ch = 'A';
    cout << "ASCII value of " << ch << " is " << int(ch) << endl;
    return 0;
}
```

**Task:** Loop over the alphabet (`for (char c = 'A'; c <= 'Z'; c++)`) printing each letter and its code.

## Exercise 2: Check Vowel or Consonant
**Difficulty:** Basic
**Concepts:** `if / else`, logical operators, `tolower` from `<cctype>`

Read a letter and report whether it is a vowel or a consonant.

**Starter code:**
```cpp
#include <iostream>
#include <cctype>
using namespace std;

int main() {
    char ch = 'e';
    ch = tolower(ch);

    if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u')
        cout << ch << " is a vowel" << endl;
    else
        cout << ch << " is a consonant" << endl;

    return 0;
}
```

**Task:** Use `isalpha(ch)` to reject non-letter input, and read the character from the user with `cin`.

## Exercise 3: Maximum and Minimum in a Vector
**Difficulty:** Basic
**Concepts:** `std::vector`, range-based `for`, `std::minmax_element`

Find the largest and smallest values in a collection of numbers.

**Starter code:**
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> numbers = {45, 12, 78, 34, 89, 23};
    int max = numbers[0];
    int min = numbers[0];

    for (int n : numbers) {
        if (n > max) max = n;
        if (n < min) min = n;
    }

    cout << "Max: " << max << ", Min: " << min << endl;
    return 0;
}
```

**Task:** Rewrite using `minmax_element(numbers.begin(), numbers.end())` and print the results via the returned iterators.

## Exercise 4: Simple Calculator
**Difficulty:** Basic
**Concepts:** `switch`, arithmetic operators, `cin`

Build a calculator that reads two numbers and an operator and prints the result.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    double a, b;
    char op;

    cout << "Enter expression (e.g. 10 + 5): ";
    cin >> a >> op >> b;

    switch (op) {
        case '+': cout << a + b << endl; break;
        case '-': cout << a - b << endl; break;
        case '*': cout << a * b << endl; break;
        case '/':
            if (b != 0) cout << a / b << endl;
            else cout << "Cannot divide by zero" << endl;
            break;
        default: cout << "Invalid operator" << endl;
    }
    return 0;
}
```

**Task:** Wrap the logic in a function `double calculate(double a, char op, double b)` and call it from `main`.

## Exercise 5: Print Prime Numbers in a Range
**Difficulty:** Basic
**Concepts:** nested loops, `break`, boolean flags

Print every prime number between two given bounds (e.g. 10 and 50).

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int start = 10, end = 50;

    for (int num = start; num <= end; num++) {
        bool isPrime = num >= 2;
        for (int i = 2; i * i <= num; i++) {
            if (num % i == 0) {
                isPrime = false;
                break;
            }
        }
        if (isPrime) cout << num << " ";
    }
    cout << endl;
    return 0;
}
```

**Task:** Extract the check into a `bool isPrime(int n)` function and print the count of primes found.
