## Exercise 3: Factorial
- **Difficulty:** Easy
- **Description:** Write a function `factorial(int n)` that returns n! using recursion, and print `factorial(5)`.
- **Concepts:** functions, recursion, base case
- **Starter code:**
```cpp
#include <iostream>

int factorial(int n) {
    if (n == 0) return 1;
    return n * factorial(n - 1);
}

int main() {
    std::cout << factorial(5) << std::endl; // 120
    return 0;
}
```
