## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** iostream, for loop, functions

Compute the factorial of a non-negative integer using a function.

**Starter code:**
```cpp
#include <iostream>

long long factorial(int n) {
    long long result = 1;
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
    return result;
}

int main() {
    int n;
    std::cout << "Enter a non-negative integer: ";
    std::cin >> n;
    std::cout << n << "! = " << factorial(n) << "\n";
    return 0;
}
```

**Task:** Print the factorial of every number from 1 to 10 in a loop.

## Exercise 2: Prime Number Check
**Difficulty:** Basic
**Concepts:** for loop, modulo, bool

Read an integer and print whether it is prime.

**Starter code:**
```cpp
#include <iostream>

int main() {
    int n;
    std::cout << "Enter a positive integer: ";
    std::cin >> n;

    bool isPrime = n > 1;
    for (int i = 2; i * i <= n && isPrime; i++) {
        if (n % i == 0) isPrime = false;
    }
    std::cout << n << (isPrime ? " is prime" : " is not prime") << "\n";
    return 0;
}
```

**Task:** Print all primes between 2 and 100 using a nested loop.

## Exercise 3: Count Vowels in a String
**Difficulty:** Basic
**Concepts:** std::string, range-based for, find

Count the vowels in a string, case-insensitively.

**Starter code:**
```cpp
#include <iostream>
#include <string>

int main() {
    std::string text;
    std::cout << "Enter some text: ";
    std::getline(std::cin, text);

    const std::string vowels = "aeiou";
    int count = 0;
    for (char ch : text) {
        ch = std::tolower(ch);
        if (vowels.find(ch) != std::string::npos) count++;
    }
    std::cout << "Vowel count: " << count << "\n";
    return 0;
}
```

**Task:** Count each vowel separately and print the totals.

## Exercise 4: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** arrays, for loop

Sum the elements of an integer array.

**Starter code:**
```cpp
#include <iostream>

int main() {
    int numbers[] = {3, 8, 2, 7, 1};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int sum = 0;
    for (int i = 0; i < size; i++) {
        sum += numbers[i];
    }
    std::cout << "Sum: " << sum << "\n";
    return 0;
}
```

**Task:** Also print the average and the minimum value.

## Exercise 5: Area of a Circle
**Difficulty:** Basic
**Concepts:** constants, cmath, double

Read a radius and print the area of the circle (`area = π * r²`).

**Starter code:**
```cpp
#include <iostream>
#include <cmath>

int main() {
    const double PI = 3.141592653589793;
    double radius;
    std::cout << "Enter the radius: ";
    std::cin >> radius;
    double area = PI * std::pow(radius, 2);
    std::cout << "Area: " << area << "\n";
    return 0;
}
```

**Task:** Use `M_PI` from `<cmath>` (or define your own) and also print the circumference.
