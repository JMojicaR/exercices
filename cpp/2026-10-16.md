## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** string, std::reverse, iterators

Read a string and print it reversed.

**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <algorithm>

int main() {
    std::string text;
    std::cout << "Enter a string: ";
    std::getline(std::cin, text);

    std::reverse(text.begin(), text.end());
    std::cout << "Reversed: " << text << std::endl;
    return 0;
}
```

**Task:** Reverse the string using a loop and `rbegin()`/`rend()` instead of `std::reverse`.

## Exercise 2: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** conditionals, cin, comparisons

Read three numbers and print the largest.

**Starter code:**
```cpp
#include <iostream>

int main() {
    int a, b, c;
    std::cout << "Enter three numbers: ";
    std::cin >> a >> b >> c;

    int largest = a;
    if (b > largest) largest = b;
    if (c > largest) largest = c;

    std::cout << "Largest: " << largest << std::endl;
    return 0;
}
```

**Task:** Rewrite using `std::max({a, b, c})` from `<algorithm>`.

## Exercise 3: Multiplication Table
**Difficulty:** Basic
**Concepts:** for loop, output

Print the multiplication table (1 to 10) for a given number.

**Starter code:**
```cpp
#include <iostream>

int main() {
    int n;
    std::cout << "Enter a number: ";
    std::cin >> n;

    for (int i = 1; i <= 10; i++) {
        std::cout << n << " x " << i << " = " << n * i << std::endl;
    }
    return 0;
}
```

**Task:** Print tables for all numbers from 1 to 5.

## Exercise 4: Armstrong Number
**Difficulty:** Basic
**Concepts:** while loop, modulo, pow, digit counting

Check whether a number is an Armstrong number.

**Starter code:**
```cpp
#include <iostream>
#include <cmath>

int main() {
    int n, original, remainder, digits = 0;
    int sum = 0;

    std::cout << "Enter a positive integer: ";
    std::cin >> n;
    original = n;

    for (int temp = n; temp != 0; temp /= 10) digits++;
    for (int temp = n; temp != 0; temp /= 10) {
        remainder = temp % 10;
        sum += std::pow(remainder, digits);
    }

    if (sum == original) {
        std::cout << original << " is an Armstrong number" << std::endl;
    } else {
        std::cout << original << " is not an Armstrong number" << std::endl;
    }
    return 0;
}
```

**Task:** Print all Armstrong numbers between 1 and 1000.

## Exercise 5: Count Digits in a Number
**Difficulty:** Basic
**Concepts:** while loop, integer division, counting

Count the digits of an integer.

**Starter code:**
```cpp
#include <iostream>

int main() {
    int n, count = 0;
    std::cout << "Enter an integer: ";
    std::cin >> n;

    if (n == 0) {
        count = 1;
    } else {
        while (n != 0) {
            n /= 10;
            count++;
        }
    }

    std::cout << "Number of digits: " << count << std::endl;
    return 0;
}
```

**Task:** Count the digits of a negative number correctly (ignoring the sign).
