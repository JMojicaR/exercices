## 1. Temperature Converter
**Description:** Convert a temperature between Celsius and Fahrenheit based on user input, using `std::cin` and `std::cout`.
**Difficulty:** Basic
**Concepts:** `iostream`, `std::cin`/`std::cout`, functions, arithmetic, `std::fixed`/`std::setprecision`.
**Starter code:**
```cpp
#include <iostream>
#include <iomanip>

double toFahrenheit(double c) { return c * 9.0 / 5.0 + 32.0; }
double toCelsius(double f) { return (f - 32.0) * 5.0 / 9.0; }

int main() {
    double temp;
    char scale;
    std::cout << "Enter temperature and scale (e.g. 100 C): ";
    std::cin >> temp >> scale;

    std::cout << std::fixed << std::setprecision(1);
    if (scale == 'C' || scale == 'c') {
        std::cout << temp << "C = " << toFahrenheit(temp) << "F\n";
    } else if (scale == 'F' || scale == 'f') {
        std::cout << temp << "F = " << toCelsius(temp) << "C\n";
    } else {
        std::cout << "Unknown scale\n";
    }
    return 0;
}
```

## 2. Prime Number Check
**Description:** Read an integer and determine whether it is prime (greater than 1, divisible only by 1 and itself).
**Difficulty:** Basic
**Concepts:** `for` loop, modulo `%`, `bool`, early return, `<cmath>`.
**Starter code:**
```cpp
#include <iostream>
#include <cmath>

bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= std::sqrt(n); i++) {
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    int n;
    std::cout << "Enter a number: ";
    std::cin >> n;
    std::cout << n << (isPrime(n) ? " is prime\n" : " is not prime\n");
    return 0;
}
```

## 3. Count Vowels in a String
**Description:** Read a line of text and count the number of vowels (a, e, i, o, u), ignoring case.
**Difficulty:** Basic
**Concepts:** `std::string`, `std::getline`, range-based `for`, `tolower`, `switch` or `if`.
**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <cctype>

int main() {
    std::string text;
    std::cout << "Enter a sentence: ";
    std::getline(std::cin, text);

    int count = 0;
    for (char ch : text) {
        ch = std::tolower(ch);
        if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u') {
            count++;
        }
    }
    std::cout << "Vowel count: " << count << "\n";
    return 0;
}
```

## 4. Multiplication Table
**Description:** Print the multiplication table (1–10) for a user-provided number.
**Difficulty:** Basic
**Concepts:** `for` loop, `std::cout` formatting.
**Starter code:**
```cpp
#include <iostream>

int main() {
    int n;
    std::cout << "Enter a number: ";
    std::cin >> n;

    for (int i = 1; i <= 10; i++) {
        std::cout << n << " x " << i << " = " << n * i << "\n";
    }
    return 0;
}
```

## 5. Swap Two Numbers (by Reference)
**Description:** Write a function that swaps two integers using reference parameters, then demonstrate it from `main`.
**Difficulty:** Basic
**Concepts:** Functions, reference parameters (`int&`), call by reference.
**Starter code:**
```cpp
#include <iostream>

void swap(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 5, y = 10;
    std::cout << "Before: x=" << x << ", y=" << y << "\n";
    swap(x, y);
    std::cout << "After:  x=" << x << ", y=" << y << "\n";
    return 0;
}
```
