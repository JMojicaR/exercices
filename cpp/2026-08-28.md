## Exercise 1: Hello World

**Difficulty:** Basic

### Problem
Write a C++ program that prints "Hello, World!" and then prints the value of an integer and a string variable.

**Expected Output:**
```
Hello, World!
Name: Alice, Age: 25
```

### Concepts
- `#include <iostream>`
- `std::cout` with the `<<` insertion operator
- Variables and `std::string`

### Example / Starter Code

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name = "Alice";
    int age = 25;

    std::cout << "Hello, World!" << std::endl;
    std::cout << "Name: " << name << ", Age: " << age << std::endl;

    return 0;
}
```

## Exercise 2: Even or Odd

**Difficulty:** Basic

### Problem
Write a C++ program that reads an integer and prints whether it is even or odd.

**Given Input:** `7`

**Expected Output:**
```
Enter a number: 7
7 is Odd
```

### Concepts
- `std::cin` for input
- `if`/`else` and the modulo operator `%`

### Example / Starter Code

```cpp
#include <iostream>

int main() {
    int number;

    std::cout << "Enter a number: ";
    std::cin >> number;

    if (number % 2 == 0) {
        std::cout << number << " is Even" << std::endl;
    } else {
        std::cout << number << " is Odd" << std::endl;
    }

    return 0;
}
```

## Exercise 3: Sum of Numbers 1 to N

**Difficulty:** Basic

### Problem
Write a C++ program that reads a positive integer `n` and prints the sum of all integers from 1 to `n`.

**Given Input:** `10`

**Expected Output:**
```
Sum from 1 to 10 is 55
```

### Concepts
- `for` loop
- Accumulator variable

### Example / Starter Code

```cpp
#include <iostream>

int main() {
    int n, total = 0;

    std::cout << "Enter a positive integer: ";
    std::cin >> n;

    for (int i = 1; i <= n; i++) {
        total += i;
    }

    std::cout << "Sum from 1 to " << n << " is " << total << std::endl;

    return 0;
}
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a C++ program that counts the vowels (a, e, i, o, u) in a string, ignoring case.

**Given Input:** `"Hello World"`

**Expected Output:**
```
Number of vowels: 3
```

### Concepts
- `std::string`
- Range-based `for` loop
- `std::tolower()` from `<cctype>`

### Example / Starter Code

```cpp
#include <iostream>
#include <string>
#include <cctype>

int main() {
    std::string text = "Hello World";
    int count = 0;

    for (char c : text) {
        c = std::tolower(c);
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            count++;
        }
    }

    std::cout << "Number of vowels: " << count << std::endl;

    return 0;
}
```

## Exercise 5: Find the Maximum in a Vector

**Difficulty:** Basic

### Problem
Write a C++ program that stores numbers in a `std::vector` and finds the maximum value.

**Given Input:** `{12, 5, 8, 130, 44}`

**Expected Output:**
```
Maximum is 130
```

### Concepts
- `std::vector` and `push_back()`
- Range-based `for` loop traversal
- Tracking a running maximum

### Example / Starter Code

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers = {12, 5, 8, 130, 44};

    int max = numbers[0];
    for (int num : numbers) {
        if (num > max) {
            max = num;
        }
    }

    std::cout << "Maximum is " << max << std::endl;

    return 0;
}
```
