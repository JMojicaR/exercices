## Exercise 1: Linear Search
**Difficulty:** Basic
**Concepts:** `for` loop, `std::vector`, indexing, comparison, function return

Write a function that searches for a target value in a vector and returns its index, or `-1` if not found.

**Starter code:**
```cpp
#include <iostream>
#include <vector>

int linearSearch(const std::vector<int>& arr, int target) {
    for (int i = 0; i < arr.size(); i++) {
        if (arr[i] == target) {
            return i;
        }
    }
    return -1;
}

int main() {
    std::vector<int> numbers = {10, 23, 45, 70, 11, 15};
    std::cout << linearSearch(numbers, 70) << "\n"; // expected: 3
    std::cout << linearSearch(numbers, 99) << "\n"; // expected: -1
    return 0;
}
```

**Task:** Convert the function to use a range-based `for` loop with an index counter.

## Exercise 2: Binary Search
**Difficulty:** Basic
**Concepts:** `while` loop, midpoint index, sorted input, integer arithmetic

Search for a target in a *sorted* vector using binary search, halving the search range each step.

**Starter code:**
```cpp
#include <iostream>
#include <vector>

int binarySearch(const std::vector<int>& arr, int target) {
    int low = 0, high = arr.size() - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] == target) return mid;
        if (arr[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}

int main() {
    std::vector<int> sorted = {1, 3, 5, 7, 9, 11, 13};
    std::cout << binarySearch(sorted, 9) << "\n"; // expected: 4
    std::cout << binarySearch(sorted, 4) << "\n"; // expected: -1
    return 0;
}
```

**Task:** Print `low`, `high`, and `mid` at the start of each iteration to visualize how the range shrinks.

## Exercise 3: Bubble Sort
**Difficulty:** Basic
**Concepts:** nested `for` loops, `std::swap`, comparison operators, pass by reference

Sort a vector in ascending order using bubble sort (repeatedly swap adjacent out-of-order elements).

**Starter code:**
```cpp
#include <iostream>
#include <vector>

void bubbleSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                std::swap(arr[j], arr[j + 1]);
            }
        }
    }
}

int main() {
    std::vector<int> data = {64, 34, 25, 12, 22, 11, 90};
    bubbleSort(data);
    for (int v : data) std::cout << v << " ";
    std::cout << "\n"; // expected: 11 12 22 25 34 64 90
    return 0;
}
```

**Task:** Add a `bool swapped` flag that breaks out of the outer loop early when a pass makes no swaps.

## Exercise 4: Find Minimum and Maximum
**Difficulty:** Basic
**Concepts:** iteration, comparison, `std::pair`, reference return, empty-vector edge case

Find and return the smallest and largest values in a vector in a single pass using a `std::pair`.

**Starter code:**
```cpp
#include <iostream>
#include <vector>
#include <utility>

std::pair<int, int> findMinMax(const std::vector<int>& arr) {
    if (arr.empty()) return {0, 0};
    int min = arr[0], max = arr[0];
    for (int v : arr) {
        if (v < min) min = v;
        if (v > max) max = v;
    }
    return {min, max};
}

int main() {
    std::vector<int> nums = {45, 2, 78, 13, 9, 54};
    auto [lo, hi] = findMinMax(nums); // structured binding (C++17)
    std::cout << "Min: " << lo << " Max: " << hi << "\n"; // Min: 2 Max: 78
    return 0;
}
```

**Task:** Also return the *indices* of the min and max elements (hint: use `std::distance` or track indices manually).

## Exercise 5: Selection Sort
**Difficulty:** Basic
**Concepts:** nested loops, index tracking, `std::swap`, finding the minimum in a sub-range

Sort a vector using selection sort: repeatedly find the smallest remaining element and move it to the front.

**Starter code:**
```cpp
#include <iostream>
#include <vector>

void selectionSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        std::swap(arr[i], arr[minIdx]);
    }
}

int main() {
    std::vector<int> data = {29, 10, 14, 37, 13};
    selectionSort(data);
    for (int v : data) std::cout << v << " ";
    std::cout << "\n"; // expected: 10 13 14 29 37
    return 0;
}
```

**Task:** Sort in *descending* order by changing a single comparison, and skip the swap when `minIdx == i`.
