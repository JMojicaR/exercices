## Exercise 1: Simple Calculator
- **Difficulty:** Easy
- **Description:** Read two numbers and an operator from the user and print the result using `switch`. Handle division by zero.
- **Concepts:** `std::cin`/`std::cout`, `switch`, arithmetic
- **Starter code:**
```cpp

    double a, b;
    char op;
    std::cout << "Enter a op b: ";
    std::cin >> a >> op >> b;

    switch (op) {
        case '+': std::cout << a + b << "\n"; break;
        // TODO: add cases for '-', '*', '/'
        default: std::cout << "Unknown operator\n";
```
