## Exercise 2: Simple Calculator with Switch
- **Difficulty**: Basic
- **Concepts**: `switch` statement, User I/O (`cin`/`cout`), Arithmetic operators
- **Description**: Write a simple calculator that takes two numbers and an operator (+, -, *, /) from the user and performs the corresponding arithmetic operation. Use a `switch` statement to select the operation. Handle division by zero gracefully.

### Example/Starter Code
```cpp
#include <iostream>
using namespace std;

int main() {
    char op;
    double num1, num2;
    
    cout << "Enter operator (+, -, *, /): ";
    cin >> op;
    
    cout << "Enter two numbers: ";
    cin >> num1 >> num2;
    
    switch(op) {
        case '+':
            cout << num1 << " + " << num2 << " = " << num1 + num2;
            break;
        case '-':
            cout << num1 << " - " << num2 << " = " << num1 - num2;
            break;
        case '*':
            cout << num1 << " * " << num2 << " = " << num1 * num2;
            break;
        case '/':
            if (num2 != 0)
                cout << num1 << " / " << num2 << " = " << num1 / num2;
            else
                cout << "Error! Division by zero.";
            break;
        default:
            cout << "Invalid operator!";
    }
    
    cout << endl;
    return 0;
}
```

## Exercise 3: Find the Largest of Three Numbers
- **Difficulty**: Basic
- **Concepts**: Conditional statements (`if-else if-else`), Comparison operators
- **Description**: Write a program that reads three numbers from the user and determines which one is the largest. Practice nested conditionals and logical thinking with comparisons.

### Example/Starter Code
```cpp
#include <iostream>
using namespace std;

int main() {
    double a, b, c;
    
    cout << "Enter three numbers: ";
    cin >> a >> b >> c;
    
    // Find and print the largest number
    if (a >= b && a >= c) {
        cout << "Largest = " << a;
    } else if (b >= a && b >= c) {
        cout << "Largest = " << b;
    } else {
        cout << "Largest = " << c;
    }
    
    cout << endl;
    return 0;
}
```

## Exercise 4: Fibonacci Series
- **Difficulty**: Basic
- **Concepts**: Loops (`for`), Sequence generation, Multiple variable update
- **Description**: Write a program that prints the first N terms of the Fibonacci series. The Fibonacci sequence starts with 0 and 1, and each subsequent term is the sum of the two preceding terms. Example: 0, 1, 1, 2, 3, 5, 8, 13, ...

### Example/Starter Code
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, t1 = 0, t2 = 1, nextTerm;
    
    cout << "Enter the number of terms: ";
    cin >> n;
    
    cout << "Fibonacci Series: ";
    
    for (int i = 1; i <= n; i++) {
        if (i == 1) {
            cout << t1;
        } else if (i == 2) {
            cout << ", " << t2;
        } else {
            nextTerm = t1 + t2;
            t1 = t2;
            t2 = nextTerm;
            cout << ", " << nextTerm;
        }
    }
    
    cout << endl;
    return 0;
}
```

## Exercise 5: Reverse a String
- **Difficulty**: Basic
- **Concepts**: Strings (`std::string`), String length, Loops, Character indexing
- **Description**: Write a program that takes a string input from the user and prints its reverse. This exercise introduces `std::string`, accessing individual characters by index, and iterating backwards through a string.

### Example/Starter Code
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string str;
    
    cout << "Enter a string: ";
    getline(cin, str);
    
    cout << "Reversed string: ";
    
    // Print characters in reverse order
    for (int i = str.length() - 1; i >= 0; i--) {
        cout << str[i];
    }
    
    cout << endl;
    return 0;
}
```
