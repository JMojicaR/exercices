## Exercise 1: Create a Map & Insert/Access
**Difficulty:** Basic
**Concepts:** `std::map`, `operator[]`, `.insert()`, ordered vs unordered

Store and retrieve country→capital pairs.

**Starter code:**
```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, std::string> capitals;

    capitals["Mexico"] = "Mexico City";
    capitals["France"] = "Paris";
    capitals.insert({"Japan", "Tokyo"});

    std::cout << capitals["France"] << "\n";  // Paris
    std::cout << capitals.at("Mexico") << "\n"; // Mexico City

    for (const auto& [country, capital] : capitals) {
        std::cout << country << " -> " << capital << "\n";
    }
    return 0;
}
```

**Task:** Access a missing key with `capitals["Italy"]` and observe that it inserts an empty string; then use `.at("Italy")` to see the difference (it throws `std::out_of_range`).

## Exercise 2: Word Frequencies with unordered_map
**Difficulty:** Basic
**Concepts:** `std::unordered_map`, `operator[]` auto-insert, splitting input, frequency counting

Count how many times each word appears in a sentence.

**Starter code:**
```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <unordered_map>

int main() {
    std::string sentence = "the cat and the dog and the bird";
    std::unordered_map<std::string, int> counts;

    std::istringstream stream(sentence);
    std::string word;
    while (stream >> word) {
        counts[word]++;
    }

    for (const auto& [word, count] : counts) {
        std::cout << word << ": " << count << "\n";
    }
    return 0;
}
```

**Task:** Print the results ordered alphabetically by copying the pairs into a `std::map<std::string, int>` and iterating that instead.

## Exercise 3: Find, Erase & Count
**Difficulty:** Basic
**Concepts:** `.find()`, `.erase()`, `.count()`, `.size()`, iterator safety

Manage an inventory and safely remove an entry.

**Starter code:**
```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> stock = {
        {"apples", 10}, {"bananas", 5}, {"cherries", 20}
    };

    auto it = stock.find("bananas");
    if (it != stock.end()) {
        stock.erase(it);
    }

    std::cout << "bananas count: " << stock.count("bananas") << "\n"; // 0
    std::cout << "items: " << stock.size() << "\n";                   // 2
    return 0;
}
```

**Task:** Use `if (stock.contains("cherries"))` (C++20) as an alternative to `find`, and print whether cherries are still in stock.

## Exercise 4: Insert-or-Update Logic
**Difficulty:** Basic
**Concepts:** distinguishing insert from update, `std::pair`, `emplace` return value

Write a function that increments a counter, inserting the key first if needed.

**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <unordered_map>

void add_score(std::unordered_map<std::string, int>& scores,
               const std::string& name, int points) {
    auto result = scores.emplace(name, points);
    if (!result.second) {           // key already existed
        result.first->second += points;
    }
}

int main() {
    std::unordered_map<std::string, int> scores;
    add_score(scores, "Alice", 10);
    add_score(scores, "Alice", 5);   // now 15
    add_score(scores, "Bob", 8);

    for (const auto& [name, score] : scores) {
        std::cout << name << ": " << score << "\n";
    }
    return 0;
}
```

**Task:** Change the behavior so that a duplicate call *replaces* the score instead of adding to it (set `result.first->second = points`).

## Exercise 5: Find the Key with the Maximum Value
**Difficulty:** Basic
**Concepts:** `std::max_element`, iterators, lambda comparators, empty-map handling

Find the student with the highest grade.

**Starter code:**
```cpp
#include <algorithm>
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> grades = {
        {"Alice", 85}, {"Bob", 72}, {"Carol", 90}, {"Dave", 78}
    };

    auto best = std::max_element(
        grades.begin(), grades.end(),
        [](const auto& a, const auto& b) { return a.second < b.second; });

    std::cout << best->first << " has the highest grade: "
              << best->second << "\n";  // Carol, 90
    return 0;
}
```

**Task:** Guard against an empty map with `if (grades.empty()) { ... }` before calling `max_element`.
