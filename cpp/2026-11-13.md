## Exercise 1: Write Text to a File
**Difficulty:** Basic
**Concepts:** `std::ofstream`, `operator<<`, checking `.is_open()`

Write a program that creates a file named `notes.txt` and writes two lines into it. `ofstream` opens the file for writing and creates it if it doesn't exist.

**Starter code:**
```cpp
#include <iostream>
#include <fstream>

int main() {
    std::ofstream out("notes.txt");
    if (!out.is_open()) {
        std::cout << "Could not open file.\n";
        return 1;
    }
    out << "First line\n";
    out << "Second line\n";
    out.close();
    std::cout << "File written.\n";
    return 0;
}
```

**Task:** Write the numbers 1 through 5, one per line, using a `for` loop and `out << i << '\n';`.

## Exercise 2: Read a File Line by Line
**Difficulty:** Basic
**Concepts:** `std::ifstream`, `std::getline`, `std::string`

Write a program that opens `notes.txt` and prints its contents to the console line by line.

**Starter code:**
```cpp
#include <iostream>
#include <fstream>
#include <string>

int main() {
    std::ifstream in("notes.txt");
    if (!in.is_open()) {
        std::cout << "Could not open file.\n";
        return 1;
    }
    std::string line;
    while (std::getline(in, line)) {
        std::cout << line << '\n';
    }
    in.close();
    return 0;
}
```

**Task:** Read the whole file at once using `std::string content((std::istreambuf_iterator<char>(in)), std::istreambuf_iterator<char>());` and print it.

## Exercise 3: Append a Line to a File
**Difficulty:** Basic
**Concepts:** `ofstream` with `std::ios::app`, preserving existing content

Write a program that adds a new line to the end of `notes.txt` without deleting the existing content.

**Starter code:**
```cpp
#include <iostream>
#include <fstream>

int main() {
    std::ofstream out("notes.txt", std::ios::app);
    if (!out.is_open()) {
        std::cout << "Could not open file.\n";
        return 1;
    }
    out << "Appended line\n";
    out.close();
    std::cout << "Appended.\n";
    return 0;
}
```

**Task:** Append the numbers 1 through 5 in a loop, then read the file back to confirm the original lines remain.

## Exercise 4: Count Words in a File
**Difficulty:** Basic
**Concepts:** `std::getline`, `std::istringstream`, `operator>>` for word extraction

Write a program that opens `notes.txt` and reports the number of lines and the total number of words it contains.

**Starter code:**
```cpp
#include <iostream>
#include <fstream>
#include <sstream>
#include <string>

int main() {
    std::ifstream in("notes.txt");
    std::string line;
    int lines = 0;
    int words = 0;
    while (std::getline(in, line)) {
        lines++;
        std::istringstream iss(line);
        std::string word;
        while (iss >> word) {
            words++;
        }
    }
    std::cout << "Lines: " << lines << '\n';
    std::cout << "Words: " << words << '\n';
    return 0;
}
```

**Task:** Also count characters using `line.size()`, and print the longest line's length. Then count how many lines contain the word "the".

## Exercise 5: Copy a File
**Difficulty:** Basic
**Concepts:** `ifstream` + `ofstream`, `.rdbuf()` stream copy

Write a program that copies the contents of `notes.txt` into a new file named `notes_copy.txt`.

**Starter code:**
```cpp
#include <iostream>
#include <fstream>

int main() {
    std::ifstream src("notes.txt");
    std::ofstream dst("notes_copy.txt");
    if (!src.is_open() || !dst.is_open()) {
        std::cout << "Could not open files.\n";
        return 1;
    }
    dst << src.rdbuf();
    src.close();
    dst.close();
    std::cout << "Copied.\n";
    return 0;
}
```

**Task:** Rewrite the copy manually with a `std::string line;` / `std::getline` loop and print each line as it is copied. Then use `std::filesystem::exists` to check the destination before overwriting.
