## Exercise 1: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a C++ program that reads a non-negative integer and prints its factorial using a `for` loop. Factorial of 0 is 1.

**Given Input:** `5`

**Expected Output:**
```
Factorial of 5 is 120
```

### Concepts
- `std::cin` / `std::cout`
- `for` loop accumulator
- `unsigned long long` type

### Example / Starter Code

```cpp
#include <iostream>

int main() {
    int n;
    unsigned long long factorial = 1;

    std::cout << "Enter a number: ";
    std::cin >> n;

    for (int i = 1; i <= n; i++) {
        factorial *= i;
    }

    std::cout << "Factorial of " << n << " is " << factorial << "\n";
    return 0;
}
```

## Exercise 2: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a C++ program that prints the first `n` terms of the Fibonacci sequence (`0, 1, 1, 2, 3, 5, …`).

**Given Input:** `7`

**Expected Output:**
```
0
1
1
2
3
5
8
```

### Concepts
- `for` loop
- Swapping variables
- Output streaming

### Example / Starter Code

```cpp
#include <iostream>

int main() {
    int n, a = 0, b = 1;

    std::cout << "How many terms? ";
    std::cin >> n;

    for (int i = 0; i < n; i++) {
        std::cout << a << "\n";
        int next = a + b;
        a = b;
        b = next;
    }
    return 0;
}
```

## Exercise 3: Palindrome Check

**Difficulty:** Basic

### Problem
Write a C++ program that reads a string and checks whether it is a palindrome (case-insensitive) using `std::string`.

**Given Input:** `Racecar`

**Expected Output:**
```
racecar is a palindrome
```

### Concepts
- `std::string` and `std::tolower`
- Two-pointer comparison
- `if`/`else`

### Example / Starter Code

```cpp
#include <iostream>
#include <string>
#include <cctype>

int main() {
    std::string text;
    std::cout << "Enter a string: ";
    std::cin >> text;

    for (char& c : text) {
        c = std::tolower(c);
    }

    bool isPalindrome = true;
    int len = text.length();
    for (int i = 0; i < len / 2; i++) {
        if (text[i] != text[len - 1 - i]) {
            isPalindrome = false;
            break;
        }
    }

    if (isPalindrome) {
        std::cout << text << " is a palindrome\n";
    } else {
        std::cout << text << " is not a palindrome\n";
    }
    return 0;
}
```

## Exercise 4: Prime Number Check

**Difficulty:** Basic

### Problem
Write a C++ program that reads a positive integer and determines whether it is a prime number.

**Given Input:** `29`

**Expected Output:**
```
29 is a prime number
```

### Concepts
- `for` loop with `break`
- Modulo operator `%`
- `sqrt()` from `<cmath>`

### Example / Starter Code

```cpp
#include <iostream>
#include <cmath>

int main() {
    int n;
    std::cout << "Enter a number: ";
    std::cin >> n;

    bool isPrime = n > 1;
    for (int i = 2; isPrime && i <= std::sqrt(n); i++) {
        if (n % i == 0) {
            isPrime = false;
        }
    }

    if (isPrime) {
        std::cout << n << " is a prime number\n";
    } else {
        std::cout << n << " is not a prime number\n";
    }
    return 0;
}
```

## Exercise 5: Sum of Digits

**Difficulty:** Basic

### Problem
Write a C++ program that reads a positive integer and prints the sum of its digits.

**Given Input:** `12345`

**Expected Output:**
```
Sum of digits: 15
```

### Concepts
- `while` loop
- Modulo `%` and integer division `/`
- Digit extraction

### Example / Starter Code

```cpp
#include <iostream>

int main() {
    int n, total = 0;

    std::cout << "Enter a number: ";
    std::cin >> n;

    while (n > 0) {
        total += n % 10;
        n /= 10;
    }

    std::cout << "Sum of digits: " << total << "\n";
    return 0;
}
```
