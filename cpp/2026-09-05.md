## 2. Even or Odd
- **Description**: Read an integer from the user and print whether it is even or odd.
- **Difficulty**: Beginner
- **Concepts**: `std::cin`, `%` operator, `if/else`
- **Example/Starter code**:
```cpp
#include <iostream>
using namespace std;

int main() {
    int number;
    cout << "Enter a number: ";
    cin >> number;
    if (number % 2 == 0) {
        cout << number << " is even" << endl;
    } else {
        cout << number << " is odd" << endl;
    }
    return 0;
}
```

## 3. Sum of First N Numbers
- **Description**: Take a positive integer N and print the sum of all integers from 1 to N.
- **Difficulty**: Beginner
- **Concepts**: `for` loops, accumulation
- **Example/Starter code**:
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, sum = 0;
    cout << "Enter a positive integer: ";
    cin >> n;
    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    cout << "Sum from 1 to " << n << " is " << sum << endl;
    return 0;
}
```

## 4. Largest Element in an Array
- **Description**: Write a program that finds and prints the largest element in an array of integers.
- **Difficulty**: Beginner
- **Concepts**: Arrays, `for` loops, comparison
- **Example/Starter code**:
```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[] = {3, 9, 1, 14, 6};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int largest = numbers[0];
    for (int i = 1; i < size; i++) {
        if (numbers[i] > largest) {
            largest = numbers[i];
        }
    }
    cout << "Largest: " << largest << endl; // 14
    return 0;
}
```

## 5. Factorial (Recursion)
- **Description**: Write a recursive function that computes the factorial of a non-negative integer n.
- **Difficulty**: Beginner
- **Concepts**: Functions, recursion, base case
- **Example/Starter code**:
```cpp
#include <iostream>
using namespace std;

int factorial(int n) {
    if (n == 0 || n == 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

int main() {
    int n = 5;
    cout << "Factorial of " << n << " is " << factorial(n) << endl; // 120
    return 0;
}
```
