## Exercise 1: Hello, Name!
**Difficulty:** Basic
**Concepts:** `iostream`, `std::cin`/`std::cout`, `std::string`, namespaces.

Write a program that asks the user for their name and greets them.

**Starter code:**
```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;

    std::cout << "What is your name? ";
    std::cin >> name;

    std::cout << "Hello, " << name << "!" << std::endl;
    return 0;
}
```

**Task:** Use `std::getline` so the program can handle full names containing spaces.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** Conditionals, modulo (`%`), comparison.

Write a program that reads an integer and reports whether it is even or odd.

**Starter code:**
```cpp
#include <iostream>

int main() {
    int num;
    std::cout << "Enter an integer: ";
    std::cin >> num;

    if (num % 2 == 0) {
        std::cout << "Even" << std::endl;
    } else {
        std::cout << "Odd" << std::endl;
    }

    return 0;
}
```

**Task:** Also report whether the number is positive, negative, or zero.

## Exercise 3: Fibonacci Series
**Difficulty:** Basic
**Concepts:** Loops, variables, updating two values in sequence.

Write a program that prints the first N Fibonacci numbers (0, 1, 1, 2, 3, 5, 8, …).

**Starter code:**
```cpp
#include <iostream>

int main() {
    int n, a = 0, b = 1, next;

    std::cout << "How many terms? ";
    std::cin >> n;

    for (int i = 0; i < n; i++) {
        std::cout << a << " ";
        next = a + b;
        a = b;
        b = next;
    }
    std::cout << std::endl;

    return 0;
}
```

**Task:** Print the Fibonacci numbers separated by commas instead of spaces.

## Exercise 4: Reverse a String
**Difficulty:** Basic
**Concepts:** `std::string`, loops, indexing, `std::reverse`.

Write a program that reads a string and prints it reversed.

**Starter code:**
```cpp
#include <iostream>
#include <string>

int main() {
    std::string text;
    std::cout << "Enter a string: ";
    std::cin >> text;

    std::string reversed;
    for (int i = text.length() - 1; i >= 0; i--) {
        reversed += text[i];
    }

    std::cout << "Reversed: " << reversed << std::endl;
    return 0;
}
```

**Task:** Check whether the string is a palindrome (reads the same forwards and backwards).

## Exercise 5: Maximum in a Vector
**Difficulty:** Basic
**Concepts:** `std::vector`, loops, comparison, or `std::max_element`.

Write a program that stores a list of numbers in a `std::vector` and prints the maximum value.

**Starter code:**
```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers = {12, 5, 8, 21, 3, 17};

    int maxVal = numbers[0];
    for (int n : numbers) {
        if (n > maxVal) {
            maxVal = n;
        }
    }

    std::cout << "Maximum: " << maxVal << std::endl;
    return 0;
}
```

**Task:** Also compute the sum and average of the vector's elements.
