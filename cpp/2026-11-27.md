## Exercise 1: Define a Node and Build a Small Tree
**Difficulty:** Basic
**Concepts:** `struct`, constructor, member initializer list, raw pointers

**Starter code:**
```cpp
#include <iostream>

struct Node {
    int value;
    Node* left = nullptr;
    Node* right = nullptr;

    Node(int v) : value(v) {}
};

int main() {
    //         8
    //        / \
    //       3   10
    Node* root = new Node(8);
    root->left  = new Node(3);
    root->right = new Node(10);
    return 0;
}
```

**Task:** Build the full tree below and print `root->left->right->value`:
```
       8
      / \
     3   10
    / \    \
   1   6    14
```
(Expected output: `6`.)

## Exercise 2: Insert a Value into the BST
**Difficulty:** Basic
**Concepts:** recursive function, `nullptr` base case, `new` allocation at the empty spot

**Starter code:**
```cpp
Node* insert(Node* node, int value) {
    if (node == nullptr) return new Node(value);
    if (value < node->value)
        node->left = insert(node->left, value);
    else
        node->right = insert(node->right, value);
    return node;
}

int main() {
    Node* root = nullptr;
    for (int v : {8, 3, 10, 1, 6}) {
        root = insert(root, v);
    }
    return 0;
}
```

**Task:** Insert `14`, `4`, and `7`, then write a recursive `print_tree(Node* n)` that prints `value (left, right)` for each node to confirm the structure.

## Exercise 3: Search for a Value
**Difficulty:** Basic
**Concepts:** recursive search, pruning half the tree each call, `bool` return

**Starter code:**
```cpp
bool contains(Node* node, int value) {
    if (node == nullptr) return false;
    if (node->value == value) return true;
    if (value < node->value) return contains(node->left, value);
    return contains(node->right, value);
}

int main() {
    Node* root = nullptr;
    for (int v : {8, 3, 10, 1, 6, 14, 4, 7}) {
        root = insert(root, v);
    }
    std::cout << contains(root, 6)  << "\n";  // 1
    std::cout << contains(root, 12) << "\n";  // 0
    return 0;
}
```

**Task:** Modify `contains` to return the depth (steps from the root) where the value is found, or `-1` if absent.

## Exercise 4: In-Order Traversal (Sorted Output)
**Difficulty:** Basic
**Concepts:** left → current → right recursion, printing during traversal

**Starter code:**
```cpp
void inorder(Node* node) {
    if (node == nullptr) return;
    inorder(node->left);
    std::cout << node->value << " ";
    inorder(node->right);
}

int main() {
    Node* root = nullptr;
    for (int v : {8, 3, 10, 1, 6, 14, 4, 7}) {
        root = insert(root, v);
    }
    inorder(root);  // 1 3 4 6 7 8 10 14
    std::cout << "\n";
    return 0;
}
```

**Task:** Add a `preorder(Node*)` function (current → left → right). Print both traversals and confirm `inorder` is sorted while `preorder` begins with `8`.

## Exercise 5: Find the Minimum and Maximum
**Difficulty:** Basic
**Concepts:** following `left`/`right` chains with a `while` loop, `delete` to free memory

**Starter code:**
```cpp
int min_value(Node* node) {
    while (node->left != nullptr) {
        node = node->left;
    }
    return node->value;
}

int max_value(Node* node) {
    while (node->right != nullptr) {
        node = node->right;
    }
    return node->value;
}

int main() {
    Node* root = nullptr;
    for (int v : {8, 3, 10, 1, 6, 14, 4, 7}) {
        root = insert(root, v);
    }
    std::cout << min_value(root) << "\n";  // 1
    std::cout << max_value(root) << "\n";  // 14
    return 0;
}
```

**Task:** Rewrite both functions using recursion, and write a `free_tree(Node*)` function that recursively `delete`s every node.
