## Exercise 1: Define a Book Class
**Difficulty:** Basic
**Concepts:** `class`, `private`/`public`, constructor, member initializer list

Create a `Book` class with private fields and a public constructor, then print an instance in `main`.

**Starter code:**
```cpp
#include <iostream>
#include <string>

class Book {
private:
    std::string title;
    std::string author;
    int year;

public:
    Book(std::string t, std::string a, int y)
        : title(t), author(a), year(y) {}

    std::string describe() const {
        return title + " by " + author + " (" + std::to_string(year) + ")";
    }
};

int main() {
    Book book("1984", "George Orwell", 1949);
    std::cout << book.describe() << "\n";
    return 0;
}
```

**Task:** Add a `double price` field and a `price()` getter, then print the price of a book.

## Exercise 2: Create and Use Multiple Objects
**Difficulty:** Basic
**Concepts:** vectors of objects, range-based `for`, method calls

Store three `Book` objects in a `std::vector` and print each with a loop.

**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <vector>

class Book {
public:
    Book(std::string t, std::string a, int y)
        : title(t), author(a), year(y) {}

    std::string describe() const {
        return title + " by " + author + " (" + std::to_string(year) + ")";
    }

private:
    std::string title;
    std::string author;
    int year;
};

int main() {
    std::vector<Book> books = {
        Book("1984", "George Orwell", 1949),
        Book("Dune", "Frank Herbert", 1965),
        Book("Neuromancer", "William Gibson", 1984),
    };

    for (const auto &b : books) {
        std::cout << b.describe() << "\n";
    }
    return 0;
}
```

**Task:** Add a `double price` field with a `price()` getter and compute the total price of all books in the vector.

## Exercise 3: Add Member Functions
**Difficulty:** Basic
**Concepts:** member functions, `const` methods, computing derived values

Add methods that compute derived values from the object's own fields.

**Starter code:**
```cpp
#include <iostream>
#include <string>

class Book {
public:
    Book(std::string t, std::string a, int y, double p)
        : title(t), author(a), year(y), price(p) {}

    int age(int currentYear) const {
        return currentYear - year;
    }

    double discountedPrice(double percent) const {
        return price * (1 - percent / 100.0);
    }

private:
    std::string title;
    std::string author;
    int year;
    double price;
};

int main() {
    Book book("Dune", "Frank Herbert", 1965, 15.99);
    std::cout << "Age: " << book.age(2026) << "\n";
    std::cout << "Discounted: " << book.discountedPrice(20) << "\n";
    return 0;
}
```

**Task:** Add a `bool isClassic(int currentYear) const` method returning `true` when the book is 50+ years old, and test it on several books.

## Exercise 4: Encapsulation with Getters and Setters
**Difficulty:** Basic
**Concepts:** private fields, getters/setters, validation, data hiding

Protect the `price` field with a setter that rejects negative values.

**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <stdexcept>

class Book {
public:
    Book(std::string t, double p) : title(t), price(p) {}

    std::string getTitle() const { return title; }

    double getPrice() const { return price; }

    void setPrice(double p) {
        if (p < 0) {
            throw std::invalid_argument("price cannot be negative");
        }
        price = p;
    }

private:
    std::string title;
    double price;
};

int main() {
    Book book("1984", 12.50);
    std::cout << book.getTitle() << " costs " << book.getPrice() << "\n";
    book.setPrice(10.00);
    std::cout << "New price: " << book.getPrice() << "\n";
    return 0;
}
```

**Task:** Add a `setTitle` method, and wrap a `setPrice(-1)` call in a `try/catch` to print the exception message.

## Exercise 5: A Library That Holds Books
**Difficulty:** Basic
**Concepts:** composition, `std::vector`, search methods, reference return types

Build a `Library` class that stores `Book` objects in a `std::vector` and can add, list, and find them.

**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>

class Book {
public:
    Book(std::string t, std::string a, int y)
        : title(t), author(a), year(y) {}

    std::string describe() const {
        return title + " by " + author + " (" + std::to_string(year) + ")";
    }

    std::string getTitle() const { return title; }

private:
    std::string title;
    std::string author;
    int year;
};

class Library {
public:
    void add(const Book &b) {
        books.push_back(b);
    }

    const Book *find(const std::string &title) const {
        for (const auto &b : books) {
            if (b.getTitle() == title) {
                return &b;
            }
        }
        return nullptr;
    }

    void list() const {
        for (const auto &b : books) {
            std::cout << b.describe() << "\n";
        }
    }

private:
    std::vector<Book> books;
};

int main() {
    Library lib;
    lib.add(Book("Dune", "Frank Herbert", 1965));
    lib.add(Book("1984", "George Orwell", 1949));
    lib.list();

    const Book *found = lib.find("Dune");
    if (found) {
        std::cout << "Found: " << found->describe() << "\n";
    }
    return 0;
}
```

**Task:** Add a `size_t count() const` method and a `std::vector<Book> booksByYear(int year) const` method.
