## Exercise 1: `std::stack` — Push, Pop, Top
**Difficulty:** Basic
**Concepts:** `std::stack`, `push()`, `pop()`, `top()`, `empty()`, LIFO order

`std::stack` is a container adapter that provides LIFO behavior over any sequence container.

**Starter code:**
```cpp
#include <iostream>
#include <stack>

int main() {
    std::stack<std::string> s;

    s.push("a");   // push
    s.push("b");
    s.push("c");

    std::cout << s.top() << "\n";   // c (top without removing)
    s.pop();                        // remove top
    std::cout << s.top() << "\n";   // b
    std::cout << s.empty() << "\n"; // 0 (false)
    return 0;
}
```

**Task:** Push the integers `1..5` onto a stack and pop them all in a loop, printing each. The output should be `5 4 3 2 1`.

## Exercise 2: `std::queue` — Push, Pop, Front
**Difficulty:** Basic
**Concepts:** `std::queue`, `push()`, `pop()`, `front()`, `back()`, FIFO order

`std::queue` provides FIFO behavior.

**Starter code:**
```cpp
#include <iostream>
#include <queue>

int main() {
    std::queue<std::string> q;

    q.push("a");   // enqueue (back)
    q.push("b");
    q.push("c");

    std::cout << q.front() << "\n";   // a (front without removing)
    q.pop();                          // dequeue (remove front)
    std::cout << q.front() << "\n";   // b
    std::cout << q.back() << "\n";    // c (back without removing)
    return 0;
}
```

**Task:** Enqueue the numbers `1..5` and dequeue them all, printing each. The output should be `1 2 3 4 5`.

## Exercise 3: Balanced Parentheses with `std::stack`
**Difficulty:** Basic
**Concepts:** `std::stack<char>`, matching pairs, early `false` on mismatch

Use a stack of characters to check balanced brackets.

**Starter code:**
```cpp
#include <iostream>
#include <stack>

bool is_balanced(const std::string &s) {
    std::stack<char> st;
    for (char ch : s) {
        if (ch == '(' || ch == '[' || ch == '{') {
            st.push(ch);
        } else if (ch == ')' || ch == ']' || ch == '}') {
            if (st.empty()) return false;
            char open = st.top(); st.pop();
            if ((ch == ')' && open != '(') ||
                (ch == ']' && open != '[') ||
                (ch == '}' && open != '{')) return false;
        }
    }
    return st.empty();
}

int main() {
    std::cout << std::boolalpha;
    std::cout << is_balanced("(a[b]{c})") << "\n";   // true
    std::cout << is_balanced("([)]") << "\n";        // false
    return 0;
}
```

**Task:** Add a test for the input `"((("` and confirm it returns `false` (unmatched openers remain on the stack).

## Exercise 4: Reverse a String with `std::stack`
**Difficulty:** Basic
**Concepts:** push characters, pop to rebuild, `std::string` building

Push each character and pop them off to reverse the string.

**Starter code:**
```cpp
#include <iostream>
#include <stack>

std::string reverse_string(const std::string &text) {
    std::stack<char> st;
    for (char ch : text) st.push(ch);
    std::string result;
    while (!st.empty()) {
        result += st.top();
        st.pop();
    }
    return result;
}

int main() {
    std::cout << reverse_string("hello") << "\n";   // "olleh"
    return 0;
}
```

**Task:** Modify the function so it ignores spaces (spaces keep their positions), e.g. `reverse_string("a b c")` should return `"c b a"`.

## Exercise 5: Process a FIFO Task Queue
**Difficulty:** Basic
**Concepts:** `std::queue`, `while (!q.empty())`, simulating a work queue

Simulate a job queue that processes tasks in arrival order.

**Starter code:**
```cpp
#include <iostream>
#include <queue>

int main() {
    std::queue<std::string> jobs;
    jobs.push("download");
    jobs.push("compile");
    jobs.push("deploy");

    while (!jobs.empty()) {
        std::cout << "Processing: " << jobs.front() << "\n";
        jobs.pop();
    }
    std::cout << "All jobs done: " << std::boolalpha << jobs.empty() << "\n";
    return 0;
}
```

**Task:** Add a `size()` check inside the loop and print the remaining queue size after each job completes.
