## Exercise 1: Print a Right-Angled Triangle of Stars
**Difficulty:** Basic
**Concepts:** nested `for` loops, `cin` / `cout`

Print a right-angled triangle of `*` where the number of rows is user-supplied.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int rows;
    cout << "Enter number of rows: ";
    cin >> rows;

    for (int i = 1; i <= rows; i++) {
        for (int j = 1; j <= i; j++) {
            cout << "*";
        }
        cout << endl;
    }
    return 0;
}
```

**Task:** Print an inverted triangle instead, then print numbers (`1`, `22`, `333`, …) using the same nested-loop structure.

## Exercise 2: Print Floyd's Triangle
**Difficulty:** Basic
**Concepts:** nested loops, running counter, `cout`

Print Floyd's triangle — consecutive numbers arranged in rows of increasing length.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int rows, num = 1;
    cout << "Enter number of rows: ";
    cin >> rows;

    for (int i = 1; i <= rows; i++) {
        for (int j = 1; j <= i; j++) {
            cout << num << " ";
            num++;
        }
        cout << endl;
    }
    return 0;
}
```

**Task:** Right-align the triangle with leading spaces, and start the counter at a user-supplied value.

## Exercise 3: Count Uppercase and Lowercase Letters
**Difficulty:** Basic
**Concepts:** `std::string`, `<cctype>` (`isupper()` / `islower()`), range-based `for`

Count how many uppercase and lowercase letters a string contains.

**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <cctype>
using namespace std;

int main() {
    string text;
    cout << "Enter a string: ";
    getline(cin, text);

    int upper = 0, lower = 0;
    for (char ch : text) {
        if (isupper(ch)) upper++;
        else if (islower(ch)) lower++;
    }

    cout << "Uppercase: " << upper << ", Lowercase: " << lower << endl;
    return 0;
}
```

**Task:** Also count digits (`isdigit()`) and whitespace (`isspace()`), and print a full breakdown.

## Exercise 4: Remove All Spaces from a String
**Difficulty:** Basic
**Concepts:** `std::string`, erase-remove idiom, `std::remove()`

Remove every space from an input string and print the result.

**Starter code:**
```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    string text;
    cout << "Enter a string: ";
    getline(cin, text);

    text.erase(remove(text.begin(), text.end(), ' '), text.end());
    cout << "Without spaces: " << text << endl;
    return 0;
}
```

**Task:** Remove all whitespace (tabs, newlines) using a predicate with `isspace()`, and implement a manual loop version.

## Exercise 5: Find the Largest Digit in a Number
**Difficulty:** Basic
**Concepts:** `%` and `/`, `while` loop, max tracking

Read a whole number and print its largest single digit.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int num, largest = 0;
    cout << "Enter a number: ";
    cin >> num;

    while (num > 0) {
        int digit = num % 10;
        if (digit > largest) largest = digit;
        num /= 10;
    }

    cout << "Largest digit: " << largest << endl;
    return 0;
}
```

**Task:** Also find the smallest digit, and handle negative input using `abs()` from `<cstdlib>`.
