## Exercise 1: try/throw/catch Basics
**Difficulty:** Basic
**Concepts:** `throw`, `try`, `catch`, throwing and catching a `const char *`

Throw a message when a division is impossible and catch it.

**Starter code:**
```cpp
#include <iostream>
using namespace std;

double divide(double a, double b) {
    if (b == 0) {
        throw "Division by zero!";
    }
    return a / b;
}

int main() {
    try {
        cout << divide(10, 2) << endl; // 5
        cout << divide(10, 0) << endl; // throws
    } catch (const char *msg) {
        cerr << "Error: " << msg << endl;
    }
    return 0;
}
```

**Task:** Also throw when `a` or `b` is negative, with a different message, and confirm the same catch block prints it.

## Exercise 2: Standard Exceptions (std::runtime_error)
**Difficulty:** Basic
**Concepts:** `<stdexcept>`, `std::runtime_error`, `throw` an object, `e.what()`

Throw a standard library exception and read its message via `what()`.

**Starter code:**
```cpp
#include <iostream>
#include <stdexcept>
using namespace std;

double divide(double a, double b) {
    if (b == 0) {
        throw runtime_error("division by zero");
    }
    return a / b;
}

int main() {
    try {
        cout << divide(10, 0) << endl;
    } catch (const runtime_error &e) {
        cerr << "Caught: " << e.what() << endl;
    }
    return 0;
}
```

**Task:** Catch by `const std::exception &e` instead and observe that `what()` still works — demonstrating polymorphic catching of the base class.

## Exercise 3: Catching std::out_of_range
**Difficulty:** Basic
**Concepts:** `std::vector`, `.at()` vs `[]`, `std::out_of_range`

Use `.at()` so an out-of-bounds access throws instead of silently misbehaving.

**Starter code:**
```cpp
#include <iostream>
#include <vector>
#include <stdexcept>
using namespace std;

int main() {
    vector<int> nums = {1, 2, 3};
    try {
        cout << nums.at(5) << endl; // throws out_of_range
    } catch (const out_of_range &e) {
        cerr << "Out of range: " << e.what() << endl;
    }
    return 0;
}
```

**Task:** Loop `index` from `0` to `4` inside the `try` and, once the exception is caught, print which index failed using a variable visible outside the block.

## Exercise 4: Multiple catch Blocks
**Difficulty:** Basic
**Concepts:** `std::stoi`, `std::invalid_argument`, multiple `catch` blocks in most-specific-first order

Handle the specific failure of `stoi` before the generic handler.

**Starter code:**
```cpp
#include <iostream>
#include <stdexcept>
#include <string>
using namespace std;

int main() {
    try {
        string s = "abc";
        int n = stoi(s); // throws invalid_argument
        cout << n << endl;
    } catch (const invalid_argument &e) {
        cerr << "Invalid argument: " << e.what() << endl;
    } catch (const exception &e) {
        cerr << "Other: " << e.what() << endl;
    }
    return 0;
}
```

**Task:** Add a `catch (const out_of_range &e)` block between the two, and trigger it by parsing a number too large for `int` (e.g. `"99999999999999999999"`).

## Exercise 5: Custom Exception Class
**Difficulty:** Basic
**Concepts:** deriving from `std::exception`, overriding `what()`, `noexcept`, `throw` a custom type

Define your own exception type with a custom message.

**Starter code:**
```cpp
#include <iostream>
#include <exception>
using namespace std;

class NegativeAgeError : public exception {
public:
    const char *what() const noexcept override {
        return "Age cannot be negative";
    }
};

void setAge(int age) {
    if (age < 0) {
        throw NegativeAgeError();
    }
    cout << "Age set to " << age << endl;
}

int main() {
    try {
        setAge(-5);
    } catch (const exception &e) {
        cerr << "Error: " << e.what() << endl;
    }
    return 0;
}
```

**Task:** Add a `setAge` check for `age > 150` that throws a second custom class `TooOldError` with its own `what()` message, and catch both types separately.
