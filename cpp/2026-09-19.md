## 1. Hello, World!
**Description:** Write the minimal C++ program using `std::cout` to print a greeting.
**Difficulty:** Basic
**Concepts:** `#include <iostream>`, `main()`, `std::cout`, namespaces.
**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

## 2. Even or Odd
**Description:** Read an integer and print whether it is even or odd.
**Difficulty:** Basic
**Concepts:** `std::cin`, conditionals, modulo operator.
**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter a number: ";
    cin >> n;
    if (n % 2 == 0) {
        cout << n << " is even" << endl;
    } else {
        cout << n << " is odd" << endl;
    }
    return 0;
}
```

## 3. Sum of Array Elements
**Description:** Compute the sum of all elements in an array.
**Difficulty:** Basic
**Concepts:** Arrays, `for` loop, array size.
**Starter code:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[] = {1, 2, 3, 4, 5};
    int size = sizeof(numbers) / sizeof(numbers[0]);
    int sum = 0;
    for (int i = 0; i < size; i++) {
        sum += numbers[i];
    }
    cout << "Sum: " << sum << endl;
    return 0;
}
```

## 4. Factorial (Loop and Recursion)
**Description:** Compute the factorial of a number using both an iterative loop and a recursive function.
**Difficulty:** Basic
**Concepts:** Loops, recursion, function definitions, base case.
**Starter code:**
```cpp
#include <iostream>
using namespace std;

long factorialRec(int n) {
    if (n <= 1) return 1;
    return n * factorialRec(n - 1);
}

int main() {
    int n = 5;
    long result = 1;
    for (int i = 1; i <= n; i++) result *= i;
    cout << "Iterative: " << result << endl;
    cout << "Recursive: " << factorialRec(n) << endl;
    return 0;
}
```

## 5. Palindrome String
**Description:** Check whether a given string is a palindrome (reads the same forwards and backwards).
**Difficulty:** Basic
**Concepts:** `std::string`, `string::length()`, indexing, conditionals.
**Starter code:**
```cpp
#include <iostream>
#include <string>
using namespace std;

bool isPalindrome(const string& s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        if (s[left] != s[right]) return false;
        left++;
        right--;
    }
    return true;
}

int main() {
    cout << isPalindrome("racecar") << endl; // 1 (true)
    cout << isPalindrome("hello") << endl;   // 0 (false)
    return 0;
}
```
