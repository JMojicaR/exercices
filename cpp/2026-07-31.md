## Exercise 1: Hello World and I/O Streams

**Title:** Hello, C++! — cout and cin

**Description:** Write a C++ program that prints "Hello, World!" and then asks the user for their name and age using `cin`. Print a personalized greeting using `cout`.

**Difficulty:** ★☆☆☆☆ (Very Easy)

**Concepts Practiced:**
- `#include <iostream>`
- `using namespace std;`
- `cout` for output
- `cin` for input
- `string` data type
- Namespace usage

**Starter Code:**
```cpp
// Exercise 1: Hello, C++!
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    int age;

    cout << "Hello, World!" << endl;
    cout << "Enter your name: ";
    cin >> name;
    cout << "Enter your age: ";
    cin >> age;

    cout << "Welcome, " << name << "! You are " << age << " years old." << endl;

    return 0;
}
```

## Exercise 2: Simple Calculator

**Title:** Menu-Driven Calculator with Switch

**Description:** Write a C++ program that presents a menu to the user with options for addition, subtraction, multiplication, and division. Use a `switch` statement to perform the chosen operation.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- `switch` statement
- Arithmetic operations
- `double` data type
- Menu-driven programs
- Division by zero handling

**Starter Code:**
```cpp
// Exercise 2: Simple Calculator
#include <iostream>
using namespace std;

int main() {
    double num1, num2, result;
    char op;

    cout << "Enter first number: ";
    cin >> num1;
    cout << "Enter operator (+, -, *, /): ";
    cin >> op;
    cout << "Enter second number: ";
    cin >> num2;

    switch (op) {
        case '+': result = num1 + num2; break;
        case '-': result = num1 - num2; break;
        case '*': result = num1 * num2; break;
        case '/':
            if (num2 != 0)
                result = num1 / num2;
            else {
                cout << "Error: Division by zero!" << endl;
                return 1;
            }
            break;
        default:
            cout << "Invalid operator!" << endl;
            return 1;
    }

    cout << "Result: " << result << endl;
    return 0;
}
```

## Exercise 3: Factorial with Recursion

**Title:** Recursive Factorial Function

**Description:** Write a C++ program that computes the factorial of a non-negative integer using a recursive function. The factorial of n is n × (n-1) × ... × 1, with 0! = 1.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Function declaration and definition
- Recursive functions
- Base case and recursive case
- `unsigned long long` data type
- Input validation

**Starter Code:**
```cpp
// Exercise 3: Factorial with Recursion
#include <iostream>
using namespace std;

unsigned long long factorial(int n) {
    if (n == 0 || n == 1)
        return 1;
    return n * factorial(n - 1);
}

int main() {
    int n;
    cout << "Enter a non-negative integer: ";
    cin >> n;

    if (n < 0) {
        cout << "Factorial not defined for negative numbers." << endl;
    } else {
        cout << n << "! = " << factorial(n) << endl;
    }

    return 0;
}
```

## Exercise 4: Prime Number Checker

**Title:** Check and List Prime Numbers

**Description:** Write a C++ program that checks if a given number is prime and then lists all prime numbers up to a user-specified limit. A prime number is only divisible by 1 and itself.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Boolean functions
- `for` loops
- Modulo operator
- `sqrt()` from `<cmath>`
- Algorithm optimization

**Starter Code:**
```cpp
// Exercise 4: Prime Number Checker
#include <iostream>
#include <cmath>
using namespace std;

bool isPrime(int n) {
    if (n <= 1) return false;
    for (int i = 2; i <= sqrt(n); i++) {
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    int limit;
    cout << "Enter the upper limit: ";
    cin >> limit;

    cout << "Prime numbers up to " << limit << ": ";
    for (int i = 2; i <= limit; i++) {
        if (isPrime(i))
            cout << i << " ";
    }
    cout << endl;

    return 0;
}
```

## Exercise 5: Vector Operations

**Title:** Working with std::vector

**Description:** Write a C++ program that uses `std::vector<int>` to store numbers. Perform the following: add elements with `push_back`, find the sum, find max/min, sort the vector, and print all elements using a range-based `for` loop.

**Difficulty:** ★★★☆☆ (Moderate)

**Concepts Practiced:**
- `std::vector` from `<vector>`
- `push_back()` and `size()`
- Range-based `for` loops
- `std::sort` from `<algorithm>`
- STL containers basics

**Starter Code:**
```cpp
// Exercise 5: Vector Operations
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> numbers;

    // Add elements
    numbers.push_back(42);
    numbers.push_back(15);
    numbers.push_back(73);
    numbers.push_back(8);
    numbers.push_back(91);

    // Print original
    cout << "Vector: ";
    for (int num : numbers)
        cout << num << " ";
    cout << endl;

    // Sum
    int sum = 0;
    for (int num : numbers) sum += num;
    cout << "Sum: " << sum << endl;

    // Max and Min
    int maxVal = *max_element(numbers.begin(), numbers.end());
    int minVal = *min_element(numbers.begin(), numbers.end());
    cout << "Maximum: " << maxVal << endl;
    cout << "Minimum: " << minVal << endl;

    // Sort
    sort(numbers.begin(), numbers.end());
    cout << "Sorted: ";
    for (int num : numbers)
        cout << num << " ";
    cout << endl;

    return 0;
}
```
