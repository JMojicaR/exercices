## Exercise 1: Student API — GET and POST with Pydantic Models

### Problem

Build a FastAPI app that manages students using a Pydantic model for request validation. Create two endpoints:

- `GET /students` — returns all students as JSON
- `POST /students` — accepts a `StudentCreate` body (`name`, `age`), assigns an `id`, and returns the created student with status 201

The `Student` response model has: `id`, `name`, `age`.

### Concepts

- `FastAPI()` application instance
- Pydantic `BaseModel` for request bodies
- Type hints (`int`, `str`) for automatic validation
- Path decorators `@app.get` / `@app.post`
- `status_code` parameter for POST (201)

### HTTP Method(s)

`GET`, `POST`

### Example/Starter Code

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

students = []
next_id = 1


class StudentCreate(BaseModel):
    name: str
    age: int


class Student(StudentCreate):
    id: int


@app.get("/students")
def get_students():
    return students


@app.post("/students", status_code=201)
def create_student(student: StudentCreate):
    global next_id
    new_student = Student(id=next_id, name=student.name, age=student.age)
    next_id += 1
    students.append(new_student)
    return new_student
```

**Test:**
```bash
uvicorn main:app --reload
curl http://localhost:8000/students
curl -X POST http://localhost:8000/students \
  -H "Content-Type: application/json" \
  -d '{"name":"Alice","age":20}'
```
Auto-generated docs are available at `http://localhost:8000/docs`.

## Exercise 2: Item API — Full CRUD with HTTPException

### Problem

Build a full CRUD API for `items` using in-memory storage and `HTTPException` for error handling:

- `GET /items` — returns all items
- `POST /items` — creates an item (`name`, `price`); returns it with 201
- `GET /items/{item_id}` — returns a single item, or raises 404 if not found
- `PUT /items/{item_id}` — updates an item, or raises 404 if not found
- `DELETE /items/{item_id}` — deletes an item, or raises 404 if not found

### Concepts

- Path parameters (`{item_id}`) with type hints
- `HTTPException` with `status_code` and `detail`
- Pydantic models with `Field` validation (e.g. `min_length`, `gt`)
- `response_model` for output shaping

### HTTP Method(s)

`GET`, `POST`, `PUT`, `DELETE`

### Example/Starter Code

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()

items = []
next_id = 1


class Item(BaseModel):
    name: str = Field(min_length=1, max_length=100)
    price: float = Field(gt=0)


class ItemResponse(Item):
    id: int


@app.get("/items", response_model=list[ItemResponse])
def get_items():
    return items


@app.post("/items", response_model=ItemResponse, status_code=201)
def create_item(item: Item):
    global next_id
    new_item = ItemResponse(id=next_id, name=item.name, price=item.price)
    next_id += 1
    items.append(new_item)
    return new_item


@app.get("/items/{item_id}", response_model=ItemResponse)
def get_item(item_id: int):
    for item in items:
        if item.id == item_id:
            return item
    raise HTTPException(status_code=404, detail="Item not found")


@app.put("/items/{item_id}", response_model=ItemResponse)
def update_item(item_id: int, item: Item):
    for existing in items:
        if existing.id == item_id:
            existing.name = item.name
            existing.price = item.price
            return existing
    raise HTTPException(status_code=404, detail="Item not found")


@app.delete("/items/{item_id}")
def delete_item(item_id: int):
    for i, item in enumerate(items):
        if item.id == item_id:
            items.pop(i)
            return {"message": f"Item {item_id} deleted"}
    raise HTTPException(status_code=404, detail="Item not found")
```

**Test:**
```bash
curl -X POST http://localhost:8000/items \
  -H "Content-Type: application/json" \
  -d '{"name":"Keyboard","price":49.99}'
curl http://localhost:8000/items/1
curl http://localhost:8000/items/999   # 404
```

## Exercise 3: Query Parameter Filtering and Validation

### Problem

Build a products API that supports searching and filtering through query parameters with validation:

- `GET /products` — returns products, optionally filtered by `category` (optional string) and `max_price` (optional positive float)
- `GET /products/{product_id}` — returns a single product by ID

Use `Query` to declare optional query parameters with defaults and constraints, and use `HTTPException` for a missing product.

### Concepts

- `Query(...)` for query parameter declaration and validation
- Optional query parameters with `None` defaults
- Filtering with list comprehensions
- Path parameters combined with query parameters

### HTTP Method(s)

`GET`

### Example/Starter Code

```python
from fastapi import FastAPI, HTTPException, Query
from pydantic import BaseModel

app = FastAPI()


class Product(BaseModel):
    id: int
    name: str
    category: str
    price: float


products = [
    Product(id=1, name="Clean Code", category="books", price=29.99),
    Product(id=2, name="Desk Lamp", category="home", price=15.50),
    Product(id=3, name="Atomic Habits", category="books", price=18.75),
]


@app.get("/products")
def get_products(
    category: str | None = Query(default=None),
    max_price: float | None = Query(default=None, gt=0),
):
    result = products
    if category:
        result = [p for p in result if p.category == category]
    if max_price:
        result = [p for p in result if p.price <= max_price]
    return result


@app.get("/products/{product_id}")
def get_product(product_id: int):
    for p in products:
        if p.id == product_id:
            return p
    raise HTTPException(status_code=404, detail="Product not found")
```

**Test:**
```bash
curl "http://localhost:8000/products?category=books"
curl "http://localhost:8000/products?category=books&max_price=20"
```
