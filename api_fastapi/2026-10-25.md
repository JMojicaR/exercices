## Exercise 1: Pydantic Model + GET Endpoints
**Difficulty:** Basic
**Concepts:** `FastAPI` app, Pydantic `BaseModel`, `@app.get`, return types

Define a `Course` model and expose list and health-check endpoints.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Course(BaseModel):
    id: int
    title: str
    instructor: str
    credits: int

courses = [
    {"id": 1, "title": "Intro to Python", "instructor": "Dr. Reyes", "credits": 3},
    {"id": 2, "title": "Data Structures", "instructor": "Prof. Smith", "credits": 4},
]

@app.get("/health")
def health():
    return {"status": "ok"}

@app.get("/courses")
def get_courses():
    return courses
```

**Task:** Add a `GET /courses/{course_id}` endpoint (return the matching course), and set the `get_courses` response model to `list[Course]`.

## Exercise 2: POST + GET by ID + PUT
**Difficulty:** Basic
**Concepts:** POST with body model, `status_code`, `HTTPException`, `model_dump()`, update

Add endpoints to create, read, and update a course.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()
courses = []
next_id = 1

class Course(BaseModel):
    id: int = 0
    title: str
    instructor: str = "TBA"
    credits: int

@app.post("/courses", status_code=201)
def create_course(course: Course):
    global next_id
    course.id = next_id
    next_id += 1
    courses.append(course.model_dump())
    return course

@app.get("/courses/{course_id}")
def get_course(course_id: int):
    for course in courses:
        if course["id"] == course_id:
            return course
    raise HTTPException(status_code=404, detail="Course not found")

@app.put("/courses/{course_id}")
def update_course(course_id: int, updated: Course):
    for course in courses:
        if course["id"] == course_id:
            course.update(updated.model_dump(exclude={"id"}))
            return course
    raise HTTPException(status_code=404, detail="Course not found")
```

**Task:** Validate `credits` to be between 1 and 8 using a Pydantic `Field`, returning a 422 automatically when out of range.

## Exercise 3: DELETE + Query Filtering
**Difficulty:** Basic
**Concepts:** DELETE, query parameters, `Query`, filtering, full CRUD

Add a delete endpoint and a search endpoint with a query parameter.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException, Query

app = FastAPI()
courses = []

@app.delete("/courses/{course_id}")
def delete_course(course_id: int):
    for course in courses:
        if course["id"] == course_id:
            courses.remove(course)
            return {"message": "Course deleted"}
    raise HTTPException(status_code=404, detail="Course not found")

@app.get("/courses/search")
def search_courses(instructor: str | None = Query(default=None)):
    if instructor:
        return [c for c in courses if c["instructor"].lower() == instructor.lower()]
    return courses
```

**Task:** Register `/courses/search` *before* any `/courses/{course_id}` route (FastAPI matches routes in definition order), and add a second optional `min_credits` query parameter.
