## Exercise 1: Your First FastAPI — Hello World & Automatic Docs
**Difficulty:** ★☆☆☆☆  
**Concepts:** FastAPI app, `@app.get`, path parameters, query parameters, automatic Swagger docs

### Description
Create a FastAPI app with:
1. `GET /` — Returns `{"message": "Welcome to FastAPI!"}`
2. `GET /hello/{name}` — Returns a personalized greeting (path parameter)
3. `GET /greet?name=World&times=1` — Returns greeting repeated N times (query parameters with defaults)
