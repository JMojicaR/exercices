## Exercise 1: Pydantic Model + GET + POST
**Difficulty:** Basic
**Concepts:** Pydantic models, `@app.get`, `@app.post`, in-memory storage

Create a FastAPI app with a Pydantic model and endpoints to list and create songs.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Song(BaseModel):
    id: int
    title: str
    artist: str
    duration_sec: int

songs = [
    Song(id=1, title="Shape of You", artist="Ed Sheeran", duration_sec=234),
]

@app.get("/songs")
def get_songs():
    return songs

@app.post("/songs", status_code=201)
def create_song(song: Song):
    songs.append(song)
    return song
```

**Task:** Add a `GET /songs/count` endpoint that returns the number of songs.

## Exercise 2: GET by ID + PUT + HTTPException
**Difficulty:** Basic
**Concepts:** path parameters, `HTTPException`, PUT, updating records

Add endpoints to fetch a song by ID and update it, returning proper 404 errors.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Song(BaseModel):
    id: int
    title: str
    artist: str
    duration_sec: int

songs = [Song(id=1, title="Shape of You", artist="Ed Sheeran", duration_sec=234)]

@app.get("/songs/{song_id}")
def get_song(song_id: int):
    for song in songs:
        if song.id == song_id:
            return song
    raise HTTPException(status_code=404, detail="Song not found")

@app.put("/songs/{song_id}")
def update_song(song_id: int, updated: Song):
    for i, song in enumerate(songs):
        if song.id == song_id:
            songs[i] = updated
            return updated
    raise HTTPException(status_code=404, detail="Song not found")
```

**Task:** Validate `duration_sec > 0` with a Pydantic `Field(gt=0)` and observe the automatic 422 response.

## Exercise 3: DELETE + Query Filtering + Full CRUD
**Difficulty:** Basic
**Concepts:** DELETE, query parameters, filtering, complete CRUD

Add a delete endpoint and an artist filter to complete the CRUD API.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException, Query
from pydantic import BaseModel

app = FastAPI()

class Song(BaseModel):
    id: int
    title: str
    artist: str
    duration_sec: int

songs = [Song(id=1, title="Shape of You", artist="Ed Sheeran", duration_sec=234)]

@app.get("/songs")
def get_songs(artist: str | None = Query(default=None)):
    if artist is None:
        return songs
    return [s for s in songs if s.artist.lower() == artist.lower()]

@app.delete("/songs/{song_id}")
def delete_song(song_id: int):
    for i, song in enumerate(songs):
        if song.id == song_id:
            return songs.pop(i)
    raise HTTPException(status_code=404, detail="Song not found")
```

**Task:** Run with `uvicorn` and test the full CRUD flow (POST → GET → PUT → DELETE) with `curl` or the interactive docs at `/docs`.
