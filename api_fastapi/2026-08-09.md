## Exercise 1: Book API — Create and Read with Pydantic Models

### Problem

Build a FastAPI book management API using Pydantic models and an in-memory list. Create the following endpoints:

- `POST /book` — accepts a `Book` object (`id`, `title`, `author`, `publisher`) in the request body, adds it to the in-memory `data` list, and returns the updated list
- `GET /list` — returns the entire list of books
- `GET /book/{id}` — retrieves a single book by its `id` path parameter (the list index is `id - 1`)

Define a `Book` Pydantic model with fields: `id: int`, `title: str`, `author: str`, `publisher: str`.

### Concepts

- Pydantic `BaseModel` for request body validation and serialization
- `@app.post()`, `@app.get()` decorators with path and type hints
- FastAPI automatic request parsing from type annotations
- Path parameters with type hints (`id: int`)
- In-memory list as a temporary database
- Automatic OpenAPI / Swagger UI documentation at `/docs`

### HTTP Method(s)

`POST`, `GET`

### Example/Starter Code

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

data = []  # In-memory book storage


class Book(BaseModel):
    id: int
    title: str
    author: str
    publisher: str


@app.post("/book")
def add_book(book: Book):
    data.append(book.model_dump())
    return data


@app.get("/list")
def get_books():
    return data


@app.get("/book/{id}")
def get_book(id: int):
    # List is zero-indexed, book ids are 1-indexed
    return data[id - 1]
```

**Run with Uvicorn:**
```bash
pip install fastapi uvicorn
uvicorn main:app --reload
```

**Test:** Open `http://127.0.0.1:8000/docs` in your browser and use the interactive Swagger UI. Click "POST /book" → "Try it out" → enter a JSON body → "Execute".

**Example POST body:**
```json
{
  "id": 1,
  "title": "Learning FastAPI",
  "author": "Jane Doe",
  "publisher": "TechBooks"
}
```

## Exercise 2: Item CRUD with SQLAlchemy Database

### Problem

Build a complete CRUD API for an `items` resource backed by a SQLite database using SQLAlchemy. Create all four endpoints:

- `POST /items/` — creates a new item with `name` and `description` (query parameters), saves it to the database, and returns the created item
- `GET /items/{item_id}` — retrieves a single item by ID from the database
- `PUT /items/{item_id}` — updates an existing item's `name` and `description` (query parameters) in the database
- `DELETE /items/{item_id}` — deletes an item and returns a success message

Use a `SessionLocal` factory for database sessions. The `Item` SQLAlchemy model should have columns: `id` (Integer, primary key), `name` (String), `description` (String).

### Concepts

- SQLAlchemy `create_engine`, `declarative_base`, `sessionmaker` setup
- SQLite connection string (`sqlite:///./test.db`)
- `Base.metadata.create_all()` for table creation
- Database session management: create session, commit, refresh, close
- CRUD operations with SQLAlchemy ORM: `db.add()`, `db.query().filter()`, `db.delete()`
- Async endpoint functions with `async def`

### HTTP Method(s)

`POST`, `GET`, `PUT`, `DELETE`

### Example/Starter Code

```python
import uvicorn
from fastapi import FastAPI
from sqlalchemy import Column, Integer, String, create_engine
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker

# Database setup
SQLALCHEMY_DATABASE_URL = "sqlite:///./test.db"
engine = create_engine(SQLALCHEMY_DATABASE_URL)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


# SQLAlchemy model
class Item(Base):
    __tablename__ = "items"
    id = Column(Integer, primary_key=True, index=True)
    name = Column(String, index=True)
    description = Column(String, index=True)


Base.metadata.create_all(bind=engine)

app = FastAPI()


# CREATE
@app.post("/items/")
async def create_item(name: str, description: str):
    db = SessionLocal()
    db_item = Item(name=name, description=description)
    db.add(db_item)
    db.commit()
    db.refresh(db_item)
    return db_item


# READ
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    db = SessionLocal()
    item = db.query(Item).filter(Item.id == item_id).first()
    return item


# UPDATE
@app.put("/items/{item_id}")
async def update_item(item_id: int, name: str, description: str):
    db = SessionLocal()
    db_item = db.query(Item).filter(Item.id == item_id).first()
    db_item.name = name
    db_item.description = description
    db.commit()
    return db_item


# DELETE
@app.delete("/items/{item_id}")
async def delete_item(item_id: int):
    db = SessionLocal()
    db_item = db.query(Item).filter(Item.id == item_id).first()
    db.delete(db_item)
    db.commit()
    return {"message": "Item deleted successfully"}


if __name__ == "__main__":
    uvicorn.run(app)
```

**Run with Uvicorn:**
```bash
pip install fastapi uvicorn sqlalchemy
uvicorn main:app --reload
```

**Test via Swagger UI** at `http://127.0.0.1:8000/docs`:
1. Expand `POST /items/` → "Try it out" → enter `name` and `description` → "Execute"
2. Expand `GET /items/{item_id}` → enter `item_id: 1` → "Execute"
3. Expand `PUT /items/{item_id}` → update fields → "Execute"
4. Expand `DELETE /items/{item_id}` → "Execute" to remove

## Exercise 3: CRUD with Query Parameters — Search and Filter

### Problem

Build a product catalog API that supports CRUD operations using an in-memory list, plus query-parameter-based search. The `Product` model should have `id`, `name`, `category`, and `price` fields:

- `POST /products` — creates a product from a Pydantic model request body
- `GET /products` — returns all products; optionally accepts a `?category=string` query parameter to filter by category
- `GET /products/search` — accepts a `?name=string` query parameter and returns products whose name contains the search string (case-insensitive). If no match, returns `{"message": "No products found"}`
- `PUT /products/{product_id}` — updates a product by ID
- `DELETE /products/{product_id}` — deletes a product by ID

### Concepts

- Query parameters with FastAPI (`category: str = None`)
- Optional query parameter filtering logic
- Pydantic model with `model_dump()` for serialization
- String matching with `str.lower()` and `in` operator
- Path parameters combined with query parameters

### HTTP Method(s)

`POST`, `GET`, `PUT`, `DELETE`

### Example/Starter Code

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

products = []
next_id = 1


class Product(BaseModel):
    id: int | None = None  # Auto-assigned
    name: str
    category: str
    price: float


@app.post("/products")
def create_product(product: Product):
    global next_id
    new_product = product.model_dump()
    new_product["id"] = next_id
    next_id += 1
    products.append(new_product)
    return new_product


@app.get("/products")
def get_products(category: str = None):
    if category:
        return [p for p in products if p["category"].lower() == category.lower()]
    return products


@app.get("/products/search")
def search_products(name: str):
    results = [p for p in products if name.lower() in p["name"].lower()]
    if not results:
        return {"message": "No products found"}
    return results


@app.put("/products/{product_id}")
def update_product(product_id: int, product: Product):
    for p in products:
        if p["id"] == product_id:
            update_data = product.model_dump(exclude_unset=True)
            p.update(update_data)
            p["id"] = product_id  # Preserve original ID
            return p
    raise HTTPException(status_code=404, detail="Product not found")


@app.delete("/products/{product_id}")
def delete_product(product_id: int):
    for i, p in enumerate(products):
        if p["id"] == product_id:
            products.pop(i)
            return {"message": f"Product {product_id} deleted"}
    raise HTTPException(status_code=404, detail="Product not found")
```

