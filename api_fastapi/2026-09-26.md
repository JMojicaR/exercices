## Exercise 1: Hello API with a Pydantic Model (GET + POST)
**Difficulty:** Basic
**Concepts:** `FastAPI()` app, decorators (`@app.get`/`@app.post`), Pydantic `BaseModel`, auto-validation.

Create a FastAPI app with a `GET /` greeting and a `POST /echo` endpoint that validates and returns a request body using a Pydantic model.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Message(BaseModel):
    text: str

@app.get("/")
def home():
    return {"message": "Hello, FastAPI!"}

@app.post("/echo")
def echo(message: Message):
    return {"you_sent": message.text}

# Run with: uvicorn main:app --reload
```

## Exercise 2: Path & Query Parameters with Validation
**Difficulty:** Basic
**Concepts:** Path params, query params, type hints, `Query` validation, default values.

Create endpoints that use path and query parameters, with validation on the query parameter.

**Starter code:**
```python
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/greet/{name}")
def greet(name: str, title: str = "friend"):
    return {"message": f"Hello, {title} {name}!"}

@app.get("/add")
def add(a: int, b: int = Query(..., gt=0, description="A positive integer")):
    return {"sum": a + b}

# Run with: uvicorn main:app --reload
```

**Task:** Make the `title` query parameter optional with a maximum length using `Query(max_length=20)`.

## Exercise 3: In-Memory CRUD with HTTPException
**Difficulty:** Basic
**Concepts:** GET/POST/PUT/DELETE, Pydantic models, `HTTPException`, in-memory store, status codes.

Build a "tasks" API backed by a Python list, with full CRUD and proper 404/400 error handling via `HTTPException`.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException, status
from pydantic import BaseModel

app = FastAPI()

class TaskCreate(BaseModel):
    title: str

class Task(TaskCreate):
    id: int
    done: bool = False

tasks: list[Task] = []
next_id = 1

@app.get("/tasks")
def list_tasks():
    return tasks

@app.post("/tasks", status_code=status.HTTP_201_CREATED)
def create_task(body: TaskCreate):
    global next_id
    task = Task(id=next_id, title=body.title)
    next_id += 1
    tasks.append(task)
    return task

@app.get("/tasks/{task_id}")
def get_task(task_id: int):
    for task in tasks:
        if task.id == task_id:
            return task
    raise HTTPException(status_code=404, detail="Task not found")

@app.put("/tasks/{task_id}")
def update_task(task_id: int, body: TaskCreate):
    for task in tasks:
        if task.id == task_id:
            task.title = body.title
            return task
    raise HTTPException(status_code=404, detail="Task not found")

@app.delete("/tasks/{task_id}")
def delete_task(task_id: int):
    for i, task in enumerate(tasks):
        if task.id == task_id:
            return tasks.pop(i)
    raise HTTPException(status_code=404, detail="Task not found")

# Run with: uvicorn main:app --reload
```

**Task:** Add a `PATCH /tasks/{task_id}/toggle` endpoint that flips the `done` field, and confirm the auto-generated Swagger docs at `/docs` show all endpoints.
