## Exercise 1: Pydantic Model + GET /employees + POST
**Difficulty:** Basic
**Concepts:** Pydantic models, FastAPI app, GET/POST, automatic validation

Define an `Employee` model and endpoints to list and create employees.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Employee(BaseModel):
    id: int
    name: str
    role: str

employees = [
    Employee(id=1, name="Ana López", role="Engineer"),
]

@app.get("/employees")
def get_employees():
    return employees

@app.post("/employees", status_code=201)
def create_employee(emp: Employee):
    employees.append(emp)
    return emp
```

## Exercise 2: Path Params + PUT + HTTPException
**Difficulty:** Basic
**Concepts:** path parameters, PUT, HTTPException, 404 handling

Fetch and update a single employee by id, raising a 404 when missing.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Employee(BaseModel):
    id: int
    name: str
    role: str

employees = [
    Employee(id=1, name="Ana López", role="Engineer"),
]

@app.get("/employees/{emp_id}")
def get_employee(emp_id: int):
    for emp in employees:
        if emp.id == emp_id:
            return emp
    raise HTTPException(status_code=404, detail="employee not found")

@app.put("/employees/{emp_id}")
def update_employee(emp_id: int, updated: Employee):
    for i, emp in enumerate(employees):
        if emp.id == emp_id:
            employees[i] = updated
            return updated
    raise HTTPException(status_code=404, detail="employee not found")
```

**Task:** Add a query parameter `?role=Engineer` to filter the list returned by GET /employees.

## Exercise 3: DELETE + Full CRUD
**Difficulty:** Basic
**Concepts:** DELETE, status codes, complete CRUD

Add a delete endpoint so the API supports full create/read/update/delete.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Employee(BaseModel):
    id: int
    name: str
    role: str

employees = [
    Employee(id=1, name="Ana López", role="Engineer"),
]

@app.get("/employees")
def list_employees():
    return employees

@app.post("/employees", status_code=201)
def create_employee(emp: Employee):
    employees.append(emp)
    return emp

@app.get("/employees/{emp_id}")
def get_employee(emp_id: int):
    for emp in employees:
        if emp.id == emp_id:
            return emp
    raise HTTPException(status_code=404, detail="employee not found")

@app.put("/employees/{emp_id}")
def update_employee(emp_id: int, updated: Employee):
    for i, emp in enumerate(employees):
        if emp.id == emp_id:
            employees[i] = updated
            return updated
    raise HTTPException(status_code=404, detail="employee not found")

@app.delete("/employees/{emp_id}", status_code=204)
def delete_employee(emp_id: int):
    for i, emp in enumerate(employees):
        if emp.id == emp_id:
            employees.pop(i)
            return
    raise HTTPException(status_code=404, detail="employee not found")
```

**Task:** Use `response_model=list[Employee]` on the list endpoint so responses are documented and validated.
