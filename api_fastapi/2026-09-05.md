## 1. Basic GET Endpoint with Query Parameters
- **Description**: Create a FastAPI app with a `GET` endpoint that accepts a query parameter and returns a greeting.
- **Difficulty**: Beginner
- **Concepts**: FastAPI app setup, path operations (`@app.get`), query parameters, automatic docs (`/docs`)
- **Example/Starter code**:
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"message": "Hello, World!"}

@app.get("/greet")
def greet(name: str = "Guest"):
    return {"message": f"Hello, {name}!"}
```

## 2. RESTful CRUD API with Pydantic Models
- **Description**: Build a CRUD API for managing items using Pydantic models for request/response validation, supporting `GET`, `POST`, `PUT`, and `DELETE`.
- **Difficulty**: Beginner
- **Concepts**: Pydantic `BaseModel`, `Body`, path parameters, HTTP status codes, CRUD
- **Example/Starter code**:
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str

items = {1: {"name": "apple"}}

@app.get("/items")
def get_items():
    return items

@app.post("/items", status_code=201)
def create_item(item: Item):
    item_id = max(items) + 1
    items[item_id] = {"name": item.name}
    return {"id": item_id, **items[item_id]}

@app.put("/items/{item_id}")
def update_item(item_id: int, item: Item):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    items[item_id] = {"name": item.name}
    return {"id": item_id, **items[item_id]}

@app.delete("/items/{item_id}")
def delete_item(item_id: int):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    del items[item_id]
    return {"message": "Deleted"}
```

## 3. Error Handling & Validation
- **Description**: Use `HTTPException` and FastAPI's automatic request validation to return consistent error responses for invalid input and missing resources.
- **Difficulty**: Beginner
- **Concepts**: `HTTPException`, Pydantic validation (automatic 422), custom exception handlers
- **Example/Starter code**:
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()

class User(BaseModel):
    name: str = Field(min_length=2)
    age: int = Field(ge=0, le=120)

users = {}

@app.post("/users")
def create_user(user: User):
    user_id = len(users) + 1
    users[user_id] = user
    return {"id": user_id, **user.model_dump()}

@app.get("/users/{user_id}")
def get_user(user_id: int):
    if user_id not in users:
        raise HTTPException(status_code=404, detail="User not found")
    return users[user_id]
```
