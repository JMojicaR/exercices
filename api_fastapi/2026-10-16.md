## Exercise 1: Pydantic model + GET /products + POST /products
**Difficulty:** Basic
**Concepts:** Pydantic BaseModel, routing, type hints

Define a Product model and create endpoints to list and create products.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Product(BaseModel):
    name: str
    price: float

products = [
    {"id": 1, "name": "Laptop", "price": 999.99},
]

@app.get("/products")
def get_products():
    return products

@app.post("/products", status_code=201)
def create_product(product: Product):
    new_product = {"id": len(products) + 1, **product.model_dump()}
    products.append(new_product)
    return new_product
```

**Task:** Add a `quantity` field (int, default 0) to the Product model and return it in responses.

## Exercise 2: Path params + PUT + HTTPException
**Difficulty:** Basic
**Concepts:** path parameters, PUT, HTTPException, status codes

Add an endpoint to update a product by id, raising a 404 when not found.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Product(BaseModel):
    name: str
    price: float

products = [
    {"id": 1, "name": "Laptop", "price": 999.99},
]

@app.put("/products/{product_id}")
def update_product(product_id: int, product: Product):
    for p in products:
        if p["id"] == product_id:
            p.update(product.model_dump())
            return p
    raise HTTPException(status_code=404, detail="product not found")
```

**Task:** Add a GET /products/{product_id} endpoint that also raises 404 when the product is missing.

## Exercise 3: DELETE + full CRUD + query param filtering
**Difficulty:** Basic
**Concepts:** DELETE, query parameters, full CRUD

Complete the CRUD API with a delete endpoint and a query filter.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import Optional

app = FastAPI()

class Product(BaseModel):
    name: str
    price: float

products = [
    {"id": 1, "name": "Laptop", "price": 999.99},
    {"id": 2, "name": "Mouse", "price": 24.99},
]

@app.get("/products")
def get_products(name: Optional[str] = None):
    if name:
        return [p for p in products if name.lower() in p["name"].lower()]
    return products

@app.delete("/products/{product_id}")
def delete_product(product_id: int):
    for p in products:
        if p["id"] == product_id:
            products.remove(p)
            return {"message": "deleted"}
    raise HTTPException(status_code=404, detail="product not found")
```

**Task:** Add POST and PUT endpoints so the Products API supports the complete set of CRUD operations.
