## Exercise 1: Pydantic model + GET /tasks + POST /tasks
**Difficulty:** Basic
**Concepts:** Pydantic models, GET/POST, automatic validation

Define a `Task` model and create endpoints to list and create tasks.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks = [
    Task(id=1, title="Learn FastAPI"),
    Task(id=2, title="Build a CRUD API", done=True),
]

@app.get("/tasks")
def get_tasks():
    return tasks

@app.post("/tasks", status_code=201)
def create_task(task: Task):
    tasks.append(task)
    return task
```

**Task:** Add a query parameter `?done=true` that filters the returned tasks by completion status.

## Exercise 2: GET /tasks/{id} + HTTPException 404
**Difficulty:** Basic
**Concepts:** path parameters, HTTPException, error handling

Fetch a single task by id, returning a 404 with a JSON error when it does not exist.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks = [Task(id=1, title="Learn FastAPI")]

@app.get("/tasks/{task_id}")
def get_task(task_id: int):
    for task in tasks:
        if task.id == task_id:
            return task
    raise HTTPException(status_code=404, detail="task not found")
```

**Task:** Add validation so `task_id` must be a positive integer (use `gt=0` in the path parameter).

## Exercise 3: PUT /tasks/{id} + DELETE /tasks/{id} (full CRUD)
**Difficulty:** Basic
**Concepts:** PUT, DELETE, in-memory CRUD, HTTPException

Add update and delete endpoints to complete a full CRUD API.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks = [Task(id=1, title="Learn FastAPI")]

@app.get("/tasks")
def get_tasks():
    return tasks

@app.post("/tasks", status_code=201)
def create_task(task: Task):
    tasks.append(task)
    return task

@app.get("/tasks/{task_id}")
def get_task(task_id: int):
    for task in tasks:
        if task.id == task_id:
            return task
    raise HTTPException(status_code=404, detail="task not found")

@app.put("/tasks/{task_id}")
def update_task(task_id: int, updated: Task):
    for i, task in enumerate(tasks):
        if task.id == task_id:
            tasks[i] = updated
            return updated
    raise HTTPException(status_code=404, detail="task not found")

@app.delete("/tasks/{task_id}", status_code=204)
def delete_task(task_id: int):
    for i, task in enumerate(tasks):
        if task.id == task_id:
            del tasks[i]
            return None
    raise HTTPException(status_code=404, detail="task not found")
```

**Task:** Auto-generate the id when it is omitted from the request body instead of requiring the client to provide it.
