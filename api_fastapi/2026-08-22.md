## Exercise 1: Calculator API (path + query params)
**Difficulty:** Basic
### Problem
Build a calculator API with two endpoints:
1. `GET /add/{a}/{b}` — add two integers passed as **path parameters**.
2. `GET /calculate?a=<num>&b=<num>&op=<add|subtract|multiply|divide>` — compute using **query parameters**. Return an error (400) when dividing by zero or using an unknown operation.

### Concepts
- Path parameters with type hints (`a: int`)
- Query parameters with defaults (`op: str = "add"`)
- Returning dictionaries (FastAPI auto-converts to JSON)

### HTTP Method(s)
`GET`

### Example / Starter Code
```python
from fastapi import FastAPI
from fastapi.responses import JSONResponse

app = FastAPI()

@app.get("/add/{a}/{b}")
def add(a: int, b: int):
    return {"operation": "add", "result": a + b}

@app.get("/calculate")
def calculate(a: float, b: float, op: str = "add"):
    if op == "add":
        result = a + b
    elif op == "subtract":
        result = a - b
    elif op == "multiply":
        result = a * b
    elif op == "divide":
        if b == 0:
            return JSONResponse(status_code=400, content={"error": "Cannot divide by zero"})
        result = a / b
    else:
        return JSONResponse(status_code=400, content={"error": f"Unknown operation: {op}"})
    return {"operation": op, "result": result}
```
**Test with curl:**
```bash
curl "http://127.0.0.1:8000/add/3/4"
curl "http://127.0.0.1:8000/calculate?a=10&b=4&op=multiply"
curl "http://127.0.0.1:8000/calculate?a=10&b=0&op=divide"
```
> Run with: `uvicorn main:app --reload` (save the file as `main.py`).

## Exercise 2: Recipes CRUD with Pydantic Models
**Difficulty:** Basic
### Problem
Build an in-memory CRUD API for recipes using Pydantic models:
- Define `Recipe` (name, ingredients, steps) and `RecipeOut` (adds `id`).
- `GET /recipes` — list all recipes.
- `POST /recipes` — create a recipe (validate with Pydantic, status 201).
- `GET /recipes/{id}` — fetch one recipe or 404.
- `PUT /recipes/{id}` — update a recipe or 404.
- `DELETE /recipes/{id}` — delete a recipe or 404.

### Concepts
- Pydantic `BaseModel` for request/response schemas
- `response_model` for automatic serialization
- `status_code` and `HTTPException` for 404s
- In-memory dict with auto-incrementing id

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code
```python
from typing import List, Optional
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Recipe(BaseModel):
    name: str
    ingredients: List[str] = []
    steps: Optional[str] = None

class RecipeOut(Recipe):
    id: int

recipes = {}
next_id = 1

@app.get("/recipes", response_model=List[RecipeOut])
def list_recipes():
    return list(recipes.values())

@app.post("/recipes", response_model=RecipeOut, status_code=201)
def create_recipe(recipe: Recipe):
    global next_id
    new_recipe = RecipeOut(id=next_id, **recipe.dict())
    recipes[next_id] = new_recipe
    next_id += 1
    return new_recipe

@app.get("/recipes/{recipe_id}", response_model=RecipeOut)
def get_recipe(recipe_id: int):
    if recipe_id not in recipes:
        raise HTTPException(status_code=404, detail="Recipe not found")
    return recipes[recipe_id]

@app.put("/recipes/{recipe_id}", response_model=RecipeOut)
def update_recipe(recipe_id: int, recipe: Recipe):
    if recipe_id not in recipes:
        raise HTTPException(status_code=404, detail="Recipe not found")
    updated = RecipeOut(id=recipe_id, **recipe.dict())
    recipes[recipe_id] = updated
    return updated

@app.delete("/recipes/{recipe_id}")
def delete_recipe(recipe_id: int):
    if recipe_id not in recipes:
        raise HTTPException(status_code=404, detail="Recipe not found")
    del recipes[recipe_id]
    return {"message": "Recipe deleted"}
```
**Test with curl:**
```bash
curl http://127.0.0.1:8000/recipes
curl -X POST http://127.0.0.1:8000/recipes \
  -H "Content-Type: application/json" \
  -d '{"name": "Pancakes", "ingredients": ["flour", "milk", "egg"], "steps": "Mix and fry."}'
curl http://127.0.0.1:8000/recipes/1
curl -X PUT http://127.0.0.1:8000/recipes/1 \
  -H "Content-Type: application/json" \
  -d '{"name": "Fluffy Pancakes", "ingredients": ["flour", "milk", "egg", "sugar"]}'
curl -X DELETE http://127.0.0.1:8000/recipes/1
curl http://127.0.0.1:8000/recipes/999   # -> 404
```
> Run with: `uvicorn main:app --reload` (save the file as `main.py`).

## Exercise 3: Validation + HTTPException + Custom Middleware
**Difficulty:** Basic
### Problem
Combine validation, error handling, and middleware:
1. Add a custom HTTP middleware that measures request time and adds an `X-Process-Time` response header.
2. Define an `Item` Pydantic model with validation rules (`name` 1–50 chars, `price > 0`, `quantity >= 0`).
3. `POST /items` creates an item (FastAPI auto-validates, returning 422 on bad input).
4. `GET /items/{id}` returns an item or raises `HTTPException` 404.

### Concepts
- `@app.middleware("http")` for custom middleware
- Pydantic `Field` constraints (`min_length`, `gt`, `ge`)
- Automatic request validation (422 responses)
- Raising `HTTPException`

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code
```python
import time
from fastapi import FastAPI, HTTPException, Request
from pydantic import BaseModel, Field

app = FastAPI()

@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    start = time.time()
    response = await call_next(request)
    process_time = time.time() - start
    response.headers["X-Process-Time"] = str(process_time)
    return response

class Item(BaseModel):
    name: str = Field(..., min_length=1, max_length=50)
    price: float = Field(..., gt=0)
    quantity: int = Field(0, ge=0)

items = {}
next_id = 1

@app.post("/items", status_code=201)
def create_item(item: Item):
    global next_id
    items[next_id] = item
    item_id = next_id
    next_id += 1
    return {"id": item_id, **item.dict()}

@app.get("/items/{item_id}")
def get_item(item_id: int):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": item_id, **items[item_id].dict()}
```
**Test with curl:**
```bash
curl -X POST http://127.0.0.1:8000/items \
  -H "Content-Type: application/json" \
  -d '{"name": "Widget", "price": 9.99, "quantity": 3}'
curl -X POST http://127.0.0.1:8000/items \
  -H "Content-Type: application/json" \
  -d '{"name": "", "price": -5}'          # -> 422 validation error
curl http://127.0.0.1:8000/items/1
curl http://127.0.0.1:8000/items/999       # -> 404
curl -i http://127.0.0.1:8000/items/1      # note the X-Process-Time header
```
> Run with: `uvicorn main:app --reload` (save the file as `main.py`).
