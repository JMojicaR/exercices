## Exercise 1: Hello + Echo API (path & query params)

**Difficulty:** Basic

### Problem
Build a FastAPI app with two endpoints:
1. `GET /` — returns a JSON welcome message.
2. `GET /echo/{message}?repeat=<int>` — echoes the message repeated `repeat` times (default 1).

**Example request:** `GET /echo/Hi?repeat=3`

**Expected response:** `{"echo": "HiHiHi"}`

### Concepts
- `@app.get()` decorator
- Path parameters (`{message}`)
- Query parameters with defaults and types

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "Hello, FastAPI!"}

@app.get("/echo/{message}")
def echo(message: str, repeat: int = 1):
    return {"echo": message * repeat}
```

## Exercise 2: Books CRUD with Pydantic

**Difficulty:** Basic

### Problem
Build a Books API backed by an in-memory dictionary. Implement `GET /books`, `POST /books`, `GET /books/{id}`, `PUT /books/{id}`, and `DELETE /books/{id}` using a Pydantic `Book` model for request validation.

### Concepts
- Pydantic `BaseModel`
- `status_code` on route decorators
- `HTTPException` with `404`
- `model_dump()`

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from typing import Optional
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Book(BaseModel):
    title: str
    author: str
    year: Optional[int] = None

books = {}
next_id = 1

@app.get("/books")
def list_books():
    return list(books.values())

@app.post("/books", status_code=201)
def create_book(book: Book):
    global next_id
    books[next_id] = {"id": next_id, **book.model_dump()}
    next_id += 1
    return books[next_id - 1]

@app.get("/books/{book_id}")
def get_book(book_id: int):
    if book_id not in books:
        raise HTTPException(status_code=404, detail="Book not found")
    return books[book_id]

@app.put("/books/{book_id}")
def update_book(book_id: int, book: Book):
    if book_id not in books:
        raise HTTPException(status_code=404, detail="Book not found")
    books[book_id] = {"id": book_id, **book.model_dump()}
    return books[book_id]

@app.delete("/books/{book_id}")
def delete_book(book_id: int):
    if book_id not in books:
        raise HTTPException(status_code=404, detail="Book not found")
    del books[book_id]
    return {"message": "Book deleted"}
```

## Exercise 3: Middleware + Custom Exception Handler

**Difficulty:** Basic

### Problem
Add an HTTP middleware that measures request time and sets an `X-Process-Time` response header, and a custom `HTTPException` handler that returns a consistent JSON error shape. Include an endpoint that raises `400` for invalid input.

### Concepts
- `@app.middleware("http")`
- `@app.exception_handler(HTTPException)`
- `JSONResponse`
- `HTTPException` with status codes

### HTTP Method(s)
`GET` (any)

### Example / Starter Code

```python
import time
from fastapi import FastAPI, Request, HTTPException
from fastapi.responses import JSONResponse

app = FastAPI()

@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    start = time.time()
    response = await call_next(request)
    response.headers["X-Process-Time"] = str(time.time() - start)
    return response

@app.exception_handler(HTTPException)
async def http_exception_handler(request, exc):
    return JSONResponse(status_code=exc.status_code, content={"error": exc.detail})

@app.get("/items/{item_id}")
def read_item(item_id: int):
    if item_id < 1:
        raise HTTPException(status_code=400, detail="item_id must be positive")
    return {"item_id": item_id}
```
