## Exercise 1: Read — GET with Path and Query Parameters
**Difficulty:** Basic
**Concepts:** `FastAPI` app, `@app.get`, path params with type hints, Pydantic model, `HTTPException`

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Note(BaseModel):
    id: int
    title: str
    body: str

notes = [
    Note(id=1, title="Buy milk", body="Remember to buy milk"),
    Note(id=2, title="Call mom", body="Call mom on Sunday"),
]

@app.get("/notes")
def list_notes():
    return notes

@app.get("/notes/{note_id}")
def get_note(note_id: int):
    for note in notes:
        if note.id == note_id:
            return note
    raise HTTPException(status_code=404, detail="Note not found")
```

**Task:** Run with `uvicorn main:app --reload` and open `http://127.0.0.1:8000/docs` to try the endpoints. Confirm `/notes/99` returns 404.

## Exercise 2: Create — POST with Automatic Validation
**Difficulty:** Basic
**Concepts:** request-body model, automatic `422` validation, `status_code=201`, id generation

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class NoteIn(BaseModel):
    title: str
    body: str

class Note(NoteIn):
    id: int

notes = []

@app.post("/notes", status_code=201)
def create_note(payload: NoteIn):
    new_id = max((n.id for n in notes), default=0) + 1
    note = Note(id=new_id, title=payload.title, body=payload.body)
    notes.append(note)
    return note
```

**Task:** POST `{"title": "Gym", "body": "Leg day"}` and confirm a `201`. Then POST `{"title": "Missing body"}` (no `body`) and confirm FastAPI returns a `422` automatically.

## Exercise 3: Update and Delete — PUT/DELETE + HTTPException
**Difficulty:** Basic
**Concepts:** `@app.put`, `@app.delete`, updating in place, removing by id, raising `HTTPException`

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class NoteIn(BaseModel):
    title: str
    body: str

class Note(NoteIn):
    id: int

notes = [Note(id=1, title="Buy milk", body="Remember")]

@app.put("/notes/{note_id}")
def update_note(note_id: int, payload: NoteIn):
    for note in notes:
        if note.id == note_id:
            note.title = payload.title
            note.body = payload.body
            return note
    raise HTTPException(status_code=404, detail="Note not found")

@app.delete("/notes/{note_id}")
def delete_note(note_id: int):
    for i, note in enumerate(notes):
        if note.id == note_id:
            removed = notes.pop(i)
            return {"deleted": removed}
    raise HTTPException(status_code=404, detail="Note not found")
```

**Task:** PUT note `1` with a new title/body, then DELETE it, then GET `/notes/1` and confirm a 404.
