## Exercise 1: Todo API — Full CRUD with Pydantic Models

**Difficulty:** Basic

### Problem
Build a `todos` API with full CRUD using Pydantic models:
- `GET /todos` — list all todos
- `POST /todos` — create a todo from a `TodoCreate` body; return 201
- `GET /todos/{todo_id}` — return one todo, or 404
- `PUT /todos/{todo_id}` — replace a todo, or 404
- `DELETE /todos/{todo_id}` — delete a todo, or 404

### Concepts
- `BaseModel` request/response models
- `response_model` for typed responses
- Path parameters with type hints (`todo_id: int`)
- `HTTPException(status_code=404, ...)`

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List

app = FastAPI()


class Todo(BaseModel):
    id: int
    task: str
    done: bool = False


class TodoCreate(BaseModel):
    task: str
    done: bool = False


todos: List[Todo] = []
next_id = 1


@app.get('/todos', response_model=List[Todo])
def list_todos():
    return todos


@app.post('/todos', response_model=Todo, status_code=201)
def create_todo(todo: TodoCreate):
    global next_id
    new = Todo(id=next_id, task=todo.task, done=todo.done)
    next_id += 1
    todos.append(new)
    return new


@app.get('/todos/{todo_id}', response_model=Todo)
def get_todo(todo_id: int):
    for t in todos:
        if t.id == todo_id:
            return t
    raise HTTPException(status_code=404, detail='Todo not found')


@app.put('/todos/{todo_id}', response_model=Todo)
def update_todo(todo_id: int, todo: TodoCreate):
    for t in todos:
        if t.id == todo_id:
            t.task = todo.task
            t.done = todo.done
            return t
    raise HTTPException(status_code=404, detail='Todo not found')


@app.delete('/todos/{todo_id}')
def delete_todo(todo_id: int):
    for i, t in enumerate(todos):
        if t.id == todo_id:
            todos.pop(i)
            return {'message': f'Todo {todo_id} deleted'}
    raise HTTPException(status_code=404, detail='Todo not found')
```

**Run & test:**
```bash
uvicorn main:app --reload
curl -X POST http://localhost:8000/todos -H "Content-Type: application/json" -d '{"task":"Buy milk"}'
curl http://localhost:8000/todos
curl http://localhost:8000/todos/1
```

## Exercise 2: Products API — Query & Path Parameter Validation

**Difficulty:** Basic

### Problem
Build a `products` API with parameter validation:
- `GET /products?limit=5` — return up to `limit` products; `limit` must be between 1 and 100
- `GET /products/{product_id}` — return a product by ID (`>= 1`), or 404
- `POST /products` — create a product from a `Product` body; return 201

### Concepts
- `Query(..., ge=1, le=100)` for query validation
- `Path(..., ge=1)` for path validation
- Pydantic model for the request body
- `status_code=201`

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code

```python
from fastapi import FastAPI, HTTPException, Query, Path
from pydantic import BaseModel

app = FastAPI()


class Product(BaseModel):
    id: int
    name: str
    price: float


products = [
    Product(id=1, name='Widget', price=9.99),
    Product(id=2, name='Gadget', price=19.99),
]


@app.get('/products')
def list_products(limit: int = Query(10, ge=1, le=100)):
    return products[:limit]


@app.get('/products/{product_id}')
def get_product(product_id: int = Path(..., ge=1)):
    for p in products:
        if p.id == product_id:
            return p
    raise HTTPException(status_code=404, detail='Product not found')


@app.post('/products', status_code=201)
def create_product(product: Product):
    products.append(product)
    return product
```

**Test:**
```bash
curl "http://localhost:8000/products?limit=1"
curl http://localhost:8000/products/2
curl -X POST http://localhost:8000/products -H "Content-Type: application/json" -d '{"id":3,"name":"Doohickey","price":4.99}'
```

## Exercise 3: Books API — Middleware & Error Handling

**Difficulty:** Basic

### Problem
Build a `books` API with request-logging middleware and conflict handling:
- `GET /books` — list all books
- `POST /books` — create a book; return 409 if the ID already exists
- `GET /books/{book_id}` — return a book, or 404
- Add `@app.middleware("http")` that logs the method, path, status code, and elapsed time for every request

### Concepts
- HTTP middleware with `@app.middleware("http")`
- Timing a request with `time.time()`
- `HTTPException` for 404 and 409 responses
- `response_model`

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code

```python
from fastapi import FastAPI, Request, HTTPException
from pydantic import BaseModel
from typing import List
import time

app = FastAPI()


@app.middleware('http')
async def log_requests(request: Request, call_next):
    start = time.time()
    response = await call_next(request)
    elapsed = time.time() - start
    print(f'{request.method} {request.url.path} -> {response.status_code} ({elapsed:.4f}s)')
    return response


class Book(BaseModel):
    id: int
    title: str
    author: str


books: List[Book] = []


@app.get('/books', response_model=List[Book])
def list_books():
    return books


@app.post('/books', response_model=Book, status_code=201)
def create_book(book: Book):
    if any(b.id == book.id for b in books):
        raise HTTPException(status_code=409, detail='Book already exists')
    books.append(book)
    return book


@app.get('/books/{book_id}', response_model=Book)
def get_book(book_id: int):
    for b in books:
        if b.id == book_id:
            return b
    raise HTTPException(status_code=404, detail='Book not found')
```

**Test:**

```bash
curl http://localhost:8000/books
curl http://localhost:8000/books/999   # 404
```
