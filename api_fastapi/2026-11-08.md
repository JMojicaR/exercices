## Exercise 1: Pydantic Model + GET Endpoints
**Difficulty:** Basic
**Concepts:** `FastAPI` app, `BaseModel`, `pydantic` types, `@app.get`, path parameters

Define a `User` model and two GET endpoints: one listing all users and one returning a single user by `id` (404 if missing).

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class User(BaseModel):
    id: int
    name: str
    email: str

users = [
    User(id=1, name="Ana", email="ana@example.com"),
    User(id=2, name="Luis", email="luis@example.com"),
]

@app.get("/users")
def get_users():
    return users

@app.get("/users/{user_id}")
def get_user(user_id: int):
    for user in users:
        if user.id == user_id:
            return user
    raise HTTPException(status_code=404, detail="User not found")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

**Task:** Add a `?active=true` query filter to `get_users()` using a `bool` query parameter. Run with `uvicorn` and visit the auto-generated docs at `http://localhost:8000/docs`.

## Exercise 2: POST + PUT with Field Validation
**Difficulty:** Basic
**Concepts:** `@app.post`, `@app.put`, request body, `Field` validation, `EmailStr`

Add a `POST /users` endpoint to create a user and a `PUT /users/<id>` endpoint to replace one, validating the body with Pydantic `Field` constraints.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()

class UserIn(BaseModel):
    name: str = Field(..., min_length=1, max_length=50)
    email: str = Field(..., pattern=r"^[^@]+@[^@]+\.[^@]+$")

class User(UserIn):
    id: int

users = [
    User(id=1, name="Ana", email="ana@example.com"),
    User(id=2, name="Luis", email="luis@example.com"),
]

@app.post("/users", status_code=201)
def create_user(user_in: UserIn):
    new_user = User(id=max(u.id for u in users) + 1, **user_in.model_dump())
    users.append(new_user)
    return new_user

@app.put("/users/{user_id}")
def update_user(user_id: int, user_in: UserIn):
    for user in users:
        if user.id == user_id:
            user.name = user_in.name
            user.email = user_in.email
            return user
    raise HTTPException(status_code=404, detail="User not found")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

**Task:** Send an invalid email and observe FastAPI's automatic `422` validation response. Then add a `phone: str | None = None` optional field to `UserIn` and confirm it is accepted as `null`.

## Exercise 3: DELETE + Query Filtering
**Difficulty:** Basic
**Concepts:** `@app.delete`, `HTTPException`, query parameters, status codes

Add a `DELETE /users/<id>` endpoint, and a filtered `GET /users/search?name=...` endpoint that returns matching users.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class User(BaseModel):
    id: int
    name: str
    email: str

users = [
    User(id=1, name="Ana", email="ana@example.com"),
    User(id=2, name="Luis", email="luis@example.com"),
]

@app.delete("/users/{user_id}")
def delete_user(user_id: int):
    for i, user in enumerate(users):
        if user.id == user_id:
            deleted = users.pop(i)
            return {"message": f"Deleted '{deleted.name}'"}
    raise HTTPException(status_code=404, detail="User not found")

@app.get("/users/search")
def search_users(name: str):
    return [u for u in users if name.lower() in u.name.lower()]

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

**Task:** Make `DELETE /users/<id>` return `204 No Content` (empty body) with `status_code=204`. Then add a `GET /users/count` endpoint returning `{"total": len(users)}`.
