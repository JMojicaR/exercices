## Exercise 1: Greeting API (path + query params)

**Difficulty:** Basic

### Problem
Build a FastAPI app with:
1. `GET /` — returns `{"message": "Hello, World!"}`.
2. `GET /greet/{name}` — returns a greeting using the path parameter.
3. `GET /greet?name=<string>` — returns a greeting using an optional query parameter (default "World").

### Concepts
- `@app.get` decorator
- Path parameters `{name}`
- Optional query parameters with defaults

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "Hello, World!"}

@app.get("/greet/{name}")
def greet_path(name: str):
    return {"message": f"Hello, {name}!"}

@app.get("/greet")
def greet_query(name: str = "World"):
    return {"message": f"Hello, {name}!"}
```

## Exercise 2: Students CRUD with Pydantic

**Difficulty:** Basic

### Problem
Build a Students API backed by an in-memory dict. Define a Pydantic `Student` model and implement:
1. `POST /students` — create a student.
2. `GET /students` — list all students.
3. `GET /students/{id}` — fetch one student.
4. `PUT /students/{id}` — update a student.
5. `DELETE /students/{id}` — delete a student.

Return 404 via `HTTPException` for missing students.

### Concepts
- Pydantic `BaseModel`
- Request body with type hints
- `HTTPException` with status codes

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Student(BaseModel):
    name: str
    grade: int

students = {}
next_id = 1

@app.post("/students", status_code=201)
def create_student(student: Student):
    global next_id
    students[next_id] = student
    student_id = next_id
    next_id += 1
    return {"id": student_id, **student.model_dump()}

@app.get("/students")
def list_students():
    return [{"id": sid, **s.model_dump()} for sid, s in students.items()]

@app.get("/students/{student_id}")
def get_student(student_id: int):
    if student_id not in students:
        raise HTTPException(status_code=404, detail="Student not found")
    return {"id": student_id, **students[student_id].model_dump()}

@app.put("/students/{student_id}")
def update_student(student_id: int, student: Student):
    if student_id not in students:
        raise HTTPException(status_code=404, detail="Student not found")
    students[student_id] = student
    return {"id": student_id, **student.model_dump()}

@app.delete("/students/{student_id}")
def delete_student(student_id: int):
    if student_id not in students:
        raise HTTPException(status_code=404, detail="Student not found")
    del students[student_id]
    return {"message": "Student deleted"}
```

## Exercise 3: Validation + Error Handling + Middleware

**Difficulty:** Basic

### Problem
Extend the API with:
1. Path/query parameter validation (e.g. `ge=1` for positive integers).
2. A logging middleware (`@app.middleware("http")`) that prints each request's method and path.
3. Consistent error handling via `HTTPException`.

### Concepts
- `Query`/path validation constraints (`ge`, `le`)
- HTTP middleware
- `HTTPException` with custom `detail`

### HTTP Method(s)
`GET` (any)

### Example / Starter Code

```python
from fastapi import FastAPI, Query, Request, HTTPException

app = FastAPI()

@app.middleware("http")
async def log_requests(request: Request, call_next):
    print(f"{request.method} {request.url.path}")
    response = await call_next(request)
    return response

@app.get("/square")
def square(n: int = Query(..., ge=1, description="A positive integer")):
    return {"result": n * n}
```
