## Exercise 1: Pydantic model + GET/POST endpoints
**Difficulty:** Basic
**Concepts:** Pydantic models, GET, POST

Define a Product model and endpoints to list and create products.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Product(BaseModel):
    name: str
    price: float

products = [
    {"id": 1, "name": "Laptop", "price": 999.99},
    {"id": 2, "name": "Mouse", "price": 24.50},
]

@app.get("/products")
def get_products():
    return products

@app.post("/products")
def create_product(product: Product):
    item = {"id": len(products) + 1, **product.dict()}
    products.append(item)
    return item

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app)
```

**Task:** Make the POST endpoint return a 201 status code instead of the default 200.

## Exercise 2: Path/query params + HTTPException 404
**Difficulty:** Basic
**Concepts:** path parameters, query parameters, HTTPException

Fetch one product by id and filter the list with a query parameter, returning 404 when missing.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Product(BaseModel):
    name: str
    price: float

products = [
    {"id": 1, "name": "Laptop", "price": 999.99},
    {"id": 2, "name": "Mouse", "price": 24.50},
]

@app.get("/products")
def get_products(category: str = None):
    if category:
        return [p for p in products if p.get("category") == category]
    return products

@app.get("/products/{product_id}")
def get_product(product_id: int):
    for product in products:
        if product["id"] == product_id:
            return product
    raise HTTPException(status_code=404, detail="product not found")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app)
```

**Task:** Add a GET /products/search endpoint that filters products by a name query parameter.

## Exercise 3: PUT/DELETE full CRUD
**Difficulty:** Basic
**Concepts:** PUT, DELETE, full CRUD

Complete CRUD by adding update and delete endpoints for products.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Product(BaseModel):
    name: str
    price: float

products = [
    {"id": 1, "name": "Laptop", "price": 999.99},
]

@app.get("/products")
def get_products():
    return products

@app.post("/products")
def create_product(product: Product):
    item = {"id": len(products) + 1, **product.dict()}
    products.append(item)
    return item

@app.put("/products/{product_id}")
def update_product(product_id: int, product: Product):
    for p in products:
        if p["id"] == product_id:
            p.update(product.dict())
            return p
    raise HTTPException(status_code=404, detail="product not found")

@app.delete("/products/{product_id}")
def delete_product(product_id: int):
    for i, p in enumerate(products):
        if p["id"] == product_id:
            products.pop(i)
            return {"message": "deleted"}
    raise HTTPException(status_code=404, detail="product not found")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app)
```

**Task:** Add a GET /products/{product_id} endpoint so the API exposes full CRUD.
