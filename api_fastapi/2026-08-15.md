## Exercise 1: Basic Endpoints with a Pydantic Model

**Difficulty:** Basic

### Problem
Create a FastAPI app with:
- `GET /` — returns a welcome message
- `POST /items` — accepts a Pydantic `Item` body (`name: str`, `price: float`, `in_stock: bool = True`) and returns it with an `id`
- Use a response model to shape the output

### Concepts
- `FastAPI()` app instantiation
- Pydantic `BaseModel` for request bodies
- Type-hinted endpoint signatures
- `response_model` for output shaping

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    price: float
    in_stock: bool = True


class ItemOut(Item):
    id: int


items = []
next_id = 1


@app.get('/')
def home():
    return {"message": "Welcome to the FastAPI store!"}


@app.post('/items', response_model=ItemOut, status_code=201)
def create_item(item: Item):
    global next_id
    new_item = ItemOut(id=next_id, **item.model_dump())
    next_id += 1
    items.append(new_item)
    return new_item
```

**Test:**
```bash
uvicorn main:app --reload
# Open http://127.0.0.1:8000/docs to try POST /items
```

## Exercise 2: Full CRUD with Path Parameters & HTTPException

**Difficulty:** Basic

### Problem
Build a full CRUD API for `posts`:
- `GET /posts` — list all posts
- `POST /posts` — create a post (`title`, `content`)
- `GET /posts/{post_id}` — fetch one post, or raise 404
- `PUT /posts/{post_id}` — update a post, or raise 404
- `DELETE /posts/{post_id}` — delete a post, or raise 404

### Concepts
- Path parameters with type hints
- `HTTPException(status_code=404, ...)`
- Full CRUD pattern
- In-memory dictionary storage

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()


class Post(BaseModel):
    title: str
    content: str


class PostOut(Post):
    id: int


posts = {}
next_id = 1


@app.get('/posts')
def list_posts():
    return list(posts.values())


@app.post('/posts', response_model=PostOut, status_code=201)
def create_post(post: Post):
    global next_id
    new_post = PostOut(id=next_id, **post.model_dump())
    posts[next_id] = new_post
    next_id += 1
    return new_post


@app.get('/posts/{post_id}', response_model=PostOut)
def get_post(post_id: int):
    if post_id not in posts:
        raise HTTPException(status_code=404, detail="Post not found")
    return posts[post_id]


@app.put('/posts/{post_id}', response_model=PostOut)
def update_post(post_id: int, post: Post):
    if post_id not in posts:
        raise HTTPException(status_code=404, detail="Post not found")
    updated = PostOut(id=post_id, **post.model_dump())
    posts[post_id] = updated
    return updated


@app.delete('/posts/{post_id}')
def delete_post(post_id: int):
    if post_id not in posts:
        raise HTTPException(status_code=404, detail="Post not found")
    del posts[post_id]
    return {"message": f"Post {post_id} deleted"}
```

**Test:**
```bash
curl -X POST http://127.0.0.1:8000/posts \
  -H "Content-Type: application/json" \
  -d '{"title":"Hello","content":"World"}'
curl http://127.0.0.1:8000/posts
curl http://127.0.0.1:8000/posts/999   # 404
```

## Exercise 3: Query Parameters, Validation & Middleware

**Difficulty:** Basic

### Problem
Extend a `books` API with query filtering, validation, and a middleware:
- `GET /books` — list books, optionally filtered by `author` query param and `min_pages` (int, `ge=1`)
- `POST /books` — create a book (`title`, `author`, `pages`)
- Add `@app.middleware("http")` that logs the method and path of each request

### Concepts
- Query parameters with validation (`Query(..., ge=1)`)
- Optional query params (`author: str | None = None`)
- `@app.middleware("http")` request/response interception
- `request.method` and `request.url.path`

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code

```python
from fastapi import FastAPI, Query
from pydantic import BaseModel
import time

app = FastAPI()


class Book(BaseModel):
    title: str
    author: str
    pages: int


class BookOut(Book):
    id: int


books = []
next_id = 1


@app.middleware("http")
async def log_requests(request, call_next):
    start = time.time()
    response = await call_next(request)
    duration = time.time() - start
    print(f"[LOG] {request.method} {request.url.path} -> {response.status_code} ({duration:.4f}s)")
    return response


@app.get('/books')
def list_books(author: str | None = None, min_pages: int = Query(1, ge=1)):
    result = books
    if author:
        result = [b for b in result if b.author.lower() == author.lower()]
    if min_pages:
        result = [b for b in result if b.pages >= min_pages]
    return result


@app.post('/books', response_model=BookOut, status_code=201)
def create_book(book: Book):
    global next_id
    new_book = BookOut(id=next_id, **book.model_dump())
    next_id += 1
    books.append(new_book)
    return new_book
```

**Test:**
```bash
curl -X POST http://127.0.0.1:8000/books \
  -H "Content-Type: application/json" \
  -d '{"title":"1984","author":"Orwell","pages":328}'
curl "http://127.0.0.1:8000/books?author=orwell&min_pages=300"
```
