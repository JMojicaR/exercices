## Exercise 1: Pydantic Model + GET Endpoints
**Difficulty:** Basic
**Concepts:** `FastAPI` app, Pydantic `BaseModel`, `@app.get`, path parameters, `HTTPException`

Define an `Expense` Pydantic model and two GET endpoints: one listing all expenses, and one returning a single expense by `id` (404 if missing).

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List

app = FastAPI()

class Expense(BaseModel):
    id: int
    description: str
    amount: float
    category: str

expenses: List[Expense] = [
    Expense(id=1, description="Groceries", amount=45.20, category="Food"),
    Expense(id=2, description="Metro card", amount=10.00, category="Transport"),
]

@app.get("/expenses", response_model=List[Expense])
def get_expenses():
    return expenses

@app.get("/expenses/{expense_id}", response_model=Expense)
def get_expense(expense_id: int):
    for e in expenses:
        if e.id == expense_id:
            return e
    raise HTTPException(status_code=404, detail="Expense not found")

# Run with: uvicorn main:app --reload
```

**Task:** Add a `?category=...` query parameter to `get_expenses()` using `category: str | None = None` and filter the list when provided.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** `@app.post`, `@app.put`, request body, automatic validation, status codes

Add a `POST /expenses` endpoint to create an expense and a `PUT /expenses/{id}` endpoint to update one, using the request body for input and returning `201` on creation.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field
from typing import List

app = FastAPI()

class Expense(BaseModel):
    id: int
    description: str
    amount: float = Field(gt=0, description="Must be positive")
    category: str

expenses: List[Expense] = [
    Expense(id=1, description="Groceries", amount=45.20, category="Food"),
    Expense(id=2, description="Metro card", amount=10.00, category="Transport"),
]

@app.post("/expenses", response_model=Expense, status_code=201)
def create_expense(expense: Expense):
    expenses.append(expense)
    return expense

@app.put("/expenses/{expense_id}", response_model=Expense)
def update_expense(expense_id: int, updated: Expense):
    for i, e in enumerate(expenses):
        if e.id == expense_id:
            expenses[i] = updated
            return updated
    raise HTTPException(status_code=404, detail="Expense not found")
```

**Task:** Make `amount` required to be greater than zero and test the automatic `422` validation by POSTing a negative amount. Then add a `PATCH /expenses/{id}` endpoint that updates only the fields supplied (use a partial model).

## Exercise 3: DELETE + Query Filtering
**Difficulty:** Basic
**Concepts:** `@app.delete`, `HTTPException`, optional query params, status codes

Add a `DELETE /expenses/{id}` endpoint and enhance the list endpoint with optional filters for `category` and a `min_amount` threshold.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

class Expense(BaseModel):
    id: int
    description: str
    amount: float
    category: str

expenses: List[Expense] = [
    Expense(id=1, description="Groceries", amount=45.20, category="Food"),
    Expense(id=2, description="Metro card", amount=10.00, category="Transport"),
]

@app.delete("/expenses/{expense_id}")
def delete_expense(expense_id: int):
    for i, e in enumerate(expenses):
        if e.id == expense_id:
            deleted = expenses.pop(i)
            return {"message": f"Deleted '{deleted.description}'"}
    raise HTTPException(status_code=404, detail="Expense not found")

@app.get("/expenses", response_model=List[Expense])
def get_expenses(category: Optional[str] = None, min_amount: Optional[float] = None):
    result = expenses
    if category:
        result = [e for e in result if e.category == category]
    if min_amount is not None:
        result = [e for e in result if e.amount >= min_amount]
    return result
```

**Task:** Add a `GET /expenses/total` endpoint that returns the sum of all expense amounts, and document it by adding `summary`/`tags` to each route. Confirm the interactive docs are available at `/docs`.
