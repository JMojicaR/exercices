## Exercise 1: App Setup, Pydantic Model & GET/POST (routing + models)
**Difficulty:** Basic
**Concepts:** `FastAPI()`, `BaseModel`, request-body validation, status codes, list endpoints.

Create a FastAPI app with an `Item` Pydantic model and GET/POST endpoints for a store.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    price: float

items = []

@app.get("/")
def read_root():
    return {"message": "Welcome to the FastAPI store"}

@app.get("/items")
def list_items():
    return items

@app.post("/items", status_code=201)
def create_item(item: Item):
    items.append(item)
    return item
```

**Task:** Add an `id` field to `Item` and return the created item with a generated `id`.

## Exercise 2: Path/Query Params, Validation & HTTPException (request/response + errors)
**Difficulty:** Basic
**Concepts:** Path parameters, query parameters with defaults, `HTTPException`, error responses.

Create an endpoint that looks up an item by name and returns its price, with an optional currency query param.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

items = {"laptop": 999.99, "mouse": 25.50}

@app.get("/items/{item_name}")
def get_item(item_name: str, currency: str = "USD"):
    if item_name not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"name": item_name, "price": items[item_name], "currency": currency}
```

**Task:** Add a `min_price` query parameter that returns a 400 error if the item's price is below it.

## Exercise 3: PUT/DELETE Full CRUD (update + delete)
**Difficulty:** Basic
**Concepts:** PUT/DELETE verbs, Pydantic models for updates, `HTTPException`, in-memory CRUD.

Extend the store with update and delete endpoints for a given item name.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    price: float

items: dict[str, Item] = {}

@app.put("/items/{item_name}")
def update_item(item_name: str, item: Item):
    if item_name not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    items[item_name] = item
    return item

@app.delete("/items/{item_name}")
def delete_item(item_name: str):
    if item_name not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    return items.pop(item_name)
```

**Task:** Add a `POST /items` endpoint so the full CRUD cycle (create → read → update → delete) works end-to-end.
