## Exercise 1: Pydantic model + GET /items + POST /items
**Difficulty:** Basic
**Concepts:** Pydantic models, routing, type hints

Create a FastAPI app with an `Item` model and endpoints to list and create items.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    quantity: int
    price: float

items = [
    {"id": 1, "name": "Laptop", "quantity": 10, "price": 999.99},
]

@app.get("/items")
def get_items():
    return items

@app.post("/items", status_code=201)
def create_item(item: Item):
    new_item = {"id": len(items) + 1, **item.model_dump()}
    items.append(new_item)
    return new_item
```

## Exercise 2: Path/query params + HTTPException 404
**Difficulty:** Basic
**Concepts:** path parameters, query parameters, HTTPException

Fetch a single item by id and support an optional `min_quantity` query filter.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    quantity: int
    price: float

items = [
    {"id": 1, "name": "Laptop", "quantity": 10, "price": 999.99},
    {"id": 2, "name": "Mouse", "quantity": 4, "price": 24.50},
]

@app.get("/items")
def get_items(min_quantity: int = 0):
    return [i for i in items if i["quantity"] >= min_quantity]

@app.get("/items/{item_id}")
def get_item(item_id: int):
    for item in items:
        if item["id"] == item_id:
            return item
    raise HTTPException(status_code=404, detail="item not found")
```

**Task:** Add a 400 error when `min_quantity` is negative.

## Exercise 3: PUT/DELETE full CRUD
**Difficulty:** Basic
**Concepts:** PUT, DELETE, request body, response model

Add update and delete endpoints to complete the CRUD cycle.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    quantity: int
    price: float

items = [
    {"id": 1, "name": "Laptop", "quantity": 10, "price": 999.99},
]

@app.get("/items")
def get_items():
    return items

@app.post("/items", status_code=201)
def create_item(item: Item):
    new_item = {"id": len(items) + 1, **item.model_dump()}
    items.append(new_item)
    return new_item

@app.put("/items/{item_id}")
def update_item(item_id: int, item: Item):
    for existing in items:
        if existing["id"] == item_id:
            existing.update(item.model_dump())
            return existing
    raise HTTPException(status_code=404, detail="item not found")

@app.delete("/items/{item_id}")
def delete_item(item_id: int):
    for i, existing in enumerate(items):
        if existing["id"] == item_id:
            return items.pop(i)
    raise HTTPException(status_code=404, detail="item not found")
```

**Task:** Add response models (`response_model=Item`) so the API schema is self-documenting in `/docs`.
