## Exercise 1: Pydantic Model + GET/POST
**Difficulty:** Basic
**Concepts:** `FastAPI()` app, Pydantic `BaseModel`, `@app.get`/`@app.post`, response models.

Create a `Book` model and endpoints to list all books and create a new book.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Book(BaseModel):
    id: int
    title: str
    author: str
    pages: int

books = [
    Book(id=1, title="1984", author="George Orwell", pages=328),
    Book(id=2, title="Dune", author="Frank Herbert", pages=412),
]

@app.get("/books")
def list_books():
    return books

@app.post("/books", status_code=201)
def create_book(book: Book):
    books.append(book)
    return book
```

## Exercise 2: Path & Query Params + HTTPException
**Difficulty:** Basic
**Concepts:** Path parameters, query parameters, `HTTPException`, status codes.

Add `GET /books/{book_id}` and a `GET /books/` filter by author, raising a 404 when not found.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Book(BaseModel):
    id: int
    title: str
    author: str
    pages: int

books = [
    Book(id=1, title="1984", author="George Orwell", pages=328),
    Book(id=2, title="Dune", author="Frank Herbert", pages=412),
]

@app.get("/books/{book_id}")
def get_book(book_id: int):
    for book in books:
        if book.id == book_id:
            return book
    raise HTTPException(status_code=404, detail="Book not found")

@app.get("/books")
def list_books(author: str | None = None):
    if author:
        return [b for b in books if b.author.lower() == author.lower()]
    return books
```

## Exercise 3: PUT/DELETE Full CRUD
**Difficulty:** Basic
**Concepts:** `PUT`/`DELETE` methods, updating models, removing items, `HTTPException`.

Add update and delete endpoints to complete the CRUD operations.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Book(BaseModel):
    id: int
    title: str
    author: str
    pages: int

books = [
    Book(id=1, title="1984", author="George Orwell", pages=328),
    Book(id=2, title="Dune", author="Frank Herbert", pages=412),
]

@app.put("/books/{book_id}")
def update_book(book_id: int, updated: Book):
    for i, book in enumerate(books):
        if book.id == book_id:
            books[i] = updated
            return updated
    raise HTTPException(status_code=404, detail="Book not found")

@app.delete("/books/{book_id}")
def delete_book(book_id: int):
    for i, book in enumerate(books):
        if book.id == book_id:
            removed = books.pop(i)
            return {"deleted": removed}
    raise HTTPException(status_code=404, detail="Book not found")
```

**Task:** Add a `GET /books/{book_id}/summary` endpoint returning just the title and author.
