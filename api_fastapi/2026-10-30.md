## Exercise 1: Pydantic Model + GET Endpoints
**Difficulty:** Basic
**Concepts:** `FastAPI`, `BaseModel`, type hints, path parameters, query parameters

Define a `WeatherRecord` model and two GET endpoints: list all records and fetch one by `id`, with an optional query filter.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class WeatherRecord(BaseModel):
    id: int
    city: str
    temperature_c: float
    condition: str

records = [
    WeatherRecord(id=1, city="Mexico City", temperature_c=18.5, condition="Sunny"),
    WeatherRecord(id=2, city="Guadalajara", temperature_c=22.0, condition="Cloudy"),
]

@app.get("/weather")
def list_weather():
    return records

@app.get("/weather/{record_id}")
def get_weather(record_id: int):
    for record in records:
        if record.id == record_id:
            return record
    raise HTTPException(status_code=404, detail="Record not found")

@app.get("/weather/")
def filter_weather(city: str | None = None):
    if city is None:
        return records
    return [r for r in records if r.city.lower() == city.lower()]
```

**Task:** Run with `uvicorn main:app --reload` and test `/weather`, `/weather/1`, and `/weather/?city=Mexico City`.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** `status_code=201`, request body validation, updating models, `HTTPException`

Add a `POST /weather` endpoint to create a record and a `PUT /weather/{id}` endpoint to replace an existing one.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException, status
from pydantic import BaseModel

app = FastAPI()

class WeatherRecord(BaseModel):
    id: int
    city: str
    temperature_c: float
    condition: str

records: list[WeatherRecord] = []

@app.post("/weather", status_code=status.HTTP_201_CREATED)
def create_record(record: WeatherRecord):
    for existing in records:
        if existing.id == record.id:
            raise HTTPException(status_code=400, detail="ID already exists")
    records.append(record)
    return record

@app.put("/weather/{record_id}")
def update_record(record_id: int, updated: WeatherRecord):
    for i, record in enumerate(records):
        if record.id == record_id:
            records[i] = updated
            return records[i]
    raise HTTPException(status_code=404, detail="Record not found")
```

**Task:** Make `temperature_c` reject values below `-90` or above `60` using Pydantic field constraints (`Field(ge=-90, le=60)`).

## Exercise 3: DELETE + Error Handling
**Difficulty:** Basic
**Concepts:** DELETE endpoint, `HTTPException`, list removal, query filters, response models

Add a `DELETE /weather/{id}` endpoint and return clean JSON error bodies for missing records.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException, status
from pydantic import BaseModel

app = FastAPI()

class WeatherRecord(BaseModel):
    id: int
    city: str
    temperature_c: float
    condition: str

records = [
    WeatherRecord(id=1, city="Mexico City", temperature_c=18.5, condition="Sunny"),
    WeatherRecord(id=2, city="Guadalajara", temperature_c=22.0, condition="Cloudy"),
]

@app.delete("/weather/{record_id}", status_code=status.HTTP_204_NO_CONTENT)
def delete_record(record_id: int):
    for i, record in enumerate(records):
        if record.id == record_id:
            del records[i]
            return
    raise HTTPException(status_code=404, detail="Record not found")

@app.get("/weather/hottest")
def hottest_record():
    if not records:
        raise HTTPException(status_code=404, detail="No records available")
    return max(records, key=lambda r: r.temperature_c)
```

**Task:** Use the interactive docs at `/docs` to test DELETE, and add a query parameter `?min_temp=` to filter records above a temperature threshold.
