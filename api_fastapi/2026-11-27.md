## Exercise 1: Basic GET Endpoints
**Difficulty:** Basic
**Concepts:** `FastAPI` app, decorators, path parameters, return type hints

**Starter code:**
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Flights API is running"}

@app.get("/flights/{flight_id}")
def get_flight(flight_id: int):
    return {"flight_id": flight_id}
```

**Task:** Add a `GET /health` endpoint returning `{"status": "ok"}`, and a `GET /flights` endpoint returning a static list of two flights. FastAPI automatically returns JSON and generates interactive docs at `/docs`.

## Exercise 2: Full CRUD with a Pydantic Model
**Difficulty:** Basic
**Concepts:** `BaseModel`, type validation, GET/POST/PUT/DELETE, in-memory store

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Flight(BaseModel):
    airline: str
    origin: str
    destination: str
    price: float

flights = {
    1: {"id": 1, "airline": "AeroMex", "origin": "MEX", "destination": "CUN", "price": 1200.0},
}

@app.get("/flights")
def list_flights():
    return list(flights.values())

@app.get("/flights/{flight_id}")
def get_flight(flight_id: int):
    return flights[flight_id]

@app.post("/flights", status_code=201)
def create_flight(flight: Flight):
    new_id = max(flights) + 1
    flights[new_id] = {"id": new_id, **flight.model_dump()}
    return flights[new_id]
```

**Task:** Add `PUT /flights/{flight_id}` (accept a `Flight` body and replace the stored fields) and `DELETE /flights/{flight_id}` (return the deleted flight). Note FastAPI already auto-validates the request body and returns `422` for malformed input.

## Exercise 3: Error Handling with HTTPException
**Difficulty:** Basic
**Concepts:** `HTTPException`, `status` codes, query parameters, response models

**Starter code:**
```python
from fastapi import FastAPI, HTTPException

@app.get("/flights/{flight_id}")
def get_flight(flight_id: int):
    if flight_id not in flights:
        raise HTTPException(status_code=404, detail="Flight not found")
    return flights[flight_id]

@app.delete("/flights/{flight_id}", status_code=204)
def delete_flight(flight_id: int):
    if flight_id not in flights:
        raise HTTPException(status_code=404, detail="Flight not found")
    del flights[flight_id]
```

**Task:** Add a `GET /flights/search?origin=...&max_price=...` endpoint that filters the in-memory flights by origin and maximum price, and returns an empty list when nothing matches. Make `origin` optional.
