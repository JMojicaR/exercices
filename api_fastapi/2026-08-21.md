## Exercise 1: Hello World + Path & Query Parameters

**Difficulty:** Basic

### Problem
Create a FastAPI app with:
- `GET /` — returns `{"message": "Hello, World!"}`
- `GET /hello/{name}` — greets a user via a path parameter
- `GET /hello?name=...` — optional query-parameter greeting with a default value

### Concepts
- `@app.get` decorators
- Path parameters (`{name}`)
- Query parameters with defaults (`name: str = "World"`)

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
def index():
    return {"message": "Hello, World!"}


@app.get("/hello/{name}")
def hello_path(name: str):
    return {"message": f"Hello, {name}!"}


@app.get("/hello")
def hello_query(name: str = "World"):
    return {"message": f"Hello, {name}!"}
```

**Run & test:**
```bash
uvicorn main:app --reload
curl http://localhost:8000/
curl http://localhost:8000/hello/Alice
curl "http://localhost:8000/hello?name=Bob"
```

## Exercise 2: Items CRUD with Pydantic Models

**Difficulty:** Basic

### Problem
Build an in-memory `items` API using Pydantic models:
- Define `Item` (id, name, price) and `ItemCreate` (name, price) models
- `GET /items` — list all items
- `POST /items` — create an item (auto-assign id), return 201
- `GET /items/{item_id}` — return one item, or 404
- `PUT /items/{item_id}` — update name/price, or 404
- `DELETE /items/{item_id}` — delete an item, or 404

### Concepts
- Pydantic `BaseModel`
- `response_model` and request body typing
- `HTTPException` with `status_code`

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from fastapi import FastAPI, HTTPException, status
from pydantic import BaseModel

app = FastAPI()


class ItemCreate(BaseModel):
    name: str
    price: float


class Item(ItemCreate):
    id: int


items = []
next_id = 1


@app.get("/items", response_model=list[Item])
def list_items():
    return items


@app.post("/items", response_model=Item, status_code=status.HTTP_201_CREATED)
def create_item(item: ItemCreate):
    global next_id
    new_item = Item(id=next_id, name=item.name, price=item.price)
    next_id += 1
    items.append(new_item)
    return new_item


@app.get("/items/{item_id}", response_model=Item)
def get_item(item_id: int):
    for item in items:
        if item.id == item_id:
            return item
    raise HTTPException(status_code=404, detail="Item not found")


@app.put("/items/{item_id}", response_model=Item)
def update_item(item_id: int, updated: ItemCreate):
    for item in items:
        if item.id == item_id:
            item.name = updated.name
            item.price = updated.price
            return item
    raise HTTPException(status_code=404, detail="Item not found")


@app.delete("/items/{item_id}")
def delete_item(item_id: int):
    global items
    for i, item in enumerate(items):
        if item.id == item_id:
            del items[i]
            return {"message": f"Item {item_id} deleted"}
    raise HTTPException(status_code=404, detail="Item not found")
```

**Test with curl:**
```bash
curl -X POST http://localhost:8000/items -H "Content-Type: application/json" -d '{"name":"Laptop","price":999.99}'
curl http://localhost:8000/items
curl -X PUT http://localhost:8000/items/1 -H "Content-Type: application/json" -d '{"name":"Gaming Laptop","price":1299.99}'
curl -X DELETE http://localhost:8000/items/1
```

## Exercise 3: Error Handling with HTTPException & Middleware

**Difficulty:** Basic

### Problem
Add validation, error handling, and middleware to a FastAPI app:
- `GET /divide?a=...&b=...` — divide two numbers; return 400 if `b` is 0 or if params are missing
- Use `HTTPException` for error responses
- Add an `@app.middleware("http")` that logs each request's method and path and records processing time

### Concepts
- `HTTPException` with custom `detail`
- Query-parameter validation
- HTTP middleware (`@app.middleware("http")`)

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
import time
from fastapi import FastAPI, HTTPException, Request

app = FastAPI()


@app.middleware("http")
async def log_requests(request: Request, call_next):
    start = time.time()
    response = await call_next(request)
    duration = time.time() - start
    print(f"{request.method} {request.url.path} -> {response.status_code} ({duration:.4f}s)")
    return response


@app.get("/divide")
def divide(a: float, b: float):
    if b == 0:
        raise HTTPException(status_code=400, detail="Cannot divide by zero")
    return {"a": a, "b": b, "result": a / b}
```

**Test with curl:**
```bash
curl "http://localhost:8000/divide?a=10&b=2"
curl "http://localhost:8000/divide?a=10&b=0"   # 400
```
