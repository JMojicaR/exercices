## Exercise 1: POST /tasks — Create with Pydantic Validation
**Difficulty:** Basic
**Concepts:** Pydantic `BaseModel`, `@app.post`, automatic request validation, `response_model`, 422 errors

Create a `POST /tasks` endpoint that validates the request body using a Pydantic model and enqueues the task.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class TaskIn(BaseModel):
    name: str

class TaskOut(BaseModel):
    id: int
    name: str

tasks = []          # in-memory queue (deque)
next_id = 1

@app.post("/tasks", response_model=TaskOut, status_code=201)
def create_task(task: TaskIn):
    global next_id
    new_task = {"id": next_id, "name": task.name}
    next_id += 1
    tasks.append(new_task)   # enqueue
    return new_task

# FastAPI auto-validates: a missing "name" returns 422.
```

## Exercise 2: GET /tasks and GET /tasks/next — List & Dequeue
**Difficulty:** Basic
**Concepts:** GET endpoints, `response_model=list[...]`, dequeuing (FIFO), `HTTPException` 404

Add a list endpoint and a "next" endpoint that dequeues the oldest task (FIFO).

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    name: str

tasks = [{"id": 1, "name": "compile"}, {"id": 2, "name": "deploy"}]

@app.get("/tasks", response_model=list[Task])
def list_tasks():
    return tasks

@app.get("/tasks/next", response_model=Task)
def dequeue_task():
    if not tasks:
        raise HTTPException(status_code=404, detail="queue is empty")
    return tasks.pop(0)   # FIFO dequeue

# Optional helper to run: `uvicorn main:app --reload`
```

## Exercise 3: PUT and DELETE /tasks/{id} — Update & Remove
**Difficulty:** Basic
**Concepts:** PUT with path parameter + body, DELETE, `HTTPException` 404, basic CRUD

Add update and delete endpoints that operate on a task by id.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class TaskIn(BaseModel):
    name: str

class Task(BaseModel):
    id: int
    name: str

tasks = [{"id": 1, "name": "compile"}]

def find(task_id: int):
    for i, t in enumerate(tasks):
        if t["id"] == task_id:
            return i, t
    raise HTTPException(status_code=404, detail="task not found")

@app.put("/tasks/{task_id}", response_model=Task)
def update_task(task_id: int, task: TaskIn):
    i, _ = find(task_id)
    tasks[i]["name"] = task.name
    return tasks[i]

@app.delete("/tasks/{task_id}")
def delete_task(task_id: int):
    i, removed = find(task_id)
    del tasks[i]
    return {"deleted": removed}
```

**Task:** Add a `DELETE /tasks` endpoint that clears all tasks and returns the number removed.
