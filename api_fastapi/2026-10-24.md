## Exercise 1: Pydantic Model + GET/POST
**Difficulty:** Basic
**Concepts:** app creation, Pydantic models, `@app.get`, `@app.post`, status codes

Create a FastAPI app with a `Todo` model and endpoints to list and create todos.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Todo(BaseModel):
    id: int
    title: str
    done: bool = False

todos = []

@app.get("/todos")
def list_todos():
    return todos

@app.post("/todos", status_code=201)
def create_todo(todo: Todo):
    todos.append(todo)
    return todo
```

**Task:** Add a `GET /health` endpoint that returns `{"status": "ok"}`, and auto-assign IDs with a counter instead of asking the client for one.

## Exercise 2: GET by ID + PUT + 404
**Difficulty:** Basic
**Concepts:** path parameters, `HTTPException`, `response_model`

Add endpoints to fetch a single todo and to update it, returning 404 when missing.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Todo(BaseModel):
    id: int
    title: str
    done: bool = False

todos = []

@app.get("/todos/{todo_id}")
def get_todo(todo_id: int):
    for todo in todos:
        if todo.id == todo_id:
            return todo
    raise HTTPException(status_code=404, detail="Todo not found")

@app.put("/todos/{todo_id}")
def update_todo(todo_id: int, updated: Todo):
    for i, todo in enumerate(todos):
        if todo.id == todo_id:
            todos[i] = updated
            return updated
    raise HTTPException(status_code=404, detail="Todo not found")
```

**Task:** Allow partial updates — update only the fields the client actually sent — using `exclude_unset` on a Pydantic model.

## Exercise 3: DELETE + Query Filtering + Full CRUD
**Difficulty:** Basic
**Concepts:** `@app.delete`, query parameters, filtering

Add a delete endpoint and a query filter for listing only done (or pending) todos.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Todo(BaseModel):
    id: int
    title: str
    done: bool = False

todos = []

@app.delete("/todos/{todo_id}")
def delete_todo(todo_id: int):
    for i, todo in enumerate(todos):
        if todo.id == todo_id:
            deleted = todos.pop(i)
            return {"message": "Todo deleted", "deleted": deleted}
    raise HTTPException(status_code=404, detail="Todo not found")

@app.get("/todos")
def list_todos(done: bool | None = None):
    if done is None:
        return todos
    return [t for t in todos if t.done == done]
```

**Task:** Add a `title` query filter (`/todos?title=...`) using `str | None = None`, and a `PATCH` endpoint that toggles the `done` field.
