## Exercise 1: Hello API with Pydantic Model (GET)
**Difficulty:** Basic
**Concepts:** App creation, decorators, Pydantic models, automatic docs.

Create a FastAPI app with a `GET /` endpoint returning a greeting.

**Starter code:**
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Hello, FastAPI!"}
```

## Exercise 2: Path & Query Parameters + POST Body (GET/POST)
**Difficulty:** Basic
**Concepts:** Path params, query params, request body validation with Pydantic.

Create endpoints that use path params, query params, and a validated POST body.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    price: float
    quantity: int = 1

@app.get("/greet/{name}")
def greet(name: str, title: str = "friend"):
    return {"message": f"Hello, {title} {name}!"}

@app.post("/items")
def create_item(item: Item):
    return {"item": item, "total": item.price * item.quantity}
```

**Task:** Add a `GET /add?a=&b=` endpoint that returns the sum of two query params as floats.

## Exercise 3: Full CRUD with Error Handling (GET/POST/PUT/DELETE)
**Difficulty:** Basic
**Concepts:** All HTTP methods, `HTTPException`, in-memory store, path params.

Build a "books" API with full CRUD and proper error handling.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Book(BaseModel):
    title: str
    author: str

books = {}
next_id = 1

@app.get("/books")
def list_books():
    return list(books.values())

@app.post("/books", status_code=201)
def create_book(book: Book):
    global next_id
    record = {"id": next_id, **book.model_dump()}
    books[next_id] = record
    next_id += 1
    return record

@app.get("/books/{book_id}")
def get_book(book_id: int):
    if book_id not in books:
        raise HTTPException(status_code=404, detail="Book not found")
    return books[book_id]

@app.put("/books/{book_id}")
def update_book(book_id: int, book: Book):
    if book_id not in books:
        raise HTTPException(status_code=404, detail="Book not found")
    books[book_id].update(book.model_dump())
    return books[book_id]

@app.delete("/books/{book_id}")
def delete_book(book_id: int):
    if book_id not in books:
        raise HTTPException(status_code=404, detail="Book not found")
    return books.pop(book_id)
```

**Task:** Add request validation so a `title` shorter than 3 characters is rejected (use Pydantic `min_length`).
