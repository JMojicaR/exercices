## Exercise 1: Pydantic Model + GET Endpoints
**Difficulty:** Basic
**Concepts:** `FastAPI`, `BaseModel`, path/type hints, automatic JSON responses

Define a `Task` Pydantic model and two GET endpoints: one that returns all tasks and one that returns a task by `id` (raising a 404 if missing).

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks = [
    Task(id=1, title="Write report", done=False),
    Task(id=2, title="Buy groceries", done=True),
]

@app.get("/tasks")
def get_tasks():
    return tasks

@app.get("/tasks/{task_id}")
def get_task(task_id: int):
    for task in tasks:
        if task.id == task_id:
            return task
    raise HTTPException(status_code=404, detail="Task not found")
```

**Task:** Add a `GET /tasks?done=true` query filter using an optional `done: bool = None` parameter.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** request body model, `status_code=201`, id generation, `HTTPException`

Add a `POST /tasks` endpoint to create a task and a `PUT /tasks/<id>` endpoint to replace an existing one.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

class TaskIn(BaseModel):
    title: str
    done: bool = False

tasks = [Task(id=1, title="Write report", done=False)]

@app.post("/tasks", status_code=201)
def create_task(task_in: TaskIn):
    new_id = max(t.id for t in tasks) + 1 if tasks else 1
    task = Task(id=new_id, title=task_in.title, done=task_in.done)
    tasks.append(task)
    return task

@app.put("/tasks/{task_id}")
def update_task(task_id: int, task_in: TaskIn):
    for task in tasks:
        if task.id == task_id:
            task.title = task_in.title
            task.done = task_in.done
            return task
    raise HTTPException(status_code=404, detail="Task not found")
```

**Task:** Add validation so `title` must be non-empty (use `min_length=1` in the Pydantic field).

## Exercise 3: DELETE + Query Filter
**Difficulty:** Basic
**Concepts:** DELETE endpoint, list removal, `HTTPException`, optional query parameters

Add a `DELETE /tasks/<id>` endpoint and a `GET /tasks?done=<bool>` status filter.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks = [
    Task(id=1, title="Write report", done=False),
    Task(id=2, title="Buy groceries", done=True),
]

@app.delete("/tasks/{task_id}")
def delete_task(task_id: int):
    for i, task in enumerate(tasks):
        if task.id == task_id:
            return tasks.pop(i)
    raise HTTPException(status_code=404, detail="Task not found")

@app.get("/tasks")
def list_tasks(done: bool = None):
    if done is None:
        return tasks
    return [t for t in tasks if t.done == done]
```

**Task:** Add a `GET /tasks/<id>` that confirms deletion by raising a 404 when re-read after `DELETE`.
