## 1. Hello World GET Endpoint
**Description:** Create a minimal FastAPI app with a `GET /` route returning a JSON greeting and a `GET /hello/{name}` route demonstrating path parameters.
**Difficulty:** Basic
**Concepts:** `FastAPI()`, `@app.get`, path parameters, return dicts (auto-JSON).
**Starter code:**
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Hello, World!"}

@app.get("/hello/{name}")
def hello(name: str):
    return {"message": f"Hello, {name}!"}
```

## 2. CRUD API with Pydantic Models
**Description:** Build a full CRUD API for an "item" resource using Pydantic models for request validation and an in-memory store. Implement GET (list/single), POST, PUT, and DELETE.
**Difficulty:** Basic
**Concepts:** Pydantic `BaseModel`, `Optional` fields, `Query`/`Path` params, `status_code`.
**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import Optional

app = FastAPI()

class Item(BaseModel):
    name: str
    price: float
    description: Optional[str] = None

items = {}
next_id = 1

@app.get("/items")
def list_items():
    return list(items.values())

@app.post("/items", status_code=201)
def create_item(item: Item):
    global next_id
    items[next_id] = {"id": next_id, **item.model_dump()}
    next_id += 1
    return items[next_id - 1]

@app.get("/items/{item_id}")
def get_item(item_id: int):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    return items[item_id]

@app.put("/items/{item_id}")
def update_item(item_id: int, item: Item):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    items[item_id] = {"id": item_id, **item.model_dump()}
    return items[item_id]

@app.delete("/items/{item_id}")
def delete_item(item_id: int):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    del items[item_id]
    return {"result": "deleted"}
```

## 3. Query Parameters, Validation, and Error Handling
**Description:** Add a filtered search endpoint using query parameters with validation, and handle errors with `HTTPException` returning clean JSON error responses.
**Difficulty:** Basic
**Concepts:** Query parameters, `Query` validation (`min_length`, defaults), `HTTPException`, status codes.
**Starter code:**
```python
from fastapi import FastAPI, HTTPException, Query

app = FastAPI()

books = [
    {"id": 1, "title": "Clean Code", "author": "Martin"},
    {"id": 2, "title": "The Pragmatic Programmer", "author": "Hunt"},
]

@app.get("/books")
def search_books(author: str = Query(..., min_length=1)):
    results = [b for b in books if b["author"].lower() == author.lower()]
    if not results:
        raise HTTPException(status_code=404, detail="No books by that author")
    return results
```
