## Exercise 3: In-Memory Products CRUD with HTTPException
- **Difficulty:** Easy
- **Description:** Build a CRUD API for products stored in a dictionary keyed by id. Implement GET (list all), GET by id, POST (create), PUT (update), and DELETE (remove). Raise `HTTPException(status_code=404)` when a product is not found.
- **Concepts:** CRUD, in-memory storage, path parameters, `HTTPException`, status codes
- **Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()
products = {}
next_id = 1

class Product(BaseModel):
    name: str
    price: float

@app.get("/products")
def list_products():
    return list(products.values())

@app.post("/products", status_code=201)
def create_product(product: Product):
    global next_id
    item = {"id": next_id, "name": product.name, "price": product.price}
    products[next_id] = item
    next_id += 1
    return item
```
