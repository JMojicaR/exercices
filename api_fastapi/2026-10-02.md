## Exercise 1: Pydantic Model + GET/POST (routing & validation)
**Difficulty:** Basic
**Concepts:** `FastAPI` app, `BaseModel` (Pydantic), type hints, `@app.get`/`@app.post`, automatic validation.

Create a FastAPI app with a `Task` model, a `GET /tasks` endpoint, and a `POST /tasks` endpoint.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks = [
    Task(id=1, title="Learn FastAPI"),
    Task(id=2, title="Build an API"),
]

@app.get("/tasks")
def list_tasks():
    return tasks

@app.post("/tasks", status_code=201)
def create_task(task: Task):
    tasks.append(task)
    return task
```

## Exercise 2: Path & Query Params + HTTPException
**Difficulty:** Basic
**Concepts:** Path parameters, query parameters, `HTTPException`, status codes.

Add a `GET /tasks/{task_id}` endpoint and a `GET /tasks` filter using a query parameter.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks = [
    Task(id=1, title="Learn FastAPI", done=True),
    Task(id=2, title="Build an API"),
]

@app.get("/tasks")
def list_tasks(done: bool | None = None):
    if done is None:
        return tasks
    return [t for t in tasks if t.done == done]

@app.get("/tasks/{task_id}")
def get_task(task_id: int):
    for t in tasks:
        if t.id == task_id:
            return t
    raise HTTPException(status_code=404, detail="Task not found")
```

## Exercise 3: PUT/DELETE Full CRUD
**Difficulty:** Basic
**Concepts:** `@app.put`, `@app.delete`, request body models, status codes, full CRUD lifecycle.

Complete the CRUD by adding update and delete endpoints.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks = [
    Task(id=1, title="Learn FastAPI", done=True),
    Task(id=2, title="Build an API"),
]

@app.put("/tasks/{task_id}")
def update_task(task_id: int, updated: Task):
    for i, t in enumerate(tasks):
        if t.id == task_id:
            tasks[i] = updated
            return updated
    raise HTTPException(status_code=404, detail="Task not found")

@app.delete("/tasks/{task_id}", status_code=204)
def delete_task(task_id: int):
    for i, t in enumerate(tasks):
        if t.id == task_id:
            tasks.pop(i)
            return
    raise HTTPException(status_code=404, detail="Task not found")
```

**Task:** Use `@app.patch` to allow partial updates (only fields provided are changed), keeping the rest unchanged.
