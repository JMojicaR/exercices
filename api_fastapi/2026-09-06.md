## 1. Greeting Endpoint (Path & Query Params)
- **Description**: Create a FastAPI app with a `GET` endpoint that accepts a name in the path and an optional `greeting` query parameter with a default value.
- **Difficulty**: Beginner
- **Concepts**: `FastAPI()`, path/query parameters, automatic type hints, interactive docs (`/docs`)
- **Example/Starter code**:
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/hello/{name}")
def hello(name: str, greeting: str = "Hello"):
    return {"message": f"{greeting}, {name}!"}
```

## 2. Item CRUD with Pydantic Models
- **Description**: Build a CRUD API for items using a Pydantic model for validation and an in-memory dictionary as the store.
- **Difficulty**: Beginner
- **Concepts**: Pydantic `BaseModel`, request body, path parameters, `status_code`, `HTTPException`
- **Example/Starter code**:
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    price: float

items = {1: {"name": "apple", "price": 0.5}}

@app.get("/items")
def list_items():
    return items

@app.post("/items", status_code=201)
def create_item(item: Item):
    new_id = max(items) + 1
    items[new_id] = item.dict()
    return {"id": new_id, **item.dict()}

@app.put("/items/{item_id}")
def update_item(item_id: int, item: Item):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    items[item_id] = item.dict()
    return {"id": item_id, **item.dict()}

@app.delete("/items/{item_id}")
def delete_item(item_id: int):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    del items[item_id]
    return {"message": "Item deleted"}
```

## 3. Validation & Custom Exception Handling
- **Description**: Add field validation with Pydantic `Field` constraints and a custom `HTTPException` handler that returns consistent JSON errors.
- **Difficulty**: Beginner
- **Concepts**: `Field(min_length/max_length/ge/le)`, `@app.exception_handler`, `JSONResponse`, query validation
- **Example/Starter code**:
```python
from fastapi import FastAPI, HTTPException
from fastapi.responses import JSONResponse
from pydantic import BaseModel, Field

app = FastAPI()

class User(BaseModel):
    name: str = Field(min_length=1, max_length=50)
    age: int = Field(ge=0, le=120)

@app.exception_handler(HTTPException)
async def http_exception_handler(request, exc):
    return JSONResponse(status_code=exc.status_code, content={"error": exc.detail})

@app.post("/users")
def create_user(user: User):
    return {"message": f"User {user.name} created"}

@app.get("/users/{user_id}")
def get_user(user_id: int):
    if user_id <= 0:
        raise HTTPException(status_code=400, detail="Invalid user id")
    return {"id": user_id}
```
