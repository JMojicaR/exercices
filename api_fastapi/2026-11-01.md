## Exercise 1: Pydantic Model + GET Endpoints
**Difficulty:** Basic
**Concepts:** `FastAPI` app, `pydantic.BaseModel`, `@app.get`, path parameters, `HTTPException`

Define a `Student` Pydantic model and two GET endpoints: one returning all students, one returning a single student by `id` (404 if missing).

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Student(BaseModel):
    id: int
    name: str
    grade: float

students = [
    Student(id=1, name="Ana", grade=9.2),
    Student(id=2, name="Luis", grade=8.1),
    Student(id=3, name="María", grade=9.8),
]

@app.get("/students")
def get_students():
    return students

@app.get("/students/{student_id}")
def get_student(student_id: int):
    for s in students:
        if s.id == student_id:
            return s
    raise HTTPException(status_code=404, detail="Student not found")
```

**Task:** Add a `GET /students?min_grade=9.0` query filter returning only students at or above that grade.

## Exercise 2: POST + PUT (Create & Replace)
**Difficulty:** Basic
**Concepts:** `@app.post` with `status_code`, request body (Pydantic), `@app.put`, `HTTPException`

Add a `POST /students` endpoint to create a student and a `PUT /students/{id}` endpoint to replace an existing one.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Student(BaseModel):
    id: int
    name: str
    grade: float

students = [
    Student(id=1, name="Ana", grade=9.2),
    Student(id=2, name="Luis", grade=8.1),
]

@app.post("/students", status_code=201)
def create_student(student: Student):
    if any(s.id == student.id for s in students):
        raise HTTPException(status_code=400, detail="Student id already exists")
    students.append(student)
    return student

@app.put("/students/{student_id}")
def update_student(student_id: int, student: Student):
    for i, s in enumerate(students):
        if s.id == student_id:
            students[i] = student
            return student
    raise HTTPException(status_code=404, detail="Student not found")
```

**Task:** Validate the `grade` field (add `ge=0, le=10` to the model) so FastAPI automatically rejects out-of-range grades with a 422.

## Exercise 3: DELETE + Query Filtering
**Difficulty:** Basic
**Concepts:** `@app.delete`, `del`, query parameters, `HTTPException`, list comprehensions

Add a `DELETE /students/{id}` endpoint and extend the `GET /students` endpoint with an optional grade filter.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Student(BaseModel):
    id: int
    name: str
    grade: float

students = [
    Student(id=1, name="Ana", grade=9.2),
    Student(id=2, name="Luis", grade=8.1),
]

@app.delete("/students/{student_id}")
def delete_student(student_id: int):
    for i, s in enumerate(students):
        if s.id == student_id:
            del students[i]
            return {"message": f"Student {student_id} deleted"}
    raise HTTPException(status_code=404, detail="Student not found")

@app.get("/students")
def get_students(min_grade: float = 0.0):
    return [s for s in students if s.grade >= min_grade]
```

**Task:** Add a `GET /students/{student_id}/status` endpoint that returns `"pass"` when `grade >= 6.0` and `"fail"` otherwise.
