## Exercise 1: Root + Item Lookup (Path & Query Params)

**Difficulty:** Basic

### Problem
Build a FastAPI app with:
1. `GET /` — returns a welcome message.
2. `GET /items/{item_id}?q=<string>` — returns the item id and optional query string.

**Example request:** `GET /items/42?q=search`

**Expected response:** `{"item_id": 42, "q": "search"}`

### Concepts
- `@app.get` decorator
- Path parameters and query parameters
- Automatic type conversion & validation

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"message": "Welcome to the FastAPI exercises"}

@app.get("/items/{item_id}")
def read_item(item_id: int, q: str | None = None):
    return {"item_id": item_id, "q": q}
```

## Exercise 2: Notes CRUD (Pydantic)

**Difficulty:** Basic

### Problem
Build a Notes API backed by an in-memory dictionary. Define a Pydantic `Note` model with `title` and `content`. Implement:
1. `GET /notes` — list all notes.
2. `POST /notes` — create a note (returns `201`).
3. `GET /notes/{note_id}` — fetch one note.
4. `PUT /notes/{note_id}` — update a note.
5. `DELETE /notes/{note_id}` — delete a note.

Return `404` for missing notes.

### Concepts
- Pydantic `BaseModel`
- `status_code=201`
- `HTTPException` with `404`
- `dict` for in-memory storage

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Note(BaseModel):
    title: str
    content: str

notes: dict[int, Note] = {}
next_id = 1

@app.get("/notes")
def list_notes():
    return notes

@app.post("/notes", status_code=201)
def create_note(note: Note):
    global next_id
    notes[next_id] = note
    next_id += 1
    return {"id": next_id - 1, **note.model_dump()}

@app.get("/notes/{note_id}")
def get_note(note_id: int):
    if note_id not in notes:
        raise HTTPException(status_code=404, detail="Note not found")
    return {"id": note_id, **notes[note_id].model_dump()}

@app.put("/notes/{note_id}")
def update_note(note_id: int, note: Note):
    if note_id not in notes:
        raise HTTPException(status_code=404, detail="Note not found")
    notes[note_id] = note
    return {"id": note_id, **note.model_dump()}

@app.delete("/notes/{note_id}")
def delete_note(note_id: int):
    if note_id not in notes:
        raise HTTPException(status_code=404, detail="Note not found")
    del notes[note_id]
    return {"message": "Note deleted"}
```

## Exercise 3: Middleware + Custom Exception Handler

**Difficulty:** Basic

### Problem
Add request-logging middleware that prints the method and path of every request, and a custom exception handler for `404` that returns JSON. Include a `GET /ping` endpoint to exercise it.

**Example request:** `GET /nonexistent`

**Expected response:** `404` → `{"error": "Custom 404: path not found"}`

### Concepts
- `@app.middleware("http")`
- `@app.exception_handler` (e.g. for `StarletteHTTPException`)
- `JSONResponse`

### HTTP Method(s)
`GET` (applies to all)

### Example / Starter Code

```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
from starlette.exceptions import HTTPException as StarletteHTTPException

app = FastAPI()

@app.middleware("http")
async def log_requests(request: Request, call_next):
    print(f"Request: {request.method} {request.url.path}")
    response = await call_next(request)
    return response

@app.exception_handler(StarletteHTTPException)
async def custom_http_handler(request: Request, exc: StarletteHTTPException):
    if exc.status_code == 404:
        return JSONResponse(status_code=404, content={"error": "Custom 404: path not found"})
    return JSONResponse(status_code=exc.status_code, content={"error": str(exc.detail)})

@app.get("/ping")
def ping():
    return {"message": "pong"}
```
