## Exercise 1: Pydantic Model + GET/POST Endpoints
**Difficulty:** Basic
**Concepts:** `FastAPI` app, Pydantic `BaseModel`, `@app.get`, `@app.post`, response model

Create a FastAPI app with a Pydantic model and endpoints to list and create albums.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Album(BaseModel):
    id: int
    title: str
    artist: str
    year: int

albums = [
    Album(id=1, title="Abbey Road", artist="The Beatles", year=1969),
]

@app.get("/albums")
def get_albums():
    return albums

@app.post("/albums", status_code=201)
def create_album(album: Album):
    albums.append(album)
    return album
```

## Exercise 2: Path Params + PUT + HTTPException
**Difficulty:** Basic
**Concepts:** path parameters, `HTTPException`, updating records

Fetch a single album by ID and update an existing album, returning 404 when missing.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Album(BaseModel):
    id: int
    title: str
    artist: str
    year: int

albums = []

@app.get("/albums/{album_id}")
def get_album(album_id: int):
    for album in albums:
        if album.id == album_id:
            return album
    raise HTTPException(status_code=404, detail="Album not found")

@app.put("/albums/{album_id}")
def update_album(album_id: int, updated: Album):
    for i, album in enumerate(albums):
        if album.id == album_id:
            albums[i] = updated
            return updated
    raise HTTPException(status_code=404, detail="Album not found")
```

**Task:** Make `update_album` patch only the fields provided instead of replacing the whole album.

## Exercise 3: DELETE + Query Filtering + Full CRUD
**Difficulty:** Basic
**Concepts:** `@app.delete`, query parameters, filtering, full CRUD

Add a DELETE endpoint and query-parameter filtering to complete the CRUD cycle.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException, Query
from pydantic import BaseModel

app = FastAPI()

class Album(BaseModel):
    id: int
    title: str
    artist: str
    year: int

albums = [
    Album(id=1, title="Abbey Road", artist="The Beatles", year=1969),
    Album(id=2, title="Thriller", artist="Michael Jackson", year=1982),
]

@app.get("/albums")
def get_albums(artist: str | None = Query(None)):
    if artist:
        return [a for a in albums if a.artist.lower() == artist.lower()]
    return albums

@app.delete("/albums/{album_id}")
def delete_album(album_id: int):
    for i, album in enumerate(albums):
        if album.id == album_id:
            albums.pop(i)
            return {"message": "Album deleted"}
    raise HTTPException(status_code=404, detail="Album not found")
```

**Task:** Add a `year` query parameter that filters albums released in or after a given year.
