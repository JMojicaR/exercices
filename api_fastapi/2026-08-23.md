## Exercise 1: Math Utility API (path/query params + Pydantic body)
**Difficulty:** Basic
### Problem
Build a math utility API:
1. `GET /factorial/{n}` — return the factorial of `n` (path parameter).
2. `GET /fibonacci?n=<int>` — return the first `n` Fibonacci numbers (query parameter).
3. `POST /is-prime` — accept a Pydantic body `{"n": <int>}` and return whether it is prime.

### Concepts
- Path parameters (`{n}`)
- Query parameters with type hints
- Pydantic `BaseModel` for request body
- Automatic validation and `response_model`

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

def factorial(n: int) -> int:
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

def fibonacci(n: int) -> list[int]:
    seq, a, b = [], 0, 1
    for _ in range(n):
        seq.append(a)
        a, b = b, a + b
    return seq

def is_prime(n: int) -> bool:
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

@app.get("/factorial/{n}")
def get_factorial(n: int):
    if n < 0:
        return {"error": "n must be non-negative"}
    return {"n": n, "factorial": factorial(n)}

@app.get("/fibonacci")
def get_fibonacci(n: int = 0):
    if n < 0:
        return {"error": "n must be non-negative"}
    return {"n": n, "fibonacci": fibonacci(n)}

class PrimeRequest(BaseModel):
    n: int

@app.post("/is-prime")
def check_prime(body: PrimeRequest):
    return {"n": body.n, "is_prime": is_prime(body.n)}
```
**Test with curl:**
```bash
curl "http://127.0.0.1:8000/factorial/5"
curl "http://127.0.0.1:8000/fibonacci?n=10"
curl -X POST http://127.0.0.1:8000/is-prime \
  -H "Content-Type: application/json" \
  -d '{"n": 17}'
```

## Exercise 2: Todo CRUD API (Pydantic + in-memory)
**Difficulty:** Basic
### Problem
Build an in-memory CRUD API for todos:
- `GET /todos` — list all todos.
- `POST /todos` — create a todo from `{"title", "done"}` (auto-increment `id`).
- `GET /todos/{id}` — return one todo or raise `HTTPException(404)`.
- `PUT /todos/{id}` — update a todo or raise `404`.
- `DELETE /todos/{id}` — remove a todo or raise `404`.

### Concepts
- Pydantic models for request/response
- `HTTPException` with status codes
- `dict` in-memory storage and auto-incrementing id

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import Optional

app = FastAPI()

class Todo(BaseModel):
    id: int
    title: str
    done: bool = False

class TodoCreate(BaseModel):
    title: str
    done: bool = False

class TodoUpdate(BaseModel):
    title: Optional[str] = None
    done: Optional[bool] = None

todos: dict[int, Todo] = {}
next_id = 1

@app.get("/todos", response_model=list[Todo])
def list_todos():
    return list(todos.values())

@app.post("/todos", response_model=Todo, status_code=201)
def create_todo(body: TodoCreate):
    global next_id
    todo = Todo(id=next_id, title=body.title, done=body.done)
    todos[next_id] = todo
    next_id += 1
    return todo

@app.get("/todos/{todo_id}", response_model=Todo)
def get_todo(todo_id: int):
    if todo_id not in todos:
        raise HTTPException(status_code=404, detail="Todo not found")
    return todos[todo_id]

@app.put("/todos/{todo_id}", response_model=Todo)
def update_todo(todo_id: int, body: TodoUpdate):
    if todo_id not in todos:
        raise HTTPException(status_code=404, detail="Todo not found")
    todo = todos[todo_id]
    if body.title is not None:
        todo.title = body.title
    if body.done is not None:
        todo.done = body.done
    return todo

@app.delete("/todos/{todo_id}")
def delete_todo(todo_id: int):
    if todo_id not in todos:
        raise HTTPException(status_code=404, detail="Todo not found")
    del todos[todo_id]
    return {"message": "Todo deleted"}
```
**Test with curl:**
```bash
curl http://127.0.0.1:8000/todos
curl -X POST http://127.0.0.1:8000/todos \
  -H "Content-Type: application/json" \
  -d '{"title": "Learn FastAPI"}'
curl http://127.0.0.1:8000/todos/1
curl -X PUT http://127.0.0.1:8000/todos/1 \
  -H "Content-Type: application/json" \
  -d '{"done": true}'
curl -X DELETE http://127.0.0.1:8000/todos/1
```

## Exercise 3: Validation, HTTPException & Custom Middleware
**Difficulty:** Basic
### Problem
Add validation, error handling, and middleware:
1. Use `@app.middleware("http")` to add a custom header to every response.
2. Add a `GET /divide?a=<int>&b=<int>` endpoint that raises `HTTPException(400)` for division by zero.
3. Add a `POST /items` endpoint that validates a Pydantic body and raises `HTTPException(400)` for an empty name.

### Concepts
- `@app.middleware("http")`
- `HTTPException` for error responses
- Pydantic field validation (`min_length`, etc.)
- `Request` and `call_next`

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code
```python
from fastapi import FastAPI, HTTPException, Request
from pydantic import BaseModel, Field

app = FastAPI()

@app.middleware("http")
async def add_header(request: Request, call_next):
    response = await call_next(request)
    response.headers["X-Powered-By"] = "FastAPI-Exercises"
    return response

@app.get("/divide")
def divide(a: int, b: int):
    if b == 0:
        raise HTTPException(status_code=400, detail="Cannot divide by zero")
    return {"result": a / b}

class Item(BaseModel):
    name: str = Field(..., min_length=1)
    price: float = Field(..., gt=0)

@app.post("/items", status_code=201)
def create_item(item: Item):
    return {"name": item.name, "price": item.price}
```
**Test with curl:**
```bash
curl "http://127.0.0.1:8000/divide?a=10&b=4"
curl "http://127.0.0.1:8000/divide?a=10&b=0"          # 400 error
curl -X POST http://127.0.0.1:8000/items \
  -H "Content-Type: application/json" \
  -d '{"name": "Widget", "price": 9.99}'
curl -X POST http://127.0.0.1:8000/items \
  -H "Content-Type: application/json" \
  -d '{"name": "", "price": -5}'                       # 422 validation error
```
