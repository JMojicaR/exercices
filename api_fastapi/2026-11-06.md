## Exercise 1: Pydantic Model + GET Endpoints
**Difficulty:** Basic
**Concepts:** `FastAPI` app, `BaseModel`, type hints, `@app.get`, path parameters, `HTTPException`

Define an `Employee` Pydantic model and two GET endpoints: one returning all employees and one returning a single employee by `id` (404 if missing).

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Employee(BaseModel):
    id: int
    name: str
    role: str
    salary: float

employees = [
    Employee(id=1, name="Ana García", role="Engineer", salary=45000.0),
    Employee(id=2, name="Luis Pérez", role="Designer", salary=38000.0),
    Employee(id=3, name="María López", role="Manager", salary=60000.0),
]

@app.get("/employees")
def get_employees():
    return employees

@app.get("/employees/{employee_id}")
def get_employee(employee_id: int):
    for emp in employees:
        if emp.id == employee_id:
            return emp
    raise HTTPException(status_code=404, detail="Employee not found")
```

**Task:** Add an optional query parameter `?role=Engineer` that filters the employee list by role.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** request body model, `@app.post`, returning 201, id generation, validation

Add a `POST /employees` endpoint to create an employee and a `PUT /employees/{id}` endpoint to replace one.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Employee(BaseModel):
    id: int
    name: str
    role: str
    salary: float

employees = [
    Employee(id=1, name="Ana García", role="Engineer", salary=45000.0),
    Employee(id=2, name="Luis Pérez", role="Designer", salary=38000.0),
]

@app.post("/employees", status_code=201)
def create_employee(employee: Employee):
    employees.append(employee)
    return employee

@app.put("/employees/{employee_id}")
def update_employee(employee_id: int, updated: Employee):
    for i, emp in enumerate(employees):
        if emp.id == employee_id:
            employees[i] = updated
            return updated
    raise HTTPException(status_code=404, detail="Employee not found")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

**Task:** Validate that `salary` is positive with Pydantic `Field(gt=0)`, and return a `400` automatically when the rule is violated.

## Exercise 3: DELETE + Query Filtering
**Difficulty:** Basic
**Concepts:** `@app.delete`, query parameters, removing items, `HTTPException`

Add a `DELETE /employees/{id}` endpoint and a `GET` endpoint that filters employees by salary threshold.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Employee(BaseModel):
    id: int
    name: str
    role: str
    salary: float

employees = [
    Employee(id=1, name="Ana García", role="Engineer", salary=45000.0),
    Employee(id=2, name="Luis Pérez", role="Designer", salary=38000.0),
    Employee(id=3, name="María López", role="Manager", salary=60000.0),
]

@app.get("/employees/filter")
def filter_by_salary(min_salary: float):
    return [e for e in employees if e.salary >= min_salary]

@app.delete("/employees/{employee_id}")
def delete_employee(employee_id: int):
    for i, emp in enumerate(employees):
        if emp.id == employee_id:
            deleted = employees.pop(i)
            return {"message": f"Deleted {deleted.name}"}
    raise HTTPException(status_code=404, detail="Employee not found")
```

**Task:** Note the route-ordering pitfall — explain why `/employees/filter` must be declared before `/employees/{employee_id}` and what happens if it is not.
