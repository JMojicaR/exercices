## 1. Hello World + Path & Query Parameters
**Description:** Create a FastAPI app with a `GET /` root route and a `GET /items/{item_id}` route combining a path parameter and an optional query parameter.
**Difficulty:** Basic
**Concepts:** `FastAPI()`, path parameters, query parameters with defaults, return types.
**Starter code:**
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"message": "Hello, World!"}

@app.get("/items/{item_id}")
def read_item(item_id: int, q: str | None = None):
    return {"item_id": item_id, "q": q}
```

## 2. Pydantic CRUD API (Users)
**Description:** Build a CRUD API for "users" stored in an in-memory list, using a Pydantic `BaseModel` for the request body and validation. Implement `GET /users`, `POST /users`, `PUT /users/{id}`, and `DELETE /users/{id}`.
**Difficulty:** Basic
**Concepts:** Pydantic `BaseModel`, `List`/`Dict`, request bodies, `status_code`, path params.
**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class User(BaseModel):
    name: str
    email: str

users: dict[int, User] = {}
next_id = 1

@app.get("/users")
def list_users():
    return users

@app.post("/users", status_code=201)
def create_user(user: User):
    global next_id
    users[next_id] = user
    next_id += 1
    return {"id": next_id - 1, **user.model_dump()}

@app.put("/users/{user_id}")
def update_user(user_id: int, user: User):
    if user_id not in users:
        raise HTTPException(status_code=404, detail="User not found")
    users[user_id] = user
    return {"id": user_id, **user.model_dump()}

@app.delete("/users/{user_id}")
def delete_user(user_id: int):
    if user_id not in users:
        raise HTTPException(status_code=404, detail="User not found")
    del users[user_id]
    return {"result": "deleted"}
```

## 3. Validation & HTTPException Error Handling
**Description:** Add field-level validation to a Pydantic model (min length, email format) and demonstrate raising `HTTPException` with proper status codes for invalid requests.
**Difficulty:** Basic
**Concepts:** Pydantic `Field` constraints, automatic 422 validation, `HTTPException`, `status` codes.
**Starter code:**
```python
from fastapi import FastAPI, HTTPException, status
from pydantic import BaseModel, Field, EmailStr

app = FastAPI()

class Product(BaseModel):
    name: str = Field(min_length=2, max_length=50)
    price: float = Field(gt=0)
    contact_email: EmailStr | None = None

products: dict[int, Product] = {}
next_id = 1

@app.post("/products", status_code=status.HTTP_201_CREATED)
def create_product(product: Product):
    global next_id
    products[next_id] = product
    next_id += 1
    return {"id": next_id - 1, **product.model_dump()}

@app.get("/products/{product_id}")
def get_product(product_id: int):
    if product_id not in products:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="Product not found",
        )
    return products[product_id]
```
> Note: `EmailStr` requires `pip install "pydantic[email]"`.
