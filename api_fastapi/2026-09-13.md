## Exercise 3: In-Memory Task CRUD with HTTPException
- **Difficulty:** Easy
- **Description:** Build a CRUD API for tasks stored in a `dict`. Implement GET (list all), GET by id, POST (add), PUT (update), and DELETE (remove). Raise `HTTPException(404)` when a task is not found.
- **Concepts:** CRUD, `HTTPException`, path parameters, Pydantic, in-memory storage
- **Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()
tasks = {}
next_id = 1

class Task(BaseModel):
    title: str
    done: bool = False

@app.get('/tasks')
def list_tasks():
    return list(tasks.values())

@app.post('/tasks', status_code=201)
def create_task(task: Task):
    global next_id
    tasks[next_id] = {"id": next_id, **task.model_dump()}
    next_id += 1
    return tasks[next_id - 1]
```
