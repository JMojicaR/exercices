## Exercise 1: Pydantic Model + GET Endpoints
**Difficulty:** Basic
**Concepts:** `FastAPI` app, `BaseModel`, type hints, `@app.get`, path parameters, `HTTPException`

Define a `Task` Pydantic model and two GET endpoints: one returning all tasks and one returning a single task by `id` (404 if missing).

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks = [
    Task(id=1, title="Estudiar FastAPI", done=False),
    Task(id=2, title="Hacer ejercicio", done=True),
    Task(id=3, title="Leer documentación", done=False),
]

@app.get("/tasks")
def get_tasks():
    return tasks

@app.get("/tasks/{task_id}")
def get_task(task_id: int):
    for task in tasks:
        if task.id == task_id:
            return task
    raise HTTPException(status_code=404, detail="Task not found")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

**Task:** Add an optional query parameter `?done=true` that filters the task list by completion status. Test it in the interactive docs at `http://localhost:8000/docs`.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** request body model, `@app.post` with `status_code=201`, id generation, `Field` validation

Add a `POST /tasks` endpoint to create a task and a `PUT /tasks/{id}` endpoint to replace one, with validation that the title is non-empty.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str = Field(..., min_length=1)
    done: bool = False

tasks = [
    Task(id=1, title="Estudiar FastAPI", done=False),
    Task(id=2, title="Hacer ejercicio", done=True),
]

@app.post("/tasks", status_code=201)
def create_task(task: Task):
    tasks.append(task)
    return task

@app.put("/tasks/{task_id}")
def update_task(task_id: int, updated: Task):
    for i, task in enumerate(tasks):
        if task.id == task_id:
            tasks[i] = updated
            return updated
    raise HTTPException(status_code=404, detail="Task not found")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

**Task:** Post a task with an empty title and observe that FastAPI returns `422` automatically thanks to `Field(min_length=1)`. Then add a `max_length=100` constraint.

## Exercise 3: DELETE + Query Filtering
**Difficulty:** Basic
**Concepts:** `@app.delete`, query parameters, removing items, `HTTPException`

Add a `DELETE /tasks/{id}` endpoint and a `GET /tasks/completed` endpoint that returns only the completed tasks.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Task(BaseModel):
    id: int
    title: str
    done: bool = False

tasks = [
    Task(id=1, title="Estudiar FastAPI", done=False),
    Task(id=2, title="Hacer ejercicio", done=True),
    Task(id=3, title="Leer documentación", done=False),
]

@app.get("/tasks/completed")
def get_completed_tasks():
    return [t for t in tasks if t.done]

@app.delete("/tasks/{task_id}")
def delete_task(task_id: int):
    for i, task in enumerate(tasks):
        if task.id == task_id:
            deleted = tasks.pop(i)
            return {"message": f"Deleted '{deleted.title}'"}
    raise HTTPException(status_code=404, detail="Task not found")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

**Task:** Explain the route-ordering pitfall — why `/tasks/completed` must be declared before `/tasks/{task_id}` and what happens if it is not. Then add a `PATCH /tasks/{id}/toggle` endpoint that flips `done`.
