## Exercise 1: Pydantic Model + GET / POST
**Difficulty:** Basic
**Concepts:** `FastAPI()`, Pydantic `BaseModel`, `@app.get`, `@app.post`, type hints

Create a FastAPI app with a Pydantic model and endpoints to list and create city records.

**Starter code:**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class City(BaseModel):
    name: str
    country: str
    temp_c: float

cities = [
    {"id": 1, "name": "Mexico City", "country": "Mexico", "temp_c": 22.5},
]

@app.get("/cities")
def get_cities():
    return cities

@app.post("/cities", status_code=201)
def create_city(city: City):
    new_city = {"id": len(cities) + 1, **city.model_dump()}
    cities.append(new_city)
    return new_city
```

**Task:** Add a `GET /health` endpoint returning `{"status": "ok"}`, and test the POST route with the interactive docs at `/docs`.

## Exercise 2: Path Params + PUT + HTTPException
**Difficulty:** Basic
**Concepts:** path parameters, `@app.put`, `HTTPException`, updating records

Add endpoints to fetch and update a single city by ID.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class City(BaseModel):
    name: str
    country: str
    temp_c: float

cities = [{"id": 1, "name": "Mexico City", "country": "Mexico", "temp_c": 22.5}]

@app.get("/cities/{city_id}")
def get_city(city_id: int):
    for city in cities:
        if city["id"] == city_id:
            return city
    raise HTTPException(status_code=404, detail="City not found")

@app.put("/cities/{city_id}")
def update_city(city_id: int, updated: City):
    for city in cities:
        if city["id"] == city_id:
            city.update(updated.model_dump())
            return city
    raise HTTPException(status_code=404, detail="City not found")
```

**Task:** Make the `name` field in the update optional, so a partial update (only changing `temp_c`) also works.

## Exercise 3: DELETE + Query Filtering + Full CRUD
**Difficulty:** Basic
**Concepts:** `@app.delete`, query parameters, filtering, CRUD completion

Add a delete endpoint and a query filter (e.g. by country) to complete the CRUD API.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class City(BaseModel):
    name: str
    country: str
    temp_c: float

cities = [{"id": 1, "name": "Mexico City", "country": "Mexico", "temp_c": 22.5}]

@app.get("/cities")
def get_cities(country: str | None = None):
    if country:
        return [c for c in cities if c["country"].lower() == country.lower()]
    return cities

@app.delete("/cities/{city_id}")
def delete_city(city_id: int):
    for i, city in enumerate(cities):
        if city["id"] == city_id:
            cities.pop(i)
            return {"message": "City deleted"}
    raise HTTPException(status_code=404, detail="City not found")
```

**Task:** Add a query filter for `min_temp` that returns only cities with `temp_c` above a threshold, and confirm all four CRUD operations work end-to-end.
