## Exercise 1: Pydantic Model + GET Endpoints
**Difficulty:** Basic
**Concepts:** `FastAPI` app, `BaseModel`, `@app.get`, path parameters, `HTTPException`

Define a Pydantic `Workout` model and create two GET endpoints: list all and get one by id.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Workout(BaseModel):
    id: int
    exercise: str
    sets: int
    reps: int

workouts = [
    Workout(id=1, exercise="Squat", sets=3, reps=10),
    Workout(id=2, exercise="Bench Press", sets=4, reps=8),
]

@app.get("/workouts")
def get_workouts():
    return workouts

@app.get("/workouts/{workout_id}")
def get_workout(workout_id: int):
    for w in workouts:
        if w.id == workout_id:
            return w
    raise HTTPException(status_code=404, detail="Workout not found")

# Run with: uvicorn main:app --reload
```

**Task:** Add a `?exercise=...` query filter to `get_workouts()` using an optional `exercise: str = None` query parameter.

## Exercise 2: POST + PUT with Validation
**Difficulty:** Basic
**Concepts:** `@app.post`, `@app.put`, `Field(gt=...)` validation, status codes, `response_model`

Add POST (create) and PUT (update) endpoints with validation that `sets` and `reps` must be greater than zero.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()

class Workout(BaseModel):
    id: int
    exercise: str
    sets: int = Field(gt=0)
    reps: int = Field(gt=0)

workouts = [
    Workout(id=1, exercise="Squat", sets=3, reps=10),
    Workout(id=2, exercise="Bench Press", sets=4, reps=8),
]

@app.post("/workouts", status_code=201)
def create_workout(workout: Workout):
    if any(w.id == workout.id for w in workouts):
        raise HTTPException(status_code=400, detail="Workout id already exists")
    workouts.append(workout)
    return workout

@app.put("/workouts/{workout_id}")
def update_workout(workout_id: int, updated: Workout):
    for i, w in enumerate(workouts):
        if w.id == workout_id:
            workouts[i] = updated
            return workouts[i]
    raise HTTPException(status_code=404, detail="Workout not found")

# Run with: uvicorn main:app --reload
```

**Task:** Split the model into a `WorkoutCreate` (no `id`) request model and a `Workout` response model, generating the id inside `create_workout`. Test the validation by sending `"sets": 0` and confirming FastAPI returns a `422`.

## Exercise 3: DELETE + Query Filters
**Difficulty:** Basic
**Concepts:** `@app.delete`, `HTTPException`, query parameters, filtering lists

Add a DELETE endpoint and a filtered list endpoint that filters by `exercise` and `min_sets`.

**Starter code:**
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Workout(BaseModel):
    id: int
    exercise: str
    sets: int
    reps: int

workouts = [
    Workout(id=1, exercise="Squat", sets=3, reps=10),
    Workout(id=2, exercise="Bench Press", sets=4, reps=8),
    Workout(id=3, exercise="Squat", sets=5, reps=5),
]

@app.delete("/workouts/{workout_id}")
def delete_workout(workout_id: int):
    for i, w in enumerate(workouts):
        if w.id == workout_id:
            return workouts.pop(i)
    raise HTTPException(status_code=404, detail="Workout not found")

@app.get("/workouts")
def get_workouts(exercise: str = None, min_sets: int = None):
    result = workouts
    if exercise:
        result = [w for w in result if w.exercise.lower() == exercise.lower()]
    if min_sets is not None:
        result = [w for w in result if w.sets >= min_sets]
    return result

# Run with: uvicorn main:app --reload
```

**Task:** Add a `max_reps` query parameter to further filter results, and confirm `DELETE /workouts/3` removes the third entry while `DELETE /workouts/99` returns a 404.
