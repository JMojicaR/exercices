## Exercise 1: Root + Recipe Lookup

**Difficulty:** Basic

### Problem
Build a FastAPI app with:
1. `GET /` — returns a welcome message.
2. `GET /recipes/{recipe_id}` — returns a recipe dict by id from an in-memory dict; return `404` if missing.
3. `GET /search?query=<string>` — echoes the search query back.

**Example request:** `GET /recipes/1`

**Expected response:** `{"id": 1, "title": "Pancakes", "ingredients": ["flour", "milk", "egg"]}`

### Concepts
- `@app.get` with path and query parameters
- `HTTPException` for `404`
- `Query` defaults

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from fastapi import FastAPI, HTTPException

app = FastAPI()

recipes = {
    1: {"id": 1, "title": "Pancakes", "ingredients": ["flour", "milk", "egg"]},
    2: {"id": 2, "title": "Omelette", "ingredients": ["egg", "salt", "butter"]},
}

@app.get("/")
def root():
    return {"message": "Welcome to the Recipes API"}

@app.get("/recipes/{recipe_id}")
def get_recipe(recipe_id: int):
    if recipe_id not in recipes:
        raise HTTPException(status_code=404, detail="Recipe not found")
    return recipes[recipe_id]

@app.get("/search")
def search(query: str = ""):
    return {"query": query}
```

## Exercise 2: Recipes CRUD (Pydantic)

**Difficulty:** Basic

### Problem
Build a Recipes API backed by an in-memory dict. Implement `POST` (create), `GET` (list + one), `PUT` (update), and `DELETE` using a Pydantic model for validation.

**Example request:** `POST /recipes` with body `{"title": "Salad", "ingredients": ["lettuce", "tomato"]}`

**Expected response:** `201` → `{"id": 3, "title": "Salad", "ingredients": ["lettuce", "tomato"]}`

### Concepts
- Pydantic `BaseModel`
- `Body` / request model
- `status_code=201` and `HTTPException`

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Recipe(BaseModel):
    title: str
    ingredients: list[str] = []

recipes = {}
next_id = 1

@app.post("/recipes", status_code=201)
def create_recipe(recipe: Recipe):
    global next_id
    recipes[next_id] = {"id": next_id, **recipe.model_dump()}
    next_id += 1
    return recipes[next_id - 1]

@app.get("/recipes")
def list_recipes():
    return list(recipes.values())

@app.get("/recipes/{recipe_id}")
def get_recipe(recipe_id: int):
    if recipe_id not in recipes:
        raise HTTPException(status_code=404, detail="Recipe not found")
    return recipes[recipe_id]

@app.put("/recipes/{recipe_id}")
def update_recipe(recipe_id: int, recipe: Recipe):
    if recipe_id not in recipes:
        raise HTTPException(status_code=404, detail="Recipe not found")
    recipes[recipe_id] = {"id": recipe_id, **recipe.model_dump()}
    return recipes[recipe_id]

@app.delete("/recipes/{recipe_id}")
def delete_recipe(recipe_id: int):
    if recipe_id not in recipes:
        raise HTTPException(status_code=404, detail="Recipe not found")
    del recipes[recipe_id]
    return {"message": "Recipe deleted"}
```

## Exercise 3: Logging Middleware + Custom Exception Handler

**Difficulty:** Basic

### Problem
Add:
1. A middleware that logs each request's method and path.
2. A custom `ValueError` exception handler returning `400`.

**Example request:** `GET /recipes/-1` (an endpoint that raises `ValueError`)

**Expected response:** `400` → `{"error": "Invalid recipe id"}`

### Concepts
- `@app.middleware("http")`
- `@app.exception_handler(ValueError)`
- `JSONResponse`

### HTTP Method(s)
`GET` (with middleware wrapping all requests)

### Example / Starter Code

```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

app = FastAPI()

@app.middleware("http")
async def log_requests(request: Request, call_next):
    print(f"{request.method} {request.url.path}")
    response = await call_next(request)
    return response

@app.exception_handler(ValueError)
async def value_error_handler(request: Request, exc: ValueError):
    return JSONResponse(status_code=400, content={"error": str(exc)})

@app.get("/recipes/{recipe_id}")
def get_recipe(recipe_id: int):
    if recipe_id < 0:
        raise ValueError("Invalid recipe id")
    return {"id": recipe_id, "title": "Demo"}
```
