## Exercise 1: Hello World & First JSON Endpoints

**Difficulty:** Basic

### Problem
Create a minimal Flask application with:
- `GET /` — returns a plain-text welcome message
- `GET /api/health` — returns a JSON status object `{"status": "ok", "service": "flask-api"}`
- `POST /api/echo` — accepts a JSON body and echoes it back with a generated `id`

### Concepts
- `Flask(__name__)` application factory
- `@app.route()` with the `methods` parameter
- Returning plain text vs. `jsonify()`
- `request.get_json()` and default values

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)
next_id = 1


@app.route('/')
def home():
    return "Welcome to the Flask API!"


@app.route('/api/health', methods=['GET'])
def health():
    return jsonify({"status": "ok", "service": "flask-api"})


@app.route('/api/echo', methods=['POST'])
def echo():
    global next_id
    data = request.get_json() or {}
    response = {"id": next_id, "echo": data}
    next_id += 1
    return jsonify(response), 201


if __name__ == '__main__':
    app.run(debug=True)
```

**Test with curl:**
```bash
curl http://localhost:5000/
curl http://localhost:5000/api/health
curl -X POST http://localhost:5000/api/echo \
  -H "Content-Type: application/json" \
  -d '{"message":"hi"}'
```

## Exercise 2: User API — Full CRUD with Path Parameters

**Difficulty:** Basic

### Problem
Build a REST API managing `users` with full CRUD and proper status codes:
- `GET /users` — list all users (200)
- `POST /users` — create a user from JSON (`name`, `email`); return 201, or 400 if fields missing
- `GET /users/<int:user_id>` — return one user, or 404
- `PUT /users/<int:user_id>` — update `name` and/or `email`, or 404
- `DELETE /users/<int:user_id>` — delete a user, or 404

### Concepts
- Path parameters with `<int:user_id>`
- Request validation with `400 Bad Request`
- Resource lookup with `404 Not Found`
- In-memory `list` of dictionaries

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

users = []
next_id = 1


def find_user(user_id):
    return next((u for u in users if u["id"] == user_id), None)


@app.route('/users', methods=['GET'])
def list_users():
    return jsonify(users)


@app.route('/users', methods=['POST'])
def create_user():
    global next_id
    data = request.get_json() or {}
    if "name" not in data or "email" not in data:
        return jsonify({"error": "'name' and 'email' are required"}), 400

    user = {"id": next_id, "name": data["name"], "email": data["email"]}
    next_id += 1
    users.append(user)
    return jsonify(user), 201


@app.route('/users/<int:user_id>', methods=['GET'])
def get_user(user_id):
    user = find_user(user_id)
    if user is None:
        return jsonify({"error": "User not found"}), 404
    return jsonify(user)


@app.route('/users/<int:user_id>', methods=['PUT'])
def update_user(user_id):
    user = find_user(user_id)
    if user is None:
        return jsonify({"error": "User not found"}), 404

    data = request.get_json() or {}
    if "name" in data:
        user["name"] = data["name"]
    if "email" in data:
        user["email"] = data["email"]
    return jsonify(user)


@app.route('/users/<int:user_id>', methods=['DELETE'])
def delete_user(user_id):
    user = find_user(user_id)
    if user is None:
        return jsonify({"error": "User not found"}), 404

    users.remove(user)
    return jsonify({"message": f"User {user_id} deleted"})


if __name__ == '__main__':
    app.run(debug=True)
```

**Test with curl:**
```bash
curl -X POST http://localhost:5000/users \
  -H "Content-Type: application/json" \
  -d '{"name":"Ada","email":"ada@example.com"}'
curl http://localhost:5000/users
curl -X PUT http://localhost:5000/users/1 \
  -H "Content-Type: application/json" -d '{"name":"Ada Lovelace"}'
curl -X DELETE http://localhost:5000/users/1
```

## Exercise 3: Middleware & Custom Error Handlers

**Difficulty:** Basic

### Problem
Extend a `notes` API with request middleware and a custom error handler:
- `GET /notes` — list all notes
- `POST /notes` — create a note (requires `title`)
- `@app.before_request` middleware that logs method + path (and rejects requests without the `X-API-Key: secret` header with 401)
- `@app.errorhandler(404)` and `@app.errorhandler(405)` returning consistent JSON error bodies

### Concepts
- `@app.before_request` middleware
- `request.headers.get()` for custom headers
- Early-return of a 401 response from middleware
- `@app.errorhandler()` for global JSON error responses

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

notes = []
next_id = 1
API_KEY = "secret"


@app.before_request
def check_api_key():
    print(f"[LOG] {request.method} {request.path}")
    if request.headers.get("X-API-Key") != API_KEY:
        return jsonify({"error": "Unauthorized — missing or invalid API key"}), 401


@app.route('/notes', methods=['GET'])
def list_notes():
    return jsonify(notes)


@app.route('/notes', methods=['POST'])
def create_note():
    global next_id
    data = request.get_json() or {}
    if "title" not in data:
        return jsonify({"error": "'title' is required"}), 400

    note = {"id": next_id, "title": data["title"], "content": data.get("content", "")}
    next_id += 1
    notes.append(note)
    return jsonify(note), 201


@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404


@app.errorhandler(405)
def method_not_allowed(error):
    return jsonify({"error": "Method not allowed"}), 405


if __name__ == '__main__':
    app.run(debug=True)
```

**Test with curl:**
```bash
curl http://localhost:5000/notes -H "X-API-Key: secret"
curl -X POST http://localhost:5000/notes -H "X-API-Key: secret" \
  -H "Content-Type: application/json" -d '{"title":"Buy milk"}'
curl http://localhost:5000/notes   # 401 without the header
```
