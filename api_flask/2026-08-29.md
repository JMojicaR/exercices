## Exercise 1: Health Check + Echo API

**Difficulty:** Basic

### Problem
Build a Flask API with two endpoints:
1. `GET /health` — returns `{"status": "ok"}`.
2. `GET /echo?msg=<string>` — returns the message echoed back; default to `"Hello"` when `msg` is absent.

**Example request:** `GET /echo?msg=Flask`

**Expected response:** `{"echo": "Flask"}`

### Concepts
- `@app.route` with `methods=['GET']`
- `request.args.get()` for query parameters
- `jsonify`

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/health', methods=['GET'])
def health():
    return jsonify({"status": "ok"})

@app.route('/echo', methods=['GET'])
def echo():
    msg = request.args.get('msg', 'Hello')
    return jsonify({"echo": msg})

if __name__ == '__main__':
    app.run(debug=True)
```

## Exercise 2: Movies CRUD (in-memory)

**Difficulty:** Basic

### Problem
Build a Movies API backed by an in-memory list. Implement:
1. `GET /movies` — list all movies.
2. `POST /movies` — create a movie from JSON `{"title": ..., "year": ...}`.
3. `GET /movies/<id>` — fetch one movie by id.
4. `PUT /movies/<id>` — update a movie.
5. `DELETE /movies/<id>` — delete a movie.

Return `201` on create and `404` for missing movies.

### Concepts
- Route parameters (`<int:movie_id>`)
- `request.get_json()`
- `jsonify` with status codes
- In-memory list with `append` and `remove`

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)
movies = []
next_id = 1

@app.route('/movies', methods=['GET'])
def list_movies():
    return jsonify(movies)

@app.route('/movies', methods=['POST'])
def create_movie():
    global next_id
    data = request.get_json()
    movie = {"id": next_id, "title": data["title"], "year": data.get("year")}
    next_id += 1
    movies.append(movie)
    return jsonify(movie), 201

@app.route('/movies/<int:movie_id>', methods=['GET', 'PUT', 'DELETE'])
def handle_movie(movie_id):
    movie = next((m for m in movies if m["id"] == movie_id), None)
    if movie is None:
        return jsonify({"error": "Movie not found"}), 404
    if request.method == 'GET':
        return jsonify(movie)
    if request.method == 'PUT':
        data = request.get_json()
        movie["title"] = data.get("title", movie["title"])
        movie["year"] = data.get("year", movie["year"])
        return jsonify(movie)
    movies.remove(movie)
    return jsonify({"message": "Movie deleted"})
```

## Exercise 3: Input Validation + JSON Error Handlers

**Difficulty:** Basic

### Problem
Build a `POST /register` endpoint that validates the request body and returns `400` when required fields are missing. Register JSON error handlers for `404` and `405`.

**Example request:** `POST /register` with body `{"username": "alice"}` (missing email)

**Expected response:** `400` → `{"error": "username and email are required"}`

### Concepts
- Validating `request.get_json()`
- `@app.errorhandler(404)` and `@app.errorhandler(405)`
- Returning JSON from error handlers

### HTTP Method(s)
`POST` (and any that hits the handlers)

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/register', methods=['POST'])
def register():
    data = request.get_json()
    if not data or "username" not in data or "email" not in data:
        return jsonify({"error": "username and email are required"}), 400
    return jsonify({"message": f"Welcome, {data['username']}!"}), 201

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

@app.errorhandler(405)
def method_not_allowed(error):
    return jsonify({"error": "Method not allowed"}), 405

if __name__ == '__main__':
    app.run(debug=True)
```
