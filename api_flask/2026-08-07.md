## Exercise 2: Book API — Full CRUD with In-Memory Storage
**Difficulty:** ★★☆☆☆  
**Concepts:** GET/POST/PUT/DELETE, `request.get_json()`, route parameters, HTTP status codes

### Description
Build a simple Book API that manages a list of books in memory. Each book has: `id`, `title`, `author`, and `year`. Implement the following endpoints:

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/books` | Return all books |
| GET | `/api/books/<id>` | Return a single book by ID |
| POST | `/api/books` | Create a new book |
| PUT | `/api/books/<id>` | Update an existing book |
| DELETE | `/api/books/<id>` | Delete a book |

Return appropriate HTTP status codes: 200 (OK), 201 (Created), 404 (Not Found), 400 (Bad Request).

### Starter Code
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)

books = [
    {"id": 1, "title": "1984", "author": "George Orwell", "year": 1949},
    {"id": 2, "title": "Dune", "author": "Frank Herbert", "year": 1965},
]

# Your code here — implement all 5 endpoints

if __name__ == '__main__':
    app.run(debug=True, port=5000)
```

**Test with:**
```bash
curl http://localhost:5000/api/books
curl -X POST http://localhost:5000/api/books -H "Content-Type: application/json" -d '{"title":"Neuromancer","author":"William Gibson","year":1984}'
curl -X PUT http://localhost:5000/api/books/1 -H "Content-Type: application/json" -d '{"title":"Nineteen Eighty-Four","author":"George Orwell","year":1949}'
```

**Concepts:** Request validation, custom error responses, query parameters, filtering

### Description

Implement:
- `GET /api/tasks` — Return all tasks. Support optional query param `?completed=true` to filter.

- `POST /api/tasks` — Create a task with validation (title required, priority must be valid).
- `PUT /api/tasks/<id>` — Update task fields with partial updates.
- `DELETE /api/tasks/<id>` — Delete task.

Add a custom error handler for 404 and for validation errors that returns structured JSON.

```python

app = Flask(__name__)

tasks = []
next_id = 1

VALID_PRIORITIES = {"low", "medium", "high"}

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

    app.run(debug=True, port=5000)
```

**Test with:**
