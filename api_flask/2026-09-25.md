## Exercise 1: Hello API (GET)
**Difficulty:** Basic
**Concepts:** App creation, routing (`@app.route`), `jsonify`, running the server.

Create a Flask app with a `GET /` endpoint that returns a JSON greeting.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route("/", methods=["GET"])
def home():
    return jsonify({"message": "Hello, Flask API!"})

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /health` endpoint that returns `{"status": "ok"}`.

## Exercise 2: Path & Query Parameters (GET)
**Difficulty:** Basic
**Concepts:** Path parameters, query strings, `request.args`.

Create an endpoint that greets a user by name (path param) and optional title (query param).

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

@app.route("/greet/<name>", methods=["GET"])
def greet(name):
    title = request.args.get("title", "friend")
    return jsonify({"message": f"Hello, {title} {name}!"})

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /add?a=&b=` endpoint that returns the sum of two query parameters.

## Exercise 3: In-Memory CRUD with Error Handling
**Difficulty:** Basic
**Concepts:** GET/POST/PUT/DELETE, JSON request body, 404 handling, in-memory store.

Build a simple "tasks" API backed by a Python list, with full CRUD and error handling.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)
tasks = []
next_id = 1

@app.route("/tasks", methods=["GET"])
def list_tasks():
    return jsonify(tasks)

@app.route("/tasks", methods=["POST"])
def create_task():
    global next_id
    data = request.get_json()
    if not data or "title" not in data:
        abort(400, description="Missing 'title'")
    task = {"id": next_id, "title": data["title"], "done": False}
    next_id += 1
    tasks.append(task)
    return jsonify(task), 201

@app.route("/tasks/<int:task_id>", methods=["PUT"])
def update_task(task_id):
    data = request.get_json()
    for task in tasks:
        if task["id"] == task_id:
            task["title"] = data.get("title", task["title"])
            task["done"] = data.get("done", task["done"])
            return jsonify(task)
    abort(404, description="Task not found")

@app.route("/tasks/<int:task_id>", methods=["DELETE"])
def delete_task(task_id):
    for i, task in enumerate(tasks):
        if task["id"] == task_id:
            return jsonify(tasks.pop(i))
    abort(404, description="Task not found")

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /tasks/<int:task_id>` endpoint to fetch a single task (return 404 if missing).
