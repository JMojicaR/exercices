## Exercise 1: App + GET /students + GET /health
**Difficulty:** Basic
**Concepts:** routing, jsonify, Flask app

Create a Flask app that serves a list of students as JSON and a health-check endpoint.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

students = [
    {"id": 1, "name": "Ada Lovelace", "major": "Computer Science"},
    {"id": 2, "name": "Alan Turing", "major": "Mathematics"},
]

@app.route("/health")
def health():
    return jsonify({"status": "ok"})

@app.route("/students")
def get_students():
    return jsonify(students)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a GET /students/count endpoint that returns the number of students as JSON.

## Exercise 2: POST /students + GET /students/<id> + 404 handling
**Difficulty:** Basic
**Concepts:** POST, URL parameters, 404 responses

Let clients add students and fetch one student by id, returning 404 when missing.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

students = [
    {"id": 1, "name": "Ada Lovelace", "major": "Computer Science"},
]

@app.route("/students", methods=["GET", "POST"])
def students_collection():
    if request.method == "POST":
        data = request.get_json()
        student = {"id": len(students) + 1, **data}
        students.append(student)
        return jsonify(student), 201
    return jsonify(students)

@app.route("/students/<int:student_id>")
def get_student(student_id):
    for student in students:
        if student["id"] == student_id:
            return jsonify(student)
    return jsonify({"error": "student not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Reject POST requests whose JSON body lacks a "name" field with a 400 response.

## Exercise 3: PUT/DELETE + @app.errorhandler middleware
**Difficulty:** Basic
**Concepts:** PUT, DELETE, error handler middleware

Add update and delete endpoints plus a global error handler for bad JSON.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

students = [
    {"id": 1, "name": "Ada Lovelace", "major": "Computer Science"},
]

@app.errorhandler(400)
def bad_request(error):
    return jsonify({"error": "bad request"}), 400

@app.route("/students", methods=["GET", "POST"])
def students_collection():
    if request.method == "POST":
        data = request.get_json()
        student = {"id": len(students) + 1, **data}
        students.append(student)
        return jsonify(student), 201
    return jsonify(students)

@app.route("/students/<int:student_id>", methods=["PUT", "DELETE"])
def student_detail(student_id):
    for student in students:
        if student["id"] == student_id:
            if request.method == "DELETE":
                students.remove(student)
                return jsonify({"message": "deleted"}), 200
            data = request.get_json()
            student.update(data)
            return jsonify(student), 200
    return jsonify({"error": "student not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a 404 error handler that returns JSON instead of the default HTML error page.
