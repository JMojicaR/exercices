## Exercise 1: App + GET /books + GET /health
**Difficulty:** Basic
**Concepts:** routing, jsonify, Flask app

Create a Flask app that serves a list of books as JSON plus a health-check endpoint.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

books = [
    {"id": 1, "title": "1984", "author": "George Orwell"},
    {"id": 2, "title": "Dune", "author": "Frank Herbert"},
]

@app.route("/health")
def health():
    return jsonify({"status": "ok"})

@app.route("/books")
def get_books():
    return jsonify(books)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a GET /books/count endpoint that returns the number of books as JSON.

## Exercise 2: POST /books + GET /books/<id> + 404 handling
**Difficulty:** Basic
**Concepts:** POST, URL parameters, 404 responses

Let clients add books and fetch one book by id, returning 404 when missing.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

books = [
    {"id": 1, "title": "1984", "author": "George Orwell"},
]

@app.route("/books", methods=["GET", "POST"])
def books_collection():
    if request.method == "POST":
        data = request.get_json()
        book = {"id": len(books) + 1, **data}
        books.append(book)
        return jsonify(book), 201
    return jsonify(books)

@app.route("/books/<int:book_id>")
def get_book(book_id):
    for book in books:
        if book["id"] == book_id:
            return jsonify(book)
    return jsonify({"error": "book not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Reject POST requests whose JSON body lacks a "title" field with a 400 response.

## Exercise 3: PUT/DELETE + @app.errorhandler middleware
**Difficulty:** Basic
**Concepts:** PUT, DELETE, error handler middleware

Add update and delete endpoints plus a global error handler for bad JSON.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

books = [
    {"id": 1, "title": "1984", "author": "George Orwell"},
]

@app.errorhandler(400)
def bad_request(error):
    return jsonify({"error": "bad request"}), 400

@app.route("/books", methods=["GET", "POST"])
def books_collection():
    if request.method == "POST":
        data = request.get_json()
        book = {"id": len(books) + 1, **data}
        books.append(book)
        return jsonify(book), 201
    return jsonify(books)

@app.route("/books/<int:book_id>", methods=["PUT", "DELETE"])
def book_detail(book_id):
    for book in books:
        if book["id"] == book_id:
            if request.method == "DELETE":
                books.remove(book)
                return jsonify({"message": "deleted"}), 200
            data = request.get_json()
            book.update(data)
            return jsonify(book), 200
    return jsonify({"error": "book not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a 404 error handler that returns JSON instead of the default HTML error page.
