## Exercise 1: Todo List API — GET and POST Endpoints

### Problem

Build a Flask API that manages a todo list using in-memory storage. Create two endpoints:

- `GET /todos` — returns the full list of todos as JSON
- `POST /todos` — accepts a JSON object (`task`, `done`), appends it to the list with an auto-generated `id`, and returns the created todo with status 201

Each todo has the structure: `{"id": int, "task": str, "done": bool}`.

### Concepts

- `Flask(__name__)` application factory
- `@app.route()` with the `methods` parameter
- `jsonify()` for JSON responses
- `request.get_json()` to parse incoming JSON
- In-memory `list` as a temporary store
- Auto-incrementing ID pattern

### HTTP Method(s)

`GET`, `POST`

### Example/Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

todos = []
next_id = 1


@app.route('/todos', methods=['GET'])
def get_todos():
    return jsonify(todos)


@app.route('/todos', methods=['POST'])
def add_todo():
    global next_id
    data = request.get_json()
    if not data or "task" not in data:
        return jsonify({"error": "'task' is required"}), 400

    todo = {"id": next_id, "task": data["task"], "done": data.get("done", False)}
    next_id += 1
    todos.append(todo)
    return jsonify(todo), 201


if __name__ == '__main__':
    app.run(debug=True)
```

**Test with curl:**
```bash
curl http://localhost:5000/todos
curl -X POST http://localhost:5000/todos \
  -H "Content-Type: application/json" \
  -d '{"task":"Learn Flask","done":false}'
```

## Exercise 2: Book API — Full CRUD with Error Handling

### Problem

Build a REST API that performs full CRUD (Create, Read, Update, Delete) on a `books` resource with proper HTTP status codes and error handling:

- `GET /books` — returns all books (200 OK)
- `POST /books` — creates a book from JSON (`title`, `author`); returns it (201 Created), or 400 if fields are missing
- `GET /books/<int:book_id>` — returns one book (200 OK), or 404 if not found
- `PUT /books/<int:book_id>` — updates a book's fields (200 OK), or 404 if not found
- `DELETE /books/<int:book_id>` — deletes a book (200 OK), or 404 if not found

### Concepts

- Full CRUD pattern across all HTTP methods
- Request validation and `400 Bad Request`
- Resource lookup with `404 Not Found`
- `@app.errorhandler()` for global error handling
- In-memory storage with a list of dictionaries

### HTTP Method(s)

`GET`, `POST`, `PUT`, `DELETE`

### Example/Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

books = []
next_id = 1


@app.route('/books', methods=['GET'])
def get_books():
    return jsonify(books)


@app.route('/books', methods=['POST'])
def create_book():
    global next_id
    data = request.get_json()
    if not data or "title" not in data or "author" not in data:
        return jsonify({"error": "Both 'title' and 'author' are required"}), 400

    book = {"id": next_id, "title": data["title"], "author": data["author"]}
    next_id += 1
    books.append(book)
    return jsonify(book), 201


@app.route('/books/<int:book_id>', methods=['GET'])
def get_book(book_id):
    for book in books:
        if book["id"] == book_id:
            return jsonify(book)
    return jsonify({"error": "Book not found"}), 404


@app.route('/books/<int:book_id>', methods=['PUT'])
def update_book(book_id):
    data = request.get_json() or {}
    for book in books:
        if book["id"] == book_id:
            if "title" in data:
                book["title"] = data["title"]
            if "author" in data:
                book["author"] = data["author"]
            return jsonify(book)
    return jsonify({"error": "Book not found"}), 404


@app.route('/books/<int:book_id>', methods=['DELETE'])
def delete_book(book_id):
    for i, book in enumerate(books):
        if book["id"] == book_id:
            books.pop(i)
            return jsonify({"message": f"Book {book_id} deleted"})
    return jsonify({"error": "Book not found"}), 404


@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404


if __name__ == '__main__':
    app.run(debug=True)
```

```bash
  -H "Content-Type: application/json" \
  -d '{"title":"1984","author":"George Orwell"}'
curl http://localhost:5000/books
curl http://localhost:5000/books/1
```

## Exercise 3: Query Parameters and Logging Middleware

### Problem

Extend a products API to support search/filtering via query parameters and add a simple logging middleware:

- `GET /products` — returns all products, optionally filtered by `category` and `max_price` query parameters (e.g. `/products?category=books&max_price=20`)
- `POST /products` — adds a new product
- Add a `@app.before_request` middleware that logs every incoming request's method and path to the console

Products have the structure: `{"id": int, "name": str, "category": str, "price": float}`.

### Concepts

- Reading query parameters with `request.args.get()`
- Filtering lists by multiple criteria
- Type conversion (`float()`)
- `@app.before_request` middleware hooks
- `request.method` and `request.path`

### HTTP Method(s)

`GET`, `POST`

### Example/Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

products = [
    {"id": 1, "name": "Clean Code", "category": "books", "price": 29.99},
    {"id": 2, "name": "Desk Lamp", "category": "home", "price": 15.50},
    {"id": 3, "name": "Atomic Habits", "category": "books", "price": 18.75},
]


@app.before_request
def log_request():
    print(f"[LOG] {request.method} {request.path}")


@app.route('/products', methods=['GET'])
def get_products():
    category = request.args.get('category')
    max_price = request.args.get('max_price')

    result = products
    if category:
        result = [p for p in result if p["category"] == category]
    if max_price:
        result = [p for p in result if p["price"] <= float(max_price)]

    return jsonify(result)


@app.route('/products', methods=['POST'])
def add_product():
    data = request.get_json()
    new_id = max(p["id"] for p in products) + 1
    product = {"id": new_id, **data}
    products.append(product)
    return jsonify(product), 201


if __name__ == '__main__':
    app.run(debug=True)
```

**Test with curl:**
```bash
curl "http://localhost:5000/products?category=books"
curl "http://localhost:5000/products?category=books&max_price=20"
```
