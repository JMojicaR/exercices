## Exercise 1: Health Check + Greeting API

**Difficulty:** Basic

### Problem
Build a Flask API with two endpoints:
1. `GET /health` — returns `{"status": "ok"}`.
2. `GET /hello?name=<string>` — returns a greeting; default to `"World"` when `name` is absent.

**Example request:** `GET /hello?name=Alice`

**Expected response:** `{"message": "Hello, Alice!"}`

### Concepts
- `@app.route` with `methods=['GET']`
- `request.args.get()`
- `jsonify`

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/health', methods=['GET'])
def health():
    return jsonify({"status": "ok"})

@app.route('/hello', methods=['GET'])
def hello():
    name = request.args.get('name', 'World')
    return jsonify({"message": f"Hello, {name}!"})

if __name__ == '__main__':
    app.run(debug=True)
```

## Exercise 2: Employees CRUD (in-memory)

**Difficulty:** Basic

### Problem
Build an Employees API backed by an in-memory list. Implement:
1. `GET /employees` — list all employees.
2. `POST /employees` — create from JSON `{"name": ..., "role": ...}`.
3. `GET /employees/<id>` — fetch one by id.
4. `PUT /employees/<id>` — update an employee.
5. `DELETE /employees/<id>` — delete an employee.

Return `201` on create and `404` for missing employees.

### Concepts
- Route parameters (`<int:employee_id>`)
- `request.get_json()`
- `jsonify` with status codes
- In-memory list with `append` and `remove`

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)
employees = []
next_id = 1

@app.route('/employees', methods=['GET'])
def list_employees():
    return jsonify(employees)

@app.route('/employees', methods=['POST'])
def create_employee():
    global next_id
    data = request.get_json()
    emp = {"id": next_id, "name": data["name"], "role": data.get("role")}
    next_id += 1
    employees.append(emp)
    return jsonify(emp), 201

@app.route('/employees/<int:employee_id>', methods=['GET', 'PUT', 'DELETE'])
def handle_employee(employee_id):
    emp = next((e for e in employees if e["id"] == employee_id), None)
    if emp is None:
        return jsonify({"error": "Employee not found"}), 404
    if request.method == 'GET':
        return jsonify(emp)
    if request.method == 'PUT':
        data = request.get_json()
        emp["name"] = data.get("name", emp["name"])
        emp["role"] = data.get("role", emp["role"])
        return jsonify(emp)
    employees.remove(emp)
    return jsonify({"message": "Employee deleted"})
```

## Exercise 3: Input Validation + JSON Error Handlers

**Difficulty:** Basic

### Problem
Build a `POST /employees` endpoint that validates the request body and returns `400` when `name` is missing or empty. Register JSON error handlers for `404` and `405`.

**Example request:** `POST /employees` with body `{"role": "Engineer"}` (missing name)

**Expected response:** `400` → `{"error": "name is required"}`

### Concepts
- Validating `request.get_json()`
- `@app.errorhandler(404)` and `@app.errorhandler(405)`
- Returning JSON from error handlers

### HTTP Method(s)
`POST` (and any that hits the handlers)

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)
employees = []

@app.route('/employees', methods=['POST'])
def create_employee():
    data = request.get_json()
    if not data or not data.get("name"):
        return jsonify({"error": "name is required"}), 400
    emp = {"id": len(employees) + 1, "name": data["name"], "role": data.get("role")}
    employees.append(emp)
    return jsonify(emp), 201

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

@app.errorhandler(405)
def method_not_allowed(error):
    return jsonify({"error": "Method not allowed"}), 405

if __name__ == '__main__':
    app.run(debug=True)
```
