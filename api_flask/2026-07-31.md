## Exercise 1: Basic GET Endpoint

**Title:** Your First Flask API — Hello World Endpoint

**Description:** Create a simple Flask application with a GET endpoint that returns a JSON response. Add a second endpoint that returns a personalized greeting using a query parameter. Learn basic route definition and `jsonify`.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Flask app initialization
- Route decorators (`@app.route`)
- HTTP GET method
- `jsonify()` for JSON responses
- Query parameters (`request.args`)
- Running the Flask dev server

**Starter Code:**
```python
# Exercise 1: Basic Flask API Endpoints
from flask import Flask, jsonify, request

app = Flask(__name__)

@app.route('/')
def home():
    return jsonify({
        "message": "Welcome to the Flask API!",
        "status": "online"
    })

@app.route('/greet')
def greet():
    name = request.args.get('name', 'Guest')
    return jsonify({
        "greeting": f"Hello, {name}!",
        "method": "GET"
    })

if __name__ == '__main__':
    app.run(debug=True)
```

**Test with:**
```bash
curl http://127.0.0.1:5000/
curl "http://127.0.0.1:5000/greet?name=Alice"
```

## Exercise 2: CRUD API for a Task Manager

**Title:** Task Manager — Full CRUD Operations

**Description:** Build a REST API for managing tasks using an in-memory list. Implement all CRUD operations: Create (POST), Read all (GET), Read one (GET with ID), Update (PUT), and Delete (DELETE). Each task has an `id`, `title`, `description`, and `done` status.

**Difficulty:** ★★★☆☆ (Moderate)

**Concepts Practiced:**
- HTTP methods (GET, POST, PUT, DELETE)
- Route parameters (`<int:id>`)
- Request body parsing (`request.get_json()`)
- HTTP status codes (200, 201, 404)
- In-memory data storage
- JSON request/response handling

**Starter Code:**
```python
# Exercise 2: Task Manager CRUD API
from flask import Flask, jsonify, request, abort

app = Flask(__name__)

tasks = [
    {"id": 1, "title": "Learn Flask", "description": "Study Flask basics", "done": False},
    {"id": 2, "title": "Build API", "description": "Create a REST API", "done": False},
]
next_id = 3

def find_task(task_id):
    return next((t for t in tasks if t["id"] == task_id), None)

@app.route('/tasks', methods=['GET'])
def get_tasks():
    return jsonify({"tasks": tasks, "count": len(tasks)})

@app.route('/tasks/<int:task_id>', methods=['GET'])
def get_task(task_id):
    task = find_task(task_id)
    if task is None:
        return jsonify({"error": "Task not found"}), 404
    return jsonify(task)

@app.route('/tasks', methods=['POST'])
def create_task():
    global next_id
    data = request.get_json()
    if not data or 'title' not in data:
        return jsonify({"error": "Title is required"}), 400

    task = {
        "id": next_id,
        "title": data["title"],
        "description": data.get("description", ""),
        "done": False
    }
    next_id += 1
    tasks.append(task)
    return jsonify(task), 201

@app.route('/tasks/<int:task_id>', methods=['PUT'])
def update_task(task_id):
    task = find_task(task_id)
    if task is None:
        return jsonify({"error": "Task not found"}), 404

    data = request.get_json()
    task["title"] = data.get("title", task["title"])
    task["description"] = data.get("description", task["description"])
    task["done"] = data.get("done", task["done"])
    return jsonify(task)

@app.route('/tasks/<int:task_id>', methods=['DELETE'])
def delete_task(task_id):
    global tasks
    task = find_task(task_id)
    if task is None:
        return jsonify({"error": "Task not found"}), 404

    tasks = [t for t in tasks if t["id"] != task_id]
    return jsonify({"message": f"Task {task_id} deleted"})

if __name__ == '__main__':
    app.run(debug=True)
```

**Test with:**
```bash
curl http://127.0.0.1:5000/tasks
curl -X POST http://127.0.0.1:5000/tasks -H "Content-Type: application/json" -d '{"title":"New Task"}'
curl -X PUT http://127.0.0.1:5000/tasks/1 -H "Content-Type: application/json" -d '{"done":true}'
curl -X DELETE http://127.0.0.1:5000/tasks/1
```

## Exercise 3: Error Handling and Middleware

**Title:** Custom Error Handlers and Request Logging Middleware

**Description:** Extend the Task Manager API with proper error handling and middleware. Add a custom 404 handler, a global error handler for unexpected exceptions, and a `before_request` hook that logs all incoming requests with timestamps.

**Difficulty:** ★★★☆☆ (Moderate)

**Concepts Practiced:**
- `@app.errorhandler` decorator
- Custom error responses
- `@app.before_request` middleware
- Request logging
- `datetime` and timestamps
- `abort()` for controlled error raising

**Starter Code:**
```python
# Exercise 3: Error Handling and Middleware
from flask import Flask, jsonify, request, abort, g
from datetime import datetime

app = Flask(__name__)

# In-memory "database"
items = []
next_id = 1

# --- Middleware ---
@app.before_request
def log_request():
    """Log every incoming request."""
    g.start_time = datetime.now()
    print(f"[{g.start_time}] {request.method} {request.path}")

@app.after_request
def log_response(response):
    """Log response status and duration."""
    duration = (datetime.now() - g.start_time).total_seconds()
    print(f"  → {response.status_code} ({duration:.3f}s)")
    return response

# --- Custom Error Handlers ---
@app.errorhandler(404)
def not_found(error):
    return jsonify({
        "error": "Not Found",
        "message": "The requested resource does not exist.",
        "status_code": 404
    }), 404

@app.errorhandler(400)
def bad_request(error):
    return jsonify({
        "error": "Bad Request",
        "message": str(error.description) if hasattr(error, 'description') else "Invalid request.",
        "status_code": 400
    }), 400

@app.errorhandler(500)
def internal_error(error):
    return jsonify({
        "error": "Internal Server Error",
        "message": "Something went wrong on the server.",
        "status_code": 500
    }), 500

# --- Routes ---
@app.route('/items', methods=['GET'])
def get_items():
    category = request.args.get('category')
    if category:
        filtered = [i for i in items if i.get("category") == category]
        return jsonify({"items": filtered, "count": len(filtered)})
    return jsonify({"items": items, "count": len(items)})

@app.route('/items/<int:item_id>', methods=['GET'])
def get_item(item_id):
    item = next((i for i in items if i["id"] == item_id), None)
    if item is None:
        abort(404, description=f"Item {item_id} not found")
    return jsonify(item)

@app.route('/items', methods=['POST'])
def create_item():
    global next_id
    data = request.get_json()
    if not data or 'name' not in data:
        abort(400, description="Field 'name' is required")

    item = {
        "id": next_id,
        "name": data["name"],
        "category": data.get("category", "general"),
        "created_at": datetime.now().isoformat()
    }
    next_id += 1
    items.append(item)
    return jsonify(item), 201

@app.route('/items/<int:item_id>', methods=['DELETE'])
def delete_item(item_id):
    global items
    item = next((i for i in items if i["id"] == item_id), None)
    if item is None:
        abort(404, description=f"Item {item_id} not found")
    items = [i for i in items if i["id"] != item_id]
    return jsonify({"message": f"Item {item_id} deleted", "remaining": len(items)})

if __name__ == '__main__':
    app.run(debug=True)
```
