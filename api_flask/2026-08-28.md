## Exercise 1: Greeting API (GET with query param)

**Difficulty:** Basic

### Problem
Build a Flask API with a single `GET /greet` endpoint that accepts an optional `?name=<string>` query parameter and returns a JSON greeting. Default to "World" when no name is provided.

**Example request:** `GET /greet?name=Alice`

**Expected response:** `{"message": "Hello, Alice!"}`

### Concepts
- `@app.route` with `methods=['GET']`
- `request.args.get()`
- `jsonify`

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/greet', methods=['GET'])
def greet():
    name = request.args.get('name', 'World')
    return jsonify({"message": f"Hello, {name}!"})

if __name__ == '__main__':
    app.run(debug=True)
```

## Exercise 2: Notes CRUD (in-memory)

**Difficulty:** Basic

### Problem
Build a Notes API backed by an in-memory list. Implement:
1. `GET /notes` — list all notes.
2. `POST /notes` — create a note from JSON `{"title": ..., "body": ...}`.
3. `GET /notes/<id>` — fetch one note by id.
4. `PUT /notes/<id>` — update a note.
5. `DELETE /notes/<id>` — delete a note.

Return appropriate status codes and 404 for missing notes.

### Concepts
- Route parameters (`<int:note_id>`)
- `request.get_json()`
- `jsonify` with status codes
- In-memory list with `append`

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)
notes = []
next_id = 1

@app.route('/notes', methods=['GET'])
def list_notes():
    return jsonify(notes)

@app.route('/notes', methods=['POST'])
def create_note():
    global next_id
    data = request.get_json()
    note = {"id": next_id, "title": data["title"], "body": data["body"]}
    next_id += 1
    notes.append(note)
    return jsonify(note), 201

@app.route('/notes/<int:note_id>', methods=['GET', 'PUT', 'DELETE'])
def handle_note(note_id):
    note = next((n for n in notes if n["id"] == note_id), None)
    if note is None:
        return jsonify({"error": "Note not found"}), 404
    if request.method == 'GET':
        return jsonify(note)
    if request.method == 'PUT':
        data = request.get_json()
        note["title"] = data.get("title", note["title"])
        note["body"] = data.get("body", note["body"])
        return jsonify(note)
    # DELETE
    notes.remove(note)
    return jsonify({"message": "Note deleted"})
```

## Exercise 3: Logging Middleware + JSON Error Handlers

**Difficulty:** Basic

### Problem
Add a `before_request` logging middleware that prints the method and path of every request, and register a 404 error handler that returns JSON instead of HTML. Also handle a 400 `BadRequest` with a JSON response.

### Concepts
- `@app.before_request`
- `@app.errorhandler(404)`
- Returning JSON from error handlers

### HTTP Method(s)
`GET` (any)

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.before_request
def log_request():
    print(f"{request.method} {request.path}")

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

@app.errorhandler(400)
def bad_request(error):
    return jsonify({"error": "Bad request"}), 400

@app.route('/')
def index():
    return jsonify({"message": "API is running"})

if __name__ == '__main__':
    app.run(debug=True)
```
