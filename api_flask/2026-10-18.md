## Exercise 1: App Setup + GET Endpoints
**Difficulty:** Basic
**Concepts:** app creation, routing, `jsonify`, list endpoint, health check

Create a Flask app with a health-check route and a route that returns all authors.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

authors = [
    {"id": 1, "name": "Jane Austen", "country": "UK"},
    {"id": 2, "name": "Gabriel García Márquez", "country": "Colombia"},
]

@app.route("/health", methods=["GET"])
def health():
    return jsonify({"status": "ok"})

@app.route("/authors", methods=["GET"])
def get_authors():
    return jsonify(authors)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /authors/count` endpoint that returns `{"count": len(authors)}`.

## Exercise 2: POST + GET by ID (404 handling)
**Difficulty:** Basic
**Concepts:** POST, request body, `request.get_json()`, path parameters, 404

Add endpoints to create an author and fetch a single author by ID.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
authors = []
next_id = 1

@app.route("/authors", methods=["POST"])
def create_author():
    global next_id
    data = request.get_json()
    author = {"id": next_id, "name": data["name"], "country": data.get("country", "Unknown")}
    next_id += 1
    authors.append(author)
    return jsonify(author), 201

@app.route("/authors/<int:author_id>", methods=["GET"])
def get_author(author_id):
    for author in authors:
        if author["id"] == author_id:
            return jsonify(author)
    return jsonify({"error": "Author not found"}), 404
```

**Task:** Validate that `name` is present in the request body; if missing, return a 400 error.

## Exercise 3: PUT + DELETE + Error Handler
**Difficulty:** Basic
**Concepts:** PUT, DELETE, updating records, `@app.errorhandler`

Add endpoints to update and delete an author, plus a global error handler.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
authors = []

@app.route("/authors/<int:author_id>", methods=["PUT"])
def update_author(author_id):
    data = request.get_json()
    for author in authors:
        if author["id"] == author_id:
            author["name"] = data.get("name", author["name"])
            author["country"] = data.get("country", author["country"])
            return jsonify(author)
    return jsonify({"error": "Author not found"}), 404

@app.route("/authors/<int:author_id>", methods=["DELETE"])
def delete_author(author_id):
    for author in authors:
        if author["id"] == author_id:
            authors.remove(author)
            return jsonify({"message": "Author deleted"})
    return jsonify({"error": "Author not found"}), 404

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404
```

**Task:** Add a `@app.errorhandler(405)` handler that returns a friendly JSON message when an HTTP method is not allowed.
