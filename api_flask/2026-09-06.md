## 1. Greeting Endpoint (Path & Query Params)
- **Description**: Create a Flask app with a `GET` endpoint that accepts a name in the path and an optional `greeting` query parameter, returning a JSON message.
- **Difficulty**: Beginner
- **Concepts**: `@app.route()`, path parameters, `request.args`, `jsonify`, running the dev server
- **Example/Starter code**:
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

@app.route("/hello/<name>")
def hello(name):
    greeting = request.args.get("greeting", "Hello")
    return jsonify({"message": f"{greeting}, {name}!"})

if __name__ == "__main__":
    app.run(debug=True)
```

## 2. Book CRUD API (In-Memory)
- **Description**: Build a REST API for managing books with full CRUD — `GET`, `POST`, `PUT`, and `DELETE` — using an in-memory list.
- **Difficulty**: Beginner
- **Concepts**: HTTP methods, `request.get_json()`, status codes, route parameters, basic CRUD
- **Example/Starter code**:
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
books = [{"id": 1, "title": "1984", "author": "George Orwell"}]

@app.route("/books", methods=["GET"])
def list_books():
    return jsonify(books)

@app.route("/books", methods=["POST"])
def create_book():
    data = request.get_json()
    book = {"id": len(books) + 1, "title": data["title"], "author": data["author"]}
    books.append(book)
    return jsonify(book), 201

@app.route("/books/<int:book_id>", methods=["PUT"])
def update_book(book_id):
    data = request.get_json()
    for book in books:
        if book["id"] == book_id:
            book.update({k: data[k] for k in data if k in book})
            return jsonify(book)
    return jsonify({"error": "Book not found"}), 404

@app.route("/books/<int:book_id>", methods=["DELETE"])
def delete_book(book_id):
    global books
    books = [b for b in books if b["id"] != book_id]
    return jsonify({"message": "Book deleted"}), 200

if __name__ == "__main__":
    app.run(debug=True)
```

## 3. Logging Middleware & Error Handling
- **Description**: Add request-logging middleware (`before_request`) and custom JSON error handlers so the API logs every request and returns consistent errors.
- **Difficulty**: Beginner
- **Concepts**: `@app.before_request`, `@app.errorhandler`, JSON error responses, `request.method`/`request.path`
- **Example/Starter code**:
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

@app.before_request
def log_request():
    print(f"{request.method} {request.path}")

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

@app.errorhandler(405)
def method_not_allowed(error):
    return jsonify({"error": "Method not allowed"}), 405

@app.route("/items")
def items():
    return jsonify([{"id": 1, "name": "sample"}])

if __name__ == "__main__":
    app.run(debug=True)
```
