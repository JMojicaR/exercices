## 1. Hello World API (Basic GET Endpoint)
- **Description**: Create a minimal Flask app exposing a single `GET` endpoint that returns a greeting message.
- **Difficulty**: Beginner
- **Concepts**: Flask app setup, routes, `@app.route()`, returning responses, running the dev server
- **Example/Starter code**:
```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route("/")
def home():
    return jsonify({"message": "Hello, World!"})

if __name__ == "__main__":
    app.run(debug=True)
```

## 2. RESTful CRUD API (In-Memory Items)
- **Description**: Build a REST API for managing a list of items with full CRUD — `GET`, `POST`, `PUT`, and `DELETE` — using an in-memory list as the data store.
- **Difficulty**: Beginner
- **Concepts**: HTTP methods, route parameters, request JSON body (`request.get_json()`), status codes, basic CRUD
- **Example/Starter code**:
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
items = [{"id": 1, "name": "apple"}]

@app.route("/items", methods=["GET"])
def get_items():
    return jsonify(items)

@app.route("/items", methods=["POST"])
def create_item():
    data = request.get_json()
    new_item = {"id": len(items) + 1, "name": data.get("name")}
    items.append(new_item)
    return jsonify(new_item), 201

@app.route("/items/<int:item_id>", methods=["PUT"])
def update_item(item_id):
    data = request.get_json()
    for item in items:
        if item["id"] == item_id:
            item["name"] = data.get("name", item["name"])
            return jsonify(item)
    return jsonify({"error": "Not found"}), 404

@app.route("/items/<int:item_id>", methods=["DELETE"])
def delete_item(item_id):
    global items
    items = [i for i in items if i["id"] != item_id]
    return jsonify({"message": "Deleted"}), 200

if __name__ == "__main__":
    app.run(debug=True)
```

## 3. Error Handling & Validation
- **Description**: Add a custom 404 handler and input validation so the API returns consistent JSON errors for missing routes and invalid payloads.
- **Difficulty**: Beginner
- **Concepts**: Error handlers (`@app.errorhandler`), `abort()`, validation, JSON error responses
- **Example/Starter code**:
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

@app.errorhandler(400)
def bad_request(error):
    return jsonify({"error": "Bad request"}), 400

@app.route("/greet", methods=["POST"])
def greet():
    data = request.get_json(silent=True)
    if not data or "name" not in data:
        abort(400)
    return jsonify({"message": f"Hello, {data['name']}!"})

if __name__ == "__main__":
    app.run(debug=True)
```
