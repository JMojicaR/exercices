# Flask — API Exercises (2026-11-20)
Sources: Flask docs, Real Python, Miguel Grinberg's Flask Tutorial

Theme: **Dictionary-Backed CRUD API** — a products store held in an in-memory Python `dict` keyed by `id`, with GET/POST/PUT/DELETE endpoints, validation, and error handling.

All three exercises build on the same tiny app. Install Flask with `pip install flask` and run with `python app.py`, then test at `http://127.0.0.1:5000`.

## Exercise 1: GET Endpoints (List + By ID)
**Difficulty:** Basic
**Concepts:** `@app.route`, `jsonify`, returning a `dict` as JSON, path variables, 404 handling

Serve a dictionary of products over HTTP: list all, and fetch one by `id`.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

products = {
    1: {"name": "Laptop", "price": 1200.0},
    2: {"name": "Mouse", "price": 25.0},
    3: {"name": "Keyboard", "price": 75.0},
}

@app.route("/products", methods=["GET"])
def list_products():
    return jsonify(products)

@app.route("/products/<int:product_id>", methods=["GET"])
def get_product(product_id):
    product = products.get(product_id)
    if product is None:
        return jsonify({"error": "Product not found"}), 404
    return jsonify(product)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `?name=` query filter to `/products` using `request.args.get("name")` that returns only products whose name matches.

## Exercise 2: POST & PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** `request.get_json`, generating new ids, `POST` vs `PUT`, validation, `201` status

Create new products and update existing ones, validating the request body.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

products = {
    1: {"name": "Laptop", "price": 1200.0},
    2: {"name": "Mouse", "price": 25.0},
}

@app.route("/products", methods=["POST"])
def create_product():
    data = request.get_json()
    if not data or "name" not in data or "price" not in data:
        return jsonify({"error": "name and price are required"}), 400

    new_id = max(products.keys(), default=0) + 1
    products[new_id] = {"name": data["name"], "price": data["price"]}
    return jsonify({"id": new_id, **products[new_id]}), 201

@app.route("/products/<int:product_id>", methods=["PUT"])
def update_product(product_id):
    if product_id not in products:
        return jsonify({"error": "Product not found"}), 404

    data = request.get_json()
    products[product_id].update(data)
    return jsonify(products[product_id])

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a check in `update_product` that rejects non-numeric `price` values with a `400` response.

## Exercise 3: DELETE + Global Error Handler
**Difficulty:** Basic
**Concepts:** `DELETE`, `@app.errorhandler`, centralizing 404s, method responses

Delete a product and add a catch-all error handler for malformed requests.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

products = {
    1: {"name": "Laptop", "price": 1200.0},
    2: {"name": "Mouse", "price": 25.0},
}

@app.route("/products/<int:product_id>", methods=["DELETE"])
def delete_product(product_id):
    removed = products.pop(product_id, None)
    if removed is None:
        return jsonify({"error": "Product not found"}), 404
    return jsonify({"deleted": product_id, "remaining": len(products)})

@app.errorhandler(404)
def not_found(e):
    return jsonify({"error": "Route not found"}), 404

@app.errorhandler(400)
def bad_request(e):
    return jsonify({"error": "Malformed request body"}), 400

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Verify the 404 handler by requesting `/products/999` with DELETE, and confirm the global handler fires for a typo'd route like `/productz`.
