## Exercise 1: Basic App + GET Endpoints
**Difficulty:** Basic
**Concepts:** `Flask` app, `@app.route`, returning JSON with `jsonify`, path parameters

Create a Flask app with an in-memory list of books, plus two GET endpoints: one that returns all books and one that returns a single book by `id` (404 if missing).

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

books = [
    {"id": 1, "title": "1984", "author": "George Orwell"},
    {"id": 2, "title": "Brave New World", "author": "Aldous Huxley"},
    {"id": 3, "title": "Dune", "author": "Frank Herbert"},
]

@app.route("/books", methods=["GET"])
def get_books():
    return jsonify(books)

@app.route("/books/<int:book_id>", methods=["GET"])
def get_book(book_id):
    for book in books:
        if book["id"] == book_id:
            return jsonify(book)
    return jsonify({"error": "Book not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /books?author=Orwell` query filter using `request.args.get("author")`.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** `request.get_json()`, request body parsing, `jsonify`, returning 201, id generation

Add a `POST /books` endpoint to create a new book and a `PUT /books/<id>` endpoint to replace an existing one.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

books = [
    {"id": 1, "title": "1984", "author": "George Orwell"},
    {"id": 2, "title": "Brave New World", "author": "Aldous Huxley"},
]

@app.route("/books", methods=["POST"])
def create_book():
    data = request.get_json()
    new_id = max(b["id"] for b in books) + 1 if books else 1
    book = {"id": new_id, "title": data.get("title"), "author": data.get("author")}
    books.append(book)
    return jsonify(book), 201

@app.route("/books/<int:book_id>", methods=["PUT"])
def update_book(book_id):
    data = request.get_json()
    for book in books:
        if book["id"] == book_id:
            book["title"] = data.get("title", book["title"])
            book["author"] = data.get("author", book["author"])
            return jsonify(book)
    return jsonify({"error": "Book not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Validate that `title` is a non-empty string and return a 400 error if it is missing.

## Exercise 3: DELETE + Error Handling
**Difficulty:** Basic
**Concepts:** DELETE endpoint, removing list items, `@app.errorhandler`, custom error responses

Add a `DELETE /books/<id>` endpoint and a global error handler for 404 and 405 responses.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

books = [
    {"id": 1, "title": "1984", "author": "George Orwell"},
    {"id": 2, "title": "Brave New World", "author": "Aldous Huxley"},
]

@app.route("/books/<int:book_id>", methods=["DELETE"])
def delete_book(book_id):
    for book in books:
        if book["id"] == book_id:
            books.remove(book)
            return jsonify({"message": f"Book {book_id} deleted"})
    return jsonify({"error": "Book not found"}), 404

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Route or resource not found"}), 404

@app.errorhandler(405)
def method_not_allowed(error):
    return jsonify({"error": "Method not allowed for this route"}), 405

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /books/<id>` endpoint and confirm the custom 404 handler fires when the id does not exist (vs. a wrong URL path).
