## Exercise 1: App Setup, Health Check & GET Collection (routing)
**Difficulty:** Basic
**Concepts:** App creation, `@app.route`, `jsonify`, returning JSON lists, running the server.

Create a Flask app with a `GET /health` endpoint and a `GET /books` endpoint that returns a list of books.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

books = [
    {"id": 1, "title": "1984", "author": "George Orwell"},
    {"id": 2, "title": "Dune", "author": "Frank Herbert"},
]

@app.route("/health", methods=["GET"])
def health():
    return jsonify({"status": "ok"})

@app.route("/books", methods=["GET"])
def list_books():
    return jsonify(books)

if __name__ == "__main__":
    app.run(debug=True)
```

## Exercise 2: POST Create + GET by ID with 404 (request/response)
**Difficulty:** Basic
**Concepts:** `request.get_json`, POST bodies, path parameters (`<int:book_id>`), `abort(400/404)`, status codes.

Extend the app with a `POST /books` endpoint that validates and creates a book, plus a `GET /books/<int:book_id>` endpoint.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)
books = []
next_id = 1

@app.route("/books", methods=["POST"])
def create_book():
    global next_id
    data = request.get_json()
    if not data or "title" not in data or "author" not in data:
        abort(400, description="title and author are required")
    book = {"id": next_id, "title": data["title"], "author": data["author"]}
    next_id += 1
    books.append(book)
    return jsonify(book), 201

@app.route("/books/<int:book_id>", methods=["GET"])
def get_book(book_id):
    for book in books:
        if book["id"] == book_id:
            return jsonify(book)
    abort(404, description="Book not found")

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /books?author=<name>` query filter that returns only books by that author.

## Exercise 3: PUT/DELETE + Middleware & Custom Error Handlers
**Difficulty:** Basic
**Concepts:** `before_request` middleware, custom `errorhandler(404/400)`, PUT/DELETE verbs, in-place update.

Add update and delete endpoints, plus request logging and custom JSON error handlers.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)
books = []

@app.before_request
def log_request():
    print(f"{request.method} {request.path}")

@app.errorhandler(404)
def not_found(err):
    return jsonify({"error": "Not found"}), 404

@app.errorhandler(400)
def bad_request(err):
    return jsonify({"error": err.description}), 400

@app.route("/books/<int:book_id>", methods=["PUT"])
def update_book(book_id):
    data = request.get_json()
    for book in books:
        if book["id"] == book_id:
            book["title"] = data.get("title", book["title"])
            book["author"] = data.get("author", book["author"])
            return jsonify(book)
    abort(404)

@app.route("/books/<int:book_id>", methods=["DELETE"])
def delete_book(book_id):
    for i, book in enumerate(books):
        if book["id"] == book_id:
            return jsonify(books.pop(i))
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `before_request` check that rejects requests with a `Content-Type` other than `application/json` for POST/PUT (return 415).
