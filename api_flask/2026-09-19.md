## 1. Hello World GET Endpoint
**Description:** Create a minimal Flask app with a single `GET /` route that returns a JSON greeting, plus a `GET /hello/<name>` route demonstrating a path parameter.
**Difficulty:** Basic
**Concepts:** `Flask(__name__)`, `@app.route`, `jsonify`, path parameters, `app.run(debug=True)`.
**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route("/")
def home():
    return jsonify({"message": "Hello, World!"})

@app.route("/hello/<name>")
def hello(name):
    return jsonify({"message": f"Hello, {name}!"})

if __name__ == "__main__":
    app.run(debug=True)
```

## 2. In-Memory CRUD API (Tasks)
**Description:** Build a full CRUD API for a "task" resource stored in an in-memory list. Implement `GET /tasks`, `POST /tasks`, `PUT /tasks/<id>`, and `DELETE /tasks/<id>`.
**Difficulty:** Basic
**Concepts:** HTTP methods, JSON request body (`request.get_json()`), status codes, list manipulation.
**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
tasks = []
next_id = 1

@app.route("/tasks", methods=["GET"])
def get_tasks():
    return jsonify(tasks)

@app.route("/tasks", methods=["POST"])
def create_task():
    global next_id
    data = request.get_json()
    task = {"id": next_id, "title": data["title"], "done": False}
    next_id += 1
    tasks.append(task)
    return jsonify(task), 201

@app.route("/tasks/<int:task_id>", methods=["PUT"])
def update_task(task_id):
    data = request.get_json()
    for task in tasks:
        if task["id"] == task_id:
            task["title"] = data.get("title", task["title"])
            task["done"] = data.get("done", task["done"])
            return jsonify(task)
    return jsonify({"error": "Not found"}), 404

@app.route("/tasks/<int:task_id>", methods=["DELETE"])
def delete_task(task_id):
    global tasks
    tasks = [t for t in tasks if t["id"] != task_id]
    return jsonify({"result": "deleted"}), 204

if __name__ == "__main__":
    app.run(debug=True)
```

## 3. Request Handling and Error Handling
**Description:** Add a custom 404 error handler and validate POST input, returning proper error responses when the request body is malformed or missing required fields.
**Difficulty:** Basic
**Concepts:** `@app.errorhandler`, JSON validation, `abort()`, HTTP status codes (400/404).
**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)

items = []

@app.errorhandler(404)
def not_found(e):
    return jsonify({"error": "Resource not found"}), 404

@app.route("/items", methods=["POST"])
def add_item():
    data = request.get_json()
    if not data or "name" not in data:
        abort(400, description="Field 'name' is required")
    items.append(data["name"])
    return jsonify({"added": data["name"]}), 201

if __name__ == "__main__":
    app.run(debug=True)
```
