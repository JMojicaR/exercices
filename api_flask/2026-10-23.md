## Exercise 1: App Setup + GET Endpoints
**Difficulty:** Basic
**Concepts:** app creation, routing, `jsonify`, list endpoint, health check

Create a Flask app with a health-check route and a route that returns all cars.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

cars = [
    {"id": 1, "make": "Toyota", "model": "Corolla", "year": 2020},
    {"id": 2, "make": "Honda", "model": "Civic", "year": 2019},
]

@app.route("/health", methods=["GET"])
def health():
    return jsonify({"status": "ok"})

@app.route("/cars", methods=["GET"])
def get_cars():
    return jsonify(cars)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /cars/count` endpoint that returns `{"count": len(cars)}`, and add a `GET /cars/<make>` filter route.

## Exercise 2: POST + GET by ID (404 handling)
**Difficulty:** Basic
**Concepts:** POST, request body, `request.get_json()`, path parameters, 404

Add endpoints to create a car and fetch a single car by ID.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
cars = []
next_id = 1

@app.route("/cars", methods=["POST"])
def create_car():
    global next_id
    data = request.get_json()
    car = {
        "id": next_id,
        "make": data["make"],
        "model": data["model"],
        "year": data.get("year", 2024),
    }
    next_id += 1
    cars.append(car)
    return jsonify(car), 201

@app.route("/cars/<int:car_id>", methods=["GET"])
def get_car(car_id):
    for car in cars:
        if car["id"] == car_id:
            return jsonify(car)
    return jsonify({"error": "Car not found"}), 404
```

**Task:** Validate that `make` and `model` are present in the request body; if missing, return a 400 error with a descriptive message.

## Exercise 3: PUT + DELETE + Error Handler
**Difficulty:** Basic
**Concepts:** PUT, DELETE, updating records, `@app.errorhandler`

Add endpoints to update and delete a car, plus a global error handler.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
cars = []

@app.route("/cars/<int:car_id>", methods=["PUT"])
def update_car(car_id):
    data = request.get_json()
    for car in cars:
        if car["id"] == car_id:
            car["make"] = data.get("make", car["make"])
            car["model"] = data.get("model", car["model"])
            car["year"] = data.get("year", car["year"])
            return jsonify(car)
    return jsonify({"error": "Car not found"}), 404

@app.route("/cars/<int:car_id>", methods=["DELETE"])
def delete_car(car_id):
    for car in cars:
        if car["id"] == car_id:
            cars.remove(car)
            return jsonify({"message": "Car deleted"})
    return jsonify({"error": "Car not found"}), 404

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404
```

**Task:** Add a `@app.errorhandler(405)` handler that returns a friendly JSON message when an HTTP method is not allowed.
