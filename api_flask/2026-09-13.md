## Exercise 3: In-Memory Book CRUD API
- **Difficulty:** Easy
- **Description:** Build a full CRUD API for a list of books stored in memory (a Python list). Implement GET (list all), GET by id, POST (add), PUT (update), and DELETE (remove). Return 404 with an error when a book is not found.
- **Concepts:** CRUD, in-memory storage, path parameters, HTTP methods, status codes
- **Starter code:**
```python
from flask import Flask, request, jsonify

app = Flask(__name__)
books = []
next_id = 1

@app.route('/books', methods=['GET'])
def list_books():
    return jsonify(books)

@app.route('/books', methods=['POST'])
def create_book():
    global next_id
    data = request.get_json()
    book = {"id": next_id, "title": data.get("title"), "author": data.get("author")}
    books.append(book)
    next_id += 1
    return jsonify(book), 201
```
