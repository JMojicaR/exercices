## Exercise 1: Todo API — Full CRUD with Query-Param Filtering

**Difficulty:** Basic

### Problem
Build a REST API managing `todos` with full CRUD and query-parameter filtering:
- `GET /todos` — list all todos, optionally filter with `?done=true` or `?done=false`
- `POST /todos` — create a todo from JSON (`task` required, `done` optional); return 201, or 400 if `task` missing
- `GET /todos/<int:todo_id>` — return one todo, or 404
- `PUT /todos/<int:todo_id>` — update `task` and/or `done`, or 404
- `DELETE /todos/<int:todo_id>` — delete a todo, or 404

### Concepts
- `request.args.get()` for query parameters
- Filtering a list by a boolean field
- Path parameters with `<int:todo_id>`
- Returning proper status codes

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

todos = []
next_id = 1


@app.route('/todos', methods=['GET'])
def list_todos():
    done = request.args.get('done')
    if done is not None:
        wanted = (done.lower() == 'true')
        return jsonify([t for t in todos if t['done'] == wanted])
    return jsonify(todos)


@app.route('/todos', methods=['POST'])
def create_todo():
    global next_id
    data = request.get_json() or {}
    if 'task' not in data:
        return jsonify({'error': "'task' is required"}), 400
    todo = {'id': next_id, 'task': data['task'], 'done': data.get('done', False)}
    next_id += 1
    todos.append(todo)
    return jsonify(todo), 201


@app.route('/todos/<int:todo_id>', methods=['GET'])
def get_todo(todo_id):
    todo = next((t for t in todos if t['id'] == todo_id), None)
    if todo is None:
        return jsonify({'error': 'Todo not found'}), 404
    return jsonify(todo)


@app.route('/todos/<int:todo_id>', methods=['PUT'])
def update_todo(todo_id):
    todo = next((t for t in todos if t['id'] == todo_id), None)
    if todo is None:
        return jsonify({'error': 'Todo not found'}), 404
    data = request.get_json() or {}
    if 'task' in data:
        todo['task'] = data['task']
    if 'done' in data:
        todo['done'] = data['done']
    return jsonify(todo)


@app.route('/todos/<int:todo_id>', methods=['DELETE'])
def delete_todo(todo_id):
    global todos
    todo = next((t for t in todos if t['id'] == todo_id), None)
    if todo is None:
        return jsonify({'error': 'Todo not found'}), 404
    todos = [t for t in todos if t['id'] != todo_id]
    return jsonify({'message': f'Todo {todo_id} deleted'})


if __name__ == '__main__':
    app.run(debug=True)
```

**Test with curl:**
```bash
curl -X POST http://localhost:5000/todos -H "Content-Type: application/json" -d '{"task":"Buy milk"}'
curl http://localhost:5000/todos
curl "http://localhost:5000/todos?done=false"
curl -X PUT http://localhost:5000/todos/1 -H "Content-Type: application/json" -d '{"done":true}'
curl -X DELETE http://localhost:5000/todos/1
```

## Exercise 2: Calculator API — Arithmetic Endpoints with Validation

**Difficulty:** Basic

### Problem
Build a calculator API that performs arithmetic using query parameters:
- `GET /calc/add?a=5&b=3` — returns `{"operation": "add", "a": 5, "b": 3, "result": 8}`
- `GET /calc/subtract`, `GET /calc/multiply`, `GET /calc/divide` — analogous operations
- Validate that `a` and `b` are present and numeric; return 400 otherwise
- For `divide`, return 400 if `b` is 0

### Concepts
- `request.args.get(..., type=float)` with type coercion
- Validating missing/invalid inputs
- Handling division-by-zero
- Returning structured JSON responses

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)


@app.route('/calc/<op>', methods=['GET'])
def calculate(op):
    a = request.args.get('a', type=float)
    b = request.args.get('b', type=float)
    if a is None or b is None:
        return jsonify({'error': "Query params 'a' and 'b' are required numbers"}), 400

    if op == 'add':
        result = a + b
    elif op == 'subtract':
        result = a - b
    elif op == 'multiply':
        result = a * b
    elif op == 'divide':
        if b == 0:
            return jsonify({'error': 'Division by zero'}), 400
        result = a / b
    else:
        return jsonify({'error': f"Unknown operation '{op}'"}), 400

    return jsonify({'operation': op, 'a': a, 'b': b, 'result': result})


if __name__ == '__main__':
    app.run(debug=True)
```

**Test with curl:**
```bash
curl "http://localhost:5000/calc/add?a=5&b=3"
curl "http://localhost:5000/calc/multiply?a=4&b=6"
curl "http://localhost:5000/calc/divide?a=10&b=0"
curl "http://localhost:5000/calc/divide?a=10"      # 400
```

## Exercise 3: Books API — Pagination & Custom Error Handlers

**Difficulty:** Basic

### Problem
Build a `books` API with pagination and custom error handlers:
- `GET /books?page=1&per_page=10` — return a paginated list with `total`, `page`, and `books`
- `POST /books` — create a book (`title` and `author` required); return 201 or 400
- `@app.errorhandler(404)` and `@app.errorhandler(400)` returning consistent JSON error bodies

### Concepts
- `request.args.get(..., type=int)` with defaults
- Slicing a list for pagination (`start`, `end` offsets)
- `@app.errorhandler()` for global JSON errors
- Creating resources with auto-incrementing IDs

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

books = [
    {'id': 1, 'title': '1984', 'author': 'George Orwell'},
    {'id': 2, 'title': 'Dune', 'author': 'Frank Herbert'},
]


@app.route('/books', methods=['GET'])
def list_books():
    page = request.args.get('page', 1, type=int)
    per_page = request.args.get('per_page', 10, type=int)
    start = (page - 1) * per_page
    end = start + per_page
    return jsonify({
        'total': len(books),
        'page': page,
        'books': books[start:end],
    })


@app.route('/books', methods=['POST'])
def create_book():
    data = request.get_json() or {}
    if 'title' not in data or 'author' not in data:
        return jsonify({'error': "'title' and 'author' are required"}), 400
    book = {'id': len(books) + 1, 'title': data['title'], 'author': data['author']}
    books.append(book)
    return jsonify(book), 201


@app.errorhandler(404)
def not_found(error):
    return jsonify({'error': 'Resource not found'}), 404


@app.errorhandler(400)
def bad_request(error):
    return jsonify({'error': 'Bad request'}), 400


if __name__ == '__main__':
    app.run(debug=True)
```

**Test with curl:**
```bash

curl -X POST http://localhost:5000/books -H "Content-Type: application/json" -d '{"title":"Neuromancer","author":"William Gibson"}'
curl http://localhost:5000/unknown   # 404 JSON
```
