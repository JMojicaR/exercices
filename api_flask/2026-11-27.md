## Exercise 1: Basic GET Endpoints
**Difficulty:** Basic
**Concepts:** app creation, `@app.route`, returning JSON, path parameters

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route("/")
def home():
    return jsonify({"message": "Flights API is running"})

@app.route("/flights/<int:flight_id>")
def get_flight(flight_id):
    return jsonify({"flight_id": flight_id})

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /health` endpoint returning `{"status": "ok"}` and a `GET /flights` endpoint returning a static list of two flights (each with `id`, `airline`, `origin`, `destination`, `price`).

## Exercise 2: Full CRUD with an In-Memory List
**Difficulty:** Basic
**Concepts:** `request.get_json()`, GET/POST/PUT/DELETE, in-memory data store, `jsonify`

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

flights = [
    {"id": 1, "airline": "AeroMex", "origin": "MEX", "destination": "CUN", "price": 1200},
]

@app.route("/flights", methods=["GET"])
def list_flights():
    return jsonify(flights)

@app.route("/flights/<int:flight_id>", methods=["GET"])
def get_flight(flight_id):
    flight = next((f for f in flights if f["id"] == flight_id), None)
    return jsonify(flight) if flight else (jsonify({"error": "not found"}), 404)

@app.route("/flights", methods=["POST"])
def create_flight():
    data = request.get_json()
    new_id = max(f["id"] for f in flights) + 1
    data["id"] = new_id
    flights.append(data)
    return jsonify(data), 201
```

**Task:** Complete the API by adding `PUT /flights/<int:flight_id>` (update `airline`, `origin`, `destination`, `price`) and `DELETE /flights/<int:flight_id>`. Return `404` when the id does not exist and `204` on successful delete.

## Exercise 3: Validation and Error Handling
**Difficulty:** Basic
**Concepts:** `@app.errorhandler`, custom error responses, input validation, middleware via `before_request`

**Starter code:**
```python
@app.route("/flights", methods=["POST"])
def create_flight():
    data = request.get_json()
    required = ["airline", "origin", "destination", "price"]
    missing = [field for field in required if field not in data]
    if missing:
        return jsonify({"error": "missing fields", "fields": missing}), 400
    new_id = max(f["id"] for f in flights) + 1
    data["id"] = new_id
    flights.append(data)
    return jsonify(data), 201

@app.errorhandler(404)
def not_found(e):
    return jsonify({"error": "resource not found"}), 404
```

**Task:** Add a `@app.before_request` middleware that logs `f"{request.method} {request.path}"` to the console, and an error handler for `400` that returns `{"error": "bad request"}`. Test that posting a flight without an `airline` returns your custom `400` response.
