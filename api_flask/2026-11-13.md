## Exercise 1: GET Endpoints + 404 Handling
**Difficulty:** Basic
**Concepts:** `Flask` app, `@app.route`, `jsonify`, URL parameters, `abort(404)`

Create two GET endpoints: one returning all playlists, and one returning a single playlist by `id` (404 if missing).

**Starter code:**
```python
from flask import Flask, jsonify, abort

app = Flask(__name__)

playlists = [
    {"id": 1, "name": "Gym", "songs": ["Eye of the Tiger", "Lose Yourself"]},
    {"id": 2, "name": "Study", "songs": ["Clair de Lune", "Weightless"]},
]

@app.route("/playlists", methods=["GET"])
def get_playlists():
    return jsonify(playlists)

@app.route("/playlists/<int:playlist_id>", methods=["GET"])
def get_playlist(playlist_id):
    for p in playlists:
        if p["id"] == playlist_id:
            return jsonify(p)
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Replace `abort(404)` with `jsonify({"error": "Playlist not found"})` plus a `404` status, and add a `?name=...` query filter to `get_playlists()` using `request.args.get("name")`.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** `@app.route` with methods, `request.get_json()`, request-body validation, id generation

Add a `POST /playlists` endpoint to create a playlist and a `PUT /playlists/<id>` endpoint to replace one, both validating the incoming JSON.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)

playlists = [
    {"id": 1, "name": "Gym", "songs": ["Eye of the Tiger", "Lose Yourself"]},
    {"id": 2, "name": "Study", "songs": ["Clair de Lune", "Weightless"]},
]

@app.route("/playlists", methods=["POST"])
def create_playlist():
    data = request.get_json()
    if not data or "name" not in data:
        return jsonify({"error": "name is required"}), 400
    new_playlist = {
        "id": max(p["id"] for p in playlists) + 1,
        "name": data["name"],
        "songs": data.get("songs", []),
    }
    playlists.append(new_playlist)
    return jsonify(new_playlist), 201

@app.route("/playlists/<int:playlist_id>", methods=["PUT"])
def update_playlist(playlist_id):
    data = request.get_json()
    for p in playlists:
        if p["id"] == playlist_id:
            p["name"] = data.get("name", p["name"])
            p["songs"] = data.get("songs", p["songs"])
            return jsonify(p)
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Validate that `songs` is a list of strings, returning `400` if not. Test with `curl -X POST -H "Content-Type: application/json" -d '{"name":"Road Trip","songs":["Highway to Hell"]}' http://localhost:5000/playlists`.

## Exercise 3: DELETE + Custom Error Handler
**Difficulty:** Basic
**Concepts:** `@app.route` with `DELETE`, `@app.errorhandler`, consistent JSON errors

Add a `DELETE /playlists/<id>` endpoint and a custom error handler that turns all `404` responses into a consistent JSON shape.

**Starter code:**
```python
from flask import Flask, jsonify, abort

app = Flask(__name__)

playlists = [
    {"id": 1, "name": "Gym", "songs": ["Eye of the Tiger", "Lose Yourself"]},
    {"id": 2, "name": "Study", "songs": ["Clair de Lune", "Weightless"]},
]

@app.route("/playlists/<int:playlist_id>", methods=["DELETE"])
def delete_playlist(playlist_id):
    for i, p in enumerate(playlists):
        if p["id"] == playlist_id:
            deleted = playlists.pop(i)
            return jsonify({"message": f"Deleted '{deleted['name']}'"})
    abort(404)

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `@app.errorhandler(405)` for wrong-method requests, and verify it fires with `curl -X PATCH http://localhost:5000/playlists/1`. Then add a `GET /playlists/<id>/songs` endpoint that returns just the `songs` list.
