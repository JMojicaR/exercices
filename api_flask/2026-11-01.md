## Exercise 1: Basic App + GET Endpoints
**Difficulty:** Basic
**Concepts:** `Flask` app, `@app.route`, returning JSON with `jsonify`, path parameters

Create a Flask app with an in-memory list of recipes, plus two GET endpoints: one that returns all recipes and one that returns a single recipe by `id` (404 if missing).

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

recipes = [
    {"id": 1, "name": "Pancakes", "time_minutes": 20},
    {"id": 2, "name": "Pasta Carbonara", "time_minutes": 30},
    {"id": 3, "name": "Tacos al Pastor", "time_minutes": 60},
]

@app.route("/recipes", methods=["GET"])
def get_recipes():
    return jsonify(recipes)

@app.route("/recipes/<int:recipe_id>", methods=["GET"])
def get_recipe(recipe_id):
    for recipe in recipes:
        if recipe["id"] == recipe_id:
            return jsonify(recipe)
    return jsonify({"error": "Recipe not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /recipes?max_time=30` query filter using `request.args.get("max_time")`.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** `request.get_json()`, request body parsing, `jsonify`, returning 201, id generation

Add a `POST /recipes` endpoint to create a new recipe and a `PUT /recipes/<id>` endpoint to replace an existing one.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

recipes = [
    {"id": 1, "name": "Pancakes", "time_minutes": 20},
    {"id": 2, "name": "Pasta Carbonara", "time_minutes": 30},
]

@app.route("/recipes", methods=["POST"])
def create_recipe():
    data = request.get_json()
    new_id = max(r["id"] for r in recipes) + 1 if recipes else 1
    recipe = {
        "id": new_id,
        "name": data.get("name"),
        "time_minutes": data.get("time_minutes"),
    }
    recipes.append(recipe)
    return jsonify(recipe), 201

@app.route("/recipes/<int:recipe_id>", methods=["PUT"])
def update_recipe(recipe_id):
    data = request.get_json()
    for recipe in recipes:
        if recipe["id"] == recipe_id:
            recipe["name"] = data.get("name", recipe["name"])
            recipe["time_minutes"] = data.get("time_minutes", recipe["time_minutes"])
            return jsonify(recipe)
    return jsonify({"error": "Recipe not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Validate that `name` is a non-empty string and return a 400 error if it is missing or blank.

## Exercise 3: DELETE + Error Handling
**Difficulty:** Basic
**Concepts:** DELETE endpoint, removing list items, `@app.errorhandler`, custom error responses

Add a `DELETE /recipes/<id>` endpoint and a global error handler for 404 and 405 responses.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

recipes = [
    {"id": 1, "name": "Pancakes", "time_minutes": 20},
    {"id": 2, "name": "Pasta Carbonara", "time_minutes": 30},
]

@app.route("/recipes/<int:recipe_id>", methods=["DELETE"])
def delete_recipe(recipe_id):
    for recipe in recipes:
        if recipe["id"] == recipe_id:
            recipes.remove(recipe)
            return jsonify({"message": f"Recipe {recipe_id} deleted"})
    return jsonify({"error": "Recipe not found"}), 404

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Route or resource not found"}), 404

@app.errorhandler(405)
def method_not_allowed(error):
    return jsonify({"error": "Method not allowed for this route"}), 405

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `DELETE /recipes` bulk endpoint that removes every recipe whose `time_minutes` is above a given value passed as a query parameter.
