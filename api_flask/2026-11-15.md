## Exercise 1: GET Endpoints + 404 Handling
**Difficulty:** Basic
**Concepts:** `Flask` app, `@app.route`, `jsonify`, URL parameters, `abort(404)`

Create two GET endpoints: one returning all cars, and one returning a single car by `id` (404 if missing).

**Starter code:**
```python
from flask import Flask, jsonify, abort

app = Flask(__name__)

cars = [
    {"id": 1, "make": "Toyota", "model": "Corolla", "year": 2021, "price": 23500},
    {"id": 2, "make": "Honda", "model": "Civic", "year": 2022, "price": 25100},
]

@app.route("/cars", methods=["GET"])
def get_cars():
    return jsonify(cars)

@app.route("/cars/<int:car_id>", methods=["GET"])
def get_car(car_id):
    for c in cars:
        if c["id"] == car_id:
            return jsonify(c)
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Replace `abort(404)` with `jsonify({"error": "Car not found"})` plus a `404` status, and add a `?make=...` query filter to `get_cars()` using `request.args.get("make")`.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** `@app.route` with methods, `request.get_json()`, request-body validation, id generation

Add a `POST /cars` endpoint to create a car and a `PUT /cars/<id>` endpoint to update one, both validating the incoming JSON.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)

cars = [
    {"id": 1, "make": "Toyota", "model": "Corolla", "year": 2021, "price": 23500},
    {"id": 2, "make": "Honda", "model": "Civic", "year": 2022, "price": 25100},
]

@app.route("/cars", methods=["POST"])
def create_car():
    data = request.get_json()
    if not data or "make" not in data or "model" not in data:
        return jsonify({"error": "make and model are required"}), 400
    new_car = {
        "id": max(c["id"] for c in cars) + 1,
        "make": data["make"],
        "model": data["model"],
        "year": data.get("year", 2024),
        "price": data.get("price", 0),
    }
    cars.append(new_car)
    return jsonify(new_car), 201

@app.route("/cars/<int:car_id>", methods=["PUT"])
def update_car(car_id):
    data = request.get_json()
    for c in cars:
        if c["id"] == car_id:
            c["make"] = data.get("make", c["make"])
            c["model"] = data.get("model", c["model"])
            c["year"] = data.get("year", c["year"])
            c["price"] = data.get("price", c["price"])
            return jsonify(c)
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Validate that `price` is a non-negative number, returning `400` if not. Test with `curl -X POST -H "Content-Type: application/json" -d '{"make":"Mazda","model":"3","year":2023,"price":27000}' http://localhost:5000/cars`.

## Exercise 3: DELETE + Custom Error Handler
**Difficulty:** Basic
**Concepts:** `@app.route` with `DELETE`, `@app.errorhandler`, consistent JSON errors

Add a `DELETE /cars/<id>` endpoint and a custom error handler that turns all `404` responses into a consistent JSON shape.

**Starter code:**
```python
from flask import Flask, jsonify, abort

app = Flask(__name__)

cars = [
    {"id": 1, "make": "Toyota", "model": "Corolla", "year": 2021, "price": 23500},
    {"id": 2, "make": "Honda", "model": "Civic", "year": 2022, "price": 25100},
]

@app.route("/cars/<int:car_id>", methods=["DELETE"])
def delete_car(car_id):
    for i, c in enumerate(cars):
        if c["id"] == car_id:
            deleted = cars.pop(i)
            return jsonify({"message": f"Deleted '{deleted['make']} {deleted['model']}'"})
    abort(404)

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `@app.errorhandler(405)` for wrong-method requests, and verify it fires with `curl -X PATCH http://localhost:5000/cars/1`. Then add a `GET /cars/<id>/price` endpoint that returns just the car's price.
