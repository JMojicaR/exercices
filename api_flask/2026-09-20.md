## 1. Hello World + Path & Query Parameters
**Description:** Create a Flask app with a `GET /` route returning JSON, a `GET /greet/<name>` route using a path parameter, and a `GET /add` route reading query parameters (`?a=2&b=3`).
**Difficulty:** Basic
**Concepts:** `Flask(__name__)`, `@app.route`, `jsonify`, path parameters, `request.args`.
**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

@app.route("/")
def home():
    return jsonify({"message": "Hello, World!"})

@app.route("/greet/<name>")
def greet(name):
    return jsonify({"message": f"Hello, {name}!"})

@app.route("/add")
def add():
    a = int(request.args.get("a", 0))
    b = int(request.args.get("b", 0))
    return jsonify({"result": a + b})

if __name__ == "__main__":
    app.run(debug=True)
```

## 2. In-Memory CRUD API (Books)
**Description:** Build a full CRUD API for a "book" resource stored in an in-memory list. Implement `GET /books`, `GET /books/<id>`, `POST /books`, `PUT /books/<id>`, and `DELETE /books/<id>`.
**Difficulty:** Basic
**Concepts:** HTTP methods, `request.get_json()`, status codes (200/201/204/404), list manipulation.
**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
books = []
next_id = 1

@app.route("/books", methods=["GET"])
def list_books():
    return jsonify(books)

@app.route("/books/<int:book_id>", methods=["GET"])
def get_book(book_id):
    for book in books:
        if book["id"] == book_id:
            return jsonify(book)
    return jsonify({"error": "Book not found"}), 404

@app.route("/books", methods=["POST"])
def create_book():
    global next_id
    data = request.get_json()
    book = {"id": next_id, "title": data["title"], "author": data.get("author", "")}
    next_id += 1
    books.append(book)
    return jsonify(book), 201

@app.route("/books/<int:book_id>", methods=["PUT"])
def update_book(book_id):
    data = request.get_json()
    for book in books:
        if book["id"] == book_id:
            book["title"] = data.get("title", book["title"])
            book["author"] = data.get("author", book["author"])
            return jsonify(book)
    return jsonify({"error": "Book not found"}), 404

@app.route("/books/<int:book_id>", methods=["DELETE"])
def delete_book(book_id):
    global books
    before = len(books)
    books = [b for b in books if b["id"] != book_id]
    if len(books) == before:
        return jsonify({"error": "Book not found"}), 404
    return jsonify({"result": "deleted"}), 204

if __name__ == "__main__":
    app.run(debug=True)
```

## 3. Middleware & Error Handling
**Description:** Add a `before_request` middleware that logs every incoming request, and a custom error handler that returns JSON for 404 errors and validates POST input with `abort(400, ...)`.
**Difficulty:** Basic
**Concepts:** `@app.before_request`, `@app.errorhandler`, `abort()`, request logging, status codes.
**Starter code:**
```python
from flask import Flask, jsonify, request, abort
import logging

app = Flask(__name__)
logging.basicConfig(level=logging.INFO)
items = []

@app.before_request
def log_request():
    app.logger.info("%s %s", request.method, request.path)

@app.errorhandler(404)
def not_found(e):
    return jsonify({"error": "Resource not found"}), 404

@app.route("/items", methods=["POST"])
def add_item():
    data = request.get_json()
    if not data or "name" not in data:
        abort(400, description="Field 'name' is required")
    items.append(data["name"])
    return jsonify({"added": data["name"]}), 201

if __name__ == "__main__":
    app.run(debug=True)
```
