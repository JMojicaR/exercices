## Exercise 1: GET Endpoints + 404 Handling
**Difficulty:** Basic
**Concepts:** `Flask` app, `@app.route`, `jsonify`, URL parameters, `abort(404)`

Create two GET endpoints: one returning all pets, and one returning a single pet by `id` (404 if missing).

**Starter code:**
```python
from flask import Flask, jsonify, abort

app = Flask(__name__)

pets = [
    {"id": 1, "name": "Max", "species": "dog", "age": 3},
    {"id": 2, "name": "Luna", "species": "cat", "age": 2},
]

@app.route("/pets", methods=["GET"])
def get_pets():
    return jsonify(pets)

@app.route("/pets/<int:pet_id>", methods=["GET"])
def get_pet(pet_id):
    for p in pets:
        if p["id"] == pet_id:
            return jsonify(p)
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Replace `abort(404)` with `jsonify({"error": "Pet not found"})` plus a `404` status, and add a `?species=...` query filter to `get_pets()` using `request.args.get("species")`.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** `@app.route` with methods, `request.get_json()`, request-body validation, id generation

Add a `POST /pets` endpoint to create a pet and a `PUT /pets/<id>` endpoint to replace one, both validating the incoming JSON.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)

pets = [
    {"id": 1, "name": "Max", "species": "dog", "age": 3},
    {"id": 2, "name": "Luna", "species": "cat", "age": 2},
]

@app.route("/pets", methods=["POST"])
def create_pet():
    data = request.get_json()
    if not data or "name" not in data:
        return jsonify({"error": "name is required"}), 400
    new_pet = {
        "id": max(p["id"] for p in pets) + 1,
        "name": data["name"],
        "species": data.get("species", "unknown"),
        "age": data.get("age", 0),
    }
    pets.append(new_pet)
    return jsonify(new_pet), 201

@app.route("/pets/<int:pet_id>", methods=["PUT"])
def update_pet(pet_id):
    data = request.get_json()
    for p in pets:
        if p["id"] == pet_id:
            p["name"] = data.get("name", p["name"])
            p["species"] = data.get("species", p["species"])
            p["age"] = data.get("age", p["age"])
            return jsonify(p)
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Validate that `age` is a non-negative integer, returning `400` if not. Test with `curl -X POST -H "Content-Type: application/json" -d '{"name":"Bella","species":"rabbit","age":1}' http://localhost:5000/pets`.

## Exercise 3: DELETE + Custom Error Handler
**Difficulty:** Basic
**Concepts:** `@app.route` with `DELETE`, `@app.errorhandler`, consistent JSON errors

Add a `DELETE /pets/<id>` endpoint and a custom error handler that turns all `404` responses into a consistent JSON shape.

**Starter code:**
```python
from flask import Flask, jsonify, abort

app = Flask(__name__)

pets = [
    {"id": 1, "name": "Max", "species": "dog", "age": 3},
    {"id": 2, "name": "Luna", "species": "cat", "age": 2},
]

@app.route("/pets/<int:pet_id>", methods=["DELETE"])
def delete_pet(pet_id):
    for i, p in enumerate(pets):
        if p["id"] == pet_id:
            deleted = pets.pop(i)
            return jsonify({"message": f"Deleted '{deleted['name']}'"})
    abort(404)

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `@app.errorhandler(405)` for wrong-method requests, and verify it fires with `curl -X PATCH http://localhost:5000/pets/1`. Then add a `GET /pets/<id>/name` endpoint that returns just the pet's name.
