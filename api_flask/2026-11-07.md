## Exercise 1: GET Endpoints + 404 Handling
**Difficulty:** Basic
**Concepts:** `Flask` app, `@app.route`, `jsonify`, URL parameters, `abort(404)`

Create two GET endpoints: one returning all books, and one returning a single book by `id` (404 if missing).

**Starter code:**
```python
from flask import Flask, jsonify, abort

app = Flask(__name__)

books = [
    {"id": 1, "title": "1984", "author": "George Orwell"},
    {"id": 2, "title": "Cien años de soledad", "author": "Gabriel García Márquez"},
    {"id": 3, "title": "El Principito", "author": "Antoine de Saint-Exupéry"},
]

@app.route("/books", methods=["GET"])
def get_books():
    return jsonify(books)

@app.route("/books/<int:book_id>", methods=["GET"])
def get_book(book_id):
    for book in books:
        if book["id"] == book_id:
            return jsonify(book)
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Change `abort(404)` to `jsonify({"error": "Book not found"})` with a `404` status, and add a `?author=Orwell` query filter to `get_books()` using `request.args.get("author")`.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** `@app.route` with methods, `request.get_json()`, request-body validation, id generation

Add a `POST /books` endpoint to create a book and a `PUT /books/<id>` endpoint to replace one, both validating the incoming JSON.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)

books = [
    {"id": 1, "title": "1984", "author": "George Orwell"},
    {"id": 2, "title": "Cien años de soledad", "author": "Gabriel García Márquez"},
]

@app.route("/books", methods=["POST"])
def create_book():
    data = request.get_json()
    if not data or "title" not in data or "author" not in data:
        return jsonify({"error": "title and author are required"}), 400
    new_book = {
        "id": max(b["id"] for b in books) + 1,
        "title": data["title"],
        "author": data["author"],
    }
    books.append(new_book)
    return jsonify(new_book), 201

@app.route("/books/<int:book_id>", methods=["PUT"])
def update_book(book_id):
    data = request.get_json()
    for book in books:
        if book["id"] == book_id:
            book["title"] = data.get("title", book["title"])
            book["author"] = data.get("author", book["author"])
            return jsonify(book)
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Use `request.get_json(silent=True)` and return `400` when the body is missing or not JSON. Test with `curl -X POST -H "Content-Type: application/json" -d '{"title":"Rayuela","author":"Julio Cortázar"}' http://localhost:5000/books`.

## Exercise 3: DELETE + Custom Error Handler
**Difficulty:** Basic
**Concepts:** `@app.route` with `DELETE`, `@app.errorhandler`, custom JSON error responses

Add a `DELETE /books/<id>` endpoint and a custom error handler that turns all `404` responses into a consistent JSON shape.

**Starter code:**
```python
from flask import Flask, jsonify, abort

app = Flask(__name__)

books = [
    {"id": 1, "title": "1984", "author": "George Orwell"},
    {"id": 2, "title": "Cien años de soledad", "author": "Gabriel García Márquez"},
    {"id": 3, "title": "El Principito", "author": "Antoine de Saint-Exupéry"},
]

@app.route("/books/<int:book_id>", methods=["DELETE"])
def delete_book(book_id):
    for i, book in enumerate(books):
        if book["id"] == book_id:
            deleted = books.pop(i)
            return jsonify({"message": f"Deleted '{deleted['title']}'"})
    abort(404)

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `@app.errorhandler(405)` for wrong-method requests, and verify your handler fires by `curl -X PATCH http://localhost:5000/books/1`. Then add a `GET /books/search?title=...` endpoint that returns matching books.
