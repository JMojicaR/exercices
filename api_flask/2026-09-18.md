## Exercise 3: In-Memory Notes CRUD API
- **Difficulty:** Easy
- **Description:** Build a full CRUD API for notes stored in a Python list. Implement GET (list all), GET by id, POST (create), PUT (update text), and DELETE (remove). Return 404 with an error when a note is not found.
- **Concepts:** CRUD, in-memory storage, path parameters, HTTP methods, status codes
- **Starter code:**
```python
from flask import Flask, request, jsonify

app = Flask(__name__)
notes = []
next_id = 1

@app.route('/notes', methods=['GET'])
def list_notes():
    return jsonify(notes)

@app.route('/notes', methods=['POST'])
def create_note():
    global next_id
    data = request.get_json()
    note = {"id": next_id, "text": data.get("text", "")}
    notes.append(note)
    next_id += 1
    return jsonify(note), 201
```
