## Exercise 1: Hello World & Basic GET Endpoints
- **Description**: Create a Flask application with at least three GET endpoints. One returns a simple "Hello, World!" message. Another returns JSON data (e.g., server status with uptime and version). A third accepts a URL path parameter (e.g., `/greet/<name>`) and returns a personalized greeting. This exercise teaches you how to create a Flask app, define routes, return plain text and JSON responses, and handle URL parameters.
- **Difficulty**: Beginner
- **Concepts**: Flask app initialization, route decorators, jsonify, URL path parameters, running a dev server
- **Example/Starter Code**:
```python
from flask import Flask, jsonify
from datetime import datetime

app = Flask(__name__)
start_time = datetime.now()

@app.route('/')
def hello_world():
    return "Hello, World!"

@app.route('/status')
def status():
    uptime = (datetime.now() - start_time).total_seconds()
    return jsonify({
        "status": "running",
        "version": "1.0.0",
        "uptime_seconds": uptime
    })

@app.route('/greet/<name>')
def greet(name):
    return jsonify({
        "message": f"Hello, {name}! Welcome to the Flask API."
    })

if __name__ == '__main__':
    app.run(debug=True)
```

## Exercise 2: TODO List CRUD API
- **Description**: Build a full CRUD (Create, Read, Update, Delete) REST API for managing a todo list. Use an in-memory list to store todos (each with an id, title, and completed status). Implement: `GET /todos` (list all), `GET /todos/<id>` (get one), `POST /todos` (create new), `PUT /todos/<id>` (update), and `DELETE /todos/<id>` (delete). Return proper HTTP status codes (200, 201, 404) and JSON responses.
- **Difficulty**: Beginner
- **Concepts**: RESTful routing, HTTP methods (GET/POST/PUT/DELETE), request.get_json(), status codes, in-memory data storage, list/dict manipulation
- **Example/Starter Code**:
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

# In-memory "database"
todos = []
next_id = 1

@app.route('/todos', methods=['GET'])
def get_todos():
    return jsonify(todos)

@app.route('/todos/<int:todo_id>', methods=['GET'])
def get_todo(todo_id):
    todo = next((t for t in todos if t['id'] == todo_id), None)
    if todo is None:
        return jsonify({"error": "Todo not found"}), 404
    return jsonify(todo)

@app.route('/todos', methods=['POST'])
def create_todo():
    global next_id
    data = request.get_json()

    if not data or 'title' not in data:
        return jsonify({"error": "Title is required"}), 400

    todo = {
        "id": next_id,
        "title": data['title'],
        "completed": data.get('completed', False)
    }
    next_id += 1
    todos.append(todo)
    return jsonify(todo), 201

@app.route('/todos/<int:todo_id>', methods=['PUT'])
def update_todo(todo_id):
    todo = next((t for t in todos if t['id'] == todo_id), None)
    if todo is None:
        return jsonify({"error": "Todo not found"}), 404

    data = request.get_json()
    if 'title' in data:
        todo['title'] = data['title']
    if 'completed' in data:
        todo['completed'] = data['completed']

    return jsonify(todo)

@app.route('/todos/<int:todo_id>', methods=['DELETE'])
def delete_todo(todo_id):
    global todos
    todo = next((t for t in todos if t['id'] == todo_id), None)
    if todo is None:
        return jsonify({"error": "Todo not found"}), 404

    todos = [t for t in todos if t['id'] != todo_id]
    return jsonify({"message": "Todo deleted"}), 200

if __name__ == '__main__':
    app.run(debug=True)
```

**Testing the API:**
```bash

# In another terminal:

curl -X POST http://127.0.0.1:5000/todos \
  -H "Content-Type: application/json" \
  -d '{"title": "Learn Flask"}'

# Update a todo
curl -X PUT http://127.0.0.1:5000/todos/1 \
  -H "Content-Type: application/json" \
  -d '{"completed": true}'

# Delete a todo
curl -X DELETE http://127.0.0.1:5000/todos/1
```

## Exercise 3: Book Collection API with Query Parameters
- **Description**: Build a REST API for managing a small book collection. Each book has an id, title, author, year, and genre. In addition to full CRUD (like the TODO exercise), add query parameter filtering: `GET /books?author=Doe` should return only books by that author, and `GET /books?genre=fiction` should filter by genre. Support combining filters. Also add a `GET /books/search?q=term` endpoint that searches for books where the title or author contains the search term (case-insensitive). This exercise builds on CRUD basics by adding query string handling and search functionality.
- **Difficulty**: Beginner
- **Concepts**: query parameters (request.args), string filtering, case-insensitive search, list comprehensions, RESTful API design, combined filters
- **Example/Starter Code**:
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

# Seed data
books = [
    {"id": 1, "title": "To Kill a Mockingbird", "author": "Harper Lee", "year": 1960, "genre": "fiction"},
    {"id": 2, "title": "1984", "author": "George Orwell", "year": 1949, "genre": "fiction"},
    {"id": 3, "title": "A Brief History of Time", "author": "Stephen Hawking", "year": 1988, "genre": "science"},
]
next_id = 4

@app.route('/books', methods=['GET'])
def get_books():
    # Start with all books
    result = books

    # Apply filters from query parameters
    author_filter = request.args.get('author', '').lower()
    genre_filter = request.args.get('genre', '').lower()

    if author_filter:
        result = [b for b in result if author_filter in b['author'].lower()]
    if genre_filter:
        result = [b for b in result if genre_filter in b['genre'].lower()]

    return jsonify(result)

@app.route('/books/search', methods=['GET'])
def search_books():
    query = request.args.get('q', '').lower()
    if not query:
        return jsonify({"error": "Query parameter 'q' is required"}), 400

    results = [
        b for b in books
        if query in b['title'].lower() or query in b['author'].lower()
    ]
    return jsonify(results)

@app.route('/books', methods=['POST'])
def create_book():
    global next_id
    data = request.get_json()

    required_fields = ['title', 'author', 'year', 'genre']
    missing = [f for f in required_fields if f not in data]
    if missing:
        return jsonify({"error": f"Missing fields: {', '.join(missing)}"}), 400

    book = {
        "id": next_id,
        "title": data['title'],
        "author": data['author'],
        "year": data['year'],
        "genre": data['genre']
    }
    next_id += 1
    books.append(book)
    return jsonify(book), 201

@app.route('/books/<int:book_id>', methods=['GET'])
def get_book(book_id):
    book = next((b for b in books if b['id'] == book_id), None)
    if book is None:
        return jsonify({"error": "Book not found"}), 404
    return jsonify(book)

@app.route('/books/<int:book_id>', methods=['PUT'])
def update_book(book_id):
    book = next((b for b in books if b['id'] == book_id), None)
    if book is None:
        return jsonify({"error": "Book not found"}), 404

    data = request.get_json()
    for field in ['title', 'author', 'year', 'genre']:
        if field in data:
            book[field] = data[field]

    return jsonify(book)

@app.route('/books/<int:book_id>', methods=['DELETE'])
def delete_book(book_id):
    global books
    book = next((b for b in books if b['id'] == book_id), None)
    if book is None:
        return jsonify({"error": "Book not found"}), 404

    books = [b for b in books if b['id'] != book_id]
    return jsonify({"message": "Book deleted"}), 200

if __name__ == '__main__':
    app.run(debug=True)
```

**Testing the search and filters:**
