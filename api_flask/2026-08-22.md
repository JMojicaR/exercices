## Exercise 1: Calculator API (GET query params + POST JSON)
**Difficulty:** Basic
### Problem
Build a small calculator API with two endpoints:
1. `GET /add?a=<int>&b=<int>` — add two numbers passed as **query parameters**.
2. `POST /calculate` — accept a **JSON body** `{"a": <num>, "b": <num>, "op": "add|subtract|multiply|divide"}` and return the result. Return a JSON error if the operation is unknown or if dividing by zero.

### Concepts
- `@app.route` with `methods=[...]`
- `request.args.get(...)` for query parameters
- `request.get_json()` for JSON bodies
- `jsonify` for JSON responses

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/add')
def add():
    a = int(request.args.get('a', 0))
    b = int(request.args.get('b', 0))
    return jsonify({"operation": "add", "result": a + b})

@app.route('/calculate', methods=['POST'])
def calculate():
    data = request.get_json()
    a = data['a']
    b = data['b']
    op = data.get('op', 'add')

    if op == 'add':
        result = a + b
    elif op == 'subtract':
        result = a - b
    elif op == 'multiply':
        result = a * b
    elif op == 'divide':
        if b == 0:
            return jsonify({"error": "Cannot divide by zero"}), 400
        result = a / b
    else:
        return jsonify({"error": f"Unknown operation: {op}"}), 400

    return jsonify({"operation": op, "result": result})

if __name__ == '__main__':
    app.run(debug=True)
```
**Test with curl:**
```bash
curl "http://127.0.0.1:5000/add?a=3&b=4"
curl -X POST http://127.0.0.1:5000/calculate \
  -H "Content-Type: application/json" \
  -d '{"a": 10, "b": 4, "op": "multiply"}'
curl -X POST http://127.0.0.1:5000/calculate \
  -H "Content-Type: application/json" \
  -d '{"a": 10, "b": 0, "op": "divide"}'
```

## Exercise 2: Employees CRUD API (in-memory)
**Difficulty:** Basic
### Problem
Build a full in-memory CRUD API for employees (stored in a Python dict):
- `GET /employees` — list all employees.
- `POST /employees` — create an employee from JSON `{"name", "role"}` (assign an auto-incremented `id`).
- `GET /employees/<int:id>` — return one employee or 404.
- `PUT /employees/<int:id>` — update name/role or 404.
- `DELETE /employees/<int:id>` — remove one employee or 404.

### Concepts
- RESTful resource routing with `<int:id>` converters
- In-memory storage with a dict and an auto-incrementing id
- Correct status codes (`201` on create, `404` on missing)

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

employees = {}
next_id = 1

@app.route('/employees', methods=['GET'])
def list_employees():
    return jsonify(list(employees.values()))

@app.route('/employees', methods=['POST'])
def create_employee():
    global next_id
    data = request.get_json()
    emp = {"id": next_id, "name": data["name"], "role": data.get("role", "")}
    employees[next_id] = emp
    next_id += 1
    return jsonify(emp), 201

@app.route('/employees/<int:emp_id>', methods=['GET'])
def get_employee(emp_id):
    emp = employees.get(emp_id)
    if emp is None:
        return jsonify({"error": "Employee not found"}), 404
    return jsonify(emp)

@app.route('/employees/<int:emp_id>', methods=['PUT'])
def update_employee(emp_id):
    emp = employees.get(emp_id)
    if emp is None:
        return jsonify({"error": "Employee not found"}), 404
    data = request.get_json()
    emp["name"] = data.get("name", emp["name"])
    emp["role"] = data.get("role", emp["role"])
    return jsonify(emp)

@app.route('/employees/<int:emp_id>', methods=['DELETE'])
def delete_employee(emp_id):
    if emp_id not in employees:
        return jsonify({"error": "Employee not found"}), 404
    del employees[emp_id]
    return jsonify({"message": "Employee deleted"})

if __name__ == '__main__':
    app.run(debug=True)
```
**Test with curl:**
```bash
curl http://127.0.0.1:5000/employees
curl -X POST http://127.0.0.1:5000/employees \
  -H "Content-Type: application/json" \
  -d '{"name": "Alice", "role": "Engineer"}'
curl http://127.0.0.1:5000/employees/1
curl -X PUT http://127.0.0.1:5000/employees/1 \
  -H "Content-Type: application/json" \
  -d '{"role": "Senior Engineer"}'
curl -X DELETE http://127.0.0.1:5000/employees/1
```

## Exercise 3: Request-Logging Middleware + Global JSON Error Handlers
**Difficulty:** Basic
### Problem
Add request logging and global JSON error handling to a Flask app:
1. Use `@app.before_request` to log every incoming request's method and path.
2. Register global error handlers for `404` and `500` that return JSON instead of HTML.
3. Include a `/boom` route that raises an exception to demonstrate the `500` handler.

### Concepts
- `@app.before_request` as middleware
- `@app.errorhandler(code)` for global error handlers
- Returning JSON error payloads

### HTTP Method(s)
`GET`

### Example / Starter Code
```python
import logging
from flask import Flask, request, jsonify

app = Flask(__name__)
logging.basicConfig(level=logging.INFO)

@app.before_request
def log_request():
    app.logger.info(f"{request.method} {request.path}")

@app.errorhandler(404)
def not_found(e):
    return jsonify({"error": "Resource not found"}), 404

@app.errorhandler(500)
def server_error(e):
    return jsonify({"error": "Internal server error"}), 500

@app.route('/')
def index():
    return jsonify({"message": "Welcome to the API"})

@app.route('/boom')
def boom():
    raise Exception("Something went wrong!")

if __name__ == '__main__':
    app.run(debug=True)
```
**Test with curl:**
```bash
curl http://127.0.0.1:5000/
curl http://127.0.0.1:5000/nope          # triggers the 404 handler
curl http://127.0.0.1:5000/boom          # triggers the 500 handler
```
