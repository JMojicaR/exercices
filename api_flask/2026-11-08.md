## Exercise 1: GET Endpoints + 404 Handling
**Difficulty:** Basic
**Concepts:** `Flask` app, `@app.route`, `jsonify`, URL parameters, `abort(404)`

Create two GET endpoints: one returning all notes, and one returning a single note by `id` (404 if missing).

**Starter code:**
```python
from flask import Flask, jsonify, abort

app = Flask(__name__)

notes = [
    {"id": 1, "title": "Comprar leche", "body": "Supermercado antes de las 8"},
    {"id": 2, "title": "Llamar al doctor", "body": "Confirmar cita del martes"},
]

@app.route("/notes", methods=["GET"])
def get_notes():
    return jsonify(notes)

@app.route("/notes/<int:note_id>", methods=["GET"])
def get_note(note_id):
    for note in notes:
        if note["id"] == note_id:
            return jsonify(note)
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Change `abort(404)` to `jsonify({"error": "Note not found"})` with a `404` status, and add a `?title=...` query filter to `get_notes()` using `request.args.get("title")`.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** `@app.route` with methods, `request.get_json()`, request-body validation, id generation

Add a `POST /notes` endpoint to create a note and a `PUT /notes/<id>` endpoint to replace one, both validating the incoming JSON.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)

notes = [
    {"id": 1, "title": "Comprar leche", "body": "Supermercado antes de las 8"},
    {"id": 2, "title": "Llamar al doctor", "body": "Confirmar cita del martes"},
]

@app.route("/notes", methods=["POST"])
def create_note():
    data = request.get_json()
    if not data or "title" not in data or "body" not in data:
        return jsonify({"error": "title and body are required"}), 400
    new_note = {
        "id": max(n["id"] for n in notes) + 1,
        "title": data["title"],
        "body": data["body"],
    }
    notes.append(new_note)
    return jsonify(new_note), 201

@app.route("/notes/<int:note_id>", methods=["PUT"])
def update_note(note_id):
    data = request.get_json()
    for note in notes:
        if note["id"] == note_id:
            note["title"] = data.get("title", note["title"])
            note["body"] = data.get("body", note["body"])
            return jsonify(note)
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Use `request.get_json(silent=True)` and return `400` when the body is missing or not JSON. Test with `curl -X POST -H "Content-Type: application/json" -d '{"title":"Regar plantas","body":"Domingo"}' http://localhost:5000/notes`.

## Exercise 3: DELETE + Custom Error Handler
**Difficulty:** Basic
**Concepts:** `@app.route` with `DELETE`, `@app.errorhandler`, custom JSON error responses

Add a `DELETE /notes/<id>` endpoint and a custom error handler that turns all `404` responses into a consistent JSON shape.

**Starter code:**
```python
from flask import Flask, jsonify, abort

app = Flask(__name__)

notes = [
    {"id": 1, "title": "Comprar leche", "body": "Supermercado antes de las 8"},
    {"id": 2, "title": "Llamar al doctor", "body": "Confirmar cita del martes"},
]

@app.route("/notes/<int:note_id>", methods=["DELETE"])
def delete_note(note_id):
    for i, note in enumerate(notes):
        if note["id"] == note_id:
            deleted = notes.pop(i)
            return jsonify({"message": f"Deleted '{deleted['title']}'"})
    abort(404)

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `@app.errorhandler(405)` for wrong-method requests, and verify it fires with `curl -X PATCH http://localhost:5000/notes/1`. Then add a `GET /notes/search?title=...` endpoint that returns matching notes.
