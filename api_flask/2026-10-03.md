## Exercise 1: App Setup, Health Check & GET Collection (routing)
**Difficulty:** Basic
**Concepts:** App creation, `@app.route`, `jsonify`, returning JSON lists, running the server.

Create a Flask app with a `GET /health` endpoint and a `GET /tasks` endpoint that returns a list of tasks.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

tasks = [
    {"id": 1, "title": "Learn Flask", "done": False},
    {"id": 2, "title": "Build an API", "done": False},
]

@app.route("/health", methods=["GET"])
def health():
    return jsonify({"status": "ok"})

@app.route("/tasks", methods=["GET"])
def list_tasks():
    return jsonify(tasks)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /` root endpoint returning `{"message": "Welcome to the Tasks API"}`.

## Exercise 2: POST Create + GET by ID with 404 (request/response)
**Difficulty:** Basic
**Concepts:** `request.get_json`, POST bodies, path parameters (`<int:task_id>`), `abort(400/404)`, status codes.

Extend the app with `POST /tasks` to create a task and `GET /tasks/<int:task_id>` to fetch one.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)
tasks = [
    {"id": 1, "title": "Learn Flask", "done": False},
    {"id": 2, "title": "Build an API", "done": False},
]
next_id = 3

@app.route("/tasks", methods=["GET"])
def list_tasks():
    return jsonify(tasks)

@app.route("/tasks/<int:task_id>", methods=["GET"])
def get_task(task_id):
    for t in tasks:
        if t["id"] == task_id:
            return jsonify(t)
    abort(404, description="Task not found")

@app.route("/tasks", methods=["POST"])
def create_task():
    global next_id
    data = request.get_json()
    if not data or "title" not in data:
        abort(400, description="title is required")
    task = {"id": next_id, "title": data["title"], "done": False}
    next_id += 1
    tasks.append(task)
    return jsonify(task), 201
```

**Task:** Add an error handler so 404s return a JSON body instead of the default HTML page.

## Exercise 3: PUT/DELETE + Middleware + Error Handlers
**Difficulty:** Basic
**Concepts:** `PUT`/`DELETE` methods, updating/deleting items, `@app.before_request` middleware, `@app.errorhandler`.

Add update and delete endpoints, a request-logging middleware, and a JSON error handler.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)
tasks = [
    {"id": 1, "title": "Learn Flask", "done": False},
    {"id": 2, "title": "Build an API", "done": False},
]
next_id = 3

@app.before_request
def log_request():
    print(f"{request.method} {request.path}")

@app.errorhandler(404)
def not_found(e):
    return jsonify({"error": "resource not found"}), 404

@app.route("/tasks/<int:task_id>", methods=["PUT"])
def update_task(task_id):
    data = request.get_json() or {}
    for t in tasks:
        if t["id"] == task_id:
            t["title"] = data.get("title", t["title"])
            t["done"] = data.get("done", t["done"])
            return jsonify(t)
    abort(404)

@app.route("/tasks/<int:task_id>", methods=["DELETE"])
def delete_task(task_id):
    for i, t in enumerate(tasks):
        if t["id"] == task_id:
            removed = tasks.pop(i)
            return jsonify({"deleted": removed})
    abort(404)
```

**Task:** Add a `@app.errorhandler(400)` JSON handler and a `GET /tasks?done=true` filter using `request.args`.
