## Exercise 1: Basic App + GET Endpoints
**Difficulty:** Basic
**Concepts:** `Flask` app, `@app.route`, returning JSON with `jsonify`, path parameters

Create a Flask app with an in-memory list of animals, plus two GET endpoints: one that returns all animals and one that returns a single animal by `id` (404 if missing).

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

animals = [
    {"id": 1, "name": "Simba", "species": "Lion"},
    {"id": 2, "name": "Nala", "species": "Lion"},
    {"id": 3, "name": "Marty", "species": "Zebra"},
]

@app.route("/animals", methods=["GET"])
def get_animals():
    return jsonify(animals)

@app.route("/animals/<int:animal_id>", methods=["GET"])
def get_animal(animal_id):
    for animal in animals:
        if animal["id"] == animal_id:
            return jsonify(animal)
    return jsonify({"error": "Animal not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /animals?species=Lion` query filter using `request.args.get("species")`.

## Exercise 2: POST + PUT (Create & Update)
**Difficulty:** Basic
**Concepts:** `request.get_json()`, request body parsing, `jsonify`, returning 201, id generation

Add a `POST /animals` endpoint to create a new animal and a `PUT /animals/<id>` endpoint to replace an existing one.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

animals = [
    {"id": 1, "name": "Simba", "species": "Lion"},
    {"id": 2, "name": "Nala", "species": "Lion"},
]

@app.route("/animals", methods=["POST"])
def create_animal():
    data = request.get_json()
    new_id = max(a["id"] for a in animals) + 1 if animals else 1
    animal = {"id": new_id, "name": data.get("name"), "species": data.get("species")}
    animals.append(animal)
    return jsonify(animal), 201

@app.route("/animals/<int:animal_id>", methods=["PUT"])
def update_animal(animal_id):
    data = request.get_json()
    for animal in animals:
        if animal["id"] == animal_id:
            animal["name"] = data.get("name", animal["name"])
            animal["species"] = data.get("species", animal["species"])
            return jsonify(animal)
    return jsonify({"error": "Animal not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Validate that `name` is a non-empty string and return a 400 error if it is missing.

## Exercise 3: DELETE + Error Handling
**Difficulty:** Basic
**Concepts:** DELETE endpoint, removing list items, `@app.errorhandler`, custom error responses

Add a `DELETE /animals/<id>` endpoint and a global error handler for 404 and 405 responses.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

animals = [
    {"id": 1, "name": "Simba", "species": "Lion"},
    {"id": 2, "name": "Nala", "species": "Lion"},
]

@app.route("/animals/<int:animal_id>", methods=["DELETE"])
def delete_animal(animal_id):
    for animal in animals:
        if animal["id"] == animal_id:
            animals.remove(animal)
            return jsonify({"message": f"Animal {animal_id} deleted"})
    return jsonify({"error": "Animal not found"}), 404

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Route or resource not found"}), 404

@app.errorhandler(405)
def method_not_allowed(error):
    return jsonify({"error": "Method not allowed for this route"}), 405

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /animals/<id>` that returns the animal, and confirm the custom 404 handler fires when the id does not exist (vs. a wrong URL path).
