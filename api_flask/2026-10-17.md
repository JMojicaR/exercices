## Exercise 1: App Setup + GET Endpoints
**Difficulty:** Basic
**Concepts:** app creation, routing, `jsonify`, list endpoint, health check

Create a Flask app with a health-check route and a route that returns all courses.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

courses = [
    {"id": 1, "title": "Intro to Python", "level": "beginner"},
    {"id": 2, "title": "Web Dev with Flask", "level": "intermediate"},
]

@app.route("/health", methods=["GET"])
def health():
    return jsonify({"status": "ok"})

@app.route("/courses", methods=["GET"])
def get_courses():
    return jsonify(courses)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /courses/count` endpoint that returns `{"count": len(courses)}`.

## Exercise 2: POST + GET by ID (404 handling)
**Difficulty:** Basic
**Concepts:** POST, request body, `request.get_json()`, path parameters, 404

Add endpoints to create a course and fetch a single course by its ID.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
courses = []
next_id = 1

@app.route("/courses", methods=["POST"])
def create_course():
    global next_id
    data = request.get_json()
    course = {"id": next_id, "title": data["title"], "level": data.get("level", "beginner")}
    next_id += 1
    courses.append(course)
    return jsonify(course), 201

@app.route("/courses/<int:course_id>", methods=["GET"])
def get_course(course_id):
    for course in courses:
        if course["id"] == course_id:
            return jsonify(course)
    return jsonify({"error": "Course not found"}), 404
```

**Task:** Validate that `title` is present in the request body; if missing, return a 400 error.

## Exercise 3: PUT + DELETE + Error Handler
**Difficulty:** Basic
**Concepts:** PUT, DELETE, updating records, `@app.errorhandler`

Add endpoints to update and delete a course, plus a global error handler.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
courses = []

@app.route("/courses/<int:course_id>", methods=["PUT"])
def update_course(course_id):
    data = request.get_json()
    for course in courses:
        if course["id"] == course_id:
            course["title"] = data.get("title", course["title"])
            course["level"] = data.get("level", course["level"])
            return jsonify(course)
    return jsonify({"error": "Course not found"}), 404

@app.route("/courses/<int:course_id>", methods=["DELETE"])
def delete_course(course_id):
    for course in courses:
        if course["id"] == course_id:
            courses.remove(course)
            return jsonify({"message": "Course deleted"})
    return jsonify({"error": "Course not found"}), 404

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404
```

**Task:** Add a `@app.errorhandler(405)` handler that returns a friendly JSON message when an HTTP method is not allowed.
