## Exercise 1: App + GET /movies + GET /health
**Difficulty:** Basic
**Concepts:** routing, jsonify, Flask app

Create a Flask app that serves a list of movies as JSON plus a health-check endpoint.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

movies = [
    {"id": 1, "title": "Inception", "year": 2010},
    {"id": 2, "title": "The Matrix", "year": 1999},
]

@app.route("/health")
def health():
    return jsonify({"status": "ok"})

@app.route("/movies")
def get_movies():
    return jsonify(movies)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a GET /movies/count endpoint that returns the number of movies as JSON.

## Exercise 2: POST /movies + GET /movies/<id> + 404 handling
**Difficulty:** Basic
**Concepts:** POST, URL parameters, 404 responses

Let clients add movies and fetch one movie by id, returning 404 when missing.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

movies = [
    {"id": 1, "title": "Inception", "year": 2010},
]

@app.route("/movies", methods=["GET", "POST"])
def movies_collection():
    if request.method == "POST":
        data = request.get_json()
        movie = {"id": len(movies) + 1, **data}
        movies.append(movie)
        return jsonify(movie), 201
    return jsonify(movies)

@app.route("/movies/<int:movie_id>")
def get_movie(movie_id):
    for movie in movies:
        if movie["id"] == movie_id:
            return jsonify(movie)
    return jsonify({"error": "movie not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Reject POST requests whose JSON body lacks a "title" field with a 400 response.

## Exercise 3: PUT/DELETE + @app.errorhandler middleware
**Difficulty:** Basic
**Concepts:** PUT, DELETE, error handler middleware

Add update and delete endpoints plus a global error handler for bad JSON.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

movies = [
    {"id": 1, "title": "Inception", "year": 2010},
]

@app.errorhandler(400)
def bad_request(error):
    return jsonify({"error": "bad request"}), 400

@app.route("/movies", methods=["GET", "POST"])
def movies_collection():
    if request.method == "POST":
        data = request.get_json()
        movie = {"id": len(movies) + 1, **data}
        movies.append(movie)
        return jsonify(movie), 201
    return jsonify(movies)

@app.route("/movies/<int:movie_id>", methods=["PUT", "DELETE"])
def movie_detail(movie_id):
    for movie in movies:
        if movie["id"] == movie_id:
            if request.method == "DELETE":
                movies.remove(movie)
                return jsonify({"message": "deleted"}), 200
            data = request.get_json()
            movie.update(data)
            return jsonify(movie), 200
    return jsonify({"error": "movie not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a 404 error handler that returns JSON instead of the default HTML error page.
