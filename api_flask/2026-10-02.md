## Exercise 1: App Setup, Health Check & GET Collection (routing)
**Difficulty:** Basic
**Concepts:** App creation, `@app.route`, `jsonify`, returning JSON lists, running the server.

Create a Flask app with a `GET /health` endpoint and a `GET /products` endpoint that returns a list of products.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

products = [
    {"id": 1, "name": "Laptop", "price": 899.99},
    {"id": 2, "name": "Mouse", "price": 24.50},
]

@app.route("/health", methods=["GET"])
def health():
    return jsonify({"status": "ok"})

@app.route("/products", methods=["GET"])
def list_products():
    return jsonify(products)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /` root endpoint that returns `{"message": "Welcome to the Products API"}`.

## Exercise 2: POST Create + GET by ID with 404 (request/response)
**Difficulty:** Basic
**Concepts:** `request.get_json`, POST bodies, path parameters (`<int:product_id>`), `abort(400/404)`, status codes.

Extend the app with a `POST /products` endpoint that validates and creates a product, plus a `GET /products/<int:product_id>` endpoint.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)
products = [
    {"id": 1, "name": "Laptop", "price": 899.99},
    {"id": 2, "name": "Mouse", "price": 24.50},
]
next_id = 3

@app.route("/products", methods=["GET"])
def list_products():
    return jsonify(products)

@app.route("/products/<int:product_id>", methods=["GET"])
def get_product(product_id):
    for p in products:
        if p["id"] == product_id:
            return jsonify(p)
    abort(404, description="Product not found")

@app.route("/products", methods=["POST"])
def create_product():
    global next_id
    data = request.get_json()
    if not data or "name" not in data or "price" not in data:
        abort(400, description="name and price are required")
    product = {"id": next_id, "name": data["name"], "price": data["price"]}
    next_id += 1
    products.append(product)
    return jsonify(product), 201
```

**Task:** Add a `GET /products/<id>` behavior that returns a 404 JSON body instead of the default HTML error page (use an error handler).

## Exercise 3: PUT/DELETE + Middleware + Error Handlers
**Difficulty:** Basic
**Concepts:** `PUT`/`DELETE` methods, updating/deleting list items, `@app.before_request` middleware, `@app.errorhandler`.

Add update and delete endpoints plus a simple request-logging middleware and a JSON error handler.

**Starter code:**
```python
from flask import Flask, jsonify, request, abort

app = Flask(__name__)
products = [
    {"id": 1, "name": "Laptop", "price": 899.99},
    {"id": 2, "name": "Mouse", "price": 24.50},
]
next_id = 3

@app.before_request
def log_request():
    print(f"{request.method} {request.path}")

@app.errorhandler(404)
def not_found(e):
    return jsonify({"error": "resource not found"}), 404

@app.route("/products/<int:product_id>", methods=["PUT"])
def update_product(product_id):
    data = request.get_json() or {}
    for p in products:
        if p["id"] == product_id:
            p["name"] = data.get("name", p["name"])
            p["price"] = data.get("price", p["price"])
            return jsonify(p)
    abort(404)

@app.route("/products/<int:product_id>", methods=["DELETE"])
def delete_product(product_id):
    for i, p in enumerate(products):
        if p["id"] == product_id:
            removed = products.pop(i)
            return jsonify({"deleted": removed})
    abort(404)
```

**Task:** Add a `@app.errorhandler(400)` that returns a JSON body, and a `GET /products?max_price=X` filter using `request.args`.
