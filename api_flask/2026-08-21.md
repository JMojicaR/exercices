## Exercise 1: Greeting API — Path & Query Parameters

**Difficulty:** Basic

### Problem
Build a small greeting API:
- `GET /` — returns `{"message": "Hello, World!"}`
- `GET /hello/<name>` — returns a personalized greeting using a path parameter
- `GET /hello?name=...` — (optional) greet using a query parameter instead

### Concepts
- `@app.route` with a path variable (`<name>`)
- `request.args.get()` for query parameters
- `jsonify` for JSON responses

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)


@app.route('/')
def index():
    return jsonify({'message': 'Hello, World!'})


@app.route('/hello/<name>')
def hello_path(name):
    return jsonify({'message': f'Hello, {name}!'})


@app.route('/hello')
def hello_query():
    name = request.args.get('name', 'World')
    return jsonify({'message': f'Hello, {name}!'})


if __name__ == '__main__':
    app.run(debug=True)
```

**Test with curl:**
```bash
curl http://localhost:5000/
curl http://localhost:5000/hello/Alice
curl "http://localhost:5000/hello?name=Bob"
```

## Exercise 2: Notes CRUD API — Full In-Memory CRUD

**Difficulty:** Basic

### Problem
Build a REST API managing `notes` (id + content) with full CRUD:
- `GET /notes` — list all notes
- `POST /notes` — create a note (`content` required); return 201 or 400
- `GET /notes/<int:note_id>` — return one note, or 404
- `PUT /notes/<int:note_id>` — update `content`, or 404
- `DELETE /notes/<int:note_id>` — delete a note, or 404

### Concepts
- `request.get_json()` for request bodies
- Auto-incrementing IDs
- Returning proper status codes (`201`, `400`, `404`)

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

notes = []
next_id = 1


@app.route('/notes', methods=['GET'])
def list_notes():
    return jsonify(notes)


@app.route('/notes', methods=['POST'])
def create_note():
    global next_id
    data = request.get_json() or {}
    if 'content' not in data:
        return jsonify({'error': "'content' is required"}), 400
    note = {'id': next_id, 'content': data['content']}
    next_id += 1
    notes.append(note)
    return jsonify(note), 201


@app.route('/notes/<int:note_id>', methods=['GET'])
def get_note(note_id):
    note = next((n for n in notes if n['id'] == note_id), None)
    if note is None:
        return jsonify({'error': 'Note not found'}), 404
    return jsonify(note)


@app.route('/notes/<int:note_id>', methods=['PUT'])
def update_note(note_id):
    note = next((n for n in notes if n['id'] == note_id), None)
    if note is None:
        return jsonify({'error': 'Note not found'}), 404
    data = request.get_json() or {}
    note['content'] = data.get('content', note['content'])
    return jsonify(note)


@app.route('/notes/<int:note_id>', methods=['DELETE'])
def delete_note(note_id):
    global notes
    if not any(n['id'] == note_id for n in notes):
        return jsonify({'error': 'Note not found'}), 404
    notes = [n for n in notes if n['id'] != note_id]
    return jsonify({'message': f'Note {note_id} deleted'})


if __name__ == '__main__':
    app.run(debug=True)
```

**Test with curl:**
```bash
curl -X POST http://localhost:5000/notes -H "Content-Type: application/json" -d '{"content":"Buy groceries"}'
curl http://localhost:5000/notes
curl -X PUT http://localhost:5000/notes/1 -H "Content-Type: application/json" -d '{"content":"Buy groceries and milk"}'
curl -X DELETE http://localhost:5000/notes/1
```

## Exercise 3: Request-Logging Middleware & Custom Error Handlers

**Difficulty:** Basic

### Problem
Add middleware and error handling to a small API:
- Use `@app.before_request` to log every incoming request's method and path
- Register `@app.errorhandler(404)` and `@app.errorhandler(405)` to return consistent JSON error bodies
- Provide a single `GET /status` endpoint that returns `{"status": "ok"}`

### Concepts
- `@app.before_request` middleware
- `@app.errorhandler` for global JSON errors
- Logging to the console

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from flask import Flask, jsonify, request

app = Flask(__name__)


@app.before_request
def log_request():
    print(f"{request.method} {request.path}")


@app.route('/status')
def status():
    return jsonify({'status': 'ok'})


@app.errorhandler(404)
def not_found(error):
    return jsonify({'error': 'Resource not found'}), 404


@app.errorhandler(405)
def method_not_allowed(error):
    return jsonify({'error': 'Method not allowed'}), 405


if __name__ == '__main__':
    app.run(debug=True)
```

**Test with curl:**
```bash
curl http://localhost:5000/status
curl http://localhost:5000/nope     # 404 JSON
```
