## Exercise 1: App Setup + GET Endpoints
**Difficulty:** Basic
**Concepts:** app creation, routing, `jsonify`, list endpoint, health check

Create a Flask app with a health-check route and a route that returns all movies.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

movies = [
    {"id": 1, "title": "Inception", "year": 2010, "rating": 8.8},
    {"id": 2, "title": "The Matrix", "year": 1999, "rating": 8.7},
]

@app.route("/health", methods=["GET"])
def health():
    return jsonify({"status": "ok"})

@app.route("/movies", methods=["GET"])
def get_movies():
    return jsonify(movies)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /movies/count` endpoint that returns `{"count": len(movies)}`, and a `GET /movies/<title>` filter route.

## Exercise 2: POST + GET by ID (404 handling)
**Difficulty:** Basic
**Concepts:** POST, request body, `request.get_json()`, path parameters, 404

Add endpoints to create a movie and fetch a single movie by ID.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
movies = []
next_id = 1

@app.route("/movies", methods=["POST"])
def create_movie():
    global next_id
    data = request.get_json()
    movie = {
        "id": next_id,
        "title": data["title"],
        "year": data.get("year", 2024),
        "rating": data.get("rating"),
    }
    next_id += 1
    movies.append(movie)
    return jsonify(movie), 201

@app.route("/movies/<int:movie_id>", methods=["GET"])
def get_movie(movie_id):
    for movie in movies:
        if movie["id"] == movie_id:
            return jsonify(movie)
    return jsonify({"error": "Movie not found"}), 404
```

**Task:** Validate that `title` is present in the request body; if missing, return a 400 error with a descriptive message.

## Exercise 3: PUT + DELETE + Error Handler
**Difficulty:** Basic
**Concepts:** PUT, DELETE, updating records, `@app.errorhandler`

Add endpoints to update and delete a movie, plus a global error handler.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
movies = []

@app.route("/movies/<int:movie_id>", methods=["PUT"])
def update_movie(movie_id):
    data = request.get_json()
    for movie in movies:
        if movie["id"] == movie_id:
            movie["title"] = data.get("title", movie["title"])
            movie["year"] = data.get("year", movie["year"])
            movie["rating"] = data.get("rating", movie["rating"])
            return jsonify(movie)
    return jsonify({"error": "Movie not found"}), 404

@app.route("/movies/<int:movie_id>", methods=["DELETE"])
def delete_movie(movie_id):
    for movie in movies:
        if movie["id"] == movie_id:
            movies.remove(movie)
            return jsonify({"message": "Movie deleted"})
    return jsonify({"error": "Movie not found"}), 404

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404
```

**Task:** Add a `@app.errorhandler(405)` handler that returns a friendly JSON message when an HTTP method is not allowed.
