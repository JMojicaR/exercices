## Exercise 1: Read — List All and Get One Note
**Difficulty:** Basic
**Concepts:** `Flask` app, `@app.get` routes, path parameters, `jsonify`, 404 response

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

notes = [
    {"id": 1, "title": "Buy milk", "body": "Remember to buy milk"},
    {"id": 2, "title": "Call mom", "body": "Call mom on Sunday"},
]

@app.get("/notes")
def get_notes():
    return jsonify(notes)

@app.get("/notes/<int:note_id>")
def get_note(note_id):
    for note in notes:
        if note["id"] == note_id:
            return jsonify(note)
    return jsonify({"error": "Note not found"}), 404
```

**Task:** Run the app (`flask --app app run`) and hit both endpoints with a browser or `curl`. Confirm `/notes/3` returns a 404 with a JSON error body.

## Exercise 2: Create — POST with Validation
**Difficulty:** Basic
**Concepts:** `@app.post`, `request.get_json()`, input validation, `201` status, id generation

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
notes = []

@app.post("/notes")
def create_note():
    data = request.get_json()
    if not data or "title" not in data or "body" not in data:
        return jsonify({"error": "title and body are required"}), 400
    new_id = max((n["id"] for n in notes), default=0) + 1
    note = {"id": new_id, "title": data["title"], "body": data["body"]}
    notes.append(note)
    return jsonify(note), 201
```

**Task:** POST a note with `{"title": "Gym", "body": "Leg day"}` and confirm a `201` with the new id. Then POST an empty body and confirm a `400` error.

## Exercise 3: Update and Delete — PUT/DELETE + Error Handler
**Difficulty:** Basic
**Concepts:** `@app.put`, `@app.delete`, partial updates, removing by id, `@app.errorhandler`

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
notes = [{"id": 1, "title": "Buy milk", "body": "Remember"}]

@app.put("/notes/<int:note_id>")
def update_note(note_id):
    data = request.get_json()
    for note in notes:
        if note["id"] == note_id:
            if "title" in data:
                note["title"] = data["title"]
            if "body" in data:
                note["body"] = data["body"]
            return jsonify(note)
    return jsonify({"error": "Note not found"}), 404

@app.delete("/notes/<int:note_id>")
def delete_note(note_id):
    for i, note in enumerate(notes):
        if note["id"] == note_id:
            removed = notes.pop(i)
            return jsonify({"deleted": removed}), 200
    return jsonify({"error": "Note not found"}), 404

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404
```

**Task:** Update note `1`'s title, then DELETE it, then GET `/notes/1` and confirm it returns 404.
