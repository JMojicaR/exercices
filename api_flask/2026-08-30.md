## Exercise 1: Health Check + Welcome API

**Difficulty:** Basic

### Problem
Build a Flask API with two endpoints:
1. `GET /health` — returns `{"status": "ok"}`.
2. `GET /welcome?name=<string>` — returns a personalized greeting; default to `"Guest"` when `name` is absent.

**Example request:** `GET /welcome?name=Alice`

**Expected response:** `{"message": "Hello, Alice!"}`

### Concepts
- `@app.route` with `methods=['GET']`
- `request.args.get()` for query parameters
- `jsonify`

### HTTP Method(s)
`GET`

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/health', methods=['GET'])
def health():
    return jsonify({"status": "ok"})

@app.route('/welcome', methods=['GET'])
def welcome():
    name = request.args.get('name', 'Guest')
    return jsonify({"message": f"Hello, {name}!"})

if __name__ == '__main__':
    app.run(debug=True)
```

## Exercise 2: Products CRUD (in-memory)

**Difficulty:** Basic

### Problem
Build a Products API backed by an in-memory list. Implement:
1. `GET /products` — list all products.
2. `POST /products` — create a product from JSON `{"name": ..., "price": ...}`.
3. `GET /products/<id>` — fetch one product by id.
4. `PUT /products/<id>` — update a product.
5. `DELETE /products/<id>` — delete a product.

Return `201` on create and `404` for missing products.

### Concepts
- Route parameters (`<int:product_id>`)
- `request.get_json()`
- `jsonify` with status codes
- In-memory list with `append` and `remove`

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)
products = []
next_id = 1

@app.route('/products', methods=['GET'])
def list_products():
    return jsonify(products)

@app.route('/products', methods=['POST'])
def create_product():
    global next_id
    data = request.get_json()
    product = {"id": next_id, "name": data["name"], "price": data.get("price")}
    next_id += 1
    products.append(product)
    return jsonify(product), 201

@app.route('/products/<int:product_id>', methods=['GET', 'PUT', 'DELETE'])
def handle_product(product_id):
    product = next((p for p in products if p["id"] == product_id), None)
    if product is None:
        return jsonify({"error": "Product not found"}), 404
    if request.method == 'GET':
        return jsonify(product)
    if request.method == 'PUT':
        data = request.get_json()
        product["name"] = data.get("name", product["name"])
        product["price"] = data.get("price", product["price"])
        return jsonify(product)
    products.remove(product)
    return jsonify({"message": "Product deleted"})
```

## Exercise 3: Input Validation + JSON Error Handlers

**Difficulty:** Basic

### Problem
Build a `POST /products` endpoint that validates the request body and returns `400` when `name` is missing or `price` is not a number. Register JSON error handlers for `404` and `405`.

**Example request:** `POST /products` with body `{"price": 10}` (missing name)

**Expected response:** `400` → `{"error": "name and price are required"}`

### Concepts
- Validating `request.get_json()`
- `@app.errorhandler(404)` and `@app.errorhandler(405)`
- Returning JSON from error handlers

### HTTP Method(s)
`POST` (and any that hits the handlers)

### Example / Starter Code

```python
from flask import Flask, request, jsonify

app = Flask(__name__)
products = []

@app.route('/products', methods=['POST'])
def create_product():
    data = request.get_json()
    if not data or "name" not in data or "price" not in data:
        return jsonify({"error": "name and price are required"}), 400
    if not isinstance(data["price"], (int, float)):
        return jsonify({"error": "price must be a number"}), 400
    product = {"id": len(products) + 1, "name": data["name"], "price": data["price"]}
    products.append(product)
    return jsonify(product), 201

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

@app.errorhandler(405)
def method_not_allowed(error):
    return jsonify({"error": "Method not allowed"}), 405

if __name__ == '__main__':
    app.run(debug=True)
```
