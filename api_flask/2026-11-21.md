## Exercise 1: POST /tasks — Create a Task
**Difficulty:** Basic
**Concepts:** Flask `@app.route`, `request.get_json()`, POST endpoint, request body parsing, response JSON

Create a `POST /tasks` endpoint that accepts a JSON body with a `name` and pushes it onto an in-memory stack.

**Starter code:**
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

tasks = []   # in-memory stack (LIFO)

@app.route("/tasks", methods=["POST"])
def create_task():
    data = request.get_json()
    if not data or "name" not in data:
        return jsonify({"error": "name is required"}), 400
    task = {"id": len(tasks) + 1, "name": data["name"]}
    tasks.append(task)   # push
    return jsonify(task), 201

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `"priority"` field that defaults to `"normal"` when not provided, and include it in the returned task.

## Exercise 2: GET /tasks — List Tasks (with Peek)
**Difficulty:** Basic
**Concepts:** GET endpoint, returning lists as JSON, top-of-stack peek, 404 on empty

Add endpoints to list all tasks and to peek at the most recently added task (top of stack).

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

tasks = []

@app.route("/tasks", methods=["GET"])
def list_tasks():
    return jsonify(tasks)

@app.route("/tasks/top", methods=["GET"])
def peek_task():
    if not tasks:
        return jsonify({"error": "no tasks"}), 404
    return jsonify(tasks[-1])   # top of stack (LIFO)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /tasks/count` endpoint that returns `{"count": len(tasks)}`.

## Exercise 3: DELETE /tasks/<id> — Remove a Task + Error Handler
**Difficulty:** Basic
**Concepts:** DELETE endpoint, URL path parameter, 404 handling, `@app.errorhandler`, basic CRUD

Add a `DELETE /tasks/<int:task_id>` endpoint to remove a task by id, plus a custom 404 error handler.

**Starter code:**
```python
from flask import Flask, jsonify, abort

app = Flask(__name__)

tasks = [{"id": 1, "name": "write-report"}]

@app.route("/tasks/<int:task_id>", methods=["DELETE"])
def delete_task(task_id):
    global tasks
    for i, t in enumerate(tasks):
        if t["id"] == task_id:
            removed = tasks.pop(i)
            return jsonify({"deleted": removed})
    abort(404)

@app.errorhandler(404)
def not_found(e):
    return jsonify({"error": "resource not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `DELETE /tasks` endpoint that clears the entire stack (all tasks) and returns the number of tasks that were removed.
