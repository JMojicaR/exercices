## Exercise 1: Math Utility API (GET query params + POST JSON)
**Difficulty:** Basic
### Problem
Build a small math utility API:
1. `GET /factorial?n=<int>` — return the factorial of `n` as JSON.
2. `GET /fibonacci?n=<int>` — return the first `n` Fibonacci numbers as a JSON array.
3. `POST /is-prime` — accept JSON `{"n": <int>}` and return whether it is prime.
Return a JSON error for invalid input (e.g. negative `n`).

### Concepts
- `@app.route` with `methods=[...]`
- `request.args.get(...)` for query parameters
- `request.get_json()` for JSON bodies
- `jsonify` for JSON responses

### HTTP Method(s)
`GET`, `POST`

### Example / Starter Code
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

def factorial(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

def fibonacci(n):
    seq, a, b = [], 0, 1
    for _ in range(n):
        seq.append(a)
        a, b = b, a + b
    return seq

def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

@app.route('/factorial')
def factorial_route():
    n = int(request.args.get('n', 0))
    if n < 0:
        return jsonify({"error": "n must be non-negative"}), 400
    return jsonify({"n": n, "factorial": factorial(n)})

@app.route('/fibonacci')
def fibonacci_route():
    n = int(request.args.get('n', 0))
    if n < 0:
        return jsonify({"error": "n must be non-negative"}), 400
    return jsonify({"n": n, "fibonacci": fibonacci(n)})

@app.route('/is-prime', methods=['POST'])
def is_prime_route():
    data = request.get_json()
    n = data.get('n')
    if n is None:
        return jsonify({"error": "missing 'n'"}), 400
    return jsonify({"n": n, "is_prime": is_prime(n)})

if __name__ == '__main__':
    app.run(debug=True)
```
**Test with curl:**
```bash
curl "http://127.0.0.1:5000/factorial?n=5"
curl "http://127.0.0.1:5000/fibonacci?n=10"
curl -X POST http://127.0.0.1:5000/is-prime \
  -H "Content-Type: application/json" \
  -d '{"n": 17}'
```

## Exercise 2: Books Library CRUD API (in-memory)
**Difficulty:** Basic
### Problem
Build a full in-memory CRUD API for books:
- `GET /books` — list all books.
- `POST /books` — create a book from JSON `{"title", "author"}` (auto-increment `id`).
- `GET /books/<int:id>` — return one book or 404.
- `PUT /books/<int:id>` — update title/author or 404.
- `DELETE /books/<int:id>` — remove one book or 404.

### Concepts
- RESTful routing with `<int:id>` converters
- In-memory dict storage with auto-incrementing id
- Correct status codes (`201` on create, `404` on missing)

### HTTP Method(s)
`GET`, `POST`, `PUT`, `DELETE`

### Example / Starter Code
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

books = {}
next_id = 1

@app.route('/books', methods=['GET'])
def list_books():
    return jsonify(list(books.values()))

@app.route('/books', methods=['POST'])
def create_book():
    global next_id
    data = request.get_json()
    book = {"id": next_id, "title": data["title"], "author": data.get("author", "")}
    books[next_id] = book
    next_id += 1
    return jsonify(book), 201

@app.route('/books/<int:book_id>', methods=['GET'])
def get_book(book_id):
    book = books.get(book_id)
    if book is None:
        return jsonify({"error": "Book not found"}), 404
    return jsonify(book)

@app.route('/books/<int:book_id>', methods=['PUT'])
def update_book(book_id):
    book = books.get(book_id)
    if book is None:
        return jsonify({"error": "Book not found"}), 404
    data = request.get_json()
    book["title"] = data.get("title", book["title"])
    book["author"] = data.get("author", book["author"])
    return jsonify(book)

@app.route('/books/<int:book_id>', methods=['DELETE'])
def delete_book(book_id):
    if book_id not in books:
        return jsonify({"error": "Book not found"}), 404
    del books[book_id]
    return jsonify({"message": "Book deleted"})

if __name__ == '__main__':
    app.run(debug=True)
```
**Test with curl:**
```bash
curl http://127.0.0.1:5000/books
curl -X POST http://127.0.0.1:5000/books \
  -H "Content-Type: application/json" \
  -d '{"title": "Clean Code", "author": "Robert C. Martin"}'
curl http://127.0.0.1:5000/books/1
curl -X PUT http://127.0.0.1:5000/books/1 \
  -H "Content-Type: application/json" \
  -d '{"author": "R. Martin"}'
curl -X DELETE http://127.0.0.1:5000/books/1
```

## Exercise 3: Request Validation + Global JSON Error Handlers + Middleware
**Difficulty:** Basic
### Problem
Add request validation, a custom `before_request` middleware, and global JSON error handlers:
1. Use `@app.before_request` to add a custom response header (e.g. `X-Powered-By`).
2. Register global handlers for `404` and `405` that return JSON instead of HTML.
3. Add a `GET /divide` route that validates query params and returns a JSON error for division by zero or missing params.

### Concepts
- `@app.before_request` as middleware
- `@app.errorhandler(code)` for global error handlers
- Manual input validation returning `400`

### HTTP Method(s)
`GET`

### Example / Starter Code
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.before_request
def log_request():
    app.logger.info(f"{request.method} {request.path}")

@app.after_request
def set_header(response):
    response.headers['X-Powered-By'] = 'Flask-Exercises'
    return response

@app.errorhandler(404)
def not_found(e):
    return jsonify({"error": "Resource not found"}), 404

@app.errorhandler(405)
def method_not_allowed(e):
    return jsonify({"error": "Method not allowed"}), 405

@app.route('/divide')
def divide():
    a = request.args.get('a')
    b = request.args.get('b')
    if a is None or b is None:
        return jsonify({"error": "Missing query params 'a' or 'b'"}), 400
    b = int(b)
    if b == 0:
        return jsonify({"error": "Cannot divide by zero"}), 400
    return jsonify({"result": int(a) / b})

if __name__ == '__main__':
    app.run(debug=True)
```
**Test with curl:**
```bash
curl "http://127.0.0.1:5000/divide?a=10&b=4"
curl "http://127.0.0.1:5000/divide?a=10&b=0"
curl "http://127.0.0.1:5000/nope"          # triggers 404 handler
curl -X POST http://127.0.0.1:5000/divide # triggers 405 handler
```
