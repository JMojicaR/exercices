## Exercise 1: App + GET /recipes + GET /health
**Difficulty:** Basic
**Concepts:** routing, jsonify, Flask app

Create a Flask app that serves a list of recipes as JSON plus a health-check endpoint.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

recipes = [
    {"id": 1, "name": "Pancakes", "difficulty": "easy"},
    {"id": 2, "name": "Tacos", "difficulty": "medium"},
]

@app.route("/health")
def health():
    return jsonify({"status": "ok"})

@app.route("/recipes")
def get_recipes():
    return jsonify(recipes)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a GET /recipes/count endpoint that returns the number of recipes as JSON.

## Exercise 2: POST /recipes + GET /recipes/<id> + 404 handling
**Difficulty:** Basic
**Concepts:** POST, URL parameters, 404 responses

Let clients add recipes and fetch one recipe by id, returning 404 when missing.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

recipes = [
    {"id": 1, "name": "Pancakes", "difficulty": "easy"},
]

@app.route("/recipes", methods=["GET", "POST"])
def recipes_collection():
    if request.method == "POST":
        data = request.get_json()
        recipe = {"id": len(recipes) + 1, **data}
        recipes.append(recipe)
        return jsonify(recipe), 201
    return jsonify(recipes)

@app.route("/recipes/<int:recipe_id>")
def get_recipe(recipe_id):
    for recipe in recipes:
        if recipe["id"] == recipe_id:
            return jsonify(recipe)
    return jsonify({"error": "recipe not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Reject POST requests whose JSON body lacks a "name" field with a 400 response.

## Exercise 3: PUT/DELETE + @app.errorhandler middleware
**Difficulty:** Basic
**Concepts:** PUT, DELETE, error handler middleware

Add update and delete endpoints plus a global error handler for bad JSON.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

recipes = [
    {"id": 1, "name": "Pancakes", "difficulty": "easy"},
]

@app.errorhandler(400)
def bad_request(error):
    return jsonify({"error": "bad request"}), 400

@app.route("/recipes", methods=["GET", "POST"])
def recipes_collection():
    if request.method == "POST":
        data = request.get_json()
        recipe = {"id": len(recipes) + 1, **data}
        recipes.append(recipe)
        return jsonify(recipe), 201
    return jsonify(recipes)

@app.route("/recipes/<int:recipe_id>", methods=["PUT", "DELETE"])
def recipe_detail(recipe_id):
    for recipe in recipes:
        if recipe["id"] == recipe_id:
            if request.method == "DELETE":
                recipes.remove(recipe)
                return jsonify({"message": "deleted"}), 200
            data = request.get_json()
            recipe.update(data)
            return jsonify(recipe), 200
    return jsonify({"error": "recipe not found"}), 404

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a 404 error handler that returns JSON instead of the default HTML error page.
