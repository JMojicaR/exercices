## Exercise 1: App Setup + GET Endpoints
**Difficulty:** Basic
**Concepts:** app creation, routing, `jsonify`, list endpoint, health check

Create a Flask app with a health-check route and a route that returns all songs.

**Starter code:**
```python
from flask import Flask, jsonify

app = Flask(__name__)

songs = [
    {"id": 1, "title": "Bohemian Rhapsody", "artist": "Queen", "duration": 354},
    {"id": 2, "title": "Billie Jean", "artist": "Michael Jackson", "duration": 294},
]

@app.route("/health", methods=["GET"])
def health():
    return jsonify({"status": "ok"})

@app.route("/songs", methods=["GET"])
def get_songs():
    return jsonify(songs)

if __name__ == "__main__":
    app.run(debug=True)
```

**Task:** Add a `GET /songs/count` endpoint returning `{"count": len(songs)}`, and a `GET /songs/<artist>` route that filters by artist.

## Exercise 2: POST + GET by ID (404 handling)
**Difficulty:** Basic
**Concepts:** POST, request body, `request.get_json()`, path parameters, 404

Add endpoints to create a song and fetch a single song by ID.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
songs = []
next_id = 1

@app.route("/songs", methods=["POST"])
def create_song():
    global next_id
    data = request.get_json()
    song = {
        "id": next_id,
        "title": data["title"],
        "artist": data.get("artist", "Unknown"),
        "duration": data.get("duration"),
    }
    next_id += 1
    songs.append(song)
    return jsonify(song), 201

@app.route("/songs/<int:song_id>", methods=["GET"])
def get_song(song_id):
    for song in songs:
        if song["id"] == song_id:
            return jsonify(song)
    return jsonify({"error": "Song not found"}), 404
```

**Task:** Validate that `title` is present in the request body; if missing, return a 400 error with a descriptive message.

## Exercise 3: PUT + DELETE + Error Handler
**Difficulty:** Basic
**Concepts:** PUT, DELETE, updating records, `@app.errorhandler`

Add endpoints to update and delete a song, plus a global error handler.

**Starter code:**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
songs = []

@app.route("/songs/<int:song_id>", methods=["PUT"])
def update_song(song_id):
    data = request.get_json()
    for song in songs:
        if song["id"] == song_id:
            song["title"] = data.get("title", song["title"])
            song["artist"] = data.get("artist", song["artist"])
            song["duration"] = data.get("duration", song["duration"])
            return jsonify(song)
    return jsonify({"error": "Song not found"}), 404

@app.route("/songs/<int:song_id>", methods=["DELETE"])
def delete_song(song_id):
    for song in songs:
        if song["id"] == song_id:
            songs.remove(song)
            return jsonify({"message": "Song deleted"})
    return jsonify({"error": "Song not found"}), 404

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404
```

**Task:** Add a `@app.errorhandler(405)` handler that returns a friendly JSON message when an HTTP method is not allowed.
