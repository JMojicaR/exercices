## Exercise 1: Hello World

**Difficulty:** Basic

### Problem
Write an Erlang module that exports a function `hello/0` which prints "Hello, World!" using `io:format`.

**Expected Output:**
```
Hello, World!
```

### Concepts
- Modules (`-module`, `-export`)
- `io:format/2`
- Function clauses

### Example / Starter Code

```erlang
-module(hello).
-export([hello/0]).

hello() ->
    io:format("Hello, World!~n").
```

## Exercise 2: Even or Odd

**Difficulty:** Basic

### Problem
Write an Erlang function `even_or_odd/1` that returns the atom `even` or `odd` for a given integer, using guards.

**Given Input:** `even_or_odd(7)`

**Expected Output:**
```
odd
```

### Concepts
- Guards with `rem`
- Multiple function clauses

### Example / Starter Code

```erlang
-module(even_odd).
-export([even_or_odd/1]).

even_or_odd(N) when N rem 2 =:= 0 -> even;
even_or_odd(_N) -> odd.
```

## Exercise 3: Sum of Numbers 1 to N

**Difficulty:** Basic

### Problem
Write an Erlang function `sum_to_n/1` that returns the sum of all integers from 1 to `N`. Do it first with `lists:seq/2` + `lists:sum/1`, then write a tail-recursive version.

**Given Input:** `sum_to_n(10)`

**Expected Output:**
```
55
```

### Concepts
- `lists:seq/2` and `lists:sum/1`
- Tail recursion with an accumulator

### Example / Starter Code

```erlang
-module(sum_to_n).
-export([sum_to_n/1, sum_to_n_rec/1]).

sum_to_n(N) ->
    lists:sum(lists:seq(1, N)).

sum_to_n_rec(N) -> sum_to_n_rec(N, 0).

sum_to_n_rec(0, Acc) -> Acc;
sum_to_n_rec(N, Acc) -> sum_to_n_rec(N - 1, Acc + N).
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write an Erlang function `count_vowels/1` that counts the vowels (a, e, i, o, u) in a string, ignoring case.

**Given Input:** `count_vowels("Hello World")`

**Expected Output:**
```
3
```

### Concepts
- Strings as lists of characters
- Recursion over a list
- `string:lowercase/1` and `lists:member/2`

### Example / Starter Code

```erlang
-module(count_vowels).
-export([count_vowels/1]).

count_vowels(Str) ->
    count_vowels(string:lowercase(Str), 0).

count_vowels([], Acc) -> Acc;
count_vowels([H | T], Acc) ->
    case lists:member(H, "aeiou") of
        true  -> count_vowels(T, Acc + 1);
        false -> count_vowels(T, Acc)
    end.
```

## Exercise 5: Sum of a List

**Difficulty:** Basic

### Problem
Write an Erlang function `sum_list/1` that sums a list of integers using recursion.

**Given Input:** `sum_list([10, 20, 30, 40, 50])`

**Expected Output:**
```
150
```

### Concepts
- Pattern matching on list head/tail
- Recursion with a base case

### Example / Starter Code

```erlang
-module(sum_list).
-export([sum_list/1]).

sum_list([]) -> 0;
sum_list([H | T]) -> H + sum_list(T).
```
