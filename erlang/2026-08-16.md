## Exercise 1: Even or Odd Check

**Difficulty:** Basic

### Problem
Write a module with a function `check/1` that returns the atom `even` or `odd` for a given integer.

**Given Input:** `even_odd:check(7).`

**Expected Output:**
```
odd
```

### Concepts
- Module and `-export` declarations
- Pattern matching with `case ... of`
- The `rem` operator

### Example / Starter Code

```erlang
-module(even_odd).
-export([check/1]).

check(N) ->
    case N rem 2 of
        0 -> even;
        _ -> odd
    end.
```

**Usage in the Erlang shell:**
```erlang
1> c(even_odd).
2> even_odd:check(7).
odd
3> even_odd:check(4).
even
```

## Exercise 2: Length of a List

**Difficulty:** Basic

### Problem
Write a function `len/1` that returns the number of elements in a list using recursion (not the built-in `length/1`).

**Given Input:** `list_len:len([1, 2, 3, 4]).`

**Expected Output:**
```
4
```

### Concepts
- Recursion over a list head/tail
- Pattern matching on `[]` and `[Head | Tail]`
- Accumulating a count

### Example / Starter Code

```erlang
-module(list_len).
-export([len/1]).

len([]) -> 0;
len([_ | Tail]) -> 1 + len(Tail).
```

**Usage:**
```erlang
1> c(list_len).
2> list_len:len([a, b, c, d]).
4
```

## Exercise 3: Maximum Element in a List

**Difficulty:** Basic

### Problem
Write a function `max/1` that returns the largest element of a non-empty list of numbers.

**Given Input:** `list_max:max([3, 9, 2, 8]).`

**Expected Output:**
```
9
```

### Concepts
- Recursion with a base case of a single element
- `if` expression with guards
- Comparing the head with the recursive result

### Example / Starter Code

```erlang
-module(list_max).
-export([max/1]).

max([H]) -> H;
max([H | T]) ->
    MaxT = max(T),
    if H >= MaxT -> H;
       true -> MaxT
    end.
```

**Usage:**
```erlang
1> c(list_max).
2> list_max:max([3, 9, 2, 8]).
9
```

## Exercise 4: Nth Fibonacci Number

**Difficulty:** Basic

### Problem
Write a function `fib/1` that returns the Nth Fibonacci number (`fib(0) = 0`, `fib(1) = 1`).

**Given Input:** `fib:fib(10).`

**Expected Output:**
```
55
```

### Concepts
- Multiple function clauses
- Recursion with two base cases
- Guards (`when N > 1`)

### Example / Starter Code

```erlang
-module(fib).
-export([fib/1]).

fib(0) -> 0;
fib(1) -> 1;
fib(N) when N > 1 -> fib(N - 1) + fib(N - 2).
```

**Usage:**
```erlang
1> c(fib).
2> fib:fib(10).
55
```

## Exercise 5: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a function `count/1` that counts how many vowels (`a, e, i, o, u`, case-insensitive) appear in a string.

**Given Input:** `count_vowels:count("Hello World").`

**Expected Output:**
```
3
```

### Concepts
- Iterating over a string as a list of characters
- Character literals with `$a`, `$e`, etc.
- Pattern matching in a `case` expression

### Example / Starter Code

```erlang
-module(count_vowels).
-export([count/1]).

count(Str) -> count_chars(Str, 0).

count_chars([], N) -> N;
count_chars([H | T], N) ->
    case H of
        $a -> count_chars(T, N + 1);
        $e -> count_chars(T, N + 1);
        $i -> count_chars(T, N + 1);
        $o -> count_chars(T, N + 1);
        $u -> count_chars(T, N + 1);
        $A -> count_chars(T, N + 1);
        $E -> count_chars(T, N + 1);
        $I -> count_chars(T, N + 1);
        $O -> count_chars(T, N + 1);
        $U -> count_chars(T, N + 1);
        _ -> count_chars(T, N)
    end.
```

**Usage:**
```erlang
1> c(count_vowels).
2> count_vowels:count("Hello World").
3
```
