factorial(N) when N > 0 ->
    %% TODO: N * factorial(N-1)

## Exercise 4: FizzBuzz — Pattern Matching & Guards

| Field | Detail |
|-------|--------|
| **Difficulty** | ★★☆☆☆ |
| **Concepts** | Guards (`rem`), `lists:foreach/2`, `lists:seq/2`, function clauses |

**Description:**  
Write a function `fizzbuzz/0` that prints numbers 1 to 100 with FizzBuzz rules using `lists:foreach` and `lists:seq`, delegating to a pattern-matched helper function.

**Starter Code:**
```erlang
-module(fizzbuzz).
-export([run/0]).

run() ->
    lists:foreach(fun fizzbuzz/1, lists:seq(1, 100)).

fizzbuzz(N) when N rem 15 =:= 0 -> io:format("FizzBuzz~n");
fizzbuzz(N) when N rem 3 =:= 0  -> io:format("Fizz~n");
fizzbuzz(N) when N rem 5 =:= 0  -> io:format("Buzz~n");
fizzbuzz(N)                      -> io:format("~p~n", [N]).
```

## Exercise 5: Simple Message Passing — spawn, ! (send), receive

| Field | Detail |
|-------|--------|
| **Difficulty** | ★★★☆☆ |
| **Concepts** | `spawn/1`, `!` (send), `receive ... end`, process IDs, `self()` |

**Description:**  
Create a simple "ping-pong" system:
- Spawn a process that waits for a `{ping, From}` message, prints `"pong"`, and sends `{pong, self()}` back.
- From the shell, send it a `{ping, self()}` message and receive the reply.

**Starter Code:**
```erlang
-module(ping_pong).
-export([start/0, pong_loop/0]).

pong_loop() ->
    receive
        {ping, From} ->
            io:format("Received ping, sending pong~n"),
            From ! {pong, self()},
            pong_loop();
        stop ->
            io:format("Stopping~n"),
            ok
    end.

start() ->
    Pid = spawn(?MODULE, pong_loop, []),
    Pid ! {ping, self()},
    receive
        {pong, Pid} ->
            io:format("Got pong back!~n")
    end,
    Pid ! stop.
```

**Test in shell:**
```erlang
ping_pong:start().
%% Expected: Received ping, sending pong
%%           Got pong back!
%%           Stopping
```
