## Exercise 1: Factorial (Recursion)

**Difficulty:** Basic

### Problem
Write a module with a function `fact/1` that returns the factorial of a non-negative integer using recursion.

**Given Input:** `fact:fact(5).`

**Expected Output:**
```
120
```

### Concepts
- Modules and `-export`
- Pattern matching on function clauses
- Recursion

### Example / Starter Code

```erlang
-module(fact).
-export([fact/1]).

fact(0) -> 1;
fact(N) when N > 0 -> N * fact(N - 1).

%% In the shell:
%% 1> c(fact).
%% 2> fact:fact(5).
%% 120
```

## Exercise 2: Fibonacci (Recursion)

**Difficulty:** Basic

### Problem
Write a function `fib/1` that returns the N-th Fibonacci number (0-indexed: fib(0) -> 0, fib(1) -> 1) using recursion.

**Given Input:** `fib:fib(10).`

**Expected Output:**
```
55
```

### Concepts
- Multiple function clauses
- Base cases
- Recursive calls

### Example / Starter Code

```erlang
-module(fib).
-export([fib/1]).

fib(0) -> 0;
fib(1) -> 1;
fib(N) when N > 1 -> fib(N - 1) + fib(N - 2).

%% In the shell:
%% 1> c(fib).
%% 2> fib:fib(10).
%% 55
```

## Exercise 3: Palindrome (Lists)

**Difficulty:** Basic

### Problem
Write a function `is_palindrome/1` that returns `true` if a list (or string) equals its own reverse.

**Given Input:** `pal:is_palindrome("racecar").`

**Expected Output:**
```
true
```

### Concepts
- `lists:reverse/1`
- Lists vs strings
- Equality comparison

### Example / Starter Code

```erlang
-module(pal).
-export([is_palindrome/1]).

is_palindrome(L) -> L =:= lists:reverse(L).

%% In the shell:
%% 1> c(pal).
%% 2> pal:is_palindrome("racecar").
%% true
%% 3> pal:is_palindrome("hello").
%% false
```

## Exercise 4: Prime Number Check (Guards + Recursion)

**Difficulty:** Basic

### Problem
Write a function `is_prime/1` that returns `true` if a number is prime using a helper function and guards.

**Given Input:** `prime:is_prime(17).`

**Expected Output:**
```
true
```

### Concepts
- Guards (`when`)
- Tail recursion with an accumulator/helper
- `rem` operator

### Example / Starter Code

```erlang
-module(prime).
-export([is_prime/1]).

is_prime(N) when N < 2 -> false;
is_prime(N) -> is_prime(N, 2).

is_prime(N, D) when D * D > N -> true;
is_prime(N, D) when N rem D =:= 0 -> false;
is_prime(N, D) -> is_prime(N, D + 1).

%% In the shell:
%% 1> c(prime).
%% 2> prime:is_prime(17).
%% true
%% 3> prime:is_prime(15).
%% false
```

## Exercise 5: Reverse a List (Recursion)

**Difficulty:** Basic

### Problem
Write your own `reverse/1` function using recursion (do not use `lists:reverse/1`) that returns a list in reverse order.

**Given Input:** `rev:reverse([1, 2, 3, 4, 5]).`

**Expected Output:**
```
[5,4,3,2,1]
```

### Concepts
- List construction `[H | T]`
- Accumulator pattern
- Tail recursion

### Example / Starter Code

```erlang
-module(rev).
-export([reverse/1]).

reverse(List) -> reverse(List, []).

reverse([], Acc) -> Acc;
reverse([H | T], Acc) -> reverse(T, [H | Acc]).

%% In the shell:
%% 1> c(rev).
%% 2> rev:reverse([1, 2, 3, 4, 5]).
%% [5,4,3,2,1]
```
