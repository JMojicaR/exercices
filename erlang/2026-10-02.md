## Exercise 1: Hello Module and a Double Function
**Difficulty:** Basic
**Concepts:** Modules, exports, function clauses, compiling (`c(module).`), calling.

Create a module with a `hello/0` function and a `double/1` function, then compile and test it in the Erlang shell.

**Starter code:**
```erlang
-module(demo).
-export([hello/0, double/1]).

hello() ->
    io:format("Hello, Erlang!~n").

double(N) ->
    N * 2.
```

**Usage:**
```erlang
c(demo).
demo:hello().      % Hello, Erlang!
demo:double(12).   % 24
```

**Task:** Add a `triple/1` function and a `greet/1` function that prints "Hello, {Name}!".

## Exercise 2: Even or Odd with Guards
**Difficulty:** Basic
**Concepts:** Function clauses, guards (`when`), `rem`.

Write a function `classify/1` that returns `even` or `odd` using two clauses with guards.

**Starter code:**
```erlang
-module(classify).
-export([classify/1]).

classify(N) when N rem 2 =:= 0 -> even;
classify(_N) -> odd.
```

**Usage:**
```erlang
c(classify).
classify:classify(4).   % even
classify:classify(7).   % odd
```

**Task:** Add a `sign/1` function that returns `positive`, `negative`, or `zero` using three clauses.

## Exercise 3: Factorial (Recursion)
**Difficulty:** Basic
**Concepts:** Recursion, base case, pattern matching on `0`.

Write a recursive function that computes the factorial of a non-negative integer.

**Starter code:**
```erlang
-module(math_fun).
-export([factorial/1]).

factorial(0) -> 1;
factorial(N) when N > 0 -> N * factorial(N - 1).
```

**Usage:**
```erlang
c(math_fun).
math_fun:factorial(5).   % 120
math_fun:factorial(0).   % 1
```

**Task:** Reimplement it with tail recursion using an accumulator (`factorial(N, Acc)`).

## Exercise 4: Sum of a List (Tail Recursion)
**Difficulty:** Basic
**Concepts:** List pattern matching (`[H|T]`), recursion, accumulator.

Write a function that sums all the numbers in a list.

**Starter code:**
```erlang
-module(list_sum).
-export([sum/1]).

sum(List) ->
    sum(List, 0).

sum([], Acc) -> Acc;
sum([H | T], Acc) -> sum(T, Acc + H).
```

**Usage:**
```erlang
c(list_sum).
list_sum:sum([1, 2, 3, 4, 5]).   % 15
```

**Task:** Add a `product/1` function that multiplies the list elements together.

## Exercise 5: Square Every Number (map + list comprehension)
**Difficulty:** Basic
**Concepts:** `lists:map/2`, list comprehensions, anonymous functions (`fun`).

Write a function that squares every number in a list, once with `lists:map/2` and once with a list comprehension.

**Starter code:**
```erlang
-module(square).
-export([square_map/1, square_comp/1]).

square_map(List) ->
    lists:map(fun(X) -> X * X end, List).

square_comp(List) ->
    [X * X || X <- List].
```

**Usage:**
```erlang
c(square).
square:square_map([1, 2, 3]).    % [1, 4, 9]
square:square_comp([4, 5]).      % [16, 25]
```

**Task:** Write a `filter_even/1` function that returns only the even numbers using `lists:filter/2` or a comprehension.
