## Exercise 1: List as a Stack
**Difficulty:** Basic
**Concepts:** cons (`[H|T]`), LIFO via head insertion, recursion

In Erlang, a list is a natural stack: push by consing onto the front, pop by matching the head.

**Starter code:**
```erlang
-module(stack_demo).
-export([push/2, pop/1, peek/1]).

push(Item, Stack) -> [Item | Stack].   % push (cons onto front)

pop([H | T]) -> {ok, H, T};            % pop head
pop([]) -> empty.

peek([H | _]) -> {ok, H};
peek([]) -> empty.

% Usage:
% 1> c(stack_demo).
% 2> S0 = stack_demo:push(a, []),
% 2> S1 = stack_demo:push(b, S0),
% 2> S2 = stack_demo:push(c, S1).       % [c, b, a]
% 3> stack_demo:pop(S2).                % {ok, c, [b, a]}
```

**Task:** Add a `size/1` function that counts the number of elements in the stack using recursion, and test it on `[c, b, a]` (should return `3`).

## Exercise 2: The `queue` Module
**Difficulty:** Basic
**Concepts:** `queue:new`, `queue:in` (enqueue), `queue:out` (dequeue), FIFO order

Erlang's `queue` module provides FIFO queues with O(1) amortized operations.

**Starter code:**
```erlang
-module(queue_demo).
-export([demo/0]).

demo() ->
    Q0 = queue:new(),
    Q1 = queue:in(a, Q0),              % enqueue
    Q2 = queue:in(b, Q1),
    Q3 = queue:in(c, Q2),
    {{value, First}, Q4} = queue:out(Q3),   % dequeue (front)
    First.                              % returns a
```

**Task:** Write a function `drain/1` that dequeues every element of a queue and returns them as a list (in FIFO order). Test it on `queue:from_list([1,2,3])` and confirm the result is `[1,2,3]`.

## Exercise 3: Balanced Parentheses Checker
**Difficulty:** Basic
**Concepts:** list stack, recursion over a string, pattern matching, early failure

Use a list as a stack of characters to check balanced brackets.

**Starter code:**
```erlang
-module(balanced).
-export([is_balanced/1]).

is_balanced(Str) ->
    check(Str, []).

check([], Stack) ->
    Stack =:= [];
check([H | T], Stack) when H =:= $(; H =:= $[; H =:= ${ ->
    check(T, [H | Stack]);
check([H | T], [Open | Rest]) when H =:= $); H =:= $]; H =:= $} ->
    case {Open, H} of
        {$(, $)} -> check(T, Rest);
        {$[, $]} -> check(T, Rest);
        {${, $}} -> check(T, Rest);
        _ -> false
    end;
check([H | T], []) when H =:= $); H =:= $]; H =:= $} ->
    false;
check([_ | T], Stack) ->
    check(T, Stack).
```

**Task:** Add a test for the string `"((("` and confirm it returns `false` (unmatched openers remain on the stack).

## Exercise 4: Reverse a List Using an Accumulator
**Difficulty:** Basic
**Concepts:** tail recursion with an accumulator, `lists:reverse` equivalence

Reverse a list by pushing each element onto an accumulator (a stack) and returning it.

**Starter code:**
```erlang
-module(reverse_demo).
-export([reverse_list/1]).

reverse_list(List) -> reverse_list(List, []).

reverse_list([H | T], Acc) -> reverse_list(T, [H | Acc]);
reverse_list([], Acc) -> Acc.
```

**Task:** Verify `reverse_list("hello")` returns `"olleh"` (strings are lists of characters in Erlang), and compare it to `lists:reverse("hello")`.

## Exercise 5: FIFO with the `queue` Module
**Difficulty:** Basic
**Concepts:** `queue:from_list`, `queue:out`, `queue:len`, processing in arrival order

Process a job queue in FIFO order using the `queue` module.

**Starter code:**
```erlang
-module(job_queue).
-export([process/0]).

process() ->
    Q = queue:from_list(["download", "compile", "deploy"]),
    drain(Q).

drain(Q) ->
    case queue:out(Q) of
        {empty, _} ->
            done;
        {{value, Job}, Rest} ->
            io:format("Processing: ~s~n", [Job]),
            drain(Rest)
    end.
```

**Task:** Add a `queue:len(Q)` call so the function prints the number of remaining jobs before each one is processed.
