## Exercise 1: Factorial Using Recursion

### Problem
Write an Erlang module with a function `factorial/1` that computes the factorial of a non-negative integer using recursion. The factorial of N (written N!) is the product of all positive integers from 1 to N. By definition, `0! = 1`.

### Concepts
- Module declaration (`-module`, `-export`)
- Recursive functions
- Guards (`when N == 0`, `when N > 0`)
- Pattern matching on function clauses
- `io:format/2`

### Example/Starter Code
```erlang
-module(factorial_ex).
-export([factorial/1]).

factorial(0) ->
    1;
factorial(N) when N > 0 ->
    % TODO: Return N * factorial(N-1)
    ok.

% Test in the Erlang shell:
% c(factorial_ex).
% factorial_ex:factorial(5).  %% Should return 120
```

## Exercise 2: List Length Using Pattern Matching

### Problem
Write an Erlang function `list_len/1` that computes the length of a list using recursion and pattern matching. When the list is empty, return 0. For a non-empty list `[H|T]`, return `1 + list_len(T)`.

### Concepts
- List pattern matching (`[H|T]`, `[]`)
- Recursive list processing
- Base case vs recursive case
- `io:format/2`

### Example/Starter Code
```erlang
-module(list_len_ex).
-export([list_len/1]).

list_len([]) ->
    0;
list_len([_Head | Tail]) ->
    % TODO: Return 1 + list_len(Tail)
    ok.

% Test:
% c(list_len_ex).
% list_len_ex:list_len([a, b, c, d]).  %% Should return 4
```

## Exercise 4: Reverse a List Using Tail Recursion

### Problem
Write an Erlang function `reverse/1` that reverses a list using tail recursion with an accumulator. A tail-recursive function keeps an extra parameter (the accumulator) to store intermediate results, avoiding stack growth. The public function `reverse/1` should call a private helper `reverse/2` with an empty accumulator.

### Concepts
- Tail recursion (no growing stack)
- Accumulator pattern
- Public/private functions (exported vs non-exported)
- Pattern matching on base case

### Example/Starter Code
```erlang
-module(reverse_ex).
-export([reverse/1]).

reverse(List) ->
    reverse(List, []).  % Call helper with empty accumulator

reverse([], Acc) ->
    Acc;
reverse([Head | Tail], Acc) ->
    % TODO: Recursively call reverse(Tail, [Head | Acc])
    ok.

% Test:
% c(reverse_ex).
% reverse_ex:reverse([1, 2, 3, 4]).  %% Should return [4, 3, 2, 1]
```

## Exercise 5: Duplicate Elements in a List

### Problem
Write an Erlang function `duplicate/2` that takes an integer N and a term, and returns a list containing N copies of that term. Use recursion with guards. For example, `duplicate(3, hello)` should return `[hello, hello, hello]`.

### Concepts
- Recursion with guards (`when N > 0`)
- List construction (`[Term | Rest]`)
- Base case (N = 0 returns empty list)
- `io:format/2` for output

### Example/Starter Code
```erlang
-module(duplicate_ex).
-export([duplicate/2]).

duplicate(0, _Term) ->
    [];
duplicate(N, Term) when N > 0 ->
    % TODO: Return [Term | duplicate(N-1, Term)]
    ok.

% Test:
% c(duplicate_ex).
% duplicate_ex:duplicate(5, x).  %% Should return [x, x, x, x, x]
```
