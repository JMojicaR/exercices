## Exercise 1: Create a Map & Get/Update
**Difficulty:** Basic
**Concepts:** map literal `#{}`, `maps:get/2`, `maps:get/3` default, `=>` vs `:=`

Store and retrieve student grades, then update one entry.

**Starter code:**
```erlang
-module(grades).
-export([demo/0]).

demo() ->
    Grades = #{alice => 85, bob => 72, carol => 90},

    Alice = maps:get(alice, Grades),        % 85
    Dave   = maps:get(dave, Grades, 0),     % 0 (default when missing)

    Updated1 = Grades#{dave => 78},         % add a new key
    Updated2 = Updated1#{bob := 75},        % update existing key (must exist)

    {Alice, Dave, Updated2}.
```

**Task:** Call `maps:get(dave, Grades)` (without a default) on the map that has no `dave` key and observe the `{badkey, dave}` error.

## Exercise 2: Count Character Frequencies
**Difficulty:** Basic
**Concepts:** recursion over a list, `maps:update_with/4`, `maps:get/3`

Count how many times each character appears in a list of characters.

**Starter code:**
```erlang
-module(charcount).
-export([count/1]).

count(Chars) ->
    count(Chars, #{}).

count([], Acc) ->
    Acc;
count([Ch | Rest], Acc) ->
    NewAcc = maps:update_with(Ch, fun(N) -> N + 1 end, 1, Acc),
    count(Rest, NewAcc).
```

**Test in the shell:**
```erlang
1> charcount:count("hello").
#{101 => 1, 104 => 1, 108 => 2, 111 => 1}
```

**Task:** Add a `count_words/1` function that splits a sentence on spaces using `string:split/2` and counts each word the same way.

## Exercise 3: Iterate Keys & Values
**Difficulty:** Basic
**Concepts:** `maps:keys/1`, `maps:values/1`, `maps:to_list/1`, `lists:foreach/2`

Print every country and its capital from a map.

**Starter code:**
```erlang
-module(capitals).
-export([print_all/0]).

print_all() ->
    Capitals = #{mexico => "Mexico City",
                 france => "Paris",
                 japan  => "Tokyo"},

    io:format("Countries: ~p~n", [maps:keys(Capitals)]),
    io:format("Capitals: ~p~n", [maps:values(Capitals)]),

    lists:foreach(
        fun({Country, Capital}) ->
            io:format("~p -> ~s~n", [Country, Capital])
        end,
        maps:to_list(Capitals)).
```

**Task:** Sort the output by country by wrapping the list in `lists:sort(maps:to_list(Capitals))`.

## Exercise 4: Check Membership & Remove
**Difficulty:** Basic
**Concepts:** `maps:is_key/2`, `maps:remove/2`, `maps:find/2`, `map_size/1`

Manage an inventory and safely remove an item.

**Starter code:**
```erlang
-module(inventory).
-export([demo/0]).

demo() ->
    Stock = #{apples => 10, bananas => 5, cherries => 20},

    HasBananas = maps:is_key(bananas, Stock),       % true
    Removed     = maps:remove(bananas, Stock),

    FindResult = maps:find(cherries, Removed),      % {ok, 20}
    Missing    = maps:find(bananas, Removed),       % error

    {HasBananas, map_size(Removed), FindResult, Missing}.
```

**Task:** Use `case maps:find(bananas, Removed) of {ok, V} -> ...; error -> ... end` to print a friendly message.

## Exercise 5: Find the Key with the Maximum Value
**Difficulty:** Basic
**Concepts:** `maps:fold/3`, accumulator tuples, comparing values

Find the student with the highest grade.

**Starter code:**
```erlang
-module(beststudent).
-export([best/1]).

best(Grades) ->
    maps:fold(
        fun(Name, Grade, {BestName, BestGrade}) ->
            case Grade > BestGrade of
                true  -> {Name, Grade};
                false -> {BestName, BestGrade}
            end
        end,
        {none, -1},
        Grades).

%% Test: beststudent:best(#{alice => 85, bob => 72, carol => 90, dave => 78}).
%% => {carol, 90}
```

**Task:** Handle the empty map by returning `{none, -1}` for `best(#{})`, and add a helper that prints `"No students"` when the best name is `none`.
