# Erlang — Basic Exercises (2026-10-11)
Sources: Learn You Some Erlang, Exercism Erlang track, Learn Erlang Step-By-Step

**Note:** Erlang exercises are written as modules with exported functions. Compile with `erlc file.erl`, then test in the `erl` shell (e.g. `c(sum_natural).` then `sum_natural:sum_to(10).`).

## Exercise 1: Sum of Natural Numbers (Recursion)
**Difficulty:** Basic
**Concepts:** recursion, tail recursion, pattern matching, accumulators

Compute the sum of all natural numbers from 1 to `N` using recursion.

**Starter code:**
```erlang
-module(sum_natural).
-export([sum_to/1]).

sum_to(N) -> sum_to(N, 0).
sum_to(0, Acc) -> Acc;
sum_to(N, Acc) -> sum_to(N - 1, Acc + N).
```

**Task:** Rewrite it without an accumulator (non-tail-recursive) and compare.

## Exercise 2: Power of a Number (Recursion)
**Difficulty:** Basic
**Concepts:** recursion, guards, pattern matching

Compute `Base` raised to `Exp` using recursion.

**Starter code:**
```erlang
-module(power).
-export([power/2]).

power(_, 0) -> 1;
power(Base, Exp) when Exp > 0 -> Base * power(Base, Exp - 1).
```

**Task:** Add a guard clause that returns an error (or handles `0^0`) for negative exponents.

## Exercise 3: Count Occurrences of an Element
**Difficulty:** Basic
**Concepts:** recursion, list pattern matching `[H|T]`

Count how many times an element appears in a list.

**Starter code:**
```erlang
-module(count_occurrences).
-export([count/2]).

count(_, []) -> 0;
count(X, [X | T]) -> 1 + count(X, T);
count(X, [_ | T]) -> count(X, T).
```

**Task:** Implement the same count with a list comprehension and `length/1`.

## Exercise 4: Filter Even Numbers
**Difficulty:** Basic
**Concepts:** list comprehensions, rem, filter

Return a list containing only the even numbers from an input list.

**Starter code:**
```erlang
-module(even_filter).
-export([even/1]).

even(List) -> [X || X <- List, X rem 2 =:= 0].
```

**Task:** Use `lists:filter/2` instead of a comprehension to achieve the same result.

## Exercise 5: Count Words in a String
**Difficulty:** Basic
**Concepts:** string:tokens, length, strings as lists

Count the number of words in a space-separated string.

**Starter code:**
```erlang
-module(word_count).
-export([count_words/1]).

count_words(Str) -> length(string:tokens(Str, " ")).
```

**Task:** Count words separated by any whitespace (spaces, tabs, newlines) using `string:lexemes/2`.
