## Exercise 1: Hello, World Module
**Difficulty:** Basic
**Concepts:** Modules (`-module`), exports (`-export`), functions, `io:format`.

Write an Erlang module with a function that prints "Hello, World!".

**Starter code:**
```erlang
-module(hello).
-export([hello/0]).

hello() ->
    io:format("Hello, World!~n").
```

**Task:** Add a `greet/1` function that takes a name and prints "Hello, <Name>!".

## Exercise 2: Factorial (Recursion)
**Difficulty:** Basic
**Concepts:** Recursion, pattern matching, function clauses, guards.

Write a recursive function that computes the factorial of a non-negative integer.

**Starter code:**
```erlang
-module(math_utils).
-export([factorial/1]).

factorial(0) -> 1;
factorial(N) when N > 0 -> N * factorial(N - 1).
```

**Task:** Add a clause that handles negative input by returning an error tuple like `{error, negative}`.

## Exercise 3: Fibonacci (Recursion)
**Difficulty:** Basic
**Concepts:** Recursion, multiple clauses, pattern matching.

Write a function that returns the Nth Fibonacci number.

**Starter code:**
```erlang
-module(fib).
-export([fib/1]).

fib(0) -> 0;
fib(1) -> 1;
fib(N) when N > 1 -> fib(N - 1) + fib(N - 2).
```

**Task:** Compute `fib(10)` and print the result with `io:format`.

## Exercise 4: Sum of a List
**Difficulty:** Basic
**Concepts:** Lists, recursion, pattern matching on `[H|T]`, the `lists:sum/1` BIF.

Write a function that computes the sum of all elements in a list.

**Starter code:**
```erlang
-module(list_utils).
-export([sum/1]).

sum([]) -> 0;
sum([H | T]) -> H + sum(T).
```

**Task:** Rewrite the sum using the built-in `lists:sum/1` and verify both give the same result.

## Exercise 5: Length of a List
**Difficulty:** Basic
**Concepts:** Recursion, list traversal, accumulator pattern, pattern matching.

Write a function that returns the number of elements in a list.

**Starter code:**
```erlang
-module(list_utils).
-export([my_length/1]).

my_length([]) -> 0;
my_length([_ | T]) -> 1 + my_length(T).
```

**Task:** Implement a tail-recursive version using an accumulator, and compare with `length/1`.
