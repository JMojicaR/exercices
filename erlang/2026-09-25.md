## Exercise 1: Hello, World!
**Difficulty:** Basic
**Concepts:** Modules, exported functions, `io:format`.

Write a module with a function that prints "Hello, World!".

**Starter code:**
```erlang
-module(hello).
-export([hello/0]).

hello() ->
    io:format("Hello, World!~n").
```

**Task:** Add a `greet/1` function that takes a name and prints a personalized greeting.

## Exercise 2: Factorial (Recursion)
**Difficulty:** Basic
**Concepts:** Recursion, pattern matching, function clauses.

Write a `factorial/1` function using recursion.

**Starter code:**
```erlang
-module(math_utils).
-export([factorial/1]).

factorial(0) -> 1;
factorial(N) when N > 0 -> N * factorial(N - 1).
```

**Task:** Test it in the Erlang shell with `math_utils:factorial(5).` and add a clause for negative input.

## Exercise 3: Even or Odd (Pattern Matching)
**Difficulty:** Basic
**Concepts:** Pattern matching, guards, `rem`.

Write a function that classifies an integer as even or odd.

**Starter code:**
```erlang
-module(parity).
-export([classify/1]).

classify(N) when N rem 2 =:= 0 -> even;
classify(_N) -> odd.
```

**Task:** Add a clause that returns `zero` for the input `0`.

## Exercise 4: Sum of a List (Recursion)
**Difficulty:** Basic
**Concepts:** Lists, head/tail pattern matching (`[H|T]`), recursion.

Write a function that sums the elements of a list.

**Starter code:**
```erlang
-module(list_utils).
-export([sum/1]).

sum([]) -> 0;
sum([H | T]) -> H + sum(T).
```

**Task:** Also write a `count/1` function that returns the number of elements in a list.

## Exercise 5: List Operations (Built-ins)
**Difficulty:** Basic
**Concepts:** `lists:map`, `lists:filter`, list comprehensions.

Use the `lists` module to double each number and keep only the even ones.

**Starter code:**
```erlang
-module(list_ops).
-export([double_all/1, only_even/1]).

double_all(List) -> lists:map(fun(X) -> X * 2 end, List).

only_even(List) -> lists:filter(fun(X) -> X rem 2 =:= 0 end, List).
```

**Task:** Rewrite `only_even/1` using a list comprehension: `[X || X <- List, X rem 2 =:= 0]`.
