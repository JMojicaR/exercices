## Exercise 1: Sum of List Elements
**Difficulty:** Basic
**Concepts:** lists, recursion, pattern matching, `lists:sum/1`

Write a function that returns the sum of all elements in a list of numbers.

**Starter code:**
```erlang
-module(mymath).
-export([sum/1]).

sum(List) ->
    lists:sum(List).
```

**Task:** Reimplement `sum/1` with explicit recursion and pattern matching:
```erlang
sum([]) -> 0;
sum([H | T]) -> H + sum(T).
```

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** pattern matching, guards, `rem`

Write a function that reports whether a number is even or odd.

**Starter code:**
```erlang
-module(mymath).
-export([even_or_odd/1]).

even_or_odd(N) when N rem 2 =:= 0 -> even;
even_or_odd(_N) -> odd.
```

**Task:** Use `lists:filter/2` with an `is_even/1` predicate to return only the even numbers from a list.

## Exercise 3: Celsius to Fahrenheit
**Difficulty:** Basic
**Concepts:** functions, arithmetic, pattern matching

Convert Celsius to Fahrenheit using `F = C × 9/5 + 32`.

**Starter code:**
```erlang
-module(temp).
-export([c2f/1, f2c/1]).

c2f(C) -> (C * 9 / 5) + 32.
f2c(F) -> (F - 32) * 5 / 9.
```

**Task:** Add a `convert({c, T})` / `convert({f, T})` function that picks the right conversion from a tagged tuple.

## Exercise 4: Find the Smallest Number
**Difficulty:** Basic
**Concepts:** lists, recursion, guards, `lists:min/1`

Write a function that returns the smallest element of a list.

**Starter code:**
```erlang
-module(mymath).
-export([minimum/1]).

minimum(List) ->
    lists:min(List).
```

**Task:** Reimplement `minimum/1` with explicit recursion:
```erlang
minimum([H | T]) -> minimum(T, H).
minimum([], Acc) -> Acc;
minimum([H | T], Acc) when H < Acc -> minimum(T, H);
minimum([_ | T], Acc) -> minimum(T, Acc).
```

## Exercise 5: Simple Interest
**Difficulty:** Basic
**Concepts:** functions, arithmetic

Calculate simple interest using `SI = (P × R × T) / 100`.

**Starter code:**
```erlang
-module(interest).
-export([simple_interest/3]).

simple_interest(Principal, Rate, Time) ->
    (Principal * Rate * Time) / 100.
```

**Task:** Add a `total_amount/3` function that returns principal + interest.
