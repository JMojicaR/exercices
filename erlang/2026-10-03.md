## Exercise 1: Even or Odd
**Difficulty:** Basic
**Concepts:** Modules, exported functions, `rem`, guards.

Write a module with a function that returns `true` if a number is even, `false` otherwise.

**Starter code:**
```erlang
-module(numbers).
-export([is_even/1]).

is_even(N) when N rem 2 =:= 0 -> true;
is_even(_) -> false.
```

**Task:** Add an `is_positive/1` function using guards that returns `true` for `N > 0`.

## Exercise 2: Reverse a List
**Difficulty:** Basic
**Concepts:** Pattern matching, list recursion, `[H|T]`, accumulator.

Write a function that reverses a list.

**Starter code:**
```erlang
-module(lists_ex).
-export([reverse/1]).

reverse(List) -> reverse(List, []).

reverse([], Acc) -> Acc;
reverse([H|T], Acc) -> reverse(T, [H|Acc]).
```

**Task:** Reverse the list `[1,2,3,4,5]` and confirm the result is `[5,4,3,2,1]`.

## Exercise 3: Sum of a List
**Difficulty:** Basic
**Concepts:** Recursion, accumulators, tail recursion, pattern matching.

Write a function that sums all numbers in a list.

**Starter code:**
```erlang
-module(lists_ex).
-export([sum/1]).

sum(List) -> sum(List, 0).

sum([], Acc) -> Acc;
sum([H|T], Acc) -> sum(T, Acc + H).
```

**Task:** Compute the sum of `[1,2,3,4,5]` (should be `15`) and also compute the average.

## Exercise 4: Factorial (Tail Recursive)
**Difficulty:** Basic
**Concepts:** Tail recursion, accumulator, guards for the base case.

Write a tail-recursive function that computes `n!`.

**Starter code:**
```erlang
-module(math_ex).
-export([factorial/1]).

factorial(N) -> factorial(N, 1).

factorial(0, Acc) -> Acc;
factorial(N, Acc) -> factorial(N - 1, Acc * N).
```

**Task:** Compute `factorial(5)` (should be `120`) and explain why tail recursion avoids stack growth.

## Exercise 5: Find the Maximum in a List
**Difficulty:** Basic
**Concepts:** Recursion, `max/2`, guard for empty list, pattern matching.

Write a function that returns the largest number in a non-empty list.

**Starter code:**
```erlang
-module(lists_ex).
-export([maximum/1]).

maximum([H]) -> H;
maximum([H|T]) -> max(H, maximum(T)).
```

**Task:** Handle the empty-list case (e.g. return `undefined`) and test with `[3, 9, 2, 7, 5]`.
