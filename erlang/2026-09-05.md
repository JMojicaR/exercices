## 1. Hello, World!
- **Description**: Write an Erlang module with a function that prints "Hello, World!" to the console.
- **Difficulty**: Beginner
- **Concepts**: Modules (`-module`, `-export`), functions, `io:format()`
- **Example/Starter code**:
```erlang
-module(hello).
-export([say_hello/0]).

say_hello() ->
    io:format("Hello, World!~n").
```

## 2. Even or Odd
- **Description**: Write a function that takes an integer and returns whether it is even or odd, using guards and the `rem` operator.
- **Difficulty**: Beginner
- **Concepts**: Function clauses, guards (`when`), `rem` operator, pattern matching
- **Example/Starter code**:
```erlang
-module(even_odd).
-export([check/1]).

check(N) when N rem 2 =:= 0 ->
    even;
check(_N) ->
    odd.
```

## 3. Factorial (Recursion)
- **Description**: Write a recursive function that computes the factorial of a non-negative integer n.
- **Difficulty**: Beginner
- **Concepts**: Recursion, base case, pattern matching, function clauses
- **Example/Starter code**:
```erlang
-module(factorial).
-export([fact/1]).

fact(0) -> 1;
fact(N) when N > 0 -> N * fact(N - 1).
```

## 4. Sum of a List
- **Description**: Write a function that returns the sum of all elements in a list of integers.
- **Difficulty**: Beginner
- **Concepts**: Lists, recursion, head/tail pattern matching (`[H|T]`), accumulation
- **Example/Starter code**:
```erlang
-module(sum_list).
-export([sum/1]).

sum([]) -> 0;
sum([H | T]) -> H + sum(T).
```

## 5. Reverse a List
- **Description**: Write a function that reverses a list. Implement it manually with an accumulator (or note the built-in `lists:reverse/1`).
- **Difficulty**: Beginner
- **Concepts**: Lists, recursion with accumulator, tail recursion, head/tail matching
- **Example/Starter code**:
```erlang
-module(reverse_list).
-export([reverse/1]).

reverse(L) -> reverse(L, []).

reverse([], Acc) -> Acc;
reverse([H | T], Acc) -> reverse(T, [H | Acc]).
%% Alternatively: lists:reverse(L).
```
