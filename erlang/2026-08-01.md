## Exercise 1: Hello, Erlang!
**Difficulty:** Basic

**Description:**
Create a module `hello` that exports a function `world/0` which returns the string `"Hello, Erlang!"`. This introduces the basic structure of an Erlang module, export declarations, function clauses, and the Erlang shell for testing.

**Concepts:**
- Module declaration (`-module(name).`)
- Export attribute (`-export([...]).`)
- Function clauses (`name() -> ...`)
- Atoms and strings
- Compiling and calling from the shell (`c(hello).`, `hello:world().`)

**Starter Code:**
```erlang
-module(hello).
-export([world/0]).

%% TODO: Return the string "Hello, Erlang!"
world() ->
    "Hello, Erlang!".
```

## Exercise 2: Factorial with Recursion
**Difficulty:** Basic

**Description:**
Create a module `factorial` that exports a function `fact/1` which calculates the factorial of a non-negative integer using recursion. The base case is `fact(0) -> 1`, and the recursive case is `N * fact(N-1)`. This exercise introduces pattern matching, recursion, and guards.

**Concepts:**
- Pattern matching on function arguments
- Recursive function calls
- Guards (`when N > 0`)
- Base case and recursive case structure
- Arithmetic operators

**Starter Code:**
```erlang
-module(factorial).
-export([fact/1]).

%% TODO: Implement factorial recursively
%% fact(0) -> 1
%% fact(5) -> 120

fact(0) ->
    1;
fact(N) when N > 0 ->
    %% Your recursive call here
    N * fact(N - 1).
```

## Exercise 3: Fibonacci Sequence
**Difficulty:** Basic

**Description:**
Create a module `fibonacci` that exports a function `fib/1` which returns the Nth Fibonacci number using recursion. `fib(0)` is 0, `fib(1)` is 1, and `fib(N)` is `fib(N-1) + fib(N-2)`. This reinforces pattern matching with multiple clauses and recursive thinking.

**Concepts:**
- Multiple function clauses with pattern matching
- Recursive decomposition of problems
- Guards for input validation
- Understanding exponential vs linear recursion

**Starter Code:**
```erlang
-module(fibonacci).
-export([fib/1]).

%% TODO: Compute the Nth Fibonacci number
%% fib(0) -> 0
%% fib(1) -> 1
%% fib(10) -> 55

fib(0) ->
    0;
fib(1) ->
    1;
fib(N) when N > 1 ->
    %% Your recursive call here
    fib(N - 1) + fib(N - 2).
```

## Exercise 4: List Operations — Sum and Reverse
**Difficulty:** Basic

**Description:**
Create a module `listops` that exports two functions: `sum/1` (returns the sum of a list of numbers) and `reverse/1` (returns a reversed copy of the list). Both must be implemented recursively. This exercise teaches recursive list processing and the cons operator.

**Concepts:**
- List pattern matching (`[H|T]` — head and tail)
- Recursive list traversal
- Accumulator pattern (for `reverse`)
- The cons operator `|` and `++`
- Base case for empty lists (`[]`)

**Starter Code:**
```erlang
-module(listops).
-export([sum/1, reverse/1]).

%% TODO: Sum all numbers in a list recursively
%% listops:sum([1, 2, 3, 4]) -> 10
sum([]) ->
    0;
sum([H | T]) ->
    %% Your recursive call here
    H + sum(T).

%% TODO: Reverse a list recursively (using an accumulator)
%% listops:reverse([1, 2, 3]) -> [3, 2, 1]
reverse(List) ->
    reverse(List, []).

%% Helper: reverse the remainder of the list into the accumulator
reverse([], Acc) ->
    Acc;
reverse([H | T], Acc) ->
    %% Your recursive call here
    reverse(T, [H | Acc]).
```

## Exercise 5: Simple Message Passing
**Difficulty:** Basic

**Description:**
Create a module `pingpong` that spawns a process which receives messages and replies. Export a function `start/0` that spawns a process and returns its PID. The process should respond to the message `{ping, FromPid}` by sending back `{pong, self()}`. Also export a `ping/1` function that sends a ping and waits for the pong. This introduces Erlang's core concurrency primitives.

**Concepts:**
- `spawn` for creating lightweight processes
- `receive` for message handling
- The `!` send operator
- `self()` to get the current process PID
- Pattern matching in `receive` clauses

**Starter Code:**
```erlang
-module(pingpong).
-export([start/0, ping/1]).

%% TODO: Spawn a process that responds to ping messages
%% The process should loop, waiting for {ping, FromPid} and replying with {pong, self()}
start() ->
    spawn(fun() -> loop() end).

loop() ->
    receive
        {ping, FromPid} ->
            %% TODO: Send {pong, self()} back to FromPid
            FromPid ! {pong, self()},
            loop();
        stop ->
            ok
    end.

%% TODO: Send a ping to Pid and wait for the pong response
ping(Pid) ->
    Pid ! {ping, self()},
    receive
        {pong, _FromPid} ->
            io:format("Received pong!~n"),
            pong_received
    end.
```
