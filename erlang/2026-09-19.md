# Erlang — Basic Exercises (2026-09-19)

Level: **Basic** · Sources referenced: Erlang docs, Learn You Some Erlang, Exercism, W3Schools

> Note: Erlang exercises are expressed as functions inside a module and evaluated in the Erlang shell (`erl`). Compile with `c(module_name).` then call `module:function(Args).`

---

## 1. Hello, World!
**Description:** Define a module with a function that returns the string `"Hello, World!"` (or prints it with `io:format`).
**Difficulty:** Basic
**Concepts:** Module declaration (`-module`/`-export`), function clauses, atoms, `io:format`.
**Starter code:**
```erlang
-module(hello).
-export([greet/0]).

greet() ->
    io:format("Hello, World!~n").
```

## 2. Even or Odd
**Description:** Write a function that takes an integer and returns the atom `even` or `odd`.
**Difficulty:** Basic
**Concepts:** Function clauses with pattern matching, guards (`when`), modulo operator `rem`.
**Starter code:**
```erlang
-module(evenodd).
-export([classify/1]).

classify(N) when N rem 2 =:= 0 -> even;
classify(_N) -> odd.
```

## 3. Sum of a List
**Description:** Compute the sum of all elements in a list using recursion and pattern matching.
**Difficulty:** Basic
**Concepts:** List pattern matching `[H|T]`, recursion, base case, accumulator.
**Starter code:**
```erlang
-module(listsum).
-export([sum/1]).

sum([]) -> 0;
sum([H | T]) -> H + sum(T).
```

## 4. Factorial
**Description:** Compute the factorial of a non-negative integer using recursion.
**Difficulty:** Basic
**Concepts:** Recursion, guards, base case, tail recursion (optional).
**Starter code:**
```erlang
-module(factorial).
-export([fact/1]).

fact(0) -> 1;
fact(N) when N > 0 -> N * fact(N - 1).
```

## 5. FizzBuzz (1 to N)
**Description:** Write a function that prints FizzBuzz rules for numbers 1 to N (multiples of 3 → "Fizz", 5 → "Buzz", both → "FizzBuzz").
**Difficulty:** Basic
**Concepts:** Recursion, guards, `io:format`, `rem`, string/atom output.
**Starter code:**
```erlang
-module(fizzbuzz).
-export([run/1]).

fizzbuzz(N) when N rem 15 =:= 0 -> "FizzBuzz";
fizzbuzz(N) when N rem 3 =:= 0  -> "Fizz";
fizzbuzz(N) when N rem 5 =:= 0  -> "Buzz";
fizzbuzz(N) -> integer_to_list(N).

run(0) -> ok;
run(N) ->
    run(N - 1),
    io:format("~s~n", [fizzbuzz(N)]).
```
