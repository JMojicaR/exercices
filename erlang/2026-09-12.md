# Erlang — Basic Exercises

Date: 2026-09-12 | Level: Beginner | Sources: Erlang docs, Learn You Some Erlang, Exercism (adapted)

## Exercise 1: Hello, World! (Module and Export)
- **Difficulty:** Easy
- **Description:** Create a module `hello` that exports a `greet/0` function returning the string `"Hello, World!"`, plus a `greet/1` that greets a given name.
- **Concepts:** modules, `-export`, function clauses, string concatenation
- **Starter code:**
```erlang
-module(hello).
-export([greet/0, greet/1]).

greet() ->
    "Hello, World!".

greet(Name) ->
    "Hello, " ++ Name ++ "!".
```

## Exercise 2: Even or Odd (Guards)
- **Difficulty:** Easy
- **Description:** Write a function `even_or_odd(N)` that returns `even` or `odd` using function clauses with guards.
- **Concepts:** multiple clauses, guards (`when`), `rem` operator, atoms
- **Starter code:**
```erlang
-module(parity).
-export([even_or_odd/1]).

even_or_odd(N) when N rem 2 =:= 0 ->
    even;
even_or_odd(N) ->
    odd.
```

## Exercise 3: Fibonacci (Recursion)
- **Difficulty:** Easy
- **Description:** Write a function `fib(N)` that returns the Nth Fibonacci number (0-indexed) using recursion.
- **Concepts:** recursion, pattern matching on arguments, base cases
- **Starter code:**
```erlang
-module(fib).
-export([fib/1]).

fib(0) -> 0;
fib(1) -> 1;
fib(N) when N > 1 -> fib(N - 1) + fib(N - 2).
```

## Exercise 4: Sum of a List (Accumulator)
- **Difficulty:** Easy
- **Description:** Write `sum/1` that returns the sum of a list of integers using a tail-recursive helper with an accumulator.
- **Concepts:** tail recursion, accumulators, list pattern matching (`[H|T]`)
- **Starter code:**
```erlang
-module(listops).
-export([sum/1]).

sum(List) ->
    sum(List, 0).

sum([], Acc) ->
    Acc;
sum([H | T], Acc) ->
    sum(T, Acc + H).
```

## Exercise 5: Reverse a List
- **Difficulty:** Easy
- **Description:** Write `reverse/1` that reverses a list using an accumulator, then compare it to the built-in `lists:reverse/1`.
- **Concepts:** list construction, accumulators, built-in `lists` module
- **Starter code:**
```erlang
-module(listops).
-export([reverse/1]).

reverse(List) ->
    reverse(List, []).

reverse([], Acc) ->
    Acc;
reverse([H | T], Acc) ->
    reverse(T, [H | Acc]).
```
