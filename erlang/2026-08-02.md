## Exercise 1: Pattern Matching Fundamentals
- **Difficulty**: Basic
- **Concepts**: Pattern matching in function clauses, case expressions, tuples, atoms, guards
- **Description**: Write a module that uses pattern matching to describe different shapes (circle, square, rectangle) as tuples. Create functions to compute area using multiple function clauses — one for each shape pattern. Use guards to handle special cases.

### Example/Starter Code
```erlang
-module(shapes).
-export([area/1, describe/1]).

% Pattern match on shape tuples
area({circle, Radius}) ->
    math:pi() * Radius * Radius;
area({square, Side}) ->
    Side * Side;
area({rectangle, Width, Height}) ->
    Width * Height;
area(_) ->
    {error, unknown_shape}.

% Using guards for additional constraints
describe({circle, Radius}) when Radius > 100 ->
    "A very large circle";
describe({circle, Radius}) when Radius > 0 ->
    "A circle";
describe({square, Side}) when Side > 0 ->
    "A square";
describe({rectangle, W, H}) when W > 0, H > 0, W =:= H ->
    "A rectangle that is actually a square";
describe({rectangle, W, H}) when W > 0, H > 0 ->
    "A rectangle";
describe(_) ->
    "Unknown or invalid shape".
```

## Exercise 2: Recursion and List Processing
- **Difficulty**: Basic
- **Concepts**: Recursion (base case + recursive case), head/tail pattern matching, list comprehensions, tail-call optimization
- **Description**: Implement recursive functions: `sum_list/1` to sum all numbers, `filter_positive/1` to keep only positive numbers, and `reverse/1` to reverse a list. Write both a naive recursive version and a tail-recursive version with an accumulator. Also try a list comprehension.

### Example/Starter Code
```erlang
-module(list_ops).
-export([sum_list/1, filter_positive/1, reverse_list/1, sum_list_tr/1]).

% Naive recursive sum
sum_list([]) -> 0;
sum_list([Head | Tail]) -> Head + sum_list(Tail).

% Tail-recursive sum (uses accumulator)
sum_list_tr(List) -> sum_list_tr(List, 0).
sum_list_tr([], Acc) -> Acc;
sum_list_tr([Head | Tail], Acc) -> sum_list_tr(Tail, Acc + Head).

% Filter positive numbers (recursive)
filter_positive([]) -> [];
filter_positive([Head | Tail]) when Head > 0 ->
    [Head | filter_positive(Tail)];
filter_positive([_Head | Tail]) ->
    filter_positive(Tail).

% Reverse a list (tail-recursive with accumulator)
reverse_list(List) -> reverse_list(List, []).
reverse_list([], Acc) -> Acc;
reverse_list([Head | Tail], Acc) -> reverse_list(Tail, [Head | Acc]).
```

## Exercise 3: Message Passing Between Processes
- **Difficulty**: Basic
- **Concepts**: spawn, send (!), receive, PIDs, process registration, timeouts
- **Description**: Create a simple counter server process. The server should accept `{increment, N}`, `{decrement, N}`, and `{get, CallerPid}` messages. A client process should send a series of messages and then request the current count. Use `receive ... after` for timeouts.

### Example/Starter Code
```erlang
-module(counter_server).
-export([start/0, increment/1, decrement/1, get_count/0, loop/1]).

start() ->
    Pid = spawn(?MODULE, loop, [0]),
    register(counter, Pid),
    {ok, Pid}.

loop(Count) ->
    receive
        {increment, N} ->
            loop(Count + N);
        {decrement, N} ->
            loop(Count - N);
        {get, Caller} ->
            Caller ! {count, Count},
            loop(Count);
        stop ->
            io:format("Counter stopped at ~p~n", [Count])
    after 10000 ->  % Timeout after 10s of inactivity
        io:format("Counter timed out at ~p~n", [Count])
    end.

increment(N) -> counter ! {increment, N}.
decrement(N) -> counter ! {decrement, N}.

get_count() ->
    counter ! {get, self()},
    receive
        {count, Value} -> Value
    after 1000 ->
        {error, timeout}
    end.
```

## Exercise 5: Maps, Records, and Key-Value Data
- **Difficulty**: Basic
- **Concepts**: Maps (#{}), map pattern matching, map update syntax, records, ETS basics
- **Description**: Build a simple student gradebook using maps. Store students with their scores in a map. Write functions to add/update a student, look up a grade, compute the class average, and find the top student. Demonstrate map pattern matching and the maps module.

### Example/Starter Code
```erlang
-module(gradebook).
-export([new/0, add_grade/3, get_grade/2, average/1, top_student/1]).

% Create an empty gradebook
new() -> #{}.

% Add or update a student's grade
add_grade(Gradebook, Student, Grade) ->
    Gradebook#{Student => Grade}.

% Look up a student's grade (pattern matching on map)
get_grade(Gradebook, Student) ->
    case maps:find(Student, Gradebook) of
        {ok, Grade} -> {ok, Grade};
        error -> {error, not_found}
    end.

% Compute class average
average(Gradebook) when map_size(Gradebook) > 0 ->
    Grades = maps:values(Gradebook),
    lists:sum(Grades) / map_size(Gradebook);
average(_) ->
    0.0.

% Find the top student using maps:fold
top_student(Gradebook) ->
    maps:fold(
        fun(Student, Grade, {TopStudent, TopGrade}) ->
            case Grade > TopGrade of
                true -> {Student, Grade};
                false -> {TopStudent, TopGrade}
            end
        end,
        {none, 0},
        Gradebook
    ).
```
