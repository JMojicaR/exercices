## 1. Temperature Converter
- **Description**: Write a function that converts a Celsius temperature to Fahrenheit (`F = C × 9/5 + 32`).
- **Difficulty**: Beginner
- **Concepts**: modules, `-export`, function clauses, arithmetic
- **Example/Starter code**:
```erlang
-module(temp).
-export([celsius_to_fahrenheit/1]).

celsius_to_fahrenheit(C) ->
    C * 9 / 5 + 32.
```
Run in the shell with: `temp:celsius_to_fahrenheit(100).` → `212.0`

## 2. Count the Vowels
- **Description**: Write a function that counts how many vowels appear in a string using a list comprehension.
- **Difficulty**: Beginner
- **Concepts**: list comprehensions, `lists:member/2`, strings as lists
- **Example/Starter code**:
```erlang
-module(vowels).
-export([count/1]).

count(String) ->
    length([C || C <- String,
                 lists:member(C, "aeiouAEIOU")]).
```

## 3. Fibonacci Series (Recursion)
- **Description**: Write a recursive function that returns the Nth Fibonacci number.
- **Difficulty**: Beginner
- **Concepts**: recursion, pattern matching, guards
- **Example/Starter code**:
```erlang
-module(fib).
-export([fib/1]).

fib(0) -> 0;
fib(1) -> 1;
fib(N) when N > 1 -> fib(N - 1) + fib(N - 2).
```

## 4. Sum of Digits
- **Description**: Write a recursive function that computes the sum of an integer's digits (e.g. 12345 → 15).
- **Difficulty**: Beginner
- **Concepts**: recursion, `rem` and `div`, base case
- **Example/Starter code**:
```erlang
-module(digitsum).
-export([sum_digits/1]).

sum_digits(0) -> 0;
sum_digits(N) -> N rem 10 + sum_digits(N div 10).
```

## 5. Maximum of a List
- **Description**: Write a recursive function that returns the largest element of a non-empty list.
- **Difficulty**: Beginner
- **Concepts**: pattern matching (`[H|T]`), recursion, `case` expressions
- **Example/Starter code**:
```erlang
-module(mymax).
-export([max/1]).

max([H]) -> H;
max([H | T]) ->
    M = max(T),
    case H >= M of
        true  -> H;
        false -> M
    end.
```
