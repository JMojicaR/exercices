## Exercise 1: Find Maximum & Minimum
**Difficulty:** Basic
**Concepts:** list pattern matching (`[H | T]`), tail recursion with accumulator, `erlang:min/2` / `erlang:max/2`

Return `{Min, Max}` for a non-empty list of integers.

**Starter code:**
```erlang
-module(minmax).
-export([min_max/1]).

min_max([H | T]) -> min_max(T, H, H).

min_max([], Min, Max) -> {Min, Max};
min_max([H | T], Min, Max) ->
    min_max(T, erlang:min(H, Min), erlang:max(H, Max)).
```

```
%% In the Erlang shell:
%% c(minmax).
%% minmax:min_max([3, 1, 4, 1, 5, 9, 2]).  % => {1, 9}
```

**Task:** Add a `min_max([]) -> {error, empty_list}` clause to handle the empty-list case.

## Exercise 2: Sum of Elements
**Difficulty:** Basic
**Concepts:** tail recursion, accumulator, list pattern matching

Return the sum of all integers in a list.

**Starter code:**
```erlang
-module(sumlist).
-export([sum/1]).

sum(List) -> sum(List, 0).

sum([], Acc) -> Acc;
sum([H | T], Acc) -> sum(T, Acc + H).
```

```
%% c(sumlist).
%% sumlist:sum([1, 2, 3, 4, 5]).  % => 15
```

**Task:** Replace your implementation with the built-in `lists:sum/1` and compare. Then write a body-recursive (non-tail) version and note the difference.

## Exercise 3: Reverse a List
**Difficulty:** Basic
**Concepts:** tail recursion, accumulator prepending `[H | Acc]`, list construction

Return a list with the elements in reverse order.

**Starter code:**
```erlang
-module(reverselist).
-export([reverse/1]).

reverse(List) -> reverse(List, []).

reverse([], Acc) -> Acc;
reverse([H | T], Acc) -> reverse(T, [H | Acc]).
```

```
%% c(reverselist).
%% reverselist:reverse([1, 2, 3, 4]).  % => [4, 3, 2, 1]
```

**Task:** Compare with `lists:reverse/1` and explain why building the result with `[H | Acc]` naturally reverses the order of an accumulator.

## Exercise 4: Count Occurrences
**Difficulty:** Basic
**Concepts:** `case` expression, recursion, accumulator, `=:=` (strict equality)

Count how many times a target value appears in a list.

**Starter code:**
```erlang
-module(countocc).
-export([count/2]).

count(List, Target) -> count(List, Target, 0).

count([], _Target, Acc) -> Acc;
count([H | T], Target, Acc) ->
    case H =:= Target of
        true  -> count(T, Target, Acc + 1);
        false -> count(T, Target, Acc)
    end.
```

```
%% c(countocc).
%% countocc:count([1, 2, 3, 2, 4, 2], 2).  % => 3
```

**Task:** Rewrite using a list comprehension: `length([X || X <- List, X =:= Target])`, and explain how the filter works.

## Exercise 5: Remove Duplicates
**Difficulty:** Basic
**Concepts:** `lists:member/2`, recursion, accumulator with `lists:reverse/1`, order preservation

Return a list with each element appearing only once, preserving the original order.

**Starter code:**
```erlang
-module(remdups).
-export([remove_duplicates/1]).

remove_duplicates(List) -> remove_duplicates(List, []).

remove_duplicates([], Acc) -> lists:reverse(Acc);
remove_duplicates([H | T], Acc) ->
    case lists:member(H, Acc) of
        true  -> remove_duplicates(T, Acc);
        false -> remove_duplicates(T, [H | Acc])
    end.
```

```
%% c(remdups).
%% remdups:remove_duplicates([1, 2, 2, 3, 4, 4, 4, 5]).  % => [1, 2, 3, 4, 5]
```

**Task:** Explain why the function ends with `lists:reverse(Acc)` — trace what `Acc` looks like just before the final call returns.
