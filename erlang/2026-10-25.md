Sources: erlang.org, Learn You Some Erlang, Exercism, tutorialspoint

Theme: **Matrices as lists of lists** — create, add, transpose, and summarize matrices using recursion and list comprehensions.

> Erlang has no built-in 2D array; a matrix is represented as a list of rows, where each row is a list.

## Exercise 1: Create and Print a Matrix
**Difficulty:** Basic
**Concepts:** lists of lists, recursion, `io:format`, pattern matching

Write a module that prints each row of a matrix on its own line.

**Starter code:**
```erlang
-module(matrix).
-export([print/1]).

print([]) -> ok;
print([Row | Rest]) ->
    io:format("~p~n", [Row]),
    print(Rest).
```

**Usage in the Erlang shell:**
```erlang
1> c(matrix).
2> matrix:print([[1,2,3],[4,5,6],[7,8,9]]).
[1,2,3]
[4,5,6]
[7,8,9]
ok
```

**Task:** Add a `print_reversed/1` function that prints the rows in reverse order (hint: `lists:reverse/1`).

## Exercise 2: Matrix Addition
**Difficulty:** Basic
**Concepts:** recursion, pattern matching, head/tail deconstruction

Add two matrices (lists of lists) element by element.

**Starter code:**
```erlang
-module(matrix).
-export([add/2]).

add([], []) -> [];
add([R1 | Rest1], [R2 | Rest2]) ->
    [add_rows(R1, R2) | add(Rest1, Rest2)].

add_rows([], []) -> [];
add_rows([A | As], [B | Bs]) ->
    [A + B | add_rows(As, Bs)].
```

**Usage:**
```erlang
1> matrix:add([[1,2],[3,4]], [[5,6],[7,8]]).
[[6,8],[10,12]]
```

**Task:** Add a `subtract/2` function, and a guard clause that returns `{error, size_mismatch}` when the matrices differ in size.

## Exercise 3: Matrix Transpose
**Difficulty:** Basic
**Concepts:** list comprehensions, `hd`/`tl`, recursion

Transpose a matrix (swap rows and columns).

**Starter code:**
```erlang
-module(matrix).
-export([transpose/1]).

transpose([[] | _]) -> [];
transpose(M) ->
    [[hd(Row) || Row <- M] | transpose([tl(Row) || Row <- M])].
```

**Usage:**
```erlang
1> matrix:transpose([[1,2,3],[4,5,6]]).
[[1,4],[2,5],[3,6]]
```

**Task:** Verify that `transpose(transpose(M))` returns `M`, and explain how the list comprehension builds each column.

## Exercise 4: Sum of the Main Diagonal
**Difficulty:** Basic
**Concepts:** recursion with an accumulator, `lists:nth/2`, index tracking

Sum the main diagonal (top-left to bottom-right) of a square matrix.

**Starter code:**
```erlang
-module(matrix).
-export([diagonal_sum/1]).

diagonal_sum(Matrix) -> diagonal_sum(Matrix, 1, 0).

diagonal_sum([], _N, Acc) -> Acc;
diagonal_sum([Row | Rest], N, Acc) ->
    diagonal_sum(Rest, N + 1, Acc + lists:nth(N, Row)).
```

**Usage:**
```erlang
1> matrix:diagonal_sum([[1,2,3],[4,5,6],[7,8,9]]).
15
```

**Task:** Add an `anti_diagonal_sum/1` that sums `lists:nth(length(Row) - N + 1, Row)`.

## Exercise 5: Sum of Each Row and Each Column
**Difficulty:** Basic
**Concepts:** list comprehensions, `lists:sum/1`, transpose reuse

Compute the sum of every row and every column.

**Starter code:**
```erlang
-module(matrix).
-export([row_sums/1, col_sums/1, transpose/1]).

row_sums(Matrix) ->
    [lists:sum(Row) || Row <- Matrix].

col_sums(Matrix) ->
    row_sums(transpose(Matrix)).

transpose([[] | _]) -> [];
transpose(M) ->
    [[hd(Row) || Row <- M] | transpose([tl(Row) || Row <- M])].
```

**Usage:**
```erlang
1> matrix:row_sums([[1,2,3],[4,5,6],[7,8,9]]).
[6,15,24]
2> matrix:col_sums([[1,2,3],[4,5,6],[7,8,9]]).
[12,15,18]
```

**Task:** Add a `total/1` function that sums all elements (`lists:sum(row_sums(Matrix))`), and report the largest row sum.
