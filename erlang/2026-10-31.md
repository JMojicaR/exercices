Theme: **String/List Manipulation** — reverse a list, check palindromes, count vowels, count character occurrences, and count words using `lists:reverse`, `lists:foldl`, recursion, and the `string` module.

> Erlang has no dedicated string type — strings are lists of integers (character codes). Compile each module with `erlc <file>.erl`, then call it from the Erlang shell, e.g. `reverse_string:reverse_string("hello").`

## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** `lists:reverse/1`, module/export declarations, lists as strings

Reverse a string using `lists:reverse`.

**Starter code:**
```erlang
-module(reverse_string).
-export([reverse_string/1]).

reverse_string(Str) -> lists:reverse(Str).
```

**Shell:**
```erlang
1> reverse_string:reverse_string("hello").
"olleh"
```

**Task:** Write your own recursive `reverse/1` using an accumulator and the `[H|T]` pattern.

## Exercise 2: Check Palindrome
**Difficulty:** Basic
**Concepts:** `string:lowercase/1`, `lists:reverse/1`, `=:=` comparison, `boolean()` return

Check whether a string reads the same forwards and backwards (ignoring case).

**Starter code:**
```erlang
-module(palindrome).
-export([is_palindrome/1]).

is_palindrome(Str) ->
    Lower = string:lowercase(Str),
    Lower =:= lists:reverse(Lower).
```

**Shell:**
```erlang
1> palindrome:is_palindrome("Radar").
true
2> palindrome:is_palindrome("hello").
false
```

**Task:** Strip spaces and punctuation first so `"A man, a plan, a canal: Panama"` returns `true`.

## Exercise 3: Count Vowels
**Difficulty:** Basic
**Concepts:** `lists:foldl/3`, `lists:member/2`, `string:lowercase/1`, `case`

Count how many vowels (a, e, i, o, u) appear in a string, case-insensitively.

**Starter code:**
```erlang
-module(count_vowels).
-export([count_vowels/1]).

count_vowels(Str) ->
    Lower = string:lowercase(Str),
    Vowels = "aeiou",
    lists:foldl(fun(C, Acc) ->
        case lists:member(C, Vowels) of
            true -> Acc + 1;
            false -> Acc
        end
    end, 0, Lower).
```

**Shell:**
```erlang
1> count_vowels:count_vowels("hello world").
3
```

**Task:** Rewrite it with a list comprehension (`length([C || C <- Lower, lists:member(C, Vowels)])`).

## Exercise 4: Count Character Occurrences
**Difficulty:** Basic
**Concepts:** `lists:foldl/3`, `=:=`, integer character codes

Count how many times a given character appears in a string.

**Starter code:**
```erlang
-module(count_char).
-export([count_char/2]).

count_char(Str, Ch) ->
    lists:foldl(fun(C, Acc) ->
        case C =:= Ch of
            true -> Acc + 1;
            false -> Acc
        end
    end, 0, Str).
```

**Shell:**
```erlang
1> count_char:count_char("banana", $a).
3
```

**Task:** Make the search case-insensitive by lowercasing both the string and the target character.

## Exercise 5: Count Words
**Difficulty:** Basic
**Concepts:** `string:lexemes/2`, `length/1`, tokenization

Count the number of words in a sentence (words separated by spaces).

**Starter code:**
```erlang
-module(count_words).
-export([count_words/1]).

count_words(Sentence) ->
    Words = string:lexemes(Sentence, " "),
    length(Words).
```

**Shell:**
```erlang
1> count_words:count_words("I love programming").
3
```

**Task:** Write your own recursive word counter that walks the list, tracking whether you are inside a word (like the C "in-word flag" approach).
