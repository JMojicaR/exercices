## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** recursion, guards, tail recursion

Compute the factorial of a non-negative integer using recursion.

**Starter code:**
```erlang
-module(ex1).
-export([factorial/1]).

factorial(0) -> 1;
factorial(N) when N > 0 -> N * factorial(N - 1).
```

**Task:** Rewrite `factorial` using a tail-recursive helper with an accumulator (`factorial/2`).

## Exercise 2: Palindrome List
**Difficulty:** Basic
**Concepts:** lists, pattern matching, list comparison

Check whether a list reads the same forwards and backwards.

**Starter code:**
```erlang
-module(ex2).
-export([is_palindrome/1]).

is_palindrome(List) -> List =:= lists:reverse(List).
```

**Task:** Implement the reversal yourself with recursion and an accumulator instead of `lists:reverse/1`.

## Exercise 3: Sum of a List
**Difficulty:** Basic
**Concepts:** recursion, lists:sum, accumulators

Compute the sum of a list of integers.

**Starter code:**
```erlang
-module(ex3).
-export([sum/1]).

sum([]) -> 0;
sum([H | T]) -> H + sum(T).
```

**Task:** Add a `sum/2` tail-recursive variant using an accumulator, and compare it to `lists:sum/1`.

## Exercise 4: Reverse a List
**Difficulty:** Basic
**Concepts:** recursion, accumulators

Reverse a list without using `lists:reverse/1`.

**Starter code:**
```erlang
-module(ex4).
-export([reverse/1]).

reverse(List) -> reverse(List, []).

reverse([], Acc) -> Acc;
reverse([H | T], Acc) -> reverse(T, [H | Acc]).
```

**Task:** Verify your result matches `lists:reverse/1` for several test lists.

## Exercise 5: Prime Number Check
**Difficulty:** Basic
**Concepts:** guards, recursion, modulo

Write a function that checks whether a positive integer is prime.

**Starter code:**
```erlang
-module(ex5).
-export([is_prime/1]).

is_prime(N) when N =< 1 -> false;
is_prime(N) -> is_prime(N, 2).

is_prime(N, D) when D * D > N -> true;
is_prime(N, D) when N rem D =:= 0 -> false;
is_prime(N, D) -> is_prime(N, D + 1).
```

**Task:** Add a function `primes_up_to/1` that returns all primes from 2 to N.
