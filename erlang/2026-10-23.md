# Erlang — Basic Exercises (2026-10-23)
Sources: erlang.org course, Learn You Some Erlang, Exercism

Note: In Erlang a character literal is just an integer (e.g. `$A` is `65`), and a "string" is a list of integers.

## Exercise 1: Print the ASCII Value of a Character
**Difficulty:** Basic
**Concepts:** character literals (`$A`), `io:format` with `~w`/`~c`, char ↔ integer equivalence

Given a character, print its ASCII value (which in Erlang is the character's integer form).

**Starter code:**
```erlang
-module(ascii).
-export([code/1]).

code(Char) ->
    io:format("ASCII value of ~c is ~w~n", [Char, Char]).
```

**Task:** Add a `from_code/1` function that turns an integer back into a character with `io:format("~c", [N])`, and verify `code($A)` prints `65`.

## Exercise 2: Check Vowel or Consonant
**Difficulty:** Basic
**Concepts:** `lists:member/2`, guards, `case`/`if`

Given a character, report whether it is a vowel or a consonant.

**Starter code:**
```erlang
-module(vowel).
-export([classify/1]).

classify(Ch) ->
    Lower = lower(Ch),
    Vowels = "aeiou",
    case lists:member(Lower, Vowels) of
        true  -> io:format("~c is a vowel~n", [Ch]);
        false -> io:format("~c is a consonant~n", [Ch])
    end.

lower(C) when C >= $A, C =< $Z -> C + 32;
lower(C) -> C.
```

**Task:** Add a guard or check so non-letter characters print "Not a letter" instead of "consonant".

## Exercise 3: Maximum and Minimum in a List
**Difficulty:** Basic
**Concepts:** `lists:max/1`, `lists:min/1`, recursion

Find the largest and smallest values in a list of numbers.

**Starter code:**
```erlang
-module(maxmin).
-export([range/1]).

range(Numbers) ->
    io:format("Max: ~w, Min: ~w~n", [lists:max(Numbers), lists:min(Numbers)]).
```

**Task:** Write your own recursive `my_max/1` (and `my_min/1`) that walks the list without the built-ins, and test it on `[45, 12, 78, 34, 89, 23]`.

## Exercise 4: Simple Calculator
**Difficulty:** Basic
**Concepts:** `case`/pattern matching, arithmetic operators, function clauses

Write a function that takes two numbers and an operator and returns the result.

**Starter code:**
```erlang
-module(calc).
-export([calc/3]).

calc(Op, A, B) ->
    case Op of
        add -> A + B;
        sub -> A - B;
        mul -> A * B;
        'div' when B =/= 0 -> A / B;
        'div' -> error(divide_by_zero);
        _    -> {error, invalid_operator}
    end.
```

**Task:** Add an `'rem'` (remainder) operation, and write a `run/0` function that prints the result of `calc(add, 10, 5)`.

## Exercise 5: Print Prime Numbers in a Range
**Difficulty:** Basic
**Concepts:** list comprehensions, guards, recursion

Return (or print) every prime number between two bounds (e.g. 10 and 50).

**Starter code:**
```erlang
-module(primes).
-export([range/2]).

is_prime(N) when N < 2 -> false;
is_prime(N) ->
    not lists:any(fun(I) -> N rem I =:= 0 end, lists:seq(2, trunc(math:sqrt(N)))).

range(Start, End) ->
    [N || N <- lists:seq(Start, End), is_prime(N)].
```

**Task:** Print the primes with `io:format("~p~n", ...)`, and count how many primes were found in the range.
