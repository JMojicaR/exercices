## Exercise 1: Factorial (Recursion)

**Difficulty:** Basic

### Problem
Write an Erlang module with a function `fact/1` that computes the factorial of a non-negative integer using recursion.

**Given Input:** `factorial:fact(5).`

**Expected Output:**
```
120
```

### Concepts
- Module declaration (`-module/0`) and exports (`-export/1`)
- Pattern-matching function clauses
- Recursion with a base case
- Guards (`when N > 0`)

### Example / Starter Code

```erlang
-module(factorial).
-export([fact/1]).

fact(0) -> 1;
fact(N) when N > 0 -> N * fact(N - 1).
```

**Test in the Erlang shell:**
```erlang
1> c(factorial).
2> factorial:fact(5).
120
```

## Exercise 2: Sum of a List

**Difficulty:** Basic

### Problem
Write a function `sum/1` that returns the sum of all integers in a list.

**Given Input:** `list_sum:sum([1, 2, 3, 4, 5]).`

**Expected Output:**
```
15
```

### Concepts
- List pattern matching (`[H | T]`)
- Recursion over lists
- Accumulating results

### Example / Starter Code

```erlang
-module(list_sum).
-export([sum/1]).

sum([]) -> 0;
sum([H | T]) -> H + sum(T).
```

**Test in the Erlang shell:**
```erlang
1> c(list_sum).
2> list_sum:sum([1, 2, 3, 4, 5]).
15
```

## Exercise 3: Reverse a List

**Difficulty:** Basic

### Problem
Write a function `rev/1` that reverses a list using a tail-recursive helper with an accumulator.

**Given Input:** `list_reverse:rev([1, 2, 3]).`

**Expected Output:**
```
[3, 2, 1]
```

### Concepts
- Tail recursion
- Accumulator pattern
- Helper functions with arity `rev/2`

### Example / Starter Code

```erlang
-module(list_reverse).
-export([rev/1]).

rev(List) -> rev(List, []).

rev([], Acc) -> Acc;
rev([H | T], Acc) -> rev(T, [H | Acc]).
```

**Test in the Erlang shell:**
```erlang
1> c(list_reverse).
2> list_reverse:rev([1, 2, 3]).
[3, 2, 1]
```

## Exercise 4: Palindrome Check

**Difficulty:** Basic

### Problem
Write a function `is_palindrome/1` that checks whether a list (or string) reads the same forward and backward.

**Given Input:**
- `palindrome:is_palindrome("racecar").`
- `palindrome:is_palindrome("hello").`

**Expected Output:**
- `true`
- `false`

### Concepts
- `lists:reverse/1`
- Exact equality operator (`=:=`)
- Strings as lists of characters

### Example / Starter Code

```erlang
-module(palindrome).
-export([is_palindrome/1]).

is_palindrome(List) ->
    List =:= lists:reverse(List).
```

**Test in the Erlang shell:**
```erlang
1> c(palindrome).
2> palindrome:is_palindrome("racecar").
true
3> palindrome:is_palindrome("hello").
false
```

## Exercise 5: FizzBuzz with List Comprehension

**Difficulty:** Basic

### Problem
Write a function `run/0` that returns a list applying FizzBuzz rules to numbers 1 through 15: multiples of 3 → `fizz`, multiples of 5 → `buzz`, multiples of both → `fizzbuzz`, otherwise the number itself.

**Given Input:** `fizzbuzz:run().`

**Expected Output:**
```
[1, 2, fizz, 4, buzz, fizz, 7, 8, fizz, buzz, 11, fizz, 13, 14, fizzbuzz]
```

### Concepts
- List comprehensions (`[ ... || N <- ... ]`)
- `lists:seq/2` to generate ranges
- Guards for multiple conditions
- Function clauses with pattern matching

### Example / Starter Code

```erlang
-module(fizzbuzz).
-export([run/0]).

run() -> [fizzbuzz(N) || N <- lists:seq(1, 15)].

fizzbuzz(N) when N rem 15 =:= 0 -> fizzbuzz;
fizzbuzz(N) when N rem 3 =:= 0 -> fizz;
fizzbuzz(N) when N rem 5 =:= 0 -> buzz;
fizzbuzz(N) -> N.
```

**Test in the Erlang shell:**
```erlang
1> c(fizzbuzz).
2> fizzbuzz:run().
[1,2,fizz,4,buzz,fizz,7,8,fizz,buzz,11,fizz,13,14,fizzbuzz]
```
