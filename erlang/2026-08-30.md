## Exercise 1: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a recursive function `factorial/1` that returns the factorial of a non-negative integer. Factorial of 0 is 1.

**Given Input:** `exercises:factorial(5).`

**Expected Output:**
```
120
```

### Concepts
- Function clauses and pattern matching
- Recursion with a base case
- Guard `when N > 0`

### Example / Starter Code

```erlang
-module(exercises).
-export([factorial/1]).

factorial(0) -> 1;
factorial(N) when N > 0 -> N * factorial(N - 1).
```

## Exercise 2: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a function `fibonacci/1` that returns a list of the first `N` terms of the Fibonacci sequence (`[0, 1, 1, 2, 3, …]`) using tail recursion.

**Given Input:** `exercises:fibonacci(7).`

**Expected Output:**
```
[0,1,1,2,3,5,8]
```

### Concepts
- Tail recursion with an accumulator
- `lists:reverse/1` to restore order
- Cons operator `[A | Acc]`

### Example / Starter Code

```erlang
-export([fibonacci/1]).

fibonacci(N) -> fib(N, 0, 1, []).

fib(0, _, _, Acc) -> lists:reverse(Acc);
fib(N, A, B, Acc) -> fib(N - 1, B, A + B, [A | Acc]).
```

## Exercise 3: Palindrome Check

**Difficulty:** Basic

### Problem
Write a function `is_palindrome/1` that returns `true` if a string is a palindrome (case-insensitive), `false` otherwise.

**Given Input:** `exercises:is_palindrome("Racecar").`

**Expected Output:**
```
true
```

### Concepts
- `string:lowercase/1`
- `lists:reverse/1`
- Strict equality operator `=:=`

### Example / Starter Code

```erlang
-export([is_palindrome/1]).

is_palindrome(Str) ->
    Lower = string:lowercase(Str),
    Lower =:= lists:reverse(Lower).
```

## Exercise 4: Prime Number Check

**Difficulty:** Basic

### Problem
Write a function `is_prime/1` that returns `true` if a number is prime, `false` otherwise, using recursion and guards.

**Given Input:** `exercises:is_prime(29).`

**Expected Output:**
```
true
```

### Concepts
- Guards for base cases
- Recursive helper with an accumulator
- `rem` operator and early termination

### Example / Starter Code

```erlang
-export([is_prime/1]).

is_prime(N) when N =< 1 -> false;
is_prime(2) -> true;
is_prime(N) -> is_prime(N, 2).

is_prime(N, I) when I * I > N -> true;
is_prime(N, I) when N rem I =:= 0 -> false;
is_prime(N, I) -> is_prime(N, I + 1).
```

## Exercise 5: Sum of Digits

**Difficulty:** Basic

### Problem
Write a function `sum_of_digits/1` that returns the sum of the digits of a positive integer using recursion.

**Given Input:** `exercises:sum_of_digits(12345).`

**Expected Output:**
```
15
```

### Concepts
- Recursion with a base case (`N < 10`)
- `rem` and `div` operators
- Digit extraction

### Example / Starter Code

```erlang
-export([sum_of_digits/1]).

sum_of_digits(N) when N < 10 -> N;
sum_of_digits(N) -> N rem 10 + sum_of_digits(N div 10).
```
