## Exercise 1: Hello, Module!
**Difficulty:** ★☆☆☆☆  
**Concepts:** Modules (`-module`), exports (`-export`), functions, `io:format`

### Description
Create an Erlang module `greeter` that exports a function `greet/1`. The function takes a name (string) and returns a greeting string like `"Hello, Alice!"`. Test it from the Erlang shell.

### Starter Code
```erlang
-module(greeter).
-export([greet/1]).

greet(Name) ->
    "Hello, " ++ Name ++ "!".
```

In the Erlang shell:
```erlang
1> c(greeter).
2> greeter:greet("Alice").
"Hello, Alice!"
```

Extend with a function `greet/2` that takes a name and a language atom (`english`, `spanish`, `french`) and returns the greeting in that language.

## Exercise 2: List Operations with Recursion
**Difficulty:** ★★☆☆☆  
**Concepts:** List pattern matching `[H|T]`, recursion, guards

### Description
Write a module `list_ops` with:
- `sum/1`: Sum all numbers in a list using recursion.
- `length/1`: Count elements using recursion (no `length()` BIF).
- `reverse/1`: Reverse a list using recursion.

### Starter Code
```erlang

-export([sum/1, my_length/1, reverse/1]).

sum([]) ->
    0;
sum([H|T]) ->
    % Your code here
    H + sum(T).

my_length([]) ->
    0;
my_length([_|T]) ->
    % Your code here
    ok.

reverse(List) ->
    reverse(List, []).

reverse([], Acc) ->
    Acc;
reverse([H|T], Acc) ->
    % Your code here
    ok.
```

Test in shell:
```erlang
1> list_ops:sum([1,2,3,4,5]).  % 15
2> list_ops:my_length([a,b,c]). % 3
3> list_ops:reverse([1,2,3]).   % [3,2,1]
```

## Exercise 5: Message Passing — Simple Ping-Pong
**Difficulty:** ★★☆☆☆  
**Concepts:** `spawn`, `!` (send), `receive`, process IDs (`Pid`)

### Description
Create two processes: a `ping` process and a `pong` process. The ping process sends `{ping, self()}` to pong. The pong process receives it, prints `"Pong!"`, and sends `{pong, self()}` back. The ping process receives the reply and prints `"Ping received reply!"`. Both processes exit after the exchange.

### Starter Code
```erlang
-module(pingpong).
-export([start/0, ping/1, pong/0]).

ping(PongPid) ->
    PongPid ! {ping, self()},
    io:format("Ping sent!~n"),
    receive
        {pong, PongPid} ->
            io:format("Ping received reply!~n")
    end.

pong() ->
    receive
        {ping, PingPid} ->
            io:format("Pong!~n"),
            PingPid ! {pong, self()}
    end.

start() ->
    PongPid = spawn(pingpong, pong, []),
    spawn(pingpong, ping, [PongPid]).
```

Test:
```erlang
1> pingpong:start().
Ping sent!
Pong!
Ping received reply!
```
