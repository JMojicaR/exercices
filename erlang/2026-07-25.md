## Exercise 1: Hello World
- **Description**: The classic first program. Write a function `hello/0` that returns the string `"Hello, World!"`. This exercise introduces you to the basic structure of an Erlang module, exported functions, and the Erlang shell. Erlang modules are files with a `.erl` extension that group related functions together.
- **Difficulty**: Beginner
- **Concepts**: modules, exports, functions, strings, atoms vs strings, compilation (`c(module).`)
- **Example/Starter Code**:
```erlang
-module(hello_world).
-export([hello/0]).

hello() ->
  "Hello, World!".
```

## Exercise 2: Leap Year
- **Description**: Given a year as an integer, determine whether it is a leap year. A leap year is divisible by 4, except years divisible by 100 (unless also divisible by 400). Write a function `leap_year/1` that returns `true` or `false`. This exercise teaches you about guards, `rem` operator, boolean logic (`and`, `or`), and Erlang's multiple function clause pattern.
- **Difficulty**: Beginner
- **Concepts**: guards (`when`), multiple function clauses, pattern matching, `rem` operator, boolean operators (`and`, `or`)
- **Example/Starter Code**:
```erlang
-module(leap).
-export([leap_year/1]).

leap_year(Year) when Year rem 400 =:= 0 ->
  true;
leap_year(Year) when Year rem 100 =:= 0 ->
  false;
leap_year(Year) when Year rem 4 =:= 0 ->
  true;
leap_year(_Year) ->
  false.
```

## Exercise 3: Reverse a List
- **Description**: Write a function `reverse/1` that takes a list and returns it in reverse order — **without** using the built-in `lists:reverse/1`. This forces you to implement your own recursive solution using an accumulator. In Erlang, loops are replaced by recursion, and this is the canonical introduction to that pattern. The accumulator pattern (`reverse(List, Acc)`) is fundamental to writing efficient Erlang.
- **Difficulty**: Beginner
- **Concepts**: recursion, accumulators, tail-call optimization, list construction (`[H|T]`), base case, `lists:reverse/1` (for comparison)
- **Example/Starter Code**:
```erlang
-module(my_lists).
-export([reverse/1]).

reverse(List) ->
  reverse(List, []).

reverse([], Acc) ->
  Acc;
reverse([Head | Tail], Acc) ->
  reverse(Tail, [Head | Acc]).
```

## Exercise 4: Nucleotide Count
- **Description**: DNA is represented by a string of characters: `A` (adenine), `C` (cytosine), `G` (guanine), and `T` (thymine). Write a function `count/2` that takes a DNA string and a nucleotide character, then returns how many times that nucleotide appears. This teaches list traversal, character matching, and recursion over strings (which are just lists of integers in Erlang).
- **Difficulty**: Beginner
- **Concepts**: recursion, string-as-list, pattern matching on characters (`$A`, `$C`, etc.), counting with accumulators, guards
- **Example/Starter Code**:
```erlang
-module(nucleotide_count).
-export([count/2]).

count(Strand, Nucleotide) ->
  count(Strand, Nucleotide, 0).

count([], _Nucleotide, Acc) ->
  Acc;
count([Char | Rest], Nucleotide, Acc) when Char =:= Nucleotide ->
  count(Rest, Nucleotide, Acc + 1);
count([_Char | Rest], Nucleotide, Acc) ->
  count(Rest, Nucleotide, Acc).
```

## Exercise 5: Simple Message Passing (Ping Pong)
- **Description**: Create two processes that send messages back and forth. Write a `ping/2` function that receives a count and a Pong PID, and a `pong/0` function that just responds. When Ping receives N messages, it stops. This exercise introduces you to Erlang's actor model: `spawn`, `send` (`!` operator), and `receive` — the three pillars of Erlang concurrency.
- **Difficulty**: Beginner
- **Concepts**: processes, `spawn/1`, message passing (`!`), `receive` blocks, `self()`, PIDs, actor model, pattern matching in `receive`
- **Example/Starter Code**:
```erlang
-module(pingpong).
-export([start/0, ping/2, pong/0]).

start() ->
  PongPid = spawn(pingpong, pong, []),
  spawn(pingpong, ping, [3, PongPid]).

ping(0, _PongPid) ->
  io:format("Ping finished~n"),
  ok;
ping(N, PongPid) ->
  PongPid ! {ping, self()},
  receive
    pong ->
      io:format("Ping received pong~n"),
      ping(N - 1, PongPid)
  end.

pong() ->
  receive
    {ping, PingPid} ->
      io:format("Pong received ping~n"),
      PingPid ! pong,
      pong()
  end.
```
