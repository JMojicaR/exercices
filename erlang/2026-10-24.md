## Exercise 1: Print a Right-Angled Triangle of Stars
**Difficulty:** Basic
**Concepts:** recursion, `lists:seq()`, `lists:duplicate()`, `io:format()`

Print a right-angled triangle of `*` where the number of rows is user-supplied (passed as an argument).

**Starter code:**
```erlang
-module(triangle).
-export([print_triangle/1]).

print_triangle(Rows) ->
    lists:foreach(
        fun(N) -> io:format("~s~n", [lists:duplicate(N, $*)]) end,
        lists:seq(1, Rows)).
```

**Task:** Print an inverted triangle instead (iterate `lists:seq(Rows, 1, -1)`), then print numbers (`1`, `22`, `333`, …) using `lists:duplicate` with a stringified integer.

## Exercise 2: Print Floyd's Triangle
**Difficulty:** Basic
**Concepts:** recursion with accumulator, `lists:foreach`, `io:format`

Print Floyd's triangle — consecutive numbers arranged in rows of increasing length.

**Starter code:**
```erlang
-module(floyd).
-export([print_floyd/1]).

print_floyd(Rows) ->
    print_floyd(1, Rows, 1).

print_floyd(Row, Rows, _Num) when Row > Rows ->
    ok;
print_floyd(Row, Rows, Num) ->
    print_row(Row, Num),
    print_floyd(Row + 1, Rows, Num + Row).

print_row(Count, Num) ->
    lists:foreach(
        fun(I) -> io:format("~p ", [I]) end,
        lists:seq(Num, Num + Count - 1)),
    io:format("~n").
```

**Task:** Right-align the triangle with leading spaces, and start the counter at a user-supplied value (add it as an argument).

## Exercise 3: Count Uppercase and Lowercase Letters
**Difficulty:** Basic
**Concepts:** list comprehensions, guards, `length()`

Count how many uppercase and lowercase letters a string contains (a string is a list of integers).

**Starter code:**
```erlang
-module(casecount).
-export([count_cases/1]).

count_cases(Str) ->
    Upper = length([C || C <- Str, C >= $A, C =< $Z]),
    Lower = length([C || C <- Str, C >= $a, C =< $z]),
    io:format("Uppercase: ~p, Lowercase: ~p~n", [Upper, Lower]).
```

**Task:** Also count digits (`C >= $0, C =< $9`) and spaces (`C =:= $\s`), and print a full breakdown.

## Exercise 4: Remove All Spaces from a String
**Difficulty:** Basic
**Concepts:** list comprehensions, character matching

Remove every space from an input string and return the result.

**Starter code:**
```erlang
-module(removespaces).
-export([remove_spaces/1]).

remove_spaces(Str) ->
    [C || C <- Str, C =/= $\s].
```

**Task:** Also remove tabs and newlines, and write a recursive version that processes the list one character at a time.

## Exercise 5: Find the Largest Digit in a Number
**Difficulty:** Basic
**Concepts:** recursion, `rem` / `div`, `max()`, guards

Read a whole number and return its largest single digit.

**Starter code:**
```erlang
-module(largestdigit).
-export([largest_digit/1]).

largest_digit(N) when N < 0 ->
    largest_digit(-N);
largest_digit(N) ->
    largest_digit(N, 0).

largest_digit(0, Acc) ->
    Acc;
largest_digit(N, Acc) ->
    D = N rem 10,
    largest_digit(N div 10, max(D, Acc)).
```

**Task:** Also find the smallest digit, and extract the digits into a list so you can use `lists:max/1` and `lists:min/1`.
