## Exercise 1: Even or Odd (Guards)
- **Difficulty:** Easy
- **Description:** Write a module function `even_odd/1` that returns the atom `even` or `odd` using function guards and the `rem` operator.
- **Concepts:** modules, `-export`, function clauses, guards, `rem`
- **Starter code:**
```erlang
-module(evenodd).
-export([even_odd/1]).

even_odd(N) when N rem 2 =:= 0 -> even;
even_odd(_) -> odd.

%% Test in the shell:
%% 1> c(evenodd).
%% 2> evenodd:even_odd(10).
%% even
%% 3> evenodd:even_odd(7).
%% odd
```

## Exercise 2: Factorial (Recursion)
- **Difficulty:** Easy
- **Description:** Write `factorial/1` that computes N! using recursion with a base case. Factorial of 0 is 1.
- **Concepts:** recursion, pattern matching, guards, arithmetic
- **Starter code:**
```erlang
-module(fact).
-export([factorial/1]).

factorial(0) -> 1;
factorial(N) when N > 0 ->
    % TODO: return N * factorial(N - 1)
    N.

%% 1> c(fact).
%% 2> fact:factorial(5).
%% 120
```

## Exercise 3: Palindrome Check
- **Difficulty:** Easy
- **Description:** Write `is_palindrome/1` that returns `true` if a string (list) reads the same forwards and backwards. Compare the list with its `lists:reverse/1`.
- **Concepts:** lists, `lists:reverse`, `=:=` comparison, `string:lowercase`
- **Starter code:**
```erlang
-module(pal).
-export([is_palindrome/1]).

is_palindrome(S) ->
    L = string:lowercase(S),
    % TODO: return true if L =:= lists:reverse(L), else false
    false.

%% 1> c(pal).
%% 2> pal:is_palindrome("racecar").
%% true
%% 3> pal:is_palindrome("hello").
%% false
```

## Exercise 4: Sum of Digits (Recursion)
- **Difficulty:** Easy
- **Description:** Write `sum_digits/1` that returns the sum of an integer's digits using recursion: the last digit is `N rem 10` and the rest is `N div 10` (e.g. `1234` → `10`).
- **Concepts:** recursion, base case, `rem`, `div`, guards
- **Starter code:**
```erlang
-module(sumdigits).
-export([sum_digits/1]).

sum_digits(N) when N < 10 -> N;
sum_digits(N) ->
    % TODO: return (N rem 10) + sum_digits(N div 10)
    N.

%% 1> c(sumdigits).
%% 2> sumdigits:sum_digits(1234).
%% 10
```

## Exercise 5: FizzBuzz (Recursion + Guards)
- **Difficulty:** Easy
- **Description:** Write `fizzbuzz/1` that returns `fizzbuzz`, `fizz`, `buzz`, or the number itself for a given N based on divisibility by 3 and 5.
- **Concepts:** guards, `rem`, multiple function clauses, atoms
- **Starter code:**
```erlang
-module(fizzbuzz).
-export([fizzbuzz/1]).

fizzbuzz(N) when N rem 15 =:= 0 -> fizzbuzz;
fizzbuzz(N) when N rem 3 =:= 0 -> fizz;
fizzbuzz(N) when N rem 5 =:= 0 -> buzz;
fizzbuzz(N) -> N.

%% 1> c(fizzbuzz).
%% 2> fizzbuzz:fizzbuzz(15).
%% fizzbuzz
%% 3> fizzbuzz:fizzbuzz(9).
%% fizz
%% 4> fizzbuzz:fizzbuzz(10).
%% buzz
%% 5> fizzbuzz:fizzbuzz(7).
%% 7
```
