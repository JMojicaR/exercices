## Exercise 1: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** tuples, pattern matching, module exports

Swap two values by returning them as a tuple.

**Starter code:**
```erlang
-module(swap).
-export([swap/2]).

swap(A, B) ->
    {B, A}.

%% Usage:
%% 1> c(swap).
%% 2> swap:swap(5, 10).
%% {10,5}
```

**Task:** Write `swap3/3` that returns a tuple with three values reversed: `swap3(A, B, C) -> {C, B, A}`.

## Exercise 2: Area of a Circle
**Difficulty:** Basic
**Concepts:** arithmetic, functions, floating-point numbers

Compute the area of a circle given its radius (`area = π × r²`).

**Starter code:**
```erlang
-module(circle).
-export([area/1]).

area(Radius) ->
    3.14159 * Radius * Radius.

%% Usage:
%% circle:area(5.0).
%% 78.53975
```

**Task:** Add a `circumference/1` function that returns `2 * 3.14159 * Radius`.

## Exercise 3: Positive, Negative or Zero
**Difficulty:** Basic
**Concepts:** guards, pattern matching, atoms

Classify a number as positive, negative, or zero using function guards.

**Starter code:**
```erlang
-module(check).
-export([classify/1]).

classify(N) when N > 0 -> positive;
classify(N) when N < 0 -> negative;
classify(_)            -> zero.

%% Usage:
%% check:classify(-3).
%% negative
```

**Task:** Add a `sign/1` function that returns the integer `1`, `-1`, or `0` instead of atoms.

## Exercise 4: Power of a Number (xⁿ)
**Difficulty:** Basic
**Concepts:** recursion, base case, pattern matching

Compute `base` raised to the power `exp` using recursion.

**Starter code:**
```erlang
-module(power).
-export([power/2]).

power(_, 0) -> 1;
power(Base, Exp) when Exp > 0 ->
    Base * power(Base, Exp - 1).

%% Usage:
%% power:power(2, 5).
%% 32
```

**Task:** Extend `power/2` to also handle negative exponents by returning a `float` result.

## Exercise 5: Reverse a Number
**Difficulty:** Basic
**Concepts:** `integer_to_list`, `lists:reverse`, `list_to_integer`

Reverse the digits of an integer (e.g. 1234 → 4321) by converting to a list and back.

**Starter code:**
```erlang
-module(reverse_num).
-export([reverse/1]).

reverse(N) when N < 0 ->
    -list_to_integer(lists:reverse(integer_to_list(-N)));
reverse(N) ->
    list_to_integer(lists:reverse(integer_to_list(N))).

%% Usage:
%% reverse_num:reverse(1234).
%% 4321
%% reverse_num:reverse(-1234).
%% -4321
```

**Task:** Implement `reverse/1` using pure arithmetic (a recursive helper with an accumulator) instead of list conversion.
