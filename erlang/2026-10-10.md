## Exercise 1: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** recursion, pattern matching, guards

Write a recursive function that returns the `N`th Fibonacci number (0, 1, 1, 2, 3, 5, ...).

**Starter code:**
```erlang
-module(fib).
-export([fib/1]).

fib(0) -> 0;
fib(1) -> 1;
fib(N) when N > 1 -> fib(N - 1) + fib(N - 2).
```

**Task:** Write a helper that builds the list of the first N Fibonacci numbers, e.g. `fib_list(10)`.

## Exercise 2: Sum of Digits
**Difficulty:** Basic
**Concepts:** recursion, div/rem, pattern matching

Write a function that computes the sum of the digits of a non-negative integer (e.g. 1234 → 10).

**Starter code:**
```erlang
-module(digits).
-export([sum_digits/1]).

sum_digits(0) -> 0;
sum_digits(N) -> N rem 10 + sum_digits(N div 10).
```

**Task:** Also write `count_digits/1` and `product_digits/1`.

## Exercise 3: Maximum of a List
**Difficulty:** Basic
**Concepts:** recursion over lists, pattern matching, guards

Write a function that returns the largest element of a list of integers.

**Starter code:**
```erlang
-module(mymax).
-export([maximum/1]).

maximum([H | T]) -> maximum(T, H).

maximum([], Max) -> Max;
maximum([H | T], Max) when H > Max -> maximum(T, H);
maximum([_ | T], Max) -> maximum(T, Max).
```

**Task:** Handle the empty-list case with a clear error, and also write a `minimum/1` function.

## Exercise 4: FizzBuzz
**Difficulty:** Basic
**Concepts:** lists:seq, lists:map, case, guards

Generate FizzBuzz for the numbers 1 to N, returning a list where multiples of 3 are `"Fizz"`, multiples of 5 are `"Buzz"`, and multiples of both are `"FizzBuzz"`.

**Starter code:**
```erlang
-module(fizzbuzz).
-export([fizzbuzz/1]).

fizzbuzz(N) ->
    lists:map(fun fizzbuzz_one/1, lists:seq(1, N)).

fizzbuzz_one(X) when X rem 15 =:= 0 -> "FizzBuzz";
fizzbuzz_one(X) when X rem 3 =:= 0  -> "Fizz";
fizzbuzz_one(X) when X rem 5 =:= 0  -> "Buzz";
fizzbuzz_one(X) -> X.
```

**Task:** Return `X` as an integer for non-multiples and have the caller print the list in order.

## Exercise 5: Average of a List
**Difficulty:** Basic
**Concepts:** lists:sum, length, arithmetic, recursion

Compute the average of a list of numbers using the standard library, and then reimplement it with explicit recursion.

**Starter code:**
```erlang
-module(avg).
-export([average/1]).

average([]) -> 0;
average(List) -> lists:sum(List) / length(List).
```

**Task:** Write `average/1` with your own recursive `sum/1` and `count/1` helpers instead of `lists:sum` and `length`.
