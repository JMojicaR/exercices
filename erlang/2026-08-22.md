## Exercise 1: Check Leap Year (Guards)
**Difficulty:** Basic
### Problem
Write a function `is_leap/1` that returns `true` if a year is a leap year, otherwise `false`. A year is a leap year if it is divisible by 4, except century years which must also be divisible by 400.

**Given Input:** `2024`, `1900`, `2000`, `2023`
**Expected Output:**
```
true
false
true
false
```
### Concepts
- Function clauses and pattern matching
- Guards (`when Year rem 4 =:= 0`)
- The guard BIFs `rem` and `=:=`

### Example / Starter Code
```erlang
-module(leap).
-export([is_leap/1, test/0]).

%% A leap year: divisible by 400, or divisible by 4 but not by 100.
is_leap(Year) when Year rem 400 =:= 0 -> true;
is_leap(Year) when Year rem 100 =:= 0 -> false;
is_leap(Year) when Year rem 4   =:= 0 -> true;
is_leap(_Year)                        -> false.

test() ->
    io:format("~p~n", [is_leap(2024)]),
    io:format("~p~n", [is_leap(1900)]),
    io:format("~p~n", [is_leap(2000)]),
    io:format("~p~n", [is_leap(2023)]).

%% Run in the Erlang shell:
%%   1> c(leap).
%%   2> leap:test().
```

## Exercise 2: GCD of Two Numbers (Recursion)
**Difficulty:** Basic
### Problem
Write a recursive function `gcd/2` that computes the greatest common divisor of two non-negative integers using Euclid's algorithm: `gcd(a, 0) = a`, otherwise `gcd(a, b) = gcd(b, a rem b)`.

**Given Input:** `gcd(48, 18)`, `gcd(101, 103)`
**Expected Output:**
```
6
1
```
### Concepts
- Recursion with a base case and a recursive case
- Tail recursion (the recursive call is the last expression)
- The `rem` operator

### Example / Starter Code
```erlang
-module(gcd).
-export([gcd/2, test/0]).

%% Base case: gcd(A, 0) is A.
%% Recursive case: gcd(A, B) = gcd(B, A rem B).
gcd(A, 0) -> A;
gcd(A, B) -> gcd(B, A rem B).

test() ->
    io:format("gcd(48, 18) = ~p~n", [gcd(48, 18)]),
    io:format("gcd(101, 103) = ~p~n", [gcd(101, 103)]).

%% Run in the Erlang shell:
%%   1> c(gcd).
%%   2> gcd:test().
```

## Exercise 3: List Comprehension — Squares 1..N
**Difficulty:** Basic
### Problem
Write a function `squares/1` that, given an integer `N`, returns the list of squares of all integers from `1` to `N`, using a list comprehension.

**Given Input:** `squares(5)`
**Expected Output:**
```
[1,4,9,16,25]
```
### Concepts
- List comprehensions `[Expr || Generator]`
- `lists:seq/2` to generate the range `1..N`

### Example / Starter Code
```erlang
-module(squares).
-export([squares/1, test/0]).

%% Build [X*X || X in [1,2,...,N]].
squares(N) -> [X * X || X <- lists:seq(1, N)].

test() ->
    io:format("squares(5) = ~p~n", [squares(5)]).

%% Run in the Erlang shell:
%%   1> c(squares).
%%   2> squares:test().
```

## Exercise 4: Sum of Even Numbers in a List
**Difficulty:** Basic
### Problem
Write a function `sum_even/1` that returns the sum of all even numbers in a list, using a list comprehension with a filter plus `lists:sum/1`.

**Given Input:** `sum_even([1,2,3,4,5,6])`
**Expected Output:**
```
12
```
### Concepts
- List comprehensions with a filter `[X || X <- List, Guard]`
- `lists:sum/1`
- The `rem` operator to test evenness

### Example / Starter Code
```erlang
-module(sum_even).
-export([sum_even/1, test/0]).

%% Filter even elements with a guard, then sum them.
sum_even(List) -> lists:sum([X || X <- List, X rem 2 =:= 0]).

test() ->
    io:format("sum_even([1,2,3,4,5,6]) = ~p~n", [sum_even([1,2,3,4,5,6])]).

%% Run in the Erlang shell:
%%   1> c(sum_even).
%%   2> sum_even:test().
```

## Exercise 5: Count Digits in an Integer
**Difficulty:** Basic
### Problem
Write a recursive function `count_digits/1` that returns the number of decimal digits in an integer. Handle `0` (which has 1 digit) and negative numbers (count the digits of their absolute value).

**Given Input:** `count_digits(12345)`, `count_digits(0)`, `count_digits(-789)`
**Expected Output:**
```
5
1
3
```
### Concepts
- Recursion with guards
- `div` for integer division
- Handling edge cases (zero and negatives)

### Example / Starter Code
```erlang
-module(count_digits).
-export([count_digits/1, test/0]).

count_digits(0) -> 1;                                   % 0 has one digit
count_digits(N) when N < 0 -> count_digits(-N);         % drop the sign
count_digits(N) when N < 10 -> 1;                       % single digit
count_digits(N) -> 1 + count_digits(N div 10).          % peel one digit off

test() ->
    io:format("count_digits(12345) = ~p~n", [count_digits(12345)]),
    io:format("count_digits(0)     = ~p~n", [count_digits(0)]),
    io:format("count_digits(-789)  = ~p~n", [count_digits(-789)]).

%% Run in the Erlang shell:
%%   1> c(count_digits).
%%   2> count_digits:test().
```
