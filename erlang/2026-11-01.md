## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** function clauses, pattern matching, guards (`when`), recursion

Compute `n!` using recursion with a base case of `fact(0) -> 1`.

**Starter code:**
```erlang
-module(factorial).
-export([fact/1]).

fact(0) -> 1;
fact(N) when N > 0 -> N * fact(N - 1).
```

```
%% In the Erlang shell:
%% c(factorial).
%% factorial:fact(5).  % => 120
```

**Task:** Add a guard that returns `{error, negative}` when `N < 0`.

## Exercise 2: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** multiple function clauses, recursion, integer arithmetic

Return the `N`-th Fibonacci number (0-indexed: `fib(0) = 0`, `fib(1) = 1`).

**Starter code:**
```erlang
-module(fibonacci).
-export([fib/1]).

fib(0) -> 0;
fib(1) -> 1;
fib(N) when N > 1 -> fib(N - 1) + fib(N - 2).
```

```
%% c(fibonacci).
%% fibonacci:fib(7).  % => 13
```

**Task:** Write a `fib_list(N)` function that returns the first `N` Fibonacci numbers as a list.

## Exercise 3: Check Prime Number
**Difficulty:** Basic
**Concepts:** guards, recursion, helper function with accumulator, `rem`

Return `true` if a number is prime, `false` otherwise.

**Starter code:**
```erlang
-module(prime).
-export([is_prime/1]).

is_prime(N) when N < 2 -> false;
is_prime(N) -> is_prime(N, 2).

is_prime(N, I) when I * I > N -> true;
is_prime(N, I) when N rem I =:= 0 -> false;
is_prime(N, I) -> is_prime(N, I + 1).
```

```
%% c(prime).
%% prime:is_prime(7).   % => true
%% prime:is_prime(10).  % => false
```

**Task:** Write a `primes_up_to(Limit)` function that returns a list of all primes below `Limit`.

## Exercise 4: Sum of Digits
**Difficulty:** Basic
**Concepts:** `div` and `rem`, recursion, base case

Return the sum of the individual digits of a number.

**Starter code:**
```erlang
-module(sumdigits).
-export([sum_digits/1]).

sum_digits(0) -> 0;
sum_digits(N) -> (N rem 10) + sum_digits(N div 10).
```

```
%% c(sumdigits).
%% sumdigits:sum_digits(1234).  % => 10
```

**Task:** Convert the number to a list of digit integers with `integer_to_list/1` and use `lists:sum/1`.

## Exercise 5: Greatest Common Divisor (GCD)
**Difficulty:** Basic
**Concepts:** Euclidean algorithm, recursion, pattern matching on `0`

Compute the greatest common divisor of two integers.

**Starter code:**
```erlang
-module(gcd).
-export([gcd/2]).

gcd(A, 0) -> A;
gcd(A, B) -> gcd(B, A rem B).
```

```
%% c(gcd).
%% gcd:gcd(48, 18).  % => 6
%% gcd:gcd(100, 35). % => 5
```

**Task:** Add an `lcm/2` function using `lcm(A, B) = A div gcd(A, B) * B`.
