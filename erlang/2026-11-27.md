# Erlang — Basic Exercises (2026-11-27)
Sources: Learn You Some Erlang, erlang.org, GeeksforGeeks, Exercism

Theme: **Binary Search Trees (BST)** — functional tuple trees, insert, search, in-order traversal, min/max.

> Erlang is immutable, so a BST is represented as nested tuples `{Value, Left, Right}` with `nil` for an empty subtree. Each operation returns a *new* tree (or a value).

## Exercise 1: Define a Node and Build a Small Tree
**Difficulty:** Basic
**Concepts:** tuples as data, module + `export`, `nil` as the empty tree

**Starter code:**
```erlang
-module(bst).
-export([build/0]).

%% A node is {Value, Left, Right}; empty tree is nil.

build() ->
    %         8
    %        / \
    %       3   10
    {8, {3, nil, nil}, {10, nil, nil}}.
```

**Task:** Extend `build/0` to produce the tree below and add a function `left_right_value/1` that returns the right child of the left child (expected `6`):
```
       8
      / \
     3   10
    / \    \
   1   6    14
```

## Exercise 2: Insert a Value into the BST
**Difficulty:** Basic
**Concepts:** recursion, guards (`when`), building a new tuple on each call

**Starter code:**
```erlang
-module(bst).
-export([insert/2]).

insert(nil, V) ->
    {V, nil, nil};
insert({V, L, R}, NewV) when NewV < V ->
    {V, insert(L, NewV), R};
insert({V, L, R}, NewV) ->
    {V, L, insert(R, NewV)}.

% Example:
% T1 = insert(nil, 8),
% T2 = insert(T1, 3),
% T3 = insert(T2, 10).
```

**Task:** Build a tree by inserting `[8, 3, 10, 1, 6, 14, 4, 7]` one at a time (e.g. with `lists:foldl(fun insert/2, nil, List)`). Confirm the top node is still `8` and its right child is `10`.

## Exercise 3: Search for a Value
**Difficulty:** Basic
**Concepts:** multiple function clauses, guards, recursion, pattern matching

**Starter code:**
```erlang
-module(bst).
-export([contains/2]).

contains(nil, _) -> false;
contains({V, _, _}, V) -> true;
contains({V, L, _}, T) when T < V -> contains(L, T);
contains({_, _, R}, T) -> contains(R, T).
```

**Task:** Modify `contains` to return the depth (steps from the root) where the value is found, or `-1` if absent. (Hint: add an accumulator parameter or use a helper `contains_depth/3`.)

## Exercise 4: In-Order Traversal (Sorted Output)
**Difficulty:** Basic
**Concepts:** recursion (left → current → right), `++` list concatenation

**Starter code:**
```erlang
-module(bst).
-export([inorder/1]).

inorder(nil) -> [];
inorder({V, L, R}) -> inorder(L) ++ [V] ++ inorder(R).
```

**Task:** Add a `preorder/1` function (current → left → right). Build the tree from `[8, 3, 10, 1, 6, 14, 4, 7]` and confirm `inorder` returns `[1,3,4,6,7,8,10,14]` while `preorder` starts with `8`.

## Exercise 5: Find the Minimum and Maximum
**Difficulty:** Basic
**Concepts:** recursion down the `left`/`right` side, pattern matching on `nil`

**Starter code:**
```erlang
-module(bst).
-export([min_value/1, max_value/1]).

min_value({V, nil, _}) -> V;
min_value({_, L, _}) -> min_value(L).

max_value({V, _, nil}) -> V;
max_value({_, _, R}) -> max_value(R).
```

**Task:** Write a `count/1` function that returns the total number of nodes in the tree, using the same recursive style. (Hint: `count(nil) -> 0; count({_, L, R}) -> 1 + count(L) + count(R).`)
