## Exercise 1: Hello, Name!
**Difficulty:** Basic
**Concepts:** Modules, exports, function clauses, `io:format`.

Write a module with a `greet/1` function that prints a greeting using the given name.

**Starter code:**
```erlang
-module(greet).
-export([greet/0, greet/1]).

greet() ->
    greet("World").

greet(Name) ->
    io:format("Hello, ~s!~n", [Name]).
```

**Task:** Add a `greet/2` clause that takes a name and a language and greets in that language.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** Guards, `rem`, boolean returns.

Write a module with `even/1` and `odd/1` functions that return `true`/`false`.

**Starter code:**
```erlang
-module(parity).
-export([even/1, odd/1]).

even(N) -> N rem 2 =:= 0.
odd(N)  -> N rem 2 =/= 0.
```

**Task:** Add a `classify/1` function that returns the atom `even` or `odd` using guards.

## Exercise 3: Factorial (Recursion)
**Difficulty:** Basic
**Concepts:** Recursion, base case, pattern matching, guards.

Write a `fact/1` function that computes the factorial of a non-negative integer.

**Starter code:**
```erlang
-module(math).
-export([fact/1]).

fact(0) -> 1;
fact(N) when N > 0 -> N * fact(N - 1).
```

**Task:** Rewrite it with a tail-recursive accumulator (`fact(N, Acc)`).

## Exercise 4: Reverse a List
**Difficulty:** Basic
**Concepts:** List pattern matching `[H|T]`, recursion, accumulators.

Write a `reverse/1` function that returns a list in reverse order (without using `lists:reverse`).

**Starter code:**
```erlang
-module(listops).
-export([reverse/1]).

reverse(L) -> reverse(L, []).
reverse([], Acc) -> Acc;
reverse([H|T], Acc) -> reverse(T, [H|Acc]).
```

**Task:** Confirm it matches `lists:reverse/1` for a few test lists.

## Exercise 5: Filter Evens & Find Max
**Difficulty:** Basic
**Concepts:** List comprehensions, recursion, guards.

Write functions that (a) return only the even elements of a list and (b) find the maximum element.

**Starter code:**
```erlang
-module(listops).
-export([evens/1, max/1]).

evens(L) -> [X || X <- L, X rem 2 =:= 0].

max([H|T]) -> max(T, H).
max([], M) -> M;
max([H|T], M) when H > M -> max(T, H);
max([_|T], M) -> max(T, M).
```

**Task:** Add a `sum/1` function that sums all elements of a list using recursion.
