## Exercise 1: Multiplication Table

**Difficulty:** Basic

### Problem
Write a function `table/1` that prints the multiplication table of a number `N` from 1 to 10 using a list comprehension over `lists:seq/2`.

**Given Input:** `mult_table:table(5).`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

### Concepts
- List comprehensions (`[ ... || ... ]`)
- `lists:seq/2`
- `io:format/2` with `~p`

### Example / Starter Code

```erlang
-module(mult_table).
-export([table/1]).

table(N) ->
    [io:format("~p x ~p = ~p~n", [N, I, N * I]) || I <- lists:seq(1, 10)].
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a function `max3/3` that returns the largest of three numbers using guarded function clauses.

**Given Input:** `largest:max3(10, 25, 15).`

**Expected Output:**
```
25
```

### Concepts
- Function clauses with guards
- Pattern matching on arguments
- `when` guards

### Example / Starter Code

```erlang
-module(largest).
-export([max3/3]).

max3(A, B, C) when A >= B, A >= C -> A;
max3(_, B, C) when B >= C -> B;
max3(_, _, C) -> C.
```

## Exercise 4: Leap Year Checker

**Difficulty:** Basic

### Problem
Write a function `is_leap/1` that returns `true` or `false` for a given year using guarded function clauses and the `rem` operator.

**Given Input:** `leap_year:is_leap(2024).`

**Expected Output:**
```
true
```

### Concepts
- Function clauses with guards
- `rem` (remainder) operator
- Guard evaluation order

### Example / Starter Code

```erlang
-module(leap_year).
-export([is_leap/1]).

is_leap(Y) when Y rem 400 =:= 0 -> true;
is_leap(Y) when Y rem 100 =:= 0 -> false;
is_leap(Y) when Y rem 4 =:= 0   -> true;
is_leap(_)                      -> false.
```

## Exercise 5: Simple Calculator

**Difficulty:** Basic

### Problem
Write a function `calc/3` that takes two numbers and an operator atom (`'+'`, `'-'`, `'*'`, `'/'`) and returns the result. Handle division by zero and invalid operators.

**Given Input:** `calculator:calc(8, 2, '/').`

**Expected Output:**
```
4.0
```

### Concepts
- Function clauses with pattern matching on the operator
- Guards on arithmetic
- Returning error tuples (`{error, _}`)

### Example / Starter Code

```erlang
-module(calculator).
-export([calc/3]).

calc(_, B, '/') when B =:= 0 -> {error, division_by_zero};
calc(A, B, '+') -> A + B;
calc(A, B, '-') -> A - B;
calc(A, B, '*') -> A * B;
calc(A, B, '/') -> A / B;
calc(_, _, _)   -> {error, invalid_operator}.
```
