# Erlang — Basic Exercises (2026-11-22)
Sources: Learn You Some Erlang, erlang.org, TutorialsPoint, learnerlang.com

Theme: **Linked Lists** — Erlang lists *are* linked lists (head + tail via cons). Exercises cover building, appending, length/sum, search, and delete via recursion and pattern matching.

## Exercise 1: Build and Print a List
**Difficulty:** Basic
**Concepts:** lists as `[Head | Tail]`, pattern matching, `io:format`, list literals

In Erlang a list `[10, 20, 30]` is really `[10 | [20 | [30 | []]]]` — a linked list of cons cells.

**Starter code:**
```erlang
-module(list1).
-export([demo/0]).

demo() ->
    List = [10, 20, 30],
    [Head | Tail] = List,        % Head = 10, Tail = [20, 30]
    io:format("Head: ~p, Tail: ~p~n", [Head, Tail]),
    io:format("~p~n", [List]).   % [10,20,30]
```

**Task:** Write a `prepend/2` function so `prepend(5, [10,20])` returns `[5,10,20]` using the `[H | T]` syntax.

## Exercise 2: Append an Element
**Difficulty:** Basic
**Concepts:** `++` operator, `lists:append/2`, building a new list

**Starter code:**
```erlang
-module(list2).
-export([append/2]).

append(Item, List) ->
    List ++ [Item].
```

**Task:** Call `append(40, [10,20,30])` and confirm it returns `[10,20,30,40]`. Note that appending with `++` walks the whole list, so prefer cons for building large lists.

## Exercise 3: Length and Sum via Recursion
**Difficulty:** Basic
**Concepts:** recursion with multiple function clauses, base case `[]`, tail recursion

**Starter code:**
```erlang
-module(list3).
-export([len/1, sum/1]).

len([]) -> 0;
len([_Head | Tail]) -> 1 + len(Tail).

sum([]) -> 0;
sum([Head | Tail]) -> Head + sum(Tail).
```

**Task:** Verify `len([4,6,8])` returns `3` and `sum([4,6,8])` returns `18`. Then rewrite `len/1` using a tail-recursive accumulator.

## Exercise 4: Search for a Value
**Difficulty:** Basic
**Concepts:** pattern matching with a matching head, recursion over the tail

**Starter code:**
```erlang
-module(list4).
-export([member/2]).

member(_Item, []) -> false;
member(Item, [Item | _Tail]) -> true;
member(Item, [_Head | Tail]) -> member(Item, Tail).
```

**Task:** Write `index_of/2` that returns the 0-based index of the first match, or `-1` (use a helper with an accumulator).

## Exercise 5: Delete an Element
**Difficulty:** Basic
**Concepts:** recursion, rebuilding the list without the matching element

**Starter code:**
```erlang
-module(list5).
-export([delete/2]).

delete(_Item, []) -> [];
delete(Item, [Item | Tail]) -> Tail;               % found: skip it
delete(Item, [Head | Tail]) -> [Head | delete(Item, Tail)].
```

**Task:** Call `delete(20, [10,20,30])` and confirm it returns `[10,30]`. Test deleting a value that is not present, and deleting the head element.
