## Exercise 2: Count Vowels
- **Difficulty:** Easy
- **Description:** Write a function `count_vowels(String)` that counts vowels (a, e, i, o, u, case-insensitive) using recursion over a list of characters. Hint: convert to lowercase with `string:lowercase/1` and check membership with `lists:member/2`.
- **Concepts:** lists, recursion, pattern matching, `string:lowercase/1`, `lists:member/2`
- **Starter code:**
```erlang
-module(vowels).
-export([count_vowels/1]).

count_vowels(String) ->
    Lower = string:lowercase(String),
    count_vowels(Lower, 0).

count_vowels([], Acc) ->
    Acc;
count_vowels([H | T], Acc) ->
    case lists:member(H, "aeiou") of
        true -> count_vowels(T, Acc + 1);
        false -> count_vowels(T, Acc)
    end.
```

## Exercise 5: Simple Calculator
