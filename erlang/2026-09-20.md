# Erlang — Basic Exercises (2026-09-20)

Level: **Basic** · Sources referenced: Learn You Some Erlang, Erlang docs, Exercism

> These exercises are written as module functions intended to be compiled and called from the Erlang shell (`erl`). Compile with `c(module_name).`, then call e.g. `module_name:fact(5).`

---

## 1. Factorial (Recursive)
**Description:** Write a recursive function `fact/1` that computes N! using pattern matching and a guard for the base case.
**Difficulty:** Basic
**Concepts:** Modules, `-export`, recursion, pattern matching, guards (`when N > 0`).
**Starter code:**
```erlang
-module(factorial).
-export([fact/1]).

fact(0) -> 1;
fact(N) when N > 0 -> N * fact(N - 1).
```
Run: `factorial:fact(5).` → `120`.

## 2. Fibonacci
**Description:** Write a recursive function `fib/1` that returns the Nth Fibonacci number (0-indexed).
**Difficulty:** Basic
**Concepts:** Recursion with multiple clauses, pattern matching, guards.
**Starter code:**
```erlang
-module(fibonacci).
-export([fib/1]).

fib(0) -> 0;
fib(1) -> 1;
fib(N) when N > 1 -> fib(N - 1) + fib(N - 2).
```
Run: `fibonacci:fib(10).` → `55`.

## 3. Sum of a List
**Description:** Write `sum_list/1` that returns the sum of all numbers in a list using recursion and the `[Head | Tail]` pattern.
**Difficulty:** Basic
**Concepts:** List construction, `[H|T]` destructuring, recursion, base case `[]`.
**Starter code:**
```erlang
-module(list_ops).
-export([sum_list/1]).

sum_list([]) -> 0;
sum_list([Head | Tail]) -> Head + sum_list(Tail).
```
Run: `list_ops:sum_list([1, 2, 3, 4]).` → `10`.

## 4. Reverse a List
**Description:** Write `reverse/1` that reverses a list using an accumulator (tail recursion).
**Difficulty:** Basic
**Concepts:** Tail recursion, accumulators, `[H|T]` destructuring, `++` (alternative non-tail version).
**Starter code:**
```erlang
-module(list_ops2).
-export([reverse/1]).

reverse(List) -> reverse(List, []).

reverse([], Acc) -> Acc;
reverse([Head | Tail], Acc) -> reverse(Tail, [Head | Acc]).
```
Run: `list_ops2:reverse([1, 2, 3]).` → `[3, 2, 1]`.

## 5. Even or Odd (Guards & Pattern Matching)
**Description:** Write `classify/1` that returns `even` or `odd` for an integer, and a clause for non-integer input.
**Difficulty:** Basic
**Concepts:** Guards (`when is_integer`), pattern matching, function clauses, atoms.
**Starter code:**
```erlang
-module(classify).
-export([classify/1]).

classify(N) when is_integer(N), N rem 2 =:= 0 -> even;
classify(N) when is_integer(N) -> odd;
classify(_) -> not_an_integer.
```
Run: `classify:classify(4).` → `even`, `classify:classify(7).` → `odd`.
