## Exercise 1: Sort a List (Bubble/Insertion Sort)

**Difficulty:** Basic

### Problem
Write a module that sorts a list of integers in ascending order. Erlang is immutable, so implement sorting functionally (e.g. an insertion sort built from recursion) instead of swapping in place.

**Given Input:** `[64, 34, 25, 12, 22, 11, 90]`

**Expected Output:**
```
[11,12,22,25,34,64,90]
```

### Concepts
- Recursion over lists
- Pattern matching `[X | T]`
- Guard `when X =< Y`

### Example / Starter Code

```erlang
-module(sort_list).
-export([bubble/1]).

insert(X, []) -> [X];
insert(X, [Y | T]) when X =< Y -> [X, Y | T];
insert(X, [Y | T]) -> [Y | insert(X, T)].

bubble([]) -> [];
bubble([X | T]) -> insert(X, bubble(T)).
```

Run with: `sort_list:bubble([64, 34, 25, 12, 22, 11, 90]).`

## Exercise 2: Linear Search

**Difficulty:** Basic

### Problem
Write a function that returns the index of a target value in a list, or `-1` if absent.

**Given Input:** list `[10, 23, 45, 70, 11, 15]`, target `70`

**Expected Output:**
```
3
```

### Concepts
- Recursion with accumulator index
- Multiple function clauses
- `case` expression

### Example / Starter Code

```erlang
-module(linear_search).
-export([search/2]).

search(_, []) -> -1;
search(X, [X | _]) -> 0;
search(X, [_ | T]) ->
    case search(X, T) of
        -1 -> -1;
        N  -> N + 1
    end.
```

Run with: `linear_search:search(70, [10, 23, 45, 70, 11, 15]).`

## Exercise 3: Anagram Check

**Difficulty:** Basic

### Problem
Write a function that checks whether two strings are anagrams, ignoring case.

**Given Input:** `"listen"`, `"silent"`

**Expected Output:**
```
true
```

### Concepts
- `string:lowercase/1`
- `lists:sort/1` on charlists
- List equality `==`

### Example / Starter Code

```erlang
-module(anagram).
-export([is_anagram/2]).

is_anagram(S1, S2) ->
    lists:sort(string:lowercase(S1)) == lists:sort(string:lowercase(S2)).
```

Run with: `anagram:is_anagram("listen", "silent").`

## Exercise 4: Greatest Common Divisor (GCD)

**Difficulty:** Basic

### Problem
Write a function that computes the GCD of two integers using the Euclidean algorithm.

**Given Input:** `48`, `18`

**Expected Output:**
```
6
```

### Concepts
- Recursion with base case `gcd(A, 0) -> A`
- `rem` operator
- Tail recursion

### Example / Starter Code

```erlang
-module(gcd).
-export([gcd/2]).

gcd(A, 0) -> A;
gcd(A, B) -> gcd(B, A rem B).
```

Run with: `gcd:gcd(48, 18).`

## Exercise 5: Armstrong Number Check

**Difficulty:** Basic

### Problem
Write a function that checks whether a number is an Armstrong number.

**Given Input:** `153`

**Expected Output:**
```
true
```

### Concepts
- `integer_to_list/1`
- `length/1` and `lists:sum/1`
- List comprehension with `math:pow/2`

### Example / Starter Code

```erlang
-module(armstrong).
-export([is_armstrong/1]).

is_armstrong(N) ->
    Digits = integer_to_list(N),
    Power = length(Digits),
    Sum = lists:sum([math:pow(D - $0, Power) || D <- Digits]),
    trunc(Sum) == N.
```

Run with: `armstrong:is_armstrong(153).`
