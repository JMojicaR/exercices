## Exercise 1: Hello World and Basic Module

**Title:** Hello, Erlang! — Modules and Functions

**Description:** Write an Erlang module that exports a function to print "Hello, World!" and another function that takes a name as an argument and returns a personalized greeting string.

**Difficulty:** ★☆☆☆☆ (Very Easy)

**Concepts Practiced:**
- Module declaration (`-module(name).`)
- Export directive (`-export([...]).`)
- Function clauses
- `io:format()` for output
- String concatenation (`++`)
- Compilation and running in the Erlang shell

**Starter Code:**
```erlang
% Exercise 1: Hello, Erlang!
-module(hello).
-export([hello/0, greet/1]).

hello() ->
    io:format("Hello, World!~n").

greet(Name) ->
    io:format("Hello, ~s! Welcome to Erlang.~n", [Name]).
```

**How to Run:**
```erlang
% In the Erlang shell:
c(hello).
hello:hello().
hello:greet("Alice").
```

## Exercise 2: Factorial Using Recursion

**Title:** Recursive Factorial with Pattern Matching

**Description:** Write an Erlang module with a function that computes the factorial of a non-negative integer using recursion and pattern matching. Handle the base case (0! = 1) and the recursive case.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Pattern matching in function heads
- Recursive functions
- Guards (`when`)
- Arithmetic in Erlang
- Tail recursion (optional extension)

**Starter Code:**
```erlang
% Exercise 2: Factorial
-module(factorial).
-export([fact/1]).

% Base case: 0! = 1
fact(0) ->
    1;
% Recursive case
fact(N) when N > 0 ->
    N * fact(N - 1).

% Tail-recursive version (bonus):
% fact_tr(N) -> fact_tr(N, 1).
% fact_tr(0, Acc) -> Acc;
% fact_tr(N, Acc) when N > 0 -> fact_tr(N - 1, N * Acc).
```

**How to Test:**
```erlang
c(factorial).
factorial:fact(0).  % → 1
factorial:fact(5).  % → 120
factorial:fact(10). % → 3628800
```

## Exercise 3: List Operations

**Title:** List Manipulation — Sum, Max, Reverse

**Description:** Write an Erlang module with functions that operate on lists: calculate the sum of all elements, find the maximum value, reverse a list, and filter even numbers. Use recursion and pattern matching on lists.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- List pattern matching (`[H|T]`)
- Recursion over lists
- Guards
- List construction (`[H|T]`)
- Accumulator pattern

**Starter Code:**
```erlang
% Exercise 3: List Operations
-module(listops).
-export([sum/1, max/1, reverse/1, filter_even/1]).

% Sum of list elements
sum([]) -> 0;
sum([H|T]) -> H + sum(T).

% Maximum value in a list
max([H]) -> H;
max([H|T]) ->
    MaxTail = max(T),
    if H > MaxTail -> H;
       true -> MaxTail
    end.

% Reverse a list (using accumulator)
reverse(List) -> reverse(List, []).
reverse([], Acc) -> Acc;
reverse([H|T], Acc) -> reverse(T, [H|Acc]).

% Filter even numbers
filter_even([]) -> [];
filter_even([H|T]) when H rem 2 == 0 ->
    [H | filter_even(T)];
filter_even([_|T]) ->
    filter_even(T).
```

**How to Test:**
```erlang
c(listops).
listops:sum([1, 2, 3, 4, 5]).        % → 15
listops:max([3, 7, 2, 9, 1]).        % → 9
listops:reverse([1, 2, 3, 4, 5]).    % → [5, 4, 3, 2, 1]
listops:filter_even([1, 2, 3, 4, 5, 6]). % → [2, 4, 6]
```

## Exercise 4: FizzBuzz in Erlang

**Title:** FizzBuzz with Guards and Recursion

**Description:** Write an Erlang module that implements FizzBuzz. The function should accept a number N and return a list of results from 1 to N. Use guards to determine whether to emit the number, "Fizz", "Buzz", or "FizzBuzz".

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Guards with `rem`
- Recursive list building
- `if` expressions or multiple function clauses
- List construction

**Starter Code:**
```erlang
% Exercise 4: FizzBuzz
-module(fizzbuzz).
-export([fizzbuzz/1, fizzbuzz_range/1]).

% Single number check
fizzbuzz(N) when N rem 15 == 0 -> "FizzBuzz";
fizzbuzz(N) when N rem 3 == 0  -> "Fizz";
fizzbuzz(N) when N rem 5 == 0  -> "Buzz";
fizzbuzz(N) -> integer_to_list(N).

% Generate FizzBuzz for range 1..N
fizzbuzz_range(N) -> fizzbuzz_range(1, N, []).

fizzbuzz_range(Current, Max, Acc) when Current > Max ->
    lists:reverse(Acc);
fizzbuzz_range(Current, Max, Acc) ->
    fizzbuzz_range(Current + 1, Max, [fizzbuzz(Current) | Acc]).
```

**How to Test:**
```erlang
c(fizzbuzz).
fizzbuzz:fizzbuzz(3).   % → "Fizz"
fizzbuzz:fizzbuzz(5).   % → "Buzz"
fizzbuzz:fizzbuzz(15).  % → "FizzBuzz"
fizzbuzz:fizzbuzz_range(16).
% → ["1","2","Fizz","4","Buzz","Fizz","7","8","Fizz","Buzz","11","Fizz","13","14","FizzBuzz","16"]
```

## Exercise 5: Simple Calculator with Case Expressions

**Title:** Expression Parser — Basic Arithmetic

**Description:** Write an Erlang module that implements a simple calculator. It should export a `calc/3` function that takes two numbers and an operator atom (add, subtract, multiply, divide) and returns the result. Use `case` expressions and handle division by zero.

**Difficulty:** ★★★☆☆ (Moderate)

**Concepts Practiced:**
- `case ... of` expressions
- Atoms as operators
- Error handling with tuples (`{ok, Result}` / `{error, Reason}`)
- Pattern matching on results
- Guards

**Starter Code:**
```erlang
% Exercise 5: Simple Calculator
-module(calc).
-export([calc/3, run/0]).

calc(A, B, add) ->
    {ok, A + B};
calc(A, B, subtract) ->
    {ok, A - B};
calc(A, B, multiply) ->
    {ok, A * B};
calc(A, B, divide) when B /= 0 ->
    {ok, A / B};
calc(_, _, divide) ->
    {error, "Division by zero"};
calc(_, _, _) ->
    {error, "Unknown operator"}.

run() ->
    io:format("Simple Calculator~n"),
    TestCases = [
        {10, 5, add},
        {10, 5, subtract},
        {10, 5, multiply},
        {10, 5, divide},
        {10, 0, divide},
        {10, 5, modulo}
    ],
    lists:foreach(fun({A, B, Op}) ->
        case calc(A, B, Op) of
            {ok, Result} ->
                io:format("~p ~p ~p = ~p~n", [A, Op, B, Result]);
            {error, Reason} ->
                io:format("Error (~p ~p ~p): ~s~n", [A, Op, B, Reason])
        end
    end, TestCases).
```

**How to Run:**
```erlang
c(calc).
calc:run().
calc:calc(10, 3, add).      % → {ok, 13}
calc:calc(10, 0, divide).   % → {error, "Division by zero"}
```
