Theme: **File I/O** — reading and writing files with the `file` module (`file:write_file`, `file:read_file`, `file:open`, `file:read_line`).

## Exercise 1: Write Text to a File
**Difficulty:** Basic
**Concepts:** `file:write_file/2`, atoms, `ok`/`error` tuples

Write a function that creates a file named `notes.txt` and writes two lines into it. `file:write_file` returns `ok` on success or `{error, Reason}` on failure.

**Starter code:**
```erlang
-module(file_write).
-export([write_notes/0]).

write_notes() ->
    Contents = <<"First line\nSecond line\n">>,
    case file:write_file("notes.txt", Contents) of
        ok -> io:format("File written.~n");
        {error, Reason} -> io:format("Error: ~p~n", [Reason])
    end.
```

**Task:** Write multiple lines by building a binary from a list of binaries with `iolist_to_binary` or by passing an `iolist` directly to `file:write_file/2`.

## Exercise 2: Read an Entire File
**Difficulty:** Basic
**Concepts:** `file:read_file/1`, binaries, pattern matching on result tuples

Write a function that reads the whole contents of `notes.txt` and prints it.

**Starter code:**
```erlang
-module(file_read).
-export([read_notes/0]).

read_notes() ->
    case file:read_file("notes.txt") of
        {ok, Bin} -> io:format("~s", [Bin]);
        {error, Reason} -> io:format("Error: ~p~n", [Reason])
    end.
```

**Task:** Convert the binary to a list of lines with `binary:split(Bin, <<"\n">>, [global])`, then print each line on its own using `lists:foreach`.

## Exercise 3: Append a Line to a File
**Difficulty:** Basic
**Concepts:** `file:open/2` with `[append]`, `file:write/2`, `file:close/1`

Write a function that adds a new line to the end of `notes.txt` without deleting the existing content.

**Starter code:**
```erlang
-module(file_append).
-export([append_notes/0]).

append_notes() ->
    case file:open("notes.txt", [append]) of
        {ok, IoDevice} ->
            file:write(IoDevice, <<"Appended line\n">>),
            file:close(IoDevice),
            io:format("Appended.~n");
        {error, Reason} ->
            io:format("Error: ~p~n", [Reason])
    end.
```

**Task:** Append the numbers 1 through 5, one per line, using a recursive function or `lists:foreach`. Then read the file back to confirm the original lines remain.

## Exercise 4: Count Lines in a File
**Difficulty:** Basic
**Concepts:** `file:open/2`, `file:read_line/1`, recursion with an accumulator, `eof`

Write a function that opens `notes.txt` and counts how many lines it contains using `file:read_line/1` in a recursive loop.

**Starter code:**
```erlang
-module(file_count).
-export([count_lines/0]).

count_lines() ->
    case file:open("notes.txt", [read]) of
        {ok, IoDevice} ->
            Count = count_lines(IoDevice, 0),
            file:close(IoDevice),
            io:format("Lines: ~p~n", [Count]);
        {error, Reason} ->
            io:format("Error: ~p~n", [Reason])
    end.

count_lines(IoDevice, Acc) ->
    case file:read_line(IoDevice) of
        {ok, _Line} -> count_lines(IoDevice, Acc + 1);
        eof -> Acc;
        {error, Reason} -> io:format("Error: ~p~n", [Reason]), Acc
    end.
```

**Task:** Also count the total number of characters by accumulating `byte_size(Line)`. Then write a version using `file:read_file/1` and `binary:split` for comparison.

## Exercise 5: Copy a File
**Difficulty:** Basic
**Concepts:** reading one file and writing another, `file:copy/2`, error handling

Write a function that copies the contents of `notes.txt` into a new file named `notes_copy.txt`.

**Starter code:**
```erlang
-module(file_copy).
-export([copy_notes/0]).

copy_notes() ->
    case file:copy("notes.txt", "notes_copy.txt") of
        {ok, _Bytes} -> io:format("Copied.~n");
        {error, Reason} -> io:format("Error: ~p~n", [Reason])
    end.
```

**Task:** Rewrite the copy manually: read the whole source with `file:read_file/1`, then write it to the destination with `file:write_file/2`. Print the number of bytes copied (`byte_size(Bin)`).
