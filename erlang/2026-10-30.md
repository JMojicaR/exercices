## Exercise 1: Linear Search
**Difficulty:** Basic
**Concepts:** recursion, pattern matching, guards, list head/tail (`[H|T]`)

Write a recursive function that searches for an element in a list and returns its 1-based position, or `not_found`.

**Starter code:**
```erlang
-module(exercises).
-export([linear_search/2]).

linear_search(List, Target) ->
    linear_search(List, Target, 1).

linear_search([H | _T], Target, Pos) when H =:= Target ->
    Pos;
linear_search([_H | T], Target, Pos) ->
    linear_search(T, Target, Pos + 1);
linear_search([], _Target, _Pos) ->
    not_found.
```

**Test:**
```erlang
1> c(exercises).
2> exercises:linear_search([10, 23, 45, 70, 11, 15], 70).
4
3> exercises:linear_search([10, 23, 45, 70, 11, 15], 99).
not_found
```

**Task:** Rewrite the function using the built-in `lists:member/2` plus `lists:nth/2`, and compare the two approaches.

## Exercise 2: Binary Search
**Difficulty:** Basic
**Concepts:** recursion, `lists:nth/2`, `lists:sublist/2`, guards, sorted input

Search for a target in a *sorted* list using binary search, halving the list each step.

**Starter code:**
```erlang
-module(exercises).
-export([binary_search/2]).

binary_search(SortedList, Target) ->
    binary_search(SortedList, Target, 1, length(SortedList)).

binary_search(_List, _Target, Low, High) when Low > High ->
    not_found;
binary_search(List, Target, Low, High) ->
    Mid = Low + ((High - Low) div 2),
    case lists:nth(Mid, List) of
        Target -> Mid;
        Val when Val < Target ->
            binary_search(List, Target, Mid + 1, High);
        _Val ->
            binary_search(List, Target, Low, Mid - 1)
    end.
```

**Test:**
```erlang
1> c(exercises).
2> exercises:binary_search([1, 3, 5, 7, 9, 11, 13], 9).
5
3> exercises:binary_search([1, 3, 5, 7, 9, 11, 13], 4).
not_found
```

**Task:** Print the current `Low`, `Mid`, and `High` (using `io:format/2`) before each comparison to visualize how the range shrinks.

## Exercise 3: Bubble Sort
**Difficulty:** Basic
**Concepts:** recursion, pattern matching, list building (`[X|Rest]`), comparison

Implement bubble sort by repeatedly bubbling the largest element to the end of the list.

**Starter code:**
```erlang
-module(exercises).
-export([bubble_sort/1]).

bubble_sort(List) ->
    bubble_sort(List, length(List)).

bubble_sort(List, 0) ->
    List;
bubble_sort(List, N) ->
    bubble_sort(bubble_pass(List), N - 1).

%% Move the largest element to the end in one pass.
bubble_pass([A, B | Rest]) when A > B ->
    [B | bubble_pass([A | Rest])];
bubble_pass([A | Rest]) ->
    [A | bubble_pass(Rest)];
bubble_pass([]) ->
    [].
```

**Test:**
```erlang
1> c(exercises).
2> exercises:bubble_sort([64, 34, 25, 12, 22, 11, 90]).
[11,12,22,25,34,64,90]
```

**Task:** Add a guard/case that stops early when a pass makes no swaps (list already sorted), and print each intermediate pass with `io:format/2`.

## Exercise 4: Find Minimum and Maximum
**Difficulty:** Basic
**Concepts:** recursion, pattern matching, accumulator pattern, `lists:min/1` and `lists:max/1`

Find the smallest and largest values in a list in a single pass using accumulators.

**Starter code:**
```erlang
-module(exercises).
-export([find_min_max/1]).

find_min_max([]) ->
    {error, empty};
find_min_max([First | Rest]) ->
    {Min, Max} = find_min_max(Rest, First, First),
    {Min, Max}.

find_min_max([], Min, Max) ->
    {Min, Max};
find_min_max([H | T], Min, Max) ->
    NewMin = case H < Min of true -> H; false -> Min end,
    NewMax = case H > Max of true -> H; false -> Max end,
    find_min_max(T, NewMin, NewMax).
```

**Test:**
```erlang
1> c(exercises).
2> exercises:find_min_max([45, 2, 78, 13, 9, 54]).
{2,78}
3> exercises:find_min_max([]).
{error,empty}
```

**Task:** Compare your result with `lists:min/1` and `lists:max/1`, and also return the *positions* of the min and max elements.

## Exercise 5: Selection Sort
**Difficulty:** Basic
**Concepts:** recursion, `lists:delete/2`, `lists:min/1`, list building, pattern matching

Implement selection sort: repeatedly take the smallest remaining element and prepend it to the result.

**Starter code:**
```erlang
-module(exercises).
-export([selection_sort/1]).

selection_sort([]) ->
    [];
selection_sort(List) ->
    Min = lists:min(List),
    [Min | selection_sort(lists:delete(Min, List))].
```

**Test:**
```erlang
1> c(exercises).
2> exercises:selection_sort([29, 10, 14, 37, 13]).
[10,13,14,29,37]
```

**Task:** Sort in *descending* order by taking the maximum each step instead, and handle duplicate values (note `lists:delete/2` removes only the first match).
