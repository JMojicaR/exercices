# Erlang — Basic Exercises (2026-11-14)
Sources: Learn You Some Erlang, erlang.org std docs, Erlang/OTP docs

Theme: **Records** — Erlang has no classes, so the OOP-equivalent basics are `-record` definitions, record construction, field access, field updates, and functions over lists of records.

## Exercise 1: Define a Book Record
**Difficulty:** Basic
**Concepts:** `-record`, record construction `#book{}`, field access with dot syntax

Define a `book` record with `title`, `author`, and `year` fields, create an instance, and print its fields.

**Starter code:**
```erlang
-module(book_basic).
-export([run/0]).

-record(book, {title, author, year}).

run() ->
    Book = #book{title = "1984", author = "George Orwell", year = 1949},
    io:format("~s by ~s (~p)~n", [Book#book.title, Book#book.author, Book#book.year]).
```

**Task:** Add a `price` field to the record, set it on the instance, and print all four fields.

## Exercise 2: Create and Use Multiple Records
**Difficulty:** Basic
**Concepts:** lists of records, `lists:foreach`, higher-order functions

Create three book records in a list and print each one using `lists:foreach`.

**Starter code:**
```erlang
-module(book_list).
-export([run/0]).

-record(book, {title, author, year}).

run() ->
    Books = [
        #book{title = "1984", author = "George Orwell", year = 1949},
        #book{title = "Dune", author = "Frank Herbert", year = 1965},
        #book{title = "Neuromancer", author = "William Gibson", year = 1984}
    ],
    lists:foreach(fun describe/1, Books).

describe(Book) ->
    io:format("~s by ~s (~p)~n", [Book#book.title, Book#book.author, Book#book.year]).
```

**Task:** Add a `price` field and sum the total price of all books with `lists:foldl`.

## Exercise 3: Functions Over Records
**Difficulty:** Basic
**Concepts:** pattern matching on records, returning computed values, `io:format`

Write functions that compute derived values from a record's fields.

**Starter code:**
```erlang
-module(book_methods).
-export([run/0]).

-record(book, {title, author, year, price}).

run() ->
    Book = #book{title = "Dune", author = "Frank Herbert", year = 1965, price = 15.99},
    io:format("Age: ~p~n", [age(Book, 2026)]),
    io:format("Discounted: ~.2f~n", [discounted_price(Book, 20)]).

age(#book{year = Year}, CurrentYear) ->
    CurrentYear - Year.

discounted_price(#book{price = Price}, Percent) ->
    Price * (1 - Percent / 100).
```

**Task:** Add an `is_classic(Book, CurrentYear) -> boolean()` function returning `true` when the book is 50+ years old, and test it on several books.

## Exercise 4: Update a Record Field
**Difficulty:** Basic
**Concepts:** record update syntax `Book#book{...}`, immutability

Write a function that returns a new book record with a discounted price, without mutating the original.

**Starter code:**
```erlang
-module(book_update).
-export([run/0]).

-record(book, {title, author, year, price}).

run() ->
    Book = #book{title = "1984", author = "George Orwell", year = 1949, price = 12.50},
    Discounted = apply_discount(Book, 20),
    io:format("Original price: ~.2f~n", [Book#book.price]),
    io:format("Discounted price: ~.2f~n", [Discounted#book.price]).

apply_discount(Book, Percent) ->
    NewPrice = Book#book.price * (1 - Percent / 100),
    Book#book{price = NewPrice}.
```

**Task:** Add a `retitle(Book, NewTitle)` function that returns a record with a new title, and verify the original record is unchanged.

## Exercise 5: A Library List of Records
**Difficulty:** Basic
**Concepts:** lists, recursive search, `string:equal`, `lists:filter`

Build functions to add books to a list, list them, and find one by title.

**Starter code:**
```erlang
-module(library).
-export([run/0]).

-record(book, {title, author, year}).

run() ->
    Library0 = [],
    Library1 = add(#book{title = "Dune", author = "Frank Herbert", year = 1965}, Library0),
    Library2 = add(#book{title = "1984", author = "George Orwell", year = 1949}, Library1),
    list_books(Library2),
    case find_by_title("dune", Library2) of
        not_found -> io:format("Not found~n");
        Book -> io:format("Found: ~s by ~s (~p)~n",
                          [Book#book.title, Book#book.author, Book#book.year])
    end.

add(Book, Library) ->
    [Book | Library].

list_books(Library) ->
    lists:foreach(fun describe/1, Library).

describe(Book) ->
    io:format("~s by ~s (~p)~n", [Book#book.title, Book#book.author, Book#book.year]).

find_by_title(_Title, []) ->
    not_found;
find_by_title(Title, [Book | Rest]) ->
    case string:equal(string:lowercase(Book#book.title), string:lowercase(Title)) of
        true -> Book;
        false -> find_by_title(Title, Rest)
    end.
```

**Task:** Add a `books_by_year(Year, Library)` function using `lists:filter` to return all books published in a given year.
