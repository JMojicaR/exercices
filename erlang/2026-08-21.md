## Exercise 1: Hello World Module

**Difficulty:** Basic

### Problem
Write a module `hello` that exports a function `hello/0` which prints `"Hello, World!"` to the console.

### Concepts
- Module declaration (`-module` / `-export`)
- `io:format/1`
- Compiling with `c(hello).` and calling `hello:hello().`

### Example / Starter Code

```erlang
-module(hello).
-export([hello/0]).

hello() ->
    io:format("Hello, World!~n").
```

**Run:**
```erlang
1> c(hello).
2> hello:hello().
Hello, World!
ok
```

## Exercise 2: Sum of List Elements

**Difficulty:** Basic

### Problem
Write a function `sum/1` that returns the sum of all elements in a list using recursion.

**Given Input:** `sum([1, 2, 3, 4])`

**Expected Output:**
```
10
```

### Concepts
- Pattern matching on `[Head | Tail]`
- Recursion with a base case
- Accumulator or direct recursion

### Example / Starter Code

```erlang
-module(list_ops).
-export([sum/1]).

sum([]) -> 0;
sum([Head | Tail]) -> Head + sum(Tail).
```

**Run:**
```erlang
1> c(list_ops).
2> list_ops:sum([1, 2, 3, 4]).
10
```

## Exercise 3: Reverse a List

**Difficulty:** Basic

### Problem
Write a function `reverse/1` that returns its list argument reversed, using a tail-recursive accumulator.

**Given Input:** `reverse([1, 2, 3, 4])`

**Expected Output:**
```
[4, 3, 2, 1]
```

### Concepts
- Tail recursion with an accumulator
- Two-clause functions (public + helper)
- Building lists with `[Head | Acc]`

### Example / Starter Code

```erlang
-module(list_ops).
-export([reverse/1]).

reverse(List) ->
    reverse(List, []).

reverse([], Acc) -> Acc;
reverse([Head | Tail], Acc) ->
    reverse(Tail, [Head | Acc]).
```

**Run:**
```erlang
1> c(list_ops).
2> list_ops:reverse([1, 2, 3, 4]).
[4,3,2,1]
```

## Exercise 4: Factorial

**Difficulty:** Basic

### Problem
Write a function `factorial/1` that returns the factorial of a non-negative integer `N`, using recursion with guards.

**Given Input:** `factorial(5)`

**Expected Output:**
```
120
```

### Concepts
- Guards (`when N > 0`)
- Multiple function clauses
- Recursion

### Example / Starter Code

```erlang
-module(math_ops).
-export([factorial/1]).

factorial(0) -> 1;
factorial(N) when N > 0 ->
    N * factorial(N - 1).
```

**Run:**
```erlang
1> c(math_ops).
2> math_ops:factorial(5).
120
```

## Exercise 5: Count Occurrences of an Element

**Difficulty:** Basic

### Problem
Write a function `count/2` that returns how many times a given element appears in a list.

**Given Input:** `count(2, [1, 2, 3, 2, 4, 2])`

**Expected Output:**
```
3
```

### Concepts
- Recursion over a list
- Pattern matching and equality (`==`)
- Multiple function clauses

### Example / Starter Code

```erlang
-module(list_ops).
-export([count/2]).

count(_, []) -> 0;
count(Elem, [Elem | Tail]) -> 1 + count(Elem, Tail);
count(Elem, [_ | Tail]) -> count(Elem, Tail).
```

**Run:**
```erlang
1> c(list_ops).
2> list_ops:count(2, [1, 2, 3, 2, 4, 2]).
3
```
