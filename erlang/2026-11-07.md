# Erlang — Basic Exercises (2026-11-07)
Sources: Learn You Some Erlang, erlang.org docs, LearnErlang, Erlang Campus

Theme: **Control Flow — Recursion, Guards & Pattern Matching** — Erlang has no `for`/`while`; the same "conditionals and loops" concepts are expressed with function clauses, guards, and recursion. Each exercise shows the idiomatic recursive form.

> To run: save the module as `exercises.erl`, then in the Erlang shell: `c(exercises).` followed by e.g. `exercises:even_or_odd(4).`

## Exercise 1: Even or Odd Checker
**Difficulty:** Basic
**Concepts:** function clauses, guards (`when N rem 2 =:= 0`), `io:format/2`

Write a function that prints whether a number is even or odd, using two clauses with guards instead of `if`/`else`.

**Starter code:**
```erlang
-module(exercises).
-export([even_or_odd/1]).

even_or_odd(N) when N rem 2 =:= 0 ->
    io:format("~p is even~n", [N]);
even_or_odd(N) ->
    io:format("~p is odd~n", [N]).
```

**Task:** Add a guard clause `when N =:= 0` before the others and print `"0 is neither"`. Then rewrite using `case N rem 2 of 0 -> ...; _ -> ... end`.

## Exercise 2: Print Numbers 1 to N
**Difficulty:** Basic
**Concepts:** recursion with a base case, head recursion, `io:format/2`

Print every integer from 1 up to and including `N`, one per line, using recursion (no loops exist in Erlang).

**Starter code:**
```erlang
-module(exercises).
-export([print_range/1]).

print_range(0) ->
    ok;
print_range(N) when N > 0 ->
    print_range(N - 1),
    io:format("~p~n", [N]).
```

**Task:** Trace why the `io:format` call placed *after* the recursive call prints in ascending order (1…N). Then write a `print_odd/1` variant that skips even numbers with a guard.

## Exercise 3: Countdown
**Difficulty:** Basic
**Concepts:** tail recursion vs head recursion, base case, `io:format/2`

Print a countdown from `N` down to 1, then print `"Liftoff!"`, using recursion.

**Starter code:**
```erlang
-module(exercises).
-export([countdown/1]).

countdown(0) ->
    io:format("Liftoff!~n");
countdown(N) when N > 0 ->
    io:format("~p~n", [N]),
    countdown(N - 1).
```

**Task:** Add a clause `countdown(N) when N < 0 -> io:format("Nothing to count~n")`. Then explain the difference between this (tail-recursive) version and the head-recursive `print_range/1` from Exercise 2.

## Exercise 4: Grade Classifier
**Difficulty:** Basic
**Concepts:** multiple guarded clauses, ordering of clauses, catch-all `_` clause

Convert a numeric score (0–100) into a letter grade using guards: 90+ → A, 80–89 → B, 70–79 → C, 60–69 → D, below 60 → F.

**Starter code:**
```erlang
-module(exercises).
-export([classify/1]).

classify(Score) when Score >= 90, Score =< 100 -> "A";
classify(Score) when Score >= 80 -> "B";
classify(Score) when Score >= 70 -> "C";
classify(Score) when Score >= 60 -> "D";
classify(Score) when Score >= 0  -> "F";
classify(_) -> "Invalid".
```

**Task:** Explain why the clauses must appear in this descending order. Then rewrite the function using a `case` expression with ranges, or add an intermediate `plus/1` that appends `"+"` for scores ending in 7–9.

## Exercise 5: Sum of Even Numbers up to N
**Difficulty:** Basic
**Concepts:** recursion with accumulator-style return values, guards, arithmetic

Return the sum of every even number from 2 up to and including `N`, using recursion.

**Starter code:**
```erlang
-module(exercises).
-export([sum_even/1]).

sum_even(0) ->
    0;
sum_even(N) when N rem 2 =:= 0 ->
    N + sum_even(N - 1);
sum_even(N) ->
    sum_even(N - 1).
```

**Task:** Rewrite using an explicit accumulator: `sum_even(N) -> sum_even(N, 0).` with `sum_even(0, Acc) -> Acc;` (tail recursion). Then add a `sum_odd/1` and verify `sum_even(N) + sum_odd(N)` equals `N*(N+1)/2` for a given `N`.
