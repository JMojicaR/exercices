# Erlang — Basic Exercises

Date: 2026-09-11 | Level: Beginner | Sources: Learn You Some Erlang, Erlang.org docs, Exercism (adapted)

## Exercise 1: Hello, World! Module
- **Difficulty:** Easy
- **Description:** Write a module `hello` that exports a function `say_hello/0` which prints "Hello, World!" using `io:format`.
- **Concepts:** modules, exports, `io:format`, the `~n` newline format specifier
- **Starter code:**
```erlang
-module(hello).
-export([say_hello/0]).

say_hello() ->
    io:format("Hello, World!~n").
```

## Exercise 2: Even or Odd with Guards
- **Difficulty:** Easy
- **Description:** Write a function `check/1` that returns the atom `even` or `odd` for a given integer using guard clauses and the `rem` operator.
- **Concepts:** pattern matching, guards, atoms, `rem`
- **Starter code:**
```erlang
-module(evenodd).
-export([check/1]).

check(N) when N rem 2 =:= 0 -> even;
check(_N) -> odd.
```

## Exercise 3: Factorial (Tail Recursion)
- **Difficulty:** Easy
- **Description:** Implement `factorial/1` using tail recursion with an accumulator. `factorial(5)` should return `120`.
- **Concepts:** recursion, tail recursion, accumulators, pattern matching on base case
- **Starter code:**
```erlang
-module(factorial).
-export([factorial/1]).

factorial(N) -> factorial(N, 1).

factorial(0, Acc) -> Acc;
factorial(N, Acc) -> factorial(N - 1, N * Acc).
```

## Exercise 4: FizzBuzz
- **Difficulty:** Easy
- **Description:** Write `fizzbuzz/1` that returns a list for numbers 1..N, mapping multiples of 3 to `"Fizz"`, 5 to `"Buzz"`, 15 to `"FizzBuzz"`, and all others to the number itself.
- **Concepts:** list comprehensions, `lists:seq/2`, guards, `rem`
- **Starter code:**
```erlang
-module(fizzbuzz).
-export([fizzbuzz/1]).

fizzbuzz(N) ->
    [fizzbuzz_value(I) || I <- lists:seq(1, N)].

fizzbuzz_value(I) when I rem 15 =:= 0 -> "FizzBuzz";
fizzbuzz_value(I) when I rem 3 =:= 0 -> "Fizz";
fizzbuzz_value(I) when I rem 5 =:= 0 -> "Buzz";
fizzbuzz_value(I) -> I.
```

## Exercise 5: Sum of a List
- **Difficulty:** Easy
- **Description:** Write `sum/1` that returns the sum of a list of integers using recursion and pattern matching on the head/tail.
- **Concepts:** list destructuring `[H | T]`, recursion, base case `[]`
- **Starter code:**
```erlang
-module(listsum).
-export([sum/1]).

sum([]) -> 0;
sum([H | T]) -> H + sum(T).
```
