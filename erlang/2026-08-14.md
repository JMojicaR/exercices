## Exercise 1: Fibonacci (Recursion)

### Problem
Write a module with a function `fib(N)` that returns the Nth Fibonacci number using recursion. `fib(0) = 0`, `fib(1) = 1`, and `fib(N) = fib(N-1) + fib(N-2)`.

**Given Input:** `fib(10)`

**Expected Output:**
```
55
```

### Concepts
- Recursion
- Multiple function clauses with pattern matching
- Guards (`when N > 1`)

### Example / Starter Code

```erlang
-module(fibonacci).
-export([fib/1]).

fib(0) -> 0;
fib(1) -> 1;
fib(N) when N > 1 ->
    fib(N - 1) + fib(N - 2).
```

Run in the Erlang shell:
```erlang
c(fibonacci).
fibonacci:fib(10).   % 55
```

## Exercise 2: Check Even or Odd

### Problem
Write a function `even(N)` that returns `true` if `N` is even and `false` if it is odd, using pattern matching and guards.

**Given Input:**
- `even(4)`
- `even(7)`

**Expected Output:**
- `true`
- `false`

### Concepts
- Guards with `rem` (remainder)
- Function clauses
- Boolean return values

### Example / Starter Code

```erlang
-module(parity).
-export([even/1, odd/1]).

even(N) when N rem 2 =:= 0 -> true;
even(_) -> false.

odd(N) when N rem 2 =/= 0 -> true;
odd(_) -> false.
```

Run in the Erlang shell:
```erlang
c(parity).
parity:even(4).   % true
parity:odd(7).    % true
```

## Exercise 3: Maximum of a List

### Problem
Write a function `max_of_list(List)` that returns the largest element in a non-empty list of numbers.

**Given Input:** `max_of_list([3, 7, 1, 9, 4])`

**Expected Output:**
```
9
```

### Concepts
- Recursion over lists (`[Head | Tail]`)
- Pattern matching on empty vs. non-empty lists
- Comparing elements

### Example / Starter Code

```erlang
-module(listmax).
-export([max_of_list/1]).

max_of_list([H]) -> H;
max_of_list([H | T]) ->
    MaxTail = max_of_list(T),
    case H > MaxTail of
        true -> H;
        false -> MaxTail
    end.
```

Run in the Erlang shell:
```erlang
c(listmax).
listmax:max_of_list([3, 7, 1, 9, 4]).   % 9
```

## Exercise 4: Count Occurrences of an Element

### Problem
Write a function `count(Element, List)` that returns how many times `Element` appears in `List`.

**Given Input:** `count(1, [1, 2, 1, 3, 1])`

**Expected Output:**
```
3
```

### Concepts
- Recursion with an accumulator
- Pattern matching for the matching element
- Guards

### Example / Starter Code

```erlang
-module(counting).
-export([count/2]).

count(_, []) -> 0;
count(Element, [Element | T]) -> 1 + count(Element, T);
count(Element, [_ | T]) -> count(Element, T).
```

Run in the Erlang shell:
```erlang
c(counting).
counting:count(1, [1, 2, 1, 3, 1]).   % 3
```

## Exercise 5: Filter Even Numbers from a List

### Problem
Write a function `filter_even(List)` that returns a new list containing only the even numbers from the input list.

**Given Input:** `filter_even([1, 2, 3, 4, 5, 6])`

**Expected Output:**
```
[2, 4, 6]
```

### Concepts
- Recursion over lists
- Building a result list (`[H | Result]`)
- Guards with `rem`
- `lists:filter/2` as a built-in alternative

### Example / Starter Code

```erlang
-module(evenfilter).
-export([filter_even/1]).

filter_even([]) -> [];
filter_even([H | T]) when H rem 2 =:= 0 ->
    [H | filter_even(T)];
filter_even([_ | T]) ->
    filter_even(T).
```

Run in the Erlang shell:
```erlang
c(evenfilter).
evenfilter:filter_even([1, 2, 3, 4, 5, 6]).   % [2,4,6]
```
