## Exercise 1: Fibonacci (recursive)
**Difficulty:** Basic
**Concepts:** recursion, pattern matching, guards

Compute the nth Fibonacci number with a naive recursive function.

**Starter code:**
```erlang
fib(0) -> 0;
fib(1) -> 1;
fib(N) when N > 1 -> fib(N - 1) + fib(N - 2).

%% erl shell:
%% > fib(10).
%% 55
```

**Task:** Add a guard clause that returns `error` for negative inputs.

## Exercise 2: GCD (Euclidean Algorithm)
**Difficulty:** Basic
**Concepts:** recursion, guards, rem

Compute the greatest common divisor using Euclid's algorithm.

**Starter code:**
```erlang
gcd(A, 0) -> A;
gcd(A, B) -> gcd(B, A rem B).

%% erl shell:
%% > gcd(48, 18).
%% 6
```

**Task:** Add a clause that normalizes negative inputs to their absolute values.

## Exercise 3: Count Occurrences of an Element in a List
**Difficulty:** Basic
**Concepts:** recursion, pattern matching, lists

Count how many times an element appears in a list.

**Starter code:**
```erlang
count(_, []) -> 0;
count(X, [X | T]) -> 1 + count(X, T);
count(X, [_ | T]) -> count(X, T).

%% erl shell:
%% > count(2, [1, 2, 3, 2]).
%% 2
```

**Task:** Write a helper that returns the element that occurs most often in the list.

## Exercise 4: Square Each Element of a List
**Difficulty:** Basic
**Concepts:** recursion, list construction

Return a new list where every element is squared.

**Starter code:**
```erlang
square([]) -> [];
square([H | T]) -> [H * H | square(T)].

%% erl shell:
%% > square([1, 2, 3, 4]).
%% [1, 4, 9, 16]
```

**Task:** Extend it to a `map/2`-style function that applies any fun to each element.

## Exercise 5: Sum of Digits of an Integer
**Difficulty:** Basic
**Concepts:** recursion, guards, div and rem

Sum the decimal digits of a non-negative integer.

**Starter code:**
```erlang
sum_digits(N) when N >= 0, N < 10 -> N;
sum_digits(N) when N >= 10 -> N rem 10 + sum_digits(N div 10).

%% erl shell:
%% > sum_digits(1234).
%% 10
```

**Task:** Add a version that returns the digital root by repeating the sum until a single digit remains.
