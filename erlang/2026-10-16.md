## Exercise 1: Reverse a List
**Difficulty:** Basic
**Concepts:** pattern matching, list recursion, accumulator

Write a function that reverses a list. Use a tail-recursive function with an accumulator.

**Starter code:**
```erlang
-module(reverse).
-export([reverse/1]).

reverse(List) -> reverse(List, []).

reverse([], Acc) ->
    Acc;
reverse([H | T], Acc) ->
    reverse(T, [H | Acc]).
```

**Task:** Verify that `reverse([1,2,3,4,5])` returns `[5,4,3,2,1]`, and reverse a list of strings.

## Exercise 2: Maximum of a List
**Difficulty:** Basic
**Concepts:** recursion, guards, list pattern matching

Write a function that returns the largest element of a list of numbers.

**Starter code:**
```erlang
-module(max_list).
-export([max_list/1]).

max_list([H | T]) -> max_list(T, H).

max_list([], Max) ->
    Max;
max_list([H | T], Max) when H > Max ->
    max_list(T, H);
max_list([_ | T], Max) ->
    max_list(T, Max).
```

**Task:** Extend it to return the minimum as well, or use `lists:max/1` to verify your result.

## Exercise 3: Multiplication Table (List Comprehension)
**Difficulty:** Basic
**Concepts:** list comprehension, arithmetic, tuples

Generate a list of `{N, I, N * I}` tuples for `I` from 1 to 10 using a list comprehension.

**Starter code:**
```erlang
-module(table).
-export([table/1]).

table(N) ->
    [{N, I, N * I} || I <- lists:seq(1, 10)].
```

**Task:** Format and print each tuple as `N x I = result` using `io:format/2`.

## Exercise 4: Armstrong Number
**Difficulty:** Basic
**Concepts:** recursion, modulo, pow, digit counting

Check whether a number is an Armstrong number (e.g. 153 = 1³ + 5³ + 3³).

**Starter code:**
```erlang
-module(armstrong).
-export([is_armstrong/1]).

is_armstrong(N) when N >= 0 ->
    Digits = digit_count(N),
    N =:= armstrong_sum(N, Digits).

armstrong_sum(0, _Digits) ->
    0;
armstrong_sum(N, Digits) ->
    D = N rem 10,
    math:pow(D, Digits) + armstrong_sum(N div 10, Digits).

digit_count(0) ->
    1;
digit_count(N) ->
    digit_count(N, 0).

digit_count(0, Count) ->
    Count;
digit_count(N, Count) ->
    digit_count(N div 10, Count + 1).
```

**Task:** Print all Armstrong numbers between 1 and 1000.

## Exercise 5: Count Digits in a Number
**Difficulty:** Basic
**Concepts:** recursion, integer division, counting

Write a function that counts the digits of an integer.

**Starter code:**
```erlang
-module(count_digits).
-export([count_digits/1]).

count_digits(0) ->
    1;
count_digits(N) ->
    count_digits(N, 0).

count_digits(0, Count) ->
    Count;
count_digits(N, Count) ->
    count_digits(N div 10, Count + 1).
```

**Task:** Use `length(integer_to_list(N))` as an alternative and verify it gives the same answer.
