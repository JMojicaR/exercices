## Exercise 1: Console Output and Variables
**Difficulty:** Basic
**Concepts:** `console.log()`, `let`/`const`, string concatenation and template literals.

Declare a few variables (name, age, country) and log a sentence using them.

**Starter code:**
```javascript
const name = "Ana";
let age = 25;
const country = "Mexico";

console.log("Hi, I'm " + name + ", I'm " + age + " and I live in " + country + ".");
```

**Task:** Rewrite the `console.log` using a template literal (backticks + `${}`).

## Exercise 2: Even or Odd Checker
**Difficulty:** Basic
**Concepts:** Conditionals (`if`/`else`), modulo operator (`%`), `parseInt`/`Number`.

Write a function that takes a number and returns `"Even"` or `"Odd"`.

**Starter code:**
```javascript
function evenOrOdd(num) {
  if (num % 2 === 0) {
    return "Even";
  } else {
    return "Odd";
  }
}

console.log(evenOrOdd(7)); // Odd
```

**Task:** Extend it to return `"Zero"` when the input is `0`.

## Exercise 3: FizzBuzz
**Difficulty:** Basic
**Concepts:** Loops (`for`), conditionals, string building.

Print numbers 1 to 20. For multiples of 3 print "Fizz", for multiples of 5 print "Buzz", and for multiples of both print "FizzBuzz".

**Starter code:**
```javascript
for (let i = 1; i <= 20; i++) {
  if (i % 15 === 0) {
    console.log("FizzBuzz");
  } else if (i % 3 === 0) {
    console.log("Fizz");
  } else if (i % 5 === 0) {
    console.log("Buzz");
  } else {
    console.log(i);
  }
}
```

**Task:** Change the loop so it runs from 1 to 100.

## Exercise 4: Sum of an Array
**Difficulty:** Basic
**Concepts:** Arrays, loops, accumulator pattern, array methods.

Write a function that returns the sum of all numbers in an array.

**Starter code:**
```javascript
function sumArray(arr) {
  let total = 0;
  for (let i = 0; i < arr.length; i++) {
    total += arr[i];
  }
  return total;
}

console.log(sumArray([1, 2, 3, 4, 5])); // 15
```

**Task:** Reimplement it using `Array.prototype.reduce`.

## Exercise 5: Reverse a String
**Difficulty:** Basic
**Concepts:** Strings, string indexing, loops, `.split()`, `.reverse()`, `.join()`.

Write a function that returns the reverse of a given string.

**Starter code:**
```javascript
function reverseString(str) {
  let result = "";
  for (let i = str.length - 1; i >= 0; i--) {
    result += str[i];
  }
  return result;
}

console.log(reverseString("hello")); // "olleh"
```

**Task:** Write a second version using `str.split("").reverse().join("")`.
