## 1. Reverse a String
**Description:** Write a function that takes a string and returns it reversed. Test it with a few inputs and log the results to the console.
**Difficulty:** Basic
**Concepts:** Functions, strings, `split()`, `reverse()`, `join()`, `console.log`.
**Starter code:**
```javascript
function reverseString(str) {
  return str.split("").reverse().join("");
}

console.log(reverseString("hello")); // "olleh"
console.log(reverseString("javascript")); // "tpircsavaj"
```

## 2. Prime Number Check
**Description:** Write a function that returns `true` if a number is prime (greater than 1 and divisible only by 1 and itself) and `false` otherwise.
**Difficulty:** Basic
**Concepts:** `for` loop, modulo `%`, `if/else`, booleans, `Math.sqrt()`.
**Starter code:**
```javascript
function isPrime(n) {
  if (n < 2) return false;
  for (let i = 2; i <= Math.sqrt(n); i++) {
    if (n % i === 0) return false;
  }
  return true;
}

console.log(isPrime(7));  // true
console.log(isPrime(10)); // false
```

## 3. Sum of Digits
**Description:** Given a positive integer, compute the sum of its digits using a loop (e.g. 123 → 6).
**Difficulty:** Basic
**Concepts:** `while` loop, modulo `%`, `Math.floor()`, arithmetic.
**Starter code:**
```javascript
function sumOfDigits(num) {
  let sum = 0;
  while (num > 0) {
    sum += num % 10;
    num = Math.floor(num / 10);
  }
  return sum;
}

console.log(sumOfDigits(1234)); // 10
```

## 4. Leap Year Check
**Description:** Write a function that determines whether a year is a leap year (divisible by 4, but not by 100 unless also divisible by 400).
**Difficulty:** Basic
**Concepts:** Conditionals, modulo `%`, logical operators `&&` and `||`.
**Starter code:**
```javascript
function isLeapYear(year) {
  return (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
}

console.log(isLeapYear(2024)); // true
console.log(isLeapYear(1900)); // false
console.log(isLeapYear(2000)); // true
```

## 5. Largest and Smallest in an Array
**Description:** Find and print the largest and smallest values in an array of numbers, without using `Math.max`/`Math.min` with spread.
**Difficulty:** Basic
**Concepts:** Arrays, `for` loop, comparison logic, indexing.
**Starter code:**
```javascript
function minMax(numbers) {
  let min = numbers[0];
  let max = numbers[0];
  for (const n of numbers) {
    if (n < min) min = n;
    if (n > max) max = n;
  }
  return { min, max };
}

console.log(minMax([3, 9, 1, 7, 4])); // { min: 1, max: 9 }
```
