## Exercise 1: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** arrays, `for` loop, accumulation, `reduce()`

Compute the sum of all numbers in an array.

**Starter code:**
```javascript
const numbers = [10, 20, 30, 40, 50];
let total = 0;
for (let i = 0; i < numbers.length; i++) {
  total += numbers[i];
}
console.log("Sum:", total);
```

**Task:** Rewrite it using `numbers.reduce((acc, n) => acc + n, 0)`.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** modulo operator (`%`), `if/else`

Check whether a number is even or odd.

**Starter code:**
```javascript
function isEven(n) {
  return n % 2 === 0;
}
console.log(isEven(4) ? "even" : "odd");
console.log(isEven(7) ? "even" : "odd");
```

**Task:** Print all even numbers from 1 to 20.

## Exercise 3: Celsius to Fahrenheit
**Difficulty:** Basic
**Concepts:** arithmetic, functions, template literals

Convert Celsius to Fahrenheit using `F = C × 9/5 + 32`.

**Starter code:**
```javascript
function cToF(celsius) {
  return (celsius * 9 / 5) + 32;
}
console.log(`20°C = ${cToF(20)}°F`);
```

**Task:** Add a `fToC` function that converts Fahrenheit back to Celsius.

## Exercise 4: Find the Smallest Number
**Difficulty:** Basic
**Concepts:** arrays, comparison, `Math.min()`

Find the smallest value in an array.

**Starter code:**
```javascript
const numbers = [45, 12, 78, 4, 33];
let smallest = numbers[0];
for (const n of numbers) {
  if (n < smallest) smallest = n;
}
console.log("Smallest:", smallest);
```

**Task:** Solve it with `Math.min(...numbers)`.

## Exercise 5: Simple Interest
**Difficulty:** Basic
**Concepts:** variables, arithmetic, functions

Calculate simple interest using `SI = (P × R × T) / 100`.

**Starter code:**
```javascript
function simpleInterest(principal, rate, time) {
  return (principal * rate * time) / 100;
}
console.log("Interest:", simpleInterest(1000, 5, 3));
```

**Task:** Also return the total amount (principal + interest).
