## Exercise 1: Define a Book Class
**Difficulty:** Basic
**Concepts:** `class`, `constructor`, `this`, instance properties

Create a `Book` class whose constructor stores a `title`, `author`, and `year`, then instantiate one object and log its properties.

**Starter code:**
```javascript
class Book {
  constructor(title, author, year) {
    this.title = title;
    this.author = author;
    this.year = year;
  }
}

const book = new Book("1984", "George Orwell", 1949);
console.log(book.title, book.author, book.year);
```

**Task:** Add a `price` property with a default value of `0`, and create a second book, logging all four properties.

## Exercise 2: Create and Use Multiple Objects
**Difficulty:** Basic
**Concepts:** `new`, method on prototype, `toString()`, arrays of objects

Create a `Book` class with a `describe()` method, instantiate three books, and print each by looping over an array.

**Starter code:**
```javascript
class Book {
  constructor(title, author, year) {
    this.title = title;
    this.author = author;
    this.year = year;
  }

  describe() {
    return `${this.title} by ${this.author} (${this.year})`;
  }
}

const books = [
  new Book("1984", "George Orwell", 1949),
  new Book("Dune", "Frank Herbert", 1965),
  new Book("Neuromancer", "William Gibson", 1984),
];

for (const b of books) {
  console.log(b.describe());
}
```

**Task:** Add a `price` property and compute the total price of all books using `reduce()`.

## Exercise 3: Add Instance Methods
**Difficulty:** Basic
**Concepts:** methods, `this`, return values, method calls on objects

Add methods that compute derived values from the object's own properties.

**Starter code:**
```javascript
class Book {
  constructor(title, author, year, price) {
    this.title = title;
    this.author = author;
    this.year = year;
    this.price = price;
  }

  age(currentYear) {
    return currentYear - this.year;
  }

  discountedPrice(percent) {
    return this.price * (1 - percent / 100);
  }
}

const book = new Book("Dune", "Frank Herbert", 1965, 15.99);
console.log(book.age(2026));
console.log(book.discountedPrice(20).toFixed(2));
```

**Task:** Add an `isClassic(currentYear)` method returning a boolean when the book is 50+ years old, and test it on several books.

## Exercise 4: Getters and Setters
**Difficulty:** Basic
**Concepts:** `get`/`set` accessors, backing property, validation

Protect the `price` property by routing it through a getter/setter pair that rejects negative values.

**Starter code:**
```javascript
class Book {
  constructor(title, author, year, price) {
    this.title = title;
    this.author = author;
    this.year = year;
    this._price = price;
  }

  get price() {
    return this._price;
  }

  set price(value) {
    if (value < 0) {
      throw new Error("price cannot be negative");
    }
    this._price = value;
  }
}

const book = new Book("1984", "George Orwell", 1949, 12.5);
console.log(book.price);
book.price = 10.0;
console.log(book.price);
```

**Task:** Add a getter `label` that returns `"title — author"`, and demonstrate what happens when you try `book.price = -1` inside a `try/catch`.

## Exercise 5: A Library That Holds Books
**Difficulty:** Basic
**Concepts:** composition, class holding an array of objects, search methods

Build a `Library` class that stores `Book` objects and can add, list, and find them.

**Starter code:**
```javascript
class Book {
  constructor(title, author, year) {
    this.title = title;
    this.author = author;
    this.year = year;
  }

  describe() {
    return `${this.title} by ${this.author} (${this.year})`;
  }
}

class Library {
  constructor() {
    this.books = [];
  }

  add(book) {
    this.books.push(book);
  }

  find(title) {
    return this.books.find((b) => b.title.toLowerCase() === title.toLowerCase());
  }

  list() {
    this.books.forEach((b) => console.log(b.describe()));
  }
}

const lib = new Library();
lib.add(new Book("Dune", "Frank Herbert", 1965));
lib.add(new Book("1984", "George Orwell", 1949));
lib.list();
console.log(lib.find("dune"));
```

**Task:** Add a `count()` getter and a `booksByYear(year)` method returning a filtered array of books published in a given year.
