## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** `for` loop, function, `let`, recursion

Compute `n! = 1 × 2 × … × n` (with `0! = 1`).

**Starter code:**
```javascript
function factorial(n) {
  let result = 1;
  for (let i = 1; i <= n; i++) {
    result *= i;
  }
  return result;
}

console.log(factorial(5)); // 120
console.log(factorial(0)); // 1
```

**Task:** Rewrite the function using recursion — `factorial(n) = n * factorial(n - 1)` with base case `factorial(0) = 1`.

## Exercise 2: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** arrays, `push()`, indexing, `for` loop

Return the first `n` Fibonacci numbers as an array (`0, 1, 1, 2, 3, 5, …`).

**Starter code:**
```javascript
function fibonacci(n) {
  const seq = [0, 1];
  for (let i = 2; i < n; i++) {
    seq.push(seq[i - 1] + seq[i - 2]);
  }
  return seq.slice(0, n);
}

console.log(fibonacci(7)); // [0, 1, 1, 2, 3, 5, 8]
```

**Task:** Handle `n = 0` and `n = 1` explicitly (return `[]` and `[0]`), then print the result with `seq.join(" ")`.

## Exercise 3: Check Prime Number
**Difficulty:** Basic
**Concepts:** modulo `%`, `Math.sqrt`, `for` loop, early return

Return `true` if a number is prime, `false` otherwise.

**Starter code:**
```javascript
function isPrime(n) {
  if (n < 2) return false;
  for (let i = 2; i <= Math.sqrt(n); i++) {
    if (n % i === 0) return false;
  }
  return true;
}

console.log(isPrime(7));  // true
console.log(isPrime(10)); // false
```

**Task:** Write a `listPrimes(limit)` function that returns an array of all primes up to `limit`.

## Exercise 4: Sum of Digits
**Difficulty:** Basic
**Concepts:** `Math.floor`, `%`, `while` loop, type conversion

Return the sum of the individual digits of a number.

**Starter code:**
```javascript
function sumOfDigits(n) {
  let total = 0;
  while (n > 0) {
    total += n % 10;
    n = Math.floor(n / 10);
  }
  return total;
}

console.log(sumOfDigits(1234)); // 10
```

**Task:** Rewrite it using `String(n).split("")` and `.reduce()`, then compare both approaches.

## Exercise 5: Greatest Common Divisor (GCD)
**Difficulty:** Basic
**Concepts:** Euclidean algorithm, `while` loop, destructuring assignment, `%`

Compute the greatest common divisor of two integers.

**Starter code:**
```javascript
function gcd(a, b) {
  while (b !== 0) {
    [a, b] = [b, a % b];
  }
  return a;
}

console.log(gcd(48, 18)); // 6
console.log(gcd(100, 35)); // 5
```

**Task:** Add an `lcm(a, b)` function using `lcm(a, b) = (a * b) / gcd(a, b)`.
