## Exercise 1: Variables & Data Types
**Difficulty:** ★☆☆☆☆  
**Concepts:** Variables (let/const), data types, console.log, template literals  

**Description:**  
Declare variables of different data types (string, number, boolean, array, object). Print each variable's value and type to the console. Then create a short profile object with name, age, and hobbies, and log a formatted description.

**Example Starter Code:**
```javascript
// Declare variables of different types
const name = "Alice";
const age = 25;
const isStudent = true;
const hobbies = ["reading", "coding", "hiking"];
const address = {
    city: "San Francisco",
    state: "California",
    zip: "94105"
};

// Log each variable with its type
console.log(`name: ${name} (${typeof name})`);
console.log(`age: ${age} (${typeof age})`);
console.log(`isStudent: ${isStudent} (${typeof isStudent})`);
console.log(`hobbies: ${hobbies} (${typeof hobbies})`);
console.log(`address: ${JSON.stringify(address)} (${typeof address})`);

// Profile description
const profile = { name, age, hobbies, address };
console.log(`${profile.name} is ${profile.age} years old and lives in ${profile.address.city}.`);
console.log(`Their hobbies include: ${profile.hobbies.join(", ")}.`);
```

## Exercise 2: Interactive Counter
**Difficulty:** ★★☆☆☆  
**Concepts:** DOM manipulation, event listeners, functions  

**Description:**  
Create an HTML page with a counter. The page should display a number and have three buttons: "Increase", "Decrease", and "Reset". When clicked, the counter updates accordingly. The counter should not go below 0.

**Example Starter Code:**
```html
<!DOCTYPE html>
<html>
<head>
    <title>Counter</title>
    <style>
        body { font-family: Arial; text-align: center; margin-top: 50px; }
        #counter { font-size: 48px; margin: 20px; }
        button { font-size: 18px; padding: 10px 20px; margin: 5px; }
    </style>
</head>
<body>
    <h1>Interactive Counter</h1>
    <div id="counter">0</div>
    <button id="increase">Increase</button>
    <button id="decrease">Decrease</button>
    <button id="reset">Reset</button>

    <script>
        let count = 0;
        const counterDisplay = document.getElementById('counter');

        function updateDisplay() {
            counterDisplay.textContent = count;
        }

        document.getElementById('increase').addEventListener('click', () => {
            count++;
            updateDisplay();
        });

        document.getElementById('decrease').addEventListener('click', () => {
            if (count > 0) {
                count--;
                updateDisplay();
            }
        });

        document.getElementById('reset').addEventListener('click', () => {
            count = 0;
            updateDisplay();
        });
    </script>
</body>
</html>
```

## Exercise 3: Array Operations
**Difficulty:** ★★☆☆☆  
**Concepts:** Arrays, array methods (map, filter, reduce, forEach)  

**Description:**  
Given an array of numbers, perform these operations using array methods:
1. Double each number (map)
2. Filter out numbers less than 10 (filter)
3. Calculate the sum (reduce)
4. Find the maximum value

**Example Starter Code:**
```javascript
const numbers = [3, 7, 12, 5, 9, 15, 2, 8];

// 1. Double each number
const doubled = numbers.map(num => num * 2);
console.log("Doubled:", doubled);

// 2. Filter numbers less than 10
const filtered = numbers.filter(num => num < 10);
console.log("Numbers < 10:", filtered);

// 3. Sum all numbers
const sum = numbers.reduce((acc, num) => acc + num, 0);
console.log("Sum:", sum);

// 4. Find maximum
const max = Math.max(...numbers);
console.log("Maximum:", max);
```

**Expected Output:**
```
Doubled: [6, 14, 24, 10, 18, 30, 4, 16]
Numbers < 10: [3, 7, 5, 9, 2, 8]
Sum: 61
Maximum: 15
```

## Exercise 4: FizzBuzz
**Difficulty:** ★★☆☆☆  
**Concepts:** Loops, conditionals, modulo operator  

**Description:**  
Write the classic FizzBuzz program. Print numbers from 1 to 100. For multiples of 3, print "Fizz" instead of the number. For multiples of 5, print "Buzz". For numbers that are multiples of both 3 and 5, print "FizzBuzz".

**Example Starter Code:**
```javascript
for (let i = 1; i <= 100; i++) {
    if (i % 3 === 0 && i % 5 === 0) {
        console.log("FizzBuzz");
    } else if (i % 3 === 0) {
        console.log("Fizz");
    } else if (i % 5 === 0) {
        console.log("Buzz");
    } else {
        console.log(i);
    }
}
```

**Expected Output (first few lines):**
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
...
```

## Exercise 5: String Reverser
**Difficulty:** ★★★☆☆  
**Concepts:** String manipulation, functions, arrow functions  

**Description:**  
Write a function `reverseString(str)` that returns the reversed version of the input string. Then extend it to also count vowels and consonants in the string. Create a small interactive program that asks for a string (using prompt or an input field) and displays the reversed string along with vowel/consonant counts.

**Example Starter Code:**
```javascript
function reverseString(str) {
    return str.split('').reverse().join('');
}

function countVowelsAndConsonants(str) {
    const cleaned = str.toLowerCase().replace(/[^a-z]/g, '');
    const vowels = cleaned.match(/[aeiou]/g) || [];
    const consonants = cleaned.match(/[^aeiou]/g) || [];
    
    return {
        reversed: reverseString(str),
        vowels: vowels.length,
        consonants: consonants.length,
        total: cleaned.length
    };
}

// Test
const testStrings = ["Hello World", "JavaScript", "OpenAI"];
testStrings.forEach(s => {
    const result = countVowelsAndConsonants(s);
    console.log(`"${s}"`);
    console.log(`  Reversed: "${result.reversed}"`);
    console.log(`  Vowels: ${result.vowels}, Consonants: ${result.consonants}`);
});
```

**Expected Output:**
```
"Hello World"
  Reversed: "dlroW olleH"
  Vowels: 3, Consonants: 7
"JavaScript"
  Reversed: "tpircSavaJ"
  Vowels: 3, Consonants: 7
"OpenAI"
  Reversed: "IAnepO"
  Vowels: 4, Consonants: 2
```
