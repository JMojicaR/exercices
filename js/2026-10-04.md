## Exercise 1: Fibonacci Sequence
**Difficulty:** Basic
**Concepts:** loops, arrays, assignment

Generate the first `n` numbers of the Fibonacci sequence and store them in an array.

**Starter code:**
```javascript
function fibonacci(n) {
  let seq = [0, 1];
  for (let i = 2; i < n; i++) {
    seq.push(seq[i - 1] + seq[i - 2]);
  }
  return seq.slice(0, n);
}

console.log(fibonacci(10));
```

**Task:** Modify the function so it returns only the odd Fibonacci numbers in the sequence.

## Exercise 2: Count Occurrences of a Character
**Difficulty:** Basic
**Concepts:** strings, loops, charAt

Count how many times a given character appears in a string.

**Starter code:**
```javascript
function countChar(str, ch) {
  let count = 0;
  for (let i = 0; i < str.length; i++) {
    if (str[i] === ch) {
      count++;
    }
  }
  return count;
}

console.log(countChar("hello world", "l"));
```

**Task:** Make the function case-insensitive so it counts both uppercase and lowercase matches.

## Exercise 3: Leap Year Check
**Difficulty:** Basic
**Concepts:** conditionals, modulo, boolean logic

Determine whether a given year is a leap year (divisible by 4, but not by 100 unless also by 400).

**Starter code:**
```javascript
function isLeapYear(year) {
  return (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
}

console.log(isLeapYear(2024));
```

**Task:** Write a loop that prints every leap year between 2000 and 2050.

## Exercise 4: Find the Largest Number in an Array
**Difficulty:** Basic
**Concepts:** arrays, loops, comparisons

Find and return the largest number in an array of numbers.

**Starter code:**
```javascript
function findLargest(arr) {
  let largest = arr[0];
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] > largest) {
      largest = arr[i];
    }
  }
  return largest;
}

console.log(findLargest([3, 7, 2, 9, 5]));
```

**Task:** Also return the smallest number, and print both values together.

## Exercise 5: Simple Calculator with switch
**Difficulty:** Basic
**Concepts:** switch statement, operators, functions

Build a calculator function that takes two numbers and an operator string and returns the result using a `switch` statement.

**Starter code:**
```javascript
function calculate(a, b, op) {
  switch (op) {
    case "+":
      return a + b;
    case "-":
      return a - b;
    case "*":
      return a * b;
    case "/":
      return a / b;
    default:
      return "Invalid operator";
  }
}

console.log(calculate(8, 4, "+"));
```

**Task:** Add a case that returns an error message when dividing by zero.
