## Exercise 1: Celsius to Fahrenheit Converter
- **Difficulty**: Basic
- **Concepts**: Variables, arithmetic operators, functions, console output
- **Description**: Write a function that converts a temperature from Celsius to Fahrenheit. The formula is: F = (C × 9/5) + 32. Test it with a few values and log the results to the console.

### Example/Starter Code
```javascript
function celsiusToFahrenheit(celsius) {
    // Your code here
    return (celsius * 9/5) + 32;
}

// Test the function
let tempC = 25;
let tempF = celsiusToFahrenheit(tempC);
console.log(`${tempC}°C is ${tempF}°F`);

// Try more values
console.log(`0°C = ${celsiusToFahrenheit(0)}°F`);
console.log(`100°C = ${celsiusToFahrenheit(100)}°F`);
```

## Exercise 2: Palindrome Checker
- **Difficulty**: Basic
- **Concepts**: String methods, arrays, loops, conditional statements
- **Description**: Write a function that checks if a given string is a palindrome (reads the same forwards and backwards). Ignore case and spaces. For example, "racecar" and "A man a plan a canal Panama" should both return true.

### Example/Starter Code
```javascript
function isPalindrome(str) {
    // Remove spaces and convert to lowercase
    let cleaned = str.replace(/\s/g, '').toLowerCase();
    // Reverse and compare
    let reversed = cleaned.split('').reverse().join('');
    return cleaned === reversed;
}

console.log(isPalindrome("racecar"));      // true
console.log(isPalindrome("hello"));        // false
console.log(isPalindrome("A Santa at NASA")); // true
```

## Exercise 3: Find the Largest Number in an Array
- **Difficulty**: Basic
- **Concepts**: Arrays, loops, conditional statements, comparison operators
- **Description**: Write a function that takes an array of numbers and returns the largest number. Do not use `Math.max()` — implement the logic manually using a loop to practice iteration and comparison.

### Example/Starter Code
```javascript
function findLargest(arr) {
    // Assume the first element is the largest
    let largest = arr[0];
    // Loop through the array
    for (let i = 1; i < arr.length; i++) {
        if (arr[i] > largest) {
            largest = arr[i];
        }
    }
    return largest;
}

let numbers = [3, 7, 2, 9, 1, 5];
console.log(`Largest number: ${findLargest(numbers)}`); // 9
```

## Exercise 4: Count Vowels in a String
- **Difficulty**: Basic
- **Concepts**: Strings, loops, conditional statements, character checking
- **Description**: Write a function that counts the number of vowels (a, e, i, o, u) in a given string. Count both uppercase and lowercase vowels. For example, "Hello World" should return 3.

### Example/Starter Code
```javascript
function countVowels(str) {
    let count = 0;
    let vowels = 'aeiouAEIOU';
    
    for (let char of str) {
        if (vowels.includes(char)) {
            count++;
        }
    }
    return count;
}

console.log(countVowels("Hello World"));      // 3
console.log(countVowels("JavaScript"));       // 3
console.log(countVowels("AEIOU aeiou"));      // 10
```

## Exercise 5: Multiplication Table Generator
- **Difficulty**: Basic
- **Concepts**: Nested loops, string formatting, console output
- **Description**: Write a program that prints a multiplication table for numbers 1 through 10. Use nested loops: the outer loop iterates through the multiplicand (1 to 10), and the inner loop iterates through the multiplier (1 to 10). Format the output neatly as a grid.

### Example/Starter Code
```javascript
function multiplicationTable() {
    for (let i = 1; i <= 10; i++) {
        let row = '';
        for (let j = 1; j <= 10; j++) {
            // Pad single-digit numbers to align columns
            let product = String(i * j).padStart(4, ' ');
            row += product;
        }
        console.log(row);
    }
}

multiplicationTable();
```
