## 2. Even or Odd
- **Description**: Write a function that takes a number and returns whether it is even or odd.
- **Difficulty**: Beginner
- **Concepts**: Functions, `%` operator, `if/else`
- **Example/Starter code**:
```javascript
function evenOrOdd(number) {
  if (number % 2 === 0) {
    return number + " is even";
  } else {
    return number + " is odd";
  }
}
console.log(evenOrOdd(7)); // 7 is odd
```

## 3. Factorial
- **Description**: Write a function that computes the factorial of a non-negative integer n (n! = n × (n-1) × ... × 1).
- **Difficulty**: Beginner
- **Concepts**: Functions, `for` loops, accumulation
- **Example/Starter code**:
```javascript
function factorial(n) {
  let result = 1;
  for (let i = 1; i <= n; i++) {
    result *= i;
  }
  return result;
}
console.log(factorial(5)); // 120
```

## 4. Reverse a String
- **Description**: Write a function that reverses a given string.
- **Difficulty**: Beginner
- **Concepts**: Strings, arrays, `split()`, `reverse()`, `join()`
- **Example/Starter code**:
```javascript
function reverseString(str) {
  return str.split("").reverse().join("");
}
console.log(reverseString("hello")); // olleh
```

## 5. Largest Number in an Array
- **Description**: Write a function that returns the largest number in a given array of numbers.
- **Difficulty**: Beginner
- **Concepts**: Arrays, `for` loops, comparison, `Math.max()`
- **Example/Starter code**:
```javascript
function findLargest(numbers) {
  let largest = numbers[0];
  for (let i = 1; i < numbers.length; i++) {
    if (numbers[i] > largest) {
      largest = numbers[i];
    }
  }
  return largest;
}
console.log(findLargest([3, 9, 1, 14, 6])); // 14
```
