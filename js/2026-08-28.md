## Exercise 1: Hello World & Variables

**Difficulty:** Basic

### Problem
Write a program that logs "Hello, World!" to the console, then declares a constant `name` and a `let` variable `age`, and logs a sentence combining them using template literals.

**Expected Output (console):**
```
Hello, World!
Alice is 25 years old.
```

### Concepts
- `console.log()`
- `const` vs `let`
- Template literals (`${...}`)

### Example / Starter Code

```javascript
console.log("Hello, World!");

const name = "Alice";
let age = 25;

console.log(`${name} is ${age} years old.`);
```

## Exercise 2: Even or Odd

**Difficulty:** Basic

### Problem
Write a function `isEven(n)` that returns `true` if a number is even and `false` otherwise, using the modulo operator. Then log a message for a sample input.

**Given Input:** `7`

**Expected Output (console):**
```
7 is Odd
```

### Concepts
- Function declaration
- `if`/`else` and the modulo operator `%`
- Returning boolean values

### Example / Starter Code

```javascript
function isEven(n) {
  return n % 2 === 0;
}

const num = 7;
if (isEven(num)) {
  console.log(`${num} is Even`);
} else {
  console.log(`${num} is Odd`);
}
```

## Exercise 3: Sum of Numbers 1 to N

**Difficulty:** Basic

### Problem
Write a program that computes and logs the sum of all integers from 1 to a given `n` using a `for` loop.

**Given Input:** `10`

**Expected Output (console):**
```
Sum from 1 to 10 is 55
```

### Concepts
- `for` loop
- Accumulator variable

### Example / Starter Code

```javascript
const n = 10;
let total = 0;

for (let i = 1; i <= n; i++) {
  total += i;
}

console.log(`Sum from 1 to ${n} is ${total}`);
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a function `countVowels(str)` that counts the vowels (a, e, i, o, u) in a string, ignoring case.

**Given Input:** `"Hello World"`

**Expected Output (console):**
```
Number of vowels: 3
```

### Concepts
- Iterating over a string with `for...of`
- `.toLowerCase()` and `.includes()`

### Example / Starter Code

```javascript
function countVowels(str) {
  const vowels = "aeiou";
  let count = 0;
  for (const char of str.toLowerCase()) {
    if (vowels.includes(char)) {
      count++;
    }
  }
  return count;
}

console.log("Number of vowels:", countVowels("Hello World"));
```

## Exercise 5: Filter Even Numbers from an Array

**Difficulty:** Basic

### Problem
Given an array of numbers, return a new array containing only the even numbers. Solve it twice: once with a `for` loop and once with the `.filter()` method.

**Given Input:** `[1, 2, 3, 4, 5, 6, 7, 8]`

**Expected Output (console):**
```
[2, 4, 6, 8]
```

### Concepts
- Arrays
- `.filter()` array method
- Arrow functions

### Example / Starter Code

```javascript
const numbers = [1, 2, 3, 4, 5, 6, 7, 8];

// Loop version
const evensLoop = [];
for (const n of numbers) {
  if (n % 2 === 0) evensLoop.push(n);
}

// Filter version
const evens = numbers.filter((n) => n % 2 === 0);

console.log(evens);
```
