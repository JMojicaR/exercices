## Exercise 1: Even or Odd Check

**Difficulty:** Basic

### Problem
Write a function `isEven(n)` that returns `true` if a number is even and `false` otherwise.

**Given Input:**
- `isEven(4)`
- `isEven(7)`

**Expected Output:**
- `true`
- `false`

### Concepts
- Function declarations
- Modulo operator (`%`)
- Strict equality (`===`)
- Boolean return values

### Example / Starter Code

```javascript
function isEven(n) {
  return n % 2 === 0;
}

console.log(isEven(4));  // true
console.log(isEven(7));  // false
```

## Exercise 2: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a function `factorial(n)` that returns the factorial of a non-negative integer using a loop.

**Given Input:** `factorial(5)`

**Expected Output:**
```
120
```

### Concepts
- `for` loops
- Accumulator pattern
- `let` for mutable variables

### Example / Starter Code

```javascript
function factorial(n) {
  let result = 1;
  for (let i = 1; i <= n; i++) {
    result *= i;
  }
  return result;
}

console.log(factorial(5));  // 120
console.log(factorial(0));  // 1
```

## Exercise 3: FizzBuzz

**Difficulty:** Basic

### Problem
Write a program that prints the numbers 1 to 50. For multiples of 3 print `"Fizz"`, for multiples of 5 print `"Buzz"`, and for multiples of both print `"FizzBuzz"`.

**Expected Output (first 15 lines):**
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

### Concepts
- `for` loops
- `if / else if / else` branching
- Modulo operator for divisibility checks

### Example / Starter Code

```javascript
for (let i = 1; i <= 50; i++) {
  if (i % 3 === 0 && i % 5 === 0) {
    console.log("FizzBuzz");
  } else if (i % 3 === 0) {
    console.log("Fizz");
  } else if (i % 5 === 0) {
    console.log("Buzz");
  } else {
    console.log(i);
  }
}
```

## Exercise 4: Count Vowels

**Difficulty:** Basic

### Problem
Write a function `countVowels(str)` that counts how many vowels (`a, e, i, o, u`) a string contains, ignoring case.

**Given Input:** `countVowels("Hello World")`

**Expected Output:**
```
3
```

### Concepts
- `.toLowerCase()` for case-insensitivity
- `for...of` loop over strings
- `.includes()` for membership checks

### Example / Starter Code

```javascript
function countVowels(str) {
  const vowels = "aeiou";
  let count = 0;
  for (const char of str.toLowerCase()) {
    if (vowels.includes(char)) {
      count++;
    }
  }
  return count;
}

console.log(countVowels("Hello World"));  // 3
```

## Exercise 5: Filter Even Numbers

**Difficulty:** Basic

### Problem
Write a function `filterEven(numbers)` that returns a new array containing only the even numbers from the input array.

**Given Input:** `filterEven([1, 2, 3, 4, 5, 6])`

**Expected Output:**
```
[2, 4, 6]
```

### Concepts
- Array `.filter()` method
- Arrow functions
- Modulo operator

### Example / Starter Code

```javascript
function filterEven(numbers) {
  return numbers.filter((n) => n % 2 === 0);
}

console.log(filterEven([1, 2, 3, 4, 5, 6]));  // [2, 4, 6]
```
