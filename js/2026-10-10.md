## Exercise 1: FizzBuzz
**Difficulty:** Basic
**Concepts:** for loop, conditionals, modulo, console.log

Print the numbers from 1 to a given `n`. For multiples of 3 print "Fizz", for multiples of 5 print "Buzz", and for multiples of both print "FizzBuzz".

**Starter code:**
```javascript
function fizzBuzz(n) {
  for (let i = 1; i <= n; i++) {
    if (i % 15 === 0) console.log("FizzBuzz");
    else if (i % 3 === 0) console.log("Fizz");
    else if (i % 5 === 0) console.log("Buzz");
    else console.log(i);
  }
}
fizzBuzz(15);
```

**Task:** Collect the output into an array and return it instead of printing directly.

## Exercise 2: Temperature Converter
**Difficulty:** Basic
**Concepts:** functions, arithmetic, template literals

Write functions to convert Celsius to Fahrenheit and back. Fahrenheit = Celsius × 9/5 + 32.

**Starter code:**
```javascript
function celsiusToFahrenheit(c) {
  return (c * 9) / 5 + 32;
}

function fahrenheitToCelsius(f) {
  return ((f - 32) * 5) / 9;
}

console.log(`20°C = ${celsiusToFahrenheit(20)}°F`);
console.log(`68°F = ${fahrenheitToCelsius(68)}°C`);
```

**Task:** Round results to one decimal place and let the user pick the direction via a prompt.

## Exercise 3: Find the Maximum in an Array
**Difficulty:** Basic
**Concepts:** arrays, loops, Math.max

Given an array of numbers, find and print the largest value.

**Starter code:**
```javascript
const numbers = [12, 45, 7, 89, 23, 5];
let max = numbers[0];
for (let i = 1; i < numbers.length; i++) {
  if (numbers[i] > max) max = numbers[i];
}
console.log("Max:", max);
```

**Task:** Also find the minimum, and report the index where the maximum occurs.

## Exercise 5: Leap Year Check
**Difficulty:** Basic
**Concepts:** conditionals, modulo, functions

Write a function that returns `true` when a year is a leap year, `false` otherwise.

**Starter code:**
```javascript
function isLeapYear(year) {
  return (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
}

console.log(isLeapYear(2024)); // true
console.log(isLeapYear(1900)); // false
```

**Task:** Print all leap years between 2000 and 2100.
