## Exercise 1: Print the ASCII Value of a Character
**Difficulty:** Basic
**Concepts:** `charCodeAt()`, `String.fromCharCode()`

Given a single character, print its ASCII (Unicode) value.

**Starter code:**
```javascript
const ch = "A";
console.log("ASCII value of", ch, "is", ch.charCodeAt(0));
```

**Task:** Reverse it — given a code, print the character with `String.fromCharCode(code)`, and loop over `"ABC"` printing each letter's code.

## Exercise 2: Check Vowel or Consonant
**Difficulty:** Basic
**Concepts:** `if / else`, `includes()`, string `.toLowerCase()`

Read a single letter and report whether it is a vowel or a consonant.

**Starter code:**
```javascript
const ch = "e";
const vowels = "aeiou";

if (vowels.includes(ch.toLowerCase())) {
    console.log(ch, "is a vowel");
} else {
    console.log(ch, "is a consonant");
}
```

**Task:** Validate the input is a single letter using a regular expression like `/^[a-zA-Z]$/` before classifying it.

## Exercise 3: Maximum and Minimum in an Array
**Difficulty:** Basic
**Concepts:** arrays, loops, `Math.max` / `Math.min`, spread operator

Find the largest and smallest numbers in an array.

**Starter code:**
```javascript
const numbers = [45, 12, 78, 34, 89, 23];
let maximum = numbers[0];
let minimum = numbers[0];

for (const n of numbers) {
    if (n > maximum) maximum = n;
    if (n < minimum) minimum = n;
}

console.log("Max:", maximum, "Min:", minimum);
```

**Task:** Rewrite it using `Math.max(...numbers)` and `Math.min(...numbers)` and compare the results.

## Exercise 4: Simple Calculator
**Difficulty:** Basic
**Concepts:** `switch`, arithmetic operators, functions

Write a function that takes two numbers and an operator and returns the result.

**Starter code:**
```javascript
function calculate(a, b, op) {
    switch (op) {
        case "+": return a + b;
        case "-": return a - b;
        case "*": return a * b;
        case "/": return b !== 0 ? a / b : "Cannot divide by zero";
        default: return "Invalid operator";
    }
}

console.log(calculate(10, 5, "+")); // 15
```

**Task:** Extend it to support `%` (modulo) and `**` (exponent), and add a few more `console.log` test cases.

## Exercise 5: Print Prime Numbers in a Range
**Difficulty:** Basic
**Concepts:** nested `for` loops, `break`, boolean flags

Print every prime number between two given bounds (e.g. 10 and 50).

**Starter code:**
```javascript
const start = 10, end = 50;

for (let num = start; num <= end; num++) {
    if (num < 2) continue;
    let isPrime = true;
    for (let i = 2; i <= Math.sqrt(num); i++) {
        if (num % i === 0) {
            isPrime = false;
            break;
        }
    }
    if (isPrime) console.log(num);
}
```

**Task:** Collect the primes into an array and print them joined with commas, plus a count.
