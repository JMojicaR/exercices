## Exercise 1: Sum of Array Elements

**Difficulty:** Basic

### Problem
Write a function that returns the total of all numbers in an array.

**Given Input:** `sumArray([1, 2, 3, 4, 5])`

**Expected Output:**
```
15
```

### Concepts
- `for...of` loop over an array
- Accumulator variable
- Function return values

### Example / Starter Code

```javascript
function sumArray(numbers) {
    let total = 0;
    for (const n of numbers) {
        total += n;
    }
    return total;
}

console.log(sumArray([1, 2, 3, 4, 5]));   // 15
console.log(sumArray([]));                // 0
```

## Exercise 2: Reverse a String

**Difficulty:** Basic

### Problem
Write a function that returns the given string reversed.

**Given Input:** `reverseString("hello")`

**Expected Output:**
```
"olleh"
```

### Concepts
- `.split("")` to break a string into characters
- `.reverse()` on an array
- `.join("")` to recombine characters

### Example / Starter Code

```javascript
function reverseString(str) {
    return str.split("").reverse().join("");
}

console.log(reverseString("hello"));      // "olleh"
console.log(reverseString("JavaScript")); // "tpircSavaJ"
```

## Exercise 3: Palindrome Check

**Difficulty:** Basic

### Problem
Write a function that returns `true` if a string is a palindrome (reads the same forwards and backwards, ignoring case) and `false` otherwise.

**Given Input:**
- `isPalindrome("racecar")`
- `isPalindrome("hello")`

**Expected Output:**
- `true`
- `false`

### Concepts
- String normalization with `.toLowerCase()`
- Reuse of the reverse-string technique
- Strict equality comparison

### Example / Starter Code

```javascript
function isPalindrome(str) {
    const cleaned = str.toLowerCase();
    return cleaned === cleaned.split("").reverse().join("");
}

console.log(isPalindrome("racecar"));   // true
console.log(isPalindrome("hello"));     // false
```

## Exercise 4: Find the Largest Number in an Array

**Difficulty:** Basic

### Problem
Write a function that returns the largest number from an array.

**Given Input:** `findLargest([3, 9, 2, 8, 5])`

**Expected Output:**
```
9
```

### Concepts
- Spread operator (`...`) to expand an array
- `Math.max()`
- Passing an array to a variadic function

### Example / Starter Code

```javascript
function findLargest(numbers) {
    return Math.max(...numbers);
}

console.log(findLargest([3, 9, 2, 8, 5]));   // 9
console.log(findLargest([-1, -5, -3]));      // -1
```

## Exercise 5: Temperature Conversion

**Difficulty:** Basic

### Problem
Write two functions: one converting Celsius to Fahrenheit and one converting Fahrenheit to Celsius.

Formulas:
- `F = (C × 9/5) + 32`
- `C = (F − 32) × 5/9`

**Given Input:**
- `celsiusToFahrenheit(0)`
- `fahrenheitToCelsius(32)`

**Expected Output:**
- `32`
- `0`

### Concepts
- Arithmetic operators and operator precedence
- Rounding results when needed
- Returning computed values

### Example / Starter Code

```javascript
function celsiusToFahrenheit(c) {
    return (c * 9) / 5 + 32;
}

function fahrenheitToCelsius(f) {
    return ((f - 32) * 5) / 9;
}

console.log(celsiusToFahrenheit(0));     // 32
console.log(celsiusToFahrenheit(100));   // 212
console.log(fahrenheitToCelsius(32));    // 0
console.log(fahrenheitToCelsius(212));   // 100
```
