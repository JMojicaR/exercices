## Exercise 1: Even or Odd Checker
**Difficulty:** Basic
**Concepts:** `if`/`else`, modulo operator `%`, comparison, `console.log()`

Write a function that takes an integer and logs whether it is even or odd.

**Starter code:**
```javascript
function evenOrOdd(n) {
  if (n % 2 === 0) {
    console.log(`${n} is even`);
  } else {
    console.log(`${n} is odd`);
  }
}

evenOrOdd(4); // 4 is even
evenOrOdd(7); // 7 is odd
```

**Task:** Rewrite using the conditional (ternary) operator `?:`. Then use the strict-equality `===` vs loose `==` difference to explain why `4 === "4"` is `false`.

## Exercise 2: Print Numbers 1 to N
**Difficulty:** Basic
**Concepts:** `for` loop, `let` vs `const`, loop variable, `console.log()`

Log every integer from 1 up to and including `N`, one per line.

**Starter code:**
```javascript
function printRange(n) {
  for (let i = 1; i <= n; i++) {
    console.log(i);
  }
}

printRange(5);
// 1
// 2
// 3
// 4
// 5
```

**Task:** Modify the loop to print only even numbers. Then convert the `for` loop into a `for...of` loop over an array `[1, 2, 3, 4, 5]`.

## Exercise 3: Countdown
**Difficulty:** Basic
**Concepts:** `while` loop, decrementing a counter, loop condition

Log a countdown from `N` down to 1, then log `"Liftoff!"`.

**Starter code:**
```javascript
function countdown(n) {
  while (n > 0) {
    console.log(n);
    n--;
  }
  console.log("Liftoff!");
}

countdown(5);
// 5
// 4
// 3
// 2
// 1
// Liftoff!
```

**Task:** Add a guard so that `n <= 0` logs `"Nothing to count"`. Then rewrite the countdown with a `for` loop that decrements.

## Exercise 4: Grade Classifier
**Difficulty:** Basic
**Concepts:** `if`/`else if`/`else` ladder, comparison operators, multiple conditions

Convert a numeric score (0–100) into a letter grade: 90+ → A, 80–89 → B, 70–79 → C, 60–69 → D, below 60 → F.

**Starter code:**
```javascript
function classify(score) {
  if (score >= 90) {
    return "A";
  } else if (score >= 80) {
    return "B";
  } else if (score >= 70) {
    return "C";
  } else if (score >= 60) {
    return "D";
  } else {
    return "F";
  }
}

console.log(classify(95)); // A
console.log(classify(83)); // B
console.log(classify(57)); // F
```

**Task:** Rewrite the ladder using a `switch` statement (or a lookup object/Map). Then handle scores outside 0–100 by returning `"Invalid"`.

## Exercise 5: Sum of Even Numbers up to N
**Difficulty:** Basic
**Concepts:** `for` loop + `if` condition, accumulator variable, `+=`

Return the sum of every even number from 2 up to and including `N`.

**Starter code:**
```javascript
function sumEven(n) {
  let total = 0;
  for (let i = 1; i <= n; i++) {
    if (i % 2 === 0) {
      total += i;
    }
  }
  return total;
}

console.log(sumEven(10)); // 2 + 4 + 6 + 8 + 10 = 30
console.log(sumEven(7));  // 2 + 4 + 6 = 12
```

**Task:** Rewrite using `i += 2` so the conditional is unnecessary, and add a `sumOdd(n)` function. Compare `sumEven(n) + sumOdd(n)` against `n*(n+1)/2` for a given `n`.
