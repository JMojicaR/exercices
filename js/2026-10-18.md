## Exercise 1: Swap Two Numbers
**Difficulty:** Basic
**Concepts:** variables, temporary variable, array destructuring

Swap the values of two variables.

**Starter code:**
```javascript
let a = 5, b = 10;

let temp = a;
a = b;
b = temp;

console.log(`a = ${a}, b = ${b}`);
```

**Task:** Swap again using array destructuring: `[a, b] = [b, a]`.

## Exercise 2: Area of a Circle
**Difficulty:** Basic
**Concepts:** `Math.PI`, arithmetic, template literals, `toFixed()`

Compute the area of a circle given its radius (`area = π × r²`).

**Starter code:**
```javascript
const radius = 5;
const area = Math.PI * radius ** 2;
console.log(`Area: ${area.toFixed(2)}`);
```

**Task:** Wrap it in a function `areaOfCircle(r)` and read the radius using `prompt()`.

## Exercise 3: Positive, Negative or Zero
**Difficulty:** Basic
**Concepts:** `if / else if / else`, comparison operators

Classify a number as positive, negative, or zero.

**Starter code:**
```javascript
const n = -3;
if (n > 0) {
    console.log("Positive");
} else if (n < 0) {
    console.log("Negative");
} else {
    console.log("Zero");
}
```

**Task:** Read the number from the user with `prompt()` and convert it with `Number()`.

## Exercise 4: Power of a Number (xⁿ)
**Difficulty:** Basic
**Concepts:** functions, `for` loop, `Math.pow`, `**`

Compute `base` raised to the power `exp` using a loop.

**Starter code:**
```javascript
function power(base, exp) {
    let result = 1;
    for (let i = 0; i < exp; i++) {
        result *= base;
    }
    return result;
}

console.log(power(2, 5)); // 32
```

**Task:** Rewrite using the `**` operator and then using `Math.pow(base, exp)`.

## Exercise 5: Reverse a Number
**Difficulty:** Basic
**Concepts:** string methods, `parseInt`, `Math.abs`, sign handling

Reverse the digits of an integer (e.g. 1234 → 4321).

**Starter code:**
```javascript
function reverseNumber(n) {
    const sign = n < 0 ? -1 : 1;
    const rev = parseInt(Math.abs(n).toString().split("").reverse().join(""));
    return sign * rev;
}

console.log(reverseNumber(1234));  // 4321
console.log(reverseNumber(-1234)); // -4321
```

**Task:** Rewrite using only arithmetic (a `while` loop with `%` and integer division) instead of string methods.
