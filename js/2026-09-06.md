## 1. Temperature Converter
- **Description**: Write a function that converts a Celsius temperature to Fahrenheit using `F = C × 9/5 + 32` and logs the result.
- **Difficulty**: Beginner
- **Concepts**: Functions, arithmetic operators, template literals
- **Example/Starter code**:
```javascript
function celsiusToFahrenheit(celsius) {
    return celsius * 9 / 5 + 32;
}

const celsius = 25;
console.log(`${celsius}°C = ${celsiusToFahrenheit(celsius)}°F`);
```

## 2. Count the Vowels
- **Description**: Write a function that counts the number of vowels in a given string, ignoring case.
- **Difficulty**: Beginner
- **Concepts**: Strings, `.toLowerCase()`, `.includes()`, `for...of` loops
- **Example/Starter code**:
```javascript
function countVowels(text) {
    const vowels = "aeiou";
    let count = 0;
    for (const ch of text.toLowerCase()) {
        if (vowels.includes(ch)) count++;
    }
    return count;
}

console.log("Vowel count:", countVowels("hello world"));
```

## 3. Multiplication Table
- **Description**: Write a function that prints the multiplication table (1 to 10) for a given number.
- **Difficulty**: Beginner
- **Concepts**: `for` loops, template literals, functions
- **Example/Starter code**:
```javascript
function multiplicationTable(n) {
    for (let i = 1; i <= 10; i++) {
        console.log(`${n} x ${i} = ${n * i}`);
    }
}

multiplicationTable(7);
```

## 4. Find the Largest in an Array
- **Description**: Write a function that returns the largest number in an array of numbers.
- **Difficulty**: Beginner
- **Concepts**: Arrays, `for...of` loops, comparison operators
- **Example/Starter code**:
```javascript
function findMax(numbers) {
    let max = numbers[0];
    for (const n of numbers) {
        if (n > max) max = n;
    }
    return max;
}

console.log("Max:", findMax([10, 42, 7, 99, 5]));
```

## 5. Palindrome Check
- **Description**: Write a function that returns `true` if a string reads the same forwards and backwards, otherwise `false`.
- **Difficulty**: Beginner
- **Concepts**: Strings, `.split()`, `.reverse()`, `.join()`, comparison
- **Example/Starter code**:
```javascript
function isPalindrome(text) {
    const reversed = text.split("").reverse().join("");
    return text === reversed;
}

console.log(isPalindrome("racecar")); // true
console.log(isPalindrome("hello"));   // false
```
