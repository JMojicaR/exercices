## Exercise 1: Add Two Numbers
**Difficulty:** Basic
**Concepts:** Functions, parameters, `return`, `console.log`.

Write a function that takes two numbers and returns their sum.

**Starter code:**
```javascript
function add(a, b) {
  return a + b;
}

console.log(add(5, 3)); // 8
```

**Task:** Add a `subtract` and `multiply` function and log all three results.

## Exercise 2: Even or Odd
**Difficulty:** Basic
**Concepts:** Modulo (`%`), comparison, `if`/`else`.

Write a function that returns `true` if a number is even, `false` otherwise.

**Starter code:**
```javascript
function isEven(n) {
  return n % 2 === 0;
}

console.log(isEven(4)); // true
console.log(isEven(7)); // false
```

**Task:** Write an `isOdd` function that reuses `isEven` instead of repeating the modulo logic.

## Exercise 3: Check if a Number is Prime
**Difficulty:** Basic
**Concepts:** Loops (`for`), early `return`, `Math` operations, edge cases.

Write a function that returns `true` if a number is prime, `false` otherwise.

**Starter code:**
```javascript
function isPrime(n) {
  if (n <= 1) return false;
  for (let i = 2; i * i <= n; i++) {
    if (n % i === 0) return false;
  }
  return true;
}

console.log(isPrime(11)); // true
console.log(isPrime(12)); // false
```

**Task:** Print all primes from 2 to 50 using this function.

## Exercise 4: Largest Element in an Array
**Difficulty:** Basic
**Concepts:** Arrays, `for...of`, comparison, accumulator variable.

Write a function that returns the largest number in an array.

**Starter code:**
```javascript
function largest(arr) {
  let max = arr[0];
  for (const n of arr) {
    if (n > max) max = n;
  }
  return max;
}

console.log(largest([3, 7, 2, 9, 5])); // 9
```

**Task:** Also return the smallest number (either in the same function or a new one).

## Exercise 5: Count Characters and Words in a String
**Difficulty:** Basic
**Concepts:** String properties (`.length`), `trim()`, `split()`, regex.

Write functions to count the number of characters and the number of words in a string.

**Starter code:**
```javascript
function countChars(str) {
  return str.length;
}

function countWords(str) {
  return str.trim().split(/\s+/).length;
}

console.log(countChars("hello"));       // 5
console.log(countWords("hello world")); // 2
```

**Task:** Handle empty and whitespace-only strings so `countWords` returns `0`.
