Theme: **2D arrays / matrices** — create, add, transpose, and summarize matrices using nested loops.

## Exercise 1: Create and Print a Matrix
**Difficulty:** Basic
**Concepts:** nested arrays, nested `for` loops, string building

Print a 2D array row by row.

**Starter code:**
```javascript
const matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9],
];

console.log("Matrix:");
for (let i = 0; i < matrix.length; i++) {
  let line = "";
  for (let j = 0; j < matrix[i].length; j++) {
    line += matrix[i][j] + " ";
  }
  console.log(line.trim());
}
```

**Task:** Print the matrix using `for...of` loops, then print it in reverse row order.

## Exercise 2: Matrix Addition
**Difficulty:** Basic
**Concepts:** nested arrays, element-wise addition, dynamic row creation

Add two matrices of the same size and print the result.

**Starter code:**
```javascript
const a = [[1, 2], [3, 4]];
const b = [[5, 6], [7, 8]];
const result = [];

for (let i = 0; i < a.length; i++) {
  result[i] = [];
  for (let j = 0; j < a[i].length; j++) {
    result[i][j] = a[i][j] + b[i][j];
  }
}

console.log(result);
```

**Task:** Refactor to use `.map()` on each row, and handle the case where the matrices have different sizes.

## Exercise 3: Matrix Transpose
**Difficulty:** Basic
**Concepts:** row/column swapping, dynamic array sizing

Transpose a matrix (swap rows and columns).

**Starter code:**
```javascript
const matrix = [[1, 2, 3], [4, 5, 6]];
const transpose = [];

for (let i = 0; i < matrix[0].length; i++) {
  transpose[i] = [];
  for (let j = 0; j < matrix.length; j++) {
    transpose[i][j] = matrix[j][i];
  }
}

console.log(transpose);
```

**Task:** Implement the transpose with `Array.from` or a single `map`/`reduce` expression.

## Exercise 4: Sum of the Main Diagonal
**Difficulty:** Basic
**Concepts:** square matrices, single loop, index tracking

Sum the main diagonal (top-left to bottom-right) of a square matrix.

**Starter code:**
```javascript
const matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]];
let total = 0;

for (let i = 0; i < matrix.length; i++) {
  total += matrix[i][i];
}

console.log("Sum of main diagonal:", total);
```

**Task:** Add the anti-diagonal sum using `matrix[i][matrix.length - 1 - i]`.

## Exercise 5: Sum of Each Row and Each Column
**Difficulty:** Basic
**Concepts:** nested loops, running totals

Print the sum of every row and every column.

**Starter code:**
```javascript
const matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]];

console.log("Row sums:");
for (let i = 0; i < matrix.length; i++) {
  let rowSum = 0;
  for (let j = 0; j < matrix[i].length; j++) {
    rowSum += matrix[i][j];
  }
  console.log(`Row ${i}: ${rowSum}`);
}

console.log("Column sums:");
for (let j = 0; j < matrix[0].length; j++) {
  let colSum = 0;
  for (let i = 0; i < matrix.length; i++) {
    colSum += matrix[i][j];
  }
  console.log(`Col ${j}: ${colSum}`);
}
```

**Task:** Compute row sums with `matrix[i].reduce((acc, n) => acc + n, 0)` and report the grand total.
