## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** Strings, `split()`/`reverse()`/`join()`, loops, arrays.

Write a function that returns a string reversed.

**Starter code:**
```javascript
function reverseString(str) {
  return str.split("").reverse().join("");
}

console.log(reverseString("hello")); // "olleh"
```

**Task:** Write a second version that builds the reversed string with a `for` loop (no built-in `reverse()`).

## Exercise 2: FizzBuzz
**Difficulty:** Basic
**Concepts:** Loops, conditionals, modulo operator, `console.log`.

Print the numbers 1 to 30, but for multiples of 3 print "Fizz", for multiples of 5 print "Buzz", and for multiples of both print "FizzBuzz".

**Starter code:**
```javascript
for (let i = 1; i <= 30; i++) {
  if (i % 3 === 0 && i % 5 === 0) {
    console.log("FizzBuzz");
  } else if (i % 3 === 0) {
    console.log("Fizz");
  } else if (i % 5 === 0) {
    console.log("Buzz");
  } else {
    console.log(i);
  }
}
```

**Task:** Collect the output into an array and log the array at the end.

## Exercise 3: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** Arrays, `for` loops, `for...of`, `reduce()`.

Write a function that returns the sum of all numbers in an array.

**Starter code:**
```javascript
function sumArray(numbers) {
  let total = 0;
  for (const num of numbers) {
    total += num;
  }
  return total;
}

console.log(sumArray([1, 2, 3, 4, 5])); // 15
```

**Task:** Rewrite using `numbers.reduce((acc, n) => acc + n, 0)`.

## Exercise 4: Filter Even Numbers
**Difficulty:** Basic
**Concepts:** Arrays, `filter()`, arrow functions, `%` operator.

Write a function that returns a new array containing only the even numbers from the input.

**Starter code:**
```javascript
function filterEven(numbers) {
  return numbers.filter((n) => n % 2 === 0);
}

console.log(filterEven([1, 2, 3, 4, 5, 6])); // [2, 4, 6]
```

**Task:** Also write a `filterOdd` function using a `for` loop instead of `filter()`.

## Exercise 5: Check Prime Number
**Difficulty:** Basic
**Concepts:** Functions, loops, early return, edge cases.

Write a function that returns `true` if a number is prime, otherwise `false`.

**Starter code:**
```javascript
function isPrime(n) {
  if (n < 2) return false;
  for (let i = 2; i <= Math.sqrt(n); i++) {
    if (n % i === 0) return false;
  }
  return true;
}

console.log(isPrime(17)); // true
console.log(isPrime(15)); // false
```

**Task:** Print all prime numbers between 1 and 100 using this function.
