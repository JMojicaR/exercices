## Exercise 1: Number Guessing Game
**Difficulty:** Basic
**Concepts:** Math.random, loops, comparison, parseInt

Generate a random number between 1 and 100 and keep prompting the user until they guess it, giving "too low"/"too high" hints.

**Starter code:**
```javascript
const target = Math.floor(Math.random() * 100) + 1;
let guess;

do {
    guess = parseInt(prompt("Guess a number (1-100):"), 10);
    if (guess < target) console.log("Too low!");
    else if (guess > target) console.log("Too high!");
} while (guess !== target);

console.log("You guessed it!");
```

**Task:** Limit the player to 7 attempts and print "out of tries" if they fail.

## Exercise 2: Count Words in a String
**Difficulty:** Basic
**Concepts:** split, trim, regular expressions

Write a function that returns the number of words in a string.

**Starter code:**
```javascript
function countWords(text) {
    return text.trim().split(/\s+/).length;
}

console.log(countWords("The quick brown fox jumps over"));
```

**Task:** Handle an empty string and return 0 instead of 1.

## Exercise 3: Anagram Check
**Difficulty:** Basic
**Concepts:** toLowerCase, split, sort, join

Check whether two strings are anagrams (contain the same letters in a different order), e.g. "listen" and "silent".

**Starter code:**
```javascript
function isAnagram(a, b) {
    const normalize = (s) =>
        s.toLowerCase().replace(/[^a-z]/g, "").split("").sort().join("");
    return normalize(a) === normalize(b);
}

console.log(isAnagram("listen", "silent")); // true
```

**Task:** Make the comparison case-insensitive and ignore spaces and punctuation.

## Exercise 4: Sum of Even Numbers
**Difficulty:** Basic
**Concepts:** for loop, modulo, accumulator

Return the sum of all even numbers from 1 up to `n`.

**Starter code:**
```javascript
function sumEven(n) {
    let total = 0;
    for (let i = 2; i <= n; i += 2) {
        total += i;
    }
    return total;
}

console.log(sumEven(10)); // 30
```

**Task:** Write a second version that filters odd numbers with `% 2 === 0` instead of stepping by 2.

## Exercise 5: Find the Smallest Value in an Array
**Difficulty:** Basic
**Concepts:** arrays, loops, Math.min, spread

Return the smallest number in an array.

**Starter code:**
```javascript
function smallest(arr) {
    let min = arr[0];
    for (const value of arr) {
        if (value < min) min = value;
    }
    return min;
}

console.log(smallest([34, 15, 88, 2, 42])); // 2
```

**Task:** Rewrite it using `Math.min(...arr)` and compare the results.
