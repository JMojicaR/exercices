## Exercise 1: Bubble Sort

**Difficulty:** Basic

### Problem
Write a function that sorts an array of numbers in ascending order using bubble sort.

**Given Input:** `[64, 34, 25, 12, 22, 11, 90]`

**Expected Output:**
```
[ 11, 12, 22, 25, 34, 64, 90 ]
```

### Concepts
- Nested `for` loops
- Array destructuring swap `[a, b] = [b, a]`
- In-place mutation

### Example / Starter Code

```js
function bubbleSort(arr) {
  for (let i = 0; i < arr.length - 1; i++) {
    for (let j = 0; j < arr.length - i - 1; j++) {
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
      }
    }
  }
  return arr;
}

console.log(bubbleSort([64, 34, 25, 12, 22, 11, 90]));
```

## Exercise 2: Linear Search

**Difficulty:** Basic

### Problem
Write a function that searches an array for a target value and returns its index, or `-1` if not found.

**Given Input:** array `[10, 23, 45, 70, 11, 15]`, target `70`

**Expected Output:**
```
Found at index 3
```

### Concepts
- `for` loop over indices
- Strict equality `===`
- Early `return`

### Example / Starter Code

```js
function linearSearch(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) return i;
  }
  return -1;
}

const index = linearSearch([10, 23, 45, 70, 11, 15], 70);
console.log(index !== -1 ? `Found at index ${index}` : "Not found");
```

## Exercise 3: Anagram Check

**Difficulty:** Basic

### Problem
Write a function that checks whether two strings are anagrams, ignoring case.

**Given Input:** `"listen"`, `"silent"`

**Expected Output:**
```
true
```

### Concepts
- `toLowerCase()` normalization
- `split('')`, `sort()`, `join('')` pipeline
- String comparison

### Example / Starter Code

```js
function isAnagram(s1, s2) {
  const normalize = (s) => s.toLowerCase().split("").sort().join("");
  return normalize(s1) === normalize(s2);
}

console.log(isAnagram("listen", "silent"));
```

## Exercise 4: Greatest Common Divisor (GCD)

**Difficulty:** Basic

### Problem
Write a function that computes the GCD of two positive integers using the Euclidean algorithm.

**Given Input:** `48`, `18`

**Expected Output:**
```
6
```

### Concepts
- `while` loop
- Modulo `%`
- Destructuring reassignment

### Example / Starter Code

```js
function gcd(a, b) {
  while (b !== 0) {
    [a, b] = [b, a % b];
  }
  return a;
}

console.log(gcd(48, 18));
```

## Exercise 5: Armstrong Number Check

**Difficulty:** Basic

### Problem
Write a function that checks whether a number is an Armstrong number (sum of digits each raised to the power of the digit count equals the number).

**Given Input:** `153`

**Expected Output:**
```
true
```

### Concepts
- `String(n).split('')` digit extraction
- `Array.prototype.reduce()`
- `Math.pow()`

### Example / Starter Code

```js
function isArmstrong(n) {
  const digits = String(n).split("");
  const power = digits.length;
  const total = digits.reduce((sum, d) => sum + Math.pow(Number(d), power), 0);
  return total === n;
}

console.log(isArmstrong(153));
```
