## Exercise 1: Display Current Day and Time

### Problem
Write a JavaScript program to display the current day and time in the following format.

**Sample Output:**
```
Today is : Tuesday.
Current time is : 10 PM : 30 : 38
```

### Concepts
- `Date` object
- `getDay()`, `getHours()`, `getMinutes()`, `getSeconds()`
- Array indexing for day names
- Conditional logic for AM/PM formatting

### Example / Starter Code

```javascript
// Get the current date and time
const today = new Date();

// Array of day names
const days = ["Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"];

// Get the day of the week
const day = days[today.getDay()];
console.log("Today is : " + day + ".");

// Get hours, minutes, seconds
let hours = today.getHours();
const minutes = today.getMinutes();
const seconds = today.getSeconds();

// Determine AM or PM
const period = hours >= 12 ? "PM" : "AM";
hours = hours >= 12 ? hours - 12 : hours;
hours = hours === 0 ? 12 : hours;

console.log("Current time is : " + hours + " " + period + " : " + minutes + " : " + seconds);
```

## Exercise 3: Get Current Date in Various Formats

### Problem
Write a JavaScript program to get the current date and display it in multiple formats.

**Expected Output:**
```
mm-dd-yyyy, mm/dd/yyyy or dd-mm-yyyy, dd/mm/yyyy
```

### Concepts
- `Date` object methods: `getMonth()`, `getDate()`, `getFullYear()`
- Zero-based month indexing (January = 0)
- String concatenation and template literals
- Padding single-digit values with leading zeros

### Example / Starter Code

```javascript
// Get today's date
const today = new Date();

// Extract day, month, and year (month is zero-indexed)
let dd = today.getDate();
let mm = today.getMonth() + 1; // January is 0
const yyyy = today.getFullYear();

// Add leading zero if needed
if (dd < 10) {
    dd = '0' + dd;
}
if (mm < 10) {
    mm = '0' + mm;
}

// Display in different formats
console.log(mm + '-' + dd + '-' + yyyy);
console.log(mm + '/' + dd + '/' + yyyy);
console.log(dd + '-' + mm + '-' + yyyy);
console.log(dd + '/' + mm + '/' + yyyy);
```

## Exercise 4: Find Area of a Triangle

### Problem
Write a JavaScript program to find the area of a triangle where the three sides are 5, 6, and 7. Use Heron's formula: `area = √(s(s-a)(s-b)(s-c))` where `s = (a+b+c)/2`.

### Concepts
- Heron's formula for triangle area
- `Math.sqrt()` for square root
- Arithmetic operations
- Variable declaration

### Example / Starter Code

```javascript
// Three sides of the triangle
const side1 = 5;
const side2 = 6;
const side3 = 7;

// Calculate the semi-perimeter
const s = (side1 + side2 + side3) / 2;

// Heron's formula for area
const area = Math.sqrt(s * (s - side1) * (s - side2) * (s - side3));

console.log("Area of the triangle: " + area.toFixed(2));
```

## Exercise 5: Rotate String 'w3resource' Periodically

### Problem
Write a JavaScript program to rotate the string `'w3resource'` in the right direction. This is done by periodically removing one letter from the string end and attaching it to the front.

### Concepts
- String manipulation with `slice()` and `charAt()`
- `setInterval()` for periodic execution
- DOM manipulation to display animated output
- String length property

### Example / Starter Code

```javascript
function animateString(id) {
    const element = document.getElementById(id);
    let textNode = element.childNodes[0]; // Get the text node
    let text = textNode.data;

    setInterval(function () {
        // Move the last character to the front
        text = text[text.length - 1] + text.substring(0, text.length - 1);
        textNode.data = text;
    }, 200);
}

// Usage in HTML:
// <div id="target">w3resource</div>
// <script>animateString('target');</script>
```
