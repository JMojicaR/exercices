## Exercise 1: Create & Access an Object
**Difficulty:** Basic
**Concepts:** object literal, dot vs bracket notation, adding/updating properties

Build a `user` object and read/write its properties.

**Starter code:**
```javascript
const user = {
  name: "Alice",
  age: 25,
  city: "Mexico City",
};

console.log(user.name);          // Alice
console.log(user["age"]);        // 25

user.email = "alice@example.com";  // add
user.age = 26;                     // update
console.log(user);
```

**Task:** Store a key in a variable (`const key = "city"`) and read the value using bracket notation `user[key]`. Print it.

## Exercise 2: Count Character Frequencies
**Difficulty:** Basic
**Concepts:** `for...of` loop, object as a counter, `||` fallback

Count how many times each character appears in a string.

**Starter code:**
```javascript
function charCount(str) {
  const counts = {};
  for (const ch of str) {
    counts[ch] = (counts[ch] || 0) + 1;
  }
  return counts;
}

console.log(charCount("hello"));  // { h: 1, e: 1, l: 2, o: 1 }
```

**Task:** Modify the function to skip spaces, so `charCount("a b a")` returns `{ a: 2, b: 1 }`.

## Exercise 3: Iterate Keys, Values & Entries
**Difficulty:** Basic
**Concepts:** `Object.keys`, `Object.values`, `Object.entries`, `for...of`

List all keys and values of an object, then print key-value pairs.

**Starter code:**
```javascript
const prices = { apple: 1.2, banana: 0.8, cherry: 2.5 };

console.log(Object.keys(prices));    // ["apple", "banana", "cherry"]
console.log(Object.values(prices));  // [1.2, 0.8, 2.5]

for (const [fruit, price] of Object.entries(prices)) {
  console.log(`${fruit}: $${price}`);
}
```

**Task:** Use `.filter()` on `Object.entries(prices)` to build a list of fruits that cost more than `$1.00`.

## Exercise 4: Merge Two Objects
**Difficulty:** Basic
**Concepts:** spread operator `...`, `Object.assign`, key precedence on conflict

Combine two objects, letting the second object win on duplicate keys.

**Starter code:**
```javascript
const base = { color: "red", size: "M" };
const overrides = { size: "L", price: 20 };

const merged = { ...base, ...overrides };
console.log(merged);  // { color: "red", size: "L", price: 20 }
```

**Task:** Reproduce the same result using `Object.assign({}, base, overrides)` and compare the two objects with `JSON.stringify`.

## Exercise 5: The Map Class
**Difficulty:** Basic
**Concepts:** `Map`, `.set()`, `.get()`, `.has()`, `.delete()`, `.size`

Use a `Map` to store scores by player name.

**Starter code:**
```javascript
const scores = new Map();

scores.set("Alice", 100);
scores.set("Bob", 80);
scores.set("Carol", 95);

console.log(scores.get("Alice"));   // 100
console.log(scores.has("Bob"));     // true

scores.delete("Bob");
console.log(scores.size);           // 2

for (const [name, score] of scores) {
  console.log(`${name}: ${score}`);
}
```

**Task:** Add a `Map` that uses objects as keys (e.g. `const key = { id: 1 }`) and confirm `map.get(key)` works even though the key object is mutated after insertion.
