## Exercise 1: Reverse a String

### Problem
Write a function that takes a string and returns it reversed.

**Given Input:** `reverseString("hello")`

**Expected Output:**
```
olleh
```

### Concepts
- `String.split('')` to convert a string into an array of characters
- `Array.reverse()` to reverse an array
- `Array.join('')` to join characters back into a string

### Example / Starter Code

```javascript
function reverseString(str) {
    return str.split('').reverse().join('');
}

console.log(reverseString("hello"));   // "olleh"
console.log(reverseString("world"));   // "dlrow"
```

## Exercise 2: Sum of Array Elements

### Problem
Write a function that returns the sum of all numbers in an array.

**Given Input:** `sumArray([1, 2, 3, 4, 5])`

**Expected Output:**
```
15
```

### Concepts
- Iterating arrays with a `for` loop or `for...of`
- Accumulator pattern
- `Array.reduce()` as an alternative

### Example / Starter Code

```javascript
function sumArray(arr) {
    let sum = 0;
    for (let num of arr) {
        sum += num;
    }
    return sum;
}

console.log(sumArray([1, 2, 3, 4, 5]));   // 15

// Alternative using reduce:
// const sum = arr => arr.reduce((acc, n) => acc + n, 0);
```

## Exercise 3: Find the Largest Number in an Array

### Problem
Write a function that returns the largest number in an array of numbers.

**Given Input:** `largest([3, 7, 1, 9, 4])`

**Expected Output:**
```
9
```

### Concepts
- Array iteration
- Keeping track of a running maximum
- `Math.max(...arr)` as a built-in alternative

### Example / Starter Code

```javascript
function largest(arr) {
    let max = arr[0];
    for (let i = 1; i < arr.length; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}

console.log(largest([3, 7, 1, 9, 4]));   // 9
```

## Exercise 4: Check Palindrome

### Problem
Write a function that returns `true` if a given string is a palindrome (reads the same forward and backward, ignoring case), otherwise `false`.

**Given Input:**
- `isPalindrome("racecar")`
- `isPalindrome("hello")`

**Expected Output:**
- `true`
- `false`

### Concepts
- `.toLowerCase()` for case normalization
- Reversing strings
- Boolean return values

### Example / Starter Code

```javascript
function isPalindrome(str) {
    const normalized = str.toLowerCase();
    const reversed = normalized.split('').reverse().join('');
    return normalized === reversed;
}

console.log(isPalindrome("racecar"));   // true
console.log(isPalindrome("hello"));     // false
```

## Exercise 5: Multiplication Table

### Problem
Write a program that prints the multiplication table (from 1 to 10) for a given number.

**Given Input:** `multiplicationTable(7)`

**Expected Output:**
```
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
...
7 x 10 = 70
```

### Concepts
- `for` loops
- Template literals for string formatting
- Looping over a fixed range

### Example / Starter Code

```javascript
function multiplicationTable(num) {
    for (let i = 1; i <= 10; i++) {
        console.log(`${num} x ${i} = ${num * i}`);
    }
}

multiplicationTable(7);
```
