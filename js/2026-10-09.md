## Exercise 1: Factorial
**Difficulty:** Basic
**Concepts:** functions, for loop

Write a function that returns the factorial of a non-negative integer.

**Starter code:**
```javascript
function factorial(n) {
  let result = 1;
  for (let i = 1; i <= n; i++) {
    result *= i;
  }
  return result;
}

console.log(factorial(5)); // 120
```

**Task:** Add input validation that returns `null` (or throws) for negative numbers.

## Exercise 2: Reverse a String
**Difficulty:** Basic
**Concepts:** string methods, arrays, join

Reverse the characters of a given string without using a loop.

**Starter code:**
```javascript
function reverseString(str) {
  return str.split("").reverse().join("");
}

console.log(reverseString("hello")); // "olleh"
```

**Task:** Implement the same behavior manually using a `for` loop instead of `reverse()`.

## Exercise 3: Check Even or Odd
**Difficulty:** Basic
**Concepts:** if/else, modulo operator

Write a function that takes a number and returns whether it is even or odd.

**Starter code:**
```javascript
function evenOrOdd(num) {
  if (num % 2 === 0) {
    return "even";
  } else {
    return "odd";
  }
}

console.log(evenOrOdd(7)); // "odd"
```

**Task:** Return the result as a template string: `` `${num} is even` ``.

## Exercise 4: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** arrays, for loop, reduce

Compute the sum of all numbers in an array.

**Starter code:**
```javascript
function sumArray(numbers) {
  let total = 0;
  for (let i = 0; i < numbers.length; i++) {
    total += numbers[i];
  }
  return total;
}

console.log(sumArray([1, 2, 3, 4, 5])); // 15
```

**Task:** Rewrite `sumArray` using the `reduce()` method.

## Exercise 5: Count Vowels in a String
**Difficulty:** Basic
**Concepts:** strings, loops, includes

Count the number of vowels in a string, case-insensitively.

**Starter code:**
```javascript
function countVowels(str) {
  const vowels = "aeiou";
  let count = 0;
  for (const ch of str.toLowerCase()) {
    if (vowels.includes(ch)) {
      count++;
    }
  }
  return count;
}

console.log(countVowels("Hello World")); // 3
```

**Task:** Return an object mapping each vowel to how many times it appears.
