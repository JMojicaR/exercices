## Exercise 1: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a function `factorial(n)` that returns the factorial of a non-negative integer `n`. Factorial of 0 is 1.

**Given Input:** `5`

**Expected Output:**
```
Factorial of 5 is 120
```

### Concepts
- Function declaration
- `for` loop accumulator
- `Number()` conversion / `prompt()` input

### Example / Starter Code

```javascript
function factorial(n) {
  let result = 1;
  for (let i = 1; i <= n; i++) {
    result *= i;
  }
  return result;
}

const n = 5;
console.log(`Factorial of ${n} is ${factorial(n)}`);
```

## Exercise 2: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a program that prints the first `n` terms of the Fibonacci sequence (`0, 1, 1, 2, 3, 5, …`).

**Given Input:** `7`

**Expected Output:**
```
0
1
1
2
3
5
8
```

### Concepts
- `let` variables and swapping
- `for` loop
- Template literals

### Example / Starter Code

```javascript
function fibonacci(n) {
  let a = 0, b = 1;
  for (let i = 0; i < n; i++) {
    console.log(a);
    [a, b] = [b, a + b];
  }
}

fibonacci(7);
```

## Exercise 3: Palindrome Check

**Difficulty:** Basic

### Problem
Write a function `isPalindrome(str)` that returns `true` if a string is a palindrome, ignoring case.

**Given Input:** `"Racecar"`

**Expected Output:**
```
Racecar is a palindrome
```

### Concepts
- `.toLowerCase()`
- `.split("")`, `.reverse()`, `.join("")`
- Strict equality `===`

### Example / Starter Code

```javascript
function isPalindrome(str) {
  const normalized = str.toLowerCase();
  const reversed = normalized.split("").reverse().join("");
  return normalized === reversed;
}

const text = "Racecar";
console.log(`${text} ${isPalindrome(text) ? "is" : "is not"} a palindrome`);
```

## Exercise 4: Prime Number Check

**Difficulty:** Basic

### Problem
Write a function `isPrime(n)` that returns `true` if `n` is a prime number (greater than 1, divisible only by 1 and itself).

**Given Input:** `29`

**Expected Output:**
```
29 is a prime number
```

### Concepts
- `for` loop with `break`
- Modulo operator `%`
- `Math.sqrt()` for early exit

### Example / Starter Code

```javascript
function isPrime(n) {
  if (n <= 1) return false;
  for (let i = 2; i <= Math.sqrt(n); i++) {
    if (n % i === 0) return false;
  }
  return true;
}

const n = 29;
console.log(`${n} ${isPrime(n) ? "is" : "is not"} a prime number`);
```

## Exercise 5: Sum of Digits

**Difficulty:** Basic

### Problem
Write a function `sumOfDigits(n)` that returns the sum of the digits of a positive integer.

**Given Input:** `12345`

**Expected Output:**
```
Sum of digits: 15
```

### Concepts
- `while` loop
- Modulo `%` and `Math.floor()` division
- Numeric accumulator

### Example / Starter Code

```javascript
function sumOfDigits(n) {
  let total = 0;
  while (n > 0) {
    total += n % 10;
    n = Math.floor(n / 10);
  }
  return total;
}

console.log("Sum of digits:", sumOfDigits(12345));
```
