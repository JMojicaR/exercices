## Exercise 1: Find Maximum & Minimum
**Difficulty:** Basic
**Concepts:** `for...of` loop, comparisons, object return

Return the smallest and largest values in an array of numbers as an object `{ min, max }`.

**Starter code:**
```javascript
function findMinMax(numbers) {
  let min = numbers[0];
  let max = numbers[0];
  for (const n of numbers) {
    if (n < min) min = n;
    if (n > max) max = n;
  }
  return { min, max };
}

console.log(findMinMax([3, 1, 4, 1, 5, 9, 2])); // { min: 1, max: 9 }
```

**Task:** Rewrite using `Math.min(...numbers)` and `Math.max(...numbers)`. Note the spread operator and what happens with very large arrays.

## Exercise 2: Sum of Elements
**Difficulty:** Basic
**Concepts:** `for...of` loop, accumulator, `+=`

Return the sum of all numbers in an array.

**Starter code:**
```javascript
function sumArray(numbers) {
  let total = 0;
  for (const n of numbers) {
    total += n;
  }
  return total;
}

console.log(sumArray([1, 2, 3, 4, 5])); // 15
```

**Task:** Rewrite using `numbers.reduce((acc, n) => acc + n, 0)`. Then compute the average by dividing the total by `numbers.length`.

## Exercise 3: Reverse an Array
**Difficulty:** Basic
**Concepts:** `for` loop with reverse index, `.push()`

Return a new array with the elements in reverse order (do not mutate the original).

**Starter code:**
```javascript
function reverseArray(items) {
  const reversed = [];
  for (let i = items.length - 1; i >= 0; i--) {
    reversed.push(items[i]);
  }
  return reversed;
}

console.log(reverseArray([1, 2, 3, 4])); // [4, 3, 2, 1]
```

**Task:** Rewrite using the non-mutating `items.toReversed()`, and separately try `items.reverse()` — note that `reverse()` modifies the original array in place.

## Exercise 4: Count Occurrences
**Difficulty:** Basic
**Concepts:** `for...of` loop, strict equality `===`, counter

Return how many times a target value appears in an array.

**Starter code:**
```javascript
function countOccurrences(items, target) {
  let count = 0;
  for (const item of items) {
    if (item === target) count++;
  }
  return count;
}

console.log(countOccurrences([1, 2, 3, 2, 4, 2], 2)); // 3
```

**Task:** Rewrite using `items.filter(item => item === target).length`. Then build a frequency object mapping each distinct value to its count.

## Exercise 5: Remove Duplicates
**Difficulty:** Basic
**Concepts:** `.includes()`, `.push()`, order preservation

Return a new array containing each element only once, preserving original order.

**Starter code:**
```javascript
function removeDuplicates(items) {
  const unique = [];
  for (const item of items) {
    if (!unique.includes(item)) unique.push(item);
  }
  return unique;
}

console.log(removeDuplicates([1, 2, 2, 3, 4, 4, 4, 5])); // [1, 2, 3, 4, 5]
```

**Task:** Rewrite using `[...new Set(items)]` and explain why `Set` removes duplicates and how the spread operator converts it back to an array.
