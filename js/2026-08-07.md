## Exercise 1: Variable Swap
**Difficulty:** ★☆☆☆☆  
**Concepts:** Variables (`let`/`const`), assignment, console output

### Description
Declare two variables `a = 5` and `b = 10`. Swap their values without using a temporary variable (use array destructuring). Print the values before and after swapping.

### Starter Code
```javascript
let a = 5;
let b = 10;

console.log("Before swap:", "a =", a, ", b =", b);

// Your code here — swap using destructuring

console.log("After swap:", "a =", a, ", b =", b);
// Expected: a = 10, b = 5
```

## Exercise 3: Array Filter & Map
**Difficulty:** ★★☆☆☆  
**Concepts:** Arrays, `filter()`, `map()`, arrow functions

### Description
Given an array of numbers, do the following:
1. Filter out all numbers less than 10.
2. Square each remaining number.
3. Return the resulting array.

### Starter Code
```javascript
const numbers = [3, 12, 7, 20, 5, 15, 9, 25];

const result = numbers
    .filter(/* your condition */)
    .map(/* your transformation */);

console.log(result);
// Expected: [144, 400, 225, 625]
```
