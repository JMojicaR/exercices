## Exercise 1: Build a Stack with `push`/`pop`
**Difficulty:** Basic
**Concepts:** array `push()` (push), `pop()` (pop), LIFO order, `.length` for emptiness

JavaScript arrays act as stacks using `push()` and `pop()`.

**Starter code:**
```javascript
const stack = [];

stack.push("a");   // push
stack.push("b");
stack.push("c");
console.log(stack);        // ['a', 'b', 'c']

const top = stack.pop();   // removes and returns the last item
console.log(top);          // 'c'
console.log(stack);        // ['a', 'b']
console.log(stack.length === 0);   // false
```

**Task:** Write a function `pushThenPop(items)` that pushes each item of an array onto a stack, then pops them all into a result array. Confirm the result is the input in reverse order.

## Exercise 2: Build a Queue with `push`/`shift`
**Difficulty:** Basic
**Concepts:** `push()` (enqueue), `shift()` (dequeue), FIFO order

A queue uses `push()` to add to the back and `shift()` to remove from the front.

**Starter code:**
```javascript
const q = [];

q.push("a");   // enqueue (back)
q.push("b");
q.push("c");
console.log(q);            // ['a', 'b', 'c']

const first = q.shift();   // dequeue (front)
console.log(first);        // 'a'
console.log(q);            // ['b', 'c']
```

**Task:** Enqueue the numbers `1..5` and then dequeue them all in a loop, printing each. The output should be `1 2 3 4 5`.

## Exercise 3: Balanced Brackets Checker
**Difficulty:** Basic
**Concepts:** stack matching pairs, object/dictionary of matching brackets, early `false` on mismatch

Check that every opening bracket has a matching closing bracket in correct order.

**Starter code:**
```javascript
function isBalanced(s) {
  const stack = [];
  const pairs = { ")": "(", "]": "[", "}": "{" };
  for (const ch of s) {
    if ("([{".includes(ch)) {
      stack.push(ch);
    } else if (")]}".includes(ch)) {
      if (stack.length === 0 || stack.pop() !== pairs[ch]) {
        return false;
      }
    }
  }
  return stack.length === 0;
}

console.log(isBalanced("(a[b]{c})"));   // true
console.log(isBalanced("([)]"));        // false
```

**Task:** Add a check so that a closing bracket with an empty stack returns `false` cleanly (it already does via `stack.length === 0`). Add a test for the input `"((("` and confirm it returns `false`.

## Exercise 4: Reverse a String with a Stack
**Difficulty:** Basic
**Concepts:** push characters, pop to rebuild, array `join("")`

Push each character onto a stack and pop them off to get the reversed string.

**Starter code:**
```javascript
function reverseString(text) {
  const stack = [];
  for (const ch of text) {
    stack.push(ch);
  }
  let result = "";
  while (stack.length > 0) {
    result += stack.pop();
  }
  return result;
}

console.log(reverseString("hello"));   // "olleh"
```

**Task:** Rewrite the `while` loop to collect popped characters into an array and use `join("")` at the end instead of `+=`, then confirm the output is unchanged.

## Exercise 5: Implement a Queue Using Two Stacks
**Difficulty:** Basic
**Concepts:** two stacks (in/out) to simulate FIFO, moving items between stacks

Simulate a queue with two stacks by pushing to an *in* stack and flipping into an *out* stack when dequeuing.

**Starter code:**
```javascript
class TwoStackQueue {
  constructor() {
    this.inStack = [];
    this.outStack = [];
  }
  enqueue(item) {
    this.inStack.push(item);
  }
  dequeue() {
    if (this.outStack.length === 0) {
      while (this.inStack.length > 0) {
        this.outStack.push(this.inStack.pop());
      }
    }
    return this.outStack.pop();
  }
}

const q = new TwoStackQueue();
q.enqueue(1); q.enqueue(2); q.enqueue(3);
console.log(q.dequeue());   // 1
console.log(q.dequeue());   // 2
```

**Task:** Add an `isEmpty()` method returning `true` only when both stacks are empty, and log `q.isEmpty()` before and after draining the queue.
