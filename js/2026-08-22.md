## Exercise 1: Check Leap Year

**Difficulty:** Basic

### Problem
Write a function that takes a year and returns `true` if it is a leap year, otherwise `false`. A leap year is divisible by 4, except century years which must be divisible by 400.

**Given Input:** `isLeapYear(2024)`

**Expected Output:**
```
true
false
true
false
```

### Concepts
- Modulo operator (`%`)
- Logical operators (`&&`, `||`)
- `if` / `else` conditions

### Example / Starter Code

```javascript
function isLeapYear(year) {
  if ((year % 4 === 0 && year % 100 !== 0) || year % 400 === 0) {
    return true;
  }
  return false;
}

console.log(isLeapYear(2000)); // true
console.log(isLeapYear(1900)); // false
console.log(isLeapYear(2024)); // true
console.log(isLeapYear(2023)); // false
```

## Exercise 2: Sum of Digits of a Number

**Difficulty:** Basic

### Problem
Write a function that returns the sum of all digits of a given integer, extracting each digit using the modulo and division operators.

**Given Input:** `sumOfDigits(1234)`

**Expected Output:**
```
10
```

### Concepts
- `%` and `Math.floor()` for digit extraction
- `while` loop
- `Math.abs()` to handle negatives

### Example / Starter Code

```javascript
function sumOfDigits(n) {
  n = Math.abs(n);
  let sum = 0;
  while (n > 0) {
    sum += n % 10;
    n = Math.floor(n / 10);
  }
  return sum;
}

console.log(sumOfDigits(1234)); // 10
```

## Exercise 3: Find the Minimum Number in an Array

**Difficulty:** Basic

### Problem
Write a function that finds and returns the smallest number in an array of numbers by iterating through it.

**Given Input:** `findMin([4, 2, 9, 1, 7])`

**Expected Output:**
```
1
```

### Concepts
- Arrays and indexing
- `for` loop iteration
- Comparison and updating a running minimum

### Example / Starter Code

```javascript
function findMin(arr) {
  let min = arr[0];
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] < min) {
      min = arr[i];
    }
  }
  return min;
}

console.log(findMin([4, 2, 9, 1, 7])); // 1
```

## Exercise 4: Count Occurrences of a Character in a String

**Difficulty:** Basic

### Problem
Write a function that counts how many times a given character appears in a string by looping through each character.

**Given Input:** `countChar("hello world", "l")`

**Expected Output:**
```
3
```

### Concepts
- String indexing and `.length`
- `for` loop
- Equality comparison (`===`) and a counter

### Example / Starter Code

```javascript
function countChar(str, ch) {
  let count = 0;
  for (let i = 0; i < str.length; i++) {
    if (str[i] === ch) {
      count++;
    }
  }
  return count;
}

console.log(countChar("hello world", "l")); // 3
```

## Exercise 5: Simple Calculator (switch)

**Difficulty:** Basic

### Problem
Write a function that takes two numbers and an operator (`+`, `-`, `*`, `/`) and returns the result, using a `switch` statement. Guard against division by zero.

**Given Input:** `calculator(10, 5, "+")`

**Expected Output:**
```
15
5
50
2
```

### Concepts
- `switch` statement
- Arithmetic operators
- Error handling for division by zero

### Example / Starter Code

```javascript
function calculator(a, b, operator) {
  switch (operator) {
    case "+":
      return a + b;
    case "-":
      return a - b;
    case "*":
      return a * b;
    case "/":
      if (b === 0) return "Error: division by zero";
      return a / b;
    default:
      return "Invalid operator";
  }
}

console.log(calculator(10, 5, "+")); // 15
console.log(calculator(10, 5, "-")); // 5
console.log(calculator(10, 5, "*")); // 50
console.log(calculator(10, 5, "/")); // 2
```
