## Exercise 1: Print Numbers 1 to 10
**Difficulty:** Basic
**Concepts:** `console.log()`, `for` loop, variables.

Write a program that prints the numbers from 1 to 10, each on its own line.

**Starter code:**
```javascript
for (let i = 1; i <= 10; i++) {
    console.log(i);
}
```

**Task:** Print the numbers from 10 down to 1 using a `while` loop.

## Exercise 2: Positive, Negative, or Zero
**Difficulty:** Basic
**Concepts:** Conditionals (`if`/`else if`/`else`), comparison operators, `prompt()`.

Write a program that asks the user for a number and reports whether it is positive, negative, or zero.

**Starter code:**
```javascript
const num = Number(prompt("Enter a number:"));

if (num > 0) {
    console.log("Positive");
} else if (num < 0) {
    console.log("Negative");
} else {
    console.log("Zero");
}
```

**Task:** Also print whether the number is even or odd.

## Exercise 3: Reverse a String
**Difficulty:** Basic
**Concepts:** Strings, `split()`, `reverse()`, `join()`, or a manual loop.

Write a program that takes a string and prints it reversed.

**Starter code:**
```javascript
const text = "hello";
const reversed = text.split("").reverse().join("");
console.log(reversed); // "olleh"
```

**Task:** Reimplement the reversal using a `for` loop that builds the result character by character.

## Exercise 4: Sum of Array Elements
**Difficulty:** Basic
**Concepts:** Arrays, `for` loops, `reduce()`, accumulator variables.

Write a program that computes the sum of all numbers in an array.

**Starter code:**
```javascript
const numbers = [3, 7, 1, 9, 4];

let sum = 0;
for (const n of numbers) {
    sum += n;
}
console.log("Sum:", sum);
```

**Task:** Also compute the average and print the largest number in the array.

## Exercise 5: FizzBuzz
**Difficulty:** Basic
**Concepts:** Loops, conditionals, modulo (`%`), template literals.

Write a program that prints the numbers 1 to 20, but for multiples of 3 print "Fizz", for multiples of 5 print "Buzz", and for multiples of both print "FizzBuzz".

**Starter code:**
```javascript
for (let i = 1; i <= 20; i++) {
    if (i % 15 === 0) {
        console.log("FizzBuzz");
    } else if (i % 3 === 0) {
        console.log("Fizz");
    } else if (i % 5 === 0) {
        console.log("Buzz");
    } else {
        console.log(i);
    }
}
```

**Task:** Let the user choose the upper limit instead of hardcoding 20.
