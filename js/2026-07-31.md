## Exercise 1: Hello World and Variables

**Title:** Hello, JavaScript! — Console Output and Variables

**Description:** Write a JavaScript program that declares variables using `let` and `const`, stores your name and age, and logs a greeting message to the console. Also display the data type of each variable using `typeof`.

**Difficulty:** ★☆☆☆☆ (Very Easy)

**Concepts Practiced:**
- `console.log()`
- Variable declaration (`let`, `const`)
- Data types (string, number)
- `typeof` operator
- Template literals

**Starter Code:**
```javascript
// Exercise 1: Hello, JavaScript!
const name = "Alice";
let age = 25;
const currentYear = 2026;

console.log(`Hello, my name is ${name}.`);
console.log(`I am ${age} years old.`);
console.log(`I was born in ${currentYear - age}.`);
console.log(`Type of name: ${typeof name}`);
console.log(`Type of age: ${typeof age}`);
```

## Exercise 2: Temperature Converter

**Title:** Celsius to Fahrenheit Converter

**Description:** Write a JavaScript function that converts a temperature from Celsius to Fahrenheit using the formula: F = (C × 9/5) + 32. Create an array of Celsius values, convert each one, and print the results.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Functions (declaration and invocation)
- Arithmetic operations
- Arrays
- `for` loops or `forEach`
- Template literals

**Starter Code:**
```javascript
// Exercise 2: Temperature Converter
function celsiusToFahrenheit(celsius) {
    return (celsius * 9/5) + 32;
}

const celsiusTemps = [0, 10, 20, 30, 40, 100];

for (let i = 0; i < celsiusTemps.length; i++) {
    const f = celsiusToFahrenheit(celsiusTemps[i]);
    console.log(`${celsiusTemps[i]}°C = ${f}°F`);
}
```

## Exercise 3: Palindrome Checker

**Title:** Is It a Palindrome?

**Description:** Write a JavaScript function that checks whether a given string is a palindrome (reads the same forwards and backwards). Ignore case, spaces, and punctuation. Test with words like "racecar", "A man a plan a canal Panama", and "hello".

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- String methods (`toLowerCase`, `replace`, `split`, `reverse`, `join`)
- Regular expressions (basic)
- Functions with return values
- Conditional logic

**Starter Code:**
```javascript
// Exercise 3: Palindrome Checker
function isPalindrome(str) {
    const cleaned = str.toLowerCase().replace(/[^a-z0-9]/g, '');
    const reversed = cleaned.split('').reverse().join('');
    return cleaned === reversed;
}

const testWords = ["racecar", "A man a plan a canal Panama", "hello", "Madam"];
testWords.forEach(word => {
    console.log(`"${word}" → ${isPalindrome(word) ? "Palindrome" : "Not a palindrome"}`);
});
```

## Exercise 4: Array Sum and Average

**Title:** Array Statistics Calculator

**Description:** Write a JavaScript program that takes an array of numbers and calculates: the sum of all elements, the average, the maximum value, and the minimum value. Use both a traditional loop and the `reduce` method.

**Difficulty:** ★★☆☆☆ (Easy)

**Concepts Practiced:**
- Array iteration (`for` loop, `forEach`)
- `reduce()` method
- `Math.max()` and `Math.min()` with spread operator
- Array length property

**Starter Code:**
```javascript
// Exercise 4: Array Statistics
const numbers = [15, 22, 8, 42, 7, 19, 33, 5];

// Using reduce
const sum = numbers.reduce((acc, num) => acc + num, 0);
const avg = sum / numbers.length;
const max = Math.max(...numbers);
const min = Math.min(...numbers);

console.log(`Array: [${numbers}]`);
console.log(`Sum: ${sum}`);
console.log(`Average: ${avg.toFixed(2)}`);
console.log(`Maximum: ${max}`);
console.log(`Minimum: ${min}`);
```

## Exercise 5: Simple To-Do List

**Title:** To-Do List Array Manager

**Description:** Write a JavaScript program that manages a to-do list using an array of objects. Each task has an `id`, `title`, and `completed` property. Implement functions to: add a task, mark a task as complete, delete a task, and list all tasks.

**Difficulty:** ★★★☆☆ (Moderate)

**Concepts Practiced:**
- Arrays of objects
- Array methods (`push`, `filter`, `find`, `findIndex`)
- Functions with parameters
- Object property access
- Arrow functions

**Starter Code:**
```javascript
// Exercise 5: To-Do List Manager
let todos = [];
let nextId = 1;

function addTask(title) {
    todos.push({ id: nextId++, title, completed: false });
    console.log(`Added: "${title}"`);
}

function completeTask(id) {
    const task = todos.find(t => t.id === id);
    if (task) {
        task.completed = true;
        console.log(`Completed: "${task.title}"`);
    }
}

function deleteTask(id) {
    todos = todos.filter(t => t.id !== id);
    console.log(`Deleted task #${id}`);
}

function listTasks() {
    console.log("\n--- To-Do List ---");
    todos.forEach(t => {
        const status = t.completed ? "✓" : " ";
        console.log(`[${status}] #${t.id}: ${t.title}`);
    });
}

// Test it
addTask("Learn JavaScript");
addTask("Build a project");
completeTask(1);
addTask("Exercise");
listTasks();
deleteTask(3);
listTasks();
```
