## Exercise 1: Even or Odd Check

**Difficulty:** Basic

### Problem
Write a function `isEven(n)` that returns `true` if `n` is even and `false` otherwise.

**Given Input:** `isEven(4)`, `isEven(7)`

**Expected Output:**
```
true
false
```

### Concepts
- Modulo operator (`%`)
- `return` statement
- Strict equality (`===`)

### Example / Starter Code

```javascript
function isEven(n) {
  return n % 2 === 0;
}

console.log(isEven(4));   // true
console.log(isEven(7));   // false
```

## Exercise 2: Factorial of a Number

**Difficulty:** Basic

### Problem
Write a function `factorial(n)` that returns `n!` (the product of all positive integers up to `n`). Return `1` for `0`.

**Given Input:** `factorial(5)`

**Expected Output:**
```
120
```

### Concepts
- `for` loops
- Accumulator pattern
- Multiplication

### Example / Starter Code

```javascript
function factorial(n) {
  let result = 1;
  for (let i = 1; i <= n; i++) {
    result *= i;
  }
  return result;
}

console.log(factorial(5));   // 120
console.log(factorial(0));   // 1
```

## Exercise 3: FizzBuzz

**Difficulty:** Basic

### Problem
Write a function `fizzBuzz(n)` that logs the numbers from `1` to `n`. For multiples of `3` log `"Fizz"`, for multiples of `5` log `"Buzz"`, and for multiples of both log `"FizzBuzz"`. Otherwise log the number.

**Given Input:** `fizzBuzz(15)`

**Expected Output (first lines):**
```
1
2
Fizz
4
Buzz
...
14
FizzBuzz
```

### Concepts
- `for` loop
- `if / else if / else`
- Modulo divisibility

### Example / Starter Code

```javascript
function fizzBuzz(n) {
  for (let i = 1; i <= n; i++) {
    if (i % 15 === 0) {
      console.log("FizzBuzz");
    } else if (i % 3 === 0) {
      console.log("Fizz");
    } else if (i % 5 === 0) {
      console.log("Buzz");
    } else {
      console.log(i);
    }
  }
}

fizzBuzz(15);
```

## Exercise 4: Count Vowels in a String

**Difficulty:** Basic

### Problem
Write a function `countVowels(str)` that returns how many vowels (`a, e, i, o, u`) appear in a string, ignoring case.

**Given Input:** `countVowels("Hello World")`

**Expected Output:**
```
3
```

### Concepts
- `toLowerCase()`
- `includes()` or a vowel set
- `for...of` loop

### Example / Starter Code

```javascript
function countVowels(str) {
  const vowels = "aeiou";
  let count = 0;
  for (const ch of str.toLowerCase()) {
    if (vowels.includes(ch)) {
      count++;
    }
  }
  return count;
}

console.log(countVowels("Hello World"));   // 3
console.log(countVowels("JavaScript"));    // 3
```

## Exercise 5: Fibonacci Series

**Difficulty:** Basic

### Problem
Write a function `fibonacci(n)` that returns the first `n` terms of the Fibonacci sequence as an array (0, 1, 1, 2, 3, 5, ...).

**Given Input:** `fibonacci(7)`

**Expected Output:**
```
[0, 1, 1, 2, 3, 5, 8]
```

### Concepts
- Arrays and `push()`
- Tracking two previous values
- Loops

### Example / Starter Code

```javascript
function fibonacci(n) {
  const seq = [0, 1];
  for (let i = 2; i < n; i++) {
    seq.push(seq[i - 1] + seq[i - 2]);
  }
  return seq.slice(0, n);
}

console.log(fibonacci(7));   // [0, 1, 1, 2, 3, 5, 8]
console.log(fibonacci(2));   // [0, 1]
```
