**Concepts:** Switch statements, functions, arithmetic operators, user interaction

**Description:** Write a function `calculator(a, b, operator)` that takes two numbers and an operator string (`"+"`, `"-"`, `"*"`, `"/"`), performs the operation, and returns the result. Use a `switch` statement. Handle division by zero with an error message.

**Starter Code:**
```javascript

    // Your switch statement here
}

console.log(calculator(10, 5, "+"));  // 15
console.log(calculator(10, 5, "-"));  // 5
console.log(calculator(10, 5, "*"));  // 50
console.log(calculator(10, 5, "/"));  // 2
```
