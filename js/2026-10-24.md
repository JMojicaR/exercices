## Exercise 1: Print a Right-Angled Triangle of Stars
**Difficulty:** Basic
**Concepts:** `for` loops, `String.prototype.repeat()`, `console.log()`

Print a right-angled triangle of `*` where the number of rows is user-supplied.

**Starter code:**
```javascript
const rows = parseInt(prompt("Enter number of rows: "), 10);

for (let i = 1; i <= rows; i++) {
    console.log("*".repeat(i));
}
```

**Task:** Print an inverted triangle instead, then print numbers (`1`, `22`, `333`, …) using a nested loop rather than `repeat()`.

## Exercise 2: Print Floyd's Triangle
**Difficulty:** Basic
**Concepts:** nested loops, running counter, string concatenation

Print Floyd's triangle — consecutive numbers arranged in rows of increasing length.

**Starter code:**
```javascript
const rows = parseInt(prompt("Enter number of rows: "), 10);
let num = 1;

for (let i = 1; i <= rows; i++) {
    let row = "";
    for (let j = 0; j < i; j++) {
        row += num + " ";
        num++;
    }
    console.log(row.trim());
}
```

**Task:** Right-align the triangle using `String.prototype.padStart()`, and start the counter at a user-supplied value.

## Exercise 3: Count Uppercase and Lowercase Letters
**Difficulty:** Basic
**Concepts:** string iteration (`for...of`), character code comparison, counters

Count how many uppercase and lowercase letters a string contains.

**Starter code:**
```javascript
const text = prompt("Enter a string: ");
let upper = 0;
let lower = 0;

for (const ch of text) {
    if (ch >= "A" && ch <= "Z") upper++;
    else if (ch >= "a" && ch <= "z") lower++;
}

console.log("Uppercase:", upper, "Lowercase:", lower);
```

**Task:** Also count digits and whitespace using regex tests (`/\d/`, `/\s/`), and print a full breakdown.

## Exercise 4: Remove All Spaces from a String
**Difficulty:** Basic
**Concepts:** `String.prototype.replace()`, regular expressions

Remove every space from an input string and print the result.

**Starter code:**
```javascript
const text = prompt("Enter a string: ");
const noSpaces = text.replace(/ /g, "");
console.log("Without spaces:", noSpaces);
```

**Task:** Remove tabs and newlines too using `/\s/g`, and implement a manual version with a loop and `charAt()`.

## Exercise 5: Find the Largest Digit in a Number
**Difficulty:** Basic
**Concepts:** `%` and `Math.floor()`, `while` loop, max tracking

Read a whole number and print its largest single digit.

**Starter code:**
```javascript
let num = parseInt(prompt("Enter a number: "), 10);
let largest = 0;

while (num > 0) {
    const digit = num % 10;
    if (digit > largest) largest = digit;
    num = Math.floor(num / 10);
}

console.log("Largest digit:", largest);
```

**Task:** Also find the smallest digit, and handle negative input by using `Math.abs()`.
