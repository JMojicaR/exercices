## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** `.split()`, `.reverse()`, `.join()`, function return values

Write a function that returns the input string reversed.

**Starter code:**
```javascript
function reverseString(str) {
  return str.split("").reverse().join("");
}

console.log(reverseString("hello"));  // expected: "olleh"
console.log(reverseString("JavaScript"));  // expected: "tpircSavaJ"
```

**Task:** Rewrite the function using a `for` loop that builds the reversed string character by character.

## Exercise 2: Check Palindrome
**Difficulty:** Basic
**Concepts:** `.toLowerCase()`, string comparison, conditional return

Check whether a string reads the same forwards and backwards (ignoring case).

**Starter code:**
```javascript
function isPalindrome(str) {
  const lower = str.toLowerCase();
  return lower === lower.split("").reverse().join("");
}

console.log(isPalindrome("Radar"));  // expected: true
console.log(isPalindrome("hello"));  // expected: false
```

**Task:** Extend the function to ignore spaces and punctuation (e.g. `"A man, a plan, a canal: Panama"` should return `true`).

## Exercise 3: Count Vowels
**Difficulty:** Basic
**Concepts:** `for...of` loop, `includes()`, counter variable, `.toLowerCase()`

Count how many vowels (a, e, i, o, u) appear in a string, case-insensitively.

**Starter code:**
```javascript
function countVowels(str) {
  const vowels = "aeiou";
  let count = 0;
  for (const ch of str.toLowerCase()) {
    if (vowels.includes(ch)) {
      count++;
    }
  }
  return count;
}

console.log(countVowels("hello world"));  // expected: 3
```

**Task:** Also count the consonants and return both counts in an object `{ vowels, consonants }`.

## Exercise 4: Count Character Occurrences
**Difficulty:** Basic
**Concepts:** `split()`/`filter()`, function parameters, string arguments

Count how many times a given character appears in a string.

**Starter code:**
```javascript
function countChar(str, ch) {
  return str.split(ch).length - 1;
}

console.log(countChar("banana", "a"));  // expected: 3
console.log(countChar("hello", "l"));   // expected: 2
```

**Task:** Rewrite the function using a `for` loop and a counter, without `split()`.

## Exercise 5: Count Words
**Difficulty:** Basic
**Concepts:** `.trim()`, `split(/\s+/)`, `.length`, regular expressions

Count the number of words in a sentence (words separated by whitespace).

**Starter code:**
```javascript
function countWords(sentence) {
  return sentence.trim().split(/\s+/).length;
}

console.log(countWords("I love programming"));  // expected: 3
console.log(countWords("One two three four"));  // expected: 4
```

**Task:** Handle the edge case of an empty string (should return `0`, not `1`).
