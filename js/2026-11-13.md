# JavaScript — Basic Exercises (2026-11-13)
Sources: MDN, W3Schools, freeCodeCamp, Node.js docs

Theme: **File I/O** — reading and writing files in Node.js using the built-in `fs` module.

## Exercise 1: Write Text to a File
**Difficulty:** Basic
**Concepts:** `require("fs")`, `fs.writeFileSync`, file paths

Write a program that creates a file named `notes.txt` and writes a greeting into it. `fs.writeFileSync` creates the file if it doesn't exist and overwrites it if it does.

**Starter code:**
```javascript
const fs = require("fs");

fs.writeFileSync("notes.txt", "Hello from Node.js!\n");

console.log("File written.");
```

**Task:** Write multiple lines by building a string with `\n` or by joining an array of lines, then write it all in a single `writeFileSync` call.

## Exercise 2: Read an Entire File
**Difficulty:** Basic
**Concepts:** `fs.readFileSync`, encoding (`"utf8"`), string output

Write a program that reads the contents of `notes.txt` and prints them to the console.

**Starter code:**
```javascript
const fs = require("fs");

const content = fs.readFileSync("notes.txt", "utf8");

console.log(content);
```

**Task:** Read the file without the `"utf8"` encoding argument and print the result — you'll get a `Buffer`. Then convert it with `.toString()` and print that instead.

## Exercise 3: Append a Line to a File
**Difficulty:** Basic
**Concepts:** `fs.appendFileSync`, appending without overwriting

Write a program that adds a new line to the end of `notes.txt` without deleting what is already there.

**Starter code:**
```javascript
const fs = require("fs");

fs.appendFileSync("notes.txt", "Appended line\n");

console.log("Appended.");
```

**Task:** Use a loop to append the numbers 1 through 5, one per line. Then read the file back and verify the original first line is still present.

## Exercise 4: Count Lines and Words
**Difficulty:** Basic
**Concepts:** `String.split()`, arrays, `.length`, filtering

Write a program that reads `notes.txt` and reports how many lines it has and how many words (space-separated tokens) it contains in total.

**Starter code:**
```javascript
const fs = require("fs");

const content = fs.readFileSync("notes.txt", "utf8");
const lines = content.split("\n");

let wordCount = 0;
for (const line of lines) {
  wordCount += line.trim() === "" ? 0 : line.trim().split(/\s+/).length;
}

console.log(`Lines: ${lines.length}`);
console.log(`Words: ${wordCount}`);
```

**Task:** Filter out empty lines before counting (hint: the trailing `\n` may create a final empty string). Then count how many lines contain the word "the" (case-insensitive) using `.filter()`.

## Exercise 5: Copy a File
**Difficulty:** Basic
**Concepts:** reading one file and writing another, `fs.existsSync`

Write a program that copies the contents of `notes.txt` into a new file named `notes_copy.txt`.

**Starter code:**
```javascript
const fs = require("fs");

const content = fs.readFileSync("notes.txt", "utf8");
fs.writeFileSync("notes_copy.txt", content);

console.log("Copied.");
```

**Task:** Use `fs.existsSync("notes_copy.txt")` to warn the user before overwriting an existing copy. Then try the one-liner `fs.copyFileSync("notes.txt", "notes_copy.txt")` and compare the result.
