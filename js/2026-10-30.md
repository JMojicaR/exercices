## Exercise 1: Linear Search
**Difficulty:** Basic
**Concepts:** `for` loop, array indexing, comparison, `return`, functions

Write a function that searches for a target value in an array and returns its index, or `-1` if not found.

**Starter code:**
```javascript
function linearSearch(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) {
      return i;
    }
  }
  return -1;
}

const numbers = [10, 23, 45, 70, 11, 15];
console.log(linearSearch(numbers, 70)); // expected: 3
console.log(linearSearch(numbers, 99)); // expected: -1
```

**Task:** Use `console.log` to print each element as it is checked, so you can watch the search step through the array.

## Exercise 2: Binary Search
**Difficulty:** Basic
**Concepts:** `while` loop, `Math.floor()`, midpoint index, sorted input

Search for a target in a *sorted* array using binary search, halving the search range each step.

**Starter code:**
```javascript
function binarySearch(arr, target) {
  let low = 0;
  let high = arr.length - 1;
  while (low <= high) {
    const mid = Math.floor((low + high) / 2);
    if (arr[mid] === target) return mid;
    if (arr[mid] < target) low = mid + 1;
    else high = mid - 1;
  }
  return -1;
}

const sortedNums = [1, 3, 5, 7, 9, 11, 13];
console.log(binarySearch(sortedNums, 9)); // expected: 4
console.log(binarySearch(sortedNums, 4)); // expected: -1
```

**Task:** Add a counter and return the number of iterations the `while` loop performed.

## Exercise 3: Bubble Sort
**Difficulty:** Basic
**Concepts:** nested `for` loops, swapping with a temp variable, comparison operators

Sort an array in ascending order using bubble sort (repeatedly swap adjacent out-of-order elements).

**Starter code:**
```javascript
function bubbleSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    for (let j = 0; j < n - 1 - i; j++) {
      if (arr[j] > arr[j + 1]) {
        const temp = arr[j];
        arr[j] = arr[j + 1];
        arr[j + 1] = temp;
      }
    }
  }
  return arr;
}

const data = [64, 34, 25, 12, 22, 11, 90];
console.log(bubbleSort(data)); // expected: [11, 12, 22, 25, 34, 64, 90]
```

**Task:** Add a `swapped` flag to stop early when a pass makes no swaps, then compare the number of passes on a nearly-sorted array.

## Exercise 4: Find Minimum and Maximum
**Difficulty:** Basic
**Concepts:** iteration, comparison, tracking state variables, empty-array edge case

Find and return the smallest and largest values in an array in a single pass.

**Starter code:**
```javascript
function findMinMax(arr) {
  if (arr.length === 0) return [null, null];
  let min = arr[0];
  let max = arr[0];
  for (const val of arr) {
    if (val < min) min = val;
    if (val > max) max = val;
  }
  return [min, max];
}

const nums = [45, 2, 78, 13, 9, 54];
console.log(findMinMax(nums)); // expected: [2, 78]
```

**Task:** Return the *indices* of the min and max elements too, using `indexOf` or a manual loop.

## Exercise 5: Selection Sort
**Difficulty:** Basic
**Concepts:** nested loops, index tracking, swapping, finding the minimum in a sub-range

Sort an array using selection sort: repeatedly find the smallest remaining element and move it to the front.

**Starter code:**
```javascript
function selectionSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n; i++) {
    let minIdx = i;
    for (let j = i + 1; j < n; j++) {
      if (arr[j] < arr[minIdx]) minIdx = j;
    }
    [arr[i], arr[minIdx]] = [arr[minIdx], arr[i]]; // destructuring swap
  }
  return arr;
}

const data = [29, 10, 14, 37, 13];
console.log(selectionSort(data)); // expected: [10, 13, 14, 29, 37]
```

**Task:** Rewrite the swap using a temporary variable (without destructuring), then sort in descending order.
