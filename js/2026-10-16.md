## Exercise 1: Reverse a String
**Difficulty:** Basic
**Concepts:** strings, arrays, split/join/reverse

Write a function that reverses a given string.

**Starter code:**
```javascript
function reverseString(str) {
  return str.split("").reverse().join("");
}

console.log(reverseString("hello")); // "olleh"
```

**Task:** Reverse the string using a `for` loop instead of the built-in `reverse()`.

## Exercise 2: Largest of Three Numbers
**Difficulty:** Basic
**Concepts:** conditionals, Math.max, comparisons

Write a function that returns the largest of three numbers.

**Starter code:**
```javascript
function largestOfThree(a, b, c) {
  let largest = a;
  if (b > largest) largest = b;
  if (c > largest) largest = c;
  return largest;
}

console.log(largestOfThree(3, 9, 5)); // 9
```

**Task:** Rewrite it using `Math.max(a, b, c)` and confirm it gives the same result.

## Exercise 3: Multiplication Table
**Difficulty:** Basic
**Concepts:** for loop, template literals, console output

Print the multiplication table (1 to 10) for a given number.

**Starter code:**
```javascript
function multiplicationTable(n) {
  for (let i = 1; i <= 10; i++) {
    console.log(`${n} x ${i} = ${n * i}`);
  }
}

multiplicationTable(5);
```

**Task:** Print the table for every number from 1 to 5.

## Exercise 4: Armstrong Number
**Difficulty:** Basic
**Concepts:** while loop, modulo, exponent operator, string length

Check whether a number is an Armstrong number (sum of digits raised to the number of digits equals the number itself).

**Starter code:**
```javascript
function isArmstrong(n) {
  const digits = String(n).length;
  let sum = 0;
  let num = n;

  while (num > 0) {
    sum += (num % 10) ** digits;
    num = Math.floor(num / 10);
  }

  return sum === n;
}

console.log(isArmstrong(153)); // true
```

**Task:** Print all Armstrong numbers between 1 and 1000.

## Exercise 5: Count Digits in a Number
**Difficulty:** Basic
**Concepts:** while loop, Math.floor, counting

Write a function that counts the digits of a positive integer.

**Starter code:**
```javascript
function countDigits(n) {
  let count = 0;
  n = Math.abs(n);
  while (n > 0) {
    n = Math.floor(n / 10);
    count++;
  }
  return count;
}

console.log(countDigits(12345)); // 5
```

**Task:** Handle the special case where `n` is 0 (should return 1).
