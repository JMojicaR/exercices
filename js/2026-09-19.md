## 1. Hello, World! and Console Logging
**Description:** Log a greeting to the browser console / Node console. Print a few values of different types to observe output.
**Difficulty:** Basic
**Concepts:** `console.log()`, running JS in Node/browser, string literals.
**Starter code:**
```javascript
console.log("Hello, World!");
console.log("The answer is", 42);
```

## 2. Even or Odd Function
**Description:** Write a function that takes an integer and returns whether it is even or odd.
**Difficulty:** Basic
**Concepts:** Functions, `return`, conditionals, modulo operator `%`, strict equality `===`.
**Starter code:**
```javascript
function isEvenOrOdd(num) {
  if (num % 2 === 0) {
    return "even";
  } else {
    return "odd";
  }
}
console.log(isEvenOrOdd(7)); // "odd"
```

## 3. Sum of Array Elements
**Description:** Write a function that takes an array of numbers and returns their sum.
**Difficulty:** Basic
**Concepts:** Arrays, `for` loop, `for...of`, accumulator variable.
**Starter code:**
```javascript
function sumArray(arr) {
  let total = 0;
  for (const num of arr) {
    total += num;
  }
  return total;
}
console.log(sumArray([1, 2, 3, 4, 5])); // 15
```

## 4. Reverse a String
**Description:** Write a function that reverses a given string.
**Difficulty:** Basic
**Concepts:** Strings, `split()`/`join()`, arrays, loops.
**Starter code:**
```javascript
function reverseString(str) {
  return str.split("").reverse().join("");
}
console.log(reverseString("hello")); // "olleh"
```

## 5. FizzBuzz
**Description:** Print numbers 1 to 100, replacing multiples of 3 with "Fizz", multiples of 5 with "Buzz", and multiples of both with "FizzBuzz".
**Difficulty:** Basic
**Concepts:** `for` loop, `if`/`else if`/`else`, modulo operator, order of conditions.
**Starter code:**
```javascript
for (let i = 1; i <= 100; i++) {
  if (i % 15 === 0) console.log("FizzBuzz");
  else if (i % 3 === 0) console.log("Fizz");
  else if (i % 5 === 0) console.log("Buzz");
  else console.log(i);
}
```
