## Exercise 1: Build and Print a Linked List
**Difficulty:** Basic
**Concepts:** plain objects as nodes, `while`-loop traversal, `console.log`

A node is just an object with a `value` and a `next` reference (`null` marks the end).

**Starter code:**
```javascript
const head = {
  value: 10,
  next: {
    value: 20,
    next: {
      value: 30,
      next: null,
    },
  },
};

let current = head;
while (current !== null) {
  console.log(current.value);
  current = current.next;
}
// 10, 20, 30
```

**Task:** Write a function `printList(head)` that prints values joined by `" -> "` and ends with `"null"` (e.g. `10 -> 20 -> 30 -> null`).

## Exercise 2: Append a Node to the End
**Difficulty:** Basic
**Concepts:** walking to the tail, empty-list edge case, mutating `next`

**Starter code:**
```javascript
function append(head, value) {
  if (head === null) return { value, next: null };
  let current = head;
  while (current.next !== null) {
    current = current.next;
  }
  current.next = { value, next: null };
  return head;
}

let head = append(null, 10);
append(head, 20);
append(head, 30);
// 10 -> 20 -> 30 -> null
```

**Task:** Append the numbers `1..5` into an empty list in a `for` loop, then print the list.

## Exercise 3: Length and Sum of a Linked List
**Difficulty:** Basic
**Concepts:** counter variable, accumulating a running total

**Starter code:**
```javascript
function length(head) {
  let count = 0;
  let current = head;
  while (current !== null) {
    count++;
    current = current.next;
  }
  return count;
}

function total(head) {
  let sum = 0;
  let current = head;
  while (current !== null) {
    sum += current.value;
    current = current.next;
  }
  return sum;
}
```

**Task:** Build a list `5 -> 10 -> 15` and verify `length` returns `3` and `total` returns `30`.

## Exercise 4: Search for a Value
**Difficulty:** Basic
**Concepts:** early `return`, strict equality (`===`) comparison

**Starter code:**
```javascript
function contains(head, target) {
  let current = head;
  while (current !== null) {
    if (current.value === target) return true;
    current = current.next;
  }
  return false;
}
```

**Task:** Write `findIndex(head, target)` that returns the 0-based index of the first match, or `-1` if absent.

## Exercise 5: Delete the First Matching Node
**Difficulty:** Basic
**Concepts:** rewiring `next` pointers, head-removal special case

**Starter code:**
```javascript
function remove(head, value) {
  if (head === null) return null;
  if (head.value === value) return head.next;   // new head
  let current = head;
  while (current.next !== null && current.next.value !== value) {
    current = current.next;
  }
  if (current.next !== null) {
    current.next = current.next.next;
  }
  return head;
}
```

**Task:** Test `remove` on a list `10 -> 20 -> 30` by removing the head, then a middle node, then a missing value (list unchanged).
