## Exercise 1: Multiplication Table

**Difficulty:** Basic

### Problem
Write a program that prints the multiplication table of a given number `n` from 1 to 10 using a `for` loop and template literals.

**Given Input:** `5`

**Expected Output:**
```
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

### Concepts
- `for` loop
- Template literals (`` `${...}` ``)
- `console.log()`

### Example / Starter Code

```javascript
const n = 5;

for (let i = 1; i <= 10; i++) {
  console.log(`${n} x ${i} = ${n * i}`);
}
```

## Exercise 2: Largest of Three Numbers

**Difficulty:** Basic

### Problem
Write a program that finds the largest of three numbers using `if`/`else if`/`else`.

**Given Input:** `10 25 15`

**Expected Output:**
```
Largest: 25
```

### Concepts
- Comparison operators (`>=`, `&&`)
- `if`/`else if`/`else` branching
- `let` variable declaration

### Example / Starter Code

```javascript
const a = 10, b = 25, c = 15;
let largest;

if (a >= b && a >= c) {
  largest = a;
} else if (b >= a && b >= c) {
  largest = b;
} else {
  largest = c;
}

console.log("Largest:", largest);
```

## Exercise 3: Reverse a String

**Difficulty:** Basic

### Problem
Write a program that reverses a string using `split()`, `reverse()`, and `join()`.

**Given Input:** `hello`

**Expected Output:**
```
Reversed: olleh
```

### Concepts
- String methods: `.split('')`, `.reverse()`, `.join('')`
- Method chaining

### Example / Starter Code

```javascript
const text = "hello";
const reversed = text.split('').reverse().join('');
console.log("Reversed:", reversed);
```

## Exercise 4: Leap Year Checker

**Difficulty:** Basic

### Problem
Write a program that checks whether a year is a leap year using the modulo operator and boolean logic.

**Given Input:** `2024`

**Expected Output:**
```
2024 is a leap year
```

### Concepts
- Modulo operator `%`
- Boolean logic with `&&` and `||`
- Ternary operator (`? :`)

### Example / Starter Code

```javascript
const year = 2024;
const isLeap = (year % 4 === 0 && year % 100 !== 0) || (year % 400 === 0);

console.log(year + (isLeap ? " is a leap year" : " is not a leap year"));
```

## Exercise 5: Simple Calculator

**Difficulty:** Basic

### Problem
Write a program that performs a basic arithmetic operation on two numbers using a `switch` statement. Handle division by zero and invalid operators.

**Given Input:** `8 2 /`

**Expected Output:**
```
Result: 4
```

### Concepts
- `switch` statement
- Arithmetic operators
- Division-by-zero handling

### Example / Starter Code

```javascript
const a = 8, b = 2, op = '/';
let result;

switch (op) {
  case '+': result = a + b; break;
  case '-': result = a - b; break;
  case '*': result = a * b; break;
  case '/': result = b !== 0 ? a / b : "Error: division by zero"; break;
  default:  result = "Invalid operator";
}

console.log("Result:", result);
```
