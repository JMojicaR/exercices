## Exercise 3: Reverse a String
- **Difficulty:** Easy
- **Description:** Write a function `reverse(str)` that returns the string reversed. Solve it once with a loop and once with `split().reverse().join()`.
- **Concepts:** strings, loops, array methods (`split`, `reverse`, `join`)
- **Starter code:**
```javascript
function reverse(str) {
  return str.split("").reverse().join("");
}
```

## Exercise 5: Sum with `reduce`
- **Difficulty:** Easy
- **Description:** Write a function `sum(arr)` that returns the sum of all numbers in an array using `Array.prototype.reduce`. Then compute the average.
- **Concepts:** arrays, `reduce()`, arrow functions
- **Starter code:**
```javascript
const sum = (arr) => arr.reduce((acc, n) => acc + n, 0);

const nums = [4, 8, 15, 16, 23, 42];
console.log(sum(nums)); // 108

```
